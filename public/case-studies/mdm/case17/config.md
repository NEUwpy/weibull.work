# 案例17: 小样本估计的统计陷阱

## 研究背景

在 MDM 方法示例1的数据分析中，发现了一个反直觉的现象：**在某些参数组合下，n=3（样本量最小）的估计偏差反而比 n=5、n=7 甚至 n=30 更小**。

这引发了三个核心问题：
1. **偶然性问题**：当前是1000次模拟，增加模拟次数是否会消除这种"偶然"？
2. **无解率影响**：n=3的无解率最高（10%+），这是否导致了幸存者偏差？
3. **无解原因**：为什么会无解？无解的条件是什么？

## 研究参数

| 参数 | 符号 | 值 |
|------|------|-----|
| 形状参数 | β | 2.0 |
| 尺度参数 | η | 1000 |
| 位置参数 | γ | 1000 |
| 偏移量 | δ | 0.1 |

## 研究方法

- **样本量**: n = 3, 5, 7, 10, 20, 30
- **蒙特卡洛模拟**: 1000, 2000, 3000, 5000 次
- **分析内容**:
  - 偏差随模拟次数的变化（验证偶然性）
  - 无解率与样本量的关系
  - 估计值的分布特征
  - 无解样本的算法过程可视化

## 可视化图表

1. **偏差对比柱状图** - 各样本量的 β 绝对偏差
2. **无解率柱状图** - 各样本量的无解率
3. **MC次数对比折线图** - 验证偶然性假设
4. **估计值分布图** - β、η、γ 的直方图 + 真实值参考线
5. **无解样本分析** - σ_η(β) 曲线和 ∇(γ) 曲线

## 预期结论

基于初步分析，我们假设：

1. **偶然性假设**：随着模拟次数增加，n=3 的"小偏差"现象将减弱或消失
2. **幸存者偏差假设**：高无解率导致只有"幸运"样本被保留，均值被人为缩小
3. **高方差假设**：n=3 的高方差使得均值不稳定，接近真实值只是巧合
