## 案例16: WMLE 极小样本失效分析

### 研究背景

在案例14的实验中，我们发现 WMLE 方法在极小样本 (n=3, n=5) 时出现异常现象：
- **β 估计值几乎只有两个值：1.0 和 2.5**
- 真实 β=2.0，但估计结果呈现双峰分布
- 这不是正常的统计行为，而是方法失效

### 问题描述

| 样本量 n | 期望行为 | 实际行为 |
|---------|---------|---------|
| n=3 | β 围绕 2.0 分布 | β = 1.0 (60%) 或 2.5 (40%) |
| n=5 | β 围绕 2.0 分布 | β 有向 2.5 收敛趋势 |
| n>=7 | β 围绕 2.0 分布 | 正常分布 ✓ |

### 可能原因

1. **J3 权重表离散化**
   - 论文只提供 5 个离散 β 值: 0.5, 1.0, 1.5, 2.0, 2.5
   - 线性插值在极小样本时可能不够精确

2. **目标函数多模态**
   - 极小样本时目标函数存在多个局部最小值
   - 优化器被困在 β=1.0 或 β=2.5 附近的局部最优

3. **J3 权重边界效应**
   - β > 2.5 时，J3 使用外推公式
   - β < 0.5 时，J3 使用边界值
   - 这可能导致优化器被"吸"向边界

### 研究方法

1. **目标函数可视化**
   - 绘制 β-γ 平面上的等高线图
   - 展示目标函数的多模态特性
   - 对比不同 n 值的目标函数形态

2. **J3 权重分析**
   - 绘制 J3 随 β 变化的曲线
   - 分析 J3 变化率对优化器的影响

3. **多起点优化测试**
   - 从不同初始值出发优化
   - 统计收敛到各局部最小值的频率

4. **β 估计值分布**
   - 1000 次蒙特卡洛模拟
   - 统计 β 估计值的分布

### 预期结论

WMLE 方法**不适用于 n < 5 或 n < 7 的极小样本**。建议：
- 对于 n=3, n=5，使用 MDM 或其他方法
- WMLE 的有效适用范围是 n >= 8（与论文验证范围一致）
