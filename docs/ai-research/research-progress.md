## 1. 当前研究判断

当前 AI 模块处于“研究体系重建”阶段，不处于“结果解释”阶段。

核心判断：

- 旧 M1/M3 有原型价值。
- 旧 M1/M3 没有正式研究结论价值。
- 旧模型不能修修补补后继续使用。
- 新指标、新 benchmark、新损失函数和新训练协议确定后，M1/M3 必须全量重训。

## 4. 研究侧当前不做什么

当前阶段不做：

- 不训练新模型。
- 不解释旧模型精度。
- 不比较旧 AI 与传统方法优劣。
- 不写“AI 显著提升”的结论。
- 不启动 M2。
- 不扩展删失数据。
- 不先设计复杂页面。

原因：

```text
没有统一指标、benchmark、损失函数和传统基准之前，任何训练和比较都可能再次变成不可复用的原型。
```

## 6. 与工程侧的交接关系

研究侧不直接规定代码怎么写，但必须给工程侧明确目标。

交接关系：

| 研究问题 | 工程承接 |
|----------|----------|
| 参数是否估得准 | 参数层指标和公共函数 |
| B1/B5/B10 是否准 | 应用层指标和分位点函数 |
| 方法是否稳定 | 成功率、失败原因、运行时间 |
| AI 是否泛化 | `ig/ip/ex` benchmark |
| M1-A 是否有效 | δ 标签生成协议和对比实验 |
| M1-B 是否有效 | 残差标签和修正前后对比 |
| M3 是否有效 | 全部直接求解方案重训和同集对比 |

---

## 7. 研究侧验收标准

进入下一阶段前必须满足：

1. 系统级指标清单已冻结。
2. Benchmark 数据协议已冻结。
3. M1-A、M1-B、M3 的训练目标已明确。
4. 损失函数候选与研究目标有对应关系。
5. 传统基准方法和失败口径已明确。
6. 工程侧可以据此开始实现公共指标函数和数据管线。

## 8. 组会最低可讲内容

即使还没有新训练结果，也可以汇报：

1. 为什么旧 AI 原型不能作为最终结论。
2. 为什么需要系统级指标规范。
3. M1/M2/M3 的新结构。
4. M1 的两个子方向：过程量优化与偏差修正。
5. 新研究闭环：研究目标 -> 工程指标 -> benchmark -> 全量重训 -> 统一对比 -> 研究结论。
6. 下一步工程任务和预期产物。
