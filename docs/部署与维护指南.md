# 部署与维护指南

## 技术路线

```
用户访问 weibull.work / api.weibull.work
              ↓
       Cloudflare CDN
              ↓
      Cloudflare Tunnel (cloudflared)
              ↓
    ┌─────────┴─────────┐
    ↓                   ↓
前端容器              后端容器
Next.js:3000         FastAPI:8001
```

**关键点：**
- 绿联 NAS 运行 Docker，无公网 IP
- Cloudflare Tunnel 提供外网访问 + HTTPS
- GitHub 托管代码，NAS 通过 git pull 更新

---

## 部署步骤

### 1. Cloudflare 配置

1. 域名 NS 托管到 Cloudflare
2. Zero Trust → Tunnels → 创建 Tunnel
3. 获取 Token
4. 配置 Public Hostname：
   | Subdomain | Domain | Type | URL |
   |-----------|--------|------|-----|
   | (空) | weibull.work | HTTP | frontend:3000 |
   | api | weibull.work | HTTP | backend:8001 |

### 2. NAS 准备

1. 启用 SSH（端口 22）
2. 安装 Docker
3. 能访问外网（git pull 需要）

### 3. 部署到 NAS

```bash
# SSH 登录
ssh WPY@192.168.31.148

# 克隆项目
cd /share
git clone https://github.com/NEUwpy/weibull.work.git weibull
cd weibull

# 启动（首次约 5 分钟）
docker-compose up -d --build

# 验证
docker-compose ps
```

### 4. 验证

- https://weibull.work → 前端页面
- https://api.weibull.work/docs → API 文档

## 日常维护

### 更新流程

```bash
# 1. 本地开发完成后推送到 GitHub
git add .
git commit -m "描述修改内容"
git push

# 2. SSH 登录 NAS
ssh WPY@192.168.31.148

# 3. 拉取更新并重启
cd /share/weibull
git pull
docker-compose up -d --build
```

### 常用命令

| 命令 | 作用 |
|------|------|
| `docker-compose ps` | 查看状态 |
| `docker-compose logs -f` | 查看日志 |
| `docker-compose restart` | 重启服务 |
| `docker-compose down` | 停止服务 |

### 只更新前端/后端

```bash
docker-compose up -d --build frontend  # 只重建前端
docker-compose up -d --build backend   # 只重建后端
```

## 故障排查

| 问题 | 检查命令 |
|------|---------|
| 容器未运行 | `docker-compose ps` |
| 前端报错 | `docker-compose logs frontend` |
| 后端报错 | `docker-compose logs backend` |
| Tunnel 断开 | `docker-compose logs cloudflared` |
| 网络问题 | `ping github.com` |
