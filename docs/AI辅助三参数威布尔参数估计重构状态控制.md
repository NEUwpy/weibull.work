## 4. 当前已确定的关键决策

### 4.1 模块划分

AI 模块采用四分法：

- M1：AI 预测过程量；
- M2：AI 误差修正 / 偏差纠正；
- M3：AI 直接估计；
- M4：智能优化算法。

M3 中允许保留分类扩展，但作为 M3 子方向，不单独新增主模块。

### 4.2 评价体系

评价体系必须包含两套视角：

- 参数估计视角：NE、Bias、MAE、RMSE、Failure Rate、Outlier Rate、Time；
- 工程应用分位点视角：可靠度分位点误差，重点 `R ∈ {0.995, 0.990, 0.950, 0.900}`。

NE 使用 `eta` 归一化 `gamma`：

```text
NE = sqrt(
    ((beta_hat - beta) / beta)^2
  + ((eta_hat - eta) / eta)^2
  + ((gamma_hat - gamma) / eta)^2
)
```

### 4.3 状态判定

方法输出统一分为：

- `success`
- `failure`
- `outlier`

第一版默认 outlier 规则：

```text
NE > 1.0
```

后续可调整，但必须记录阈值并说明原因。

### 4.4 样本规则

所有方法必须使用共享样本。给定参数组合、样本量和重复编号，应能复现同一份样本。

共享样本用于保证传统方法、M1、M2、M3、M4 可以做配对比较。

### 4.5 Loss 对比实验

正式训练复杂模型前，先用简单 M3 直接估计模型比较 loss。

候选包括：

- 原始参数 MSE；
- 标准化参数 MSE；
- NE-Loss；
- Huber Loss；
- Quantile-Loss；
- Hybrid-Loss。

Hybrid-Loss 第一版使用：

```text
alpha ∈ {0, 0.25, 0.5, 0.75, 1.0}
```

除 loss 外的主要训练条件应固定，并尽量重复多次报告均值和方差。

### 4.6 参数空间

第一版建议参数空间：

```text
beta ∈ {0.8, 1.2, 1.5, 2.0, 3.0, 5.0}
eta ∈ {50, 100, 200}
gamma / eta ∈ {0, 0.05, 0.10, 0.20}
n ∈ {10, 20, 30, 50, 100}
```

如果实验预算有限，主实验可先固定 `eta=100`，多个 `eta` 用于数值稳定性扩展。

### 4.7 数据边界

当前第一版只处理完全观测失效数据。删失数据后续单独规划。

## 6. 当前推荐下一步

下一轮最适合做：

```text
S2 统一评价指标
```

目标是建立统一指标计算模块，包含：

1. 参数估计视角：NE、Bias、MAE、RMSE（按参数分别计算）；
2. 工程分位点视角：NQE_R、MAE_QR、RMSE_QR（R∈{0.995, 0.990, 0.950, 0.900}）；
3. 可用性指标：Failure Rate、Outlier Rate、Time；
4. 统一状态判定：success/failure/outlier，outlier 默认规则 NE>1.0。

建议产物：

```text
python/metrics/  (统一指标计算模块)
```

注意：指标模块应独立于具体方法，可被蒙特卡洛框架和 AI 训练脚本共同调用。
