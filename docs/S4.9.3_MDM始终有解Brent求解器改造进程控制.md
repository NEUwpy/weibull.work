## 2. 当前问题

当前 `python/methods/mdm.py` 的核心分支为：

```text
1. 离散梯度曲线存在 offset 交点 -> offset_root
2. 无交点，且 g(0) >= offset -> truncated_at_zero
3. 无交点，且 g(0) < offset -> no_offset_root / no_intersection
```

第 3 分支是 S4.9.3 要修正的对象。

根据 `full.md` 第 9.1 节和 2026-06-05 的人工确认，默认 MDM 只应有三种求解情形：

```text
1. 正常有解：
   梯度曲线在当前定义域内可定位 offset-root，输出内点 gamma_hat。

2. gamma=0 处梯度大于或等于 offset：
   根在 gamma<0，定义域 [0, t_min) 内没有根；
   按 gamma>=0 约束截断到 gamma_hat=0，标记 truncated_at_zero。

3. 当前离散网格最右端（最靠近 t_min 的采样点）梯度仍小于 offset：
   这不是 MDM 无解，而是网格没采到靠近 t_min 的急升段；
   因为 gamma 趋近 t_min 时梯度必然极大，必定存在交点；
   应利用最右网格点与 t_min 近端构造拟合/括弧并求交点，标记 brent_root 或同义策略。
```

因此当前代码的问题不是“MDM 方法真的无解”，而是：

```text
仍然用固定离散网格的 np.gradient 结果决定是否失败，
没有在右端靠近 t_min 处主动构造括弧并定根。
```

---

## 3. S4.9.3 目标

S4.9.3 的目标是把默认 MDM 改成真正符合 `full.md` 第 9.1 节的工程求解器：

1. 默认 MDM 不再因为 `g(0) < offset` 且离散网格没交点而返回 `no_intersection`。
2. 当 `g(0) >= offset` 时，继续输出 `gamma_hat = 0`，`solution_strategy = "truncated_at_zero"`。
3. 当 `g(0) < offset` 时，无论当前离散网格是否已经采到交点，都应输出定义域内 offset-root。若网格已包含交点，可用相邻点插值/Brent 精化；若最右网格点仍低于 offset，则使用最右网格点和 `t_min` 近端急升性质构造拟合/括弧并求交点。输出 `solution_strategy = "brent_root"` 或同义策略名。
4. trace 仍应保留可视化用的离散曲线，但求解结果应来自实际 Brent / 括弧定根，而不是固定网格上的交点漏检。
5. MDM 方法页和曲线性质研究不再展示“诊断失败起点”作为当前默认 MDM 的失败机制。
6. 不要新增第四种默认求解情形，例如 `truncated_at_upper_bound` 或 `offset_above_supported_range`。第三种网格右端仍低于 offset 的情况应补交点，而不是视为超出范围。

## 5. 推荐实现方向

### 5.1 求解流程

建议在 `python/methods/mdm.py` 中把求解主逻辑调整为：

```text
1. 定义 profile 函数 S(gamma) = min_beta sigma_eta(beta, gamma)
2. 定义 profile 梯度函数 g(gamma)
   - 可先用稳定有限差分；
   - 若后续需要更高精度，再按 full.md 的包络梯度公式实现解析梯度。
3. 探测 g(0)
4. 若 g(0) >= offset：
   - gamma_hat = 0
   - solution_strategy = "truncated_at_zero"
5. 若 g(0) < offset：
   - 先检查离散 trace 网格是否已经包含 offset 交点；
   - 若包含，使用该交点相邻采样点作为初始括弧，并可用 Brent / 割线法精化；
   - 若最右网格点仍低于 offset，则利用“gamma 趋近 t_min 时梯度必然极大”的性质，以最右网格点和 t_min 近端构造拟合/括弧；
   - 用 Brent / 割线法求 g(gamma) - offset = 0，或按最右点与 t_min 近端的拟合线求交点；
   - solution_strategy = "brent_root"
6. 最终用 gamma_hat 重新求 beta_hat 和 eta_hat
```

### 5.2 数值边界

需要特别验证：

- 当前实现对 `beta` 的有界优化范围为 `[0.1, 15.0]`；
- 若右端梯度不能按 `full.md` 预期形成括弧，应先排查有限差分、`eps`、`beta` 边界和 profile 梯度定义；不要把它升级为默认 failure 或上边界截断；
- 不要直接恢复 `no_intersection` 作为默认 MDM 失败状态；
- 不要把“离散网格最右端仍低于 offset”解释成 offset 超出范围。根据本轮人工确认，这正是需要用最右网格点与 t_min 近端拟合/定根补上的第三种情形。

### 5.3 trace 字段建议

保留已有字段：

- `search_strategy`
- `solution_strategy`
- `constraint`
- `probe_gradient_at_zero`
- `root_bracket`
- `gamma_steps`
- `optimal_gamma`
- `optimal_beta`

建议新增或调整：

| 字段 | 含义 |
|------|------|
| `root_solver` | `brent` / `secant` / `grid_interpolation` |
| `right_anchor_gamma` | 靠近 `t_min` 的右端锚点 |
| `right_anchor_gradient` | 右端锚点梯度 |
| `root_solver_iterations` | 定根迭代次数 |
| `legacy_grid_crossing` | 可选，仅用于说明离散网格是否也观察到交点 |
| `right_edge_extrapolation` | 可选，标记第三种“最右网格点仍低于 offset，向 t_min 近端补交点”的处理 |

## 10. 2026-06-06 完成记录

S4.9.3 已完成，当前默认 MDM 收束为三种情况：

```text
1. g(0) >= offset：根在 gamma<0，按 gamma>=0 约束截断到 gamma=0，标记 truncated_at_zero；
2. g(0) < offset 且右端括弧成立：使用 Brent 定根，标记 brent_root / root_solver=brent；
3. g(0) < offset 且右端锚点仍低于 offset：不返回 failure、不做上边界截断，按右端补交点规则返回 [0, t_min) 内点，标记 brent_root / root_solver=right_edge_fit。
```

关键实现：

- `python/methods/mdm.py` 使用 `profile_gradient()` 作为求解器和 trace 的同源梯度函数；

- `python/tests/test_mdm_s49.py` 覆盖三种情况、右端补交点、trace 同源性和轻量摘要；
- `python/studies/mdm_delta/generate_curve_study_data.py` 与 `public/case-studies/mdm/curve-study/data.json` 已更新为 S4.9.3 口径；
