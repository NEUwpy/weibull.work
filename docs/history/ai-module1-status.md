# AI 模块 1 现状梳理：MDM 偏移量 δ 优化

> **更新时间**: 2026-04-27
> **状态**: 阶段性结束 — 前端完成、模型已训练、核心问题已识别

## 〇、阶段性结论

**核心发现**：用最优 δ 替代固定 δ 能显著提升 MDM 估计精度（改善 97-99%），方向可行。

**根本问题**：对 MSE-δ 曲线的数学性质（单调性、极值点、有效范围）缺乏系统性认识，导致：
1. 搜索策略盲目 — 不知道该搜多宽、搜多密
2. 训练数据质量不稳定 — 边界过滤、搜索范围不一致
3. 模型学到的映射本身不准确 — 垃圾进垃圾出

**已完成**：框架搭建、模型训练、前端页面、数据可视化——基础设施完备。

**待解决**：需要先从数学层面理解 MSE-δ 曲线性质，再优化搜索策略和训练数据。

## 一、模块 1 做了什么（一句话）

训练了一个神经网络，输入一组失效时间样本，直接输出 MDM 方法应使用的最优偏移量 δ，替代人工反复尝试。

---

## 二、整体流程

```
离线（已完成）:
  蒙特卡洛模拟生成 Weibull 样本
    → 对每个样本粗搜+细搜找最优 δ
    → 每个 δ 运行 MDM 得到 est_β, est_η, est_γ
    → 用相对 MSE(β,η,γ) 选出最优 δ*
    → 训练 PyTorch MLP 学习"样本 → δ*"的映射

在线（已部署）:
  用户输入样本 → API 调用 → 模型推理 → 输出最优 δ
```

## 六、根本问题：MSE-δ 曲线性质不明

### 6.1 问题描述

**根因**：对 MSE-δ 曲线的数学性质缺乏系统性认识，导致搜索策略盲目、训练数据质量不稳定。

具体表现：
1. **不知道曲线形状**：是单调的？有极值点？多峰还是单峰？
2. **不知道有效范围**：δ 在什么范围内 MDM 有解？超出范围会怎样？
3. **不知道最优 δ 的分布**：大部分样本的最优 δ 是 0 还是正数？与 (β,η,n) 有什么关系？

### 6.2 已观察到的现象

从 MSE-δ 曲线分析（`data/mse_curves/summary.csv`）：

| 参数组合 | n | 最优 δ | 曲线特征 |
|----------|---|--------|----------|
| 大部分 n=5 | 5 | 0.005 | 单调递增（δ≈0 最优） |
| b1_e5000_n5 | 5 | 0.17 | 有最小值 |
| b5_e100_n5 | 5 | 0.03 | 有最小值 |
| b2_e1000_n20 | 20 | 0.42 | 有最小值，δ>0.52 后 MDM 失败 |
| b1_e1000_n20 | 20 | 0.005 | 单调递增 |

**关键发现**：
- 小样本（n≤10）大部分情况下 δ=0 最优
- 大样本（n=20）或特定 β/η 组合需要正的 δ
- MDM 在 δ 过大时会失败（无解），形成有效范围天花板
- 不同样本的最优 δ 差异很大（从 0.001 到 >1.0）

### 6.3 导致的连锁问题

**问题 1：搜索范围不一致**
- `generate_training_data.py`：搜索范围 [0.001, 1.0]，粗搜+细搜
- `generate_param_accuracy.py`：搜索范围 **[0.01, 0.50]**，网格搜索
- 两者定义的"最优 δ"不同，导致 param-accuracy 数据不可靠

**问题 2：边界过滤过度**
- ~44% 样本被丢弃（最优 δ 在搜索边界）
- 实际上很多样本的最优 δ 就是 0（小样本），过滤它们是错误的

**问题 3：训练数据噪声大**
- 搜索精度有限（步长 0.01）
- 不同样本的搜索策略不一致
- 模型学到的映射本身就不准确

### 6.4 验证：最优 δ 确实能提升精度

尽管数据质量有问题，现有结果仍证明方向可行：

| 对比 | MSE | 说明 |
|------|-----|------|
| 固定 δ=0.5 | 0.61（n=5 平均） | 人工选择 |
| 最优 δ | ~0.005（n=5 平均） | 搜索得到 |
| 改善幅度 | **99.2%** | 巨大提升 |

**结论**：如果能准确找到最优 δ，MDM 估计精度能大幅提升。问题在于"准确找到"这一步。

## 八、端到端调用链路

### M1-R1（直接学习）

```
用户浏览器
  ↓ 填写失效时间数据
  ↓ 点击"AI 预测最优 δ"
  ↓
src/app/ai/relationship/m1-r1/components/PlaygroundTab.tsx
  ↓ fetch POST /ai/relationship/mdm
  ↓
python/main.py → ai_predict_delta()
  ↓ _load_delta_model(n) — 按样本量加载对应 .pth
  ↓ 排序样本 → 标准化 → PyTorch 推理 → 反缩放
  ↓ 置信度评估（基于是否接近边界）
  ↓
返回 { optimal_delta, model_n, confidence }
  ↓
前端展示 δ 值 + 置信度 + 使用提示
```

### M1-R2（迭代逼近）

```
用户浏览器
  ↓ 填写失效时间数据
  ↓ 点击"迭代逼近预测 δ"
  ↓
src/app/ai/relationship/m1-r2/components/PlaygroundTab.tsx
  ↓ fetch POST /ai/relationship/mdm/iterate
  ↓
python/main.py → ai_predict_delta_iterate()
  ↓ δ₀=0.5 → MDM → M1-R2 网络 → δ₁ → MDM → ... → 收敛
  ↓
返回 { final_delta, final_params, iterations, converged }
  ↓
前端展示最终 δ + 参数估计 + 迭代历史表
```

## 九、下一步方向

### 阶段 1：数学分析（优先）

1. **系统性研究 MSE-δ 曲线性质**
   - 对不同 (β, η, γ, n) 组合，画出完整的 MSE-δ 曲线
   - 分析单调性、极值点、有效范围
   - 建立"最优 δ"与参数的理论关系

2. **确定 MDM 的 δ 有效范围**
   - δ 在什么范围内 MDM 有解？
   - δ 过大会怎样？（已观察到 δ>0.52 后失败）
   - 这个范围与 (β, η, n) 有什么关系？

### 阶段 2：搜索策略优化

3. **基于曲线性质优化搜索**
   - 如果曲线单调递增 → 最优 δ=0，不需要搜索
   - 如果曲线有极值 → 用 Brent 法精确定位
   - 如果曲线在某点后 MDM 失败 → 搜索范围自动限制

4. **统一搜索策略**
   - `generate_training_data.py` 和 `generate_param_accuracy.py` 使用相同搜索
   - 消除边界过滤的任意性

### 阶段 3：数据与模型重建

5. **重新生成训练数据**
   - 基于优化后的搜索策略
   - 提高数据质量（减少噪声、消除边界问题）

6. **重新训练模型**
   - 用高质量数据重新训练 M1-R1/M1-R2
   - 验证精度提升
