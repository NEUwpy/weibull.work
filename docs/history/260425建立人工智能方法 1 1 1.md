● 网络架构                                                                                                                                   
                                                                                                                                           
  两个网络需求不同，分别讨论：                                                                                                               
   
  N₁（真值 → 最优δ）：输入固定 3 维                                                                                                          
                                                      
  输入: (β, η, γ)  →  3 维
  输出: δ*           →  1 维

  这个映射很简单，不需要大网络。建议：

  Linear(3, 32) → ReLU → Linear(32, 16) → ReLU → Linear(16, 1) → Sigmoid

  - 输入只有 3 个特征，隐藏层太大容易过拟合
  - 但参数空间扩展后（β 有 3 个值，η 有 3 个值），数据分布变复杂，不能太小
  - 关键：输入必须标准化，因为 β∈[1,5]、η∈[100,5000]、γ=1000 量纲差异巨大

  N₂（样本 → 最优δ）：输入维度 = n

  原型是 Linear(n,64)→ReLU→Linear(64,32)→ReLU→Linear(32,1)→Sigmoid。

  参数空间扩大后，数据量从 598 增加到 ~13,500（有效数据可能 ~10,000），网络可以稍大一些。建议：

  Linear(n, 128) → ReLU → BatchNorm1d → Linear(128, 64) → ReLU → BatchNorm1d → Linear(64, 1) → Sigmoid

  改动点：
  - 隐藏层从 64→32 扩大到 128→64，匹配更大的参数空间
  - 加 BatchNorm，稳定训练（不同 n 的样本数值范围差异大）
  - 仍然按 n 分别训练（n=5/7/15 各一个模型）

  关于统计特征方案

  之前讨论过用统计特征（mean, std, cv, ...）作为输入，好处是维度固定、可以统一模型。但当前按 n
  分别训练已经可行，建议先用排序值方案，后续对比统计特征方案。

  验证策略

  数据量增大后，需要注意：

  - 随机划分：80/20 随机划分，确保训练集和验证集的参数分布一致
  - 分层划分：可以按 (β, n) 组合分层抽样，保证每个组合在验证集中都有代表
  - 数据泄漏检查：同一个 MC 种子生成的样本不能同时出现在训练和验证集中（当前按行随机划分，不存在这个问题）

  多指标训练

  你说要对比多种指标方案（MSE/相对MSE/...）。实现方式：

  - 训练时用 MSE 作为损失函数（因为需要可微分）
  - 评估时用 5 种指标分别计算，记录在 metrics.json 中
  - 对比时看不同指标下的表现差异
