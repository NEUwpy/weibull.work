## 当前最严重的几个问题

这造成：

- LRE 后端已经能计算，却不能在计算器里选择。
- “能不能算”和“有没有原理文档”被错误地绑定在一起。
- 以后补方法时容易出现前后端状态不一致。

第二，方法总览对所有方法一视同仁。MPS、LSE、MM、PWM、Bayesian 等都能进入详情页，页面也显示完整的六个 Tab 和“在计算器中应用”，但实际只有空白内容或通用壳。例如 MPS 线上页只有“暂无详细文档”，却仍显示“计算过程、结果分析、适用范围、验证、对比”。

```text
/?method=mdm
```
