# MDM strict offset-root 判据的有解性：统一分析

> 本文综合两份前作（下称**报告 A** = 15 000 样本 Monte Carlo 研究，β∈{0.5,1,2,3.5,5}，γ 域向左延伸并贴 t₁；**报告 B** = 1 920 样本 Weibull Analysis Platform 研究，β∈{1,1.5,2,3}，γ∈[0, 0.999999·t_min]），给出一个**闭式梯度公式**与一条**确定性存在判据**，证明两份看似相反的结论实为同一条曲线在不同搜索域下的两端投影，并纠正两者共同的概念问题。

---

## 0. 核心结论（先给出，后证明）

1. **良置性可严格证明。** profile 曲线 `φ(γ)=min_β σ(β|γ)` 与其梯度 `g(γ)=φ'(γ)` 良定义、连续、几乎处处可导，且 `g` 有闭式
    
    ```
    g(γ) = −Cov(η, 1/a) / std(η) = −std(1/a) · ρ(η, 1/a),    |g| ≤ std(1/a)
    ```
    
2. **存在性是确定性命题，不是"有解率"。** 对_给定样本_与_给定搜索域_ D，
    
    ```
    ∃ γ*∈D 使 g(γ*)=offset   ⟺   ψ(γ):=φ(γ)−offset·γ 在 D 内取到极小
    ```
    
    这是一条斜率（割线）判据，不是最小值搜索。
    
3. **两份报告不矛盾。** `g(γ)` 从左端（γ→−∞）的负值 −std(1/a) 升到 t₁ 附近的正值。报告 A 的域向左延伸 → 失败必为 **ALL_BELOW**（近 t₁ 窄峰漏检，分辨率问题，可恢复）；报告 B 的域裁到 γ≥0 → 失败必为 **ALL_ABOVE**（offset 穿越点落在 γ<0 被裁掉，域问题，放开负 γ 即恢复）。两份各自只出现一种失败模式、另一种恰为 0，是这一机制的铁证。
    
4. **真命题。** strict offset-root **不是无条件有解**：在全数学域 (−∞, t₁) 上对 β≥1 通常可解、对 β<1 与小 γ 需谨慎，真无解极少（近 t₁ 振荡）；在裁剪域 γ≥0 上会额外出现"域诱导无解"（all_above），对真值 γ 小者尤甚。

## 1. 记号与假设

有序样本 `t₁ ≤ t₂ ≤ … ≤ tₙ`，`n ≥ 2`，样本非退化（不是所有 tᵢ 相等）。记 `t_min = t₁`。Bernard 中位秩

```
F_i = (i − 0.3)/(n + 0.4) ∈ (0,1)   （关于 i 严格递增）
x_i = −ln(1 − F_i) > 0               （关于 i 严格递增）
```

对 `n ≥ 2` 恒有 `x₁ < 1 < xₙ`（直接代入可验：F₁ ≤ 0.7/2.4 < 1−1/e ≈ 0.632 < Fₙ）。这一点保证后面 β→0 的发散行为。

对 `β > 0`、`γ < t₁`：

```
a_i(β) = x_i^(1/β) > 0        （关于 i 严格递增 ⇒ 1/a_i 关于 i 严格递减，1/a₁ 最大）
η_i(β,γ) = (t_i − γ)/a_i > 0
σ(β|γ)  = std_i{η_i}          （样本标准差，ddof = 1）
```

把内层形状参数限制在紧区间 `B = [β_lo, β_hi] ⊂ (0,∞)`（报告 A 用 geomspace(0.05,60)，报告 B 用 [0.1,15]——两者都是紧集，这一步因此完全合法）。令

```
φ(γ) = min_{β∈B} σ(β|γ),    g(γ) = φ'(γ)
```

搜索域记为 `D = (γ_lo, γ_hi)`，`γ_hi → t₁⁻`。**数学上唯一的硬约束是 γ < t₁**（Weibull 支撑 (γ,∞) 要求）；γ 可以为负。报告 B 取 `γ_lo = 0` 是一个**实现选择**，不是数学条件——这正是后面 §4 的关键。

## 2. 良置性：profile 与梯度的存在与正则性

**引理 1（内层极小存在）。** 固定 γ < t₁，`σ(·|γ)` 在 B 上连续，B 紧，由 Weierstrass 定理最小值存在，故 φ(γ) 良定义。

_（不限制 B 时的补充：β→∞ 有 a_i→1、η_i→t_i−γ，故 σ→std(t) 有限；β→0⁺ 时 1/β→∞，对 x_i<1 的项 a_i→0⁺ 使 η_i→+∞、对 x_i>1 的项 a_i→∞ 使 η_i→0，离散度爆炸 σ→∞。所以两翼一升一平，只要曲线在某有限 β 处低于右渐近线 std(t)，极小就落在内部——实现上直接取紧 B 即可，无需此条件。报告 A、B 实测 σ(β|γ) 均为内部单谷、不贴边界，与此一致。）_

**引理 2（φ 连续、几乎处处可导）。** σ(β|γ) 在 B×(−∞,t₁) 上联合连续（分母 a_i 在紧 B 上离 0 有界、t_i−γ>0）。由 Berge 最大值定理，φ 连续、argmin 集上半连续。φ 是一族光滑函数对紧集取下确界，故局部 Lipschitz，由 Rademacher 定理几乎处处可导。

**引理 3（梯度的闭式——本文核心）。** 在内层最优 β*(γ) 唯一处，由包络定理（Danskin）`g(γ) = ∂σ/∂γ |_{β=β\*(γ)}`。注意 `∂η_i/∂γ = −1/a_i`，记 `V = σ² = (1/(n−1))Σ(η_i−η̄)²`，则

```
dV/dγ = (2/(n−1)) Σ (η_i − η̄)(∂η_i/∂γ) = −2·Cov(η, 1/a)
g = dσ/dγ = (dV/dγ)/(2σ) = −Cov(η, 1/a)/σ = −std(1/a)·ρ(η, 1/a)
```

其中 Cov、std、ρ 均为样本统计量（在 β* 处取）。因此

```
┌─────────────────────────────────────────────┐
│  g(γ) = −std(1/a) · ρ(η, 1/a),   |g| ≤ std(1/a) │
└─────────────────────────────────────────────┘
```

这把"对离散 profile 做数值梯度"换成了一个**解析的相关性表达式**：g 的符号 = −sign(ρ(η,1/a))，g 的量级被 std(1/a) 封顶。后面所有的符号与量级分析都由它直接给出，无需再依赖数值差分。

**备注（角点 = near-miss 的来源）。** 在 β*(γ) 切换（非唯一）处，φ 出现角点，g 在此**跳变**。这意味着离散符号检测可能在 g 从 <offset 跳到 >offset 时漏掉"广义根"（offset 落在左右导数之间却无符号变化）——这正是报告 B 的 `near_miss` 类的机理。严格地说，此时 0 ∈ ∂ψ（次微分），仍应视为判据的解。

## 3. 两端极限与单一存在判据

**3.1 左端（γ → −∞）：g 必为负。** `η_i = t_i/a_i − γ·(1/a_i)`，γ→−∞ 时 `η ≈ (−γ)·(1/a)`，即 η 与 1/a 同向 ⇒ `ρ(η,1/a)→+1`，于是

```
g(γ) → −std(1/a) < 0 < offset
```

因 x_i 两两不同，std(1/a) > 0 严格成立。**这一条对任何样本、任何 β 都成立**——左端永远在 offset 之下。

**3.2 近 t₁：g 转正。** γ→t₁⁻ 时 `η₁=(t₁−γ)/a₁→0⁺`（最小），而 1/a₁ 最大，"小 η 配大 1/a" ⇒ `ρ<0` ⇒ `g>0`。量级由 std(1/a) 决定：

- **β ≥ 1**（1/β ≤ 1，a_i 之间不被压扁）：std(1/a) 温和，g 升到中等正平台（报告 A 实测约 2.2）。
- **β < 1**（1/β > 1，对 x_i<1 的项 a_i→0、1/a_i 爆炸）：std(1/a) 可达数百，g 在 t₁ 极小邻域蹿到数百（报告 A：根落点 (t₁−γ*)/跨度 小到 10⁻⁶）。

**3.3 主定理（域相关存在判据）。** 令 `ψ(γ) = φ(γ) − offset·γ`，连续，且由 §3.1，ψ(γ)→+∞（γ→−∞）。则

```
∃ γ*∈D 使 g(γ*)=offset
   ⟺ ψ 在 D 内取到极小
   ⟺ ∃ γ∈D 使 g 在 γ 两侧分别 <offset 与 >offset（含角点广义根）
```

等价的"割线斜率"形式（这解释了为何报告应当用窗口割线斜率而非点导数去甄别根）：

```
有解 ⟺ ∃ 子区间 [γ, γ′] ⊂ D 使 [φ(γ′)−φ(γ)]/(γ′−γ) = offset
```

**推论（全数学域 D = (−∞, t₁)）。** 左端 g<offset 必成立，故

```
有解 ⟺ sup_{γ<t₁} g(γ) ≥ offset ⟺ g 在近 t₁ 处能否升到 offset
```

这就把"是否有解"完全压到了**右端（近 t₁）能否达到 offset**这一件事上——而它由 β 与 t-构型决定（§3.2）。

**命题（all_above 在负 γ 处有解）。** 若在裁剪域 [0, t₁) 上 g 全域 > offset（即 ALL_ABOVE，g(0)>offset），则由 ψ→+∞（γ→−∞）与 ψ'(0)>0，ψ 必在 (−∞, 0) 内取到极小 γ*，于是 `g(γ*) = offset`，`γ* < 0`。**故 all_above 的"无解"只是裁剪域内的无解，放开负 γ 即恢复一个解。**

## 4. 为什么两份报告结论相反：γ 搜索域是决定性变量

**4.1 镜像现象（铁证）。** 两份报告的失败模式恰好互补：

|失败模式|报告 A（域向左延伸贴 t₁）|报告 B（域裁到 γ∈[0, t₁)）|
|---|--:|--:|
|ALL_BELOW（g 全域 < offset）|**1 908**|**0**|
|ALL_ABOVE（g 全域 > offset）|**0**|**283**|

一份只出现下越界、另一份只出现上越界，另一种各为 0——这不可能是巧合，只能由搜索域左端的位置解释。

**4.2 机制。** g 从左端的负值升到近 t₁ 的正值（§3）：

- **报告 A 的域含 g<offset 的左段**，所以 offset 穿越从下方发生没问题；失败只能在另一端——近 t₁ 的窄峰（β<1 时尤窄）被网格漏采 → **ALL_BELOW** → **分辨率问题**。把 γ_hi 推到 t₁ 并几何加密即恢复（A：总体 0.872→0.988，β=0.5：0.358→0.938）。
- **报告 B 的域被裁到 [0, t₁)**。对真值 γ 很小的样本，谷底（g=0）与其左侧 g<offset 的整段都落在 γ<0，被裁掉；于是 [0, t₁) 上 g 已全在 offset 之上 → **ALL_ABOVE** → **域问题**。`diff_all_above_offset.svg` 即此：g−offset 全程 ≥ 9.4，最近也够不到 0。由 §3 命题，放开负 γ 即恢复解。

**4.3 设置对照。**

|维度|报告 A|报告 B|
|---|---|---|
|γ 搜索域|(γ_lo, t₁)，向左延伸、向 t₁ 几何加密|**[0, 0.999999·t_min]（非负裁剪）**|
|外层 β 取值|0.5, 1, 2, 3.5, 5（**含 β<1**）|1, 1.5, 2, 3（**全 ≥ 1**）|
|内层 β 域|geomspace(0.05, 60)|[0.1, 15]|
|主失败模式|ALL_BELOW（近 t₁ 漏检）|ALL_ABOVE（穿越落在 γ<0）|
|对"无解"的判读|九成是数值漏检（可恢复）|九成"真无解"（其实是域诱导）|

**4.4 裁决。** 作为各自设置下的数值报告，两份都对；但两份都把**有解率**（随机抽样下的概率）当成了**有解性**（对给定样本的确定性命题）。

- 报告 B 的"91.6% 真无解"**高估**了内在非存在性：那些 all_above 在 γ<0 有解（§3 命题），属域诱导而非曲线无根。
- 报告 A 的"修正后 ~99% 有解"对它的左延伸域成立，但它**从未触及 all_above 这一类**，因此不能外推到 γ≥0 的实现。
- 正确的陈述是一条与样本和域都挂钩的确定性判据（§3），它统一了两份的失败模式。

## 5. 失败模式的正确分类

|状态|语义|归因|处置|
|---|---|---|---|
|ROOT_FOUND|域内 g=offset 有稳健穿越|—|有解|
|ALL_BELOW|g 全域 < offset|**分辨率**（近 t₁ 窄峰未采到）/ 偶发真无解|向 t₁ 几何加密复核|
|ALL_ABOVE|g 全域 > offset|**域诱导**（穿越落在 γ<γ_lo，尤其 γ<0）|放宽左端 / 明确域并标注|
|NEAR_MISS|无符号变化但 min\|g−offset\| 很小|φ 角点使 g 跳过 offset，或窄峰边缘|广义根检测 + 复核|
|TRUE_NO_ROOT|高分辨率仍无 ≈offset 稳健穿越|**真无解**（近 t₁ g 剧烈振荡）|报告无解原因（A 的 186 个，全 β<1）|
|BETA_BOUNDARY / NONFINITE|β* 触边界 / 出现非有限值|子问题失稳 / 溢出|两份均≈0；向量化 + 紧 B 规避|

要点：**单看一份报告会把"域诱导"或"分辨率"误判成"曲线无根"。** 必须区分三类归因。

## 6. 诚实结论

**全数学域 (−∞, t₁)：条件存在。**

- 左端 g < offset 恒成立（§3.1），故存在性只取决于近 t₁ 能否升到 offset。
- β ≥ 1：g 升到中等正平台（>offset），通常有解——与报告 A 的 β≥1 有解率恒 = 1.0000 一致，且此处是**机制性**的而非统计性的。
- β < 1：根贴 t₁（分辨率敏感），多数可解；真无解极少（近 t₁ 振荡，A 中约 1.2%）。

**裁剪域 γ ≥ 0：额外的域诱导无解。**

- 对真值 γ 小的样本，offset 穿越落在 γ<0 被裁 → ALL_ABOVE。报告 B 数据印证：γ/η=0 仅 60%，γ/η=0.5 升到 98.8%，γ/η=1.0 达 100%。
- 这多数**不是方法缺陷**，而是把 γ 限非负的后果。

**实务取舍：**

- 若坚持 γ≥0（业务上阈值非负），必须接受小 γ 样本可能 all_above 无解，并据此设计回退（如退回两参数估计或放宽 offset），且应把它**标注为域诱导**而非笼统 no_root。
- 若允许 γ<0，多数 all_above 恢复，失败回到报告 A 式的近 t₁ 分辨率问题。

**offset 的作用（两份一致，保留）：**

- offset=0 时判据退化为 φ'=0（谷底平坦区），被数值台阶噪声切出几十个伪零点（A 中约 37 个）。
- offset>0 把判据移到 profile 的上升段，使解落在良态位置且数目稳定；offset 过大（→1）又让上升段够不到 ⇒ 有解率下降。0.1 是稳定性与可解性的折中。

**一句话：** MDM strict offset-root **不是无条件有解**；在全数学域上对 β≥1 通常可解、对 β<1 与小 γ 需谨慎，真无解极少；两份看似相反的报告，是同一条 g(γ) 判据曲线在**不同 γ 搜索域 / 不同 β 网格**下的两端投影。

## 8. 实现建议（合并两份 + 本文新增）

1. **γ 自适应网格、向 t₁ 几何加密**（治 ALL_BELOW，来自 A）。
    
2. **明确并放宽 γ 左端**（本文）：默认搜 (γ_lo, t₁)，γ_lo 取数学域（可负）；若业务要求 γ≥0，则在 all_above 时**显式返回"域诱导无解"**并给出"放开负 γ 后的恢复根"作为参考，而非笼统 no_intersection。
    
3. **扫描完整可行域、检测所有交点**，不在第一段发现交点后停止；再按明确规则（最大 γ / 最小 S 附近 / 返回全部候选）选根（两份共识）。
    
4. **稳健梯度估计**：同时算 raw finite difference、局部多项式斜率、样条导数，三者不一致标 `gradient_noise_suspect`；对每个候选根用 ±窗口割线斜率复核，要求局部斜率 ≈ offset（两份共识，且 §3 给出理论依据）。
    
5. **near-miss 单列**（来自 B），并额外检测 **φ 角点处的广义根**（offset 落在左右导数之间，本文）。
    
6. **β 优化用"网格扫描 + 有界局部精修"**，检查是否贴边界或多峰（两份共识）。
    
7. **结构化 `no_root_reason`**，明确区分三类归因：
    
    ```
    resolution_suspect   # 近 t₁ 窄峰漏检（ALL_BELOW，加密可恢复）
    domain_induced       # 穿越落在 γ < γ_lo（ALL_ABOVE，放宽左端可恢复）
    genuine_no_root      # 高分辨率仍振荡无稳健穿越（真无解）
    near_miss            # 角点/边缘广义根
    beta_unstable        # β 子问题贴边界或多峰
    invalid_gamma_domain # γ ≥ t₁ 等非法输入
    ```
