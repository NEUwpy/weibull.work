## 一、项目是什么

### 1.1 一句话概括

这是一个**可靠性工程领域的参数估计研究与实践平台**，聚焦于 Weibull 分布的参数估计方法，集计算、对比、验证、AI 优化于一体。

### 1.2 背景与动机

Weibull 分布是可靠性工程中最常用的寿命分布模型。给定一组失效时间数据，需要估计三个参数：

- **β (beta)** — 形状参数，决定失效模式（早期失效/随机失效/磨损失效）
- **η (eta)** — 尺度参数（特征寿命）
- **γ (gamma)** — 位置参数（最小寿命/偏移量）

传统参数估计方法有 25+ 种（MLE、MDM、LSE、MM、PWM、Bayesian 等），每种方法在不同样本量、不同参数组合下的表现差异很大。工程师在实际工作中面临一个核心问题：**该选哪种方法？怎么用才准确？**

这个平台就是为了解决这个问题而建的——它不仅是一个计算器，更是一个**研究环境**，让你能系统性地理解每种方法的原理、适用范围、精度表现，并探索 AI 能否做得更好。

### 1.3 线上地址

**[weibull.work](https://weibull.work)** — 部署在绿联 NAS 上，通过 Cloudflare Tunnel 暴露到公网。

### 2.3 前后端分工

- **后端**负责所有统计学核心计算：参数估计、数值优化（Nelder-Mead、Hessian）、蒙特卡洛模拟、PyTorch 模型推理

## 三、四大核心模块

### 3.1 Calculator（计算器）

提供交互式参数估计入口。用户输入失效时间数据，选择方法（单方法或多方法对比），执行计算，得到参数估计值和概率分布图像。

核心特性：
- 支持手动输入和从案例库调用数据
- 支持 2 参数 / 3 参数模型选择
- 多方法卡片叠加对比（同一数据上不同方法的结果可视化）
- 调用后端 `/calculate` API，支持计算过程追踪（trace）

### 3.2 Methods（方法系统）

这是平台最重头的模块，目标是**系统性地展示和验证 25+ 种参数估计方法**。

每个方法页面包含 7 个 Tab：

| Tab | 内容 | 状态说明 |
|-----|------|---------|
| 原理文档 | 算法数学原理、公式推导、适用条件 | 核心文档 |
| 程序流程 | 代码执行步骤与数学公式一一对应 | 代码级理解 |
| 计算过程 | 迭代轨迹、搜索路径、中间变量值 | 过程可视化 |
| 结果分析 | 拟合优度、残差、置信区间、现场蒙特卡洛 | 单次验证 |
| 适用范围 | 大规模蒙特卡洛模拟，不同参数组合下的系统性表现 | 预计算 |
| 可信性验证 | 复现论文结果，左右对比布局 | 正确性验证 |
| 方法对比 | 横向对比不同方法在同一数据上的表现 | 开发中 |

## 五、AI 方法模块 — 核心研究方向

这是平台最活跃、最有深度的部分。AI 方法模块与传统方法模块同级，定位是**探索 AI 辅助/替代传统参数估计方法的可行性与适用范围**。

### 5.1 整体架构

AI 模块按 AI 介入参数估计的方式分为三个子模块：

| 子模块 | 介入方式 | 本质 | 状态 |
|--------|---------|------|------|
| 模块 1：关系建立 | AI 拟合复杂非线性关系 | 学习"样本→过程参数"的映射 | 阶段性结束 |
| 模块 2：优化求解 | AI 辅助传统数值优化 | 仍走传统框架，AI 是辅助角色 | 暂空 |
| 模块 3：直接估计 | AI 端到端直接输出 | 完全绕过优化过程 | V2 完成 |

三者形成一个"交叉矩阵"：

```
           MDM    MLE    MMLE   ...
关系建立   ✓(δ)   —      —      待扩展
优化求解   —      待启动  —      待扩展
直接估计   —      —      —      统一✓
```

### 5.2 模块 1：关系建立（MDM 偏移量 δ 优化）

#### 做了什么

MDM（最小差异法）有一个关键的过程参数 **δ（偏移量）**，传统方法使用固定值 δ=0.5，但最优 δ 取决于具体的样本数据。模块 1 训练了一个神经网络，输入一组失效时间样本，直接输出最优 δ，替代人工反复尝试。

#### 两条研究路线

**M1-R1（直接学习）**：
- 输入：原始失效时间样本 [t1, t2, ..., tn]
- 输出：最优偏移量 δ
- 架构：Linear(n, 128)→ReLU→BN→Linear(128, 64)→ReLU→BN→Linear(64, 1)→Sigmoid
- 按样本量 n 分别训练独立模型（n=5/7/10/15/20）
- 验证 MSE：0.027-0.034，MAE：0.100-0.113

**M1-R2（迭代逼近）**：
- 输入：当前参数估计值 (β, η, γ)
- 输出：下一步的 δ
- 流程：δ₀=0.5 → MDM → 得到参数 → 神经网络预测新 δ → MDM → ... → 收敛
- 公共模型，覆盖所有 n
- 收敛率：74-80%

#### 核心发现

1. **最优 δ 替代固定 δ 能提升 MDM 精度 97-99%** — 这是巨大的改善
2. M1-R1 效果优于 M1-R2（MSE 低 ~40%），因为直接看样本信息量更大
3. **根本问题**：对 MSE-δ 曲线的数学性质（单调性、极值点、有效范围）缺乏系统性认识，导致搜索策略盲目、训练数据质量不稳定

#### MSE-δ 曲线的核心困惑

- 小样本（n≤10）大部分情况下 δ=0 最优（曲线单调递增）
- 大样本（n=20）或特定 β/η 组合需要正的 δ（曲线有最小值）
- MDM 在 δ 过大时会失败（无解），形成有效范围天花板
- 不同样本的最优 δ 差异很大（从 0.001 到 >1.0）

目前不理解为什么会有这些差异，这是模块 1 阶段性结束的原因——需要先从数学层面理解曲线性质，才能优化搜索策略。

#### 前端页面

- `/ai/relationship` — 总览页
- `/ai/relationship/m1-r1` — 8 个 Tab（原理/训练算法/训练数据/偏移量精度/三参数精度/在线使用/可信性验证/方法对比）
- `/ai/relationship/m1-r2` — 9 个 Tab（多一个迭代过程 Tab）

### 5.3 模块 3：直接估计（端到端 β,η,γ）

#### 做了什么

训练了一个神经网络，输入一组失效时间样本 [t1, ..., tn]，直接输出 Weibull 三参数估计值 (β̂, η̂, γ̂)，**完全绕过传统的迭代优化过程**。

#### 8 种预处理方案

这是模块 3 最系统性的实验——测试了 8 种不同的输入预处理方式，分为三大组：

**方案 A：独立模型（按 n 分别训练）**
- A-1 原始样本：直接输入 [t1, ..., tn]，网络自己学尺度不变性
- A-2 除以均值：[t1/t̄, ..., tn/t̄, t̄]，试图消除 η 影响
- A-3 去位置：[t1-t_min, ..., tn-t_min]，试图消除 γ 影响

**方案 B：填充+掩码（统一模型覆盖所有 n）**
- B-1 原始+掩码：补零到 n_max=15，掩码标记真实数据位置
- B-2 除以均值+掩码：同上 + 除以均值

**方案 C：统计量输入（维度固定，与 n 无关）**
- C-1 基础统计量：[mean, std, min, max]（4 个特征）
- C-2 扩展统计量：+ [偏度, 峰度, 中位数]（7 个特征）
- C-3 最大化统计量：+ [Q1, Q3, IQR, CV]（11 个特征）

#### 核心实验结论

1. **C-1 ≈ A-1** — 4 个统计量已充分提取 Weibull 参数信息，额外的统计量（偏度/峰度等）没有提供新信息
2. **B-1 统一模型可行** — 一个模型覆盖所有 n（5/7/10/15），精度与按 n 独立训练的模型几乎相同，实用性最强
3. **A-2 对 η 变差** — 除以均值反而丢失尺度信息，η 的 MAE 变大
4. **A-3 明显变差** — 去位置丢失绝对尺度信息，MAE(β) 几乎翻倍
5. **插值精度略降** — 比组内高约 20-30%
6. **外推精度大幅下降** — 8-10 倍，符合预期（模型没见过的参数范围）
7. **a2/b2 外推爆炸** — 除以均值预处理在外推时产生极大值（MAE 达 10^10）

#### 精度数据

组内验证精度（B-1 方案，验证集 20% 随机划分）：

| n | MAE(β) | MAE(η) |
|---|--------|--------|
| 5 | 0.560 | 360.3 |
| 7 | 0.473 | — |
| 10 | 0.382 | 248.2 |
| 15 | 0.295 | 208.0 |

样本量越大精度越高，符合直觉。

## 六、指标与图表体系

### 6.1 评价指标

系统使用的核心评价指标：

| 指标 | 公式 | 用途 |
|------|------|------|
| MAE | Σ\|ŷ−y\|/n | 平均绝对误差，直观反映偏差幅度 |
| MRE | Σ\|ŷ−y\|/\|y\|/n | 平均相对误差，消除量纲影响 |
| MSE | Σ(ŷ−y)²/n | 均方误差，对大偏差敏感 |
| bias | Σ(ŷ−y)/n | 系统偏差，正值=高估，负值=低估 |
| 改善率 | (MSE_fixed−MSE_ai)/MSE_fixed | AI 相对基线的改善百分比 |
| 收敛率 | 收敛样本数/总样本数 | 迭代路线的收敛比例 |

目前存在的问题：后端有 7 处重复实现 `compute_relative_mse`，前端也有多个组件内联计算 MAE/MRE。计划统一到 `python/studies/common/metrics.py` 和 `src/lib/metrics.ts`。

### 6.2 图表组件

- **AI 专用图表**（`src/components/ai/charts/`）：ScatterPlot、BoxPlot、Histogram、LineChart、MultiLineChart、BarChart、GroupedBar 等

## 十一、总结

这是一个**小而精的研究型平台**，技术栈清晰（Next.js + FastAPI + PyTorch），架构设计合理（前后端分离、Flat File 存储、组件复用体系），文档体系完善（渐进式披露、规范先行）。

最有价值的部分是 **AI 方法模块**——通过系统性的实验（8 种预处理方案、两条研究路线、泛化验证），验证了 AI 端到端参数估计的可行性，同时也发现了需要深入研究的数学问题（MSE-δ 曲线性质）。

平台目前处于一个**基础设施完备、核心研究初步完成、需要向纵深推进**的阶段。下一步的关键是从"做实验"转向"理解原理"——特别是 MSE-δ 曲线的数学性质研究，以及 AI vs 传统方法的系统性对比。
