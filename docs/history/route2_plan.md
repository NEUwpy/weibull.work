# Task Plan: AI 模块 1 路线 2 — 迭代逼近实现

## Goal
实现并验证路线 2：δ₀=0.5 → MDM → N₁ → δ₁ → MDM → N₁ → δ₂ → ... → |δ_new-δ_old|<0.001, 最大 10 步

## 背景与动机

### 路线 1 的根本问题
路线 1（N₂ 直接从样本预测 δ）存在过拟合问题：
- 训练数据的"最优 δ"是针对单个样本搜索得到的
- 实验 6 证明：所有 n 的"最优 δ"都过拟合（测试 MSE >> 训练 MSE）
- N₂ 学到的是噪声模式，不是真实的样本→δ 关系

### 路线 2 的优势
- **不依赖预计算的"最优 δ"**：迭代过程自然收敛到一个合理值
- **N₁ 的标签是稳定的**：(β,η,γ) → δ 的映射不依赖单个样本
- **自校正**：每次迭代用 MDM 重新估计，自动修正偏差

## Phase 0: 头脑风暴与方案设计

### 0.1 路线 2 完整流程

```
输入：样本 S = [t1, t2, ..., tn]

Step 0: δ₀ = 0.5（固定初始值）
Step 1: MDM(S, δ₀) → (β̂₀, η̂₀, γ̂₀)
Step 2: N₁(β̂₀, η̂₀, γ̂₀) → δ₁
Step 3: MDM(S, δ₁) → (β̂₁, η̂₁, γ̂₁)
Step 4: N₁(β̂₁, η̂₁, γ̂₁) → δ₂
...
直到 |δ_new - δ_old| < 0.001 或达到 10 步

输出：(β̂_final, η̂_final, γ̂_final, δ_final, steps)
```

### 0.2 N₁ 模型需求分析

**输入**：(β̂, η̂, γ̂) — MDM 的当前估计结果
**输出**：δ — 下一步应该使用的偏移量

**关键问题**：
- β=2 固定时，输入只有 η̂ 和 γ̂ 两个有效维度
- η̂ 的范围大约在 [100, 5000]，γ̂ 的范围大约在 [500, 1500]
- N₁ 需要学习：给定当前估计 (η̂, γ̂)，最优的 δ 是多少

**N₁ 的标签从哪来？**

这是核心问题。有几种方案：

**方案 A：用"真值→最优δ"作为标签**
- 对每个训练样本，已知真值 (β,η,γ)
- 搜索使 MDM 估计最接近真值的 δ
- 标签：(β,η,γ) → δ_optimal
- 问题：这和路线 1 一样有"最优 δ"的概念

**方案 B：用"当前估计→修正δ"作为标签**
- 对每个训练样本：
  1. 用某个 δ_current 运行 MDM，得到 (β̂, η̂, γ̂)
  2. 搜索一个更好的 δ_next 使 MDM 估计更接近真值
  3. 标签：(β̂, η̂, γ̂) → δ_next
- 问题：需要对每个样本搜索多个 δ

**方案 C：迭代过程中的中间状态作为训练数据**
- 对每个训练样本：
  1. 随机选一个 δ₀
  2. 运行 MDM → (β̂₀, η̂₀, γ̂₀)
  3. 搜索最优 δ₁（使下一步 MDM 估计更好）
  4. 记录：(β̂₀, η̂₀, γ̂₀) → δ₁
- 重复多次，生成不同起点的训练数据
- 优点：N₁ 学习的是"如何从当前估计修正到更好的 δ"
- 问题：计算量大

**方案 D：简化——用真值直接训练 N₁**
- 标签：(β,η,γ) → δ*（使 MDM 估计最接近真值的 δ）
- 这和方案 A 一样，但我们可以接受这个"最优 δ"的过拟合
- 因为在路线 2 中，N₁ 的输入是 MDM 的估计值，不是真值
- 迭代会自动修正偏差

### 0.3 推荐方案：方案 D（简化版）

**理由**：
1. 最简单，计算量最小
2. N₁ 的标签虽然也有过拟合，但迭代会修正
3. 路线 2 的关键在于迭代，不在于 N₁ 的精确度
4. N₁ 只需要给出一个"大致方向正确的 δ"，不需要精确最优

**实现步骤**：
1. 对每个 (β,η,γ,n) 组合，MC=500 个样本
2. 对每个样本，搜索使相对 MSE 最小的 δ
3. 记录：(β,η,γ) → δ_optimal
4. 训练 N₁：输入 (β,η,γ)，输出 δ

**注意**：
- N₁ 的标签来自真值 (β,η,γ)，不是 MDM 的估计值
- 在推理时，N₁ 的输入是 MDM 的估计值 (β̂,η̂,γ̂)
- 这引入了一个 train-test 分布偏移
- 但迭代会修正这个偏移

### 0.4 验证方案

- 对 100 个测试样本，运行路线 2 迭代

**测试 2：精度对比**

- 指标：相对 MSE

**测试 3：边界测试**
- 极端参数组合（η=100, η=5000, n=5, n=20）

## Phase 3: 迭代逻辑实现

### 3.1 算法

```python
def route2_iterate(sample, n1_model, delta_0=0.5, max_steps=10, tol=0.001):
    delta = delta_0
    history = []

    for step in range(max_steps):
        # MDM 估计
        result = run_mdm(sample, delta)
        if result is None:
            break
        beta_hat, eta_hat, gamma_hat = result

        # N₁ 预测下一个 δ
        delta_new = n1_model.predict(beta_hat, eta_hat, gamma_hat)

        history.append({
            'step': step,
            'delta': delta,
            'beta_hat': beta_hat,
            'eta_hat': eta_hat,
            'gamma_hat': gamma_hat,
        })

        # 收敛检查
        if abs(delta_new - delta) < tol:
            break

        delta = delta_new

    return beta_hat, eta_hat, gamma_hat, delta, len(history), history
```
