## 一、模块定位

### 性质：探索平台，不是用户工具

本模块与"参数估计方法"（Methods）同级、同性质：
- **参数估计方法** = 探索传统统计方法（MDM、MLE、MMLE...），验证其正确性与适用范围
- **人工智能方法** = 探索 AI 如何辅助/替代这些传统方法，验证其效果与适用范围

两者最终会形成交叉：AI 方法可以作用于不同的传统方法。

### 在系统中的位置

```
导航（同级）:
  Calculator（计算器）        ← 用户工具
  Methods（参数估计方法）      ← 探索平台：传统方法
  ★ AI（人工智能方法）        ← 探索平台：AI 辅助方法
  Cases（案例数据库）
  Library（可靠性图书馆）

URL:
  /ai                        ← 总览页
  /ai/relationship           ← 关系建立（模块 1，M1-R1 + M1-R2）
  /ai/optimization           ← 优化求解（模块 2，暂空）
  /ai/direct-estimation      ← 直接估计（模块 3，8 种预处理方案）
```

### 三类用途划分

以 AI 介入参数估计的方式划分为三个子页面：

| 子页面 | 介入方式 | 本质 | 与传统方法的关系 |
|--------|---------|------|----------------|
| 关系建立 | AI 拟合复杂非线性关系 | 学习"样本 → 过程参数"的映射 | 替代人工选择过程参数 |
| 优化求解 | AI 辅助传统数值优化 | 仍走传统框架，AI 是辅助角色 | 增强传统方法 |
| 直接估计 | AI 端到端直接输出 | 完全绕过优化过程 | 替代传统方法 |

## 三、模块 1 — 关系建立（MDM 偏移量 δ 优化）

### 做了什么

训练了一个神经网络，输入一组失效时间样本，直接输出 MDM 方法应使用的最优偏移量 δ，替代人工反复尝试。

### 研究路线

| 路线 | 模型 | 说明 | 状态 |
|------|------|------|------|
| M1-R1（直接学习） | 样本 → δ | 按 n 分别训练，MSE 0.027-0.034 | ✅ 已完成 |
| M1-R2（迭代逼近） | (β,η,γ) → δ → MDM → 循环 | 公共模型，收敛率 74-80% | ✅ 已完成 |

### 核心发现

- ✅ 最优 δ 替代固定 δ 能提升 MDM 精度 97-99%
- ⚠️ 对 MSE-δ 曲线数学性质认识不足，搜索策略盲目

## 四、模块 3 — 直接估计（端到端参数估计）

### 做了什么

训练了一个神经网络，输入一组失效时间样本 [t1, ..., tn]，直接输出 Weibull 三参数估计值 (β̂, η̂, γ̂)，无迭代优化。

### 三大方案组、8 种预处理

| 方案 | 输入 | 模型类型 | 结论 |
|------|------|---------|------|
| A-1 原始样本 | [t1, ..., tn] | 按 n 独立 | 基线方案 |
| A-2 除以均值 | [t1/t̄, ..., tn/t̄, t̄] | 按 n 独立 | 对 η 变差 |
| A-3 去位置 | [t1-t_min, ..., tn-t_min] | 按 n 独立 | 明显变差 |
| B-1 原始+掩码 | [..., mask] | 统一模型 | **最优方案** |
| B-2 除以均值+掩码 | [..., t̄, mask] | 统一模型 | ≈ B-1 |
| C-1 基础统计量 | [mean, std, min, max] | 按 n 独立 | ≈ A-1 |
| C-2 扩展统计量 | 7 特征 | 按 n 独立 | 无额外优势 |
| C-3 最大化统计量 | 11 特征 | 按 n 独立 | ≈ C-1 |

### 核心结论

1. **C-1 ≈ A-1** — 4 个统计量已充分提取 Weibull 参数信息
2. **B-1 统一模型可行** — 一个模型覆盖所有 n，精度几乎相同，实用性最强
3. **插值精度略降** — 比组内高约 20-30%
4. **外推精度大幅下降** — 8-10 倍，符合预期
5. **a2/b2 外推爆炸** — 除以均值预处理在外推时发散

### 前端页面

- `/ai/direct-estimation` — 方案选择页（A/B/C 三组，8 个子选项）
- `/ai/direct-estimation/[scheme]` — 7-Tab 详情页（原理/训练算法/训练数据/在线使用/性能展示/可信性验证/方法对比）

## 六、Tab 结构设计

### AI Methods 的 Tab（通用 7-Tab）

| Tab | AI Methods 含义 | 与 Methods 的对应关系 |
|-----|----------------|---------------------|
| **原理说明** | AI 方法的原理、动机、与传统方法的关系 | ≈ 原理文档 |

| **可信性验证** | 已知参数验证、泛化验证 | ≈ 可信性验证 |
| **方法对比** | 不同 AI 方法的横向对比 | ≈ 方法对比 |
