## 一、研究背景

### 1.1 MDM 是什么

MDM（最小差异法，Minimum Discrepancy Method）是三参数威布尔分布的一种参数估计方法。核心思路：

1. 对每个候选 γ，优化 β 使伪尺度参数 η 的标准差 σ 最小
2. 计算 σ_min(γ) 曲线的梯度
3. 用 offset 判据（梯度曲线与 offset 阈值的交点）确定最终 γ

offset 判据的直觉：σ_min(γ) 曲线通常呈 U 形，梯度从负变正，交点处就是"σ 不再显著下降"的位置。

### 1.2 发现的问题

S4 统一蒙特卡洛框架端到端验证时发现，MDM 的 failure rate 高达 32.8%。S4.5 诊断定位了原因：

- 所有 failure 均为 `no_intersection`（梯度曲线未达 offset 阈值）
- 不是实现 bug，不是搜索网格太粗，不是数值噪声

但这引出了一个关键问题：**这些 failure 是"MDM 理论上无解"，还是"当前实现找不到解"？**

### 1.3 研究目标

S4.7 的目标：

1. 理解 failure 样本的 σ 曲线形状
2. 设计替代策略消除 failure
3. 比较不同策略的精度和稳健性
4. 确定工程默认实现

## 二、研究过程

### 2.1 初版研究（已被撤回）

初版在小参数空间（gamma/eta ∈ {0, 0.1}，n ∈ {10, 30}）上比较了四种变体：

- 结论：min_sigma 精度最优（NE=0.328），推荐作为默认
- **问题：验证空间偏向边界场景，结论过于乐观**

### 2.2 修正版研究

扩展验证空间至 gamma/eta ∈ {0, 0.1, 0.5, 1.0}，n ∈ {7, 10, 30}，每组 100 次重复，共 3600 样本/变体。

关键发现：**min_sigma 在高 gamma/eta 时 outlier 率飙升到 33%**，初版结论被推翻。

## 三、四种 MDM 变体

### 3.1 设计思路

| 变体 | 无交点时行为 | 设计动机 |
|------|-------------|----------|
| `mdm_offset_strict` | 返回 failure | 原默认行为，作为 baseline |
| `mdm_offset_constrained` | 返回约束域最优边界解 | 保留 offset 框架，补充边界规则 |
| `mdm_min_sigma` | 始终取网格上 σ 最小的 γ | 完全放弃 offset 判据 |
| `mdm_allow_negative_gamma` | 扩展搜索到负 γ | 检查是否解在负域 |

### 3.2 constrained 的边界规则

当 offset 判据在非负 γ 可行域内找不到交点时：

- **diff 全正**（采样点梯度均高于 offset）→ 选 γ≈0 处的解（`boundary_left`）
- **diff 全负**（采样点梯度均低于 offset）→ 选最小 σ 处的解（`boundary_right`）
- **有正有负但无符号变化**（数值噪声）→ 选最接近 offset 的点（`closest_offset`）
- **有交点** → 用交点（`root`），与 strict 一致

每种情况都有 `fallback_reason` 诊断字段，便于后续统计。

### 3.3 min_sigma 的问题

min_sigma 的逻辑是"始终取 σ 最小的 γ"，看似合理，但有一个系统性偏差：

- 当真值 γ 较大时，σ_min(γ) 曲线的最小值往往在 γ≈0 附近
- min_sigma 会系统性地低估 γ
- 当真值 gamma/eta=0.5 或 1.0 时，γ_hat≈0 导致 NE 很大 → outlier

这就是它在高 gamma/eta 场景 outlier 率飙升的根本原因。

## 四、研究结果

### 4.1 汇总表

| Variant | NE | fail% | out% | t_ms |
|---------|------|-------|------|------|
| MLE (reference) | 0.379 | 32.3% | 13.9% | 5.3 |
| mdm_offset_strict | 0.419 | 16.8% | 4.4% | 4.7 |
| **mdm_offset_constrained** | **0.397** | **0.0%** | **5.1%** | 5.4 |
| mdm_min_sigma | 0.409 | 0.0% | **15.2%** | 4.3 |
| mdm_allow_negative_gamma | 0.396 | 0.0% | 7.5% | 4.5 |

### 4.2 按 gamma/eta 分组 outlier 率

这是最关键的对照表：

| gamma/eta | MLE | strict | constrained | min_sigma | neg_gamma |
|-----------|------|--------|-------------|-----------|-----------|
| 0.0 | 3.7% | 1.8% | 2.0% | 2.8% | 4.6% |
| 0.1 | 4.7% | 3.1% | 3.4% | 3.4% | 7.6% |
| 0.5 | 19.0% | 4.9% | 6.9% | **21.4%** | 8.1% |
| 1.0 | 28.4% | 7.9% | 8.0% | **33.0%** | 9.8% |

**min_sigma 在 gamma/eta=0.5 时 outlier 率已飙到 21.4%，gamma/eta=1.0 时达 33.0%。** 这是它不适合做默认的核心原因。

constrained 在所有 gamma/eta 水平均稳健（2.0% → 3.4% → 6.9% → 8.0%），0% failure。

### 4.3 failure 样本诊断

对 strict 变体的 605 个 failure 样本做逐样本诊断：

- **100%** 的 failure 样本 σ 曲线在离散采样点上单调非降
- **100%** 的 failure 样本最小 σ 在边界（γ≈0）
- grad_min 均值 0.4335，远高于 offset=0.1
- 有 4 个样本 grad_min - offset ≤ 0.001（边界很近）

因此：**不能说"永远不可能找到内点解"**，只能说"在当前离散搜索（gamma_steps=20）与扩展验证下，无交点样本表现为边界最优"。

### 4.4 success 样本的 σ 曲线形状

初版声称"failure 样本单调上升、success 样本呈 U 形"。修正版诊断显示：

- 39% 的全部样本（含 success）σ 曲线单调非降
- success 样本中也有 26.7% 是单调的
- 正确说法：failure 样本的最小 σ 全部在边界，success 样本的最小 σ 多数在内部

## 五、已撤回的初版结论

| 初版结论 | 撤回原因 |
|----------|----------|
| min_sigma 精度最优，推荐做默认 | 验证空间仅 gamma/eta ∈ {0, 0.1}，偏向边界场景；扩展后 outlier 飙升 |
| success 样本都是 U 形 | 39% 的样本 σ 曲线单调非降，success 中也有 26.7% 单调 |
| MDM failure 是理论限制 | 准确说法是 offset 判据内点条件不满足，不等价于 MDM 理论无解 |

## 六、最终结论

1. **默认 MDM 确定为 `mdm_offset_constrained`**：0% failure，outlier 5.1%，在所有 gamma/eta 水平均稳健
2. **`mdm_min_sigma` 保留为敏感性对照**：不作为默认，但在 S3 实验中作为对照组
3. **`mdm_offset_strict` 保留为诊断变体**：不作为工程 baseline
4. **`mdm_allow_negative_gamma` 仅用于诊断**：outlier 7.5%，不适合工程使用
5. **MLE 在扩展参数空间上 failure 率 32.3%**：说明扩展空间更难，后续横向比较必须保留 Failure Rate

## 八、后续影响

S4.7 的结论直接影响后续实验设计：

- S3 Loss 对比实验中 MDM baseline 使用 constrained
- S6 横向比较中 MDM 作为传统方法代表参与
- MLE 的 32.3% failure 提醒：后续所有实验必须报告 Failure Rate，不能只看平均精度
- gamma/eta 分层分析成为标准：不能只看总体平均值，否则会被 min_sigma 这类"总体最优但局部崩溃"的方法误导
