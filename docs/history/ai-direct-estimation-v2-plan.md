## 二、任务 1：参数空间扩展 — 加入 γ≠0

### 当前参数空间

```
β ∈ {0.5, 1, 2, 3, 5}          — 5 个值
η ∈ {100, 500, 1000, 3000, 5000} — 5 个值
γ ∈ {0}                         — 1 个值 ← 问题所在
n ∈ {5, 7, 10, 15}              — 4 个值
MC = 500
总组合: 5×5×1×4 = 100 组
总样本: 100 × 500 = 50,000 条
```

### 新参数空间

```
β ∈ {0.5, 1, 2, 3, 5}          — 5 个值（不变）
η ∈ {100, 500, 1000, 3000, 5000} — 5 个值（不变）
γ ∈ {0, 50, 100, 200}           — 4 个值 ← 新增
n ∈ {5, 7, 10, 15}              — 4 个值（不变）
MC = 500
总组合: 5×5×4×4 = 400 组（原 100 组）
总样本: 400 × 500 = 200,000 条（原 50,000 条）
```

**γ 取值依据**：
- γ 是位置参数（最小失效时间的下界）
- 与 η 的量级应可比：η∈{100,...,5000}，γ∈{0,50,100,200} 不会淹没 η 的影响
- γ < η_min=100 是合理的（位置参数通常小于尺度参数）

### 需要修改的文件

| 文件 | 改动 |
|------|------|
| `generate_training_data.py` | 默认 `--gammas 0,50,100,200` |
| `train_model.py` | 无需改动（已支持任意参数组合） |
| 后端 `main.py` | 无需改动（模型加载逻辑不变） |
| 前端精度展示 | γ 的散点图/直方图现在有意义了 |

### 执行步骤

1. 生成新训练数据：
   ```bash
   cd python/studies/direct_estimation
   python generate_training_data.py --gammas 0,50,100,200
   ```
2. 为全部 8 个预处理方案重新训练模型：
   ```bash
   python train_model.py --preprocessing a1
   python train_model.py --preprocessing a2
   # ... 依此类推，共 8 个方案
   ```
3. 复制模型和指标到 `public/ai/data/`
4. 验证前端展示（γ 的散点图应不再是退化的原点）

## 三、任务 2：泛化验证

### 问题

当前验证集从训练参数组合中随机划分（20%），只能测"已见过的参数组合的插值"，无法测泛化能力。

### 方案：三类验证数据

在数据生成阶段就标记 `validation_type`，分为三类：

| 类型 | 标记 | 参数组合来源 | 目的 |
|------|------|-------------|------|
| **in_group** | `ig` | 训练集中的参数组合 | 基线精度（已有） |
| **interpolation** | `ip` | 训练点之间的新组合 | 插值泛化 |
| **extrapolation** | `ex` | 训练范围外的组合 | 外推泛化 |

### 插值参数组合

从训练网格的"中间"取值，避开训练点：

```
β_ip ∈ {0.75, 1.5, 2.5, 4}         — 训练点 {0.5,1,2,3,5} 之间
η_ip ∈ {300, 750, 2000, 4000}       — 训练点 {100,500,1000,3000,5000} 之间
γ_ip ∈ {25, 75, 150}               — 训练点 {0,50,100,200} 之间
```

组合数：4×4×3 = 48 组 × 4 n × 100 MC = 19,200 条（MC 可以少一些，100 够用）

### 外推参数组合

超出训练范围的值：

```
β_ex ∈ {0.3, 8, 10}                — < 0.5 或 > 5
η_ex ∈ {50, 8000, 10000}           — < 100 或 > 5000
γ_ex ∈ {-50, 300, 500}             — < 0 或 > 200
```

注意：β_ex 和 η_ex 需要搭配合理的 γ（用 γ=0 或 γ=100），避免生成无意义数据。

组合数：约 20-30 组 × 4 n × 100 MC = 8,000-12,000 条

### 数据生成脚本改动

新增 `generate_test_data.py`（独立脚本，不改训练数据生成逻辑）：

```bash
# 生成插值测试集
python generate_test_data.py --type interpolation

# 生成外推测试集
python generate_test_data.py --type extrapolation

# 生成全部
python generate_test_data.py --type all
```

输出 CSV 新增 `validation_type` 列：

```csv
n,beta,eta,gamma,validation_type,t1,t2,...,tn
5,0.75,300,25,ip,123.4,234.5,...
5,8,100,0,ex,567.8,678.9,...
```

### 评估流程

1. 用现有训练好的模型对测试数据做推理
2. 新增 `evaluate_generalization.py`：
   - 加载测试 CSV
   - 对每个 scheme 调用模型推理
   - 按 `validation_type` 分组计算 MAE/MRE
   - 输出 `generalization_metrics.json`

输出 JSON 结构：

```json
{
  "scheme": "a1",
  "metrics": {
    "in_group": { "mae_beta": 0.447, "mae_eta": 273.1, ... },
    "interpolation": { "mae_beta": 0.52, "mae_eta": 310.5, ... },
    "extrapolation": { "mae_beta": 1.23, "mae_eta": 890.2, ... }
  }
}
```

### 前端改动

**VerificationTab（可信性验证）** 精度汇总表新增 Tab 切换：

```
[ 组内验证 ]  [ 插值验证 ]  [ 外推验证 ]
```

- 默认显示"组内验证"（与当前行为一致）
- 切换后显示对应 validation_type 的精度指标
- 数据来源：`generalization_metrics.json`（而非现有 metrics JSON）

**PerformanceTab（性能展示）** 散点图可选叠加：
- 散点图用颜色区分 in_group / interpolation / extrapolation
- 或者用 Tab 切换只显示某一类

## 六、风险与注意事项

1. **训练时间翻 4 倍**：γ 从 1 个值变 4 个，训练数据从 50k→200k，每个方案训练时间约 4 倍
2. **B-1/B-2 统一模型**：输入维度不变（30），但需要学习 γ 的变化，可能需要更多 epoch
3. **C-1/C-2/C-3 统计量**：统计量输入不含 γ 信息，可能对 γ≠0 的泛化较差 — 这本身是一个有价值的实验结论
4. **外推验证可能很差**：这是预期行为，用于展示模型的边界
