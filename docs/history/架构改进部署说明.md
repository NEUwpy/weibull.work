# 架构改进部署说明

## 改动概要

本次改动涉及后端 CORS 策略和 Docker 部署配置。

---

## 1. CORS 限制

**之前**: `allow_origins=["*"]`（允许任意来源）

**之后**: 仅允许 `weibull.work` 和 `localhost:3000`

如需自定义，设置环境变量 `CORS_ORIGINS`（逗号分隔）：

```
CORS_ORIGINS=https://weibull.work,http://localhost:3000,http://192.168.1.100:3000
```

## 2. Cloudflare Token 外置

**之前**: Token 硬编码在 `docker-compose.yml`

**之后**: 通过 `.env` 文件提供，Docker Compose 自动读取

### NAS 首次部署

`.env` 被 `.gitignore` 排除，`git pull` 不会拉取。需在 NAS 上手动创建一次：

```bash
# SSH 到 NAS，进入项目目录
cd /path/to/Weibull

# 创建 .env 文件（Token 见 docs/凭证信息.md）
echo 'CLOUDFLARE_TOKEN=eyJhIjoi...' > .env

# 拉取代码并重启
git pull
docker compose up -d
```

之后每次部署只需 `git pull && docker compose up -d`，不再需要其他操作。

### Token 值

完整 Token 记录在 `docs/凭证信息.md` 中。
