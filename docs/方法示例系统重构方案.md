# 方法示例系统重构方案

> 创建日期：2026-03-02
> 最后更新：2026-03-02
> 状态：进行中

## 一、问题与目标

### 现状问题

1. **案例组件臃肿**：每个案例一个 700+ 行的 tsx，代码大量重复
2. **参数硬编码**：参数写在 tsx 里，改动需要改代码
3. **脚本堆积**：Python 根目录 15+ 个调试脚本
4. **方法.py 缺乏灵活性**：步长、寻优方法等计算设置无法参数化

### 目标

- **配置驱动**：一个通用组件 + config.md 替代每个案例写 tsx
- **脚本复用**：一个通用仿真脚本替代 N 个专用脚本
- **方法参数化**：方法.py 支持计算设置作为参数

## 二、目标架构

### 方法示例 Tab 结构

```
┌─────────────────────────────────────────────────────────────────┐
│  方法示例 - [方法名]                                            │
├─────────────────────────────────────────────────────────────────┤
│  [下拉选择示例]                                                 │
├─────────────────────────────────────────────────────────────────┤
│  [β] [η] [γ]  ← 参数选择 tabs（可多选）    [筛选显示 ▼]          │
├─────────────────────────────────────────────────────────────────┤
│  参数面板：β, η, γ, n, δ 等（可选择显示维度）                   │
├─────────────────────────────────────────────────────────────────┤
│  统计表格：按显示维度分组，显示选中的统计量                      │
├─────────────────────────────────────────────────────────────────┤
│  图表区域：                                                     │
│  - 单变量：箱型图 (β/η/γ)                                       │
│  - 双变量：热力图                                               │
└─────────────────────────────────────────────────────────────────┘
```

### 核心交互

1. **参数选择 tabs**：[β] [η] [γ] - 点击多选，控制表格/图表显示哪些参数
2. **筛选显示按钮**：选择要显示的统计量
   - 均值、均值偏差
   - 中位数、中位数偏差
   - 标准差
   - 95% CI / 99% CI
   - 全范围
   - 分位数偏差 (F=0.01%~10%)
3. **显示维度选择**：参数卡片上点击"设为显示维度"

## 五、关键设计决策

### 1. 实时计算 vs 预计算

**决定**：前端实时从 CSV 计算统计量

**理由**：
- 更灵活，用户选择什么参数/统计量就实时计算
- 不需要维护 summary.json
- CSV 加载一次后，统计计算很快

### 2. 数据文件格式

**config.md**：
```yaml
---
id: "demo-1"
name: "示例1: MDM多维度研究"
description: "描述..."
method: "mdm"
params:
  - id: "beta"
    name: "形状参数"
    symbol: "β"
    state: "discrete"
    discreteValues: [1.5, 2.0, 3, 5, 7]
    isVariable: true
  # ...
defaults:
  beta: 2.0
  eta: 1000
  gamma: 1000
  sampleSize: 7
  process: 0.1
---
```

**data.csv**：
```csv
beta_true,sample_size,offset_value,sim_id,est_beta,est_eta,est_gamma,bias_beta,bias_eta,bias_gamma,r_squared
1.5,5,0,1,1.637,553.579,970.417,0.137,-446.421,-29.583,0.970
...
```
