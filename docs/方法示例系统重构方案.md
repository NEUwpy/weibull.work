# 方法示例系统重构方案

> 创建日期：2026-03-02
> 最后更新：2026-03-02
> 状态：进行中

## 一、问题与目标

### 现状问题

1. **案例组件臃肿**：每个案例一个 700+ 行的 tsx，代码大量重复
2. **参数硬编码**：参数写在 tsx 里，改动需要改代码
3. **脚本堆积**：Python 根目录 15+ 个调试脚本
4. **方法.py 缺乏灵活性**：步长、寻优方法等计算设置无法参数化

### 目标

- **配置驱动**：一个通用组件 + config.md 替代每个案例写 tsx
- **脚本复用**：一个通用仿真脚本替代 N 个专用脚本
- **方法参数化**：方法.py 支持计算设置作为参数

## 三、图表组件设计

### 图表分类

根据变量数量，图表分为两类：

| 类型 | 变量数 | 组件名 | 描述 |
|------|--------|--------|------|
| **单变量图** | 1 | `SingleVarChart` | 横坐标=变量值，纵坐标=偏差/估计值 |
| **双变量图** | 2 | `DualVarChart` | 分组柱状图或多系列折线图 |

### 图表内容

每个图表展示以下统计量：
- **偏差均值** (bias_mean)
- **偏差标准差** (bias_std)
- **估计值分布** (box plot: min, p01, median, p99, max)

### 组件命名

```
src/components/studies/
├── UniversalStudyViewer.tsx      # 主容器
├── ParameterPanel.tsx            # 参数面板（含显示维度选择）
├── StatsTable.tsx                # 统计表格
└── charts/
    ├── SingleVarChart.tsx        # 单变量图表
    ├── DualVarChart.tsx          # 双变量图表
    └── shared/
        ├── BoxPlot.tsx           # 箱型图组件
        └── chartUtils.ts         # 通用工具函数
```

## 四、数据文件

### 目录结构

```
public/studies/{method}/{demoN}/
├── config.md           # 参数配置（必需）
├── data.csv            # 原始仿真结果（必需）
└── summary.json        # 统计汇总（必需，由前端实时计算或预生成）
```

### config.md 格式

```yaml
---
id: "demo-1"
name: "示例1: MDM多维度研究"
description: "研究描述..."
method: "mdm"

# 参数配置
params:
  - id: "beta"
    name: "形状参数"
    symbol: "β"
    state: "discrete"           # fixed | range | discrete
    discreteValues: [1.5, 2.0, 3, 5, 7]
    isVariable: true

  - id: "eta"
    name: "尺度参数"
    symbol: "η"
    state: "fixed"
    fixedValue: 1000
    isVariable: false

# 默认值（非变量参数的基准值）
defaults:
  beta: 2.0
  eta: 1000
  gamma: 1000
  sampleSize: 7
  process: 0.1

# 计算设置（MDM特有，后续扩展）
computeSettings: []

# 仿真设置
simulation:
  numSimulations: 1000
---

## 研究说明

(Markdown 内容)
```

## 五、后端改造（后续）

### 通用仿真脚本

```python
# python/simulate.py
# 职责：读取 config.md → 生成 data.csv

python simulate.py --method mdm --config public/studies/mdm/demo1/config.md --output public/studies/mdm/demo1/data.csv
```

### 方法.py 改造

需要支持计算设置作为参数传入：

```python
# 现在的调用
algo = MDM(data)
result = algo.run(trace=True, offset=0.2)

# 之后支持
algo = MDM(data, settings={
    'stepSize': 0.01,
    'searchMethod': 'golden_section',
    'maxIter': 100
})
result = algo.run(trace=True, offset=0.2)
```

## 八、关键原则

1. **配置驱动**：能用配置解决的，不写代码
2. **先移植后删除**：新架构验证无误后再清理旧代码
3. **样式复用**：沿用现有案例的视觉设计
4. **向后兼容**：不影响现有 API 和计算器功能
