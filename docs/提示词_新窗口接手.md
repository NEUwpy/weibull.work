## 后续 S3 Loss 对比实验要点

S3 需要在 S4.7 用 S2R 重算之后再进入。

- 实验对象：简单 M3 直接估计模型（MLP）
- 候选 loss：原始参数 MSE / S2R 参数相对误差 MSE / S2R 参数 Huber / S2R 分位点相对误差 MSE / Hybrid-Loss
- Hybrid-Loss：`α * Loss_param_rel + (1-α) * Loss_quantile_rel`，α ∈ {0, 0.25, 0.5, 0.75, 1.0}
- 评价标准：MdAPE + MedRel + RelIQR + 尾部分位 + Valid Rate，必须按 gamma/eta 分层
- MDM baseline 需等待 S4.7 的 S2R 重算确认；旧口径下 constrained 是候选默认，min_sigma 只作为敏感性对照候选
- 每种 loss 重复若干次，报告均值和方差
