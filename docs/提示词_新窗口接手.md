**S3 Loss 对比实验要点（总纲第 5 节）：**

- 实验对象：简单 M3 直接估计模型（MLP）
- 候选 loss：原始参数 MSE / 标准化参数 MSE / NE-Loss / Huber / Quantile-Loss / Hybrid-Loss
- Hybrid-Loss：`α * Loss_param + (1-α) * Loss_quantile`，α ∈ {0, 0.25, 0.5, 0.75, 1.0}
- 评价标准：NE + NQE_R + Failure Rate + Outlier Rate，**必须按 gamma/eta 分层**
- MDM baseline 使用 mdm_offset_constrained，同时保留 min_sigma 作为敏感性对照
- 每种 loss 重复若干次，报告均值和方差

**S4.7 关键结论（你需要知道的）：**

MDM strict 的 32.8% failure 不是"理论无解"，而是在当前离散搜索下 offset 判据内点条件不满足，failure 样本表现为边界最优。

四种 MDM 变体对比（3600 样本/变体）：

| 变体 | NE | fail% | out% | 定位 |
|------|------|-------|------|------|
| strict | 0.419 | 16.8% | 4.4% | 诊断用 |
| **constrained** | **0.397** | **0.0%** | **5.1%** | **默认 MDM** |
| min_sigma | 0.409 | 0.0% | 15.2% | 敏感性对照 |
| neg_gamma | 0.396 | 0.0% | 7.5% | 仅诊断用 |

min_sigma 在 gamma/eta=1.0 时 outlier 率 33%，不适合做默认。原因是它倾向于选 gamma≈0。
