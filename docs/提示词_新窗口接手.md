## 后续 S3 Loss 对比实验要点

S3 可在 S2R 迁移完成后进入。MDM baseline 已确认为默认 `mdm`（S4.9 重写版）。

- 实验对象：简单 M3 直接估计模型（MLP）
- 候选 loss：原始参数 MSE / S2R 参数相对误差 MSE / S2R 参数 Huber / S2R 分位点相对误差 MSE / Hybrid-Loss
- Hybrid-Loss：`α * Loss_param_rel + (1-α) * Loss_quantile_rel`，α ∈ {0, 0.25, 0.5, 0.75, 1.0}
- 评价标准：MdAPE + MedRel + RelIQR + 尾部分位 + Valid Rate，必须按 gamma/eta 分层
- MDM baseline 使用默认 `mdm`（S4.9 几何网格+截断规则），不再使用 S4.5/S4.7 历史变体
- 每种 loss 重复若干次，报告均值和方差

## S4.9 MDM 当前状态（已覆盖 S4.7）

S4.9 已完成默认 MDM 重写，S4.7 的旧口径结论已被覆盖。

- 默认 MDM 使用 `geometric_from_tmin` 网格，从接近 t_min 的位置向 0 展开
- 有 offset 交点时返回 `solution_strategy = “offset_root”`
- 无交点且 gamma=0 处梯度仍高于 offset 时，截断到 gamma_hat=0，返回 `truncated_at_zero`
- offset 超过可观测梯度上限时，仍可能返回诊断性 `no_intersection` / `no_offset_root`
- 历史 MDM 变体（strict / constrained / min_sigma / neg_gamma）已归档到 `_archive/S4.9_MDM研究变体已完成/`
