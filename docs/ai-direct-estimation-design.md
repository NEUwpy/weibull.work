# AI 直接估计（模块 3）— 设计方案总览

> **状态**: V1 完成，8/8 预处理方案已实验，前端方案选择器已搭建
> **创建时间**: 2026-04-26
> **目标**: 端到端参数估计 — 输入样本 [t1,...,tn]，直接输出 β、η、γ，无迭代优化

---

## 一、核心问题

训练数据来自蒙特卡洛抽样：给定真值 (β, η, γ)，从 Weibull 分布抽取 n 个样本。
网络输入是这 n 个样本值，输出是预测的 (β̂, η̂, γ̂)。

**难点**：
- 三个输出量纲完全不同（β≈0.5-5, η≈100-5000, γ≈0）
- η 和 γ 会让同样的 β 产生完全不同范围的输入值
- n 不同时输入维度不同

---

## 二、模型架构选型

输入是固定长度的数值向量，输出是 3 个数值，本质是**表格数据回归问题**。

| 架构 | 适合场景 | 对本问题的适用性 | 结论 |
|------|---------|----------------|------|
| **MLP（全连接）** | 表格数据、向量→向量映射 | 最自然的选择，Module 1 已验证有效 | **V0 已实现** |
| **CNN（1D卷积）** | 信号、图像、有局部模式的数据 | 样本是有序统计量，不是"信号"，局部卷积无意义 | 不适合 |
| **RNN/LSTM** | 时间序列、有因果关系的序列 | 样本已排序，但顺序只是大小关系，不是时序 | 过度设计 |
| **Transformer** | 长序列、需要全局注意力 | n 通常 5-30，太短，attention 无优势 | 过度设计 |

**结论：用 MLP。** 后续可加对比实验验证。

---

## 三、三大方案

按"如何处理变长输入"划分为主方案，每个方案下有预处理子选项。

### 方案 A：独立模型

按 n 分别训练独立网络。Module 1（MDM δ 优化）采用此方案。

```
n=5  → 5→128→64→32→3  → 模型 A
n=10 → 10→128→64→32→3 → 模型 B
n=20 → 20→128→64→32→3 → 模型 C
```

- **优点**: 简单直接，每个网络专注一种输入维度，与 Module 1 一致
- **缺点**: n 越多模型越多，无法利用不同 n 之间的共性

#### 子选项：输入预处理

| 子选项 | 输入形式 | 说明 | 状态 |
|--------|---------|------|------|
| A-1 原始样本 | [t1, t2, ..., tn] | 最简单，网络自己学尺度不变性 | **V0 已实现** |
| A-2 除以均值 | [t1/t̄, t2/t̄, ..., tn/t̄, t̄] | 消掉 η 的影响，t̄ 作为额外特征保留 η 信息 | 待实验 |
| A-3 去位置 | [t1-t_min, t2-t_min, ..., tn-t_min] | 消掉 γ，网络只用学 β 和 η | **V1 已实现** |

---

### 方案 B：填充 + 掩码

固定最大长度（如 n_max=30），短样本补零，用掩码标记真实数据位置。一个模型覆盖所有 n。

```
统一输入: [t1, t2, ..., tn, 0, 0, ..., 0]  (补零到 n_max)
掩码:     [1, 1, ..., 1, 0, 0, ..., 0]      (1=真实数据, 0=填充)
```

- **优点**: 一个模型覆盖所有 n，可以利用不同 n 之间的共性
- **缺点**: 需要处理 padding；不同 n 的数据量可能不均衡

#### 子选项：输入预处理

| 子选项 | 输入形式 | 说明 |
|--------|---------|------|
| B-1 原始样本+掩码 | [t1,...,tn,0,...,0, m1,...,mn_max] | 掩码拼接到输入末尾 |
| B-2 除以均值+掩码 | [t1/t̄,...,tn/t̄,0,...,0, t̄, m1,...,mn_max] | 消 η + 掩码 |

---

### 方案 C：统计量输入

不输入原始样本，只输入预计算的统计量。输入维度固定，与 n 无关。

```
输入: [t̄, s, t_min, t_max, 偏度, 峰度, 中位数, ...]
```

- **优点**: 一个模型覆盖所有 n，维度小，训练快
- **缺点**: 丢失分布细节（不同分布可能有相同的均值和方差）
- **适用**: 对精度要求不高的场景；或作为基线对比

#### 子选项：统计量组合

| 子选项 | 输入特征 | 说明 |
|--------|---------|------|
| C-1 基础 | [t̄, s, t_min, t_max] | 4 个特征 |
| C-2 扩展 | [t̄, s, t_min, t_max, 偏度, 峰度, 中位数] | 7 个特征 |
| C-3 最大化 | C-2 + [Q1, Q3, IQR, 变异系数] | 更多分位数信息 |

## 四、输出与损失函数

**已实现：归一化 MSE + 线性输出**

```python
# 输出层：线性，直接输出归一化值
# 训练时 y 归一化为零均值、单位方差
# 推理时反归一化：y = pred * y_std + y_mean

# 损失函数（训练用）
loss = MSE(pred_normalized, y_normalized)

# 评估指标（原始尺度）
MAE(β), MAE(η), MAE(γ), 相对误差
```

> **踩坑记录**：V0 最初用相对 MSE 损失 + 原始 y 值，但 η 范围 (100-5000) 和 β 范围 (0.5-5) 差距太大，
> 网络无法同时学好两个尺度。改为输出归一化后效果大幅提升。

### 方案对比结论

| 结论 | 说明 |
|------|------|
| **C-1 ≈ A-1** | 4 个统计量 [mean, std, min, max] 已充分提取 Weibull 参数信息 |
| **B-1 统一模型可行** | 一个模型覆盖所有 n，精度与独立模型几乎相同，实用性最强 |
| **A-2 对 η 变差** | 除以均值反而丢失尺度信息，对 η 估计不利 |
| **C-2 无额外优势** | 偏度/峰度/中位数未提供超出 C-1 的新信息 |
| **A-3 明显变差** | 去位置丢失绝对尺度信息，MAE(β) 几乎翻倍（n=5: 0.97 vs 0.59） |
| **B-2 ≈ B-1** | 除以均值+掩码与原始+掩码精度相当，无明显差异 |
| **C-3 ≈ C-1** | Q1/Q3/IQR/CV 未提供超出基础统计量的新信息 |

### 设计决策

- **绝对精度 vs 相对精度**：用小 Tab 切换，不是两个独立区块
- **按维度精度分解**：单变量切换（n / β / η），每次只展示一个维度
- **散点图必须是点图**：不能用折线图连线，已有 `ScatterPlot` 组件
- **热力图（β-η 二维）**：暂缓，先把上述核心内容做好
