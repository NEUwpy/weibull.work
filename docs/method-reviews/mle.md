# MLE 计算过程建设与自查

日期：2026-11-10。按用户要求，以已确认的 MDM 建设规范完成 MLE 试建并先行自查，供用户检查；用户验收尚未进行。

## 方法依据与范围

本次展示现行`MLE.run → solve_mle_profile → mle_profile/_shape`的条件剖面计算，沿用β≥1、η>0、0≤γ<t₍₁₎的接受域，选择合格有限局部极大候选。估计规则未改。

原文及实现范围的权威说明见[方法说明](../../src/content/algorithms/mle.md)。Hirose（1996，182-105）提供数值基准；其GEV重参数化、Newton–Raphson流程与置信区间未在当前算法实现，本次页面建设不扩大这一对应范围。本轮核对本地原文与既有[原文摘录](../../reviewbyhtml/method-mle/assets/evidence.html)，PDF的SHA-256仍为`46d0b3a8ec106c7a5adff8953d55ee3b1cc71409d5c18a16a5240d7dc31f562f`。

## 步骤粒度与内容自查

依据[建设规范](../建设规范/02-参数估计方法/03-计算过程.md)，页面按六个完整计算问题组织；配置唯一维护在[MLE Python声明](../../python/methods/mle.py)。

| 页面步骤 | 自查结论 |
|---|---|
| 准备样本与支持范围 | 排序、归一化单位及可取范围有对应表和公式。经验概率仅用于最后的概率图R²，没有人为加到MLE求参中。 |
| 试算各位置的条件似然 | 每个实际试算位置联动条件形状得分图及β、η、似然值。形状得分、尺度回代和似然构造归入同一条件剖面问题；相关辅助函数完整保留在代码视角。 |
| 比较候选，确定位置 | 似然曲线、位置得分图和候选表共同解释γ。扫描、括根、窄谷/峰值精化及候选比较留在同一步；零位置及未找到有限候选有对应分支。 |
| 采纳对应位置的形状 | 单独显示所选位置的形状方程及采纳点，读取同次已完成的条件求解；β=1下界用不等式说明。 |
| 由幂均值恢复尺度 | 样本距离、幂次贡献、总和、样本数与尺度代入全部可核对；原始幂和溢出时改用已记录的归一化幂关系。 |
| 汇总结果与拟合检查 | 汇总三参数、似然、R²与求解状态；R²不参与似然选点，失败不填默认参数。 |

这一分组保留了条件剖面、位置采纳及最终参数恢复之间的关系。图像、代码和流程图共用步号；没有将一个根的差分/求解操作拆成多个导航，也没有把全部参数压成一个结果步骤。

## 图像、记录与源码核对

- MLE形状曲线和点只用实际求解记录，位置滑块也只选本次实际求过的位置。补充绘图采样及为联动另跑的条件求解已从MLE展示路径移除；调用次数测试证明开启记录没有新增条件求解。
- 每个位置保留`normalized_gamma`及`evaluation`。接近支持边界时，不同归一化位置换回物理单位可能舍入到同一γ；按原始求值身份关联形状记录，避免串到相邻求值。
- 位置曲线按横坐标排列，候选比较和函数求值不称为优化迭代。形状下界、零位置及未找到有限候选分别显示；支持边界极限保留在诊断详情，不画成已取到的参数解。
- 通用交互已提取为`CalculationWorkspace`、`MethodWorkflow`，MLE与MDM共用。MLE的步骤、21条编号公式、符号、输入输出、节点与源码引用均由`mle.py`声明；原`mle.json`及旧阶段登记已移除，旧源码链接有步号映射。
