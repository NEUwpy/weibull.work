# 计算器参数—样本双向工作流修复设计

## 背景

提交 `0cb97f8` 为避免后端失败时把本地 MLE 结果标成 MDM，改为清空计算器的 `initialResult`。方法身份问题因此消失，但参数栏、分布图和“参数生成样本”都依赖同一个 `result`，清空结果也切断了原有双向工作流。

本修复保留方法身份安全，同时恢复计算器的原有用途：用户既可以从参数生成样本，也可以从样本估计参数。

## 目标

- 参数栏始终有合法参数，图像始终由当前参数派生。
- 初始模式为 3P，默认参数为 `beta=2`、`eta=1000`、`gamma=1000`。
- 用户可以直接修改参数并生成样本。
- 只有点击“参数估计”才使用当前样本调用所选方法并覆盖参数。
- 估计失败不得清空或替换现有参数、图像和样本。
- 继续保证后端响应方法与请求方法一致，不恢复任何本地 MLE 或 WMLE 替代。

## 非目标

- 不修改任何 Weibull 估计算法。
- 不改变方法开放门控或 `05-状态.md`。
- 不改变计算器的四栏视觉布局和现有“开发中”交互。
- 不进入第一轮六个方法的建设。

## 方案选择

采用现有 `result + fitMode` 模型：

- `result` 保存参数栏和图像当前使用的参数；
- `fitMode: manual` 表示默认参数或用户直接修改的参数；
- `fitMode: fit` 仅表示经过身份校验的真实方法估计结果。

该方案复用现有数据流，改动范围小。完全拆分“显示参数”和“估计结果”会扩大变更面；回退 `0cb97f8` 会重新引入方法冒名，均不采用。

## 状态与数据流

### 初始化

- 新卡片默认进入 3P/manual 状态，参数为 `2/1000/1000`。
- 无 `caseId` 时，初始样本由上述默认参数生成，样本量沿用当前默认值。
- 有 `caseId` 时载入案例样本，但不自动执行参数估计；参数仍保持默认值，直至用户点击“参数估计”。
- 后端是否可用不得影响默认参数和图像的显示。

### 参数到样本

- 编辑 `beta`、`eta` 或 3P 下的 `gamma` 后，状态切换为 manual，图像立即更新。
- 点击“生成样本”时，使用当前参数和样本量替换样本栏数据。
- 生成样本不调用估计后端，也不改变所选方法。

### 样本到参数

- 只有点击“参数估计”才调用所选方法。
- 成功响应必须通过现有方法身份校验；通过后覆盖参数并切换为 fit，图像同步更新。
- 无解、未收敛、请求失败、后端不可用或方法身份不一致时，弹出错误信息；参数、图像、样本和模式保持调用前状态。

## 2P/3P 规则

- 默认选择 3P。
- 每张卡片保存自己的最近一次 3P `gamma`，默认值为 `1000`。
- 3P 下修改参数或成功得到 3P 估计时，同步更新该保存值。
- 从 3P 切换到 2P 时，保存当前 `gamma`，显示值强制为 `0`，位置参数不可编辑。
- 从 2P 切回 3P 时，恢复该卡片最近保存的 3P `gamma`；若没有保存值则使用 `1000`。
- 2P 下的估计结果不得覆盖已保存的 3P `gamma`。

## 重置

现有“清除参数”改名为“重置参数”：

- 3P 下重置为 `2/1000/1000`；
- 2P 下重置为 `2/1000/0`，并把待恢复的 3P `gamma` 重置为 `1000`；
- 重置后进入 manual，图像立即更新，但样本不自动改变。

## 验收与回归测试

至少覆盖以下行为：

1. 后端不可用时仍显示 3P 默认参数和对应图像。
2. 默认参数可以生成样本。
3. 手工修改参数会更新图像并进入 manual。
4. 参数估计成功后才覆盖参数并进入 fit。
5. 参数估计失败、无解或身份不一致时保留调用前的参数、图像和样本。
6. 3P → 2P 强制 `gamma=0`，2P → 3P 恢复原 `gamma`。
7. 2P/3P 重置值符合约定。
8. `caseId` 继续载入案例样本，但不自动把其他算法结果标为所选方法。
9. 计算器视觉结构、方法开放门控和既有方法身份测试不回归。
