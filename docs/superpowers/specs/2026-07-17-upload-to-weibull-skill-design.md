# Upload to Weibull 技能设计

## 目标

建立一个由 Codex、Claude Code、OpenCode 和 Hermes 共用的 `upload-to-weibull` 技能，将博士阶段文献库中已经完成 OCR 的文献安全投递到 `D:\weibull` 电子图书馆，并按当前站点规范完成发布前整理。

## 已选方案

采用“共享技能 + 安全复制脚本 + 代理语义整理”。共享技能只有一份权威实现；脚本只处理确定性的定位、预览、复制和冲突检查；YAML 元数据、图题与参考文献等需要理解论文内容的工作由代理完成。

不采用多目录独立副本，以免规则漂移；不采用全自动正文改写，以免误改数值区间、公式或作者—年份引用。

## 安装结构

- 权威目录：`C:\Users\36089\.agents\skills\upload-to-weibull`
- Codex：直接从共享 `.agents\skills` 发现技能。
- Claude Code：在 `.claude\skills` 建立指向权威目录的目录链接。
- OpenCode：在 `.config\opencode\skills` 建立指向权威目录的目录链接。
- Hermes：在当前安装实际使用的 `C:\Users\36089\AppData\Local\hermes\skills` 建立指向权威目录的目录链接；不写入已停用的旧 `C:\Users\36089\.hermes\skills` 副本。

技能包含：

- `SKILL.md`：触发条件、完整流程、边界和验收标准。
- `scripts/upload-to-weibull.ps1`：安全定位、预览和复制。
- `tests/upload-to-weibull.tests.ps1`：临时目录行为测试。

## 输入与定位

支持单个 ID、多个 ID 和同前缀连续范围，例如 `182-101`、`182-101,182-104`、`182-101到182-107`。

只允许从以下根目录递归定位：

- `D:\博士阶段\100科研文献管理`
- `D:\博士阶段\400知识管理`

每个 ID 可包含：

- 必需：`{ID}-pdf原文.md`
- 可选：`{ID}-pdf翻译.md`
- 可选：`{ID}-图片`

同一 ID 如果匹配到多个源目录，必须停止并报告歧义，不自行选择。

## 数据流

1. 解析并规范化 ID，拒绝不符合 `NNN-NNN` 的输入。
2. 定位每个 ID 的源文件，并生成投递清单。
3. 默认仅预览，不写入目标目录。
4. 用户明确要求执行后，将 Markdown 复制到 `D:\weibull\src\content`，将图片目录复制到 `D:\weibull\public`。
5. 复制后读取 `D:\weibull\src\content\README.md`，由代理完成 frontmatter、图片路径、图题和参考文献整理。
6. 检查真实 diff、资源完整性和站点相关验证，再报告结果。

## 安全规则

- 始终复制，不移动或删除博士阶段原文件。
- 默认 dry-run；只有显式执行参数才写入。
- 目标不存在时才复制。
- 目标存在且内容完全相同时跳过。
- 目标存在但内容不同时停止，禁止静默覆盖。
- 不接受源目录或目标目录越出允许根目录。
- 不读取 `_archive` 作为实现依据。
- 不修改 `05-状态.md`、方法算法、方法开放状态或生成缓存。
- 文献上传不等于方法建设证据升级。

## 语义整理规则

代理以当前 `src/content/README.md` 和同类已发布文献为准：

- 添加完整 YAML frontmatter，`summary` 必填且不超过 100 字。
- 仅在论文与方法有明确关系时填写 `related_method_id`。
- 将图片链接修复为网站可访问的根路径，但不改写公式或普通数值区间。
- 统一图题并保证图片资源实际存在。
- 将文末参考文献整理为站点支持的 `[数字]` 条目；遇到复杂书籍章末文献或作者—年份体系时逐项审核，不做无证据批量替换。

## 错误处理

下列情况立即停止对应 ID，并给出可操作报告：源原文缺失、重复源目录、目标冲突、图片引用缺失、frontmatter 无法可靠提取、参考文献结构无法安全判定。批量操作不得因一个 ID 失败而把其他 ID 伪报为成功；最终按 ID 分别列出 `planned/copied/skipped/conflict/failed`。

## 测试与验收

所有脚本测试只使用临时目录：

- 未提供执行开关时不产生目标文件。
- 显式执行时复制原文、翻译和图片。
- 缺少可选翻译或图片时仍能处理，并明确报告。
- 相同目标被跳过，不同目标触发冲突且不覆盖。
- 重复源、非法 ID 和越界路径被拒绝。
- 源目录在执行前后文件数量与哈希不变。
- 技能可被四种代理发现，且四处入口指向同一权威目录；Hermes 还需通过 `hermes skills list` 验证为 enabled。

完成语义整理后，再检查 YAML、图片链接、参考文献标题与编号、`git diff --check`，并运行与内容库相关的最小站点验证。

## 范围外事项

本技能不自动选择论文、不评价论文是否足以支撑方法状态、不修改方法建设事实源，也不自动提交或推送 Git 变更。
