## 1. 核心数学定义

基于文献 182-046 及项目代码 `mdm.py`，MDM (Minimum Deviation Method) 的核心逻辑如下：

### 1.1 尺度参数伪估计量 $\hat{\eta}_i$

对于任意给定的位置参数 $\gamma$ 和形状参数 $\beta$，每个样本点 $t_i$ 都可以反算出一个“理论上”应当存在的尺度参数 $\eta_i$：

$$
\hat{\eta}_i(\gamma, \beta) = \frac{t_i - \gamma}{(-\ln(1 - \hat{F}(t_i)))^{1/\beta}}
$$

其中 $\hat{F}(t_i)$ 是通过中位秩 (Median Rank) 等方法估计的经验累积分布概率。

令 $K_i = (-\ln(1 - \hat{F}(t_i)))$，则公式简化为：

$$
\hat{\eta}_i = (t_i - \gamma) \cdot K_i^{-1/\beta}
$$

### 1.2 目标函数 $\sigma_{\eta, \min}(\gamma)$

算法的目标是找到一组 $(\gamma, \beta)$ 使得所有 $\hat{\eta}_i$ 尽可能一致。一致性通过标准差衡量：

$$
S_\eta(\gamma, \beta) = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (\hat{\eta}_i - \bar{\hat{\eta}})^2}
$$

对于每一个固定的 $\gamma$，存在一个最优的 $\beta^*(\gamma)$ 使得标准差最小。我们将这个**条件最小标准差**定义为 $\gamma$ 的函数：

$$
\sigma_{\min}(\gamma) = \min_{\beta} S_\eta(\gamma, \beta)
$$

### 1.3 梯度 $abla(\gamma)$

文中定义的“梯度”即为条件最小标准差关于 $\gamma$ 的导数：

$$

abla(\gamma) = \frac{d \sigma_{\min}(\gamma)}{d \gamma}
$$

MDM 的修正判据是寻找 $\gamma$，使得 $
abla(\gamma) = \delta$（通常 $\delta=0.1$）。

---

## 2. 梯度单调性证明与分析

为什么在 Case 3 中观察到梯度曲线呈现单调性（通常是单调递增或递减，导致可能与水平线 $\delta$ 无交点）？

### 2.1 导数分析

考虑 $\hat{\eta}_i$ 对 $\gamma$ 的偏导数：

$$
\frac{\partial \hat{\eta}_i}{\partial \gamma} = -K_i^{-1/\beta} < 0
$$

这意味着随着 $\gamma$ 增加（逼近 $t_{\min}$），所有的 $\hat{\eta}_i$ 都在减小。

然而，我们需要关注的是**标准差**的变化。标准差反映的是 $\hat{\eta}_i$ 的离散程度。

当 $\gamma 	o t_{\min}$ (即 $\gamma$ 接近最小样本值 $t_1$) 时：
1.  对于最小的样本 $t_1$，其分子 $(t_1 - \gamma) 	o 0$。
2.  对于较大的样本 $t_n$，其分子 $(t_n - \gamma)$ 相对变化较小。
3.  因此，$\hat{\eta}_1$ 趋于 0 的速度远快于 $\hat{\eta}_n$。
4.  这导致 $\hat{\eta}_i$ 之间的相对比例发生剧烈扭曲，通常会导致离散程度（标准差）发生单调变化。

### 2.2 几何解释

在 $(x, y)$ 坐标系中（Weibull 概率纸），$\gamma$ 的改变相当于改变横坐标 $x = \ln(t - \gamma)$。
*   当 $\gamma$ 增加时，左侧的数据点（小 $t$）向左移动得比右侧数据点快得多（因为 $\ln$ 函数在接近 0 处斜率无穷大）。
*   这会改变数据点的**线性度**。
*   MDM 寻找的是使得 $\eta$ 最一致的点，本质上等价于寻找使得数据点线性度最好（或特定残差最小）的点。

$\sigma_{\min}(\gamma)$ 曲线通常是一个**下凸函数** (Convex function) 或近似下凸。
*   在 $\gamma$ 远离 $t_{\min}$ 时，标准差较大。
*   随着 $\gamma$ 接近真实值，标准差减小（达到极小值）。
*   当 $\gamma$ 过大（超过真实值，逼近 $t_{\min}$）时，数据过度弯曲，标准差再次急剧增大。

如果 $\sigma_{\min}(\gamma)$ 是下凸的，那么其导数 $
abla(\gamma)$ 就是**单调递增**的（从负值变为正值，穿过 0 点）。

**但在 Case 3 中，为什么会“单调递减”或“无交点”？**

这里存在一个定义上的混淆或特定样本的特殊性。让我们看 Case 3 的数据：
*   梯度范围：`[-0.73, -0.006]`
*   偏移值 $\delta = 0.2$

这说明在该样本范围内，$
abla(\gamma)$ 始终为负值，且最大值也未能达到 $0.2$。这意味着 $\sigma_{\min}(\gamma)$ 随着 $\gamma$ 的增加一直在减小（或者变平），但从未开始显著反弹（直到 $\gamma$ 非常接近 $t_{\min}$ 或算法截断）。

**数学证明思路：**

对于特定样本（特别是小样本），数据点可能天然呈现“下凹”形态。
增加 $\gamma$ 会拉伸左侧数据，试图将“下凹”拉直。
如果数据本身形态极端，可能需要 $\gamma$ 非常接近甚至超过 $t_1$ 才能把数据“拉直”（达到标准差极小）。
在这种情况下，在可行域 $\gamma \in (-\infty, t_1)$ 内：
1.  $\sigma_{\min}(\gamma)$ 单调递减。
2.  其导数 $
abla(\gamma)$ 始终为负。
3.  因此 $
abla(\gamma)$ 永远无法等于一个正数 $\delta=0.2$。

### 2.3 结论

Case 3 的“无交点”现象证明了：
**对于某些样本，MDM 的目标函数 $\sigma_{\min}(\gamma)$ 在定义域内没有极小值（或极小值点极其靠近边界），导致其导数 $
abla(\gamma)$ 始终小于目标偏移值 $\delta$。**

这并非算法错误，而是小样本统计规律的体现——某些样本看起来就是“右偏”严重的，统计学上认为其最佳位置参数应当尽可能大（接近 $t_{\min}$）。此时强制要求 $
abla(\gamma) = \delta > 0$ 会导致无法求解。

## 3. 算法改进建议 (182-046 启示)

文献 182-046 提议引入偏移量 $\delta=0.1$ 是为了解决**极值点通常偏小**的问题（即 $
abla=0$ 处 $\gamma$ 往往偏小）。
但在 Case 3 这种**无交点**（梯度全为负）的情况下，$\delta > 0$ 的限制反而使得问题更无解。

**代码中的处理逻辑 (`mdm.py`)：**

```python
if len(sign_changes) > 0:
    # 正常找到交点
    ...
else:
    # Fallback: Find point closest to offset
    # 寻找最接近 delta 的点
    min_diff_idx = np.argmin(np.abs(diffs))
```

在 Case 3 中，由于梯度最大值（例如 -0.006）最接近 0.2，算法会选择该点对应的 $\gamma$（通常是搜索范围的最右端，接近 $t_{\min}$）。这解释了为什么无交点样本通常会得到一个非常大的 $\gamma$ 估计值（接近边界），从而导致参数估计发散。

## 4. 总结

1.  **梯度含义**：$
abla(\gamma)$ 是尺度参数标准差关于位置参数的变化率。
2.  **单调性**：由于 $\sigma_{\min}(\gamma)$ 通常是下凸函数，$
abla(\gamma)$ 通常单调递增。
3.  **Case 3 异常**：在该案例中，$
abla(\gamma)$ 虽可能单调递增，但其**值域上限**小于 $\delta$。即曲线虽然在上升，但在撞到 $\gamma = t_{\min}$ 边界之前，从未升到 0.2 的高度。
4.  **物理意义**：这代表样本数据极度“甚至更需要更大的 $\gamma$ 才能变直”，但在 $\gamma < t_{\min}$ 的物理限制下，我们无法给它更大的 $\gamma$。
