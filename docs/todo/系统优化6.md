## 附录1：

**配置项边框颜色含义**

| 颜色 | 含义 |
|------|------|
| 🔴 红色边框 | 当前选中——统计结果对应的就是这个配置 |
| 🟢 浅绿色边框 | 已计算过，可切换选择 |
| ⚪ 白色边框 | 当前不可选（比如与红色选项冲突），但在其他组合下可选 |

**理解核对**

1. 用户点击绿色边框项 → 变成红色（当前选中）→ 统计结果更新为该配置对应的数据
2. 红色边框只能有一个（代表当前查看的配置）
3. 白色边框表示"存在这个计算结果，但与当前其他配置不兼容"

## 附录2：讨论澄清（2026-03-20）

### 1. 变量 vs 固定量的选择规则

| 类型 | 选择模式 | 红色数量 | 点击行为 |
|------|---------|---------|---------|
| **变量（多选）** | 最多2个维度 | 该维度可以有多个红色值 | 切换显示状态（点一下选中，再点取消） |
| **固定量（单选）** | 其余所有维度 | 每个维度只能有1个红色值 | 单选切换（点新的变红，旧的变绿/白） |

**示例**：
- 选择 β 作为变量（全选 β=2,3,4,5,7）→ 这5个值都是红色
- 此时 η 必须固定（只能选一个值，如 η=1000 红色）
- n 必须固定（只能选一个值，如 n=7 红色）

### 2. 变量选择的状态转换

```
当前状态：0个变量
    ↓ 点击任意参数的一个值
→ 该参数变为变量（多选模式），该值红色
→ 其他参数自动固定为默认值

当前状态：1个变量
    ↓ 点击另一个参数的一个值
→ 两种情况：
  A) 点击的是"全选"按钮 → 该参数变为第二个变量（多选模式）
  B) 点击的是某个具体值 → 该参数变为第二个变量，该值红色

当前状态：2个变量
    ↓ 点击第三个参数的某个值
→ 自动单选模式（已达变量上限）
→ 该值变红，该参数其他值按兼容性显示绿/白
→ ⚠️ 其他固定量需要随动到兼容的配置

切换变量维度：
  想从 β 改成 η 作为变量
  → 需要先取消 β 的变量状态（点击已选的值取消，或点"全不选"）
  → 再选择 η 作为变量
```

**固定量随动逻辑**：
- 当已有2个变量时，第三个参数的选择会触发其他固定量的联动
- 例如：β 和 n 是变量，选 η=1000 时，如果只有 η=1000/n=7 组合存在，则 n 自动切换到兼容值
- 需要根据已有 chunk 文件判断哪些组合可行

### 6. 前端解析逻辑

进入 Tab 后需要：
1. 请求 API 获取该示例所有 chunk 文件名列表
2. 解析文件名，提取所有可能的参数值
3. 根据当前选择状态，计算每个值的边框颜色：
   - **红色**：当前选中

**需要的 API**：
```
GET /api/studies/{methodId}/{studyId}/chunks

```
