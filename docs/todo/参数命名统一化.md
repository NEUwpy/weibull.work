# 参数命名统一化

## 问题背景

在方法对比、适用范围等组件中，参数的命名在不同层次上不统一，导致代码混乱、容易出错。

## 当前不一致情况

### 样本量 (Sample Size)

| 层级 | 名称 | 说明 |
|------|------|------|
| UI id | `sampleSize` | 配置面板中的参数标识 |
| chunk key | `n` | 文件名中的标识，如 `_n7_` |
| 内部状态 key | `n` | `selectedParams` 和 `fixedValues` 中使用 |
| CSV 列名 | `sample_size` | CSV 文件中的列头 |

### 偏移量 (Offset, MDM 特有)

| 层级 | 名称 | 说明 |
|------|------|------|
| UI id | `offset` | 配置面板中的参数标识 |
| chunk key | `d` | 文件名中的标识，如 `_d0.1_` |
| 内部状态 key | `offset` | `selectedParams` 和 `fixedValues` 中使用 |
| CSV 列名 | `offset_value` | CSV 文件中的列头 |

### 其他参数（已统一）

| 参数 | UI id | chunk key | CSV 列名 | 状态 |
|------|-------|-----------|----------|------|
| 形状参数 | `beta` | `beta` | `beta_true` | 统一 |
| 尺度参数 | `eta` | `eta` | `eta_true` | 统一 |
| 位置参数 | `gamma` | `gamma` | `gamma` | 统一 |
| 重复次数 | `rep` | `rep` | - | 统一 |
| 随机种子 | `seed` | `seed` | - | 统一 |
| 计算步长 | `step` | `step` | - | 统一 |

## 问题根源

1. **历史原因**: 不同组件在不同时期开发，没有统一的命名规范
2. **缺乏常量定义**: 每个组件各自定义参数，没有共享的参数定义文件
3. **映射分散**: `sampleSize` → `n`、`offset` → `d` 的映射逻辑分散在各处

## 导致的问题

1. **代码难以维护**: 需要记住每个参数在不同地方叫什么
2. **容易出 bug**: 如 `getBorderState('sampleSize', v)` 找不到 `selectedParams['sampleSize']`（实际是 `selectedParams['n']`）
3. **重复映射**: 多个组件都有类似的映射逻辑

## 解决方案

### 方案一：统一使用短名称

所有地方都使用 chunk key 作为标准名称：
- `beta`, `eta`, `gamma`, `n`, `d`, `rep`, `seed`, `step`

优点：简单，与文件名一致
缺点：`n` 和 `d` 可读性差

### 方案二：统一使用语义化名称

所有地方都使用语义化名称：
- `beta`, `eta`, `gamma`, `sampleSize`, `offset`, `rep`, `seed`, `step`

优点：可读性好
缺点：需要修改文件名格式（影响大）

### 方案三：创建共享参数定义（推荐）

创建一个共享的参数定义文件，集中管理映射关系：

```typescript
// src/lib/paramDefinitions.ts

export interface ParamDefinition {
  id: string           // 内部统一使用的标识
  name: string         // 中文显示名称
  symbol: string       // 数学符号
  chunkKey: string     // chunk 文件名中的 key
  csvColumn?: string   // CSV 列名（如有不同）
  isVariable: boolean  // 是否可作为变量维度
  isFixed?: boolean    // 是否固定值
}

export const PARAM_DEFINITIONS: Record<string, ParamDefinition> = {
  beta: {
    id: 'beta',
    name: '形状参数',
    symbol: 'β',
    chunkKey: 'beta',
    csvColumn: 'beta_true',
    isVariable: true
  },
  eta: {
    id: 'eta',
    name: '尺度参数',
    symbol: 'η',
    chunkKey: 'eta',
    csvColumn: 'eta_true',
    isVariable: true
  },
  gamma: {
    id: 'gamma',
    name: '位置参数',
    symbol: 'γ',
    chunkKey: 'gamma',
    csvColumn: 'gamma',
    isVariable: false,
    isFixed: true
  },
  sampleSize: {
    id: 'sampleSize',
    name: '样本量',
    symbol: 'n',
    chunkKey: 'n',
    csvColumn: 'sample_size',
    isVariable: true
  },
  offset: {
    id: 'offset',
    name: '偏移量',
    symbol: 'δ',
    chunkKey: 'd',
    csvColumn: 'offset_value',
    isVariable: false,
    isFixed: true
  },
  rep: {
    id: 'rep',
    name: '重复次数',
    symbol: 'rep',
    chunkKey: 'rep',
    isVariable: true
  },
  seed: {
    id: 'seed',
    name: '随机种子',
    symbol: 'seed',
    chunkKey: 'seed',
    isVariable: true
  },
  step: {
    id: 'step',
    name: '计算步长',
    symbol: 'step',
    chunkKey: 'step',
    isVariable: true
  }
}

// 工具函数
export const getChunkKey = (id: string) => PARAM_DEFINITIONS[id]?.chunkKey ?? id
export const getCsvColumn = (id: string) => PARAM_DEFINITIONS[id]?.csvColumn ?? id
export const getParamName = (id: string) => PARAM_DEFINITIONS[id]?.name ?? id
export const getParamSymbol = (id: string) => PARAM_DEFINITIONS[id]?.symbol ?? id
```
