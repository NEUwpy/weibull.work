### 0.1 分类维度思考

与其列出具体方法，不如先定义**分类维度**：

| 维度 | 可能的值 |
|------|---------|
| **与传统的关係** | 替代 / 辅助 / 独立 |
| **技术类型** | 优化算法 / 神经网络 / ... |

```
AI Methods
```

**特点**：技术导向，结构清晰，可扩展

## 一、核心设计理念：矩阵式交叉

**系统从四大模块变为五大模块**：

| 模块 | 定位 |
|------|------|
| Calculator | 计算器入口 |
| Methods | 传统参数估计方法（X轴） |
| **AI Methods** | 人工智能方法（Y轴）- **新增** |
| Cases | 案例数据库 |
| Library | 文献图书馆 |

**矩阵交叉示意**：

```
                    ┌────────────────────────────────────────────┐
                    │            AI Methods（Y轴）                │
                    │   GA    PSO    DE    NN-端到端   NN-过程量  │
┌───────────────────┼────────────────────────────────────────────┤
│ Methods（X轴）     │                                            │
│                   │                                            │
│  MDM    ──────────┼── MDM+GA  MDM+PSO  MDM+DE   (独立)   MDM+NN │
│  MLE    ──────────┼── MLE+GA  MLE+PSO  MLE+DE   (独立)   ...    │
│  MMLE   ──────────┼── ...                                     │
│  WMLE   ──────────┼── ...                                     │
│  ...              │                                            │
└───────────────────┴────────────────────────────────────────────┘
```

**交叉点的研究价值**：
- 横向对比：同一传统方法，不同优化器效果如何？
- 纵向对比：同一优化器，不同传统方法效果如何？
- 传统 vs AI：传统优化 vs 智能优化，谁更好？

---

## 二、AI Methods 模块组成

### 2.1 智能优化算法（与传统方法交叉）

| 算法 | 全称 | 用途 |
|------|------|------|
| GA | 遗传算法 | 替代传统方法中的优化步骤 |
| PSO | 粒子群算法 | 替代传统方法中的优化步骤 |
| DE | 差分进化 | 替代传统方法中的优化步骤 |
| ... | ... | ... |

**定位**：作为现有方法的"优化器选项"
- MDM 可以用：梯度下降 / GA / PSO / DE
- MLE 可以用：牛顿法 / GA / PSO / DE
- ...

### 2.2 神经网络方法（独立 + 交叉）

| 类型 | 描述 | 与传统方法关系 |
|------|------|---------------|
| **端到端映射** | 样本 → 参数（直接预测） | 独立，不依赖传统方法 |
| **过程量优化** | 预测最佳超参数（如MDM的δ） | 交叉，增强传统方法 |

**数据来源**：
- 针对具体任务，编写程序生成训练数据
- 不是复用现有蒙特卡洛数据，而是专项生成

### 6.3 示例：MDM-δ预测

```markdown
---
method_id: "mdm-delta"
method_name: "MDM偏移量预测"
short_name: "MDM-δ"
category: "neural-assist"

tech_type: "neural"
relation: "辅助"
related_method: "mdm"
input_form: "样本特征"
output_form: "超参数"

training:
  data_source: "遍历不同δ找最优，生成(特征, 最优δ)对"
  network_type: "MLP"
  input_dim: 8
  output_dim: 1

formula: "\hat{\delta} = f_{\theta}(x_1, x_2, ..., x_n)"
description: "用神经网络预测MDM方法中的最佳偏移量δ"
variables:
  - symbol: "x_i"
    description: "样本特征（均值、方差、偏度、峰度...）"
  - symbol: "δ"
    description: "最佳偏移量"
references: []
---

# 算法原理

## 概述

MDM方法中偏移量δ的选择影响估计精度。本方法用神经网络学习样本特征与最佳δ之间的映射关系。

## 网络结构

输入层(8) → 隐藏层(64,32) → 输出层(1)

## 训练过程

### 数据生成
1. 生成威布尔样本（不同β,η,γ,n组合）
2. 遍历δ，找使估计误差最小的δ*
3. 提取样本特征，构建训练对(特征, δ*)

...
```

### 6.4 与现有格式的差异

| 字段 | Methods | AI Methods |
|------|---------|------------|
| category | 极小化适配法等 | optimizers / neural-assist / neural-e2e |
| tech_type | 无 | optimizers / neural |
| relation | 无 | 替代 / 辅助 / 独立 |
| related_method | 无 | 关联的传统方法 |
| training | 无 | 数据生成、网络结构等 |
