# 四方法与论文的对应说明

更新：2026-09-26。完整核查统一维护在[Research09：现有四方法实现与版本核查](../../../../Research/09-Weibull参数估计方法谱系与比较基线/06-现有四方法实现与版本核查.md)，包含公式、LS/LRE区别、版本选择、历史代码差别及数值失败诊断。

| Excel标签 | 实际调用 | 当前版本及论文关系 |
|---|---|---|
| LS | lse | Soman–Misra（1992，182-104）的White回归扩展F最大化分支；次序统计量期望分数，对数寿命对分数回归 |
| LRE | lre | Bernard分数＋相关系数选位置＋分数对对数寿命OLS；Li（1994，182-107）是变换背景，Park（2018，182-106）支持相关路线；不是Li第4节直接复现 |
| WMLM / WMLE | wmle | Cousineau（2009，182-088）的权重修正方程；项目增加参数约束、查表规则和多起点接受检查 |
| MLM / MLE | mle | 三参数似然的项目多起点求解及有限候选筛选；Hirose（1996，182-105）是理论/比较依据，不能据此声称完整复现其求解程序 |

代码副本与2026-09-26生产方法一致，但不等同于8月25日原任务的所有旧实现。9月7日与9月21日案例的四方法源码与当前一致。WMLE副本缺少导入必需的 `j3_weights.tsv`，该表目前位于仓库 `python/methods`，本目录不是独立运行包。

最新W2案例中WMLE原来的3条失败已找到同方程的有效根，原Excel保留；论文比较应采用审计后的求解策略并另生成结果，不能将这三条称为理论无解。具体证据和复查命令见完整核查文档。
