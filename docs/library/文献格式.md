# 文献格式 v1

适用于 `library.json` 的 `schema_version: 1`。新整理文献用 UTF-8 Markdown，顶部为 YAML 表头，正文保留论文内容；示例见 [模板](templates/文献模板.md)。

## 编号与表头

- 沿用博士文献编号，如 `182-046`，不因移动或更换分类而重编。文件名为 `<编号>-pdf原文.md`、`<编号>-pdf翻译.md`，至少一份，直接放 `content/`。网站地址为 `/library/<编号>`。
- 有译文时，列表元数据和默认正文优先取译文；原译文均须有表头，作者、年份、类型等身份信息保持一致。只有原文也可读取。
- `title` 是识别必填项；其余字段按下表整理。元数据须有来源，不能猜测补全。

| 字段 | 格式与用途 |
|---|---|
| `title` | 非空字符串，当前语言的文献标题；必填 |
| `title_en` | 字符串，英文标题；可选 |
| `author` | 字符串，多位作者写在同一字符串中；建议填写 |
| `year` | 实际发表年份，整数；建议填写，缺失时列表会显示当前年，不能据此认定发表年 |
| `type` | 字符串：`期刊`、`会议`、`书籍`；其他值仅出现在“全部”中，不写“会议论文” |
| `publication` / `short_publication` | 出版物全称 / 简称，字符串；可选 |
| `affiliation` | 作者单位，字符串；可选 |
| `tags` | 不重复的字符串数组，如 `["Weibull", "参数估计"]`；无标签用 `[]` |
| `summary` | 论文摘要或简述，字符串；建议填写，不混入自己的研究结论 |

## 正文与资源

标题用 Markdown，行内公式用 `$...$`，独立公式用 `$$` 包围并单独成段。保留正文、公式、图表及参考文献的对应关系；不要为适配页面改写论文结论。

图片实际位置与正文网址分开写：

```text
文件：assets/182-046-图片/images/figure.jpg
正文：![图 1](/182-046-图片/images/figure.jpg)
PDF：[论文 PDF](/182-046-图片/paper.pdf)
```

网址从 `/<编号>-图片/` 开始，用 `/`，不写磁盘绝对路径、`assets/` 或相对的 `182-046-图片/...`。保留真实文件名、大小写和子目录；资源支持 PNG、JPG/JPEG、GIF、WebP、SVG、AVIF、PDF，路径中的空格可写 `%20`。PDF 使用普通链接，不会自动转换成正文。批次资源目录只保留需要发布的文件，不放 OCR 中间数据或私人笔记。

## 引用

参考文献放全文末尾，以 `## 参考文献` 或 `## References` 开始；每条独占一行，以 `[1]`、`[2]` 等实际编号开头，正文使用对应的 `[1]`。该标题后不要继续放正文或附录。

作者—年份制不能直接获得当前的结构化跳转；需核对正文与条目对应关系后再转号，不能猜测编号。

跨文章跳转另写库根 `references.json`，例如：

```json
{"182-046":{"1":"182-088"}}
```

表示 `182-046` 的第 1 条参考文献链接到已入库的 `182-088`。只登记已核实的关系；没有映射用 `{}`，参考条目仍可显示。软件不自动按题名或 DOI 匹配，导入工具也不合并此文件。

## 入库检查

按 [README 的流程](README.md)先整理副本再导入。检查编号与表头、资源网址及文件、原译文对应、引用编号，最后运行 `check` 并打开网页验收；工具通过不代表 OCR 或公式内容正确。
