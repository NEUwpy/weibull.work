v2书票示例，演示值应换成核实信息：

```json
{
  "schema_version": 2,
  "mode": "source",
  "sources": [{
    "root": "D:/博士阶段/100科研文献管理/100科研文献管理/180_AI辅助参数估计/182_传统参数估计方法",
    "papers": [{"id": "182-046", "metadata": {
      "title": "论文实际标题", "author": "实际作者", "year": 2025,
      "type": "期刊", "tags": ["参数估计"], "summary": "核实后的公开简述"
    }}]
  }]
}
```

`root`为本机绝对路径，指向核实后的具体分类目录，以消歧历史重号；不提交本机选单路径或凭证。只读取`papers`选中的编号，活动目录存在多个版本时停止，不猜版本；历史、归档、190及隐藏目录不参与选篇。当前源读取不支持发布包内相对root。

公开题录`metadata`优先于原译文YAML，其余题名、作者、年份等可兼容笔记题录。`title`须为有效标题，`year`为真实四位年份；`author`为字符串，`type`沿用期刊/会议/书籍等展示分类，`tags`为去重字符串数组。可另填`title_en`、`affiliation`、`publication`、`short_publication`、`summary`、`related_method_id`；不填未知值，不猜元数据。`summary`只取书票或原译文显式公开字段，不自动发布笔记正文或笔记摘要。

正文与图片格式按110的模板维护，不要求全库增加网站YAML。图片写源稿相对路径；读取层只在内存将其转为资源网址，不回写源文件。只开放选中编号的`ID-图片/`资源，支持PNG、JPG/JPEG、GIF、WebP、SVG、AVIF及PDF；笔记和邻近文件不作为资源公开。

阅读地址仍为`/library/<编号>`；原译文分别读取。旧网站`144-003`已据重命名证据对应100的`171-003`：本机source模式兼容旧内容/资源请求，列表只显示171-003；v1回退仍按原144-003读取。

跨文献引用写`references.json`，如`{"182-030":{"28":"182-095"}}`。只对已选目标提供站内跳转；未选、待修目标保留引用文字，不制造失效站内链接。公开正文不混入私人笔记、OCR日志或校对清单。
