## 网页验证、待上架与恢复

统一验证器在100的`110_管理规范与总集/工具/文献编译器/`，直接复用本仓真实源读取器及`library-markdown`规则。`validate --file`检查一份Markdown；`compile`检查同篇现有原译文或批量检查。失败报告文件、行号、原因；**通过即达到待上架标准**，无额外人工验收表门槛。内容校对照常据原文进行，但不能用其记录审批代替网页验证。

`register`每次编译当前源稿和书票；显式`--apply`后进入正式书单，`--ledger`可选。编译通过只代表待上架，所有正式上架均须用户明确选择；编译不自动修改书单。100缺文献时只列下载清单，由用户下载到191后入库。100的格式、模板、命令及共用技能2.6.0见[110 README](D:/博士阶段/100科研文献管理/100科研文献管理/110_管理规范与总集/README.md)。

迁移和整理必须比较原完整书单、各份原译文及资源，逐项确认保留，不能以“文件还在”代替“网站仍可用”。当前恢复证据、版本差异与原配置备份在`D:\weibull-backups\library-validation-correction-20261029`。此前因质量问题移除条目的做法已更正；既存新发现的格式问题如实记录，不静默撤书。

台账仅汇集验证结果和候选，不能成为第二份文献数据库。网页所用源稿、题录、图片、解析规则改变后重新验证；PDF和个人笔记模板变化本身不作显示门槛。
