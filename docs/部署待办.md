## NAS 远程终端配置（一次性）

配置后可异地远程访问 NAS 终端，无需局域网。

### 步骤 1：创建配置文件

在 NAS 上创建 `/share/docker/remote-terminal/` 目录，放入两个文件：

**Dockerfile:**
```dockerfile
FROM alpine:latest
RUN sed -i 's~dl-cdn.alpinelinux.org~mirrors.aliyun.com~' /etc/apk/repositories \
        && apk --update --no-cache add bash \
        bash-doc \
        bash-completion \
        busybox-extras \
        && rm -rf /var/cache/apk/*
ADD runcmd.sh /bin
RUN chmod +x /bin/runcmd.sh
```

**runcmd.sh:**
```bash
#!/bin/bash
COMMAND="$1"
shift
FULL_COMMAND=$(printf "%q " "$COMMAND" "$@")
nsenter -m -u -i -n -p -t 1 sh -c "$FULL_COMMAND"
```

### 步骤 2：构建并运行（需局域网）

```bash
ssh WPY@192.168.31.148
mkdir -p /share/docker/remote-terminal
cd /share/docker/remote-terminal
# 上传 Dockerfile 和 runcmd.sh 后
docker build -t ug_temp_ssh .
docker run -itd --pid=host --privileged=true --name ug_temp_ssh ug_temp_ssh
```

### 步骤 3：远程使用

以后异地访问时：
1. 绿联云 → Docker → 容器 → ug_temp_ssh → 控制台 → 终端
2. 执行 `nsenter -m -u -i -n -p -t 1 sh` 进入宿主机
3. 或用 `runcmd.sh <命令>` 直接执行
