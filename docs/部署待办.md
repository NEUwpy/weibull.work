## NAS 首次部署命令

回到局域网后，在 Windows PowerShell 执行：

```bash
ssh WPY@192.168.31.148 'bash -s' < C:/Web/Weibull/deploy-nas.sh
```

或者手动执行：

```bash
ssh WPY@192.168.31.148
mkdir -p /share/docker && cd /share/docker && git clone https://github.com/NEUwpy/weibull.work.git weibull && cd weibull && docker-compose up -d --build
```
