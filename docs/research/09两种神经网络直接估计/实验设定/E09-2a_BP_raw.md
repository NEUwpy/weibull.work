# E09-2a BP-raw：排序样本输入实验

## 目的

检验 BP 神经网络直接使用排序样本作为输入的效果，作为后续对比的基线。

## 输入形式

- **输入维度**：n（随样本量变化）
- **输入内容**：排序后的失效样本 [x₁, x₂, ..., xₙ]
- **输出维度**：3（β̂, η̂, γ̂）

## 参数配置

| 参数 | 范围 | 说明 |
|------|------|------|
| β | [1.0, 5.0] | 形状参数 |
| η | [0.5, 5.0] | 尺度参数 |
| γ | [0.0, 2.0] | 位置参数 |

## 样本量

n ∈ {5, 7, 10, 15, 20, 50}

## 数据规模

| 数据集 | 配置数 | 重复次数 | 总样本数 |
|--------|--------|----------|----------|
| 训练集 | 500 | 4 | 2000 |
| 验证集 | 100 | 4 | 400 |
| 测试集 | 100 | 5 | 500 |

## 模型结构

```
输入(n) → Linear(128) → BN → ReLU → Dropout(0.1)
        → Linear(64) → BN → ReLU → Dropout(0.1)
        → Linear(32) → BN → ReLU → Dropout(0.1)
        → Linear(3)
```

## 训练参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 学习率 | 1e-3 | Adam |
| 权重衰减 | 1e-4 | L2正则 |
| Batch size | 64 | |
| 最大轮数 | 200 | |
| 早停轮数 | 30 | 基于验证集损失 |
| 损失函数 | MSE | 参数空间均方误差 |

## 评价指标

1. **参数视角**：β/η/γ 的 Bias, SD, RMSE, MAE
2. **工程视角**：x₀.₉₅, x₀.₉₉ 的相对 Bias, SD, RMSE, MAE
3. **失败率**：预测值无效的比例

## 输出文件

- 模型：`程序/E09-2a_bp_raw_n{N}.pt`
- 训练历史：`实验数据/E09-2a_history_n{N}.csv`
- 测试结果：`实验数据/E09-2a_test_results.csv`
- 汇总指标：`实验数据/E09-2a_summary.csv`
- 图像：`图像/E09-2a_*.png`

## 备注

- 每个样本量单独训练一个模型（因为输入维度不同）
- 记录训练时间，用于后续与特征输入方案对比
