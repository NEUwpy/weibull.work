# 09 研究骨架：三参数 Weibull 的 AI 直接估计范式比较

> 本骨架用于指导后续 Agent 编程验证与迭代补全。当前只固定研究主线、页结构和判定问题；具体参数网格、网络结构、分箱方式、特征细节由实验阶段根据结果调整。

## 总问题

三参数 Weibull 分布参数估计可直接看作连续回归，也可将连续参数空间划分为若干区域后转化为分类问题，还可先分类定位区域、再局部回归精估。本研究比较三种范式在 AI 直接估计中的适用性：

- 连续回归：样本或样本特征 -> `(beta_hat, eta_hat, gamma_hat)`
- 离散分类：样本或样本特征 -> 参数区域类别 -> 参数估计
- 分类 + 局部回归：先定位参数区域，再在区域内估计连续参数

核心评价不预设哪种一定更好，而是回答：哪种范式在不同样本量、不同参数区域、不同评价视角下更合适。

---

## 第1页：问题属性与研究问题

**目的：** 明确三参数 Weibull 直接估计在 AI 建模中的问题属性，回应“参数估计是否更像分类”的导师问题。

**过程：**

1. 说明三参数 Weibull 的目标参数 `(beta, eta, gamma)` 本质上是连续变量，直接输出参数属于连续回归。
2. 说明同一组参数会生成许多不同样本，即“参数 -> 样本”是一对多；但这并不排斥回归，也提示样本到参数的反问题可能不稳定。
3. 说明工程应用中的参数范围通常有限，可将连续参数空间划分为若干区域，把估计问题改写为“参数区域识别”。
4. 引出机器学习中的 regression-via-classification 思路：连续目标可离散化为分类任务，再由类别中心、概率加权或局部回归还原连续值。

**结果：** 本研究不争论“参数估计只能回归还是只能分类”，而是比较三种可实现范式：连续回归、离散分类、分类 + 局部回归。

**待做实验：** 无。本页为问题定义页。

## 第2页：BP 回归输入形式消融

**目的：** 重新检验已有 BP 神经网络，并先解决一个关键问题：BP 的输入到底应使用原始样本，还是固定维度统计特征。

**过程：**

设计至少两类输入：

1. **排序样本输入**：将失效样本排序后直接输入。优点是信息保留多；缺点是输入维度随 `n` 变化，通常需要按样本量分别训练。
2. **统计特征输入**：使用固定维度样本统计量，如均值、标准差、极值、分位数、偏度、峰度、变异系数、分位数比值等。优点是不同 `n` 可共用一套输入结构；缺点是可能损失原始样本形态信息。

同一训练/测试数据下比较 BP-raw 与 BP-feature 的参数误差、工程寿命误差和样本量敏感性。

**结果：** 判断 BP 表现不稳定是否主要来自输入表示。如果统计特征输入明显更稳，则后续回归、分类、混合模型优先使用统一特征输入；如果原始样本更强，则保留按 `n` 分模型的路线。

**待做实验：**

- `E09-2a` BP-raw：排序样本输入，按样本量训练或采用固定补齐策略。
- `E09-2b` BP-feature：固定统计特征输入，跨样本量训练或分层训练。
- `E09-2c` 输入形式对比：报告 `J_param`、逐参数 RMSE、`x0.95/x0.99` 误差和训练稳定性。

## 第3页：BP 回归随样本量的误差变化

**目的：** 专门回答导师提出的疑问：BP 直接回归的误差是否随样本量增大而稳定下降，还是出现平台、波动甚至变差。

**过程：**

使用第2页选出的 BP 输入方案，按样本量序列训练和测试。每个样本量下使用同一参数采样范围、同一随机种子规则、同一评价口径。

重点输出：

- `n -> RMSE_beta / RMSE_eta / RMSE_gamma`
- `n -> J_param`
- `n -> x0.95 / x0.99` 工程寿命误差
- 误差分布图，尤其观察 `gamma` 的偏态、重尾或边界行为

**结果：** 形成 BP 回归基线结论：它是否能从更大样本量中获益；若获益不足，问题主要出现在所有参数，还是集中在 `gamma` 或工程寿命指标。

**待做实验：**

- `E09-3a` BP 样本量扫描。
- `E09-3b` 参数视角误差曲线。
- `E09-3c` 工程寿命误差曲线。
- `E09-3d` BP 误差分布与失败/异常样本分析。

## 第4页：分类范式与 SVM 实验

**目的：** 将导师提出的“用分类方法 / 支持向量机”落成可验证方案，检验离散分类是否比连续 BP 回归更适合直接估计。

**过程：**

1. 在有限参数范围内划分参数区域。分箱方式先保持可调，可从等距、等频或按误差敏感区间划分开始。
2. 优先采用逐参数分类，避免三参数联合分类导致类别数爆炸。
3. 使用 SVM 分类器预测 `beta / eta / gamma` 的区域类别。
4. 将类别结果还原为参数估计：先用类别中心值；若模型支持概率输出，再测试概率加权。
5. 同时记录分类准确率和还原后的参数误差，避免只看分类准确率。

**结果：** 判断纯分类是否有实际收益。若分类在小样本或 `gamma` 上更稳，说明参数区域识别有价值；若误差受分箱宽度限制明显，则说明纯分类存在精度上限。

**待做实验：**

- `E09-4a` 参数分箱方案与离散化误差下界。
- `E09-4b` SVM 逐参数分类。
- `E09-4c` 类别中心 / 概率加权还原参数。
- `E09-4d` SVM 分类 vs BP 回归对比。

## 第5页：分类 + 局部回归混合模型

**目的：** 在纯回归和纯分类之间构造折中方案：先用分类定位参数区域，再在该区域内做连续估计。

**过程：**

两阶段模型：

1. 分类阶段：用样本特征预测参数区域。
2. 局部回归阶段：在预测区域内输出连续参数修正量或连续参数值。

可先从简单组合开始，例如 SVM 分类 + BP/SVR 局部回归；若结果支持，再考虑共享特征编码、多头输出或更复杂网络。局部回归的训练方式保留弹性，可按真实类别训练，也可按预测类别做端到端误差评估。

**结果：** 判断混合模型是否能同时减少纯回归的全局映射难度和纯分类的分箱误差。如果混合模型优于两者，说明“先区域识别、再局部精估”是更合适的直接估计范式。

**待做实验：**

- `E09-5a` SVM 分类 + BP 局部回归。
- `E09-5b` SVM 分类 + SVR 局部回归。
- `E09-5c` Oracle 分类 + 局部回归上限。
- `E09-5d` 分类错误传播分析。

## 第6页：三种范式统一对比与样本量效应

**目的：** 汇总连续回归、离散分类、分类 + 局部回归三种范式，给出最终方法选择建议。

**过程：**

在同一测试集、同一参数范围、同一指标口径下比较：

- BP 连续回归
- SVM 分类
- 分类 + 局部回归
- 必要传统估计标尺：至少包含 MDM/MLE；若使用 LSE，需标注为研究用本地对照实现

统一报告：

- 参数视角：Bias / SD / RMSE / MAE / `J_param`
- 工程视角：`x0.95 / x0.99` 的 Bias / SD / RMSE / MAE
- 样本量效应：误差随 `n` 的变化曲线
- 运行成本与部署复杂度
- `gamma` 误差分布与边界行为

**结果：** 给出最终结论表：在哪些样本量、哪些参数区域、哪个评价视角下，连续回归、离散分类或混合模型更合适。

**待做实验：**

- `E09-6a` 三种范式统一测试。
- `E09-6b` 样本量-误差主图。
- `E09-6c` 参数视角与工程视角排序对比。
- `E09-6d` 最终方法阶梯表。

## 最终主线

```text
问题属性
  -> BP 输入形式消融
  -> BP 样本量误差基线
  -> SVM 分类验证
  -> 分类 + 局部回归
  -> 三范式统一对比
```

## 执行边界

- 不提前认定分类一定优于回归，也不提前否定 BP。
- 分类路线必须同时报告分类准确率和还原后的参数误差。
- 混合模型先做简单可解释版本，再视结果决定是否加复杂网络。
- 指标默认沿用标准口径：参数 Bias / SD / RMSE / MAE，工程寿命 `x0.95 / x0.99` 同步报告。
- 具体参数网格、样本量序列、分箱数、特征列表可在实验中调整，但每次调整必须记录原因。
