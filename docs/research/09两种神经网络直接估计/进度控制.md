- 2026-06-14：创建项目结构，准备阶段。

- 2026-06-15：E09-2b BP-feature 实验完成。6个样本量训练完成，与 E09-2a 效果相近。E09-2c 对比图表已生成。创建交接文档。
- 2026-06-15：**修正 J_param 计算错误**。原计算使用绝对 RMSE 的欧氏合成，应为相对误差的平方和开根号。正确值：E09-2a 从 0.515 降至 0.281，E09-2b 从 0.518 降至 0.287。已更新研究内容和图表。
- 2026-06-15：E09-3 误差分布分析完成。主要发现：(1) beta/eta 误差右偏，gamma 左偏，偏度随样本量减小；(2) gamma 边界行为可控，负预测率<5%；(3) x0.95 尾部风险随样本量减小。
- 2026-06-15：**E09-4 SVM 分类实验完成**。主要发现：(1) 纯分类不如连续回归，J_param 高 16-26%；(2) 概率加权法比类别中心法略好；(3) 分类准确率 20-45%（K=10）；(4) 离散化下界 K=10 时为 0.452。
- 2026-06-15：**E09-5 混合模型实验完成**。主要发现：(1) 混合模型比纯 BP 差 25-31%；(2) Oracle 上限 J_param≈0.11，远低于 BP 的 0.28-0.52；(3) 分类错误传播到局部回归是主要原因。
- 2026-06-15：**E09-6 三范式统一对比完成**。最终结论：BP-raw 最优（J_param 0.281@n=50），SVM 次之（+16-26%），Hybrid 最差（+23-31%）。Oracle 上限极好（0.11），说明分类精度是瓶颈。研究全部完成。
