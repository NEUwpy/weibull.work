# 回归 vs 分类：三参数威布尔 AI 参数估计的框架对比与样本量标度律研究骨架（v1）

> 四大块，每块内按页拆分。每页 = 一个研究目的 + 对应过程 + 对应结果 + 待做实验。

> ⚠️ **状态说明：** 本骨架为立项初稿，全部实验尚未在统一框架下运行，`结果`字段多为(待填充)或先验假设。后续在统一代码框架下跑完每一轮实验后，根据最新结论回头修正后续规划，贝叶斯式迭代更新。**当前骨架是先验，不是定论。**

> **整体逻辑闭环：** 本研究回应导师提出的两个判断——**(H1)** 参数估计本质上是分类问题；**(H2)** 回归（函数拟合）方法在大样本时误差并不明显下降，甚至可能更差。01 厘清回归与分类的正确表述、并复用已建立的双视角评价体系；02 锁定**输入特征表示**这一关键混淆变量（很可能就是 H2 的真正成因）；03 在公平协议下实现并对比回归 / 分类 / 经典三类方法；04 给出核心发现——各方法的"误差-样本量"标度律与制度交叉点。**目标不是证明导师对或错，而是把两个直觉做成可发表的严格结论。**

> **与已有 MDM 工作的衔接：** 本研究是"直接用 AI 估参"这条独立支线（区别于"用 NN 选 MDM 的 δ"），但复用 01 已建立的双视角指标（J_param / J_eng），并把已吃透的 **MDM 直接纳入经典基线**，与新课题自然咬合。

# 第一大块：01 问题表述与评价框架——回归还是分类？

## 第1页：「多对一」不能判定问题类型

**目的：** 厘清导师"一组参数对应多个样本，所以是分类"这一判据是否成立，避免在论文中写下站不住脚的表述。

**过程：** 形式化对比回归与分类的输入-输出结构。指出"多个输入对应一个目标"（多对一）在回归与分类中**共有**；生成式上"一组参数 → 多个样本"只是说条件分布 p(x|θ) 有展宽，这对**任何**统计估计都成立，与 θ 离散/连续无关。

**结果：** 多对一结构**不能**判定问题类型。真正区分二者的是被预测量 θ 的性质：θ ∈ 无序有限集 → 分类；θ 连续、有序、有度量（2.0 比 1.9 更接近 2.1）→ 回归。→ **推论：** 威布尔 (β, η, γ) 连续有序，根上是回归问题；"参数估计 = 分类"作为定性表述不成立，但这并不否定分类作为一条**实现路线**（见第2页）。

**待做实验：** 无。纯论述页。

## 第2页：连续参数估计的本质是回归；分类是"离散化 recast"

**目的：** 把分类路线安放在正确的理论位置——不是"问题本来就是分类"，而是"把连续回归离散化"（regression-via-classification），这是机器学习里正当且活跃的做法。

**过程：** 论述 regression-via-classification：将连续目标分箱、用 softmax over bins 预测，配合软标签 / 有序结构。说明其代价（离散化的分辨率损失）与潜在收益（对异方差、多峰后验的天然表达）。

**结果：**（待填充——确立分类路线的正当性与定位：作为后续可实现、可对比的方法之一，而非理论必然。）

**待做实验：** 无。纯论述页。

## 第3页：分类可能优于回归的机制与条件——提出可检验假设 H1′

**目的：** 把导师"分类也许更好"的直觉，转写成**有机制、可证伪**的假设，而不是"试试看"。

**过程：** 分析分类何时可能赢过直接 MSE 回归：当后验 p(θ|样本) 偏态或多峰时（三参数威布尔小样本下，**位置参数 γ 的后验恰常如此**），softmax over bins 比单点 MSE 回归更能表达不确定性，回归会被均值拉向不可达的中点。据此提出 **H1′：分类路线的优势（若存在）集中在小样本区，尤其对 γ。**

**结果：**（待填充——给出 H1′ 的精确陈述与判定方式。）

**待做实验：** 无。假设提出页。

## 第4页：评价指标——复用双视角框架 + 新增样本量标度维度

**目的：** 确定本研究的评价口径。直接复用 01 已建立的双视角体系，避免重复造指标；新增"误差-样本量"曲线与收敛率 α 作为本研究的核心新判据。

**过程：** 沿用

- J_param = √( mean( ((β̂−β)/β)² + ((η̂−η)/η)² + ((γ̂−γ)/η)² ) )
- J_eng = √( mean( (x̂₀.₉₅−x₀.₉₅)² + (x̂₀.₉₉−x₀.₉₉)² ) )

**新增核心刻度：** 对每个方法拟合 误差(n) ≈ C·n^(−α)，以收敛率 α 作为"误差随样本量下降快慢"的单数字概括。逐参数仍成套报告 Bias / SD / RMSE 用于诊断（尤其 γ 必须看分布图，注意双峰与 γ̂=0 截断）。

**结果：**

- 排序统一用 J_param / J_eng；
- **核心新指标：收敛率 α**（理论上经典估计 α≈0.5），用于直接检验 H2；
- 诊断保留多指标 + γ̂=0 截断率 + 误差分布图。

**待做实验：**

- `E01-1` 指标管线对接：复用已有 metrics 口径，新增 α 拟合模块（对 RMSE-n 序列做 log-log 线性回归估 α 及其 95% CI）。

# 第二大块：02 输入特征表示——"大样本误差不降"的关键变量

> **核心猜想：** 导师观察到的"回归方法大样本误差不降"，主因很可能**不是回归本身，而是输入特征表示不当**。本块把特征表示作为一等研究变量，这是本研究的关键贡献点之一。

## 第1页：原始数据 vs 统计量输入

**目的：** 论证输入表示如何决定样本量标度行为，定位 H2 的可能成因。

**过程：** 对比两类输入：①原始排序样本（维度随 n 变化、受绝对尺度/位置干扰）；②固定维度统计量（与 n 解耦）。分析①在大样本下为何可能不降反难：输入维度膨胀、网络直接看绝对数值、训练困难。

**结果：**（待填充——预期：原始数据输入的 α 显著偏小或走平；统计量输入 α 更接近经典率。）

**待做实验：**

- `E02-1` 输入表示消融：同一数据、同一回归网络，分别用"原始样本输入"vs"统计量输入"，对比各自的 误差-n 曲线与 α。

## 第2页：不变性特征——偏度只依赖形状 β

**目的：** 给出针对每个参数"对的"特征，利用威布尔的不变性结构。

**过程：** 利用关键性质：**威布尔偏度对平移和缩放都不变，因此只由形状 β 决定**。设计：估 β 用位置-尺度不变特征（样本偏度、峰度、分位数比值如 (q₀.₉−q₀.₅)/(q₀.₅−q₀.₁)）。样本量越大，这些量越接近真值，β 估计自然随 n 改善——这正是对症 H2 的钥匙。

**结果：**（待填充——预期：不变特征下 β 的 α 接近 0.5，"大样本不降"在 β 上消失。）

**待做实验：**

- `E02-2` 不变性特征验证：构造偏度/峰度/分位数比值特征单独估 β，看 误差-n 曲线是否恢复下降；并做平移缩放不变性单元测试（同一底层样本经平移缩放后，特征逐位一致）。

## 第3页：分步估计结构——先定形状，再定尺度与位置

**目的：** 把不变性结构落成一个估计流程，作为可能的方法贡献点。

**过程：** 分步：①用不变特征定 β；②给定 β 后，尺度 η 与位置 γ 退化为平移-缩放问题，用原始矩 / 分位数恢复。说明其与经典概率加权矩 / L 矩思路相通。

**结果：**（待填充——分步 vs 端到端联合估计的精度与样本量标度对比。）

**待做实验：**

- `E02-3` 分步 vs 联合：对比分步估计与一次性联合回归的 J_param 及各参数 α。

## 第4页：特征方案对样本量标度的总体影响

**目的：** 汇总 02，确定进入 03 对比时回归 / 分类两条线**统一采用**的特征方案，避免特征缺陷污染后续框架对比。

**过程：** 横向对比各特征方案的 误差-n 曲线，选定一个"公平且不拖后腿"的统一特征集供 03 使用。

**结果：**（待填充——给出统一特征集与选择理由。）

**待做实验：**

- `E02-4` 特征方案阶梯表：原始 / 统计量 / 不变特征 / 分步，各自 α 与 J_param 汇总，定标 03 用特征。

# 第四大块：04 核心发现——样本量标度律与制度交叉

> 这是文章的落点：把导师的两个直觉做成严格的、量化的结论。

## 第1页：误差 floor 假设的检验——估各方法的 α

**目的：** 直接检验 H2（回归大样本不降），并把它精确化为"是否存在误差地板 / α 是否显著小于 0.5"。

**过程：** 对每个方法、每个参数，对 RMSE(n) 在 log-log 上拟合 误差 ≈ C·n^(−α)，估 α 及 CI。经典法应 α≈0.5；若某 AI 方法 α 显著 < 0.5 或 RMSE 在大 n 走平，则坐实"误差地板"。

**结果：**（待填充——预期：AI 方法存在地板，α < 0.5；经典法 α≈0.5。这正面回应 H2：原回归方法在大样本确实未明显改善。）

**待做实验：**

- `E04-1` α 对比与地板检验：各方法 α 及 CI；地板水平估计；与经典率 0.5 的显著性检验。

## 第2页：制度交叉——小样本 AI 占优、大样本经典占优

**目的：** 给出本研究**最有价值的结论**：不是"谁绝对更好"，而是"在哪个样本量区间谁更好"。

**过程：** 在 误差-n 图上定位交叉点：小 n 区，三参数威布尔 MLE 不稳（失败率高），AI 可能更准更稳；大 n 区，经典法持续按 1/√n 下降而 AI 卡在地板，经典反超。定位交叉 n*，并按参数（尤其 γ）与 γ/η 分别给出。

**结果：**（待填充——预期：存在交叉点；小样本 AI 优势区 + 大样本经典优势区 + 交叉 n*。）

**待做实验：**

- `E04-2a` 交叉点定位：各参数 / 各 γ-η 比下的 n*；小样本区 AI vs MLE 失败率对比。
- `E04-2b` 鲁棒性量化：MLE 失败率 vs n 曲线，量化小样本区 AI 的可用性价值。

## 第3页：分类 vs 回归在各制度下的差异——检验 H1′

**目的：** 回答导师最初的问题——分类到底比回归好不好，好在哪里。

**过程：** 在统一框架下比较 {回归路线} vs {分类路线}：总体 J_param / J_eng、各参数、随 n 变化。重点检验 **H1′**（分类优势若有则集中在小样本、尤其 γ 的偏态/多峰后验）。用 softmax 读出的后验形态佐证机制。

**结果：**（待填充——预期：分类总体不必然胜出，但在小样本 / γ 上可能有局部优势；给出"分类在何处有价值"的精确边界。）

**待做实验：**

- `E04-3a` 回归 vs 分类全维对比：双视角 × 各参数 × 随 n。
- `E04-3b` 后验形态佐证：分类 softmax 后验在小样本下的偏态/多峰，与分类局部优势对应。

## 第4页：结论与发表落点

**目的：** 汇总全部发现，给出论文的核心论点与贡献清单。

**过程：** 收敛三条线：①问题表述（回归为本、分类为离散化 recast）；②特征表示是大样本标度的关键（解释 H2）；③制度交叉（AI 小样本占优、经典大样本占优、交叉 n*）+ 分类局部价值（H1′）。给出方法建议（按样本量 / 参数选方法）。

**结果：**（待填充——核心论点 + 贡献清单 + 方法选择建议表。）

**待做实验：**

- `E04-4` 结论汇总表：方法 × 样本量区间 × 推荐度；与固定方法对照的显著性（CI 分离）。
