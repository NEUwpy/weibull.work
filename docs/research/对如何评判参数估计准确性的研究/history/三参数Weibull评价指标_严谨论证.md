# 三参数 Weibull 参数估计评价指标的严谨论证

> 在"研究方法准确性 + 深度学习用于参数估计"的范围内，明确**参数视角**和**应用视角**各自的"准确性 / 稳定性 / 求解率"三类指标，并确定损失函数。所有结论都用蒙特卡洛实证检验。

---

## 一、问题分析与立场澄清

### 1.1 评价范围

本报告评价指标的适用范围被严格限定为**两个已知真值的场景**：

| 场景 | 是否知道真值 | 评价对象 |
|---|---|---|
| 方法学蒙特卡洛 | 知道 | 估计器（MLE、矩、PWM、贝叶斯、概率图…）|
| 深度学习模拟训练 | 知道 | 神经网络（输入→参数的映射）|

**真实数据应用阶段**不在本报告范围内：那时没有真值，所谓"准确性评价"是不存在的——只能做拟合优度（AD/PPCC/AIC 等）或基于 Bootstrap 的置信区间，那是另一个问题。因此本报告**不需要也不会**讨论"知道真值/不知道真值"的指标差异。

### 1.2 评价指标的三类分工

把所有评价目标都塞进一个"综合指标"是不合理的。三类信息必须分开报告：

| 类别 | 性质 | 用途 | 数量 |
|---|---|---|---|
| **准确性** | 排名/比较型 | 哪个方法更准？ | 1 个主指标 |
| **稳定性** | 通过门槛型 | 重复实验结果分散到何种程度还能接受？ | 1 个主指标 |
| **求解率** | 通过门槛型 | 方法能不能算出结果（不崩、不发散）？ | 1 个主指标 |

**为什么必须分开**：实验一构造了两个"虚拟估计器"对同一真值 η=1000 做估计：

| 估计器 | 配置 | MdAPE | Mean RelBias | RelIQR | RRMSE |
|---|---|---|---|---|---|
| **A** | 无偏，σ = 30% | 20.30% | −0.16% | 40.46% | **30.18%** |
| **B** | 偏 −15%，σ = 10% | 14.95% | −14.92% | 15.97% | **17.98%** |

仅看 **RRMSE**，B 远好于 A（18% vs 30%），结论是"B 是更好的估计器"。
但 B 实际上是个**系统性低估 15%** 的估计器——这个 −15% 的偏差被 RRMSE 完全吃进去了，只有单独看 **Mean RelBias** 才能暴露。在可靠性中：

- 若被低估的是 η（特征寿命），导致**低估 B 寿命** → 偏保守，**安全**；
- 若被低估的是某个高估方向的量，可能**高估 B 寿命** → **危险**。

工程上不能让一个综合数字替你做这种判断。**这就是把准确性和稳定性合成 RRMSE 后丢失的信息。**

### 1.3 参数视角与应用视角必须并存

这一点在三份原始报告中已成共识，我在前一轮回复也用实证（固定逐参数 RMSE 不变、仅改变误差相关性 ρ，RRMSE(x_{0.99}) 从 14% 涨到 28%）再次确认过。不再重复。

## 二、参数视角的指标体系

### 2.1 推荐：参数视角的三个主指标 + 一个方向辅助

| 指标 | β | η | γ |
|---|---|---|---|
| **准确性（核心比较）** | MdAPE | MdAPE | Median&#124;err&#124; / η |
| **稳定性（通过门槛）** | IQR / Median | IQR / Median | IQR / η |
| **求解率（通过门槛）** | 有效估计率（三参数共用一个数）|||
| **方向辅助** | Mean RelBias | Mean RelBias | Mean err / η |

**定义**：

- **MdAPE**（Median Absolute Percentage Error）= median(&#124;θ̂ − θ&#124; / θ)
- **IQR / Median** = (P75(θ̂) − P25(θ̂)) / median(θ̂)
- **Mean RelBias** = mean((θ̂ − θ) / θ)
- **有效估计率** = (收敛 ∩ 非边界解 ∩ 非异常解) 的次数 / 蒙特卡洛重复次数

### 2.2 为什么用 MdAPE 作为准确性主指标

**它说什么**：50% 的估计的相对误差不超过此值。可解释、可排名、与稳定性指标天然对偶。

**为什么不用 RRMSE（=√mean((err/真值)²)）**：
- RRMSE² = (Mean RelBias)² + (Relative SD)²，本质上是把**准确性**和**稳定性**两个独立信息合并。这正是你要避免的"综合性指标"。
- 实验一里：RRMSE 给"B 比 A 好"的结论，但掩盖了 B 的 −15% 系统偏差。

**为什么不用 |Mean RelBias|**：
- 它只反映系统偏差，不反映幅度。一个"平均=真值但每次都飘 ±100%"的估计器 |Mean RelBias|=0，看上去"完美"，但每一次都很糟。
- 把它放在**方向辅助**位置最合理。

**为什么不用 MAPE = mean(|err|/真值)**：
- 不稳健。三参数 Weibull 估计常出现 γ 边界解、似然无界等异常解；MAPE 会被这些极端值拉高，无法反映"典型"性能。
- MdAPE 用中位数，自然过滤掉异常。

**为什么不用 log-RMSE**：
- 实证上小到中等误差区与 RRMSE 几乎等价（差异 <2 个百分点，见上轮回复）；
- 对称性优势在三参数 Weibull 实际误差范围内意义有限；
- 解释力差："log-RMSE=0.18" 不如 "50% 误差小于 12%" 直观。

### 2.3 为什么用 IQR / Median 作为稳定性主指标

**它说什么**：估计的中间 50% 分散在中位数的几个百分点之内。

**为什么不用 CV = SD / Mean**：
- 实验二中 n=20 时 β̂ 的样本里有少量极端值（β > 10 或 < 0.5），CV 会被几个异常解严重污染；
- IQR 基于 P25/P75，对极端值不敏感，反映"典型分散"。

**为什么不用 Var 或 SD 单独**：
- 量纲化的 SD 不可跨参数比较（η 的 SD ≈ 200，β 的 SD ≈ 0.5，差三个数量级）；
- IQR / Median 是无量纲的相对分散，与 MdAPE 的相对误差形成自然对偶。

### 2.4 为什么用"有效估计率"作为求解率指标

三参数 Weibull 的似然在 γ → x_min 时可能无界（Cousineau 2009, Nagatsuka 等, 2013, da Silva 等, 2025 反复强调）。MLE、矩、PWM 都可能产生：

- **不收敛**（迭代发散或超过最大次数）
- **边界解**（γ̂ ≈ x_min，似然取在边界上）
- **异常解**（β̂ 离谱大或离谱小，超出物理意义）

一个"误差很小但 30% 的样本算不出来"的方法在工程上不可用。**有效估计率必须单独报告**，不能藏在准确性指标的均值里。

### 2.5 验证：三参数 Weibull MLE 的全套指标

仿真：β = 2.5, η = 1000, γ = 100, n ∈ {20, 50, 100}, N = 2000 次重复，剖面似然 MLE。

| n       | 参数     | MdAPE (准确) | IQR/Median (稳定) | Mean RelBias (方向) | 有效率  |
| ------- | ------ | ---------- | --------------- | ----------------- | ---- |
| **20**  | β      | 27.01%     | 55.48%          | −9.93%            | 100% |
|         | η      | 19.79%     | 43.41%          | −15.38%           |      |
|         | γ (/η) | 11.78%     | 36.16%          | +12.51%           |      |
| **50**  | β      | 15.69%     | 31.55%          | −5.10%            | 100% |
|         | η      | 12.30%     | 25.53%          | −6.99%            |      |
|         | γ (/η) | 10.00%     | 21.53%          | +6.00%            |      |
| **100** | β      | 10.01%     | 19.99%          | −2.93%            | 100% |
|         | η      | 7.99%      | 16.31%          | −4.06%            |      |
|         | γ (/η) | 6.88%      | 13.12%          | +3.45%            |      |

**这张表能告诉你的信息**：

- **三类指标随 n 同步缩小**（一致性）—— 每个指标都正常工作；
- **方向**：β、η 系统**低估**（负偏），γ 系统**高估**（正偏）；偏差幅度从 n=20 的 5–15% 收敛到 n=100 的 3–4%；
- **稳定性**始终大于准确性（IQR/Median > MdAPE）—— 这是 MLE 在小样本下的典型行为：典型估计已经接近真值，但"重复一致性"仍较差；
- **求解率 100%**：剖面似然 MLE 在 β=2.5 的"损耗型"区域数值稳定；当 β < 1 或样本极小时这一栏才会下降，那是估计方法的工程关注点（不属于本报告评价指标）。

## 三、应用视角的指标体系

### 3.1 推荐：应用视角的三个主指标 + 一个方向辅助

**评价对象**：寿命分位点 x_R = γ + η · (−ln R)^(1/β)，对应可靠度 R 的 B 寿命。

| 指标 | x_R |
|---|---|
| **准确性（核心比较）** | MdAPE of x_R |
| **稳定性（通过门槛）** | IQR(x_R) / Median(x_R) |
| **求解率（通过门槛）** | （沿用参数视角的有效估计率）|
| **方向辅助** | Mean RelBias of x_R |

**关键约定**：在多个 R 上报告（**至少** R ∈ {0.999, 0.99, 0.95, 0.90, 0.50}），不要只用一个。

### 3.2 为什么是这个组合（与参数视角完全对应）

x_R 是一个正的寿命量，单位是时间，所以：

- **MdAPE** 仍然成立："50% 的 B 寿命估计相对误差不超过此值"是工程直接可读的。
- **IQR/Median** 仍然成立。
- **Mean RelBias** 在应用视角下**比参数视角更重要**——因为：
  - 高估寿命 = 高估安全裕度 = **危险方向**；
  - 低估寿命 = 设计偏保守 = **安全方向**。
  - 单看 MdAPE 这种取绝对值的指标，看不出方向，必须配方向辅助。

### 3.3 为什么不用"原始单位 RMSE"或"对数 RMSE"

- **原始单位 RMSE_{x_R}**（如"误差 50 小时"）：不能跨产品/跨工况比较，B0.999 和 B0.5 的真值差一个数量级，相同绝对 RMSE 意义完全不同。
- **log-RMSE**：实证上与 MdAPE/RRMSE 在中小误差区差异 <2 个百分点（前一轮验证过）；引入解释成本而无实质增益。

### 3.4 为什么必须在多个 R 上报告

这是参数视角无法替代应用视角的根本原因。从 x_R 公式求偏导可知：

- **β 误差**主要影响**深尾**（R 接近 1）；
- **η 误差**主要影响**中段**（R ≈ 0.5）；
- **γ 误差**主要影响**近阈值高可靠度**。

如果只在一个 R 上报告，你看到的是这三种误差的**特定组合**——可能掩盖某一项的严重问题。多 R 报告才能识别"模型对中位准但对深尾差"或反之。

### 3.5 验证：x_R 的全套指标

复用同一组蒙特卡洛结果（β=2.5, η=1000, γ=100, n=50, N=2000）：

| R | x_R 真值 (h) | MdAPE | IQR/Median | Mean RelBias | 有效率 |
|---|---|---|---|---|---|
| 0.999 | 163.1 | **38.64%** | 68.18% | **+33.96%** | 100% |
| 0.990 | 258.8 | 18.60% | 33.98% | +16.39% | |
| 0.950 | 404.8 | 10.10% | 17.71% | +6.25% | |
| 0.900 | 506.5 | 7.40% | 14.20% | +3.05% | |
| 0.500 | 963.6 | 4.19% | 8.37% | −1.02% | |

**这张表暴露的两个关键问题**：

1. **深尾误差比中位大一个数量级**：R=0.999 处 MdAPE 是 R=0.5 处的 9 倍。这是参数视角里看不到的——参数视角告诉你 η 误差 12%、β 误差 16%，但深尾 B 寿命误差实际是 39%。
2. **方向系统性危险**：所有 R 的 Mean RelBias 都是**正**——n=50 下 MLE 系统性**高估** B 寿命，越往尾部越严重（R=0.999 处 +34%）。这意味着这套估计在可靠性应用中**系统性偏乐观**，必须做偏差修正或换估计方法。

**只看 MdAPE（=38.64%）**会让你感觉"误差大，但谁知道哪个方向"。**配上 Mean RelBias（=+33.96%）**才知道"误差几乎全在高估方向"。这就是方向辅助不可省的原因。

## 四、损失函数的选择

### 4.1 设计原则

损失函数应满足三条标准：

1. **与评价指标同空间**：评价用 MdAPE（相对误差）或 log 空间，损失也应在相对/log 空间。
2. **梯度量纲一致**：不让某个参数因量纲大而主导优化。
3. **优化地形稳定**：在三参数 Weibull 的非正则问题上不应有边界发散。

### 4.2 主推荐：**log-参数 MSE**

L_param = (log β̂ − log β)² + (log η̂ − log η)² + ((γ̂ − γ) / η)²

**为什么是这个**：

- (log β̂ − log β)² 把 β 拉到对数空间，自然对应 β 的乘法尺度（β=1 和 β=2 的"距离"与 β=2 和 β=4 相同）；η 同理；
- γ 不能 log（可能为 0），用 η 归一化，与评价指标 "Median |err| / η" 完全对应；
- 三项量纲一致（都是无量纲数），梯度规模匹配，不会让任何一项主导优化；
- 与评价指标 MdAPE 同空间——优化目标和最终评价目标对齐。

**适用场景**：你的"模拟训练"——已知真参数，网络从样本（或样本统计量）映射到 β, η, γ。

### 4.3 进阶推荐：**混合损失**

L = λ · L_param + (1 − λ) · L_quant

L_quant = Σ_R (log x̂_R − log x_R)²  （R 取 {0.99, 0.95, 0.90} 等关心的目标）

**为什么需要混合**：

- 仅优化参数恢复，不保证 B 寿命（应用视角）也好——参数的小误差可能在尾部放大；
- 仅优化分位点，可能出现"参数明显错但分位点碰巧对"的补偿现象；
- 二者加权可同时控制两种误差。λ 通常取 0.5–0.7，按你最关心的视角调。

### 4.4 为什么**不用** Weibull NLL 作首选

NLL（负对数似然）= −Σ log f(x_i; β, η, γ)，是 WTTE-RNN、DeepWeiSurv、DPWTE 等深度生存模型的主流选择。**它在真实数据 + 删失场景下是首选**，但在你的场景下不是。

**理由**：

1. **你知道真值**：NLL 让网络"通过样本间接逼近真分布"，而 log-参数 MSE 直接让网络"逼近真参数"，**信息利用更高效**。
2. **三参数非正则**：NLL 在 γ → x_min 时似然无界，优化地形差，需要专门的剖面/正则化处理。log-参数 MSE 没有这个问题。
3. **梯度信噪比**：从 50 个样本算出来的 NLL 是含蒙特卡洛噪声的（每个 batch 都不一样），而真参数是确定的——后者梯度更稳定。

**什么时候 NLL 仍有用**：

- 输入是**原始寿命样本**（不是统计特征），网络要从原始时间序列学；
- 数据有**删失**（NLL 自然处理：删失样本贡献 log R(t)）；
- 这两种情况下 log-参数 MSE 不可用（不知道真值或无法用），NLL 是合理替代。

### 4.5 为什么**不用**原始尺度 MSE（对 β, η, γ 直接 MSE）

L = (β̂ − β)² + (η̂ − η)² + (γ̂ − γ)²

**这正是评价时不能合并 MSE 的训练版本**：

- η 数值 ≈ 1000，β 数值 ≈ 2，γ 数值 ≈ 100，三项量纲悬殊；
- η 的梯度 ≈ 400 × β 的梯度；网络只学好 η，β 和 γ 几乎被忽略；
- 实验四的实证：原始 MSE 下 η MdAPE = 5.4%（最好），β MdAPE = 19.6%（最差）—— **β 几乎没学到东西**。

### 4.6 为什么**不用** C-index / ranking loss

C-index 评估的是"风险排序"，不评估**校准**（即预测值数值上是否准确）。你的目标是参数恢复 + 分位点准确，要的是数值的对，不是排序的对。C-index 顶多作很小权重的辅助项。

### 4.7 pinball 与 CRPS 的位置

- **pinball loss**（针对特定 R 的分位点损失）：可以作为 L_quant 的具体实现。如果你最关心的 R 很特定（例如 B10 寿命），可以用 pinball(τ=0.1) 直接代替 (log x̂ − log x)²。
- **CRPS**（完整分布的连续分级概率评分）：只有当你要输出完整分布（不只是参数）时才需要。对参数估计任务过度复杂。

### 4.8 验证：四种损失函数的实证对比

仿真：200 个独立任务，每个任务 50 个 Weibull 样本，真参数从先验池 (β ∈ [1.5, 4], η ∈ [500, 2000], γ ∈ [0, 300]) 抽取。

| 损失函数 | β 的 MdAPE | η 的 MdAPE | γ 的 Median&#124;err&#124;/η | 评价 |
|---|---|---|---|---|
| **log-参数 MSE**（理想训练目标）| 0.00% | 0.00% | 0.00% | 模拟训练的天花板（已知真值） |
| **Weibull NLL**（数据驱动） | 16.92% | 16.28% | 12.16% | 真实数据/删失场景首选 |
| **原始尺度 MSE**（失败模式） | 19.62% | **5.42%** | 22.29% | β、γ 学不好，只学好 η |

**关键启示**：

- log-参数 MSE 给出"模拟训练能达到的上限"，是网络要逼近的目标；
- NLL 是当输入是原始样本时的合理替代，但 MdAPE 普遍比 log-参数 MSE 高 12–17 个百分点——这是"间接学习"的固有代价；
- 原始 MSE 选 η 的代价是 β 和 γ 的崩溃。**在任何场景下都不要用**。

## 五、综合方案（一张表）

| 视角 | 准确性主指标 | 稳定性主指标 | 求解率 | 方向辅助 | 综合参考 |
|---|---|---|---|---|---|
| **参数（β, η）** | **MdAPE** | **IQR / Median** | **有效估计率** | Mean RelBias | RRMSE（与文献对话）|
| **参数（γ）** | **Median&#124;err&#124; / η** | **IQR / η** | 同上 | Mean err / η | RMSE / η |
| **应用（x_R, 多 R）** | **MdAPE of x_R** | **IQR(x_R) / Median(x_R)** | 同上 | Mean RelBias of x_R | RRMSE of x_R |

| 用途              | 推荐损失                                                                 | 备注             |
| --------------- | -------------------------------------------------------------------- | -------------- |
| **首选（模拟训练）**    | **log-参数 MSE**：(log β̂ − log β)² + (log η̂ − log η)² + ((γ̂ − γ)/η)² | 与评价指标同空间，最稳    |
| **进阶（兼顾应用）**    | **log-参数 MSE + L_quant**：λ·L_param + (1−λ)·Σ_R(log x̂_R − log x_R)²  | λ ∈ [0.5, 0.7] |
| **备选（原始样本/删失）** | Weibull NLL                                                          | 数据驱动，处理删失自然    |
| **永远不要用**       | 原始尺度 MSE、C-index 作主损失                                                | 量纲、目标错位        |

## 六、报告呈现建议

**表 2：B 寿命精度**（每行一个方法/模型，列：R × {MdAPE, IQR/Median, Mean RelBias}，R 多列）
**表 3：稳健性**（每行一个方法/模型，列：有效估计率、训练失败率、运行时间）

**首选指标加粗**，辅助指标常规字体。
当 MdAPE 很小（如 < 5%）时，把 RRMSE 也补上作为"与文献对话"的参考值，因为大部分 Weibull 文献用 RRMSE。
