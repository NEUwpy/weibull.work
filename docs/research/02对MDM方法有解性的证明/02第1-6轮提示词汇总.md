## 二、核心问题（最终收敛为4个）

1. **为什么会无解？** 三类成因定量分离：数值漏检、γ≥0下界切除、真正固有无解。用真实样本+图像说明机理。
2. **怎么能始终有解？** 算法流程："一次探测g(0) + 括弧/Brent定根 + 负则截断到0"。无解时返回诊断信息。
3. **网格怎么取平衡精度和成本？** 几何加密 vs 均匀网格的成本-精度对比，直接给推荐步数和网格。
4. **推荐方案在蒙特卡洛下表现如何？** 覆盖多种(β, γ₀/η, n)组合，报告有解率、精度、计算量。

## 三、研究对象与公式

三参数威布尔：F(x) = 1 - exp(-((x-γ)/η)^β), x > γ

MDM核心步骤：
1. Bernard中位秩：F_i = (i - 0.3) / (n + 0.4)
2. 伪尺度参数：η_i(β,γ) = (t_i - γ) / [-ln(1-F_i)]^(1/β)
3. 对固定γ，找β使std(η_i)最小 → β*(γ)
4. 定义σ_min(γ) = std(η_i) at β*(γ)
5. 梯度g(γ) = dσ_min/dγ
6. offset-root判据：找γ使g(γ) = δ（δ=0.1，因为δ=0时波动大）

## 五、无解分类（7类，需给出每类样本数和比例）

1. σ(β|γ)正常，g(γ)=offset有交点 → 有解
2. σ正常，g全域高于offset
3. σ正常，g全域低于offset
4. g接近offset但无符号变化（near-miss）
5. 粗网格无解、高分辨率有解（数值漏检）
6. σ多峰或β贴边界导致不稳定
7. 梯度估计噪声造成假有解/假无解

## 六、必须新增的验证实验

- Bernard中位秩 vs F分布中位秩：同批样本对比有解率和根位置差异
- 直接二维搜索σ(β,γ) vs 廓线方案S(γ)=min_β σ：验证等价性
- β*(γ)≈β₀近似的成立条件
- np.gradient vs 解析梯度的差异

## 七、工程方案论证

- γ<0时截断到0：统计γ<0的分布，证明精度影响可控
- γ贴近t₁网格不够：用极贴近t₁的值试算+拟合
- 需对比：单纯加密网格 vs 几何加密 vs 截断方案的精度损失和计算效率
- 证明在精度损失可控基础上合理简化
