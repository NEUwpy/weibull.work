MDM 方法的公式和算法

给定一组失效时间样本,先排序:

t(1) ≤ t(2) ≤ ... ≤ t_(n)

对第 i 个样本点,用中位秩估计经验累积分布函数。常用 Bernard 近似:

F_i = (i - 0.3) / (n + 0.4)

令:

x_i = -ln(1 - F_i)

对于任意给定的 β 和 γ,可以由 Weibull 分布反推出第 i 个样本点对应的伪尺度参数:

η_i(β, γ) = (t_i - γ) / x_i^(1/β)

如果 β 和 γ 合理,那么所有 η_i 应该尽量接近。定义伪尺度参数标准差:

S_η(β, γ) = sqrt(1/(n-1) * Σ(η_i - mean(η_i))^2)

对于每一个固定的 γ,先寻找使 S_η 最小的 β:

β*(γ) = argmin S_η(β, γ)

然后定义条件最小标准差函数:

σmin(γ) = minβ Sη(β, γ) = Sη(β*(γ), γ)

位置参数 γ 必须满足:

γ < t_min

其中 tmin = t(1),即最小样本值。

然后计算 σ_min(γ) 关于 γ 的梯度:

∇(γ) = dσ_min(γ) / dγ

传统极值思想会取:

∇(γ) = 0

这表示 σ_min(γ) 的极值点,也就是伪尺度参数标准差最小的位置。但实际中发现,直接取 ∇(γ)=0 时,估计出的 γ 可能波动很大,尤其可能非常贴近最小样本值 t_min,导致 β、η、γ 的估计不稳定。

因此,MDM 中引入一个梯度偏移量 δ,不再取 ∇(γ)=0,而是寻找:

∇(γ) = δ

例如工程或文献中可能使用 δ = 0.1。我想证明MDM方法的有解性,给你发的文件是两个不同ai的推导,你看看哪个对,综合一下前人的智慧,给我一个更加好,论证更加清晰的版本
