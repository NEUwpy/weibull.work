这个“论文版”**整体比我之前那版更好**，更像一篇能投稿/给导师看的研究论文；但它也有几个**容易被审稿人抓住的硬伤**，需要把我之前那版里比较谨慎的表述合进去。

我的判断是：

**以这个“论文版”为主框架，吸收我那版的谨慎定义和边界说明。**

原因如下。

## 1. 这个“论文版”比我写的强在哪里

它最大的优点是**逻辑链更完整**。

它不是只说“做了蒙特卡洛，发现有解率多少”，而是形成了：

**MDM 方法背景 → 当前 strict offset-root 程序 → 蒙特卡洛发现两类无解 → 真无解机理 → 数学证明 → 步长与网格策略。**

这比我那版更像正式论文。比如它在摘要里直接提出：无解分为“数值漏检”和“真无解”，并且把真无解解释为 (g(\gamma)) 全域高于 offset，而数值漏检解释为根贴近 (t_{\min})、网格不够细导致离散梯度误判。

第二个优点是它的**数学证明比我那版深入**。我那版只推到：

[  
\sigma^2(\beta,\gamma)=A(\beta)-2\gamma B(\beta)+\gamma^2C(\beta)  
]

以及：

[  
g(\gamma)=\frac{\gamma C(\beta^_(\gamma))-B(\beta^_(\gamma))}{S(\gamma)}  
]

但这个“论文版”继续推了 (s_v=\operatorname{std}(x_i^{-1/\beta}))，并解释了为什么在 (\gamma_0\to0) 时，(g(\gamma)) 会趋近一个远大于 offset 的常数，从而导致全域高于 offset、无交点。这个方向是对的，而且更有“证明味道”。文中第 6 节把真无解与 (\gamma_v)、(s_v)、上升臂联系起来，是它最有价值的部分。

第三个优点是它的**实验和证明结合得更紧**。它先给 2400 个样本的蒙特卡洛设置，再用高分辨率基准区分“数值漏检”和“真无解”，然后用典型样本图解释两类机制。文中实验条件包括 (\beta)、(\gamma_0/\eta)、样本量、步长、高分辨率基准等，比较完整。

## 2. 我那版比它好在哪里

我那版的优点是**更稳、更不容易过度下结论**。

比如我一直强调：当前研究对象不是“原论文 MDM 方法本身是否无解”，而是：

[  
\text{当前程序实现的 strict offset-root 判据是否有解}  
]

这个区别很重要。因为原论文是“搜索—判断”的方法，并没有把它严格表述成连续方程求根；而且原论文的 (\gamma) 搜索也不是明确限制在 (0\le \gamma<t_{\min})。现在这个“论文版”虽然写了“当前主线程序”，但标题和摘要还是容易让人觉得是在研究“MDM 方法本身的有解性”。这点我那版更谨慎。

另外，“论文版”有些表述太满，比如摘要里写“无解即意味着估计失败”，这个不太严谨。对于 strict 程序，它可以说是“strict offset-root 判据失败”或“当前程序未返回 root 解”，但不能直接说“估计失败”。因为无 root 时仍可能用 constrained MDM、min-sigma 或边界规则得到参数估计。当前程序说明里也提到，无交点样本不一定是数值异常样本，很多仍可通过边界规则或最小 sigma 规则得到合法参数估计。

所以，我那版更适合作为“技术报告安全稿”；这个“论文版”更适合作为“论文主稿”。

## 3. 这个“论文版”必须改的地方

### 第一，不能说“(\sigma(\beta_0|\gamma)) 是抛物线”

这里有数学表述问题。

文中多处写：

> (\sigma(\beta_0|\gamma)) 是 (\gamma) 的抛物线。

严格来说，应该是：

[  
\sigma^2(\beta|\gamma)  
]

关于 (\gamma) 是二次函数，而：

[  
\sigma(\beta|\gamma)  
]

是二次函数开方后的曲线，不是严格意义上的抛物线。

应该改成：

> 固定 (\beta) 时，(\sigma^2(\beta|\gamma)) 关于 (\gamma) 是二次函数，因此 (\sigma(\beta|\gamma)) 呈现由二次型开方得到的 U 形曲线。在 (\sigma_{\min}\to0) 的极限情况下，该曲线趋近于以顶点为中心的 V 形。

这样最严谨。

### 第二，“顶点位于 (\gamma_0)”要改成“大样本或理想样本下趋近于 (\gamma_0)”

“论文版”摘要里写“当真实位移 (\gamma_0) 趋于 0 时，(\sigma(\beta_0|\gamma)) 是 (\gamma) 的抛物线、顶点位于 (\gamma_0)”。这个在有限样本下不严格。

它自己后面其实已经推出来了：

[  
\gamma_v=\gamma_0+\eta\frac{\operatorname{Cov}(\rho,v)}{s_v^2}  
]

这说明有限样本下顶点不是必然等于 (\gamma_0)，而是在 (\gamma_0) 附近随机扰动。只有当 Bernard 点逼近真实分位点、(\rho_i\to1) 时，顶点才趋向 (\gamma_0)。

所以摘要和结论里应改成：

> 在理想样本或大样本极限下，(\sigma(\beta_0|\gamma)) 的顶点趋近于 (\gamma_0)；有限样本下，顶点为 (\gamma_v=\gamma_0+\eta\operatorname{Cov}(\rho,v)/s_v^2)，会围绕 (\gamma_0) 随机扰动。

### 第三，“真无解的完整证明”要降一点语气

它现在写得像已经证明了“所有真无解必然如此”。但严格说，目前证明主要是基于：

1. 固定真形状 (\beta_0) 下的 (\sigma^2(\beta_0|\gamma))；
    
2. 大样本或理想样本下 (\rho_i\to1)；
    
3. profile 曲线 (S(\gamma)=\min_\beta\sigma(\beta|\gamma)) 的行为与固定 (\beta_0) 曲线一致或近似一致。
    

但 (S(\gamma)) 是对 (\beta) 优化后的曲线，(\beta^*(\gamma)) 不一定等于 (\beta_0)。所以这个证明更准确地说是：

> 给出了真无解现象的解析机制和充分解释，而不是完全严格的充要定理。

尤其是“充要图景”“完整数学证明”这类词，建议改成“机理证明”“解析解释”“在本文实验范围内得到验证的理论解释”。

### 第四，要补上“原论文方法”和“当前程序实现”的差别

这个“论文版”和我之前写的都有这个问题：没有充分强调原论文和当前程序实现的差别。

原论文使用的是 F 分布中位数形式的中位秩，而当前程序用 Bernard 近似；原论文描述的是从 (t_{(1)}) 开始逐步递减搜索 (\gamma_j)，而当前程序限定 (0\le\gamma<t_{\min})。所以这个“论文版”最好在第 2 节加一句：

> 需要说明的是，原论文采用基于 F 分布中位数的中位秩估计，并描述为从 (t_{(1)}) 开始逐步递减搜索位置参数；本文研究的是当前程序实现版本，即采用 Bernard 中位秩近似，并将 strict offset-root 搜索域限定为 (0\le\gamma<0.999999t_{\min})。因此，本文所谓“真无解”均指当前程序约束域内的 strict offset-root 无内点解，而不是原论文 MDM 思想在所有可能 (\gamma) 搜索域内无解。

这句非常关键。

我那版没有把结论说得那么满，也更强调“当前程序实现”和“原方法”的边界。

**最优方案：用这个“论文版”作为主稿，但按我上面说的四点修改。**
