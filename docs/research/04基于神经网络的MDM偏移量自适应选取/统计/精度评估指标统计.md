## 一、精度评估的使用场景分类

通过分析笔记内容，精度评估指标的使用动机可归纳为以下6个场景：

### 场景1：比较不同估计方法的优劣

**典型情况**：提出新方法后，与已有方法（MLE、LSE、贝叶斯等）进行蒙特卡洛模拟对比，用 MSE/Bias/RMSE 判定谁更优。

| 编号 | 标题 | 比较什么 | 用的指标 |
|------|------|---------|---------|
| 182-002 | 截尾数据可靠性评估 | CMLE/HEM vs MLE/LSE | MSE, MAE, MAPE |
| 182-018 | 威布尔删失数据推断 | CPLSE vs LSE/PLSE vs MLE | Bias, MSE |
| 182-019 | 竞争失效模型 | 贝叶斯 vs MLE vs Bootstrap | MSE, Bias, 覆盖率 |
| 182-021 | 混合威布尔L-M算法 | L-M vs Kececioglu vs 图估计法 | NRMSE |
| 182-024 | WMLE偏差修正 | 修正前 vs 修正后 WMLE | Bias, RMSE |
| 182-025 | 形状参数估计方法比较 | CCM vs LSM vs MDM | Bias, RMSE |
| 182-027 | 贝叶斯vs MLE比较 | MLE vs Jeffrey先验 vs 扩展先验 | MSE, Bias, 覆盖率 |
| 182-047 | 最小二乘迭代法 | 迭代法 vs 相关系数法 | Bias, RMSE |
| 182-050 | 小样本初始失效概率 | greg2'/rank/w-MLE 按形状参数分段 | Bias, RMSE |
| 182-054 | 最小差异准则 | MD vs MLE vs LSE | 偏差, 标准差, 方差 |
| 182-064 | 加速寿命试验MLE | MV-MLE vs 传统MLE | 相对误差 |
| 182-088 | 近似无偏估计 | 加权MLE vs 迭代MLE vs 两步MLE | 偏差, 标准差 |
| 182-100 | Weibull声明式模型 | 贝叶斯 vs MLE（不同损失函数） | MSE, Bias |

**常用指标**：MSE、Bias、RMSE、标准差

### 场景2：验证新提出方法的有效性

**典型情况**：提出新估计量/新算法后，通过模拟验证其统计性质（无偏性、一致性、充分性），证明方法理论上有保证。

| 编号 | 标题 | 验证什么性质 | 用的指标 |
|------|------|-------------|---------|
| 182-001 | 零失效数据威布尔估计 | 无偏估计量的有效性 | MdAD, Bias, 中心概率C_Pr |
| 182-003 | 异常值三参数威布尔 | PITE方法的稳健性 | RMSE, Def(综合缺陷指标) |
| 182-009 | 遗传算法MLE优化 | 算法收敛性和估计精度 | MSE, Bias, 方差 |
| 182-029 | MLE偏差研究 | MLE在不同样本量下的偏差规律 | MSE, Bias, 渐近方差 |
| 182-039 | 小样本参数估计 | 方法在小样本下的表现 | 偏差, 覆盖率, 标准差, 方差 |
| 182-058 | PSO联合估计 | PSO算法的估计精度 | 相对误差 |
| 182-059 | 人工蜂鸟算法 | 算法的估计稳定性 | 标准差 |
| 182-069 | 粒子群优化估计 | PSO方法的有效性 | 方差 |

**常用指标**：Bias、MSE/RMSE、方差、标准差、相对误差

| 182-005 | BB算法可靠性分析 | 置信区间 | 置信区间 |
| 182-006 | Gibbs抽样贝叶斯估计 | MCMC后验区间 | 置信区间 |
| 182-019 | 竞争失效模型 | HPD + Bootstrap + 渐近 | 覆盖率, HPD区间长度 |
| 182-023 | 异常值贝叶斯估计 | HPD区间 | HPD区间, 渐近方差 |
| 182-027 | 贝叶斯vs MLE | 置信区间 + HPD区间 | 覆盖率, 区间长度 |
| 182-030 | 最小差异法 | 置信区间 | 置信区间 |
| 182-039 | 小样本参数估计 | 置信区间 | 覆盖率 |
| 182-067 | 参数估计方法 | 区间估计 | 覆盖率 |
| 182-092 | 最小二乘全局准则 | 置信区间 | 置信区间 |

**常用指标**：覆盖率（Coverage Probability）、区间长度、置信区间、HPD区间
