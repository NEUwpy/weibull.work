# 第三大块：03 最优偏移量 δ 的选取

> 全部实验完成。三段结构：层级扫描 → 影响因素 → 部署验证 → 04桥接。

## 03-1：δ 扫描与层级探索 ✅

**问题：** 最优偏移量在什么层级上存在？与 β、n、γ/η 的关系如何？

**实验：** β∈{2,2.5,4}×n∈{7,10,20}×γ/η∈{0.1,0.5,1.0}，27配置。δ∈[0,0.5]步长0.02，500rep/配置，351K次MDM拟合。

**层级最优（J_param 口径）：**
- L0 全局：δ*=0.10, J=0.582
- L1 按 n：δ*=0.10~0.12
- L2 按 β：δ*=0.04(β=4.0)~0.20(β=2.0)
- L3 按(β,n)：δ*=0.04~0.28
- L4 按(β,n,γ/η)：δ*=0.00~0.30
- L5 逐样本 Oracle：J=0.370（比L0改善33-41%）

**逐样本误差分布：** δ=0.10的P95/P99最低，最优性来自尾部控制。

## 03-2：影响因素分析 ✅

**问题：** 最优 δ* 主要受什么量驱动？这是 04 特征选择的依据。

**结论（直接从 raw δ 实验得出，不引入额外概念）：**

| 因素 | 影响强度 | 证据 |
|---|---|---|
| β | **主要驱动** | L2按β: δ*从0.04到0.20，差5倍 |
| n | 次要 | L1按n: δ*从0.10到0.12，变化小 |
| γ/η | 弱 | L3→L4: 同一(β,n)下不同γ/η的δ*变化<0.06 |
| 逐样本 | 显著 | L5 Oracle J=0.370 vs L4 J=0.547，差距0.177 |

β 与 n 存在交互：β=2.0时n越大δ*越大，β=4.0时n越大δ*也略增但幅度更小。

## 03-3：可部署方案验证 ✅

**问题：** 部署时 β/γ/η 真值不可得，能用什么方案选 δ？

**方案1 自迭代：** 平均 -0.71%，β=4.0 全部恶化。根源：δ=0.1 处 β̂ 系统性偏低，经 δ*(β̂) 插值一律建议更大 δ，对 β=4.0 恰好反向。

**方案2 外部 β 预估：** 测试了 L 矩、WMLE（独立估计），以及 MDM δ=0、双 δ 平均（同框架不同 δ 读出）四种方法 + Oracle 对照。全部四种均劣于 Default δ=0.1。Oracle 证实真 β 可改善 4.4%，但小样本下无方法能可靠估计 β。

**方案阶梯：**

| 方案 | J_param | 说明 |
|---|---|---|
| L5 Oracle | 0.370 | 不可部署 |
| L4 查表 | 0.547 | 需全部真值 |
| L3 Oracle（真 β） | 0.556 | 需 β 真值 |
| L1 按 n | 0.581 | n 已知 |
| **Default δ=0.1** | **0.582** | **最佳可部署** |
| 自迭代 | 0.589 | 恶化 |
| WMLE+查表 | 0.626 | +7.5% |
| MDM δ=0+查表 | 0.638 | +9.6% |
| 双δ平均+查表 | 0.639 | +9.8% |
| L矩+查表 | 0.648 | +11.4%, 15.6%有效 |

## 03→04 桥接

方案1+2 覆盖了直觉上所有合理路线（自迭代、两种独立β估计+两种同框架δ读出）→ 全部失败。部署天花板 0.582 vs Oracle 0.370（57%差距）只能通过跳过β估计、直接从样本特征端到端预测δ来弥合。04 的任务：从可观测样本特征（次序统计量形态、间距比、变异系数等）预测逐样本最优 δ*。

# 第四大块：04 基于神经网络的MDM偏移量自适应选取

> 核心问题：能不能用神经网络逐样本预测最优偏移量？用什么损失函数训练？

## 第1页：从03到04——为什么需要神经网络

**目的：** 论证逐样本自适应的必要性。

**材料：** 来自03的结论——
- 部署天花板：Default δ=0.1 (J=0.582)，任何不用真值的方案都无法突破
- 逐样本空间：Oracle J=0.370 vs Default 0.582，差距57%
- 影响因素中 β 是最强的可学习信号，但真值不可得 → 需从样本特征间接捕捉

## 第2页：特征设计与数据生成方案

**特征候选（基于03-2的影响因素结论）：**
- 次序统计量形态：间距比、变异系数、偏度（间接反映β）
- 样本极端值特征：t₁/tₙ、对数间距（间接反映γ/η）
- n（已知，弱信号但可用）
- 多偏移读出：在同一样本上以多个δ求解MDM，读取β̂(δ)的变化曲线——这比单点β̂₀更稳健

**训练目标：** 逐样本最优 δ*（L5 Oracle标签）

## 第3页：训练目标与损失函数设计

- 输出：回归 δ*（MSE）
- 对比损失：ℓ_param（参数复合）vs ℓ_eng（工程指标）
- 候选：分位数回归、分类（离散化δ）作为替代方案
