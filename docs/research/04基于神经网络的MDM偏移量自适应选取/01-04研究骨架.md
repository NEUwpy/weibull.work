# 第一大块：01 用什么指标评价参数估计的准确性

## 第1页：文献里实际用什么指标？

**目的：** 不自创指标，先搞清楚文献主流用什么评价参数估计精度。

**过程：** 对 182 文件夹 68 篇文献逐篇统计精度指标使用频次。

**结果：** Bias（75%）、SD/方差（56%）、MSE/RMSE（40%）构成精度指标主干；相对误差（16%）偏低，MAE（3%）几乎不用。置信区间/敏感性/拟合优度属统计性质范畴，不纳入精度指标。结论：Bias+SD 为绝对主干，MSE/RMSE 为常见补充。

**待做实验：**
- `E01-1` ✅ 已完成：68篇文献笔记扫描，结果见01-04研究内容.md第1页

## 第2页：常见指标的定义与各自能反映什么

**目的：** 梳理常用精度指标的知识体系，明确每个指标"看的是误差的哪个维度"，为后续选择提供依据。

**过程：** 系统列出 Bias、SD、RMSE、MAE、相对误差、置信区间、拟合优度、中位数/分位数等指标的定义，分析其各自反映的信息（中心趋势、离散程度、尾部风险、无量纲化等），讨论它们的互补与冗余关系。

**结果：** Bias 看系统偏移，SD 看离散程度，MSE/RMSE 是两者的综合（MSE=Bias²+SD²），相对误差提供无量纲化视角（但 γ=0 失效），MAE 对尾部不敏感但文献几乎不用。Bias+SD 是最小充分集，MSE/RMSE 为便捷补充。

**待做实验：** 无新实验，纯知识梳理

## 第3页：为什么没有一个统一有效指标？

**目的：** 解释为什么第2页列出了许多指标，而不是直接给出一个"万能指标"。核心原因有两层：不同研究目标关心的估计效果不同；即使目标相同，单个汇总指标也可能被误差分布形态蒙蔽。

**过程：** 先从研究目标出发区分系统偏差、估计稳定性、尾部风险、跨量纲比较和工程寿命预测；再构造五个情景（含真实仿真反例），逐个说明单个指标在特定目标或分布形态下会如何失真。

**结果：**
① RMSE 相同可掩盖完全不同的偏差-方差结构 → 必须成套报告 ✅ E01-3a
② 中位/平均类指标对尾部钝感（P99.9 差 38%，最大误差差 83%）— 待E01-6
③ γ 真值接近 0 时相对指标失真 — 待E01-6
④ 参数指标排序 ≠ 寿命指标排序 — 待E01-6
⑤ 不同量纲参数的 MSE 不可横比 — 待E01-6

**待做实验：**
- `E01-3a` ✅ RMSE陷阱演示
- `E01-3b` ✅ 尾部钝感（P99.9/Median=5.4x）
- `E01-3c` ✅ γ接近0时相对指标失真（RelRMSE≈8800%）
- `E01-3d` ✅ 两视角排序差异实证
- `E01-3e` ✅ 跨量纲MSE不可横比

## 第4页：参数视角推荐方案 + 综合精度指标 J_param

**目的：** 回答"既然指标很多，参数估计到底用哪个评价"。在蒙特卡洛场景下，估计误差形成逐次分布；为了同时表示估计精度和稳定性，Bias 和 SD 是参数视角的最小充分集。若为了 δ 方案排序、神经网络训练等目的必须压缩成一个目标函数，则定义三参数联合指标 J_param。

**过程：** 综合文献调研（第1页）、指标知识（第2页）和单指标失效分析（第3页），先确定 Bias+SD 作为参数诊断主口径；再定义 J_param = √( mean( ((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)² ) )，说明其几何含义是三维标准化参数误差空间中的平均欧氏距离，并解释其可同时反映整体精度与稳定性。

**结果：**
- **多指标方案（诊断用）：** 每个参数成套报告 Bias、SD、RMSE。β/η 补充相对偏差和相对 RMSE（%）。γ 只用绝对指标（禁用一切相对指标）。附报 γ̂=0 截断率。至少一张误差分布图（γ 的双峰形态必须看图）。
- **单指标 J_param（排序/训练用）：** 三参数联合相对 RMSE，全部无量纲化，吸收 Bias+SD 体系，可跨参数比较。03-04若需要一个参数视角目标函数，用 J_param；多指标仍保留用于诊断。
- 两个视角不冲突：多指标聚焦单个参数的诊断，J_param 聚焦整体效果的排序。

**待做实验：** 无新实验，综合前3页结论给出参数视角推荐表+J_param定义 ✅ 已完成

## 第5页：工程视角的必要性 + 目标分位点 RMSE

**目的：** 说明为什么参数视角不够，必须补充工程视角：可靠性工程真正关心的不是参数本身，而是指定可靠度下的寿命分位点预测是否准确。

**过程：** 给出寿命分位点公式 x_R = γ + η(-lnR)^{1/β}，说明参数估计准不等于寿命预测准（非线性传递+参数补偿结构）。工程视角按实际任务选择目标分位点：若关心 x₀.₉₅，就报告 x̂₀.₉₅ 的 Bias/SD/RMSE；若关心 x₀.₉₉，就报告 x̂₀.₉₉ 的 Bias/SD/RMSE，不把不同可靠度强行合成。

**结果：**
- **工程诊断指标：** 对目标分位点 x_R 报告 Bias_xR、SD_xR、RMSE_xR。
- **工程排序指标：** 如果只能用一个工程指标，就用目标分位点的 RMSE：RMSE_xR = √(mean((x̂_R − x_R)²))。
- 工程指标采用绝对误差形式，因为寿命偏差的时间量级本身就是工程风险；不同 R 的指标按需求分别报告，不默认合并。

**待做实验：**
- `E01-5` 工程视角必要性论证：用 E01-6 的蒙特卡洛结果，展示参数精度高但寿命精度低的反例 — 待E01-6

## 第6页：两视角不等价的实证 + 三方法蒙特卡洛比较

**目的：** 用蒙特卡洛数据证明参数视角排序 ≠ 工程视角排序，并在两个视角下分别给出三方法的定量对比。

**过程：** β=2.5, η=1000, γ=100；n∈{5,7,10,15,20,50}；每组 2000 次重复；同批样本上 MDM/MLE/LSE 三种方法各自估计。LSE 为研究用本地对照实现。指标口径调用 metrics.py::aggregate_standard_metrics()。

**结果：** 参数视角按 β 的 RMSE：MDM 全样本量最优（n=20: 0.609 < 0.676 < 0.774）。工程视角按 x₀.₉₅ RMSE：LSE ≈ MDM（n=20: 97.8 ≈ 97.7）。**MLE 小样本灾难性失效**：n=5 失败率 54.4%。γ 是最难估的参数。γ̂=0 截断率 MDM 约 20%，LSE 无截断但有近零尖峰（~40%）。n≥50 三法趋同。

**待做实验：**
- `E01-6` ✅ 已完成：β=2.5, η=1000, γ=100；n∈{5,7,10,15,20,50}；2000次/组；MDM/MLE/LSE 配对估计；LSE 为研究用本地对照实现；结果见01-04研究内容.md第6页

## 第7页：第一大块指标选择总结

**目的：** 汇总第一大块，明确后续研究中两个评价视角各用什么指标，避免把参数估计目标和工程寿命目标混在一起。

**过程：** 回顾第1-6页的文献统计、指标知识、单指标失效分析、参数视角指标、工程视角指标和三方法蒙特卡洛对比。

**结果：**
- **参数视角：** 常规报告 Bias+SD+RMSE；需要一个排序/训练目标时用 J_param。
- **工程视角：** 先选目标可靠度 R，再报告 x_R 的 Bias/SD/RMSE；需要一个工程排序指标时用 RMSE_xR。
- **两者的取舍取决于研究目标：** 研究参数估计能力时看参数视角；面向寿命预测或工程决策时看目标分位点视角。04中必须明确神经网络优化目标属于哪一视角。

**待做实验：** 无新实验，纯总结页

# 第二大块：02 MDM 方法的有解性证明

## 第1页：无解现象与理论存在性

**目的：** 复刻 MDM 方法，发现"无解"现象；从理论上证明合法根几乎总是存在，从而推断"无解"必有具体原因。

**过程：** 按原文实现 MDM（偏置求根判据 δ=0.1），在多个配置上做蒙特卡洛检验，发现无解现象。然后推导 σ²_η(γ) 的解析形式：σ²_η = C_uu − 2γC_uv + γ²C_vv（开口向上二次函数），包络梯度 g(γ) = (γC_vv − C_uv)/S(γ) 单调上升。存在性判据：s_v > offset 且无约束根 ∈ [0, t₍₁₎) ⟹ 合法根存在且唯一。常用区间 s_v 远大于 0.1，存在性几乎不受限制。

**结果：** 理论预测合法根几乎总存在 → 实际观察到的"无解"必定另有原因 → 只能是：①根落在 γ<0 被截断（非法根）②根贴近 t₍₁₎ 被网格漏检（数值问题）。

**待做实验：** 无。纯论述页。

## 第2页：无解的两类成因

**目的：** 搞清楚"无解"到底是怎么来的，用两张图直观展示两类成因。

**过程：** 对无解样本逐个追因，检查无约束根的位置和网格分辨率。构造两个典型示例并画图。

**结果：** 无解来自两类成因：
- **成因① 下界切除（主因）：** 无约束根落在 γ<0 处，被物理约束 γ≥0 切掉。差异函数本身有良好定义的偏置根，只是不合法。γ₀/η 越大有解率越高——真值离 0 越远，根越不容易落入负区。
- **成因② 网格漏检（次因）：** 根紧贴 t₍₁₎，均匀网格看不到。n 越大时 t₍₁₎ 越贴近 0，漏检更严重。

**待做实验：**
- `E02-1` 负根示例图：构造一个典型的成因①样本，画差异函数曲线，标注无约束根（γ<0）和 γ=0 截断线，直观展示"根为负被切掉"
- `E02-2` 漏检示例图：构造一个典型的成因②样本，用 20 个搜索点画差异函数离散采样，标注根非常靠近 t₁ 导致漏检的情况

## 第3页：工程方案——截断+拟合

**目的：** 给出处理两类无解成因的工程方案。

**过程：** 针对两类成因分别处理：成因①直接截断到 γ̂=0（物理约束，最稳）；成因②不依赖密集网格，改用拟合（解析梯度）直接推算根的位置。

**结果：**（待填充）

**待做实验：** 无独立实验。成因①截断策略在 E01-6 中已验证（MDM γ̂=0 截断率 ~20%，误差可控）。成因②拟合方案在后续 03/04 的求解流程中自然体现。

## 第4页：始终有解方案的精度验证

**目的：** 证明截断+拟合方案不仅提升了可用性（failure_rate → 0%），而且没有以不可接受的精度代价换来的。这是第二大块从"能算"到"能算且可信"的关键一步。

**过程：** 同一批样本、同一 δ=0.1，对比两组策略：
- **对照组：** 标准网格搜索（20点），无解直接标记失败，指标只算 valid 样本
- **实验组：** 截断（γ<0→γ̂=0）+ 拟合（近右端根用解析梯度推算），100% 给出估计

报告指标：
- valid_rate / failure_rate
- J_param
- RMSE_β / RMSE_η / RMSE_γ

三层次对比：
1. 可用性提升：failure_rate 从 X% → 0%
2. valid-only 子集精度：同一组 valid 样本上两组的 J_param 对比
3. 全样本精度：实验组 vs 对照组 valid-only，看"补回来的那些样本"质量如何

**结果：**（待填充——目标：始终有解方案显著提升可用性，且主精度指标未出现不可接受退化）

## 第4页：真值未知时的可部署 δ 选择方案

**研究目标：** 检验两个方向上不依赖真值的 δ 选择能否可靠部署：方向1（MDM 自迭代）、方向2（外部 β 预估）。以"能否部署"为核心判据——方法不仅要在 valid-only 子集上好看，还要在全样本、失败样本 fallback、不同配置分组上都可解释。

**过程：** 分两个方向实施：
- **方向1（MDM 自迭代）：** δ=0.1 → MDM 估 β̂ → 查 δ*(β̂,n) → 迭代至收敛
- **方向2（外部 β 预估）：** L 矩/WMLE/双δ/MDM0 等方法估 β̂ → 查 δ*(β̂,n) → MDM 拟合

所有方法必须报告全样本性能、有效率、失败样本处理、fallback 后性能、按配置分组的改善/恶化热力图。valid-only 结果只能作为诊断，不能作为部署性能结论。

**预期结果：** 旧实验提示两条路线均可能无法在全参数空间稳定超越 Default δ=0.1，最终以新口径重算结果为准。若新实验确认显式 β 估计路线仍不稳健，则第三大块自然导向第四大块：神经网络不应直接使用真值，而应从可观测样本特征端到端学习 δ 策略。

- 第4页统计：每个策略报告全样本 `J_param`、valid-only `J_param`、有效率、fallback 后 `J_param`、相对 Default 改善率。

## 第5页：第三大块到第四大块的实验交接

**研究目标：** 把第三大块的新结果转化为第四大块神经网络实验的输入输出合同，而不是直接把 oracle 当成可部署方案。

**过程：** 根据第2~4页结果确定第四大块的监督信号候选。训练标签以 L3/L4/风险曲线（soft label）为候选，**最终由新版 J_param 阶梯、边际收益和标签噪声共同决定，不提前锁死单一层级**。同步确定模型输入只能来自部署时可观测信息：样本顺序统计量、间距/比值/偏度等统计特征、n、多 δ MDM 读出曲线、求解状态特征等。

# 第四大块：04 基于神经网络的MDM偏移量自适应选取

> 核心问题：训练时可以用真值生成 oracle 标签，但使用时只有样本。神经网络要证明的是：仅凭可观测样本特征，能逼近哪个信息层级的 oracle 最优 δ，并能否降低 `J_param` / regret。

## 第1页：从03到04——为什么需要神经网络

**目的：** 区分“标签生成时知道什么”和“模型使用时知道什么”，论证端到端样本特征学习的必要性。

**材料：** 来自03的结论——
- L0/L1 是可部署固定策略，但改善有限。
- L2/L3/L4 说明最优 δ 受真 β、n、γ/η 条件影响，但这些真值部署时不可得。
- L5 说明即使同一真值配置下，不同随机样本仍可能有不同事后最优 δ。
- 因此 04 要检验：样本可观测特征是否能吸收这些真值/逐样本信息。

## 第2页：特征设计与数据生成方案

**特征候选（基于03-2的影响因素结论）：**
- 次序统计量形态：间距比、变异系数、偏度（间接反映β）
- 样本极端值特征：t₁/tₙ、对数间距（间接反映γ/η）
- n（已知，弱信号但可用）
- 多偏移读出：在同一样本上以多个δ求解MDM，读取β̂(δ)的变化曲线——这比单点β̂₀更稳健

**训练标签候选：**
- L2/L3/L4 标签：平滑、可解释，用于检验模型能否从样本中隐式恢复真值条件。
- L5 标签：上界最高，但硬 argmin 噪声最大。
- 风险曲线标签：直接学习 `loss_i(δ)` 或 soft label，优先考虑，避免把近似并列的 δ 硬分成对错。

## 第3页：训练目标与损失函数设计

- 输出方案1：回归 δ*。
- 输出方案2：分类到离散 δ 网格。
- 输出方案3：预测每个 δ 的风险曲线，再选择预测风险最低的 δ。
- 评价统一用 `J_param`、配置 regret、P95/CVaR95，并保留 Bias/SD/RMSE 分项诊断。
