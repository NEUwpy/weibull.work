# 第一大块：01 用什么指标评价参数估计的准确性

## 第1页：文献里实际用什么指标？

**目的：** 不自创指标，先搞清楚文献主流用什么评价参数估计精度。

**过程：** 对 182 文件夹 68 篇文献逐篇统计精度指标使用频次。

**结果：** Bias（75%）、SD/方差（56%）、MSE/RMSE（40%）构成精度指标主干；相对误差（16%）偏低，MAE（3%）几乎不用。置信区间/敏感性/拟合优度属统计性质范畴，不纳入精度指标。结论：Bias+SD 为绝对主干，MSE/RMSE 为常见补充。

**待做实验：**
- `E01-1` ✅ 已完成：68篇文献笔记扫描，结果见01-04研究内容.md第1页

## 第2页：常见指标的定义与各自能反映什么

**目的：** 梳理常用精度指标的知识体系，明确每个指标"看的是误差的哪个维度"，为后续选择提供依据。

**过程：** 系统列出 Bias、SD、RMSE、MAE、相对误差、置信区间、拟合优度、中位数/分位数等指标的定义，分析其各自反映的信息（中心趋势、离散程度、尾部风险、无量纲化等），讨论它们的互补与冗余关系。

**结果：** Bias 看系统偏移，SD 看离散程度，MSE/RMSE 是两者的综合（MSE=Bias²+SD²），相对误差提供无量纲化视角（但 γ=0 失效），MAE 对尾部不敏感但文献几乎不用。Bias+SD 是最小充分集，MSE/RMSE 为便捷补充。

**待做实验：** 无新实验，纯知识梳理

## 第4页：参数视角推荐方案 + 综合精度指标 J_param

**目的：** 给出参数层面（β̂、η̂、γ̂）的指标推荐组合，并定义可跨参数比较的单一综合指标 J_param，用于后续03-04中不同δ方案的排序。

**过程：** 综合文献调研（第1页）、指标知识（第2页）、陷阱分析（第3页），按"信息互补、缺陷已知可控"原则选取参数视角的指标组合。同时定义 J_param = √( mean( ((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)² ) )，论证其几何含义（三维参数空间的平均欧氏距离）、与已有指标的关系、以及每个设计选择（各自除以真值、平方、均值、开根号）的理由。

**结果：**
- **多指标方案（诊断用）：** 每个参数成套报告 Bias、SD、RMSE。β/η 补充相对偏差和相对 RMSE（%）。γ 只用绝对指标（禁用一切相对指标）。附报 γ̂=0 截断率。至少一张误差分布图（γ 的双峰形态必须看图）。
- **单指标 J_param（排序用）：** 三参数联合相对RMSE，全部无量纲化，吸收了Bias+SD体系、跨参数可比性。03-04统一用J_param排序，多指标保留用于诊断。
- 两个视角不冲突：多指标聚焦单个参数的诊断，J_param 聚焦整体效果的排序。

**待做实验：** 无新实验，综合前3页结论给出参数视角推荐表+J_param定义 ✅ 已完成

## 第5页：工程视角的必要性 + 综合工程指标 J_eng

**目的：** 说明为什么参数视角不够，必须补充工程视角（高可靠寿命），并定义工程视角的综合指标 J_eng。

**过程：** 论证工程关心的不是参数本身，而是高可靠寿命 x_R = γ + η(-lnR)^{1/β}。参数估计准不代表寿命预测准（非线性传递+参数补偿结构）。给出工程视角的指标选取：x₀.₉₅、x₀.₉₉ 的 Bias/SD/RMSE。同时定义 J_eng = √( mean( (x̂₀.₉₅ − x₀.₉₅)² + (x̂₀.₉₉ − x₀.₉₉)² ) )，为绝对形式，直接衡量寿命预测的离散程度。

**结果：**
- **多指标方案（诊断用）：** x̂₀.₉₅、x̂₀.₉₉ 各自报告 Bias、SD、RMSE。两套视角必须分开报告。
- **单指标 J_eng（排序用）：** 工程联合RMSE，绝对形式，可与J_param并列用于03-04方案排序。
- J_eng 采用绝对形式而非相对形式：工程寿命的量级本身有意义（如 x₀.₉₅≈400~500），绝对偏差直接反映实际风险。

**待做实验：**
- `E01-5` 工程视角必要性论证：用 E01-6 的蒙特卡洛结果，展示参数精度高但寿命精度低的反例 — 待E01-6

## 第6页：两视角不等价的实证 + 三方法蒙特卡洛比较

**目的：** 用蒙特卡洛数据证明参数视角排序 ≠ 工程视角排序，并在两个视角下分别给出三方法的定量对比。

**过程：** β=2.5, η=1000, γ=100；n∈{5,7,10,15,20,50}；每组 2000 次重复；同批样本上 MDM/MLE/LSE 三种方法各自估计。LSE 为研究用本地对照实现。指标口径调用 metrics.py::aggregate_standard_metrics()。

**结果：** 参数视角按 β 的 RMSE：MDM 全样本量最优（n=20: 0.609 < 0.676 < 0.774）。工程视角按 x₀.₉₅ RMSE：LSE ≈ MDM（n=20: 97.8 ≈ 97.7）。**MLE 小样本灾难性失效**：n=5 失败率 54.4%。γ 是最难估的参数。γ̂=0 截断率 MDM 约 20%，LSE 无截断但有近零尖峰（~40%）。n≥50 三法趋同。

## 第7页：如果只能选一个指标——极简总结

**目的：** 在多指标体系和双综合指标的基础上，给出一个最精炼的结论：如果只能用一个指标，参数视角选什么、工程视角选什么。

**过程：** 回顾第1-6页的全部分析，提炼出两个视角各自的"一指标答案"。

**结果：**
- **参数视角 → J_param：** √( mean( ((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)² ) )。理由：三参数全部相对化，跨量纲可比，同时惩罚Bias和SD，是后续03-04排序的统一尺度。
- **工程视角 → J_eng：** √( mean( (x̂₀.₉₅ − x₀.₉₅)² + (x̂₀.₉₉ − x₀.₉₉)² ) )。理由：直接衡量工程寿命预测误差，绝对形式保留实际风险量级。
- **两者的取舍取决于应用场景：** 研究分析用 J_param（可分解到单参数），工程部署用 J_eng（直接对应业务损失）。04中将实证量化"选错指标的代价"。

## 第二大块：02 MDM 方法的有解性证明

## 第1页：MDM 无解现象与理论存在性

**目的：** 复刻 MDM 方法，发现"无解"现象；从理论上证明合法根几乎总是存在，从而推断"无解"必有具体原因。

**过程：** 按原文实现 MDM（偏置求根判据 δ=0.1），在多个配置上做蒙特卡洛检验，发现无解现象。然后推导 σ²_η(γ) 的解析形式：σ²_η = C_uu − 2γC_uv + γ²C_vv（开口向上二次函数），包络梯度 g(γ) = (γC_vv − C_uv)/S(γ) 单调上升。存在性判据：s_v > offset 且无约束根 ∈ [0, t₍₁₎) ⟹ 合法根存在且唯一。常用区间 s_v 远大于 0.1，存在性几乎不受限制。

**结果：** 理论预测合法根几乎总存在 → 实际观察到的"无解"必定另有原因 → 只能是：①根落在 γ<0 被截断（非法根）②根贴近 t₍₁₎ 被网格漏检（数值问题）。

**待做实验：** 无。纯论述页。

## 第2页：无解的两类成因

**目的：** 搞清楚"无解"到底是怎么来的，用两张图直观展示两类成因。

**过程：** 对无解样本逐个追因，检查无约束根的位置和网格分辨率。构造两个典型示例并画图。

**结果：** 无解来自两类成因：
- **成因① 下界切除（主因）：** 无约束根落在 γ<0 处，被物理约束 γ≥0 切掉。差异函数本身有良好定义的偏置根，只是不合法。γ₀/η 越大有解率越高——真值离 0 越远，根越不容易落入负区。
- **成因② 网格漏检（次因）：** 根紧贴 t₍₁₎，均匀网格看不到。n 越大时 t₍₁₎ 越贴近 0，漏检更严重。

**待做实验：**
- `E02-1` 负根示例图：构造一个典型的成因①样本，画差异函数曲线，标注无约束根（γ<0）和 γ=0 截断线，直观展示"根为负被切掉"
- `E02-2` 漏检示例图：构造一个典型的成因②样本，用 20 个搜索点画差异函数离散采样，标注根非常靠近 t₁ 导致漏检的情况

## 第3页：工程方案——截断 + 拟合

**目的：** 给出处理两类无解成因的工程方案。

**过程：** 针对两类成因分别处理：成因①直接截断到 γ̂=0（物理约束，最稳）；成因②不依赖密集网格，改用拟合（解析梯度）直接推算根的位置。

**结果：**（待填充）

**待做实验：** 无独立实验。成因①截断策略在 E01-6 中已验证（MDM γ̂=0 截断率 ~20%，误差可控）。成因②拟合方案在后续 03/04 的求解流程中自然体现。

## 第2页：真值未知时的可部署 δ 选择方案

**目的：** 第1页的L0-L5分析假设真值已知，但实际部署时只有样本、没有β/γ/η真值。本页设计三种可部署的δ选择方案，桥接"研究最优"到"工程可用"。

**过程：** 根据第1页的层级结论（假设发现δ*主要与(n,β)相关），设计三种方案：

**方案1：MDM自迭代方案**
- 流程：默认δ=0.1 → MDM估计β̂ → 查δ*(n, β̂) → MDM再估计 → 直到收敛
- 优点：只依赖MDM自身，无需外部方法
- 风险：小样本下固定点可能不稳，需要停止条件和发散保护
- 关键：需验证收敛性（是否收敛、收敛速度、发散率）

**方案2：外部β预估方案**
- 流程：用多种参数估计方法（MLE/LSE/矩估计等）先估β̂ → 查δ*(n, β̂) → 用最优δ做MDM估计
- 优点：β̂精度更高时δ*也更准
- 注意：不同外部方法在小样本下表现不同，需系统对比
- 实验设计：用多种外部方法做对比，不绑定特定方法

**方案3：样本特征→δ直接映射**
- 流程：不显式估真值参数，直接从样本形态特征预测最优δ
- 优点：跳过中间估计步骤，端到端
- 这是通向第四大块（神经网络）的桥

**结果：**（已填充——实验完成）

自迭代方案平均改善 -0.71%（仅 40.7% 配置改善），β=4.0 全部恶化。外部 β 方案：MLE+查表 J=0.597（劣于 Default 0.582，且小样本失效），LSE+查表 J=0.651（最差）。**默认 δ=0.1 就是最佳可部署方案。**

方案阶梯：L5 Oracle(0.370) < L4(0.547) < L3(0.556) < L1(0.581) < **Default(0.582)** < 自迭代(0.589) < MLE+查表(0.597) < LSE+查表(0.651)。Oracle 与最佳可部署差距 57%，为 04 神经网络提供了清晰的立项依据。

**待做实验：**
- `E03-4a` ✅ 自迭代验证：平均改善 -0.71%，不可行

# 第四大块：04 基于神经网络的MDM偏移量自适应选取

> 核心问题：能不能用神经网络逐样本预测最优偏移量？用什么损失函数训练？工程指标 vs 参数指标作为目标差多少？

## 第1页：从03到04——为什么需要神经网络

**目的：** 论证从固定δ/全局常数c到逐样本自适应δ的必要性，建立04的立项依据。

**过程：** 回顾03方案阶梯，分析可部署天花板（~0.90）与逐样本oracle（0.303）之间的缺口；引用树探针0.707越过查表线0.777的实证（证明样本形态中有超出β/n的可提取信号）；引用可学习性判据ρ̂=0.32（95% CI [0.27, 0.39]，超过0.20立项阈值）。

**结果：**
