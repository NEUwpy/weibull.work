# 第三大块：03 最优偏移量 δ 的选取

> 全部实验完成。三段结构：层级扫描 → 影响因素 → 部署验证 → 04桥接。

## 03-1：δ 扫描与层级探索 ✅

**实验：** β∈{1.5,2.0,2.5,4.0,5.0}×n∈{7,10,20}×γ/η∈{0.1,0.5,1.0}，45配置，585K次拟合。

**层级最优（J_param 口径）：**
- L0 全局：δ*=0.10, J=0.614
- L1 按 n：δ*=0.10~0.12, J=0.457~0.730
- L2 按 β：δ*=0.04(β=5)→0.40(β=1.5)，差10倍
- L5 逐样本 Oracle：J=0.387

**逐样本误差分布：** δ=0.06~0.08 均值谷底，δ=0.10 接近且尾部最优。

## 03-2：影响因素分析 ✅

| 因素 | 影响强度 | δ* 变化范围 |
|---|---|---|
| β | ★★★ 主驱动 | 0.04→0.40 (10×) |
| n | ★★ 次要 | 0.10→0.12 |
| γ/η | ★ 弱 | <0.06 |
| 逐样本 | ★★★ 显著 | L5 J=0.387 vs L4 J=0.553 |

## 03-3：可部署方案验证 ✅

**方案1 自迭代：** 平均 -0.1%，β=1.5 大幅改善（~20%），β≥4 全部恶化。总体不可靠。

**方案2 外部 β：** L矩首次优于 Default（-3.8%），但仅 21% 有效。WMLE/Dual/MDM0 全部恶化（+10~19%）。

**方案阶梯（45配置）：**

| 方案 | J_param | vs Default(0.616) |
|---|---|---|
| L5 Oracle | 0.387 | -37.2% |
| L4 查表 | 0.553 | -10.2% |
| L3 Oracle | 0.584 | -5.3% |
| L矩 + 查表 | 0.593 | -3.8% (21%有效) |
| L1 按 n | 0.607 | -1.6% |
| **Default δ=0.1** | **0.616** | **基准** |
| 自迭代/WMLE/Dual/MDM0 | 0.62~0.74 | +0~19% |

## 03→04 桥接

β 是 δ* 主驱动（10×）但真值不可得。所有显式 β 估计失败。L5 Oracle -37% 空间只能通过端到端样本特征学习弥合。04 任务：从可观测样本特征预测逐样本 δ*。

# 第四大块：04 基于神经网络的MDM偏移量自适应选取

> 核心问题：能不能用神经网络逐样本预测最优偏移量？用什么损失函数训练？

## 第1页：从03到04——为什么需要神经网络

**目的：** 论证逐样本自适应的必要性。

**材料：** 来自03的结论——
- 部署天花板：Default δ=0.1 (J=0.616)，L1 按 n (J=0.607, -1.6%)
- 逐样本空间：Oracle J=0.387 vs Default 0.616，差距37%
- 影响因素中 β 是最强可学习信号（δ*跨10倍），但真值不可得 → 需从样本特征间接捕捉

## 第2页：特征设计与数据生成方案

**特征候选（基于03-2的影响因素结论）：**
- 次序统计量形态：间距比、变异系数、偏度（间接反映β）
- 样本极端值特征：t₁/tₙ、对数间距（间接反映γ/η）
- n（已知，弱信号但可用）
- 多偏移读出：在同一样本上以多个δ求解MDM，读取β̂(δ)的变化曲线——这比单点β̂₀更稳健

**训练目标：** 逐样本最优 δ*（L5 Oracle标签）

## 第3页：训练目标与损失函数设计

- 输出：回归 δ*（MSE）
- 对比损失：ℓ_param（参数复合）vs ℓ_eng（工程指标）
- 候选：分位数回归、分类（离散化δ）作为替代方案
