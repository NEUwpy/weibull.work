# 第一大块：01 用什么指标评价参数估计的准确性

## 第1页：文献里实际用什么指标？

**目的：** 不自创指标，先搞清楚文献主流用什么评价参数估计精度。

**过程：** 对 182 文件夹 68 篇文献逐篇统计精度指标使用频次。

**结果：** Bias（75%）、SD/方差（56%）、MSE/RMSE（40%）构成精度指标主干；相对误差（16%）偏低，MAE（3%）几乎不用。置信区间/敏感性/拟合优度属统计性质范畴，不纳入精度指标。结论：Bias+SD 为绝对主干，MSE/RMSE 为常见补充。

## 第2页：常见指标的定义与各自能反映什么

**目的：** 梳理常用精度指标的知识体系，明确每个指标"看的是误差的哪个维度"，为后续选择提供依据。

**过程：** 系统列出 Bias、SD、RMSE、MAE、相对误差、置信区间、拟合优度、中位数/分位数等指标的定义，分析其各自反映的信息（中心趋势、离散程度、尾部风险、无量纲化等），讨论它们的互补与冗余关系。

**结果：** Bias 看系统偏移，SD 看离散程度，MSE/RMSE 是两者的综合（MSE=Bias²+SD²），相对误差提供无量纲化视角（但 γ=0 失效），MAE 对尾部不敏感但文献几乎不用。Bias+SD 是最小充分集，MSE/RMSE 为便捷补充。

# 第二大块：02 MDM 方法的有解性证明

## 第1页：MDM 方法与"无解"现象

**目的：** 复刻 MDM 方法，系统检验其可行性，搞清楚"无解"到底是什么情况。

**过程：** 按原文实现 MDM（偏置求根判据 δ=0.1），在 β∈{0.5,1,1.5,2,3} × γ₀/η∈{0,0.1,0.5,1} × n∈{7,10,30} × 40次 = 2400 样本上做蒙特卡洛检验，用高分辨率基准判定有解性，并分析有解率与各因素的相关性。

**结果：** 总体有解率 83.2%。分层差异极大：γ₀/η=0 时仅 52.2%，γ₀/η≥0.5 时 98.7%。有解率与 γ₀/η 高度相关——γ₀/η 越大，有解率越高。紧贴下界时样本量越大反而越容易无解——问题不在信息量，而在判据与下界的相互作用。

**待做实验：**
- `E02-1` 主蒙特卡洛：η=100 固定；β∈{0.5,1,1.5,2,3}；γ₀/η∈{0,0.1,0.5,1}；n∈{7,10,30}；每配置 40 次；用高分辨率基准（均匀 1200 点 + 向 t₍₁₎ 几何加密 1800 点，解析包络梯度，Brent 细化 xtol=1e-13·t₍₁₎）判定有解性；输出分层有解率表和柱状图

## 第2页：存在性理论（二次结构与存在性定理）

**目的：** 从理论上证明合法根几乎总是存在——从而推断"无解"只能来自非法根截断或数值漏检，而非根本身不存在。

**过程：** 固定 β 时，推导 σ²_η(γ) 的解析形式及其包络梯度。

**结果：** σ²_η = C_uu − 2γC_uv + γ²C_vv（开口向上二次函数）。包络梯度 g(γ) = (γC_vv − C_uv)/S(γ)，单调上升，上确界 s_v 仅依赖 β 和 n。存在性判据：**s_v > offset 且无约束根 ∈ [0, t₍₁₎) ⟹ 合法根存在且唯一。** 常用区间 s_v 远大于 0.1，存在性几乎不受限制。

**关键推论：** 理论预测合法根几乎总存在 → 第1页观察到的"无解"必定另有原因 → 只能是：①根落在 γ<0 被截断（非法根）②根贴近 t₍₁₎ 被网格漏检（数值问题）。→ 详见第3页。

**待做实验：**
- `E02-2a` 恒等式验证：在每个配置的样本上核对 σ²(β|γ) 的二次展开式左右两边，确认最大相对偏差为机器精度量级（~1e-13）
- `E02-2b` s_v 表：计算各 (β,n) 下的 s_v = std_i(x_i^{-1/β})，输出对照表，确认常用区间远大于 offset=0.1
- `E02-2c` 单调性验证：在高分辨率网格上用有界优化（高精度内层）重算廓线梯度，确认真正廓线梯度单调、根唯一（排除离散梯度的"多根"假象）

## 第3页：无解的两类成因

**目的：** 搞清楚"无解"到底是怎么来的，分离不同成因。

**过程：** 对全部无解样本逐个追因，检查无约束根的位置和网格分辨率。

**结果：** 无解来自两类成因：
- **成因① 下界切除（主因）：** 绝大多数无解样本的无约束根落在 γ<0 处（中位仅 −0.095η），被物理约束 γ≥0 切掉了。差异函数本身有良好定义的偏置根，只是不合法。这解释了为什么 γ₀/η 越大有解率越高——真值离 0 越远，根越不容易落入负区。
- **成因② 网格漏检（次因）：** 部分样本的根紧贴 t₍₁₎，均匀网格看不到。2400 样本中约 23 例属于此类（基准有解但网格报无解）。n 越大时 t₍₁₎ 越贴近 0，漏检更严重。

**待做实验：**
- `E02-3a` 无约束根定位：对 E02-1 中全部无解样本，用对称几何外推+Brent 在 γ<0 侧定位无约束根；统计无约束根 γ*/η 的分布（直方图）、按 γ₀/η 分层
- `E02-3b` 漏检率统计：在 E02-1 的 2400 样本上，对比两段均匀网格（各 20 点）与高分辨率基准的有解判定，统计漏检数（基准有解但网格报无解的样本数）

## 第4页：成因①的处理——截断到 0

**目的：** 对下界切除的样本，确定截断策略的误差代价，并刻画被截断样本的特征。

**过程：** 对成因①的无解样本，比较截断到 γ̂=0 与放开下界取负根两种策略的误差。同时刻画截断样本的真值特征（γ₀ 与 t₍₁₎ 的相对距离等）。

**结果：** γ₀/η=0 时截断是零误差，放开引入 0.13η 误差。γ₀/η=0.1 时截断 MAE=0.10η < 放开 0.28η。结论：无约束根为负则截断到 0，最稳且不会给出物理上不允许的负值。截断样本集中在 γ₀/η=0 和 n 较大的配置——真值贴近 0 时，t₍₁₎ 期望更小，无约束根更易落入负区。截断后的 γ̂ 误差可控（Bias = −γ₀，量级小）。

**待做实验：**

# 第四大块：04 基于神经网络的MDM偏移量自适应选取

> 核心问题：能不能用神经网络逐样本预测最优偏移量？用什么损失函数训练？工程指标 vs 参数指标作为目标差多少？

## 第1页：从03到04——为什么需要神经网络

**目的：** 论证从固定δ/全局常数c到逐样本自适应δ的必要性，建立04的立项依据。

**过程：** 回顾03方案阶梯，分析可部署天花板（~0.90）与逐样本oracle（0.303）之间的缺口；引用树探针0.707越过查表线0.777的实证（证明样本形态中有超出β/n的可提取信号）；引用可学习性判据ρ̂=0.32（95% CI [0.27, 0.39]，超过0.20立项阈值）。

**结果：**
- 全局常数c≈0.170已拿走大部分收益（误差比0.810），但逐样本异质性是真正的精度瓶颈（0.800 vs 0.565）
- 树探针0.707 > 查表0.777：样本形态特征的价值被实证验证
- ρ̂=0.32：可学习性有统计背书，但oracle的0.303不该当目标（大头是不可预测的运气）
- 现实目标：稳定落在0.60附近，即把可部署方案从~0.90推向oracle的中点
