# E02-1 负根示例图

## 目的
构造一个典型的成因①样本，画差异函数曲线，直观展示"根为负被切掉"的情况。

## 配置
- β=2.0, η=100, γ₀=0（γ₀/η=0，最易出现负根）
- n=20
- δ=0.1（MDM 偏置求根判据）

## 方法
1. 生成一个 Weibull 样本（γ₀=0 时根容易落入负区）
2. 计算差异函数 D(γ) = σ²_η(γ) − σ²_η(γ̂_MLE) − offset，在 γ∈[-0.5η, t₍₁₎] 上画曲线
3. 标注：
   - 无约束根 γ*（γ<0 处，差异函数过零点）
   - γ=0 截断线（垂直虚线）
   - t₍₁₎ 位置（样本最小值）
4. 用灰色区域标注 γ<0 的"非法区域"

## 预期
差异函数在 γ<0 处有良好定义的过零点，但被物理约束 γ≥0 切掉，直观展示"无解"的成因。
