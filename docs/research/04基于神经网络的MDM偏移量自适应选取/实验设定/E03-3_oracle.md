# E03-3 L5 Oracle（逐样本最优 δ）

## 目的
计算逐样本 Oracle 最优 δ*，作为精度上界参考。在 n∈{7, 10, 20} 上执行。

## 方法
1. 对每个样本，扫描 26 个 δ 值
2. 选使 **J_param** 最小的 δ 作为该样本的 Oracle δ*
   - J_param = √( mean( ((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)² ) )
3. 记录 Oracle δ* 的分布（均值、标准差）和对应的 J_param

## 配置
- n ∈ {7, 10, 20}
- β ∈ {2, 2.5, 4}
- γ/η ∈ {0.1, 0.5, 1.0}
- 500 次重复/配置

## 计算量
- 配置数：3×3×3 = 27
- 每配置：500 样本 × 26 δ = 13,000 次 MDM 拟合
- 总拟合次数：27 × 13,000 = **351,000 次**（与 E03-1 共用扫描数据）

## 产物
- 分片文件：`E03-3_oracle_beta{β}_n7_gamma{γ/η}.csv`
- 汇总文件：`E03-3_oracle_summary.csv`

## 意义
- Oracle δ* 的分布宽度反映了样本间的异质性
- Oracle 与可部署方案（L0~L4）的差距，衡量了"自适应 δ"的潜在收益
- 如果 Oracle 的均值与 L3/L4 接近，说明层级分组已足够好
