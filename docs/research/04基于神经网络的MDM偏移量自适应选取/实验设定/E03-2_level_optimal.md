# E03-2 层级最优计算

## 目的
从 E03-1 的汇总数据中，计算 L0~L4 各层级的最优 δ* 及对应 Bias/SD，确定最优 δ* 与哪些因素最相关。

## 方法
1. 读取 `E03-3_summary.csv`
2. 按层级分组，计算各组内使平均 |Bias(β̂)| 最小的 δ*：
   - L0：全局最优（所有配置共用一个 δ*）
   - L1：按 n 分组
   - L2：按 β 分组
   - L3：按 (β,n) 分组
   - L4：按 (β,n,γ/η) 分组
3. 输出各层级的最优 δ* 及对应的 Bias/SD

## 产物
- `E03-2_level_optimal.json`：各层级的最优 δ* 及汇总统计

## 预期结论
- 如果 L0（全局最优）与 L4（全参数最优）差距很小 → 最优 δ 对参数不敏感
- 如果 L1（按 n）明显优于 L0 → n 是主要影响因素
- 如果 L2（按 β）明显优于 L0 → β 是主要影响因素
- 如果 L3（按 β,n）明显优于 L1+L2 → β 和 n 有交互效应
