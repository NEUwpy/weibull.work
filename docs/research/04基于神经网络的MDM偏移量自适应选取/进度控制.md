## 03 核心结论

### δ* 影响因素

| 因素 | 影响强度 | 证据 |
|---|---|---|
| β | **主要驱动** | δ*从0.04(β=4)到0.20(β=2)，差5倍 |
| n | 次要 | δ*从0.10到0.12，变化小 |
| γ/η | 弱 | 同一(β,n)下不同γ/η的δ*变化<0.06 |
| 逐样本 | 显著 | L5 Oracle J=0.370 vs L4 J=0.547 |

### 方案阶梯

| 方案 | J_param | 说明 |
|---|---|---|
| L5 Oracle | 0.370 | 不可部署 |
| L4 查表 | 0.547 | 需全部真值 |
| L3 查表 | 0.556 | 需β真值 |
| **Default δ=0.1** | **0.582** | **直接部署，推荐** |
| 自迭代 | 0.589 | 恶化 |
| MLE+查表 | 0.597 | 恶化 |
| LSE+查表 | 0.651 | 恶化 |
