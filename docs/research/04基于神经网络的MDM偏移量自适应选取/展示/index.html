01-3 · No Universal Metric

为什么没有一个统一有效指标？

单指标在特定分布形态下会失真。必须成套报告 Bias+SD+RMSE，γ 禁用相对指标。

情景1：RMSE相同≠精度相同

相同RMSE可掩盖完全不同的偏差-方差结构。必须分解报告Bias和SD。

情景2：中位/均值尾部钝感

P99.9与中位数比达5.4×，最大误差差6.7×。仅报Mean/Median严重低估极端风险。

情景3：γ≈0相对指标失真

γ=2时RelRMSE达8800%。同一估计器精度没变，因真值不同相对指标任意放大。

情景4：参数排序≠工程排序

n=20：参数视角MDM最优（RMSE_β=0.609），工程视角LSE追平MDM（RMSE_x₀.₉₅≈97.8）。两视角分离。

情景5：跨量纲MSE不可比

γ的MSE是β的84000倍——纯量纲差异。跨参数比较必须用相对指标或标准化。

01-4 · Parameter Perspective Recommendation

参数视角推荐方案 + 综合精度指标 Jparam

多指标方案（诊断用）

参数BiasSDRMSE相对Bias相对RMSE其他
β̂✓✓✓✓✓
η̂✓✓✓✓✓
γ̂✓✓✓禁用禁用附报γ̂=0截断率+γ̂近零率

单指标 Jparam（排序/训练用）

Jparam = √( mean( ((β̂−β)/β)² + ((η̂−η)/η)² + ((γ̂−γ)/η)² ) )

β、η除以自身真值转为无量纲；γ不除以γ自身而除以η，避免γ≈0失真。几何含义：三维标准化误差空间中的平均欧氏距离。

设计理由

Bias和SD构成参数视角最小充分集。若为δ方案排序或神经网络训练需要标量目标，则J_param把三参数误差统一到可比较空间。

两个视角不冲突

多指标聚焦单个参数诊断，J_param聚焦整体效果排序。后续03-04：参数视角目标用J_param；多指标保留用于诊断。

Part 02 · 4 Pages

第二大块：MDM方法
的有解性证明

无解现象 → 理论存在性 → 两类成因 → 工程方案（截断+拟合） → 精度验证

02-1 · Solvability

无解现象与理论存在性

按原文实现MDM（偏置求根判据 δ=0.1），在多个配置上做蒙特卡洛检验，发现无解现象。

理论推导

σ²η(γ) = Cuu − 2γCuv + γ²Cvv

开口向上的二次函数。包络梯度 g(γ) = (γCvv − Cuv) / S(γ) 单调上升。

存在性判据：sv > offset 且无约束根 ∈ [0, t₍₁₎) ⟹ 合法根存在且唯一。

推断

理论预测合法根几乎总存在 → 实际无解必定来自：

① 根落在 γ<0 被截断（非法根）
② 根贴近 t₍₁₎ 被网格漏检（数值问题）

02-2 · Two Causes

无解的两类成因

成因① 下界切除（主因）

无约束根落在γ<0处，被物理约束γ≥0切掉。差异函数本身有良好定义的偏置根，只是不合法。γ₀/η越大有解率越高——真值离0越远，根越不容易落入负区。

成因①示例：差异函数曲线，无约束根在γ<0被截断

成因② 网格漏检（次因）

根紧贴 t₍₁₎，均匀网格看不到。n越大时 t₍₁₎ 越贴近0，漏检更严重。均匀搜索的数值分辨率不足。

成因②示例：20个搜索点离散采样，根极靠近t₁导致漏检
02-3 · Engineering Solution

工程方案：截断 + 拟合

成因① → 截断：γ̂ = 0

直接截断到γ̂=0（物理约束，最稳）。成因①截断策略在E01-6中已验证（MDM γ̂=0截断率~20%，误差可控）。

成因② → 拟合：解析梯度推算

不依赖密集网格，改用拟合（解析梯度）直接推算根的位置。避免均匀网格在t₁附近的数值分辨率不足。

三步流程

Step操作针对
1检测无解样本，分类成因①/②识别
2成因①：γ̂=0截断（物理约束）下界切除
3成因②：解析梯度直接推算根网格漏检
→failure_rate → 0%，始终有解100%可用
02-4 · Accuracy Verification

始终有解方案的精度验证

对照组（标准网格搜索，20点）vs 实验组（截断+拟合，100%给出估计）。三层次对比。

层次对比内容预期
1可用性提升：failure_rateX% → 0%
2valid-only子集精度：J_param≈一致
3全样本精度：全量 vs valid-only无退化
目标：始终有解方案显著提升可用性（failure_rate→0%），且主精度指标未出现不可接受退化。这是从"能算"到"能算且可信"的关键一步。

报告指标：valid_rate / failure_rate、J_param、RMSE_β/η/γ、RMSE_x₀.₉₅/x₀.₉₉、γ̂=0截断率与near-zero率。

实验配置：β=2.5, η=1000, γ=100；n∈{5,7,10,20}；2000次/组；δ=0.1固定。对照组（标准网格，valid-only）vs 实验组（截断+拟合，100%有解）。
