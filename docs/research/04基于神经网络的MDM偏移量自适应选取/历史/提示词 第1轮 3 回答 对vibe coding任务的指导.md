## 0. 任务一句话

为三参数 Weibull 的 MDM 估计法构建**逐样本自适应的偏移量预测器**：先用蒙特卡洛仿真生成带完整损失曲线标签的数据集，再训练一个小型神经网络直接输出偏移量 δ。主成功标准：5 折交叉验证下，中位复合误差（相对固定 δ=0.1 的比值，下称"误差比"）显著低于现有最优可部署方案的 **0.707**。

## 1. 前因后果

### 1.1 问题与方法

三参数 Weibull W(β, η, γ) 的位置参数 γ（最小寿命）难估：似然函数在 γ→t₍₁₎ 处发散，小样本下常规方法方差极大。

MDM（最小差异法）的替代思路：给定候选 (β, γ)，每个次序统计量都能反推出一个隐含的尺度估计

$$\hat\eta_i = (t_{(i)} - \gamma),/,x_i^{1/\beta}$$

若候选参数正确，这些 η̂ᵢ 应彼此一致。于是以它们的标准差 σ(β|γ) 为评分，对每个候选 γ 取内层最优 β，得到廓线 S(γ) = min_β σ(β|γ)。其中 xᵢ 是次序 i 的秩位（如中位秩）对应的标准 Weibull 变换值。**秩位约定本文不规定，以前序实现为准；若无可考，自选一种、全管线统一并记录**——s_v 等关键量依赖该约定，前后不一致比选哪一种更致命。

### 1.2 偏移量为什么存在

S(γ) 形如山谷。取谷底（梯度 = 0）的估计方差极大：谷底平坦，样本一抖，最低点就在平坦区内大幅滑动——这是 γ 难估的老毛病换了个形式。MDM 的关键设计：**在谷壁上取「梯度 = δ > 0」的点定位 γ**。壁上有确定斜率，交点对扰动稳定。代价是 γ̂ 被系统性推向 t₍₁₎ 一侧（高估）。这是偏置换方差：用少量向上偏置，换方差约一个数量级的下降。原文经验值是固定 δ=0.1。

本项目的全部出发点：**这个 δ 不该是常数，而应随样本自适应**——03 已证明这件事有可观收益且可学习。

### 1.3 已确立的事实（公理，直接采用，不要重新发现）

以下是 01–03 的最终结论。若你的实测与其冲突，停下上报（见 §8），不要自行修改。

1. **闭式解**。固定 β 时 σ² 是 γ 的开口向上抛物线 σ² = C_uu − 2γC_uv + γ²C_vv；廓线梯度有闭式 g(γ) = (γC_vv − C_uv)/S(γ)；g 在可行域 (−∞, t₍₁₎) 上从 −s_v 单调升至 +s_v，其中 s_v(β,n) = √C_vv = std_i{xᵢ^{−1/β}} 是确定性量。求根用 Brent；负根截断到 0；解不出时收缩 δ 重试。无解情形 99.7% 来自 γ≥0 截断（根在负侧一点点），真正固有无解几乎不存在。
    
2. **归一化坐标**。c = δ/s_v(β,n) 是正确坐标。最优 c* 单谷，β≥1.5 时落在窄带 [0.11, 0.34]，标度律 c* ≈ exp(−1.373 − 0.584·ln β + 0.120·ln n)（R²=0.78）。
    
3. **依赖结构**。最优偏移主要由 β 驱动，弱依赖 n（指数 0.120），与 γ、η 完全无关（梯度无量纲；不同 γ/η 下误差–c 曲线重合）。
    
4. **β̂–偏移纠缠（最重要的坑）**。偏移增大会把 γ̂ 推向 t₍₁₎、压缩左尾、令内层 β̂ 系统性低偏；β 越大越严重（c=0.21 处 β̂/β 中位：β=1 时 0.98，β=5 时 0.72）。后果：**任何以 s_v(β̂) 为乘子的部署通道都会失败**——朴素配方 0.21·s_v(β̂,n) 实测误差比 1.081，比不优化还差。
    
5. **各参数最优偏移不一致**。γ 偏好更大偏移，β̂ 偏好更小，中位差 0.08~0.18（详表见附录 B）。
    
6. **方案阶梯**（误差比，相对固定 δ=0.1，5 折 CV）：
    
    |方案|部署输入|误差比|
    |---|---|---|
    |固定 δ=0.1（基线）|无|1.000|
    |朴素配方 0.21·s_v(β̂,n)|单遍 β̂|1.081（失效）|
    |最优单一固定 δ|无|0.916|
    |按 n 调优固定 δ|n|0.896|
    |归一化全局 c=0.21（真 β，不可部署）|真 β|0.770|
    |按 (β,n) 查表（真参数，不可部署）|真 β, n|0.777|
    |多偏移读出 + 树（可部署）|样本与廓线特征|**0.707**|
    |诊断探针（特征 + 真 β）|—|0.513|
    |逐样本 oracle|—|0.303|
    
7. **可学习性**。探针预测误差与 oracle 误差的相关系数 ρ̂ = 0.32，95% CI [0.27, 0.39]，显著超过 0.20 的立项阈值。
    
8. **安全代价**。偏移系统性高估 γ 与深分位寿命（c=0.21 时 γ̂ 偏 +5.2%η，x_R(0.999) 偏 +24.5%），即偏向低估失效风险。

## 2. 八个关键设计决策

### A. 网络直接输出 δ；部署链路全程禁用 s_v(β̂) 与任何真值【硬约束】

**指令**：输出参数化为有界的 log δ（或候选 δ 网格上的离散分布）。从特征计算到最终求解的整条部署链路中，不得出现真 β/η/γ，也不得出现以 β̂ 代入 s_v 的换算。

**理由**：g 无量纲，δ 本身就是可部署的量，没有理由经过换算；而事实 4 已实测证明 s_v(β̂) 通道必死——β̂ 的低偏会被 s_v 对 β 的陡梯度放大（1.081 > 1.000）。这同时就是 Q3 的答案：能，而且必须。

### B. 训练目标 = 最小化实际实现的损失，而不是回归逐样本最优 c*【硬约束】

**指令**：二选一或两者对比：(a) 候选 δ 网格上输出 softmax 权重 p，训练损失为 Σᵢ pᵢ·ℓᵢ（该样本在 δᵢ 处已存储的真实损失），即代价敏感分类；(b) 回归整条损失曲线 ℓ(δ)，推理时取 argmin。直接回归逐样本 argmin 的 MSE 方案只允许作为对照消融存在，不得作为主线。

**理由**：逐样本 argmin 在平坦谷处近乎随机数，是高噪声、有时病态的标签；决策导向训练让"落在平坦谷内任何位置"不被无谓惩罚，天然处理多峰，且一切损失定制（不对称安全罚、参数加权）只需改 ℓ、不改训练机制。方案 (b) 附送一个置信信号：预测曲线越平坦，越应回退到保守默认值。

### C. 标签 = 每个样本的完整损失曲线；保留离线重放能力

**指令**：数据生成时，对每个样本在候选 δ 网格上逐点求解并存储：(γ̂, β̂, η̂)(δᵢ)、若干可靠度下的 x_R(δᵢ)（建议至少含 R=0.999）、分参数损失与复合损失、可解性标志。

**理由**：一条廓线建好后，任意 δ 的解只是求根，成本极低——一次生成同时产出特征（多偏移读出）与标签（损失曲线）。存曲线使得损失定义可以离线重算（直接服务 Q4），oracle 与各基线可随时重放，无需重新仿真。

### D. 候选 δ 网格用绝对 log-δ 坐标，不用 c 坐标

**指令**：网格在 log δ 上取点；密度以统一插值算子下曲线误差可忽略为准。覆盖性校验（允许用真值，但仅限生成阶段的诊断）：对训练分布内所有 (β,n)，折算成 c = δ/s_v 后网格应覆盖约 [0, 0.75]。

**理由**：c 坐标本身需要 s_v(β)，β 未知，部署不可得——用 c 网格做特征会把纠缠从后门请回来。绝对 δ 网格部署可算；并且读出曲线的形态（β̂ 随 δ 的衰减速率）本身携带真 β 的指纹——事实 4 的偏差模式在特征侧是信号而非毒药，因为训练与部署看到的是同分布的有偏特征。

### E. 已知不变性构造进特征，不指望网络自己学【硬约束】

**指令**：所有网络输入对样本的位置与尺度严格不变：时间轴按样本内尺度归一、相对 t₍₁₎ 工作；廓线几何在归一化坐标上提取。写一个单元测试：同一底层样本经平移缩放（不同 γ、η）后，特征与网络输出必须在数值容差内逐位一致。

**理由**：γ/η 与 η 不变性已被 03 验证（事实 3）。显式构造可节省大量样本复杂度，并保证部署对任意量纲成立；这个测试同时是对实现正确性的廉价体检。

### F. 真值只允许出现在标签与诊断中

**指令**：真参数只能用于：计算损失标签、生成阶段的覆盖性与分布诊断、评估报告。任何作为网络输入的量必须仅由观测样本可计算。建议在数据 schema 层面就把特征与标签分表隔离。

**理由**：用真值构造的特征会让训练表现虚高且根本不可部署——这是比代码 bug 更隐蔽的失效模式，靠纪律不如靠结构来防。

### G. 多头输出，共享主干

**指令**：至少三头：复合损失头、γ 优先头、β̂ 优先头。推荐增加逐参数偏移向量头 (δ_γ, δ_β, δ_η)：推理时各参数在各自的偏移处读数。

**理由**：事实 5——各参数最优偏移中位差 0.08~0.18，一个 δ 伺候不了所有参数；同一廓线上多解几个根近乎零成本；单一 δ 家族的天花板是 oracle 的 0.303，逐参数向量跳出了这个家族。这同时是 Q4 的实现载体。

### H. 安全不对称是一等公民

**指令**：训练损失中预留对 γ 高估与 x_R 高估的不对称罚项（权重可配，默认为 0 即还原复合损失）；评估时 γ̂ 的带符号偏差与尾部 P95 必须单独报告。交付配方中必须包含一档"保守"（不对称罚 > 0）。

**理由**：事实 8——偏移的误差方向天然是高估寿命、低估失效风险；网络为压中位损失，可能在局部学出更大的偏移，使安全问题比固定 δ 更严重。看不见就控不住。

## 3. 阶段一：蒙特卡洛数据生成

### 3.1 数值核心先行（里程碑 M0）

**指令**：先实现并验收闭式 MDM 求解器：抛物线系数、包络梯度 g、Brent 求根、负根截断到 0、解不出时收缩 δ 重试。验收项（对照 02/03 的已知行为）：g 在可行域上单调且范围为 ±s_v；构造的无解情形几乎全部来自 γ≥0 截断；固定 δ=0.1 下估计行为正常、求解率 ≈100%。

**理由**：仿真器或求解器若有隐错，后面所有学习都在学这个 bug，而且学得越好越难发现。先验收，后量产。

### 3.2 采样设计

**指令**：固定 η=1、γ=0 生成主数据（另留一小批 γ/η ∈ {0.1, 0.5, 1.0} 的样本，仅用于决策 E 的不变性回归测试）。β 与 n 用连续先验采样（例如 β 取 log-uniform、n 取合理范围内的整数）构成训练集；同时保留与 03 一致的 (β,n) 评估网格用于对照与阶梯复现。训练先验的范围以 03 网格为基准向外略扩。

**理由**：不变性已证，固定 (γ,η) 不损失一般性、省掉一个维度；连续先验防止"网格过拟合"、直接服务 Q5；不保留 03 网格，阶梯上的参考数字就失去了可对照的坐标系。

### 3.3 每个样本算什么、存什么

**指令**：每个样本建廓线一次，按决策 C/D 在 δ 网格上全解全存。特征原料的必备集：β̂(δᵢ) 读出全曲线、归一化的 γ̂(δᵢ) 轨迹（如 (t₍₁₎−γ̂)/样本尺度）、廓线几何（谷深、谷宽、壁陡）、归一化样本统计量（如 t₍₁₎/t₍ₙ₎、对数间距、变异系数）、n。在此之外的扩展特征由你自由设计（须满足决策 E/F）。元数据必存：真参数、随机种子、评估格簇 ID。

**理由**：读出曲线是 03 验证过的最有效特征族——树探针 0.707 越过真参数查表 0.777 的功臣就是它。元数据中的格簇 ID 与种子是后续无泄漏分折的唯一可靠依据，事后补不上。

### 3.4 数据量与质量

**指令**：数据量由你决定，但须满足两个可检验条件：(i) 评估格簇上按格簇聚类的 bootstrap（B=300）置信区间，足以分辨 0.05 量级的误差比差异；(ii) 给出一条数据量消融曲线，证明数据规模不是最终结论的瓶颈。

**理由**：03 的所有参考数字都带这种区间，区间盖住差异的比较没有意义；消融曲线是"数据够了"的唯一证据，比拍一个数字可信。

### 3.5 验收（里程碑 M1）

**指令**：在与 03 一致的评估网格上离线重放方案阶梯，至少复现四个点：固定 δ=0.1 基线（恒等于 1.000）、最优单一固定 δ（≈0.916）、真 β 下全局 c=0.21（≈0.770）、逐样本 oracle（≈0.303）。容差按量级一致掌握（±0.03~0.05）；显著偏离则停下诊断，禁止带病推进。

**理由**：复现阶梯是对整条管线（采样分布、求解器、损失实现、协议实现）最便宜的端到端测试，也是之后一切数字的锚。

## 4. 阶段二：神经网络训练

### 4.1 基线先行（里程碑 M2）

**指令**：先用梯度提升树在 §3.3 特征上复现多偏移读出探针，目标量级 0.68~0.74。

**理由**：树在表格特征上极强，是网络要打败的真实对手；若连树都复现不出，问题出在数据或特征，还轮不到网络。基线不立，后面所有数字无锚。

### 4.2 网络主线（里程碑 M3–M4）

**指令**：

- **M3**：同特征下的小型 MLP，预期与树打平（这是 sanity check；打不平先查目标函数与预处理，不要加深网络）。
- **M4（主结果）**：函数型输入（整条读出曲线、廓线几何序列；可用一维卷积或小型集合编码器处理归一化次序统计量）+ 决策 B 的训练目标。从小网络开始；每个增量（特征族、目标函数、结构）做独立消融。

**理由**：预期的增量来源是「函数型输入 + 决策导向目标」，不是深度——容量在这个问题上不是瓶颈。消融保证结论可归因：这是研究代码，最终要写进报告的是"为什么有效"，不只是一个分数。

### 4.3 输出与可解性

**指令**：推理时若所选 δ 超出该样本的可解范围，自动收缩重试并计数。求解率须保持 ≈100%（门槛指标），回退率单独报告。

**理由**：g 的上确界逐样本不同，越界不可完全避免；回退机制保住"总能给出估计"的工程承诺（02 的精神），而回退率本身是网络输出是否系统性越界的诊断信号。

### 4.4 配方与泛化（里程碑 M5–M6）

**指令**：

- **M5**：按决策 G/H 交付三档配方：复合最优、γ 优先、保守安全；若做逐参数偏移向量头，与单 δ 头同场对比。
- **M6**：泛化与成本。在训练先验之外留出 (β,n) 做外推测试，报告退化曲线；外推时把输出截断到训练时见过的 δ 范围。测量单次网络推理耗时与单次 MDM 求解耗时之比。

**理由**：M5 回答 Q4，M6 回答 Q5/Q6。外推截断是因为网络在分布外的行为不可信，宁可退化为近似查表也不放飞。

## 5. 评估协议【硬约束，逐条执行】

1. **所有可调方案**（含树、网络、按 n 调优的固定 δ）一律 5 折交叉验证；分折按「格簇 × 种子」聚类切分，严禁同一格簇或同一种子横跨训练与测试。——理由：防自适应乐观与数据泄漏，这是 03 全部数字可信的前提。
    
2. **主指标**：各评估格内中位复合损失相对该格固定 δ=0.1 的比值，再取全网格中位。复合损失定义必须与 03 逐字一致：
    
    $$\ell = (\ln\hat\beta - \ln\beta)^2 + (\ln\hat\eta - \ln\eta)^2 + ((\hat\gamma - \gamma)/\eta)^2$$
    
    评估聚合用中位数；训练目标可用均值（可微）。——理由：换了口径，0.707 等所有参考数字立即失去可比性。
    
3. **统一插值**：损失–δ 曲线全程使用同一插值算子；评估下限截到首个非零网格点。——理由：03 协议；不同插值会在平坦谷处制造虚假差异。
    
4. **置信区间**：所有关键比值给 95% CI（按格簇 bootstrap，B=300）。
    
5. **分项报告，不加权合成单一分数**（01 指标体系）：MdJRE（排序主指标）、逐参数 MdAPE（γ 用 /η 归一；定位短板）、Medrel 带符号偏差（方向与安全，警示型）、[P25,P75] 与 [P5,P95]、P95（稳定性与尾部，警示型）、求解率（门槛型）。最终报告附工程视角：若干可靠度 R 下 x_R 的 MdAPE 与带符号偏差。——理由：单一分数会让分项问题互相掩盖，尤其会藏住 γ 高估这类安全问题。

## 附录 A：公式速查

- 伪尺度估计：η̂ᵢ = (t₍ᵢ₎ − γ) / xᵢ^{1/β}（xᵢ 为秩位对应的标准 Weibull 变换值）
- 固定 β：σ²(β|γ) = C_uu − 2γC_uv + γ²C_vv（关于 γ 的开口向上抛物线）
- 廓线与梯度：S(γ) = min_β σ(β|γ)；g(γ) = S′(γ) = (γC_vv − C_uv)/S(γ)
- 梯度值域半径：s_v(β,n) = √C_vv = std_i{xᵢ^{−1/β}}；g 在 (−∞, t₍₁₎) 上从 −s_v 单调升至 +s_v
- 归一化偏移：c = δ / s_v(β,n)
- 复合损失：ℓ = (ln β̂ − ln β)² + (ln η̂ − ln η)² + ((γ̂ − γ)/η)²（评估用中位数聚合，训练可用均值）
- MdJRE：e_j = √{[(ln(β̂/β))² + (ln(η̂/η))² + ((γ̂−γ)/η)²]/3}，MdJRE = median_j e_j
- MdAPE(θ) = median_j |θ̂_j − θ|/θ（γ 用 /η 归一）；Medrel(θ) = median_j (θ̂_j − θ)/θ（正=系统高估）
