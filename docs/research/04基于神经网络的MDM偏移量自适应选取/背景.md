本文档汇总 01~03 的核心结论，为设计"逐样本自适应偏移量选取"的神经网络提供上下文。

## 1. MDM 方法简介（来源：02、03）

### 1.1 基本原理

三参数 Weibull 分布 W(β, η, γ) 的位置参数 γ（最小寿命）估计困难：似然函数在 γ→t₍₁₎ 处发散，常规方法在小样本下方差极大。

最小差异法（MDM，谢里阳等，2025）的思路：
1. 对给定 (β, γ)，由每个次序统计量反解一个伪尺度估计量 η̂ᵢ = (t₍ᵢ₎ − γ) / xᵢ^{1/β}
2. 以这些 η̂ᵢ 的样本标准差 σ(β|γ) 作为离散度量，越小说明 (β, γ) 越合理
3. 固定 γ 对 β 极小化，得廓线 S(γ) = min_β σ(β|γ)
4. **不在梯度为零处取根**（极小点处曲线平坦、方差大），而是在梯度等于一个小正偏移 δ 处定位 γ：

$$g(\gamma) = S'(\gamma) = \delta$$

取最靠近 t₍₁₎ 的根作为 γ̂。

### 1.2 闭式实现（来源：03 §2）

关键代数事实：固定 β 时，σ² 是关于 γ 的开口向上抛物线：

$$\sigma^2(\beta|\gamma) = C_{uu} - 2\gamma C_{uv} + \gamma^2 C_{vv}$$

廓线梯度由包络定理给出闭式：

$$g(\gamma) = S'(\gamma) = (\gamma C_{vv} - C_{uv}) / S(\gamma)$$

g 在可行域 (−∞, t₍₁₎) 上由 −s_v 单调升至 +s_v，其中：

$$s_v(\beta, n) = \sqrt{C_{vv}} = \text{std}_i\{x_i^{-1/\beta}\}$$

s_v 只依赖 β 与 n，是确定性可查表的量，也是梯度的值域半径。

### 1.3 有解性结论（来源：02）

- 99.7% 的"无解"来自 γ≥0 下界切除，根其实在负侧一点点（中位约 −0.08η）
- 真正固有无解几乎不存在：因 s_v ≫ offset，g=δ 必有根
- 工程方案：Brent 定根 + 负则截断到 0，始终有解

## 2. 偏移量 δ 的选取规律（来源：03，核心）

### 2.1 为什么需要偏移

- δ=0（纯极小点）落在廓线的平坦谷中，对样本随机性极敏感，方差极大
- δ>0 把定位点移到壁上有确定斜率处，是偏置–方差正则化：以少量向上偏置换取方差约一个数量级的下降

### 2.2 归一化与最优偏移

定义归一化偏移 c = δ / s_v(β, n)，把不同 (β,n) 放到同一坐标。

**核心发现：最优 c* 存在、单谷，且落在窄带内**

| β | 最优 c* 范围 |
|---|-------------|
| 1.5 | ~0.25 |
| 2.0 | ~0.23 |
| 3.0 | ~0.19 |
| 5.0 | ~0.13 |

β≥1.5 时 c* ∈ [0.11, 0.34]。

**标度律**（β≥1.5，R²=0.78）：

$$c^*(\beta, n) = \exp(-1.373 - 0.584 \ln\beta + 0.120 \ln n)$$

### 2.3 驱动因素与不变性

- **主要由 β 驱动**，随 n 仅缓慢变化
- **与 γ/η 无关**：γ/η ∈ {0, 0.1, 0.5, 1.0} 的误差–c 曲线基本重合
- **与 η 无关**：梯度 g 无量纲
- 有效输入空间压缩到（形状信息, n, 样本形态）

### 2.4 各参数最优偏移不一致

| β | 复合 | γ | β̂ | η̂ | x_R(0.999) | 最大差距 |
|---|------|---|-----|-----|------------|---------|
| 1.0 | 0.25 | 0.38 | 0.20 | 0.34 | 0.36 | 0.20 |
| 2.0 | 0.23 | 0.29 | 0.19 | 0.25 | 0.26 | 0.10 |
| 5.0 | 0.13 | 0.16 | 0.13 | 0.14 | 0.19 | 0.08 |

γ 偏好更大偏移，β̂ 偏好更小偏移，中位差 0.08~0.18。

### 2.5 β̂ 与偏移的纠缠（关键障碍）

沿廓线增大偏移会把 γ̂ 推向 t₍₁₎，左尾被压缩，内层最优形状随之下移：

- β̂ 在解点处随 c 增大而**系统性低偏**
- β 越大越严重：c=0.21 处 β̂/β 中位为 β=1 时 0.98，β=5 时 0.72
- **后果**：任何以 s_v(β̂) 为乘子的部署通道都会被污染（β̂ 低偏经 s_v 对 β 的陡梯度放大后，有效偏移系统性偏大且方差爆炸）

## 3. 方案阶梯与学习化可行性（来源：03 §3.9）

### 3.1 已有方案对比（复合误差比，相对固定 δ=0.1，5折CV）

| 方案 | 部署输入 | 误差比 | 说明 |
|------|---------|--------|------|
| 固定 δ=0.1（基线） | 无 | 1.000 | 原文经验值 |
| 朴素配方 0.21·s_v(β̂,n) | 单遍 β̂ | 1.081 | **失效**，β̂–偏移纠缠 |
| 最优单一固定 δ（CV） | 无 | 0.916 | 可部署天花板 |
| 按 n 调优固定 δ（CV） | n | 0.896 | 可部署天花板 |
| 归一化全局 c=0.21（真 β） | 真 β | 0.770 | 不可部署，参照 |
| 按 (β,n) 查表（真参数） | 真 β, n | 0.777 | 不可部署，参照 |
| **多偏移读出 + 树（CV）** | **样本与廓线特征** | **0.707** | **可部署，已越过查表线** |
| 诊断探针（特征+真β） | — | 0.513 | 诊断用 |
| 逐样本 oracle | — | 0.303 | 理论上界 |

### 3.2 关键判读

1. **可部署天花板 ~0.90**：不看样本形态的方案在此触顶，说明再压误差必须用逐样本信息
2. **多偏移读出探针 0.707 已越过需真参数的查表方案（0.777）**：从观测中提取形状信息的价值被验证
3. **与作弊探针（0.513）的差距** = 从观测中更充分识别形状信息的空间
4. **与 oracle（0.303）的差距** = 包含原则上不可预测的运气成分

### 3.3 可学习性判据

- 定义：探针预测误差与 oracle 误差的相关系数 ρ
- 测得：ρ̂ = 0.32，95% CI [0.27, 0.39]
- **显著超过 0.20 的立项阈值** → 为逐样本神经网络路线提供了带置信区间的立项依据

## 4. 特征设计起点（来源：03 §5）

### 4.1 多偏移读出特征

核心思想：同一条廓线 S(γ) 上，在多个偏移值 δ₁, δ₂, ... 处求解，得到对应的 β̂(δ)。β̂ 随 δ 的衰减形态编码了形状信息。

- 一条廓线构建后，任意 δ 的解只是根查找，成本极低
- 特征向量：[β̂(c₁), β̂(c₂), ..., β̂(c_k)]，c_i 在 [0, 0.75] 上采样

### 4.2 补充特征（可选）

- 样本统计量：t₍₁₎/t₍ₙ₎、样本变异系数等
- 廓线几何：S(γ) 的谷深、谷宽、壁陡度
- 样本量 n

### 4.3 目标

- 回归目标：逐样本最优 c*（或 δ*）
- 可定制损失：按应用需求调整 γ/β̂/η̂/x_R 的权重（各参数最优偏移不一致，见 §2.4）

## 5. 评估协议（来源：03 §2.4）

1. **所有调优方案一律 5 折交叉验证**，杜绝自适应乐观
2. **统一曲线插值算子**，c 的评估下限截到首个非零网格点
3. **全部关键比值给 95% 置信区间**（按格簇 bootstrap，B=300）
4. **误差比口径**：各格中位复合损失相对该格固定 δ=0.1 的比值，再取全网格中位

---

## 6. 复合损失函数（来源：03 §2.3）

量纲无关、对发散样本稳健的对数复合损失：

$$\ell = (\ln\hat{\beta} - \ln\beta)^2 + (\ln\hat{\eta} - \ln\eta)^2 + ((\hat{\gamma} - \gamma)/\eta)^2$$

主目标取其中位数（稳健）；训练时可用均值（可微，惩罚尾部）。

---

## 7. 安全边界（来源：03 §3.10）

偏移以系统性高估 γ 与深分位寿命为代价：

| c | γ̂ 偏差（%η） | x_R(0.999) 偏差（%） |
|---|-------------|---------------------|
| 0.1（固定 δ=0.1） | +3.5 | +13.7 |
| 0.21（最优带附近） | +5.2 | +24.5 |

- 偏移越大，越偏向高估寿命 = 低估失效风险
- 深尾/最小寿命的高可靠性设计应取更保守的偏移
- 学习化损失应预留不对称惩罚项

## 8. 评价指标体系（来源：01）

训练完网络后，需要用一套合理的指标评估效果。01 给出了完整的评价框架。

### 8.1 核心原则

- **评的是"参数估得多准"，不是"拟合得多好"**：只有真值已知时（MC仿真）两者才一致
- **不加权合成单一分数**：加权会让分项问题互相掩盖，应分项报告
- **评价用中位数（稳健），训练用均方（可微）**：二者处于同一相对/对数空间，只是聚合形态不同

### 8.2 三视角 × 五指标

| 视角 | 准确性（主·排序） | 方向（警示） | 稳定性（通过） | 尾部（警示） | 求解率（通过） |
|------|------------------|-------------|---------------|-------------|---------------|
| 参数视角 | MdJRE（整体一数）+ 逐参数 MdAPE | 中位带符号误差 | [P25,P75] | [P5,P95]、P95 | 有效估计率 |
| 工程应用视角 | MdAPE（每个可靠度R一个） | 中位带符号误差 | [P25,P75] | [P5,P95]、P95 | 同左 |
| 训练损失 | 非独立指标，是所选视角准确性指标的可微版本 | — | — | — | — |

### 8.3 各指标详解

**主指标 MdJRE（中位联合相对误差）**：三参数合成一个数，可直接排名

$$e_j = \sqrt{[(\ln\hat{\beta}_j/\beta)^2 + (\ln\hat{\eta}_j/\eta)^2 + ((\hat{\gamma}_j-\gamma)/\eta)^2] / 3}$$

$$\text{MdJRE} = \text{median}_j\ e_j$$

三参数各偏10%时 MdJRE 恰为10%，可直接读作"典型综合相对误差"。

**逐参数 MdAPE**：定位短板在哪个参数

$$\text{MdAPE}(\theta) = \text{median}_j |\hat{\theta}_j - \theta| / \theta \quad (\gamma\ 用\ /\eta\ 归一)$$

**方向指标**：判断高估还是低估

$$\text{Medrel}(\theta) = \text{median}_j (\hat{\theta}_j - \theta) / \theta$$

正值=系统高估，负值=系统低估。必须与幅度指标并列，不能互相替代。

**稳定性 [P25, P75]**：中间一半估计落在哪，反映可复现性

**尾部 [P5, P95] + P95(|e|)**：捕捉"有效但很烂"的解（MdAPE 和 IQR 看不见右尾）

**求解率**：有效估计的比例，门槛型指标，不参与排名

### 8.4 对04评估的具体建议

- **排序型指标**（用于方法间比大小）：MdJRE 或复合损失的中位数
- **警示型指标**（必须报告但不排名）：γ̂ 的带符号偏差（安全相关）、尾部 P95
- **通过型指标**（事先设阈值）：求解率应接近100%（MDM 在正确实现下基本都能收敛）
- **辅助指标**：RRMSE 经典分解（便于与文献对话），但不作主指标（会被异常解污染）

## 9. 待解决的核心问题（04 要做的事）

1. **把探针换成真正的神经网络**：多偏移读出特征 → 逐样本 c* 预测
2. **能否逼近 oracle（0.303）**？当前探针 0.707，作弊探针 0.513
3. **β̂ 纠缠问题的缓解**：网络能否直接输出偏移而不经过 β̂ 换算？
4. **损失可定制性**：按应用需求（γ 优先 vs β̂ 优先 vs 复合）调整训练损失
5. **泛化性**：在训练网格之外的 (β, n) 上表现如何
6. **部署成本**：推理时间 vs 精度提升的 trade-off
