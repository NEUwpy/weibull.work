# 01 结论：怎么评价参数估计准不准

## 推荐指标

对每个参数和寿命分位点，**成套报告三个指标**：

| 对象 | Bias | SD | RMSE | 补充 |
|------|------|----|------|------|
| β（形状） | ✓ | ✓ | ✓ | 可加相对偏差、相对RMSE |
| η（尺度） | ✓ | ✓ | ✓ | 可加相对偏差、相对RMSE |
| γ（位置） | ✓ | ✓ | ✓ | 加MAE、γ̂=0截断率；**禁用相对指标** |
| x₀.₉₅, x₀.₉₉（寿命） | ✓ | ✓ | ✓ | 可加相对偏差、相对RMSE |

## 注意事项

- RMSE相同可能掩盖不同的偏差-方差结构→先看误差分布图
- γ真值接近0时相对指标爆炸失真→γ只用绝对指标
- 参数视角和工程视角结论可能不一致→两套分开报
