# 三参数威布尔分布 MDM 方法最优梯度偏移量 δ 研究

本目录包含「如何确定最小差异法（MDM）中最优梯度偏移量 δ」的完整计算实验、
全部图表、实验数据，以及最终的 Word 研究报告。所有结果均由实际仿真生成，可完全复现。

## 一、核心结论（速览）

- σ_min(γ) 是「碗形 + 陡壁」结构，真实 γ 落在右侧上升翼上；经典 ∇=0（δ=0）因谷底平坦而失稳。
- 正向偏移 δ>0 把解点沿陡翼推到斜率 = δ 处，既稳定又能校正偏差。
- **最优 δ 存在但不唯一**：主要由形状 β 决定（β↑ 则 δ*↓，从 ~1.0 降到 ~0.05），样本量 n 次之，与尺度 η 无关。
- 默认 δ=0.1 仅在 β≈3 附近接近最优。
- 按 β 分层相对固定 0.1 平均降低归一化误差约 12%，数据驱动的自适应规则约 2–3%，逐样本理论上界约 31%。
- **实操三步法**：① 用 δ=0.1 跑一次得 β̂ → ② 据 (n, β̂) 查表/经验式 δ*≈1.0·β^(−1.8) 定 δ → ③ 用该 δ 重跑 MDM。

详见 `MDM最优偏移量研究报告.docx`。

## 三、实验设置

- 参数网格：n ∈ {5,10,20,30,50,100}；β ∈ {0.8,1.2,2,3,5}；γ/η ∈ {0,0.05,0.1,0.2,0.5}；
  共 150 组场景，尺度统一 η=100（另在子集测 η=50/200 验证不变性）。
- 候选偏移量：δ ∈ {0,0.01,0.03,0.05,0.08,0.1,0.15,0.2,0.3,0.5,0.7,1.0}（原始量纲；δ=0 为经典对照，δ=0.1 为基线）。
- 每组重复 R=300 次（不同随机种子）。
- 评价指标：归一化误差 NE = √[((β̂−β)/β)² + ((η̂−η)/η)² + ((γ̂−γ)/η)²]，
  并报告各参数 bias/RMSE、异常率、位置「贴边」率、严格根存在率。
- 聚合时对 NE 封顶（cap=3）后取均值以抗极端值，同时报告中位数。

## 四、如何复现

环境依赖：
- Python 3，包：numpy, scipy, matplotlib, pandas
- Node.js，包：docx（`npm install -g docx`）

复现步骤（在本目录下执行）：

```bash
# 1) 运行蒙特卡罗实验，生成 data/ 下原始与聚合结果
#    用法：python code/run_mc.py <样本量 n> [重复次数 R]；R 默认 250，本报告用 300
#    脚本每次跑一个样本量 n，便于在单核机器上分批执行
for n in 5 10 20 30 50 100; do
    python code/run_mc.py $n 300
done

# 2) 汇总分析：计算各层次最优 δ、策略对比、自适应规则、报告所用数据
python code/analyze.py

# 3) 生成全部图表到 figures/
python code/make_figures.py

# 4) 生成 Word 报告
node code/build_report.js
```

> 随机种子已固定，结果可重现；不同 BLAS / 平台下数值可能有极小差异，不影响结论。

## 五、关于 δ 的量纲

本研究采用**原始量纲**的 δ（即不对 η 归一化）。由于 σ_min 与 η 同量纲、γ 与数据同量纲，
斜率 dσ_min/dγ 无量纲，因此最优 δ 不随 η 变化（已由理论与实验共同确认）。
这意味着按形状 β（及样本量 n）选取的 δ 可直接迁移到不同尺度的数据。
