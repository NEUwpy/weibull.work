## 1　问题背景

三参数 Weibull 分布的累积分布函数为

$$F(t) = 1 - \exp\left[-\left(\frac{t-\gamma}{\eta}\right)^{\beta}\right], \quad t \ge \gamma$$

其中 β 为形状参数、η 为尺度参数、γ 为位置参数（最小寿命）。对应可靠度函数 R(t) = exp(−((t−γ)/η)^β)，可靠寿命分位 x_R = γ + η(−ln R)^{1/β}。

Weibull 分布是描述产品寿命最广泛使用的模型，在小样本场合的应用多于其他分布。参数估计的核心难点有三：

其一，**位置参数 γ 兼为分布支撑的下端点**，属端点参数估计，常规方法在此往往不够稳健，是三参数中最棘手的一个。其二，**小样本下准确性与稳健性差**。极大似然法（MLM）与最小二乘法（LSM）应用最广，但 Teimouri 等比较 12 种 Weibull 参数估计方法后指出，根据同一样本不同方法估计出的参数差异很大；由于误差过大且不稳定，参数估计方法在小样本场合的应用价值受到质疑。三参数 Weibull 的似然函数在 γ→样本最小值附近还可能发散，MLM 存在无解问题。其三，**极值判据本身的统计效应此前未被研究**：尽管"一阶导数等于零"的极值判据在参数估计中起重要作用，但样本不确定性如何影响极值判据的定位效果，在 MDM 原文之前未有人探讨——这正是 MDM 偏置判据的切入点。

## 2　最小差异法（MDM）核心原理（谢里阳等，2025）

### 2.1　尺度参数的伪估计量

对分布函数作变换，得到从样本值 t 到尺度参数 η 的映射：

$$\eta = \frac{t - \gamma}{\left[-\ln(1 - F(t))\right]^{1/\beta}}$$

设样本量为 n，升序样本值为 t_(1) ≤ t_(2) ≤ … ≤ t_(n)。原文用**秩估计法**（F 分布中位秩）估计各次序统计量对应的累积概率：

$$\hat{F}(t_{(i)}) = \frac{i}{i + (n+1-i),F_{2(n+1-i),,2i,,0.5}}, \quad i = 1,\dots,n$$

其中 F_{2(n+1−i),2i,0.5} 为相应自由度 F 分布的中位数。由此构造**尺度参数的伪估计量**：

$$\hat{\eta}_i = \frac{t_{(i)} - \gamma}{\left[-\ln(1 - \hat{F}(t_{(i)}))\right]^{1/\beta}}, \quad i = 1,\dots,n$$

称"伪"估计量，是因为它除样本值外还含未知参数 γ 与 β。

### 2.2　最小差异原理

伪估计量有一条关键性质：若代入的 γ、β 为真值且样本为理想样本，则 n 个 η̂_i 全部等于真实 η；若 γ、β 含误差 Δγ、Δβ，由

$$\Delta\eta(t) = \frac{t - (\gamma + \Delta\gamma)}{\left[(t-\gamma)/\eta\right]^{\beta/(\beta+\Delta\beta)}} - \eta$$

可知尺度参数计算值的误差不仅随 Δγ、Δβ 增大，且**对不同样本值 t 产生不同的误差**——即参数误差越大，由不同样本值算出的 n 个尺度估计值之间的差异（离散程度）越大。

由此得到**最小差异原理**：正确的位置参数和形状参数，使得根据各样本值估计出的尺度参数之间的差异最小。原文用 n 个尺度估计值的标准差 σ_η 表征差异。需要强调，这种规律是**统计意义上**而非确定意义上的规律（故称"统计最小差异原理"）——这是后文偏置判据的理论根源。

### 2.3　估计流程（搜索—判断）

整个估计通过对 (γ, β) 的二维搜索完成，不需要求解方程：

1. 设一系列候选位置参数 γ_j（从最小样本值 t_(1) 开始逐步递减）；对每个 γ_j，遍历一系列候选形状参数 β_k（如 0.10, 0.11, …, 20）。
2. 对每对 (γ_j, β_k)，由伪估计量公式得 n 个尺度估计值 η̂_i(γ_j, β_k)，计算其标准差 σ_η(γ_j, β_k)。
3. 固定 γ_j 对 β 取最小，得**条件最小标准差** σ_{η,min}(γ_j)（及对应的最优形状参数）。
4. 使 σ_{η,min}(γ_j) 达到全局最小的 (γ̂, β̂) 即为位置与形状参数的估计值。判断极小点位置时使用 σ_{η,min} 对 γ 的离散梯度：

$$\nabla\gamma = \frac{\sigma_{\eta,\min}(\gamma + \nabla\gamma) - \sigma_{\eta,\min}(\gamma)}{\nabla\gamma}$$

5. 得到 (γ̂, β̂) 后，尺度参数取 n 个伪估计的**平均值**以减小样本不确定性的影响：

$$\hat{\eta} = \frac{1}{n}\sum_{i=1}^{n} \frac{t_{(i)} - \hat{\gamma}}{\left[-\ln(1 - F(t_{(i)}))\right]^{1/\hat{\beta}}}$$

### 2.4　关键创新：极值判据中的偏置（offset）

**现象：** 理论上 σ_{η,min}(γ) 的梯度应在真实 γ 处为零，但由于样本不确定性，随机样本的梯度过零点与真值之间普遍存在偏离（可正可负），且极小点附近曲线近乎平坦，零点位置对样本波动极敏感。直接套用"梯度=0"判据时，部分样本的位置参数估计误差非常大。

**做法：** 将判据由"一阶导数等于零"改为"一阶导数等于一个大于零的小值"，原文取 **offset = 0.1**，即在梯度 ∇γ = 0.1 处定位 γ̂。其几何意义是把定位点从平坦的极小点移到其右侧一段斜率确定的位置，从而对样本波动更稳健。该做法的依据是大量案例显示**位置参数估计值误差具有非对称性**。

**效果（原文数值，真值 W(2.0, 1000, 1000)，n=7，30 个随机样本）：**

|方法 / 判据|位置参数估计范围|
|---|---|
|MDM，梯度 = 0（直接极值判据）|0 ~ 1475|
|**MDM，梯度 = 0.1（偏置判据）**|**463 ~ 1506**|
|极大似然估计|0 ~ 1691|
|最小二乘估计|0 ~ 1686|

即偏置判据把估计值散布范围大幅收窄，精度与稳健性显著优于 MLM/LSM 及无偏置的 MDM。代价是个别样本（含理想样本）的误差略增（如理想样本 −1.0% → +2.5%），但整体收益远大于损失。

**offset 取值的性质（开放问题）：** 0.1 是基于 120 个估计案例的经验值，并在近千个样本（总体形状参数 β∈2~5）上验证效果良好。最优偏置与分布特征（分散性、对称性等）和样本量有关，更恰当的取法尚待研究。

### 2.5　方法定位

MDM 的优点：原理简单、通过搜索实现、不需要求解方程、不会出现 MLM 那样的发散/无解问题，特别适合小样本三参数 Weibull 估计；且位置参数逼近真值的过程可见。其与传统方法共同的缺点：估计结果对样本不确定性敏感——偏置判据正是为缓解这一点而设。

## 3　offset-root 求解：机理、"无解"成因与推荐求解器

本节来自对 MDM 的独立重实现与追因研究（蒙特卡洛 2400 样本：η=100，β∈{0.5,1,1.5,2,3}，γ₀/η∈{0,0.1,0.5,1}，n∈{7,10,30}）。该实现相对原文有两处工程化偏离：秩位置改用 **Bernard 中位秩** F_i=(i−0.3)/(n+0.4)（对结论无定性影响）；γ 搜索显式加了 **γ≥0 下界**（这是"无解"现象的关键来源，原文从 t_(1) 往下搜、本无 0 下界）。

### 3.1　记号与判据形式化

记约化变量 x_i = −ln(1−F_i)，伪尺度 η̂_i(β,γ) = (t_(i)−γ)/x_i^{1/β}，其样本标准差为 σ(β|γ)。定义**廓线**

$$S(\gamma) = \min_{\beta} \sigma(\beta|\gamma)$$

内层关于 β 的目标在考察范围内呈单谷、最优点在区间内部，内层极小化稳定可靠（实现：β 用 500 点对数网格 + 抛物线顶点细化）。**offset-root 判据**为：求廓线梯度 g(γ)=S′(γ) 满足

$$g(\gamma) = \text{offset} = 0.1$$

的根，存在多根时**取最靠近 t_min 的根**作为 γ̂；回代得 β̂ 与 η̂ = mean_i η̂_i(β̂, γ̂)。

### 3.2　解析机理（已严格证明的部分）

**（i）σ² 是 γ 的上开口二次函数。** 固定 β，令 a_i = x_i^{1/β}、u_i = t_(i)/a_i、v_i = 1/a_i，则 η̂_i = u_i − γ·v_i，于是

$$\sigma^2(\beta|\gamma) = C_{uu} - 2\gamma C_{uv} + \gamma^2 C_{vv}$$

其中 C_uu、C_uv、C_vv 为 u、(u,v)、v 的（无偏）样本方差/协方差。顶点位于 γ_v = C_uv / C_vv。注意精确表述：**是 σ² 为抛物线，σ 本身呈 U/V 形而非抛物线**。

**（ii）真形状下的分解。** 在真形状 β₀ 处，记 ρ_i = (r_i/x_i)^{1/β₀}（r_i 为实现的约化次序统计量），有

$$\sigma^2(\beta_0|\gamma) = \eta^2,\mathrm{Var}(\rho) - 2(\gamma-\gamma_0),\eta,\mathrm{Cov}(\rho,v) + (\gamma-\gamma_0)^2 s_v^2,\qquad \gamma_v = \gamma_0 + \eta,\frac{\mathrm{Cov}(\rho,v)}{s_v^2}$$

（在反例上验证到 10⁻¹³ 量级）。**顶点恰落在 γ₀ 只在大样本极限下成立**；有限样本下顶点带偏移项。

**（iii）包络梯度与存在性。** 由包络定理，廓线梯度

$$g(\gamma) = \frac{\gamma C_{vv} - C_{uv}}{S(\gamma)}$$

在无约束可行域 (γ→−∞, t_min) 上**单调递增**，由 −s_v 经 0（在顶点 γ_v）升至 +s_v，其中判别量 s_v = √C_vv = std_i(x_i^{−1/β})。因此**只要 offset < s_v，方程 g = offset 必有唯一根**，且落在顶点右侧。s_v 仅依赖 β、n，在所考察范围内处处 ≫ offset=0.1（例如 n=10 时：s_v(β=0.5)≈64.0、s_v(1.0)≈4.26、s_v(1.5)≈1.63、s_v(2.0)≈0.96、s_v(3.0)≈0.52）。**即 s_v ≫ offset 保证 offset-root 几乎总存在**——实测 2400 样本 100% 可在 [−1.5η, t_min) 内找到根。

严谨性边界：上述 (i)–(iii) 已严格证明；把控制量等同于真形状下的 s_v(β₀) 用到了 β*(γ)≈β₀ 的近似，属"解析机理 + 数值验证"。

### 3.3　"无解"的三类成因（核心结论）

在人为约束域 [0, t_min) 内按严格 offset-root 判据搜索时，部分样本会报"无解"。2400 个样本在两段均匀网格（每段 k=20）下的归并：

|类别|含义|占比|
|---|---|---|
|正常有解|根落在 [0, t_min) 内，直接采用|**82.3%**|
|数值漏检（计算性）|根贴近 t_min、梯度陡峭，粗网格未分辨；加密即恢复|1.6%|
|**γ≥0 下界切除（约束性，主因）**|根存在但落在 γ*<0，被人为下界排除|**16.0%**|
|真正固有无解|整个 (−∞, t_min) 上无根（要求 s_v ≤ offset）|0.1%（2/2400）|

要点：

- **"无解"几乎从来不是方法的固有性质。** 99.7% 的"无解"样本属下界切除，其无约束根紧贴 0 的左侧（γ*/η 中位约 −0.08，第 5 百分位约 −0.45），绝大多数来自真值 γ₀=0 的层——估计只因抽样波动略微越过 0。
- **可解性对位移比 γ₀/η 极敏感**（γ₀/η=0 时基准有解率仅 52.7%，=1 时 100%），对 β 平缓（81%–88%）。机理：位移比越小，方差顶点 γ_v 越易滑到 0 左侧，约束域内只剩上升臂。
- **与原文"不会无解"并行不悖：** 原文指方法不依赖解方程、不会像 MLM 那样发散，且从 t_(1) 往下搜、无 0 下界，根可为负，本不遭遇此类切除。

### 3.4　数值漏检与网格选取

真实根随 n 增大**几何式贴近 t_min**（β=0.5、γ₀/η=0.3 时，根距 1−γ*/t_min 由 n=10 的 1.6×10⁻² 收缩到 n=200 的 4.2×10⁻⁸），均匀网格在此极不划算：n=200 时每段 k=20 的两段均匀网格有解率降至 0%。同一硬回归设置（β=0.5，γ₀/η=0.3，n=100）下的成本对比：单段均匀 2000 点仅约 59% 有解率；两段均匀约 240 次评估达 100%；**向 t_min 几何加密仅约 30 次评估即达 100%**。可解样本上估计精度随每段步数 k 收敛约为 1/k（双对数斜率 ≈ −0.9）。

### 3.5　推荐工程求解器："一次探测 + 括弧/Brent 定根 + 负则截断到 0"

利用梯度单调递增、且 γ→t_min 时 g→+∞ ≫ offset 两条性质：

1. **探测 g(0)：** 若 g(0) ≥ offset，由单调性知根 γ* ≤ 0，直接输出 γ̂ = 0（截断）；
2. **否则**根落在 (0, t_min) 内：以 γ=0（g<offset）与 γ = t_min(1−ε)（g≫offset）为括弧端点，用**割线/Brent 法**迭代定根，得 γ̂∈(0, t_min)。

性能（硬回归，300 次重复，中位）：**有解率 100%、评估次数约 20 次**（少于几何加密的约 31 次、远少于均匀网格）、**根定位误差 1.2×10⁻⁷**（比几何加密低约一个数量级）。根定位好之后各策略的估计误差 |Δγ|/η 趋于同一水平（约 7×10⁻⁵，为样本本身的统计涨落），即该方案以最低成本触到了精度下限——相对加密网格是**精度不降反升、成本显著下降**的合理简化。

**截断 vs 放开下界的精度（针对原"无解"样本）：**

|真值 γ₀/η|截断 γ̂=max(γ*,0) 的中位误差 \|γ̂−γ₀\|/η|放开下界取 γ* 的中位误差|
|---|---|---|
|0|≈ 0.000（近乎零误差）|≈ 0.073|
|0.1|0.100（封顶于真值本身）|0.216|
|0.5|0.500|0.625|

结论：**先验已知 γ≥0 时推荐截断**（截断仅在 γ*<0 时触发，误差被真值 γ₀ 封顶、可控可预估）；若场景允许负位置参数，则去掉截断、直接取括弧定根的 γ*（即原文做法）。无论哪条，都不应把这类情形当作"估计失败"，而应输出**结构化诊断**（根落点 γ*/η、是否触及下界）。

## 4　参数估计准确性评价体系

### 4.1　适用前提（先于一切指标）

**准确性只能在真值已知的场景下度量**：即蒙特卡洛仿真（从已知 (β,η,γ) 抽样再估计）与深度学习的仿真训练/评测（标签即真值）。真实工程数据上真值不可得，只能退而评**拟合优度**（K-S 检验、A-D 检验、概率图相关系数等）——它衡量"像不像 Weibull"，不是"参数准不准"，二者不可混为一谈。

**外部效度警告：** 蒙特卡洛若要为真实场景背书，其先验池（β,η,γ 范围）、样本量 n、删失比例必须与目标场景一致；否则"仿真里很准"不能推广到"真实数据上很准"。

### 4.2　总体框架：一个分布、三个视角、五类指标

对任一被估量 θ（参数或寿命分位），定义重复实验下的相对误差 e = (θ̂−θ)/θ。所有点估计指标本质上都在描述 e 的分布，故每个视角只需一个主指标加少量正交辅助，回答五个互不重叠的问题：

|问题|指标|公式 / 说明|
|---|---|---|
|有多大（准确性，主指标）|**MdAPE**|median_j \|θ̂_j−θ\|/θ；**γ 改用 η 归一**：MdAE(γ)/η = median\|γ̂−γ\|/η（γ 可能为 0，相对误差病态）|
|偏哪边（方向）|**中位带符号相对误差**|median_j (θ̂_j−θ)/θ（γ 用 /η）；正=系统高估，负=系统低估|
|有多散（稳定性）|**[P25, P75] / RelIQR**|相对误差的内 50% 区间；RelIQR=(Q3−Q1)/median(θ̂)|
|多深的尾（尾部风险）|**[P5, P95] 与 P95(\|e\|)**|必要时加 P99；中位+IQR 完全看不见右尾|
|算不算数（门槛）|**有效估计率**|有效 = 收敛 ∩ 非边界（γ̂ 未贴样本最小值）∩ 非异常 ∩ 数值有限；判定准则须实验前固定，其余指标**只在有效集上计算**|

设三个视角：**参数视角**（β、η、γ 各报上表一套）、**工程应用视角**（对寿命分位 x_R 报同一套）、**训练损失**（不是第四类独立指标，见 4.4）。

几条经过数值反例验证的设计决策（编号为来源材料的测试号）：

- **主指标用中位族而非均值族（T1b）：** 三参数 Weibull 似然在 γ→t_min 附近可发散、异常解时有发生；向无偏估计注入 2% 离谱解，MdAPE 仅 20.3%→20.8%，而 RRMSE 30.1%→59.1% 近乎翻倍。
- **幅度与方向必须分开报（T1、S4）：** 混合指标（如 RRMSE）会判"偏低 15% 但集中"的估计器优于"无偏但分散"的，掩盖致命系统偏倚；β 偏 +10% 与 −10% 给出完全相同的 |MdAPE|，却产生方向相反的寿命误差——只有带符号指标能识别"抬高寿命=危险"的一侧。
- **尾部指标是排序必需项而非锦上添花（T1c、S1）：** 可构造 MdAPE/方向/RelIQR 三项完全打平、但 P95(|e|) 相差 1.5 倍以上的两个估计器；80%集中+20%发散的混合估计器 MdAPE 仅 4.3%，而 P95(|e|)=69%。
- **不用加权综合分作主指标（S5）：** 不含尾部的综合分会系统性把"中心好但 10% 灾难"的危险方法排到"全程中等但尾好"的安全方法之前。分项展示，让尾部与有效率把关。
- **用相对/对数空间，不用原尺度（T2）：** 原尺度 MSE 中各参数的占比随时间单位（小时↔千小时）剧烈改变（β 占比 0.0006%↔86%），含义不稳定；相对空间恒约 33/33/33。
- **辅助陪跑：** RRMSE = √mean((θ̂/θ−1)²) 与经典偏差²–方差–MSE 分解（相对空间：MSE_rel = bias_rel² + var_rel）随附报告，便于与文献对话、与估计理论衔接，但不作主指标。
- **等价替代：** 中位 |ln(θ̂/θ)| 与 MdAPE 在误差 <20% 时数值几乎相同，且具乘法对称性、与 log 损失严格同空间，可任选其一并全程一致。

### 4.3　工程应用视角

被估量为可靠寿命分位 **x_R = γ + η(−ln R)^{1/β}**，对每个目标 R 报告与参数视角同一套指标。要点：

- **为何不可省略（T4）：** x_R 是 (β,η,γ) 的确定函数，但其误差取决于参数误差的**联合分布**（含相关性）。固定 β̂、η̂ 边际精度不变、仅改变误差相关系数 ρ（−0.8/0/+0.8），x_{0.99} 的 RRMSE 为 14.8%/21.3%/26.9%——逐参数指标完全相同而寿命误差近乎翻倍。
- **为何要多个 R（T5）：** 不同可靠度由不同参数主导（+10% β 在 R=0.999 处引起 11% 寿命变化、在 R=0.5 处仅 1.2%；+10% η 则相反）。标准化报告 **R∈{0.50, 0.90, 0.95, 0.99, 0.999}**。
- **R 必须与数据支撑挂钩（T6）：** 深尾分位误差主要来自外推而非方法本身（n=50 的 profile-MLE：x_R 的 MdAPE 从 R=0.5 的 4.4% 升到 R=0.999 的 49.7%，P95(|e|) 升到 144%）。经验规则：**目标尾概率 1−R 不应远小于 ~1/n**；不要报样本量撑不起的分位，否则会把外推困难误读成方法很差。
- **方向在高 R 处尤为关键（T6）：** profile-MLE 在深尾系统性高估寿命（n=50 时 x_{0.999} 的中位方向 +27.7%）——高估寿命即低估失效风险，是可靠性设计中偏危险的方向。
- **可选命中率（S3）：** 有明确容差 τ（如 ±10%）时加报 HR(τ)=P(|e|<τ)；相同 MdAPE 也可有不同命中率，它是与 MdAPE 正交、决策上最直观的轴。无明确容差时不必引入。

### 4.4　训练损失：所选视角准确性指标的可微投影

评价与训练同处**相对/对数空间**，只是聚合形态不同：评价用"中位数 + 绝对值"（稳健、可读），训练用"均值 + 平方"（可微、对尾部敏感）。平方损失的尾部敏感性恰好补上中位评价指标的尾部盲区，故损失不是第四类独立指标。

**基础损失（参数恢复视角）——log-参数 MSE：**

$$L_{\text{param}} = (\ln\hat{\beta}-\ln\beta)^2 + (\ln\hat{\eta}-\ln\eta)^2 + \left(\frac{\hat{\gamma}-\gamma}{\eta}\right)^2$$

**进阶损失（兼顾工程寿命）：**

$$L = \lambda,L_{\text{param}} + (1-\lambda)\sum_R w_R,(\ln\hat{x}_R - \ln x_R)^2,\qquad \lambda\in[0.5,0.7]\ (\text{默认 }0.5)$$

选 log-参数 MSE 的真正理由是**量纲不变性 + 与评价指标同空间 + 跨优化器稳健**（在 +10% 误差处，原尺度 MSE 对 η 的梯度约为对 β 的 450 倍；log 空间拉平）。诚实更正（T7）：在 Adam 等自适应优化器下，原尺度 MSE 并不会让 β"学不出来"，实际是权衡而非灾难（原尺度把精度堆在 η 上、牺牲 β；log 损失更均衡）。NLL 适合直接对原始/删失样本建模，可作补充损失，但当网络直接输出参数或寿命分位且评价用相对误差时与目标不在同一度量上；C-index 等排序型指标度量风险排序一致性而非数值准确性，不用。

### 4.5　落地清单（拿来即用）

参数视角：MdAPE（β、η 各一，γ 用 MdAE/η）+ 中位带符号误差 + [P25,P75] + [P5,P95]/P95 + 有效估计率。工程视角：对 R∈{0.50,0.90,0.95,0.99,0.999} 各报同一套，只报样本量撑得起的分位，高 R 重点看 P95 与方向；有容差时加命中率。训练：log-参数 MSE，需兼顾寿命时用加权式（λ 默认 0.5），原始/删失样本可加 NLL。全局随附 RRMSE 与偏差²–方差–MSE 分解。一致性检验（S2）：合格的指标体系应随 n 增大单调改善——profile-MLE 的 MdAPE 从 n=20 的 24.3% 单调降到 n=320 的 4.0%，本套指标全部通过。

## 5　研究衔接要点与开放问题

**推荐工作流（把三份材料串起来）：** 按目标场景设定先验池与 n →（含删失则一并设定）生成蒙特卡洛样本 → 用 §3.5 的工程求解器跑 MDM（一次探测 + 括弧/Brent + 截断，记录结构化诊断）→ 按 §4 的体系在有效集上报告参数视角与工程视角全套指标，RRMSE 陪跑 → 与 MLM/LSM 等基线在同一套指标下对比。

**实验设计中需事先明确的衔接细节：**

1. **截断解与"有效估计率"的关系：** 评价体系把"γ̂ 贴到样本最小值"列为边界解（无效），而 §3.5 求解器的截断输出 γ̂=0 是另一种边界触达。建议在实验协议中事先约定：截断解是否计入有效集、还是单列"截断率"并同时报告含/不含截断解的指标——这直接影响 MDM 与其他方法的可比性。
2. **秩公式的选择：** 原文用 F 分布中位秩，重实现用 Bernard 中位秩（影响量级为数个百分点、不改定性结论）；正式对比实验时应固定一种并显式声明。
3. **offset 的报告口径：** offset=0.1 是经验值，且其效果验证集中于 β∈2~5；若研究的 β 范围更宽（如 β<1 的浴盆早期失效区），应把 offset 敏感性纳入实验。

**开放问题（来自三份材料的明示）：**

- 最优 offset 的系统取法：与分布特征（分散性、对称性）和样本量 n 的定量关系（MDM 原文明示待研究）。
- offset-root 存在性证明中 β*(γ)≈β₀ 近似的严格化（目前为"解析机理 + 数值验证"）。
- MDM 向删失数据、其他分布族的扩展（材料未覆盖；评价体系的 NLL 补充损失已为删失场景留口）。
- 评价体系示例设定（β=2.5, η=1000, γ=100; n∈{20,50,100}）仅用于说明方法，落地须替换为真实场景设定。

**一句话总结：** MDM 用"伪尺度估计量差异最小 + 梯度=0.1 的偏置判据"以二维搜索完成三参数估计；其 offset-root 在 s_v≫offset 的保证下几乎总存在，所谓"无解"是人为 γ≥0 下界与网格分辨率所致，工程上用"一次探测 + 括弧/Brent + 负则截断"即可 100% 稳定求解；方法好坏的评判，则在真值已知的仿真中按"MdAPE + 方向 + 区间 + 尾部 + 有效率"五件套在参数与工程双视角下分项报告，训练时用同一空间的 log-MSE 可微版本。
