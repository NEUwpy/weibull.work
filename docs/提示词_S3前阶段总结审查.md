## 二、关键基础设施

### 2.1 统一评价指标（`python/studies/common/metrics.py`）

- **NE**（归一化综合误差）：gamma 用 eta 归一化，避免 gamma=0 时除零
- **NQE_R**（归一化分位点误差）：`|x_hat_R - x_R| / eta`，R ∈ {0.995, 0.990, 0.950, 0.900}
- **三态判定**：success / failure / outlier（NE > 1.0），互斥，failure 和 outlier 不进入精度均值但进入总分母

### 2.2 统一蒙特卡洛框架（`python/studies/common/`）

- `sample.py`：hashlib.sha256 种子策略，给定参数组合+样本量+编号可复现
- `runner.py`：统一调用接口，兼容 MethodResult/5 元组/4 元组，支持 MDM 变体函数表
- `experiment.py`：参数网格 × 样本量遍历，共享样本，保存逐条 CSV + 聚合 JSON

### 2.3 MDM 变体（`python/methods/mdm_variants.py`）

四种变体，81 个测试全部通过：

| 变体 | 行为 | 定位 |
|------|------|------|
| `mdm_offset_strict` | 无交点→failure | 诊断用 |
| `mdm_offset_constrained` | 无交点→边界最优解 | **默认 MDM** |
| `mdm_min_sigma` | 网格搜索最小 sigma | 敏感性对照 |
| `mdm_allow_negative_gamma` | 扩展到负 gamma | 仅诊断用 |

## 三、S4.7 核心研究结论

### 3.1 汇总表（3600 样本/变体，gamma/eta ∈ {0, 0.1, 0.5, 1.0}，n ∈ {7, 10, 30}）

| Variant | NE | fail% | out% |
|---------|------|-------|------|
| MLE (reference) | 0.379 | 32.3% | 13.9% |
| mdm_offset_strict | 0.419 | 16.8% | 4.4% |
| **mdm_offset_constrained** | **0.397** | **0.0%** | **5.1%** |
| mdm_min_sigma | 0.409 | 0.0% | **15.2%** |
| mdm_allow_negative_gamma | 0.396 | 0.0% | 7.5% |

### 3.2 按 gamma/eta 分组 outlier 率（关键对照）

| gamma/eta | MLE | strict | constrained | min_sigma | neg_gamma |
|-----------|------|--------|-------------|-----------|-----------|
| 0.0 | 3.7% | 1.8% | 2.0% | 2.8% | 4.6% |
| 0.1 | 4.7% | 3.1% | 3.4% | 3.4% | 7.6% |
| 0.5 | 19.0% | 4.9% | 6.9% | **21.4%** | 8.1% |
| 1.0 | 28.4% | 7.9% | 8.0% | **33.0%** | 9.8% |

min_sigma 在 gamma/eta=0.5/1.0 时 outlier 率飙升，核心原因：它倾向于选 gamma≈0，当真值 gamma 较大时产生系统性偏差。

### 3.3 failure 样本诊断

- 100% 的 strict failure 样本在离散采样点上 sigma 曲线单调非降
- 100% 的 strict failure 样本最小 sigma 在边界（gamma≈0）
- 有 4 个 failure 样本 grad_min - offset ≤ 0.001（边界很近）
- 因此不能说"永远不可能找到内点解"，只能说"在当前离散搜索下未发现内点交点"

### 3.4 已撤回的初版结论

- ~~"min_sigma 最优"~~ — 验证空间不足导致的假象
- ~~"success 样本都是 U 形"~~ — 39% 的样本 sigma 曲线单调非降
- ~~"MDM failure 是理论限制"~~ — 准确说法是 offset 判据内点条件不满足

## 四、S3 Loss 对比实验设计

### 4.1 实验目的

在正式训练 AI 模型前，用简单 M3 直接估计模型比较不同 loss 的影响，为后续 M1/M2/M3/M4 训练提供 loss 选择依据。

### 4.2 候选 Loss

1. **原始参数 MSE**：`MSE(β,η,γ)`，旧方法 baseline
2. **标准化参数 MSE**：参数误差做尺度归一化后 MSE
3. **NE-Loss**：与 NE 指标一致的归一化误差
4. **Huber Loss**：稳健版本，降低异常样本影响
5. **Quantile-Loss**：直接优化 R ∈ {0.995, 0.990, 0.950, 0.900} 的分位点误差
6. **Hybrid-Loss**：`α * Loss_param + (1-α) * Loss_quantile`，α ∈ {0, 0.25, 0.5, 0.75, 1.0}

### 4.3 实验控制

- 模型结构固定（MLP）
- 输入特征固定
- 训练集/验证集/测试集固定（使用 S4 统一样本框架）
- 优化器、学习率、batch size 固定
- 每种 loss 重复若干次，报告均值和方差

### 4.4 评价标准

- NE（参数视角核心指标）
- 各参数单独 RMSE 和 Bias
- NQE_R（分位点视角核心指标）
- Failure Rate、Outlier Rate
- **必须按 gamma/eta 分层看结果**，不能只看平均值

### 4.5 MDM baseline

S3 中传统方法 baseline 的 MDM 使用 `mdm_offset_constrained`（默认），同时保留 `mdm_min_sigma` 作为敏感性对照。
