## 二、关键基础设施

### 2.1 S2R 统一评价指标

实现文件：

- `python/studies/common/metrics.py`
- `src/lib/metrics.ts`
- `/help/metrics`

维护约束：

- 页面是可读规范，前后端模块是同口径实现。
- 修改任一公式、字段名或判定口径时，三处必须同步。
- 不允许在实验脚本里重新内联实现指标。

评价口径：

- 参数视角和工程分位点视角都先形成带符号相对误差分布。
- 参数视角：`beta`、`eta` 用自身归一化，`gamma` 用 `eta` 归一化。
- 分位点视角：`e_R = (x_hat_R - x_R) / x_R`，默认 R ∈ {0.50, 0.90, 0.95, 0.99, 0.999}。
- 核心输出：MdAPE、MedRel、P25/P75、RelIQR、P5/P95、P95(|e|)，必要时 P99(|e|)。
- 可用性：只保留 success/failure；误差很大但数值有效的结果进入尾部统计，不再提前剔除。
- 旧指标体系已废止，不再作为当前评价标准。

### 2.2 统一蒙特卡洛框架

- `sample.py`：hashlib.sha256 种子策略，给定参数组合+样本量+编号可复现。
- `runner.py`：统一调用接口，兼容 MethodResult/5 元组/4 元组，支持 MDM 变体函数表。
- `experiment.py`：参数网格 × 样本量遍历，共享样本，保存逐条 CSV + 聚合 JSON。

### 2.3 MDM 变体

| 变体 | 行为 | 当前定位 |
|------|------|----------|
| `mdm_offset_strict` | 无交点→failure | 诊断用 |
| `mdm_offset_constrained` | 无交点→边界最优解 | 旧口径默认候选，待 S2R 重算确认 |
| `mdm_min_sigma` | 网格搜索最小 sigma | 敏感性对照候选 |
| `mdm_allow_negative_gamma` | 扩展到负 gamma | 仅诊断用 |

## 三、S4.7 重算计划

旧口径下的 S4.7 结果只能作为历史材料。当前阶段不再使用旧表格给出正式排名。

S4.7 需要按 S2R 重新输出：

- 每个变体的 `valid_rate`、`failure_rate`；
- 参数视角的 MdAPE、MedRel、RelIQR、P95(|e|)；
- 分位点视角 R ∈ {0.50, 0.90, 0.95, 0.99, 0.999} 的同一组指标；
- 按 gamma/eta、n、beta 分层的方向偏差和尾部风险；
- MDM 曲线诊断：sigma 单调性、最小值位置、offset crossing、边界解比例。

旧口径曾提示 min_sigma 在高 gamma/eta 下有明显系统偏差风险。这个风险需要用 S2R 的 MedRel 和尾部分位重新确认。

failure 样本诊断仍然保留：

- strict failure 多数表现为 sigma 曲线单调非降；
- strict failure 的最小 sigma 常在边界；
- 因此不能说“永远不可能找到内点解”，只能说“在当前离散搜索下未发现内点交点”。

已撤回的初版结论：

- ~~“min_sigma 最优”~~ — 验证空间不足导致的假象
- ~~“success 样本都是 U 形”~~ — 成立范围不足
- ~~“MDM failure 是理论限制”~~ — 准确说法是 offset 判据内点条件不满足

## 四、后续 S3 Loss 对比实验设计

S3 应在 S4.7 S2R 重算完成后进入。

### 4.1 实验目的

在正式训练 AI 模型前，用简单 M3 直接估计模型比较不同 loss 的影响，为后续 M1/M2/M3/M4 训练提供 loss 选择依据。

### 4.2 候选 Loss

1. **原始参数 MSE**：`MSE(β,η,γ)`，旧方法 baseline。
2. **S2R 参数相对误差 MSE**：beta/eta 用自身归一化，gamma 用 eta 归一化。
3. **S2R 参数 Huber Loss**：对带符号相对误差使用稳健损失。
4. **S2R Quantile-Loss**：直接优化 R ∈ {0.50, 0.90, 0.95, 0.99, 0.999} 的分位点相对误差。
5. **Hybrid-Loss**：`α * Loss_param_rel + (1-α) * Loss_quantile_rel`，α ∈ {0, 0.25, 0.5, 0.75, 1.0}。

### 4.3 实验控制

- 模型结构固定（MLP）
- 输入特征固定
- 训练集/验证集/测试集固定（使用 S4 统一样本框架）
- 优化器、学习率、batch size 固定
- 每种 loss 重复若干次，报告均值和方差

### 4.4 评价标准

- 参数视角：MdAPE、MedRel、RelIQR、P95(|e|)
- 分位点视角：默认 R 水平下的 MdAPE、MedRel、RelIQR、P95(|e|)
- 可用性：Valid Rate、Failure Rate、失败原因
- 必须按 gamma/eta、n、beta 分层看结果，不能只看平均值

### 4.5 MDM baseline

S3 中传统方法 baseline 的 MDM 需等待 S4.7 的 S2R 重算确认。旧口径下 `mdm_offset_constrained` 是默认候选，`mdm_min_sigma` 作为敏感性对照候选。
