## 2. 当前产品能力

| 入口 | 当前行为与边界 |
|---|---|
| 过程量优化 | MDM 预测 26 个候选偏移量的损失，选离散最低点，再调用生产 MDM。计算卡片提供固定 `delta=0.10` 成对参照；预测损失不等于可观测真实误差 |
| 直接估计 | 保留原型接口，独立部署与风险证据另行验证；完成前不作为产品默认 |
| 自适应选择 | 保留页面入口；部署选择与回退规则未完成，不提供自动方法推荐 |

旧 M1-R1/M1-R2 页面、模型与“置信度”表述已退出产品入口。产品使用“过程量优化 / 直接估计 / 自适应选择”三类名称。

## 3. 研究成果进入产品的条件

一项策略进入 `/ai` 页面或生产 API 前，需要：

1. 对应边界清楚的研究问题，协议、数据身份、损失和失败合同可复核；
2. 与默认方法、最佳固定方法及必要简单规则在同一合同下比较；
3. 报告不确定性、失效区域和不可推广范围；
4. 明确拒绝或回退行为，并交付算法或模型版本、哈希及验证材料；
5. 产品文案与证据一致，预测收益不冒充样本真实误差。

新算法通过软件仓变更纳入稳定实现；新模型连同预处理、适用范围和验证材料交付。两仓不自动同步全部代码或研究结果，也不跨协议拼接排名。

## 4. 软件侧后续工作

- 复用共同输入、方法注册、风险评价和结果说明合同；
- 只接入已经有独立证据的策略，保留固定方法参照；
- 近似平局、域外或证据不足时，执行经过验证的拒绝或回退；
- 近期任务以[目标与待办](../04-目标与待办.md)为准。
