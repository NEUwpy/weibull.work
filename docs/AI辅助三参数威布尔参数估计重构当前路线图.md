## 2. 当前身份

当前主线不是旧的 `M1→M2→M3→M4` 功能堆叠，也不是用端到端网络替代传统方法。目标是形成：

> **仿真信息驱动、任务感知、风险导向，并能在信息不足时回退的三参数 Weibull 自适应估计策略。**

AI 可介入四类位置：选择方法、配置方法内部过程量、对齐工程目标、估计风险与可信度。每次只在受控条件下研究一个主要决策变量。

## 3. 当前科学证据

| 来源 | 已支持 | 尚不支持 |
|---|---|---|
| Study01 | MDM 内部 `delta` 存在样本级选择空间；Mean-Normalized-MLP 可恢复部分机会，代表性端到端比例尺度等变检查已通过 | 未训练样本量、连续参数空间、任意测量噪声或真实部署条件下的通用选择器 |
| Study02 | Q 对齐 $x_{0.95}$ 但造成跨寿命点失真；QCP 以 P 定义可行域，限制参数补偿并在三个预设寿命点恢复一致性 | 不依赖真参数的部署约束、完整寿命曲线支配、每个参数区域都赢 |
| Research04 | 直接神经估计在匹配域内有优势，低 $\beta$ 侧外推会反转；训练域扩大改善远点覆盖但牺牲局部精度，简单信号可识别部分高风险样本 | 已独立确认的部署阈值、区间可靠性或对所有传统方法的普遍替代 |
| 其他 Research | 表征、稳健求解和传统方法风险地形已提供支撑或机会证据；修正与截尾方向仍在复核或孵化 | 未经升级就直接成为产品推荐规则或论文主张 |

旧 M1-R1/M1-R2 页面、模型和“置信度”表述已退出产品入口。当前产品层使用“过程量优化 / 直接估计 / 自适应选择”三类名称；研究代号只保留在内部证据路径中。

## 4. 当前推进顺序

### A. 收口现有 Study

- Study01 的核心证据、正文 v1.5 和附录 v1.4 已形成；下一步是投稿信息、最终语言审查和可选真实案例决策。
- Study02 的 P/Q/QCP 核心证据和论文工作稿 v2.1 已形成并纳入 main；下一步是用户审阅和投稿级科学审查。

### B. 收口直接估计的使用边界

Research04 已完成域内/域外、样本量、训练域宽度、尺度等变和候选风险信号诊断。当前只补传统方法同协议比较、同宽训练窗口平移、一个简单回退规则的独立确认以及区间覆盖；证据闭合前，直接估计不作为产品默认。

### C. 从方法风险地形进入可观测选择

已完成 `Research/05 risk_landscape_v1`：在 160 个设计单元和 48,000 个共享样本中，真参数 cell 选择较最佳固定 MDM-0.1 改善 6.07% [4.85%, 7.30%]。这证明存在条件机会空间，但样本量单独没有选择收益，且真参数不可用于部署。

Research04 最小收口后，只用当前样本可观测信息，先比较最佳固定规则、少量等变统计量规则和可解释模型，检验能否识别以形状参数为主的风险分区。只有简单规则不足时才引入复杂模型。评价的是风险下降及其恢复的 oracle 比例，不是单独的分类准确率；在样本级策略稳定超过固定方法和 `n` 规则前，不建立新 Study。

### D. 加入校准、约束与回退

输出不仅包括动作，还包括预期收益、不确定性、适用域和回退方案。近似平局、域外或置信不足时，回到经过验证的固定方法。

### E. 最小化综合

只组合已经独立成立的模块；共同基线、单模块和最终组合必须在同一合同下复核。出现实质交互时再补实验，不默认收益相加。

## 5. 从研究到产品的门槛

一项策略进入 `/ai` 页面或生产 API 前，至少满足：

1. 对应一个已定义的 Study 或边界清楚的 Research；
2. 协议、数据身份、损失和失败合同可复核；
3. 超过默认、最佳固定和必要的简单规则；
4. 报告不确定性、失效区域和不应推广的范围；
5. 有明确回退行为，不能只返回“最佳”；
6. 产品文案与当前证据一致，不复活旧原型数字。

## 6. 产品层最小结构

人工智能方法的产品入口分为：

- **过程量优化**：方法已经确定，只选择方法内部过程量；当前 MDM 子页选择偏移量 `delta`。
- **直接估计**：从样本直接输出参数估计；Research04 已形成条件优势与失效边界证据，但部署阈值和区间证据尚未闭合，因此保留原型且不设为默认。
- **自适应选择**：在候选估计方法或策略之间作选择；在部署与回退证据完成前不提供自动推荐。

MDM 过程量优化在计算卡片中可切换“固定值 / AI优化”。AI 模式先输出 26 点预测损失曲线和建议 `delta`，再把建议值交给同一生产 MDM；详情页负责展示这次选择过程和适用边界，而不是复制一套参数估计实现。

```text
样本 + 工程任务
  → 适用域检查
  → 候选行动及其风险估计
  → 选择 / 拒绝 / 回退
  → 参数与工程量结果
  → 预期收益、不确定性和证据边界
```

平台需要逐步提供的是共同输入合同、候选方法注册、风险评价、决策回执和证据说明；不是先建一个庞大调度平台再寻找科学问题。

## 7. 非目标

- 不以增加网络、智能优化器或页面数量作为进展；
- 不把一个设计域内的结果包装成通用 AI 估计器；
- 不跨 Study 协议拼排名，不把历史原型当正式基线；
- 不提前给未来方向编号，也不为了组合而制造耦合；
- 不在科学证据形成前承诺“自动推荐最佳方法”。
