# 软件信息

## 建设目的

让网站用户查到功能用法、方法建设状态、更新计划和版本记录。指标定义和图表规范为各模块的结果解读提供统一依据。

## 准则

- 入口按用户要查的内容组织。使用指导回答怎么操作，建设状态回答哪些方法和功能已开放，更新计划按事项追踪进度，版本记录按版本追溯已发生的变更。
- 页面展示既有维护源的公开内容。各页来源、固定格式和维护检查见[帮助页数据来源](../../src/app/help/README.md#帮助页数据来源)。
- 指标和图表区分通用定义、展示范式与产品实际应用。术语、公式和实例的维护位置见[指标与图表规范](../../02-规则.md#5-指标与图表规范)。
