# 方法对比

## 建设目的

可以任选方法进行对比。

## 准则

- 方法对比可以使用同一批样本，也可以使用分布真值相同（β、η、γ 一致）的不同批次。不同批次的结果可以比较汇总统计。
- 解读时说明各批次的样本量、数据来源和统计口径。只有能确认各方法使用了同一组观测并逐项对应时，才称为逐样本配对比较。

## 现有页面的统计口径

现场模拟使用后端的有效数、失败数、偏差和样本标准差。失败率以全部尝试为分母，估计均值和密度图使用后端判定有效的同一批记录。历史分片按完整的三参数估计记录展示描述统计，标注有效率未核验。旧 CSV 缺少真值字段时，使用分片文件名中明示的真值。

预计算分片与现场模拟的现有入口见[模块说明](../../../06-模块.md#26-方法对比compare)。特定科研实验复用同一抽样与统计协议的要求见[对比实验要求](../../../python/studies/common/README.md#对比实验要求)。
