# 结果分析

## 建设目的

在给定的威布尔参数、样本量和方法设置下，查看逐次估计与误差分布，判断方法在这些条件下的表现。

## 准则

- 默认显示「预计算结果」，按已登记的组合直接读取已有蒙特卡洛结果。分布参数和样本量紧凑选择并联动，样本量与分布参数区分。
- 「现场计算」复用计算器卡片。用户在卡片上设定参数、样本量和组数，生成样本后对同一批样本做参数估计。计算器已生成的批次可以直接带入这张卡片，已有估计随批次展示。统计使用本次抽样参数作为真值。
- 两种来源共用 MDM 现有工作表版式。样本数据、逐次估计及其差值为主体，统计表和差值直方图直接放在下方。现场结果保留逐组状态和失败记录。
- 各方法复用页面、工作表、统计与图形。偏移量等特有设置由方法配置接入。实现及数据来源见[结果分析开发说明](../../development/applicability.md)。
