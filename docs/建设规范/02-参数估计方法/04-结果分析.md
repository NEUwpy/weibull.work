# 结果分析

## 建设目的

在给定的威布尔参数、样本量和方法设置下，查看逐次估计与误差分布，判断方法在这些条件下的表现。

## 准则

- 默认显示「预计算结果」，按已登记组合读取蒙特卡洛结果。参数与样本量用紧凑下拉联动，样本量用蓝色区分。偏移量等特有设置由方法配置接入。
- 「现场计算」复用[计算器卡片](../01-威布尔计算器.md#批量生成与卡片叠放)。已有批次连同估计带入，现场统计按该批实际抽样参数取真值，并保留逐组状态和失败记录。

## 工作簿与统计

- 两种来源共用现有工作表版式，完整样本、逐次估计及差值为主体，下方显示统计表和差值直方图。原 Excel 下载保留完整工作簿字节。
- 差值为估计值减真值，使用共享函数 `paramAbsoluteErrors`。正值暖红、负值蓝，保留正负号和数值。
- 统计仅计三参数均为有限数值的有效记录，显示计数。图和统计表使用同一批有效记录，SD 按[指标规范](../../../src/app/help/metrics/metrics-spec.ts)的样本标准差口径计算，分母为 `n−1`。

组件实现和数据入口见[结果分析开发说明](../../development/applicability.md)。
