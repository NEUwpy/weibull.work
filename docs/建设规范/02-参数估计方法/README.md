# 参数估计方法

## 建设目的

结合原论文和清晰的程序实现，查看估计过程、进行蒙特卡洛模拟，并比较任选的方法。

## 准则

- 切换方法时能继续查看对应功能，不必返回方法总览重新查找。
- 各Tab围绕自身目的组织内容，不反复展示“当前实现”“未复现范围”等声明和重复备注。
- 方法标题、功能导航和主要控件文字至少 16 px，表格数值、候选项、源码及其他辅助信息至少 14 px。用间距和结构控制密度。

方法实现的共同要求见[开发规则](../../../02-规则.md#24-方法页面与实现维护)。

计算过程的建设示例、步骤粒度和展示准则见[计算过程规范](03-计算过程.md)，实施与验收见[开发说明](../../development/method-pages.md#后续建设流程)。

## 方法选择与切换

方法总览、计算器选择器和方法子页面切换均用「分类名称＋具体方法卡片」，复用 [MethodTree](../../../src/components/shared/MethodTree.tsx) 和同一套容器宽度适配。直接展示二级方法。选择器允许直接选择具体方法。

总览保留分类说明，两个选择弹层省略说明并收紧分类栏。分类、方法和排列顺序来自[方法目录](../../../src/data/methods.json)。计算器是否开放按[建设状态](../../../05-状态.md#自动层级推导)生成的缓存判定。
