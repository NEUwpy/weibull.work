# 计算过程

## 建设目的

按求参步骤看懂本次参数怎样确定。各步与程序流程的相关步骤对应，用必要的图和数值代入，讲清横纵坐标、曲线依据、取值判据和得到的值，贴近原作者的求参思路。现有算法的补建和新增算法都按此目的执行。

## 准则

- 按求参阶段组织内容并标明对应的程序流程步骤。共享试算量、需要相互对照的图可同页展开。
- 主界面展示图、实际取值判据及本次数值。图示集中展示曲线、散点、参考线及控件，采纳点配合横纵向虚线读出坐标，边界和外推按实际分支标记。计算公式、坐标轴和符号解释集中放入标题旁的说明浮窗，默认收起，悬停或点击查看。浮窗先说明判据与图中量的计算，再解释坐标和符号。
- 实际怎样计算就怎样画。求解图使用本次算法实际求值、扫描和迭代记录，标出采纳值；连线帮助阅读，不为图形顺滑另加绘图采样或在已知参数附近加密。算法本身采用拟合时展示实际拟合结果，阶梯函数保留阶梯，不额外拟合展示曲线。
- 覆盖全部待估参数。回代、修正或取平均的步骤显示必要公式和本次数值代入即可，不为每个数额外造图；不能只列最终参数，也不必将每个操作数都铺在主界面。
- 保留方法各自有效的图和原作者的求参思路，不强套相同图式。有原文过程图时沿用其思路，无原图时据原文步骤与公式组织解释。MDM的三张图同页展开，先展示位置判据与条件形状的联动，再展示以采纳参数反算的伪尺度及其均值。
- 逐样本代入、权重和候选值放在对应步骤中按需查看。原始计算记录随接口结果返回，供绘图和核验使用。
- 说明只保留理解当前步骤所必需的内容；坐标、图例和公式已表达的内容不再写一遍，取值判据与结果合并呈现。工程说明及推导留在详情或相应文档，失败、边界、近似和过期状态仍须明确。
