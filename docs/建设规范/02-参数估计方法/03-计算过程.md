# 计算过程

## 建设目的

按原作者的求参步骤看懂参数怎样确定，用图和数值代入讲清曲线依据、取值判据和结果，并能追到现行源码。现有算法的补建和新增算法都按此目的执行。

## 建设示例与适用范围

2026-11-10 用户确认当前 MDM 计算过程为后续建设示例。新增方法、现有方法补建及计算过程重构均按本规范执行，参照 MDM 的步骤粒度、内容完整性和交互形式。各方法仍按自己的原文、求参顺序和数学判据组织内容；MDM 的六步及其梯度偏移算法不作为其他方法的固定模板。

本文件唯一维护内容与展示准则；建设顺序、数据与源码归属、组件实现和验收维护在[方法页面开发说明](../../development/method-pages.md)。原文与程序差异按[开发规则](../../../02-规则.md#24-方法页面与实现维护)处理。

## 步骤怎样划分

- 一个页面步骤回答一个完整的计算问题，产出一个可辨认的中间量、参数或结果。步骤名称写明所求对象，流程图、图像和代码共用步号。
- 服务于同一判据的操作放在同一步。求梯度、找夹区间、插值和采纳位置共同解释“γ 怎样确定”，不拆成数个来回切换的节点；代码视角仍完整显示实际执行顺序、判断及辅助函数。
- 独立的求参关系保留独立步骤。确定 γ 后回代求 β，再由二者反算 η，各自有输入与取值依据；不把这些压成一个笼统的“求三参数”。原方法确实联立求解时保留联立关系。
- 对理解结果有作用的样本准备、概率与坐标变换单独交代；循环体、函数定义、缓存、边界分支及诊断归入所属计算问题，不按每行代码或每次调用增加节点。

当前 MDM 展示了这一粒度：

| 步骤 | 本步要回答的问题 |
|---|---|
| 1. 准备样本 | 排序样本、经验概率和概率变换怎样得到？ |
| 2. 试算各位置的最小差异 | 给定试算 γ，怎样从标准差曲线取得条件形状和最小差异？ |
| 3. 按梯度偏移求位置 | 梯度怎样得到，怎样按 δ 找区间并插值采纳 γ？实际边界分支也在本步。 |
| 4. 回代位置求形状 | 固定采纳的 γ，怎样确定最终 β？ |
| 5. 反算尺度 | 怎样逐样本反算 ηᵢ，再由总和与样本数得到 η？ |
| 6. 汇总结果 | 三参数、拟合优度及求解状态是什么？ |

## 每步必须讲清什么

| 内容 | 要达到的程度 |
|---|---|
| 输入 | 样本、已知量、上一阶段结果及有效配置，说明本步实际使用什么。 |
| 判据或运算关系 | 先列决定取值的方程、极值、约束、停止条件或回代公式；不能只写“优化”“求解”等函数名。 |
| 图或数值过程 | 图中能指出取值位置；确定性回代、修正、求和与平均可用数值表和代入，说明这些数怎样算下来。 |
| 量的含义 | 横纵坐标、曲线、参考线、计算点及判据符号各是什么，曲线与各量依据什么公式得到。 |
| 输出与源码 | 标明本次采纳值和传给下一步的量，可切换到相同计算关系的现行代码。 |

所有待估参数都须走通上述关系，包括最后的尺度恢复。逐样本操作数、候选比较、权重来源及详细代入在本步按需查看，不能用最终参数表替代其形成过程。

## 图和数值怎样表达

- 中栏过程图共用绘图区比例、轴位和轴标签留白。纵轴标题按文字中心对齐纵轴中点。同一栏宽下，切换试算值、调偏移或聚焦范围时，图框和坐标轴位置固定，坐标范围、刻度与曲线随数据更新。并排的图对齐绘图区上沿，栏宽改变时按同一规则缩放。
- 优先沿用原作者过程图的思路；无原图时按原文方程与实际实现组织。坐标、曲线和参考线围绕该方法真实的极值、交点、残差、拟合或采纳判据选择。
- 实际怎样计算就怎样画。曲线读取本次实际扫描、求值或迭代记录，真实计算点同时画出；连线用于阅读，阶梯函数保留阶梯。算法本身有拟合时展示其实际拟合结果。
- 采纳点与实际求值点分清，配横纵向辅助线读数。插值交点、边界值和外推目标按本次真实分支标明，不能把虚拟梯度当成实际函数值。
- 默认显示全范围，可手动聚焦；悬停可读真实坐标及已有求值序号。采样是否等距、如何求导及如何取交点，以实际程序为准。
- 少量逐样本值优先用数值表和计算关系。MDM 尺度采用 ηᵢ 表、总和及均值代入，不为这几个值额外拟合分布、密度曲线或造一条连续趋势线。

## 多组样本的计算过程

- 整组与单组共用该方法的步骤、顺序和输入输出关系。可比较的实际求值曲线叠画，逐样本运算和汇总值可用表格。
- 准备样本统一用寿命散点图。横轴为寿命，纵轴每次重复占一行，按该组最小观测升序排列，同值按原始编号排列。每个实际观测画一个点，突出最小观测。有已知的真实起点时，标出 γ 真值及它到各组最小观测的距离。
- 图中排序只用于阅读。点选观测或在选择框指定某次重复时，按原始编号联动该次样本表、各步求值和结果。
- 页面提供单组样本和整组结果时，在顶部样本卡片位置切换数据来源，下方沿用同一计算工作区。
- 卡片叠层的生成、翻组和结果表交互归属[计算器规范](../01-威布尔计算器.md#批量生成与卡片叠放)。切入过程时复用该批真实记录并保持当前组；同一步中突出当前组曲线，其余组淡化。失败组保留状态，不补造曲线或估计值。

## 页面与交互

- 左侧流程图为总纲；中间共用工作区切换图像和代码；右侧共用当前步骤的判据、公式、输入输出。三栏标题共用顶距与行高，初始状态位于同一水平线；侧栏采用相同吸顶基准，空状态或计算提示不单独推低某栏标题。相同视角的各步在同一页连续阅读，不再用逐步 Tab 隐藏其他图。
- 自然滚动推进当前步骤并联动侧栏；节点点击定位步骤，鼠标进入或键盘聚焦并排内容时对应更新。切换图像与代码、展开收起侧栏后保持当前步骤及已输入的数据。
- 左右栏用小图标控制显隐。宽屏两侧默认各 300 px，可分别拖动分隔线调宽。空间不足时先收窄侧栏，再切换为两栏或单栏。两栏和单栏默认收起流程图，可从工具栏展开。单栏的公式和输入输出放在对应步骤下方。
- 图像／代码用轻量按钮切换，避免独占大区域的彩色切换块。中栏按可用宽度排栏，不同步骤的图可并排。表格两侧随栏宽留白，分组之间拉开距离。短表格可分组重复表头，保持原顺序，合计只列一次。
- 公式先给判据，再给判据中各量的计算与解释。正文左对齐、逐条留出间距，主公式连续编号且编号统一靠右；切换视角或同一步的计算分支保持编号稳定。
- 默认只展示理解本步所必需的内容。逐样本推导、符号详情、来源与工程备注按需展开，不重复叙述坐标、图例或已有公式，也不增加重复的“本次计算记录”区块。
- 修改可调过程量在原位自动重算，保留当前步骤及可读的上次结果，更新状态简洁显示，不弹出阻断阅读的“正在计算”窗口。失败、近似和过期状态仍须明确。

## 建设中应避免

- 为套版式删步骤、漏参数，或将一个判据拆成过细的导航；为统一外形改写其他方法的计算思路。
- 流程图、代码视角和图像视角各写一套步骤，或在 HTML／前端组件中另写一份方法判据和变量定义。
- 图只给示意线或最终点，却交代不出坐标、计算点来源和取值依据；以漂亮曲线掩盖真实的离散求值。
- 为顺滑额外等距补点、在已知参数附近加密、额外拟合展示曲线，或把候选连线称为迭代轨迹。
- 使用旧样本或旧配置的记录冒充当前结果，或在前端重新估计一套参数用于绘图。
