# 案例数据库

## 建设目标

逐篇核查当前网站正式书单，收录与威布尔参数估计有关的实测样本、试验数据、蒙特卡洛与数值模拟数据、估计结果汇总表和数据图。深度学习训练集、通用机器学习基准及与参数估计无关的图表不纳入本库。结果汇总表仍在收录范围内。

扫描得到的材料先进入整理清单，核对用途、性质和来源后再加入可查阅目录；扫描量不代表案例数或核查完成量。进度按范围内已整理文献、样本组和待补项核对。

## 记录方式

每份数据一条记录，以数据、性质、来源为主体，附稳定编号和简短名称。同一数据可有多个来源。数据记录统一放在外部数据根的 `cases/records/`，网站自动读取；逐篇核查记录单独放在 `cases/coverage/`，用于核对覆盖范围。

目录以样本组为条目。同一研究中成套使用的样本收在同一组，原始数组各自保留，不拆成多个外层条目；不因作者相同就合并不相关的研究。相关估计表、拟合图放回对应组。重复模拟的统计结果可独立为结果组。合并样本是组内派生视图，不另计独立样本。例如Hirose的五批试件记为五组样本，合并100点单列组内视图。

组名和成员名用简明中文，说明数据对象或用途；作者姓氏、方法缩写与原始符号可以保留。外层不使用原文行号、英文长图题或“样本1-1”作为名称，原图题和原始定位保留在详情出处。

`cases/index.json` 由现行数据记录自动生成，供目录快速读取。修订数据后重新生成索引，完整记录仍是数据值的唯一编辑入口。分组、选材和中文展示名只维护在 `scripts/case-catalog-selection.json`，经目录脚本生成外部 `cases/catalog.json`；未入该目录的扫描材料不进入公开目录、详情或计算器选项，原记录保留待整理。分组目录缺失或损坏时提示问题，不回退为全量扫描条目。

- 数据保留原始精度、顺序及表格结构。原始样本用数值数组；结果表保存逐格内容及原文表格；只有图形时保存原图定位；外部数据保留链接和说明。
- 性质记录实测、模拟、结果汇总或尚未确定，以及观测量、单位和完整／删失／分组等观测规则。原文未说明的字段留空或记未知。
- 来源连接当前库中实际提供该份数据的文献，记录表号、图号、页码或章节。题名、作者等题录按编号读取。
- 二次引用先关联现有转引文献，注明经该文转引，并保留原文给出的原始文献线索。补齐原论文后核对并追加来源，保留现有出处。

## 文件格式

每份数据一个 JSON 文件，包含 `id`、`name`、`data`、`nature`、`sources`。

`data` 接受数值数组，或以下载体之一：

- `{ "kind": "table", "rows": [["原表逐格内容"]], "html": "原文表格" }`
- `{ "kind": "figure", "asset": "相对原文的图片路径", "caption": "原图题" }`
- `{ "kind": "external", "description": "材料说明", "url": "原文提供的链接" }`

`nature` 包含 `kind`（`observed/simulated/result/unknown`）、`observation`（`complete/right_censored/interval_censored/grouped/summary/external/unknown`），按需补 `quantity`、`unit`、`note`。

`sources` 是数组，每项包含 `paper_id`、`location`、`relation`（`direct/secondary`）。转引时补 `original_reference`，核实并收录原论文后可补 `original_paper_id`。

分组目录为 `{ "schema_version": 1, "groups": [...] }`。每组包含 `id`、中文 `name`、`kind`（`observed/simulated/result`）、可选 `description` 及 `members`；成员只包含原记录 `id`、中文 `name` 和可选 `role`（`sample/derived/table/figure/external`），其中 `derived` 表示合并视图。每条记录只属于一组。具体提取与目录生成命令见[外部数据维护](../data/README.md#案例材料提取与核查)。

## 网站取用

页面分别提供实测数据、蒙特卡洛数据、估计结果三个入口，默认实测。案例按行列整齐排列，卡片展示数据名称、性质、简介和规模。名称只说明数据对象或试验，性质在标题下独立显示为标签，删失等附加性质保存在 `nature.tags`，组目录通过 `tags` 提供，不混入标题。搜索子样本或性质标签时显示所属组的卡片。

点击卡片在原目录上打开浮层。宽屏在侧栏切换组内数据，手机在顶部选择，数据、性质和出处显示在同一浮层。关掉浮层可继续浏览原目录，浏览器后退也能关闭。观测完整且数值符合现有计算入口的样本可直接带入威布尔计算器。删失表、结果表、数据图和外部数据可在浮层内查阅。计算器选择器沿用相同分组，既有样本和调用链接继续兼容。

批量组选择只包含独立样本，避免把合并视图与它的组成样本重复选入；合并视图仍可从案例页单独带入计算。

平台自行生成的验证样本明确注明平台生成，关联方法论文不充作样本来源；文献数值算例与重复抽样统计按正文说明区分，不把单个模拟样本称为整批蒙特卡洛试验。

## 核查

逐篇记录源稿身份、核查位置、收录记录 ID 和待补问题。网页能渲染只能证明显示有效；数值、表格和图文对应关系仍据原论文核对。缺原值、原论文或有 OCR 歧义的条目保留具体待补说明。
