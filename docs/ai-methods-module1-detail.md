## 一、目标

建立"样本数据 → 最优偏移量 δ"的映射关系。当用户有一组失效数据时，AI 可以直接给出 MDM 方法应使用的最佳 δ 值，无需人工反复尝试。

---

## 二、整体流程

```
┌─────────────────────────────────────────────────────────┐
│                    离线阶段（系统外）                      │
│                                                         │
│  1. 蒙特卡洛模拟生成样本                                   │
│     (β, η, γ, n) → Weibull 样本                          │
│                                                         │
│  2. 对每个样本，遍历 δ 值网格                               │
│     δ ∈ {0.01, 0.02, ..., 0.50}                         │
│     每个 δ 运行 MDM → 得到 est_β, est_η, est_γ           │
│                                                         │
│  3. 评估每个 δ 的估计质量                                   │
│     计算精度指标 → 选出最优 δ*                              │
│                                                         │
│  4. 训练神经网络                                           │
│     输入: 样本数据                                         │
│     输出: 最优 δ*                                         │
│                                                         │
│  5. 导出训练好的模型                                        │
└─────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    在线阶段（系统内）                      │
│                                                         │
│  用户输入样本 → API 调用 → 模型推理 → 输出最优 δ           │
│  用户使用该 δ 运行 MDM → 得到参数估计结果                   │
└─────────────────────────────────────────────────────────┘
```

## 三、训练数据生成

### 3.1 基于现有 simulate.py 改造

现有 MDM simulate.py 的核心流程：
1. 从 config.md 读取参数配置
2. 对每组 (β, η, γ, n) 组合，生成 MC 次蒙特卡洛样本
3. 对每个样本运行 MDM（固定 δ），记录估计结果
4. 输出分片 CSV + 索引

**改造方向**：在第 3 步中，不再固定 δ，而是遍历多个 δ 值，记录每个 δ 的估计结果，最终选出最优 δ。

### 3.2 改造要点

| 项目 | 原 simulate.py | 新 generate_training_data.py |
|------|---------------|------------------------------|
| δ 值 | 固定一个 δ | 遍历 δ 网格 |
| 每个样本的输出 | est_β, est_η, est_γ, bias, r2 | 每个 δ 的 est_β, est_η, est_γ + 最优 δ* |
| 目的 | 展示方法在不同参数下的表现 | 生成训练数据供神经网络学习 |
| 输出格式 | chunks（按参数组合分片） | 训练数据集（样本 → 最优 δ*） |

### 3.3 训练数据格式

每条训练数据：

```
输入特征:
  - sample: [t1, t2, ..., tn]  （排序后的失效时间）
  - n: 样本量

输出标签:
  - optimal_delta: δ*  （最优偏移量）
```

CSV 格式示例：
```csv
n,t1,t2,t3,t4,t5,t6,t7,optimal_delta
7,12.5,23.1,45.6,67.2,89.3,112.4,156.7,0.15
7,8.2,15.7,31.4,52.8,78.6,105.3,142.1,0.12
...
```

### 3.4 参数空间

需要确定的参数范围（待讨论）：

| 参数 | 范围 | 说明 |
|------|------|------|
| β (形状参数) | 待定 | 影响分布形态 |
| η (尺度参数) | 待定 | 影响分布尺度 |
| γ (位置参数) | 待定 | 影响分布位置 |
| n (样本量) | 待定 | 影响估计难度 |
| δ (偏移量) | 待定 | 搜索网格 |
| MC 次数 | 待定 | 每组参数的模拟次数 |

### 3.5 "最优"评价标准

**待讨论**。可能的方案：

| 方案 | 定义 | 优点 | 缺点 |
|------|------|------|------|
| A. MSE(β,η,γ) | 三个参数的均方误差之和 | 综合考虑所有参数 | 可能掩盖单个参数的偏差 |
| B. MSE(β)+MSE(η) | 只看形状和尺度参数 | 避免 γ 的不稳定性 | 忽略了位置参数 |
| C. 加权 MSE | w1·MSE(β)+w2·MSE(η)+w3·MSE(γ) | 可调节各参数权重 | 需要确定权重 |
| D. R² 均值 | 平均拟合优度 | 直观 | 可能不反映参数精度 |
| E. 自定义 | 用户指定的公式 | 灵活 | 需要设计 |

**建议**: 先用方案 A（MSE）做原型，后续根据效果调整。

## 四、神经网络设计

### 4.1 变长输入处理

已确认：**按 n 分别训练独立模型**。

- n=5 训练一个模型
- n=10 训练一个模型
- n=20 训练一个模型
- ...

每个模型的输入维度固定 = n，无需处理变长问题。

### 4.2 网络架构（待讨论）

**方案 A: 全连接网络（MLP）**
```
输入层 (n 个神经元)
  ↓
隐藏层 1 (64 或 128 个神经元, ReLU)
  ↓
隐藏层 2 (32 或 64 个神经元, ReLU)
  ↓
输出层 (1 个神经元, Sigmoid → 缩放到 δ 范围)
```
- 优点：简单、训练快、容易部署
- 缺点：可能无法捕捉样本的排序/结构信息

**方案 B: 1D CNN**
```
输入层 (n 个值, 视为 1D 序列)
  ↓
1D 卷积层 (提取局部特征)
  ↓
池化层
  ↓
全连接层 → 输出 δ
```
- 优点：可以捕捉局部模式
- 缺点：样本量小时优势不明显

**方案 C: 简单统计特征 + MLP**
```
输入: [t1, t2, ..., tn, mean, std, min, max, range, cv, ...]
  ↓
全连接网络 → 输出 δ
```
- 优点：输入更丰富，网络更简单
- 缺点：需要手工设计特征

**建议**: 先用方案 A（全连接）做原型，简单有效。

### 4.3 框架选择（待讨论）

| 框架 | 优点 | 缺点 |
|------|------|------|
| PyTorch | 灵活、社区大、部署方便 | 需要额外依赖 |
| TensorFlow/Keras | 部署简单、TFLite | 较重 |
| 纯 NumPy 手写 | 无额外依赖、可控 | 实现复杂、功能有限 |
| scikit-learn MLPRegressor | 简单、依赖少 | 灵活性有限 |

**部署考虑**: 模型最终放在 python/ 后端，通过 API 调用。需要考虑：
- 后端依赖是否增加
- 模型加载速度
- 推理速度

## 六、已确认的设计决策

| 决策 | 内容 |
|------|------|
| **最优评价标准** | MSE(β,η,γ) — 三参数均方误差之和 |
| **神经网络框架** | PyTorch (CPU 版本) |
| **网络架构** | 全连接 MLP: Linear(n,64)→ReLU→Linear(64,32)→ReLU→Linear(32,1)→Sigmoid |
| **数据预处理** | 输入标准化（零均值、单位方差），目标缩放到 [0,1] |
| **参数空间** | 精简方案：β∈{1,2}, η=1000, γ=0, n∈{5,10}, δ∈[0.01,0.50] |
| **MC 次数** | 200 |
| **模型格式** | .pth (PyTorch state_dict + scaler_params) |
| **训练数据规模** | n=5: 309 条, n=10: 289 条, 总计 598 条 |

### 待扩展

- **参数空间扩展**: 后续可增加 β、η、γ 的取值范围
- **模型格式**: 可考虑 ONNX 导出以减少 PyTorch 依赖
- **性能对比**: AI δ vs 固定 δ 的蒙特卡洛对比
