## 一、研究目的

### 1.1 现状

MDM（最小差异法）中，偏移量 δ 是关键过程参数：

```
梯度曲线 ∇(γ) - δ = 0  →  交点就是最优 γ  →  进而得到 β, η
```

δ 控制在梯度曲线的哪个位置"切割"来找到 γ。δ 选得不同，交点位置不同，最终 β, η, γ 全部不同。

### 1.2 问题

1. **δ 选多少？** 赋予 δ 一个较小的值可以保证 γ 取值更为合理，但赋予什么值最好？相比其它好多少？
2. **不同样本最优 δ 是否不同？** 影响多大？怎么确定最佳 δ？

### 1.3 尝试方向

用神经网络建立"样本 → 最优偏移量"间的关系。

### 1.4 核心瓶颈

1. **"最优"是相对于真值而言的**，而实际使用中我们不知道真实参数。如果知道真值，就不用估计了。
2. **何为"最优"？** 应该根据什么制定指标？

### 1.5 两条研究路线

针对核心瓶颈，提出两条路线：

**路线 1：蒙特卡洛模拟（直接学习）**

```
蒙特卡洛模拟（已知真值）→ 学习"样本 → 最优δ"的规律 → 推广到实际数据
```

- 本质：在已知真值的模拟环境中学习映射，然后假设规律可推广
- 隐含假设：模拟参数空间足够覆盖真实应用场景
- 神经网络作用：建立"样本 → 最优δ"的直接映射

**路线 2：迭代逼近**

```
样本 → 初始δ₀ → MDM → 预估(β̂,η̂,ŷ)
     → 把预估当"真值" → 神经网络(真值→最优δ) → δ₁
     → MDM → 新预估 → ... → 收敛
```

- 本质：用 MDM 自己的估计结果作为真值的近似，迭代逼近
- 神经网络作用：学的是"真值 → 最优δ"的基础映射
- 区别：路线 2 绕过了"样本 → 真值"这一步，用迭代把预估不断逼近真值

### 1.6 神经网络分支结构

```
公共基础：神经网络 N₁  (β,η,γ) → 最优δ  （真值→最优偏移量映射）
  │
  ├── 路线 1：神经网络 N₂  样本 → 最优δ  （直接学习，单独训练）
  │   └── 用户输入样本 → N₂ → δ* → MDM → β,η,γ
  │
  └── 路线 2：使用 N₁ + 迭代
      └── 用户输入样本 → δ₀=0.5 → MDM → (β̂,ŷ,ŷ) → N₁ → δ₁ → MDM → ... → 收敛
```

- N₁ 学的是"真值 → 最优δ"，这是通用映射
- 路线 1 的 N₂ 是单独的，学的是"样本 → 最优δ"
- 路线 2 复用 N₁，通过迭代逼近

## 三、两条路线设计

### 3.1 路线 1：直接学习

```
训练阶段：
  蒙特卡洛模拟（已知真值）
    → 对每个样本遍历 δ 网格
    → 用指标选出最优 δ*
    → 训练 N₂：样本 → δ*

使用阶段：
  用户输入样本 → N₂ → δ* → MDM → β,η,γ
```

### 3.2 路线 2：迭代逼近

```
训练阶段：
  蒙特卡洛模拟（已知真值）
    → 对每个样本遍历 δ 网格
    → 用指标选出最优 δ*
    → 训练 N₁：(β,η,γ) → δ*  （真值→最优δ）

使用阶段：
  δ₀ = 0.5（固定初始值）
  loop:
    MDM(δₖ) → (β̂ₖ, η̂ₖ, γ̂ₖ)
    if MDM 返回 no_intersection → 停止，返回上一步结果
    N₁(β̂ₖ, η̂ₖ, γ̂ₖ) → δₖ₊₁
    if |δₖ₊₁ - δₖ| < 0.001 → 收敛，停止
    if k ≥ 10 → 达到最大迭代，停止
  返回最终的 (β̂, η̂, γ̂) 和迭代历史
```

### 3.3 共享的训练数据

两条路线用同一批蒙特卡洛模拟数据，但训练不同的网络：

| 网络 | 输入 | 输出 | 训练数据来源 |
|------|------|------|-------------|
| N₁（公共） | (β, η, γ) 真值 | 最优 δ* | 同一批模拟数据 |
| N₂（路线1） | 样本 [t1,...,tn] | 最优 δ* | 同一批模拟数据 |

## 四、指标方案（已确认）

设置多种方案做对比：

| 方案 | 公式 | 特点 |
|------|------|------|
| A. MSE 绝对值 | (β̂-β)² + (η̂-η)² + (ŷ-γ)² | 简单直接 |
| B. 相对 MSE | (β̂-β)²/β² + (η̂-η)²/η² + (ŷ-γ)²/γ² | 消除量纲影响 |
| C. 加权 MSE | w₁(β̂-β)² + w₂(η̂-η)² + w₃(ŷ-γ)² | 可调权重 |
| D. 仅 β+η | (β̂-β)² + (η̂-η)² | 排除不稳定的 γ |
| E. R² | 1 - SS_res/SS_tot | 拟合优度 |

> 注：β∈{1,2,5}，η∈{100,1000,5000}，γ=1000，量纲差异大。方案 B 特别值得考虑。

## 五、网络架构与训练策略（已确认）

### 5.1 N₁ 架构（真值 → 最优δ）

```
Linear(3, 32) → ReLU → Linear(32, 16) → ReLU → Linear(16, 1) → Sigmoid
```

- 输入：(β, η, γ) 标准化后的 3 维向量
- 输出：δ* 缩放到 [0,1]
- 输入标准化：按列零均值单位方差（从训练集计算参数）

### 5.2 N₂ 架构（样本 → 最优δ）

```
Linear(n, 128) → ReLU → BatchNorm1d → Linear(128, 64) → ReLU → BatchNorm1d → Linear(64, 1) → Sigmoid
```

- 输入：排序后的失效时间 [t1,...,tn]，标准化
- 输出：δ* 缩放到 [0,1]
- 按 n 分别训练（n=5/7/15 各一个模型）
- 加 BatchNorm 稳定训练

### 5.3 训练超参数

| 项目 | 值 | 说明 |
|------|-----|------|
| 优化器 | Adam | 原型已验证有效 |
| 初始学习率 | 0.001 | 比原型 0.01 更保守 |
| 学习率调度 | ReduceLROnPlateau(patience=10, factor=0.5) | 验证损失不降时自动降低 |
| 批次大小 | 64 | 数据量增大后的合理选择 |
| 最大 epoch | 300 | 给足够训练时间 |
| 早停 | patience=30 | 比原型宽松，避免过早停止 |
| 验证比例 | 20% | 保持不变 |
| 损失函数 | MSE | 预测 δ 的均方误差 |

### 5.4 数据预处理

- **N₁ 输入**：(β, η, γ) 按列标准化为零均值单位方差
- **N₂ 输入**：[t1,...,tn] 按列标准化为零均值单位方差
- **输出**：δ 从 [0.01, 0.50] 线性缩放到 [0, 1]
- 标准化参数从训练集计算，保存到模型文件中

### 5.5 验证策略

- 80/20 随机划分
- 可按 (β, n) 组合分层抽样，保证每个组合在验证集中有代表
- 同一 MC 种子的样本不重复出现在训练和验证集中

### 5.6 多指标评估

- 训练时用 MSE 作为损失函数（可微分）
- 评估时用 5 种指标分别计算（MSE/相对MSE/加权MSE/仅β+η/R²）
- 对比时看不同指标下的表现差异
