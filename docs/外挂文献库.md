# 外挂文献库

软件负责解析、展示、筛选和问答取材，资料独立保存。`WEIBULL_LIBRARY_ROOT` 未配置时使用仓内 `src/content`、`public`、`src/data/references.json`；配置后仅使用指定库，不与内置资料拼接。算法说明、案例、提示词和研究结果按原位置管理。

**本机状态（2026-10-27）**：忽略的 `.env.local` 已配置 `WEIBULL_LIBRARY_ROOT=D:/weibull-data/literature`，日常服务已切换并验证。新增、修改文献使用该库；内置资料保留作回退与既有证据。NAS 线上尚未切换，本机 D 盘也不会自动同步到 NAS。

日常操作见[文献库 README](library/README.md)，文献整理见[格式规范](library/文献格式.md)及[模板](library/templates/文献模板.md)。版本源在软件仓 `docs/library/`，资料库根携带同版说明和模板；不要继续维护旧路径下的第二份实时文献库。

## 选择与回退

在本地 `.env.local` 写入以下行后重启前端；该配置不提交 Git。其他机器自行选择其资料路径。

```dotenv
WEIBULL_LIBRARY_ROOT=D:/weibull-data/literature
```

路径必须为绝对路径，库内须有 `library.json`、`content/`、`assets/` 和 `references.json`。配置错误明确报错，不自动回退。取消该配置及同名进程环境变量后重启，即使用保留的内置库。当前库内新增、修改正文或引用表后刷新即可，不需重建；构建机无需持有外挂资料。

## 初次导出与核验

以下是初始化示例，**不要对当前已存在的库重复导出**。在软件根运行，目标父目录须存在，目标库须尚不存在：

```powershell
node scripts/library-data.mjs export --source-root D:\weibull --destination D:\weibull-data\literature
node scripts/library-data.mjs check --root D:\weibull-data\literature --verify-export
```

`export` 原字节复制编号文献、文献资源目录和引用表，生成格式描述及初次哈希清单；不复制算法说明、环境变量或科研材料，也不会自动附带 `docs/library/` 的说明和模板，需另行复制。工具不覆盖已有库，不修改源文件。

`--verify-export` 仅验证初次导出清单；之后有意修改原文献会报告差异，新文献也不在旧清单内。日常检查用 `check --root <库路径>`，资料库另行备份；软件 Git 不能替代资料备份。

## NAS 挂载

先把核验后的库复制到 NAS，在 NAS 配置 `WEIBULL_LIBRARY_HOST_PATH` 为宿主机目录，再运行：

```bash
docker compose -f docker-compose.yml -f docker-compose.library.yml up -d --build
```

可选 Compose 将库只读挂入前端；更新资料由宿主机导入。默认 Compose 保持内置模式，本轮未连接或部署 NAS。

解析入口是 `src/lib/server/literature.ts`，导入工具是 `scripts/library-data.mjs`。首次复制、独立服务和浏览器验证记录在 `D:\weibull-backups\external-literature-20261027`；切换过程见[任务记录](../coworker/plans/2026-10-27-external-literature.md)。
