# 组会汇报

本目录用于准备仍在进行、需要通过 Git 跨设备协同的组会汇报。它不是论文或正式实验的事实源；研究结论和数值应链接到对应的 `Study/`、`Research/` 或正式产物，不在这里另建一套证据。

## 使用方式

- 每次正在准备的汇报直接建立日期目录，例如 `2026-08-组会阶段汇报/`，其中的汇报稿、最终图表和待确认内容由 Git 同步。
- 可由代码重建的中间图、缓存、重复导出和临时检查文件放入该次汇报的 `_local/`，不进入 Git。
- 组会结束且不再需要跨设备协作后，将整个日期目录移入 `已完成/`。该目录只在本机保留并由 Git 忽略。
- 导师意见如果改变论文或实验决策，应同步回对应项目的权威文档；本目录不替代项目记录。
