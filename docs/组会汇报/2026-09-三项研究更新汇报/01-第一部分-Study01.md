# 第一部分：MDM 方法中偏移量的自适应调整

> 第3—11页，约10分钟；另附备查页A1。页码与指定PPT对应。页面保留证据，讲稿简要说明每一步怎样引出下一步。

## 第3页｜已有经验值0.1，偏移量还能怎样选得更好？

**页面上写**

MDM 的前期研究引入正偏移量 $\delta=0.1$，改善了三参数 Weibull 小样本估计。

**本文研究：这个经验值在什么条件下合适？真参数未知时，能否根据当前样本进一步选择偏移量，提高参数估计精度？**

**讲稿**

这个工作之前讲过几次，这次主要把最后形成的逻辑和结论讲清楚。已有MDM用0.1改善了小样本估计。我们先检查，换一个统一值还能改善多少；再看参数条件和样本差异能不能提供更多选择依据；最后检验，仅看当前样本能不能把这些信息用起来。

## 第4页｜当前参数域中，0.1已接近最佳统一偏移量

**页面上写**

在当前完整参数设计中，扫描 $0,0.02,\ldots,0.50$ 共 26 个候选偏移量，比较汇总联合误差。

| 偏移量 | 联合误差 $J_1$ | 结果 |
|---|---:|---|
| 0 | 0.9481 | 无偏移基准 |
| 0.06 | 0.624518 | 当前完整设计的最低扫描点 |
| 0.10 | 0.630409 | 仅比最低值高约 0.93% |
| 0.50 | 0.7619 | 继续增大后误差回升 |

![偏移量与条件偏差方差分解](assets/study01/fig2_offset_risk_decomposition_v112.png)

**结论：当前宽混合参数域中，0.1 已接近最佳统一值，单纯更换常数的收益有限。**

组合内偏差—方差分解进一步表明：正偏移量降低抽样方差，但过大时偏差代价增加，形成风险折中。

**讲稿**

首先做最直接的检查：把 26 个候选值都扫描一遍。当前参数域里的最低点是 0.06，但 0.1 的误差只比它高约 0.93%，所以更换统一常数带来的收益有限。右侧分解说明，偏移量在偏差与方差之间形成折中，继续增大后误差回升。接下来就问：如果限定的参数空间发生变化，最佳统一偏移量是否也会改变？

## 第5页｜参数空间改变后，最佳统一偏移量随之改变

**页面上写**

**研究目的：检验最佳统一偏移量是否依赖所限定的参数空间。**

统一偏移量是在给定参数空间及其设计权重下，使汇总风险最低的取值。

**实验：** 保持形状参数窗口宽度不变，将窗口由 $[1.50,2.50]$ 平移至 $[4.00,5.00]$，比较各窗口的风险曲线及其最低点。

![固定宽度参数域与统一取值](assets/study01/fig3_beta_domain_restored_3d.png)

**参数空间位置改变后，最佳统一偏移量也发生变化。** 本次平移实验中，其取值由0.18移至0.04。

**含义：** 不同子域的风险折中不同；面向较大参数空间时，统一值取决于各子域风险的汇总。扩大或移动覆盖范围可能改变这一折中，需要重新评价。

**讲稿**

这里想验证的是，最佳统一偏移量是否会随着参数空间改变。它本来就是在一个限定空间里求平均风险最低的值，所以我们固定窗口宽度，只移动位置，看最低点是否变化。结果确实变了，0.18到0.04是这次实验的具体表现。实际应用可能覆盖更大的空间，而大空间的汇总风险由其中各部分共同决定。既然不同子域的风险折中不同，扩大或移动覆盖范围后，原来的统一值就需要重新检查。接下来进一步问：能不能根据这些参数条件分别选择？

## 第6页｜按参数条件选择，比只按样本量调整收益更大

**页面上写**

为不同信息条件构造选择规则，在训练折内选择组平均损失最低的偏移量，再用测试折评价。

| 规则 | 可用信息 | 相对固定0.10的 $J_1$ 降幅 |
|---|---|---:|
| L1 | 全局统一 | 0.83% |
| L2 | 样本量 $n$ | 1.17% |
| L3 | 真形状参数 $\beta$ | 6.33% |
| L4 | 真 $(\beta,n)$ | 6.65% |
| L5 | 真 $(\beta,\gamma/\eta,n)$ | 7.79% |
| L6（下一步的事后参照） | 当前样本的全部候选真实损失 | 21.91% |

![不同信息条件的风险](assets/study01/fig5_information_level_results.png)

**结果：只按样本量调整的收益较小，参数条件提供了更多选择空间。**

**讲稿**

先看前五行。统一选择和按样本量选择，收益都比较小；知道形状参数等条件以后，收益明显增加。所以，不同参数条件确实对应不同的选择规则。但 L5 已经知道完整参数条件，为什么最后一行的逐样本选择还好很多？这就引出了样本本身的差异。

## 第7页｜真参数相同，不同样本仍有不同的低风险偏移量

**页面上写**

- L5：同一参数条件共用一个平均风险最低的偏移量。
- L6：对每个样本查看 26 个候选的实际损失，再选最低点。
- 信息条件比较中，相对固定值的联合误差降幅由 L5 的 **7.79%** 增至 L6 的 **21.91%**。
- 补充确认集上，L5 与 L6 的偏移量完全一致率仅 **12.56%**。

**结果：即使参数条件相同，逐样本的低损失选择仍有差异，参数条件内部仍有样本差异。**

**讲稿**

L5 对同一真参数条件选一个统一值，L6 则看每个样本的实际损失。两者存在明显风险差，补充确认集上的选点一致率也只有约 12.6%。这说明，同一参数条件下仍存在样本差异。L6使用真实损失，给出事后选择参照。接下来检验观测样本能够利用其中多少选择空间。

## 第8页｜样本差异改变候选解路径和低风险偏移量

**页面上写**

对照同一参数组合下三个样本的 MDM 估计路径和候选损失，再在 20 个单元的 2,000 个确认样本上检查这种联系。

![同真值下的三个样本路径](assets/study01/fig7_sample_columns_v112.png)

`样本间距与位置结构不同 → 梯度轨迹和搜索交点变化 → 候选估计及其损失变化 → 低风险偏移量不同`

- 三个同真值样本的低损失偏移量位于不同位置。
- 固定偏移量下的位置估计与事后选点，在 20 个单元中均负相关，单元内相关中位数为 **−0.765**。

**讲稿**

这里沿每一列看同一个样本，横向比较同真值的不同样本。抽样改变了样本的间距和位置结构，也改变了 MDM 的搜索轨迹；偏移量是在这条路径上调整选解位置，因此不同样本可能需要不同的选择。诊断结果支持这种联系。到这里，问题就从找一个最佳常数，推进到能不能根据当前样本作选择。

## 第9页｜不知道真参数，只看当前样本，怎样选偏移量？

**页面上写**

用观测样本预测各候选偏移量的风险，选择预测风险最低的候选。

![样本自适应方法](assets/study01/fig1_adaptive_selection_drawio_v111.png)

模拟训练：用真参数计算候选损失。

实际使用：只输入归一化排序样本。

**网络学习样本与候选损失的关系，所选偏移量仍交由MDM估计三个参数。**

**讲稿**

前面看到，同一参数条件下，不同样本也有不同的低损失偏移量。但实际拿不到真参数，所以我们在模拟训练中计算26个候选的损失，用归一化排序样本预测这条损失曲线。实际使用时只输入样本，选预测损失最低的偏移量，再交给MDM估计三个参数。这里要学的是给定样本后各候选的平均损失，也就是条件风险。最后检验选出来的偏移量能不能真正降低参数误差。

## 第10页｜根据样本选择偏移量，联合误差降低7.27%

**页面上写**

按位置尺度比水平留出，在同一批48,000组样本上比较自适应与固定偏移量。

![主结果与逐样本损失差](assets/study01/fig6_per_n_J1.png)

联合误差由0.6304降至0.5846，降低7.27%。

四个样本量均改善，三个参数的汇总RMSE均下降。

**观测样本提供了固定偏移量规则未充分利用的信息，并带来了实际估计收益。**

**讲稿**

在位置尺度比水平留出的48,000组折外样本上，联合误差由0.6304降到0.5846，降低7.27%。四个样本量均有改善，三个参数的汇总RMSE也都下降。前面的事后比较说明有选择空间，这里的实际改善进一步说明，其中一部分信息确实能够从观测样本中利用起来。

**备查说明**

160个参数单元中125个改善、35个退化；输入表示筛选复用了折外评价数据，冻结方法后的独立确认仍待补充。当前选择器的95%配对重采样区间为6.94%—7.64%。

## 第11页｜三条结论：统一取值、自适应依据与实现方式

**页面上写**

1. 统一偏移量的本质是特定参数空间下的平均风险折中。 经验值0.1在本文宽混合参数域中接近最佳统一值，其适用性随参数域而变化。

2. 自适应选择的空间同时来自参数条件差异和样本实现差异。 即使真参数相同，不同样本也会形成不同的候选解路径和低风险偏移量。

3. 偏移量选择可以转化为基于当前样本的条件风险决策。 MLP预测候选损失并选择偏移量，无需真参数输入，联合误差降低7.27%。

**讲稿**

最后归成三条结论。第一，统一偏移量的本质，是特定参数空间下的平均风险折中。0.1在本文宽混合参数域中接近最佳统一值，参数域改变后，合适的统一取值也随之变化。第二，自适应选择的依据来自两层差异：不同参数条件有不同的平均风险，同一参数条件内部又有不同的样本实现。样本改变候选解路径，也就提供了进一步调整偏移量的空间。第三，我们把这种选择写成基于当前样本的条件风险决策，用MLP预测候选损失曲线，再选择偏移量。实际使用无需真参数输入，最终联合误差降低7.27%，说明这一思路能够转化为有效改进。

## 备查页A1｜参数精度收益是否传到寿命点？

**页面上写**

| 同一48,000样本上的方案 | 联合参数误差 $J_1$ |
|---|---:|
| 样本自适应MDM | 0.5846 |
| 固定MDM-0.1 | 0.6304 |
| WMLE | 0.7288 |
| LSE | 0.8725 |

- 三个寿命点上，所比较的WMLE相对RMSE最低。
- 自适应MDM相对固定值：$x_{0.90}$ 略差，$x_{0.95}$、$x_{0.99}$ 略好。

**讲稿**

这里再补充一个结论范围：参数误差与寿命点误差会给出不同的方法排序。三个参数共同决定寿命点，三个寿命点的误差变化幅度和方向各有不同。
