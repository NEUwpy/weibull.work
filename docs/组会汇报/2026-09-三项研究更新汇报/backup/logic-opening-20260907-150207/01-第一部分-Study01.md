# 第一部分：MDM 方法中偏移量的自适应调整

> 第3—11页，约10分钟。按当前论文梳理背景、设置、证据与结论；页面保留图表，口头简要回顾。第3页的背景、目的与设置可在制作PPT时拆页，不受暂定页码限制。

## 第3页｜研究背景、目的与实验设置

**页面上写**

**研究背景**

三参数 Weibull 分布能够描述具有非零寿命起点的数据，广泛用于寿命与可靠性分析。其位置参数既确定分布的寿命起点，也使样本支持域随待估参数变化，因而增加了参数估计的难度。

MDM 的后续研究在位置参数搜索判据中引入正偏移量 $\delta=0.1$，改善了小样本估计的精度和稳定性。这个经验值来自已有估计案例，更适当的取值与选择方式仍待研究。因此，需要说明偏移量怎样改变估计误差，并建立超出统一经验常数的选择依据。

**研究目的（沿用当前论文引言表述）**

针对 MDM 经验偏移量的取值依据与进一步优化问题，本文从参数空间、样本实现和自适应选择三个层面展开研究。通过 Monte Carlo 候选扫描考察统一偏移量对参数空间的依赖，比较不同信息条件下的选择规则，区分总体参数与抽样差异带来的优化空间；结合 MDM 搜索路径和联合误差分析，解释偏移量作用于三参数估计的过程。在此基础上，建立由归一化排序样本预测候选损失曲线的偏移量选择方法，通过参数水平留出评价检验其在总体参数未知时能否进一步提高估计精度。

**论文的逻辑主线**

`经验偏移量的依据尚不充分 → 解释偏移量怎样影响误差 → 检查统一值是否足够 → 判断进一步选择需要什么信息 → 构建只用样本的选择方法 → 验证收益、解释样本差异并明确适用范围`

| 为了研究什么 | 做了什么实验或分析 | 得到了什么结果 |
|---|---|---|
| 偏移量为什么影响精度？ | 扫描候选偏移量，对组合内误差作偏差—方差分解。 | 联合误差体现偏差与方差的折中，增大偏移量并非一直有利。 |
| 能否用一个统一常数解决？ | 比较完整参数域，并平移固定宽度的形状参数窗口。 | 当前域内 0.10 接近最佳；参数域改变后，最佳统一值由 0.18 移至 0.04。 |
| 进一步调整需要什么信息？ | 比较统一、参数条件和逐样本事后选择规则。 | 参数条件和本次抽样差异都提供选择空间，需进一步检验可观测样本能否利用这些信息。 |
| 真参数未知时能否实现收益？ | 根据样本预测候选损失，再做参数水平留出的折外比较。 | 联合误差下降 7.27%，但部分单元退化。 |
| 样本差异如何影响选点，收益能推到哪里？ | 对照同真值样本的估计路径，并比较寿命点误差。 | 样本差异伴随低风险选点移动；参数精度收益向寿命点的传递有限。 |

**主要实验设置**

| 项目 | 设置 |
|---|---|
| 研究对象 | 三参数 Weibull 小样本 MDM 估计 |
| 形状参数 | $1.5\leq\beta\leq5.0$ 的离散水平 |
| 位置尺度比 | $0.10\leq\gamma/\eta\leq1.00$ 的离散水平 |
| 样本量 | $n\in\{7,10,15,20\}$ |
| 主设计 | 160 个参数与样本量组合，48,000 组样本 |
| 候选偏移量 | $0,0.02,\ldots,0.50$，共 26 点 |
| 主要基准与评价 | 固定 $\delta=0.1$；三参数联合误差 $J_1$ |
| 自适应方法验证 | 按位置尺度比水平留出的折外评价 |

**讲稿**

这个工作的架构之前已经汇报过几次，这次主要结合现在的论文，把研究目的、实验和最后得到的答案完整捋一下。这里放的是论文中对研究目的的表述，也想请老师看一下这样理解是否准确。核心就是三个问题：偏移量怎样影响误差，统一取值由什么决定，以及真参数未知时能不能根据样本进一步调整。实验仍以小样本 MDM 为对象，在这组参数组合和候选偏移量上做比较，下面简要看结果。

## 第4页｜正偏移量通过偏差与方差的折中降低误差

**页面上写**

**研究问题：** 偏移量怎样影响估计精度，而不只是让估计更集中？

**实验设计：** 在固定参数组合内重复抽样并扫描候选偏移量，计算标准化误差的均值与方差，再按设计权重汇总，分解联合误差。

| 偏移量 | 联合误差 $J_1$ | 观察 |
|---|---:|---|
| 0 | 0.9481 | 抽样波动较大 |
| 0.10 | 0.6304 | 方差下降超过偏差增加 |
| 0.50 | 0.7619 | 方差继续下降，偏差代价增大 |

$$J_1^2=B^2+V.$$

![偏移量与条件偏差方差分解](assets/study01/fig2_offset_risk_decomposition_v112.png)

**得到的结果：** 从 0 到 0.10，方差下降超过偏差增加；继续增大至 0.50，偏差代价使联合误差回升。

**由此进入下一步：** 既然存在折中，是否能找到一个统一偏移量适用于不同参数域？

**讲稿**

先看偏移量本身的作用。从 0 增至 0.10，抽样方差下降的收益超过偏差增加的代价，联合误差降低；继续加到 0.50，虽然估计更集中，但偏差代价增大，联合误差反而回升。因此，偏移量需要在偏差和方差之间取折中，并不是越大越好。

## 第5页｜最佳统一取值随所针对的参数域改变

**页面上写**

**研究问题：** 最佳统一偏移量是否由参数域决定，经验值 0.10 是否足够？

**实验设计：** 先扫描完整混合参数域的风险，再固定形状参数窗口宽度、平移窗口位置，比较各域的风险最低点。

- 宽混合域：最低扫描点为0.06，经验值0.10的 $J_1$ 仅高0.93%。
- 固定窗口宽度、沿形状参数平移：最佳统一值由0.18移至0.04。
- 统一值是给定参数域下的平均风险折中。

![固定宽度参数域与统一取值](assets/study01/fig3_beta_domain_restored_3d.png)

**得到的结果：** 0.10 接近当前完整域的最佳统一值，但窗口平移后最佳值由 0.18 移至 0.04。

**由此进入下一步：** 统一值依赖参数域；如果允许按更细的信息调整，还能降低多少风险？

**讲稿**

在当前宽混合参数域里，0.10 已经接近最佳统一值，单纯换一个常数收益不大。但把形状参数域整体平移，最佳统一值会从 0.18 变到 0.04。所以，统一偏移量依赖所面对的参数域，不能把 0.10 理解成普遍最优常数。

## 第6页｜参数条件与本次抽样都影响低风险偏移量

**页面上写**

**研究问题：** 统一规则之外的选择空间，来自参数条件还是本次抽样差异？

**实验设计：** 在同一评价设计中比较统一、样本量、真参数条件和逐样本真实损失选点规则。

| 可用信息 | 相对固定0.10的 $J_1$ 降幅 |
|---|---:|
| 全局统一规则 | 0.83% |
| 样本量 $n$ | 1.17% |
| 真形状参数 $\beta$ | 6.33% |
| 真 $(\beta,n)$ | 6.65% |
| 真 $(\beta,\gamma/\eta,n)$ | 7.79% |
| 查看本次样本全部真实损失后选点 | 21.91% |

![不同信息条件的风险](assets/study01/fig5_information_level_results.png)

**得到的结果：** 样本量单独提供的收益较小；参数条件与逐样本事后选择提供更多选择空间。后者依赖真实损失，不能直接用于实际估计。

**由此进入下一步：** 实际只有观测样本，能否由样本预测候选风险，将选择空间变成可执行方法？

**讲稿**

这组实验用来判断进一步调整的空间在哪里。只知道样本量，收益较小；知道参数条件，收益增加；即使参数条件相同，不同样本仍有不同的低风险偏移量。最后一行查看了每个样本的真实候选损失，只是事后参照，实际使用时拿不到这些信息。

## 第7页｜网络根据观测样本预测候选损失，再交给MDM求解

**页面上写**

**要解决的问题：** 真参数和真实候选损失在应用时未知，怎样仅用样本选择偏移量？

**方法设计：** 用模拟样本的候选损失训练网络，学习从观测样本到损失曲线的映射，再由 MDM 完成参数估计。

`排序样本 ÷ 样本均值 → 26点损失曲线 → 选择低风险δ → MDM三参数估计`

- 每个 $n$ 单独训练；标准化在当前训练折拟合。
- 候选网格为 $0,0.02,\ldots,0.50$。
- 应用时输入只有寿命样本，不需要真参数。

![样本自适应方法](assets/study01/fig1_adaptive_selection_drawio_v111.png)

**形成的可执行规则：** 应用时仅输入寿命样本即可选择偏移量；是否能降低误差，由下一页的折外实验检验。

**讲稿**

方法结构之前讲过，这里简要回顾：网络根据归一化排序样本预测 26 个候选偏移量的损失，选择后仍由 MDM 求参数。预测整条曲线是为了保留相邻候选之间的损失差别，最后评价的是参数误差有没有下降，而不是是否命中唯一的最优格点。

## 第8页｜可执行选择使联合误差进一步下降7.27%

**页面上写**

**研究问题：** 仅依赖观测样本的选择，是否真的优于固定偏移量？

**实验设计：** 按位置尺度比水平留出，用同一批折外样本成对比较自适应 MDM 与固定 MDM-0.1，并检查参数误差、样本量及单元差异。

- 48,000个测试样本：$J_1$ 由0.6304降至0.5846。
- 相对下降7.27%，配对重复块bootstrap 95%区间为6.94%—7.64%。
- 四个样本量均改善，失败率0%。
- 160个参数单元中，125个改善、35个退化。

![主结果与逐样本损失差](assets/study01/fig6_per_n_J1.png)

**得到的结果：** 联合误差由 0.6304 降至 0.5846，下降 7.27%；125 个单元改善、35 个退化。

**由此进入下一步：** 总体收益已观察到，接着用样本路径诊断解释为什么同一真值下仍需要不同偏移量。

**讲稿**

这是目前论文采用的主结果：联合误差从 0.6304 降到 0.5846，下降 7.27%，四个样本量和三个参数的汇总 RMSE 都有改善。但 160 个单元中仍有 35 个退化，因此结论是当前设计下的总体改善。这批数据也参与过输入表示筛选，冻结方法后的独立确认还需要补。

## 第9页｜相同真值下，低风险偏移量随样本路径移动

**页面上写**

**研究问题：** 相同真参数下，样本差异怎样伴随低风险偏移量的变化？

**实验设计：** 对照同一参数组合下三个样本的估计路径和候选损失，并在 20 个单元的 2,000 个确认样本上核查位置估计与事后选点的关系。

- 同一参数组合的三个样本，低风险偏移量分别在不同位置。
- 20个诊断单元中，固定偏移量下的位置估计与事后选点均负相关。
- 单元内相关中位数为−0.765。

![同真值下的三个样本路径](assets/study01/fig7_sample_columns_v112.png)

**得到的结果：** 三个样本的低损失位置不同；20 个单元的相关方向均为负，中位数为 −0.765。这是样本差异的机制证据，不是对每次最优选点的精确预测。

**由此进入下一步：** 上述收益针对参数误差；还需检查它是否传递到最终使用的寿命点。

**讲稿**

这张图补充解释为什么同一参数条件下还需要调整。三个样本的真参数相同，但估计路径和低损失位置不同；20 个诊断单元也都观察到位置估计与事后选点的负相关。这支持偏移量需要响应本次抽样差异，但还不能据此精确恢复每次的最优值。

## 第10页｜参数恢复收益向寿命点的传递有限

**页面上写**

**研究问题：** 参数精度的改善，是否意味着最终寿命点也更准确？

**实验设计：** 在同一批 48,000 组样本上加入 WMLE、LSE 参照，同时比较联合参数误差和三个可靠度寿命点误差。

| 同一48,000样本上的方案 | 联合参数误差 $J_1$ |
|---|---:|
| 样本自适应MDM | 0.5846 |
| 固定MDM-0.1 | 0.6304 |
| WMLE | 0.7288 |
| LSE | 0.8725 |

- 三个寿命点上，所比较的WMLE相对RMSE最低。
- 自适应MDM相对固定值：$x_{0.90}$ 略差，$x_{0.95}$、$x_{0.99}$ 略好。

**得到的结果：** 参数误差与寿命点误差的排序不同；自适应 MDM 相对固定值的寿命点收益有限。

**由此进入下一步：** 因此，论文结论落在当前设计下的总体参数估计改善，不扩大为所有条件与寿命点上的优势。

**讲稿**

最后检查参数估计的收益能否传到寿命点。这里发现，两种评价下的方法排序不同：自适应 MDM 的联合参数误差较低，但所比较的 WMLE 在三个寿命点上的相对 RMSE 最低。因此，目前得到的是参数估计的改善，不能直接扩大为所有寿命点都更准确。

## 第11页｜偏移量选择：目前得到的三个答案

**页面上写**

| 研究问题 | 当前答案 |
|---|---|
| 偏移量为什么影响精度？ | 改变 MDM 搜索落点及三参数估计，在条件偏差与抽样方差之间形成折中。 |
| 是否存在普遍最优的统一值？ | 最佳统一值依赖参数域；0.10 在当前宽混合设计中接近最佳，但并非普遍最优。 |
| 真参数未知时能否进一步调整？ | 仅用观测样本预测候选损失，在当前折外评价中使联合误差下降 7.27%。 |

- 结论范围：当前模拟设计下的总体参数精度改善；不保证每个单元或每个寿命点都改善。
- 后续确认：冻结方法后用独立新样本检验。

**讲稿**

所以，这篇论文目前的答案是：偏移量确实影响估计中的偏差与方差；统一取值受参数域影响；真参数未知时，样本信息也能支持进一步调整，当前得到的总体改善是 7.27%。这次希望把这三个问题和对应证据讲清楚，也请老师看一下，论文这样组织是否能把研究目的和结果对应起来。
