# 第一部分：MDM 方法中偏移量的自适应调整

> 第3—11页，约10分钟。页面文字可直接用于幻灯片；讲稿用于口头展开。图为当前稿件原图，制作为PPT时可按面板拆页。

## 第3页｜偏移量调节的是同一样本的三参数估计路径

**页面上写**

- MDM沿位置参数形成一组候选解。
- 偏移量改变梯度判据的搜索落点。
- 位置改变后，形状与尺度估计也随之变化。

$$
\text{样本 }X\ \longrightarrow\ \text{候选解路径}\ \xrightarrow{\delta}\ (\hat\beta,\hat\eta,\hat\gamma).
$$

**讲稿**

第一部分要回答：为什么需要偏移量、统一取多少，以及能不能根据当前样本选择。偏移量不是总体的第四个参数，而是估计规则的调节量。它虽然出现在位置参数的搜索判据中，却会带动三个估计量一起变化，所以评价时需要看三参数联合误差。相同真值下，不同样本也可能对应不同的低风险偏移量。

## 第4页｜正偏移量通过偏差与方差的折中降低误差

**页面上写**

| 偏移量 | 联合误差 $J_1$ | 观察 |
|---|---:|---|
| 0 | 0.9481 | 抽样波动较大 |
| 0.10 | 0.6304 | 方差下降超过偏差增加 |
| 0.50 | 0.7619 | 方差继续下降，偏差代价增大 |

$$J_1^2=B^2+V.$$

![偏移量与条件偏差方差分解](assets/study01/fig2_offset_risk_decomposition_v112.png)

**讲稿**

这次补充的解释比原来只说“标准差下降”更完整。我们先在每个固定参数组合内计算重复抽样的偏差与方差，再对组合等权汇总。偏移量从0增至0.10时，方差下降的收益超过偏差增加的代价；继续加大，估计更集中，但中心偏离真值，联合误差反而上升。因此，不能把越稳定直接理解成越准确。

## 第5页｜最佳统一取值随所针对的参数域改变

**页面上写**

- 宽混合域：最低扫描点为0.06，经验值0.10的 $J_1$ 仅高0.93%。
- 固定窗口宽度、沿形状参数平移：最佳统一值由0.18移至0.04。
- 统一值是给定参数域下的平均风险折中。

![固定宽度参数域与统一取值](assets/study01/fig3_beta_domain_restored_3d.png)

**讲稿**

在当前宽混合设计中，把0.10换成另一个统一常数，可得到的收益不大。但如果应用域事先明确，统一值可以随该域重新确定。这两点并不矛盾：0.10在当前混合域中是稳健默认值，却不是脱离参数域的唯一最优值。图中的窗口保持宽度相同，便于看清位置变化对应的风险谷底移动。

## 第6页｜参数条件与本次抽样都影响低风险偏移量

**页面上写**

| 可用信息 | 相对固定0.10的 $J_1$ 降幅 |
|---|---:|
| 全局统一规则 | 0.83% |
| 样本量 $n$ | 1.17% |
| 真形状参数 $\beta$ | 6.33% |
| 真 $(\beta,n)$ | 6.65% |
| 真 $(\beta,\gamma/\eta,n)$ | 7.79% |
| 查看本次样本全部真实损失后选点 | 21.91% |

![不同信息条件的风险](assets/study01/fig5_information_level_results.png)

**讲稿**

这些规则用于判断选择空间来自哪里。只按样本量分类的收益很小，参数条件提供更多信息，但同一参数条件内仍有很大的样本差异。最后一行是L6：它在样本抽出后查看所有候选的真实损失，属于事后参照。它与前几行的信息性质不同；只知样本量与只知形状参数也不是包含关系，不能把每两行之差都解释成增加单一信息的净收益。

## 第7页｜网络根据观测样本预测候选损失，再交给MDM求解

**页面上写**

`排序样本 ÷ 样本均值 → 26点损失曲线 → 选择低风险δ → MDM三参数估计`

- 每个 $n$ 单独训练；标准化在当前训练折拟合。
- 候选网格为 $0,0.02,\ldots,0.50$。
- 应用时输入只有寿命样本，不需要真参数。

![样本自适应方法](assets/study01/fig1_adaptive_selection_drawio_v111.png)

**讲稿**

我们预测整条曲线，是因为相邻偏移量经常落在同一低损失平台上。将最低点当成硬分类标签，会把风险接近的两个选择分成对和错。损失曲线保留了这种接近程度，最后仍由MDM求解参数。网络是否有效，要看所选偏移量造成的实际估计误差，而不是选点能否精确命中事后最低格点。

## 第8页｜可执行选择使联合误差进一步下降7.27%

**页面上写**

- 48,000个测试样本：$J_1$ 由0.6304降至0.5846。
- 相对下降7.27%，配对重复块bootstrap 95%区间为6.94%—7.64%。
- 四个样本量均改善，失败率0%。
- 160个参数单元中，125个改善、35个退化。

![主结果与逐样本损失差](assets/study01/fig6_per_n_J1.png)

**讲稿**

这是按位置尺度比水平留出的折外比较。三个参数的汇总标准化偏差绝对值、混合设计误差SD和RMSE也都下降，因此联合风险改善落实到了三个参数。与此同时，35个退化单元提醒我们，总体获益不保证每个参数条件获益。区间条件于现有选择器，且输入表示筛选复用了这批折外评价数据；冻结全部选择后再用独立新样本确认，仍是后续工作。

## 第9页｜相同真值下，低风险偏移量随样本路径移动

**页面上写**

- 同一参数组合的三个样本，低风险偏移量分别在不同位置。
- 20个诊断单元中，固定偏移量下的位置估计与事后选点均负相关。
- 单元内相关中位数为−0.765。

![同真值下的三个样本路径](assets/study01/fig7_sample_columns_v112.png)

**讲稿**

沿每一列看，同一个样本的偏移量先改变位置估计，联合损失随之改变；横向比较，三个样本的真参数相同，较低损失却分别对应上调、下调或零偏移量。诊断使用20个预设单元的2,000个确认样本，分组统计进一步支持这种联系。边界解占7.1%，仅靠边界截断不能概括全部变化。相关性和路径图共同提供机制证据，但并不意味着可以从某一个统计量精确恢复每次最优选点。

## 第10页｜参数恢复收益向寿命点的传递有限

**页面上写**

| 同一48,000样本上的方案 | 联合参数误差 $J_1$ |
|---|---:|
| 样本自适应MDM | 0.5846 |
| 固定MDM-0.1 | 0.6304 |
| WMLE | 0.7288 |
| LSE | 0.8725 |

- 三个寿命点上，所比较的WMLE相对RMSE最低。
- 自适应MDM相对固定值：$x_{0.90}$ 略差，$x_{0.95}$、$x_{0.99}$ 略好。

**讲稿**

参数联合误差与寿命点误差给出了不同的方法排序。寿命点由三个参数共同决定，误差方向和协方差都会影响最终结果，所以三个参数各自更准，并不保证每一个寿命点同比例更准。这里的排序只对应本部分的设计与方法实现；第二部分采用新的训练与测试协议，不能直接把两部分的数字拼成同一个排行榜。

## 第11页｜Study01回答了偏移量选择，下一问是完整路线比较

**页面上写**

1. 偏移量调节条件偏差与抽样方差。
2. 统一值随参数域改变；本次样本还提供进一步选择信息。
3. 仅用观测样本预测损失曲线，可在当前设计下改善MDM参数估计。

**转入第二部分**

> 已经使用神经网络后，保留MDM求解过程与直接输出参数，各自在什么条件下更合适？

**讲稿**

第一部分建立的是MDM内部选择的依据与收益。下一部分把问题扩大到完整估计路线，直接面对神经网络能否取得更低误差，而不预先假定保留传统求解一定更好。
