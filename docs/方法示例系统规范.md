# 方法示例系统规范

## 概述

方法示例（Method Study）系统用于展示各种参数估计方法在不同参数组合下的蒙特卡洛仿真结果。

## 目录结构

```
public/studies/{method}/{study_id}/
├── config.md           # 配置文件（必需）
├── chunks/             # 分片数据目录（必需）
│   ├── index.json      # 分片索引
│   ├── b1.5_e200_n3_d0.1.csv
│   ├── b1.5_e200_n5_d0.1.csv
│   └── ...
└── summary.json        # 汇总统计（可选，由脚本生成）
```

**注意**：不再使用单一的 `data.csv`，而是采用分片模式。

## 分片文件命名规范

分片文件名格式：`{param1}{value1}_{param2}{value2}_....csv`

| 参数ID | 简写 | 格式化规则 |
|--------|------|-----------|
| beta | b | 保留1位小数，如 `b1.5`, `b2.0` |
| eta | e | 整数，如 `e200`, `e1000` |
| gamma | g | 整数，如 `g1000` |
| sampleSize | n | 整数，如 `n3`, `n10` |
| process | d | 保留小数但去掉末尾0，如 `d0`, `d0.05`, `d0.1` |

示例：
- `b1.5_e200_n3_d0.1.csv` → β=1.5, η=200, n=3, δ=0.1
- `b2.0_e1000_n10_d0.csv` → β=2.0, η=1000, n=10, δ=0

## 分片CSV格式

每个分片文件包含相同参数组合下的所有模拟结果：

```csv
beta_true,eta_true,sample_size,offset_value,sim_id,est_beta,est_eta,est_gamma,bias_beta,bias_eta,bias_gamma,r_squared
1.5,200,3,0.1,1,1.234,189.5,50.2,-0.266,-10.5,50.2,0.95
1.5,200,3,0.1,2,1.456,210.3,45.1,-0.044,10.3,45.1,0.97
...
```

**列说明**：
- `*_true`: 真实参数值
- `sim_id`: 模拟编号（1 到 mcRuns）
- `est_*`: 估计值（NaN 表示无解）
- `bias_*`: 偏差 = 估计值 - 真实值
- `r_squared`: 拟合优度

## 前端加载策略

### 1. 按需加载分片

```typescript
// 只加载当前显示维度对应的分片
const loadRequiredChunks = async (
  params: ParamConfig[],
  displayDimensions: ParamConfig[],
  defaults: Record<string, number>
) => {
  // 固定维度使用默认值
  const fixedParams = params.filter(p => !displayDimensions.some(d => d.id === p.id))

  // 构建文件名
  const parts = []
  for (const p of [...fixedParams, ...displayDimensions]) {
    const val = displayDimensions.some(d => d.id === p.id)
      ? displayDimensions.find(d => d.id === p.id)?.currentValue ?? defaults[p.id]
      : defaults[p.id]
    parts.push(formatParamForFilename(p.id, val))
  }

  // 加载对应的分片
  const filename = parts.join('_') + '.csv'
  // ...
}
```

## 数据生成脚本

使用 `python/studies/{method}/simulate.py` 生成数据：

```bash
cd python/studies/mdm

# 生成所有分片（增量模式）
python simulate.py demo1

# 强制重新生成
python simulate.py demo1 --force

# 只生成特定组合
python simulate.py demo1 --only beta=1.5

# 查看状态
python simulate.py demo1 --status

# 合并为单个 CSV（可选，用于备份）
python simulate.py demo1 --merge
```

## 添加新示例

1. 创建目录：`public/studies/{method}/{study_id}/`
2. 创建配置文件：`config.md`
3. 创建分片目录：`chunks/`
4. 运行生成脚本：`python simulate.py {study_id}`
5. 在前端 API 中注册（自动扫描时无需此步）

## 性能考虑

- **分片大小**：每个分片约 50-100KB（1000次模拟）
- **加载策略**：只加载当前显示所需的分片
- **缓存**：浏览器自动缓存已加载的分片
- **预加载**：可选预加载相邻参数组合的分片
