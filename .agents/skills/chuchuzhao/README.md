# chuchuzhao · 出出招

当前版本：**v1.1.0**

把当前对话或项目中的已知内容，整理成一份可以直接复制给他人或其他 AI 的上下文。接收者没有当前对话背景，但可以有通用知识；重点补上他不了解的项目背景。

## 两种用法

- **已经想好问题**：整理与问题相关的背景和现状，附上你的原问题，不擅自扩写或拆成小问题。
- **只想提供背景**：按你指定的大致范围整理内容，没有明确问题就不代拟，也不追问。

需要写的写，不需要写的不写，详略得当，不以篇幅或压缩比例为目标。专有方法要讲清基本做法及其与问题的关系，不能只报名字；通用知识点到即可，无关的配置和操作记录不展开。区分事实与猜测，缺失信息不编造，不替你限定别人的回答方向。

需要保存为独立材料时使用可追踪版本号 `v主版本.次版本.修订版本`；实质性内容变化升主版本或次版本，措辞、链接和格式修正升修订版本。日期单独记录，不代替版本号。临时对话整理不强制编号。

## 安装到 Codex

将本仓库克隆到 `$CODEX_HOME/skills/chuchuzhao`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/chuchuzhao`。若该目录已存在，请先检查其中内容，避免覆盖已有修改。

技能指令位于 [SKILL.md](SKILL.md)。

## 调用示例

明确问题时：

> 用 $chuchuzhao 整理相关背景，我要问的是：“这个项目接下来该怎么走？”背景和原问题放在一起，方便我直接复制。

只整理情况时：

> 用 $chuchuzhao 整理一下这个项目的背景和目前情况，我拿给其他 AI 看。

第二种调用只输出情况说明，不自动追加问题或求助结语。
