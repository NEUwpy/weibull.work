# 任务单：计算器多案例叠加显示功能

**创建时间**: 2026-03-05
**更新时间**: 2026-03-05 (当前会话)
**方案**: B+ - 单卡片多曲线 + 样本分隔符模式
**目标**: 支持在计算器中多选案例，用 `---` 分隔多组样本，叠加显示所有曲线

---

## 核心设计

### 样本栏语法

```
100
120
150
---
110
130
160
---
105
125
155
```

**分隔符规则**:
- 组内分隔符: 换行、空格、分号 `;` 都可作为样本点分隔
- 组间分隔符: `---` (三个连字符) 单独一行
- 右下角显示: `N=7×30` (每组7个，共30组)

### 与 overlayCurves 的区别

| 机制 | 样本栏多组 (`---`) | overlayCurves |
|------|-------------------|---------------|
| 数据来源 | 案例库多选导入 | 其他卡片的结果 |
| 存储位置 | 同一卡片内 | 跨卡片引用 |
| 方法/参数 | 共享同一套 | 各卡片独立 |
| 用途 | 批量分析同类型数据 | 对比不同来源的结果 |

### Phase 10: 方法详情页多选计算流程 🔄

**需求**: 多选案例后自动触发批量计算，
计算完成后在 Visualizer 中叠加显示

**流程**:
1. 用户在 DataEditor 中多选案例
2. `handleLabDataSaveMulti` 保存数据并**自动触发**批量计算
3. 批量计算带 `trace: true` 参数
4. 计算结果和 traceData 存入 `dataSources[i].result` 和 `dataSources[i].traceData`
5. Visualizer 接收 `dataSources` 并叠加显示
