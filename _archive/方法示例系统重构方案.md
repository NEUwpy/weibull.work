> 创建日期：2026-03-02
> 最后更新：2026-03-02
> 状态：进行中

## 一、问题与目标

### 现状问题

1. **案例组件臃肿**：每个案例一个 700+ 行的 tsx，代码大量重复
2. **参数硬编码**：参数写在 tsx 里，改动需要改代码
3. **脚本堆积**：Python 根目录 15+ 个调试脚本
4. **方法.py 缺乏灵活性**：步长、寻优方法等计算设置无法参数化

### 目标

- **配置驱动**：一个通用组件 + config.md 替代每个案例写 tsx
- **脚本复用**：一个通用仿真脚本替代 N 个专用脚本
- **方法参数化**：方法.py 支持计算设置作为参数

## 二、目标架构

### 方法示例 Tab 结构

```
┌─────────────────────────────────────────────────────────────────┐
│  方法示例 - [方法名]                                            │
├─────────────────────────────────────────────────────────────────┤
│  [下拉选择示例]                                                 │
├─────────────────────────────────────────────────────────────────┤
│  [β] [η] [γ]  ← 参数选择 tabs（可多选）    [筛选显示 ▼]          │
├─────────────────────────────────────────────────────────────────┤
│  参数面板：β, η, γ, n, δ 等（可选择显示维度）                   │
├─────────────────────────────────────────────────────────────────┤
│  统计表格：按显示维度分组，显示选中的统计量                      │
├─────────────────────────────────────────────────────────────────┤
│  图表区域：                                                     │
│  - 单变量：箱型图 (β/η/γ)                                       │
│  - 双变量：热力图                                               │
└─────────────────────────────────────────────────────────────────┘
```

### 核心交互

1. **参数选择 tabs**：[β] [η] [γ] - 点击多选，控制表格/图表显示哪些参数
2. **筛选显示按钮**：选择要显示的统计量
   - 均值、均值偏差
   - 中位数、中位数偏差
   - 标准差
   - 95% CI / 99% CI
   - 全范围
   - 分位数偏差 (F=0.01%~10%)
3. **显示维度选择**：参数卡片上点击"设为显示维度"

## 五、关键设计决策

### 1. 实时计算 vs 预计算

**决定**：前端实时从 CSV 计算统计量

**理由**：
- 更灵活，用户选择什么参数/统计量就实时计算
- 不需要维护 summary.json
- CSV 加载一次后，统计计算很快

### 2. 数据文件格式

**config.md**：
```yaml
---
id: "demo-1"
name: "示例1: MDM多维度研究"
description: "描述..."
method: "mdm"
defaults:
  beta: 2.0
  eta: 1000
  gamma: 1000
  sampleSize: 7
  process: 0.1
# 仿真设置
simulation:
  mcRuns: 1000              # 每组参数组合的蒙特卡洛重复次数
  totalCombinations: 125    # 参数组合数
  totalRuns: 125000         # 总模拟次数
  seedFormula: "sim_id + sample_size * 1000 + int(beta * 100) + int(offset * 1000)"
# MDM计算设置
calculation:
  gammaSteps: 60            # 每轮梯度计算的步数
  betaBounds: [0.1, 15.0]   # beta搜索范围
  gammaRangeRound1: [0, 0.99]     # 第一轮gamma搜索范围 (相对于t_min)
  gammaRangeRound2: [0.99, 0.999999]  # 第二轮gamma搜索范围 (相对于t_min)
  defaultOffset: 0.1        # 默认梯度偏移目标
# 图表配置（从配置加载，不在tsx中硬编码）
charts:
  univariate:
    - param: "beta"
      title: "β估计值分布"
    - param: "eta"
      title: "η估计值分布"
    - param: "gamma"
      title: "γ估计值分布"
  bivariate:
    - param: "beta"
      title: "β参数偏差热力图"
    - param: "eta"
      title: "η参数偏差热力图"
    - param: "gamma"
      title: "γ参数偏差热力图"
params:
  - id: "beta"
    name: "形状参数"
    symbol: "β"
    state: "discrete"
    discreteValues: [1.5, 2.0, 3, 5, 7]
    isVariable: true
  # ...
---
```

**data.csv**：
```csv
beta_true,sample_size,offset_value,sim_id,est_beta,est_eta,est_gamma,bias_beta,bias_eta,bias_gamma,r_squared
1.5,5,0,1,1.637,553.579,970.417,0.137,-446.421,-29.583,0.970

```

### 3. 设计原则：统一复用性

**核心思想**：如果用一样的结构对内容呈现无影响，那就不要差异化。

| 原则 | 说明 |
|------|------|
| 布局统一 | 所有图表使用相同的网格布局 `grid-cols-1 md:grid-cols-2 gap-6` |
| 样式统一 | 所有图表卡片使用相同样式 `bg-white rounded-2xl border border-slate-200 p-4` |
| 标题统一 | 所有图表标题在下方，格式 `图 N: 标题`，样式 `text-center text-sm font-semibold text-slate-700 mt-3` |
| 配置驱动 | 图题、图表类型等从 config.md 加载，tsx 只负责渲染逻辑 |

**禁止事项**：
- ❌ 在 tsx 中硬编码图题、图表配置
- ❌ 为不同图表类型创建不同的布局/样式
- ❌ 在组件内部写死任何示例特定的内容

### 4. 组件架构：插槽模式

**设计理念**：
- **主文件 = 框架**：只负责布局和卡片容器
- **图表组件 = 内容**：只负责图表渲染，不包含外框
- **ChartCard = 统一容器**：接收图表组件作为 children

```
┌─────────────────────────────────────────────────────────────┐
│  UniversalStudyViewer.tsx (框架)                            │
│  ┌─────────────────────────────────────────────────────────┐│
│  │  <ChartCard title="图 1: β估计值分布">   ← 统一容器      ││
│  │    <BoxPlotChart data={...} />         ← 图表内容       ││
│  │  </ChartCard>                                           ││
│  ├─────────────────────────────────────────────────────────┤│
│  │  <ChartCard title="图 2: β参数偏差热力图">               ││
│  │    <HeatmapChart data={...} />                          ││
│  │  </ChartCard>                                           ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘
```

**目录结构**：
```
src/components/studies/
├── UniversalStudyViewer.tsx    # 主框架（布局 + 表格 + 组合逻辑）
└── charts/                     # 图表组件（独立文件，可复用）
    ├── index.ts                # 统一导出
    ├── ChartCard.tsx           # 统一卡片容器（外框 + 标题）
    ├── BoxPlotChart.tsx        # 箱型图（只输出 SVG）
    └── HeatmapChart.tsx        # 热力图（只输出表格）
```

**组件职责划分**：

| 组件 | 职责 | 包含内容 |
|------|------|----------|
| `UniversalStudyViewer` | 框架 | 布局、配置加载、表格、组合图表 |
| `ChartCard` | 容器 | 统一外框样式 + 标题显示 |
| `BoxPlotChart` | 内容 | 只输出箱型图 SVG |
| `HeatmapChart` | 内容 | 只输出热力图表格 |

**为什么这样设计**：
1. **图表样式多变**：不同图表类型（箱型、热力、折线等）渲染逻辑差异大，必须独立
2. **容器格式统一**：所有图表都需要相同的外框和标题样式，不需要重复实现
3. **组合灵活**：新示例只需选择用哪些图表，用 ChartCard 包裹即可
4. **其他模块复用**：图表组件可被其他页面直接使用，不需要外框

**添加新图表**：
```tsx
// 1. 创建 charts/NewChart.tsx（只输出图表内容，不包含外框）
export function NewChart({ data, ...props }: NewChartProps) {
  return <svg>...</svg>  // 或其他内容
}

// 2. 在主文件中使用
import { ChartCard } from './charts/ChartCard'
import { NewChart } from './charts/NewChart'

// 3. 用 ChartCard 包裹
<ChartCard title="图 N: 标题">
  <NewChart data={...} />
</ChartCard>
```

**不需要独立的**：
- 表格组件（StatsTable、DualVarTable）- 格式固定，保留在主文件
- 布局组件 - 简单的 div 包装，不需要抽象
