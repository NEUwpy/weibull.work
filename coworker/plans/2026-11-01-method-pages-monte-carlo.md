## 目标与现状

产品定位是更便于查看、定位和核对的网页研究数据工作簿，兼顾Excel的表格阅读习惯与Research00的信息量。默认进入数据记录，统计分析可切换；方法功能具有独立地址，可就地切换其他方法；蒙特卡洛数据存放在外部data目录，软件通过可追溯索引读取。

保留方法介绍、计算、验证及现有图表，复用公共蒙特卡洛流程，改进导航、数据组织和阅读顺序。

- 方法功能目前集中在`src/app/methods/[methodId]/page.tsx`，主要以`activeTab`管理；`data`、`offset`、`trueBeta/trueEta/trueGamma`已有深链用途。
- 适用范围主要展示汇总统计与图表。当前方法级chunks目录中MDM有499片，MLE、WMLE各50片；部分重复次数分片来自同一结果的前缀，不能当作独立实验累加。
- Research00主交付有13个参数组合，各含n=7/15/30、每个n各50份样本，保留完整观测、八种方法配置的估计、配置及依赖快照；历史批次的抽样和方法版本不完全相同。
- `WEIBULL_DATA_ROOT`已接通外部数据，网页当前读`public/studies`；`monte-carlo`尚无登记批次供网页读取的接口。公共实验manifest和科研启动器的版本记录尚未与网页索引贯通。

## 页面与跨方法导航

方法首页保留原理介绍，现有功能改为共享外框下的独立子页面；导航外观可以延续Tab。

| 内容 | 目标路由 |
|---|---|
| 方法介绍 | `/methods/{methodId}` |
| 程序流程 | `/methods/{methodId}/process` |
| 计算过程 | `/methods/{methodId}/calculation` |
| 结果分析 | `/methods/{methodId}/analysis` |
| 适用范围 | `/methods/{methodId}/applicability` |
| 可信性验证 | `/methods/{methodId}/verification` |
| 方法对比 | `/methods/{methodId}/compare` |

- 共享外框提供方法选择器。由MDM切至MLE时继续停留在同一功能，无需返回方法总览。
- 方法、参数组合、样本量和方法专属参数使用左右箭头切换，保持当前值可见，并显示可切换的边界状态。
- 地址保存批次、数据/统计/来源视图及必要筛选条件；支持直达、刷新、收藏、前进后退。同一方法内切换功能保留必要计算上下文。
- 跨方法保留兼容参数和视图；同一批次确有相同样本身份时保留选中样本。方法专属配置分别保存；缺少目标结果明确提示，不悄悄改条件或自动重算。
- 方法列表复用现有注册与状态，数据可用性来自索引。可阅读历史数据与当前算法已验证、计算器已开放分别判断。
- 原有深链、案例到计算过程的跳转和计算器入口继续有效，旧入口按明确规则接入新路由。

## 适用范围的展示顺序

顶部保留紧凑的方法、批次与参数选择，主体尽量留给表格；样本数据与估计结果采用类似工作表的切换，保持同一组合和样本编号。主区提供以下视图，统计大卡片与图表不常驻数据视图上方。

主视图只保留必要字段、数值、操作和状态；清理重复备注及长按钮文字，协议和追溯信息在计算来源中查看。

| 视图 | 展示内容 |
|---|---|
| **数据记录（默认）** | 样本编号、完整有序观测、三个参数估计及状态；按需查看拟合指标、失败原因、边界与已有过程信息 |
| 统计分析 | 复用并整理原汇总表、箱线图、密度图和热力图；注明有效数、失败数及统计口径 |
| 计算来源 | 计算时间、配置、抽样协议、代码版本、数据身份及文件校验 |

- 样本表以样本编号为行、顺序统计量为列，可连续查看完整观测；估计结果表直接显示三个参数估计及状态，并能定位到相应样本。展开详情补充信息，不把所有观测都藏在逐行详情中。
- 固定表头与样本编号，数字对齐，宽表在主区内横向滚动；支持选中复制、按组合/样本量/编号/状态筛选、排序及导出。界面精度可调整，复制和导出保留完整值。
- 保留失败记录和已有候选值；分页或按需加载控制渲染量，不丢失记录。本期聚焦只读浏览、核对与导出。
- 选择记录可看相关已有诊断与图表；统计视图可定位对应记录，并保留返回位置。仅有汇总数据的图不伪造逐点对应。
- 旧分片缺完整样本或来源时如实显示缺项，不用当前算法重算来冒充历史观测。
- 方法对比复用同一数据读取与记录身份，保留横向比较能力，避免另建独立数据和统计口径。

- 批次保存实际样本、逐次估计、汇总与计算记录；网站只按已登记索引读取，运行时不依赖科研工作目录。现有`public/studies`读取保留兼容。
- manifest是生成时的完整记录；软件数据卡由其生成，保存必要摘要、相对路径与manifest哈希，不人工维护两套计算事实。
- 记录实际开始/完成时间、登记时间、方法与变体、参数网格、样本量、重复次数、抽样程序与种子规则、成功/失败及指标口径。
- 绑定入口脚本、软件仓与科研仓提交、dirty状态、关键代码/权重哈希及必要运行环境。需保留的未提交改动另存快照或补丁；路径不能代替当时的代码内容。
- 样本与估计以稳定身份关联；数据文件记录行数、大小及SHA-256。截取、补算、导入、格式转换登记来源批次、范围及程序，区分历史估计与新计算。
- Research00只读导入data，保留原冻结交付及版本身份；网页数据记录来源哈希，不人工双份编辑。旧分片只登记能证实的来源，未知项不编造。
- 新文件型实验沿用公共抽样、runner、指标和保存流程，自动生成追溯记录与数据卡，并为完整样本浏览补充样本保存能力。大规模计算继续使用Python批量执行。

## 验收标准

- 从一个方法的适用范围直接切换另一方法；同功能保持，兼容条件保留，缺数据提示明确。
- 数据首屏以可连续浏览的表格为主，样本表可直接查看完整观测，估计结果表可直接查看三参数；固定表头/编号、筛选、排序和复制可用。工作表及统计切换回来保留筛选、选中记录和浏览位置。
- Research00导入样本与估计按源数据核对，导出保留完整数值；历史原件哈希不变。不同协议及重复次数前缀不混成独立重复。
- 从网页批次可定位data文件、配置和可恢复的代码版本；新实验索引与manifest一致，缺数据或哈希变化可被识别。
- 直达、刷新、前进后退及原有深链有效；方法介绍、流程、计算过程、结果分析、验证和对比回归通过。
- 真实浏览器验证桌面、半屏和手机。宽表只在自身区域滚动，关键操作可触达；避免一次渲染全部重复记录。
- 按改动运行应用检查、类型检查与数据合同定向测试；结构检查不代替浏览器交互验收。
