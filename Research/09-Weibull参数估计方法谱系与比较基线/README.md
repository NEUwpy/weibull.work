# Research09：三参数Weibull参数估计方法的评价依据

> ACTIVE · INDEPENDENT · 更新：2026-09-28。

## 研究问题

完整样本、尤其小样本条件下，怎样评价三参数Weibull参数估计方法的有效性？先依据文献选择合理对照，再通过Monte Carlo评价参数精度、估计稳定性与有效求解能力；真实数据补充拟合和实际可用性。

报告归纳选择规律，不预设固定benchmark组合。主线为：研究问题 → 四类估计思路 → 文献实际选择及原因 → 模拟评价 → 真实数据 → 综合判断。
