## 要解决的问题

在写 Weibull 参数估计论文时，如何有依据地回答：**该与哪些方法比较，为什么选它们，用什么指标比较，以及这些选择是否覆盖近十年的重要进展？**

最终产物是一份按研究场景组织的基线选择依据，包括可追溯的方法谱系、近期方法候选、指标使用证据和研究动向。不预设存在一个适用于所有场景的“公认最优方法”，也不把高引用量直接当成估计性能证据。

用户关心的四件事同时保留：权威与代表性、方法分类、评价指标、近年动向。优先服务当前三参数 Weibull 小样本研究；普通二参数 Weibull 作为相邻证据单独整理。

## 初步判断

“经典方法 + 同任务强基线 + 近期相关方法”比按年代替换对照组更合理。经典方法提供共同参照；近期方法必须经过适用性审查，不能为了显得新就将不同分布、不同先验信息或不同观测机制的方法放在一起排名。

现有系统的八类方法可以帮助定位资料，但不直接当作本研究的统计分类。建议先按**估计原理**建立下列工作分类，全文筛选后允许合并或调整：

| 工作分类 | 代表路线 | 分类时要核对什么 |
|---|---|---|
| 似然与估计方程 | MLE、修正/加权/惩罚似然、偏差修正 | 具体目标或方程、约束、修正对象；MMLE 等同名缩写不能直接合并 |
| 概率间距 | MPS/MPSE、间距扩展 | 与似然分开编码；并列值及删失扩展须核对原文 |
| 分布距离与最小差异 | CDF-LS、加权距离、MDM/MDE | CDF 距离、分位点距离、尺度离散性不是同一个目标 |
| 概率图与回归 | LRE、相关系数法、RRX/RRY | 绘图位置、回归方向、位置参数处理及后续估计步骤 |
| 矩、分位数与构造统计量 | MM、PWM/L-moments、截尾 L 矩、百分位、不变量统计量 | 已知参数、样本统计量、可识别性；保留子家族 |
| 贝叶斯推断 | 先验与似然、后验均值/中位数/MAP、区间 | 必须指定先验与决策损失，不能只写“Bayesian” |
| 学习型估计与混合估计 | 直接 NN、过程量学习、自适应修正/选择 | 训练信息、训练域、目标、部署时可用信息 |

“稳健性”“小样本”“删失”“区间推断”作为跨家族问题标签；PSO、差分进化、梯度优化、MCMC 等另记为计算工具。灰色方法等暂保留独立标签，待其实际数学构造核验后归类，不因出现在旧综述中就自动列为必比基线。

## 当前基线建议

对于**三参数、完整独立样本、n约5—20**，建议保留MLE、Cousineau WMLE、MPS、明确版本的回归/CCM；MDM改进研究保留原始MDM。近期对照优先考虑已有的BPNN（2025），SAM（2023）作为近期非学习候选；LM进入家族覆盖与宽形状域检验。若关注β<1，进一步审计Tsukada（2025）组合估计；污染加入PITE，删失加入ICP-CDF-LS，求解效率加入ADGBO。

参数评价以逐参数Bias、RMSE和SD为主，寿命应用另评估目标分位点。现有文献的联合误差定义不同，不能宣称已有统一标准；同时记录失败、极端尾部及计算成本。具体依据与优先级见结果文件。

上述名单还不是“一起运行即可”的实验配置。某篇方法允许位置估计等于样本最小值，而当前代码要求严格小于最小值时，应先解释定义差异。较新论文的最小仿真样本量也可能大于本项目所称的小样本范围。

建议最终对照组控制在能承担明确比较责任的少量方法：经典锚点、当前任务强基线、近期实质改进各有覆盖；同源改进还要有母方法消融。方法数量由证据决定。
