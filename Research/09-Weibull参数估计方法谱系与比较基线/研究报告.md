# 三参数 Weibull 参数估计方法的比较对象选择与评价依据

> 阶段性研究报告 · 2026-09-27

## 第一章 研究背景与需求

提出一种新的参数估计方法后，需要通过与已有方法比较，判断改进是否成立。然而，对照方法的选择本身缺少明确依据：只使用提出已久的经典方法，可能遗漏近期具有竞争力的工作；仅选择新方法，又可能失去共同参照。即使方法名称相同，绘图位置、参数约束和求解程序不同，也可能产生不同结果。因此，论文需要解释的不只是“比了哪些方法”，还包括这些方法为什么具有代表性、实际比较的是哪个版本。

本研究源于三参数 Weibull 小样本估计的实际需要。已有临时比较采用 LS、LRE、WMLE 和 MLE，但尚需核清它们的统计构造和实现来源，并判断是否应加入近10—20年的方法。杨小玉等的综述[1]提供了文献入口；其分类和推荐仍需结合原始论文及后续研究核验，不能直接当作最终选择依据。

另一个困难是部分方法不能对所有样本返回有效估计。若直接删除这些样本，或把优化器失败统称为“方法无解”，就可能改变比较对象，甚至把求解器的不足当成新方法的优势。评价方案因而必须同时处理估计精度、结果可用性及计算成本。

本研究的目标是形成一套可用于论文的选择依据：针对给定估计任务，确定应比较的方法及版本，说明纳入理由，并给出一致的评价规则。当前重点为三参数 Weibull、完整独立样本和小样本点估计；删失、污染及二参数问题作为扩展场景单独讨论。

## 第二章 研究问题

上述需求归结为四个相互衔接的问题。

**问题一：已有方法如何分类，什么构成代表性？** 需要区分估计原理、数值求解工具和适用场景，避免把不同名称误认为不同统计方法。代表性应考察原始构造、后续采用和同任务相关性；发表年代或引用量不能单独证明估计性能。

**问题二：当前论文应选择哪些对照，近期方法为什么纳入或暂缓？** 在经典参照之外，需要识别近年的直接竞争方法，并检查它们是否估计相同参数、使用相同观测信息、适用于目标样本量。不同任务中的优秀方法不能直接移入同一排名。

**问题三：选中的方法究竟怎样实现，版本选择是否有依据？** 方法名称必须落实为公式、参数域、经验概率或权重、求解步骤和接受条件。现有 LS、LRE、WMLE、MLE 是核查实例，用于检验文献名称与实际程序是否对应。

**问题四：用什么指标比较，部分样本无有效估计时怎样处理？** 需要分别评价参数误差、寿命预测目标和数值可用性，并明确条件精度与全样本使用效果的区别。

这四个问题决定了研究顺序：先建立方法分类，再筛选对照；随后确认实际版本，最后规定比较口径。未经版本核查和失败处理的性能排名，不足以回答新方法是否具有优势。

## 第三章 研究内容与结果

### 3.1 研究材料与分析方法

研究以本地参数估计文献库为起点，采用文献内容分析、实现溯源和针对性数值验证三种方法。

文献内容分析从已有综述追溯原始研究，提取估计原理、参数数量、样本量、参数域、观测机制、对照方法和评价指标。当前已盘点203个活动文献编号及18个历史独有编号，并从其中14篇来源形成第一轮证据，包括2篇综述、11篇比较或方法研究和1篇WMLE构造论文。编号尚未全部按独立论文去重；这是一组有目的选取的相关文献，不能据此估计全领域方法占比或年度增长率。逐篇提取结果见[附录A：文献证据](附录A-文献证据.md)。

2026年9月27日，原先待补的DMMLE、Park 2017、Nagatsuka 2013、删失估计及MPS原始论文已全部入库，另增加4篇稳健调参相关材料。5篇已定向核查方法及模型定义：Park和DMMLE增加了原始示例的数值核验，其他三篇尚未完成数值实现。首轮14篇内容分析与新增定向核查分开登记，不合并冒充系统统计。编号与全文链接见[新入库材料状态](附录A-文献证据.md)。

实现溯源将原文公式与四方法源码、历史版本、生成程序和存档结果对应。数值验证包括40次抽样复算、工作簿9350个单元格核对，以及对失败样本的独立求根检查。它们用于确认程序行为和产物来源，不用于推断方法总体优劣。复算与版本证据见[附录B：方法实现与版本](附录B-方法实现与版本.md)。

### 3.2 方法分类与近期研究方向

已有材料支持按估计原理形成七类工作分类。

| 估计原理 | 主要构造 | 代表路线 |
|---|---|---|
| 似然与估计方程 | 最大化样本似然，或修正参数估计方程 | MLE、Cousineau WMLE |
| 概率间距 | 最大化排序样本对应的相邻CDF间距乘积 | MPS/MPSE |
| 概率图与回归 | 使变换后的样本接近直线，再恢复参数 | LS、LRE、CCM/CCWP |
| 分布距离与差异准则 | 最小化CDF、分位点或构造量之间的差异 | CDF-LS、MDM |
| 矩、分位数与构造统计量 | 将样本统计量与理论关系匹配 | MM、PWM、L矩、百分位及组合估计 |
| 贝叶斯推断 | 根据先验和似然构造后验估计 | 后验均值、中位数、MAP及区间估计 |
| 学习型与混合估计 | 从样本特征预测参数，或学习统计估计中的修正量 | BPNN、统计估计与学习校正的组合 |

污染稳健性、删失和小样本是跨类别的研究问题；粒子群、梯度搜索等是计算工具。例如，新优化器求解MLE可以提高求解可靠性，但不会因此自动形成新的统计估计准则。

近年已有工作并不限于神经网络。MDM通过样本与经验概率构造伪尺度，最小化伪尺度差异[2]；SAM通过位置参数与其他参数的逐次更新处理小样本估计[3]；BPNN直接学习样本特征到三参数的映射[4]。这些方法与当前任务直接相关。

其他进展主要对应特定困难：PITE研究污染下的稳健估计[5]，ICP-CDF-LS研究删失信息的利用[6]，ADGBO改进三参数MLE的数值求解[7]。这些证据足以说明近期仍有实质发展，但尚不能判断哪一方向占主导，也不能把当前收集到的论文视为近20年的完整覆盖。

### 3.3 对照方法的选择依据

对照组应覆盖共同参照、不同估计原理和近期同任务竞争方法。每个方法须承担明确的比较作用，而非仅增加方法数量。

| 方法 | 建议位置 | 纳入理由及条件 |
|---|---|---|
| MLE | 经典参照 | 提供通行似然基准；需明确有限候选、边界发散及求解规则 |
| Cousineau WMLE | 主比较优先 | 已针对有限样本偏差修正[8]，应使用可靠求根和可追溯权重 |
| MPS | 主比较优先 | 提供不同于似然的估计准则；已有独立比较及近期采用证据[5,9] |
| 一个明确版本的相关/回归方法 | 工程回归参照 | 覆盖概率图路线；须写明分数、回归方向和位置处理 |
| 原始MDM | MDM改进研究必留 | 判断收益来自新增步骤还是母方法[2] |
| SAM（2023） | 近期非学习候选 | 原文包含n=5、10、15、20，直接覆盖极小样本问题[3] |
| BPNN（2025） | 近期学习候选 | 原文训练和比较覆盖n=5—20，直接估计三个参数[4] |
| DMMLE（2025） | 近期偏差修正候选 | 两个作者示例已复算吻合；原仿真从n=50开始，n=5—20表现及边界接受规则仍须核验 |
| Nagatsuka变换估计（2013） | 近20年独立构造候选 | 以位置、尺度不变的统计量先估形状；积分求解尚未复现 |
| L矩（LM） | 补充候选 | 补充矩类原理，宽形状域研究时应提高优先级[9] |

DMMLE与Nagatsuka方法的原文事实及核验范围见[附录A新补原文核查](附录A-文献证据.md)。DMMLE改变修改似然的得分方程，属于近期非学习构造。Nassar–Elshahhat（2024）研究二参数删失模型，因参数数量和观测机制均不匹配，排除当前主比较。

学习方法还须公开训练参数域、训练数据预算、调参规则和训练/推断成本，测试样本不能用于选择网络或阈值。

这份名单是基于现有证据的条件推荐。SAM与BPNN应优先核对并复现；尚未复现不构成科学上的排除理由。BPNN原训练形状域从1开始，因此不能直接代表形状小于1时的近期估计水平。污染、删失或求解效率是论文主要主张时，分别加入PITE、ICP-CDF-LS或同目标优化器；否则不宜将它们强行放入完整无污染样本的主表。

选择近期方法的依据应是任务重合和构造差异，不能仅以发表年份筛选。反过来，MLE、WMLE等经典方法仍被近期研究采用[5]，其年代较早也不是剔除理由。当前缺少全面的独立采用频次统计，因而还不能将该名单称为“公认最权威方法排名”。

### 3.4 现有四方法的实现及版本差异

以下统一以β、η、γ表示形状、尺度和位置。令排序样本的对数寿命为xᵢ=ln(t₍ᵢ₎−γ)，理论分数为zᵢ。

| 方法 | 当前程序实际构造 | 文献及实现边界 |
|---|---|---|
| LS | zᵢ采用标准对数Weibull次序统计量期望；拟合x=a+bz，搜索使F比最大的γ，返回β=1/b、η=exp(a) | Soman–Misra的White回归扩展分支[10]；不是所有称作LS的方法，也未实现原文全部分支 |
| LRE | zᵢ由Bernard概率(i−0.3)/(n+0.4)双对数变换得到；最大化corr(x,z)²，拟合z=a+bx，返回β=b、η=exp(−a/b) | 项目的相关系数–OLS版本；Li提供线性化背景[11]，Park支持相关系数路线[12]，均不能直接等同于完整原文复现 |
| WMLE | 在形状、位置估计方程中加入与n及形状相关的权重修正，联立求解后恢复尺度 | Cousineau构造[8]；当前还包含非负位置约束、权重插值、形状上界及残差接受规则 |
| MLE | 多起点最大化三参数似然，从满足接受规则的收敛候选中选似然最大者 | 当前只接受形状≥1的候选；没有证明找到无限制全局极大，也未逐个证明局部极大 |

**LS与LRE的关键差别是分数构造和回归方向。** 对相同分数、相同位置和带截距回归，有

\[
F=\frac{n-2}{n-1}\frac{1}{1-r^2}.
\]

因此，在非退化情形下，最大化F与最大化相关系数平方是等价的。只用“优化目标名称不同”解释两方法差异是不充分的。另一方面，回归x对z再对斜率取倒数，一般不等于直接回归z对x；只有完全线性等特殊情形才一致。

在同一组n=7样本上，分别更换分数和回归方向，得到的形状估计从3.819变到4.581；当前LS和LRE分别约为4.129和4.262。该诊断说明实现选择会影响估计，并不证明某一版本更准确。

版本溯源还表明，8月25日与9月案例的LS一致，但LRE、WMLE和MLE的搜索策略已有变化；9月7日和9月21日案例的四方法源码与本次核查版本一致。因此，历史结果不能仅凭同名方法合并统计。

现版本的选用可以由文献来源、统一接口和历史连续性解释，但尚无系统版本比较证明其最优。正式论文应披露版本选择，而不能把“已有代码可用”写成“该版本优于其他版本”。尤其是当前LRE，不宜继续称为Li某个近似公式的直接实现。

新核查的Park（2017）明确给出“相关系数选位置＋概率图回归”及“相关系数选位置＋二参数MLE”两个版本；当前实现接近前者，但绘图位置不同。原文24点示例中，MLE2三个参数复算吻合表中舍入精度，回归版本的形状有约0.000761差异，详见附录B；不能宣称两版均完全复现。

### 3.5 评价指标与无有效估计时的处理

已有论文反复采用逐参数Bias、RMSE和SD，但三参数联合指标的定义并不统一[3–5,9]。因此，模拟比较宜保留逐参数结果，以免联合分数掩盖某个参数的退化。对同一有效重复集合S，定义

\[
\operatorname{Bias}_S=\frac{1}{|S|}\sum_{r\in S}(\widehat\theta_r-\theta),\qquad
\operatorname{RMSE}_S=\sqrt{\frac{1}{|S|}\sum_{r\in S}(\widehat\theta_r-\theta)^2}.
\]

SD用于描述重复抽样波动；SD较低不必然意味着RMSE较低。使用相同集合及分母|S|时，RMSE²=SD²+Bias²。形状无量纲，尺度和位置有时间单位，联合指标还需说明标准化方式。位置真值为0时，以真位置为分母的相对误差不适用。可预先采用eβ=(β̂−β)/β、eη=(η̂−η)/η、eγ=(γ̂−γ)/η，再汇总平方误差；这是本研究的设计建议，并非已有统一标准。区间估计则须同时报告覆盖率和区间长度。

论文若面向寿命预测，应另行评价目标分位点；例如99%可靠度寿命为q₀.₀₁=γ+η[−ln(0.99)]^(1/β)。实测数据没有已知真参数，不能计算真参数RMSE，应采用相应拟合、预测或区间指标。当前四方法返回的R²位于双对数概率图空间，接近LRE本身的优化目标，不能作为独立参数精度证据。

失败处理首先取决于失败的含义。最新W2模拟案例中，n=7时WMLE原记录为47/50组有效，其余3组因方程残差未通过而失败。采用已有的另一求根程序后，3组都找到了原权重、原约束下的根；独立代入的残差平方和均小于4×10⁻²⁷。**这三组属于数值漏根，不是估计方程无解。** 同样，当前MLE的`unbounded`标签记录的是搜索和筛选路径，不能逐样本证明不存在有限局部候选。

这一结果直接影响比较规则：必须先排查已知求解问题，再评价方法可用性。建议采用以下统一口径。

1. 固定同一批样本和重复编号，预先确定各方法的初值、重试、容差及预算。失败不重新抽样替换，也不根据真参数选根。
2. 分别报告有效率、数值失败、无效输出及有充分依据的理论无解；合法但误差极大的估计仍属于有效输出，应保留。
3. 两方法在共同有效编号上比较Bias、RMSE，并报告该集合占全部样本的比例。各自成功集合不同，其RMSE不能直接当作同一总体的排名。
4. 若评价覆盖全部输入的实际使用效果，预先规定失败后的回退方法，并以“原方法＋回退”命名整个流程。失败不得随意填0、真值或巨大误差后混算普通RMSE。还可在全部重复上报告“有效且误差不超过阈值”的比例曲线，阈值及无量纲误差预先定义。

新增DMMLE还揭示了边界判据不能机械统一：它按定义取γ̂=min(x)，而其他算法可能要求γ̂<min(x)。应统一所估分布、样本与评价目标，分别披露各准则的合法边界；将DMMLE结果裁剪或全部判失败都会改变比较。重复最小值造成的公式不可计算则须单独记录。

该协议将“能否返回有效估计”和“返回后有多准确”同时呈现。共同有效样本上的优势只能解释为条件优势；只有明确完整流程和使用目标，才能进一步讨论整体使用效果。

## 第四章 总结与结论

针对三参数Weibull完整小样本估计，现有证据支持以MLE、Cousineau WMLE、MPS及明确版本的概率图回归构成主要参照，并优先核查SAM和BPNN等近期同任务方法；研究某一方法的改进时，还应保留其原始版本。对照组应由比较责任与适用条件确定，不能以年代新旧或实现便利代替选取依据。

方法比较必须落实到具体版本。现有LS与LRE在理论分数和回归方向上存在实质差别，部分旧说明的文献归属不准确；WMLE和MLE的约束与接受规则也会改变有效率。WMLE三次失败的恢复进一步表明，求解器失败不能直接作为方法无解或新方法优越性的证据。

评价应同时报告逐参数精度、目标寿命表现和有效率，并清楚区分共同有效样本上的条件结果与含回退的全样本流程。当前已经形成选取依据和四方法实现证据，但尚未完成近10—20年的系统文献统计、近期候选的完整复现及统一性能实验。因此，本报告给出的是可继续验证的对照方案，尚不能认定一个普适最优方法或最终对照名单。
