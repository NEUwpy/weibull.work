# 固定真值：MLE、MMLE 全版本、MME 与 WMLE

本批对应邮箱任务 `research09-mmle-versions-002`。已完成6000组共享样本、15行方法版本的比较及核验；一张汇总表和一张 PNG 见下方。固定真值下，MMLE-IV 的联合 RMSE 最低，WMLE 的偏差更小、成功率略高；结论限本批条件和求解规则。

## 设计与复用

真值固定为 β=2、η=1000、γ=1000，完整、无删失的三参数 Weibull 样本；n=7、10、15、20、50，每 n 1200组。上一批的“每 n 1200组”来自12个不同真值条件，本批只有一个真值，因此改为12个100次重复块。块0的500组样本沿用上一批，其余5500组新增；不是12个真值条件，也不把旧样本当作新证据。

继续调用项目共享的 `generate_sample`、`run_method`、`run_experiment` 与 `summarize_standard_errors`，沿用上一批 MMLE-I、WMLE 和 E09 漏解复核。新增 Cohen–Whitten MMLE II–V、MME I–III 的研究用求解器和 MLE 包装；没有改动生产方法注册、平台接口或界面。所有求解器统一除以固定单位1000后计算，再恢复原始尺度；不向求解器传入真实 β/η/γ。

## 方法身份与成功口径

本批共15行：MLE、WMLE、5个非负位置 MMLE、3个 MME，以及5个 MMLE 原文参数域敏感性版本。MME 是修正矩估计，不混称 MMLE。

- **MLE（有限局部解）**：复用项目 `python/methods/mle.py` 的五起点似然优化。只接受收敛、β̂≥1、η̂>0、0≤γ̂<x₁ 的有限候选，选择其中最高似然。三参数无约束似然可在 β<1、γ趋近 x₁ 时无界，所以该行不能解释为已找到无约束全局 MLE，也不是完整 Hirose 软件复现。
- **MMLE I–V**：均保留原文形状与尺度两条似然方程，位置方程分别替换为最小值分位约束、最小值期望、总体均值=样本均值、总体方差=样本方差、总体中位数=样本中位数。原文式号依次为(3.4)、(3.6)、(3.7)、(3.8)、(3.9)。使用 ddof=1 的样本方差，偶数 n 的中位数取中间两个值的均值。
- **MMLE 非负位置主比较**：β̂∈(0.1,9.99)，0≤γ̂≤x₁−10⁻⁴（原始尺度），沿用上一批 MMLE-I 参数域。
- **MMLE 原文参数域**：β̂∈(0.1,15)，样本均值−10样本标准差≤γ̂≤x₁−10⁻⁴，允许负位置。它与非负位置版分列，不将允许域变化混为求解器改进。
- **MMLE 根选择**：97点对数位置间隙扫描、Brent 括区求根。II–V 还在离散曲线的局部极值处作有界优化以隔离相邻双根，III 显式查找 β̂=1 解支；I沿用上一批单根求解器。从 x₁ 向下取首个满足参数域和方程残差平方和≤10⁻¹²的根。现代求根与原文 Fortran 的有限次二分/插值不同，不能称作原始程序逐位复现。
- **MME I–III**：复现原文(4.5)、(4.7)、(4.9)与均值、方差方程；β̂∈(0.1,15)。扫301点对数形状网格，并检查局部极值，再 Brent 求根。多根时先保留0≤γ̂<x₁的模型有效根，再选离样本偏度矩初值最近的形状根；不使用真值选根。没有有效根时保留候选诊断，但记为失败。原文矩方程本身不自动保证位置支持域，因此“算出数值”不等于有效成功。
- **WMLE**：复用 Cousineau 权重方程、项目权重表和五起点优化，仅对生产实现拒绝的样本进行 E09 profile 漏解复核。β̂∈(0.1,9.99)，γ̂≥0，按加权方程残差和共享检查验收。J3 表的形状插值超出[0.1,5]取端点，是继承的实现边界。

所有行还经过共享状态检查：有限正形状与尺度、收敛、位置严格低于样本最小值及框架间隙容差。成功率分母始终为每 n 1200；失败不填补为真值、不以零误差进入精度。`failure_reasons.csv` 区分搜索域内未找到根、形状越界、位置支持域无效、优化失败/无界候选和共享质量检查拒绝。“未找到根”是本求解与搜索域的结论，不能直接证明理论无解。

MMLE-III 有特殊解支：β̂=1 时尺度似然方程使 η̂=样本均值−γ̂，均值约束随之自动满足。只要形状剖面在允许位置域内经过1，该解支便会被首根规则选到。这可能提高有效成功率，却造成对真值 β=2 的系统偏差。`branch_diagnostics.csv` 单列 β̂=1、β̂<1、负位置、多根和 WMLE 复核次数。

## 原文核验边界

核对了182-091原始 PDF 印刷页2637–2641的方程及2652的 Table VI。使用 Table V 的100个四位小数观测值代入：8个版本中6个与 Table VI 的三个估计值最大差异<0.001；MMLE-III 最大差异约0.00214，MME-II约0.01297。后两处差异直接见于原始 PDF，并非仅 OCR 错误；方程解分别为(1.511861,0.974681,0.081120)与(1.552032,1.007361,0.054294)。本批使用满足方程的解，明确保留表格差异，不断言其原因已被查明。`verification.json` 同时保存表值、求解值及各自代回残差。

另对15组固定样本检查 MMLE I–V 两个参数域与 MME I–III 共195项更密网格结果。完整结果的76825个成功估计均通过方程代回或 MLE 似然核验；226个搜索失败经更密网格复查仍失败，其中 III/IV 的剩余无根案例全部复查。旧500组样本哈希及三个复用方法的1500行状态/估计全部一致。数值细节见 `final_verification.json` 和 `manifest.json`。

本批未纳入 Kundu–Raqab 2009：它属于另一条构造，不是 Cohen–Whitten I–V 系列；本邮件允许将其列为范围外，本批也没有核验实现它。没有用库中名称相同的旧 MMLE 标签替代该构造。

## 指标与表图

单参数 Bias=mean(估计−真值)，RMSE=√mean((估计−真值)²)；原始尺度与归一化尺度都保存。归一化误差向量为 e=((β̂−2)/2,(η̂−1000)/1000,(γ̂−1000)/1000)。

沿用 J1=√mean(||e||²)，它本身就是联合 RMSE；联合偏差另列为 ||mean(e)||，不虚构有正负号的“J1偏差”。所有主精度按各方法自己的成功样本计算，样本选择不同，不能直接把较小值解读为对同样本的优势。`paired_vs_wmle.csv` 用两方法共同成功样本补充比较，并给2000次按重复块分层的配对 bootstrap 区间。

`汇总表.csv` 为一张15行宽表，列含每 n 的有效次数、总次数、成功率、J1、联合偏差及每参数 Bias/RMSE。`汇总表.md` 和下方紧凑表每格展示“成功率 / J1”。`全版本成功率与精度.png` 在同一张 PNG 内展示全部版本：上排为非负位置主比较，下排为 MMLE 原文参数域敏感性；MLE、WMLE在下排重复作为参照。

另保留 E09 失败平方损失固定为3的 `J1_failure3` 敏感性列；这个常数是诊断规则，不是失败的真实误差，不据此替代成功率或宣布总体优劣。

本固定真值下，MMLE-IV 的联合 RMSE 最低：n=7/10/15/20/50 的 J1 为0.626/0.523/0.415/0.351/0.218，成功率为100%/100%/100%/99.9%/99.3%。WMLE 则为0.718/0.632/0.523/0.480/0.273，成功率为99.9%/99.9%/99.9%/100%/100%。两者共同成功样本中，MMLE-IV 的 J1 降低约13%–27%，五个配对 bootstrap 差值区间均低于0；此结论限本次真值与实现规则。

“更准”还需区分偏差与 RMSE：WMLE 的三个参数在五个 n 下绝对偏差都比 MMLE-IV 小，联合偏差范数也更小（n=7 为0.340 vs 0.532；n=50 为0.041 vs 0.136）。MMLE-IV 以更明显的形状/尺度低估和位置高估，换来较小总体平方误差；它并非逐参数、逐指标都优于 WMLE，尤其 n=7 的位置 RMSE 略高。表格没有把低联合 RMSE 写成低偏差。

其他版本的成功率与精度存在明显冲突。MMLE-I 在 n=7 仅37.3%有效，MME-I 为41.9%；成功子集上的较小误差不能弥补大部分样本没有估计。MMLE-III 在 n≤15 达100%成功，但大量 β̂=1 解支使其 J1 仍高于 WMLE。其五个 n 的 β̂=1 次数为1099/1157/1186/1126/10；n=20→50 的精度跃迁伴随解支切换，不能只解释为样本量增加的统计收益。固定最小间隙会限制靠近 x₁ 的解支。

允许负位置主要提高 MMLE-I、II、V 的成功率，却增加尾部误差。例如 n=7，MMLE-I 从37.3%/0.873变为48.8%/2.240；这不是统一性能改进。修正后 III、IV 的两个参数域在本批给出相同主结果。普通 MLE 的有限局部实现小样本不稳：n=7 成功率43.3%、J1=2.006，n=50 才达到99.9%、J1=0.308；不能据此宣称所有 MLE 求解实现均如此。

结论不外推到其他真值、删失、真实数据、其他 MMLE 源流或不同根选择。没有为了寻找新的排名再扩展实验网格。

初始60个重复块存于 `blocks/`，保留首次有限网格计算的90000行。核验发现相邻双根可能落在同一格内、端点同号而被跳过，故以 `refine.py` 隔离局部极值并重算11个新增版本，66000行标准流水线结果存于 `refined_blocks/`。最终 `per_sample.csv.gz` 合并4个复用版本与11个修正版本，共90000行；初始记录不是最终排名。修正改变50行的估计或状态，其中7行从失败恢复成功，其他为更早解支替换。逐项差异见 `root_refinement_changes.csv`。

已有块只在对应源码哈希一致时复用；更改求解契约须使用新的输出目录。`manifest.json`、`environment.json` 与 `sources.json` 记录源码、版本、文献和运行环境。所有成功估计的方程核验与搜索失败加密复查见 `final_verification.json`。
