# MMLE-I为什么失败更多，以及它为何被提出

**本批不能据失败率认定MMLE-I比MLE弱：MMLE必须在非负位置域找到方程根，MLE则接受约束似然的零位置边界解；两种“成功”不等价。** 同时，MMLE-I并非普遍更准，本批n=15及以上其成功子集的联合RMSE确实高于MLE。选用的是有原始来源的经典CW-I，但此前“最常用、统一默认版本”的表述证据不足，应纠正。

**一句话：MMLE为未知位置导致三参数MLE非正规、可能无界或难算的问题提供替代估计，值得在相应模型风险和文献条件下比较；本轮非负位置约束、不同边界验收与β=2的小样本条件，使CW-I不占可用率优势，不能推广成所有MMLE都不如MLE。**

## 2. MLE成功是否意味着参数可靠

| n | MLE成功 | γ̂=0（占成功） | β̂≥5 | β̂≥10 | γ贴近x₁至间隙≤1 | β偏差 |
|---|---:|---:|---:|---:|---:|---:|
| 7 | 519 | 182（35.1%） | 175 | 18 | 0 | +2.191 |
| 10 | 715 | 103（14.4%） | 123 | 3 | 0 | +0.938 |
| 15 | 965 | 53（5.5%） | 57 | 1 | 0 | +0.320 |
| 20 | 1087 | 34（3.1%） | 38 | 0 | 0 | +0.136 |
| 50 | 1199 | 0 | 1 | 0 | 0 | −0.051 |

**不是贴近x₁被误算成功。** 所有成功MLE的原始位置间隙均大于1，各n最小间隙17.419/4.488/2.374/1.674/2.630；没有一例违反CW-I的10⁻⁴上边界间隙。这里“≤1”“β≥5/10”是公开的描述性诊断阈值，不是公认病态判据。[边界CSV](MLE边界与形状.csv)

n=7的零位置组β均值7.178，非零位置组均值2.578；零位置组对总β偏差贡献为(182/519)×(7.178−2)=1.816，占总偏差2.191的82.9%。该组η平均偏差+1041，γ偏差−1000。**我们的推断：高形状偏差主要与错误的零位置边界拟合一致，而非γ→x₁的奇异边界。** γ̂=0在非负约束MLE中可合法接受，不能仅因估计不准就事后判失败。

两者都要求0≤γ̂<x₁，但MLE允许γ=0的约束最优候选不满足内部位置得分为零；CW-I仍必须精确满足F(x₁)=1/(n+1)，不能把端点近似值当方程解。本批MLE也无β=9.99上限，CW-I有；若仅把MLE的γ=0成功记录单列为非内部解，其余成功数337/612/912/1053/1199，n=7、10的可用数排序即反转。这只是敏感性计数，未改原验收。完整入口见[MLE源码](D:/weibull/python/methods/mle.py:149)、[MLE研究包装](../../../20261005-MLE-MMLE全版本固定真值比较/experiment.py:188)。

此外，图中的MLE实际是项目多起点优化选出的**有限局部候选**（排除β<1），并非已证明存在的无约束全局MLE；MMLE是方程根。成功率表示各自实现按声明规则提供有效数值估计的比例，不是统一的参数准确率。

“大偏差”仅指β̂≥5，或|η̂−1000|≥500，或|γ̂−1000|≥500的至少一项成立；是描述性阈值，不是新增失败规则。在MMLE成功且MLE也成功的样本上，MLE的β RMSE依次为0.621/0.599/0.525/0.530/0.451，明显小于前表对应失败组。交叉数值及η/γ完整误差见[分组CSV](按MMLE成败分组的MLE误差.csv)、[成败四格表](成败交叉表.csv)。

**我们的结论：方程可解性、约束边界和抽样误差共同作用，不能压成“方法本身更弱”或“纯粹口径问题”二选一。** 本批MMLE-I在n=7、10的成功子集联合RMSE为621/610，低于MLE的972/712；在n=15/20/50为579/530/278，高于MLE的511/427/210。精度与成功率还存在条件性取舍，不能只看失败次数。[原汇总表](../../汇总表.csv)
