## 方法与复现

科学计算沿用W(2,1000,500)冻结版本，compute.py及25个源码文件逐字节相同。MMLE采用Kundu–Raqab原始构造：位置取最小观测，删去一个最小值后固定点迭代；无Firth、额外约束或回退。MLE/WMLE 改用注册表经典实现（见下节“口径回退”）；成功判定仍为有限、正β/η、收敛、γ小于保留样本最小值。config中的不加额外上限等字段描述MMLE，不代表MLE/WMLE没有既有求解域。

在程序目录执行：

```powershell
& 'D:\weibull\python\.venv\Scripts\python.exe' -B .\draw.py
.\export_workbook.ps1
```

以上从相邻数据文件夹的CSV重绘、重导表。预览及检查文件写到系统临时目录，或由R09_ARTIFACT_CACHE指定；结果目录只放交付件（三张 PNG + 一个 Excel）。若要重新估计，使用`reproduce.py --output <不存在的新目录> --workers 6`，完成后运行新目录中的export_workbook.ps1；不要覆盖当前批次。

种子算法包含真值，各组合不是同一批随机样本。全部6000组已精确重生成核对SHA，27次拟合抽查、45个统计恒等式、150个图点、188610个Excel数据单元格及15个公式通过；三图和11张工作表预览已检查。版本与文件哈希见来源与版本.json及manifest.json。
