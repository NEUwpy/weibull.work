# 执行中补充（主口径改为「照原作者做法」+ 交付要回答的三个问题）

人的原话：「既然人家作者那么做了，咱也根据作者那个做法弄就行，没有必要比他还严谨那么多，做出来的结果，人家还觉得跟原作者的不一样，不让人信服。我现在想要的其实就是，我能体现出来 MML 和 MLE 的差别。然后呢，能体现出来在不同 n 的情况下，MML、MLE 和 WMLE 的差别。然后，并且要说清楚，这个 MML 和 MLE，就是它俩差在哪？就这这三者的差别是在哪？然后差别达到的结果在哪？」

## 1. 主口径 = 原作者的做法（这条优先于此前要求）

- 位置域、形状上界、验收规则**一律照 182-091 原文及其程序**：位置域 均值−10SD ≤ γ < x₁−10⁻⁴、形状上界 15（原文 L538–540）。
- **不要附加 γ≥0、β≤9.99 这类本批自加的限制**；也不要用比原文更严的判别把 MMLE 记为失败。
- 目的：对外能说清"这是按 Cohen & Whitten (1982) 的口径做的"，避免因我们额外加严而与原文结果不一致、失去说服力。
- 工程域（γ≥0）的结果若有，只作附注列出，**不作为主结果，也不用于给 MMLE 记失败**。
- 若原文口径下仍有失败，必须说明这是原文口径下的失败，并给出归因。

## 2. 三方法必须同一套口径

MLE、MMLE-I、WMLE 在同一口径下评（参数域、验收规则一致）；不能一边放宽一边收紧。若某方法的原始定义与原文域不兼容，明确写出来并给等价处理，不要默认厚此薄彼。

## 3. 交付必须正面回答这三个问题

1. **MMLE 与 MLE 差在哪**——机制一句话 + 数值证据（哪个参数、哪个 n、差多少）。
2. **不同 n 下三者的差别**——n=7/10/15/20/50，成功率 + Bias/SD/RMSE（逐参数 + 联合）。
3. **差别落到什么结果上**——即"这个差别意味着什么"：在什么条件下差多少、对使用者有什么实际影响（可用率、偏差、精度各占什么分量）。

## 4. 交付形式

- 表：三方法 × 5 个 n 的成功率、Bias、SD、RMSE（逐参数 + 联合 RMSE）。
- 图：按 Research00 规范（线性坐标、固定范围、图内无说明框/长备注、仅保留 PNG）。
- 一句话结论 + 上面三个问题的直接答案。
- 仍**不改动既有主结果目录**。
