# Research09研究进度与报告、PPT完善计划

> 2026-09-28 · ACTIVE · INDEPENDENT。方向依据：[用户完整研究意图及最新定位](README.md)；参考输入：[外部AI评审建议原文](资料/2026-09-28外部AI评审建议.md)。已完成差距核对与计划整理，并按用户最新澄清取消对Study01／AMDM的绑定；以下研究、报告重构与PPT修改尚未执行。本文件是唯一执行计划，后续在这里更新状态。

## 目标与当前判断

最终交付一份可独立阅读的benchmark选择研究及面向导师的PPT：对完整样本、尤其小样本的三参数Weibull新估计器说明“和谁比、为什么这样比、怎样比”，形成适用条件明确的一般推荐组合、具体方法版本及实验评价方案，再给出按创新主张增补对照的规则。

当前独立于Study01开展，不使用其方法名单、样本量、参数域、实现条件或已有结果限定答案；不开展与该Study的协议对接或重算安排。普适问题仍限定于上述统计任务，不扩展成所有Weibull应用问题。明确推荐不等于宣称存在唯一通用标准。

当前方法沿革、版本核查、模拟与真实数据的区分、MLE失败分析已有基础；主要缺口是比较习惯统计尚未集中、近期研究分布缺少统一编码、最终选择仍停留在候选池。需要补决定性证据，再压缩和重组表达。

已有成果：报告v2.0、17页PPT、两份附录；202份活动OCR与2条仅PDF记录的范围台账；44条评价记录，其中38条进入经验用途统计，确认重复模拟21条、真实应用21条、两者兼有10条；9篇定向比较矩阵含20条论文—对手关系。上述集合并不相同，均不等于独立团队数或全领域普查。

## 外部建议的采用方式

采纳其主线：从知识介绍转为选择研究；用共同基准、近期竞争性参照及与创新点相关的对照解释选择；扩大已有合格文献的比较统计；按五个问题重构；压缩基础推导，将指标、真实数据和MLE讨论落到实施决定。外部建议中“直接母方法”推广为条件规则：仅对改进已有估计器的研究要求母方法对照，其他新构造根据其主张选择近邻方法。

以下内容作为待核建议，不提前写成结论：

- 外部给出的AMDM六方法组合属于特定研究示例，本轮不将它作为优先组合或预设名单。MLE、WMLE、Park、MDM、SAM等均按任务匹配、文献采用、方法代表性和可复现性审查；所有方案均区分benchmark与被评价的新方法。
- 近期类型分布图用于说明纳入文献的研究方向；仅凭现有库内计数不能推出全领域研究重心转移，更不能把它认定为经典方法持续使用的唯一原因。若时间覆盖不足，采用分布图与具体例证，不强行画趋势。
- 20—30篇是外部建议的规模示例，不设为配额。目标是在明确检索范围内纳入合格比较研究，而不是用凑篇数制造共识。
- Bias/RMSE/SD可作为拟推荐的核心组合，需区分文献高频、指标作用与本文选择理由；目前频次不足以直接称全领域统一规范。
- 技术细节移入附录，但影响公平比较的方法定义、约束和失败分母仍须在正文说明。“不能只算成功样本RMSE”应落实为同时报告有效率和明确标注的条件误差，不意味着给失败填造参数误差。

外部原文中的内容引用占位符没有可解析的来源映射；后续证据引用以本地报告、附录和论文原文为准。

## 按依赖顺序推进

### 1. 明确文献集合，完成近期方向编码

- [ ] 以现有台账和44条记录为起点，核对独立论文身份与相关子实验；补齐会改变候选覆盖的定向检索和前向引用追踪，记录入口、检索词、日期及纳排理由。
- [ ] 时间范围建议采用2006年至2026-09-28，另列2016年以来子集；在线与卷期年份使用统一规则，同篇不重复计数。小样本工作保留实际n，统计分层先明确阈值及理由，不以论文自称“小样本”代替样本量。
- [ ] 编码分两个维度：模型／观测任务（二或三参数、完整／删失／截尾、污染、特殊可靠性结构）；创新内容（新估计准则、经典修正、数值求解、贝叶斯、学习、组合构造）。允许多标签，图中说明重叠，避免把“贝叶斯”和“删失”误作互斥类别。

**产物与完成标准：** 在既有台账、附录A和结构化证据中补齐记录；形成近期研究类型分布及代表性时间线所需数据。读者能查到每类有哪些论文、统计分母是什么、哪些仅作背景。对“研究分化／转向”的表述不得超过证据。只补已识别的覆盖缺口，不无限增加路线。

### 2. 形成文献比较习惯的核心统计

依赖阶段1确定的集合与口径。

- [ ] 核查集合内所有“普通三参数＋完整样本＋跨方法比较”论文；按模拟和真实数据分开记录，无跨方法比较、仅理论、自身性能、特殊任务不混入同一分母。
- [ ] 补齐方法类别、具体版本、对手、作者选用理由、真参数、n、重复次数、指标、真实数据作用、失败处理与原文定位。原文未说明和未核实分开，重复论文及复用实验不伪装成新增证据。
- [ ] 形成主表：方法／benchmark采用论文数／近20年采用数／小样本采用数／后续跨作者采用证据。另保留逐篇矩阵和共同出现组合，区分类别汇总与具体版本；同篇同方法计一次，提出方法自身不算对手。
- [ ] 指标统计沿用已有记录，按上述相关子集复核即可；不另开泛化指标综述。核对作者重合与重复数据，避免将引用当采用，将作者不重合自动称为完全独立研究。

**产物与完成标准：** 更新现有比较矩阵、统计数据及附录A。正文可回答“纳入的同类研究通常怎样组织对照、哪些组合反复出现”，所有计数能从逐篇记录复算。不强求出现统一默认组合；没有稳定组合时，归纳共同参照与近邻对照的选择规律。

### 3. 确定一般推荐组合、版本与增补规则

依赖阶段1—2。先根据同类文献确定基础比较需要覆盖哪些作用，再给出明确的一般推荐组合及适用条件；最后说明低形状、偏差修正、学习估计、区间或母方法改进等主张如何增补对照。增补需给出触发条件和具体推荐，不以“视情况”结束。

| 必须作出的决定 | 核查与选择依据 | 最终写法 |
|---|---|---|
| MLE采用哪种定义 | 受限／局部方案、适用域、后续采用及计算可验证性 | 一个明确版本与引用，列出约束和接受规则 |
| WMLE采用哪种权重与求解版本 | 原文各分支、后续采用、权重适用域与可复现性；不因项目已有J类权重而优先选它 | 明确推荐分支与采用理由，另列项目实现差异 |
| LS及相关回归路线推荐哪个版本 | 原文构造、共同参照作用、版本差异及重复性；项目LRE不当作领域标准 | 明确一般组合内代表与额外版本的纳入条件 |
| SAM还是PM，是否均有必要 | 极小样本任务匹配、构造差异、原文可复现性和已知停止／越界问题 | 明确首选；如不能可靠实现，给出有依据的替代选择及边界 |
| MDM是否进入一般组合，采用哪个构造 | 原文版本、适用范围、后续采用及相对其他路线新增的比较作用；不预设母方法地位或固定偏移 | 明确纳入或不纳入理由，若纳入则定义概率／偏移设置 |
| MPS、PWM／L矩、LSPF、BPNN、DMMLE是否加入 | 新增的比较作用、证据、任务范围与复现缺口；不按实现方便或已有胜负挑选 | 逐项明确补充或不纳入；不再以“视情况”结束 |

**产物与完成标准：** 在报告中形成明确的“一般推荐组合＋版本表＋按主张增补的规则＋主要候选去留理由”。每项选择能追溯文献和比较作用；尚未解决且会改变名单的关键问题要先补核。即使没有领域统一组合，也应提出有依据、适用条件明确的调研建议，不再停在候选池，不以任何现有Study的有利结果筛选对手。

### 4. 将评价原则确定为实验方案

依赖阶段3的方法定义；已有评价材料直接复用。

- [ ] 形成Monte Carlo推荐表：测试参数域及其理由、样本量、共同样本、重复次数或Monte Carlo精度要求、逐参数Bias/RMSE/SD与有效率、联合指标归一化。参数域与样本量从统计问题及文献确定；非负位置等限制须说明适用情境，不继承项目约束。可靠寿命和区间指标按待验证主张增补。
- [ ] 给真实数据确定具体任务、所需数据及相应指标：应用／拟合、稳定性或留出预测分别解释；说明该设计能支持什么结论。Bootstrap详细分类留在附录，不靠增加重抽次数制造独立证据。
- [ ] 确定MLE及其他方法的预算、重试、接受与失败记录；分别报告全体生成数、各方法有效率、各自有效集及共同有效集的条件误差。增添对手可能改变共同有效集合，应给出集合定义和数量；有效极端值不按接近真值与否筛除，回退须单独定义。

**产物与完成标准：** 一张实验方案表和一份附录中的具体计算规则；实施者可据此配置实验，不需自行猜测关键参数。Research09交付推荐方案，本阶段不启动大规模性能实验、训练或全面复现。
