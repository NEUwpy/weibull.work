# 三参数 Weibull 新估计方法：比较对象与评价方案

> Research09 · v3.0 · 2026-09-28。对象为完整、独立同分布样本的普通三参数 Weibull 点估计，重点关注小样本。本研究独立于 Study01；推荐来自文献任务、方法定义与比较实践，不继承任何既有实验的胜负。本文给出调研决定与实施建议，未声称已经复现全部推荐方法或完成新的性能实验。

**本次建议：一般移位模型采用 Local-ML、WMLE-J、MPS、LSPF 四种基准；研究非负起点寿命时，再加入 Park（2017）Proposed+Plot。** 按新方法主张增加母方法、近期顺序估计、偏差修正或学习方法。用共同 Monte Carlo 样本评价逐参数误差与有效率，真实数据承担应用、拟合与算法诊断。这个组合是本调研的明确建议，不是经投票得到的领域统一标准。

## 1. 为什么需要重新确定比较对象？

提出一种新估计方法后，只与若干经典方法比较，会留下两个问题：是否避开了更有竞争力的已有构造；比较是否覆盖了新方法声称解决的困难。因此，调研的落点不是增加方法数量，而是让每个对手承担明确作用：连接既有研究、覆盖不同估计依据、回应相同问题上的近期进展，以及检验相对母方法的增量。

本研究使用

\[
F(x)=1-\exp\{-[(x-\gamma)/\eta]^\beta\},\quad x>\gamma,
\]

其中 β>0、η>0、γ∈R。完整样本表示所有个体的观测值可见，不自动排除污染、混合或离群机制；这些机制须另外标注。二参数、已知形状、删失、截尾及特殊可靠性结构均可解释研究方向，但不能直接混入普通三未知参数的性能排名。

还须区分两种任务：**一般移位模型允许负位置；非负起点寿命模型利用 γ≥0 的物理信息。** 一些概率图与顺序估计原法采用后一种约束。把所有方法静默裁零，会改变估计器，也会掩盖信息条件不同造成的影响。

## 2. 哪些估计路线值得比较，方法是怎样演变的？

方法分类的关键是“改变了什么”。同一目标换优化器、修改估计方程、引入先验和直接学习参数，解决的问题并不相同。下面保留对选型有作用的沿革，详细公式及项目实现差异见[附录B](附录B-方法实现与版本.md)。

| 路线与关键沿革                                                                 | 核心变化                         | 对选择的意义                            |
| ----------------------------------------------------------------------- | ---------------------------- | --------------------------------- |
| Fisher似然思想；Weibull似然及Cohen–Whitten修改估计；Cousineau WMLE（2009）；DMMLE（2025） | 从密度似然到修改方程、有限样本偏差校正          | MLE连接既有比较；WMLE、DMMLE不是简单换优化器      |
| White线性拟合（1969，追溯来源）；Soman–Misra三参数扩展（1992）；Li（1994）；Park（2017/2018）    | 绘图位置、回归方向、位置选择与剩余参数恢复不同      | “LS/LRE”不是唯一公式，应冻结分数、方向和位置域       |
| 传统矩；Greenwood等PWM（1979）；Hosking L矩（1990）                                | 用矩或次序统计量加权函数恢复参数             | 适合作为矩类新方法的母方法；PWM/L矩不能只按名称当两条独立思想 |
| Cheng–Amin MPS（1983）；Nagatsuka等LSPF（2013）                               | 前者最大化CDF间距；后者用标准化次序统计量构造形状似然 | 都回应非正则问题，但不是同一准则；提供不同于普通密度似然的比较对象 |
| Yang等MDM（2022在线／2023卷期）；Guo等SAM（2023）、PM（2024）                          | 伪参数一致性、最小值期望或中位数关系与顺序更新      | 是近期直接相关构造，须按位置约束、具体主张及复现状态选择      |
| Abbasi等ANN（2008）；核密度NN/GA（2014）；近期BPNN及智能优化                             | 学习样本到参数的映射，或为指定目标提供求解器／组合规则  | 学习法需控制训练信息；优化器改良应同时比较目标值、预算与统计风险  |

这不是将相邻论文都连成直接继承链：MPS与LSPF的关系主要是问题动机相近；Li与Park均利用Weibull图，但构造不同。White与Cohen–Whitten的早期身份部分由已核原文追溯，不能写成全部首创文献均已逐式复核。经典来源入口：[Soman–Misra](https://doi.org/10.1016/0026-2714(92)90057-R)、[Li](https://doi.org/10.1109/24.295002)、[PWM](https://pubs.usgs.gov/publication/70012617)、[MPS](https://doi.org/10.1111/j.2517-6161.1983.tb01268.x)。

一个直接影响名单的例子是LS与相关回归：对同一绘图分数、同一位置、带截距OLS，F比与相关系数平方的最大化可等价，但反向回归后取倒数一般不还原相同估计。因此，不应仅因叫作“LS”和“LRE”就同时纳入；也不能把项目Bernard绘图位置实现冒充原版Park方法。

“更新”不自动等于更强，也不自动更适合相同问题。例如PM不能仅因比SAM晚一年就替代SAM；两篇没有已核的直接对决。PM PDF的二分伪代码与其单调方程存在符号矛盾，位置下降补救也未明确保护上界；SAM的停止与边界重试同样需要公开实现决定。详见[原文算法核查](资料/通用比较方案核查.md)。这些发现要求认真复现，不能当作排除潜在强对手的方便理由。

### 3.3 为什么经典方法仍值得保留？

理由主要是共同参照和估计路线的可解释差异，而不是已经证明新方法都无竞争力。Cousineau的比较论文明确保留MLE作为常用基线；Nagatsuka等则依据前序研究选择WMLE、BL作为较强对手。这显示“经典共同基线＋问题相关竞争者”的逻辑，而非只按年份选择。[Cousineau比较研究](https://doi.org/10.1109/TDEI.2009.4784578)、[LSPF原文](https://doi.org/10.1016/j.csda.2012.09.005)。

当前没有足够证据认定一个近年方法已成为统一新benchmark，也不能据此断言领域不存在这样的实践。HGLM、AIMGC-PSO以及补检题录中的加权TLS、小样本磨损阶段等候选仍有全文／身份缺口。本文推荐可以用于组织研究，但投稿前若要声称覆盖截至2026年的主要竞争方法，必须按[补检处置表](资料/近期文献范围核查.md)关闭与该论文主张相关的缺口。

### 4.2 Monte Carlo负责估计风险，指标需逐参数解释

在同一13篇主子集中，明确核到逐参数RMSE 7篇、逐参数SD 5篇、逐参数Bias 4篇，另有相对Bias 1篇、MSE 1篇；跨参数平均MAE与相对MAE各1篇。联合RMSE／Bias、中位偏差和平均SD另外编码，不能强行混为相同指标。未编码表示未确认，并非证明原文没有。完整ID及逐项定义见`benchmark_comparison_audit.json`的`metric_summary`。原21条较宽用途统计保留在附录A，包含自身性能及仅形状研究，不能与本表分母混用。

本文据指标作用推荐逐参数Bias、RMSE与SD，加有效率作为主输出：Bias看系统偏离，RMSE看总误差，SD区分波动来源。MSE与RMSE提供相同排序信息，不需为了“全面”机械重复两套表。MAE或误差分位数可补充重尾诊断。只比较参数均值离真值的距离，不能代替逐次误差；只展示拟合相关系数，也不能证明参数风险更低。

### 4.3 真实数据负责应用和拟合，通常没有参数真值

| 已核例证 | 真实数据实际做了什么 | 支持的结论 |
|---|---|---|
| LSPF，182-113 | 10点轴承及4点样本；比较参数、似然形状和不收敛 | 可用性与算法困难 |
| SAM，185-005 | 复用文献寿命数据；CDF、K-S、MTTF、可靠寿命，部分为历史结果 | 拟合与应用解释，非统一重跑的参数风险 |
| BPNN，184-009 | 15点疲劳数据；CCM、MDM，经验CDF和K-S | 该数据上的拟合比较 |
| Akram–Hayat，182-096 | 10点与23点真实数据，多个估计结果；包含MLE失败处理 | 估计与求解行为，不能将替换观测忽略 |

本轮另核6篇真实部分的对手，发现并不总与模拟名单相同，故不把模拟频次复制为实测采用频次。反复出现的同一10点或4点数据不是多份独立证据。真实数据默认展示参数、经验CDF、拟合统计量、状态和用时；需要预测主张时，再使用足够大的独立或留出数据。

估参后直接套已知参数K-S临界值通常不合适；需要p值时应在拟合模型下模拟、重新估参并校准。普通非参数bootstrap会产生重复值，普通MPS的零间距及端点非正则问题不能忽略。参数bootstrap回答的是拟合模型条件下的问题，不会把未知真实参数变成已知。详细规则见附录B。

### 4.4 MLE异常须写进比较协议

当估计空间允许0<β<1、η>0，并让γ从下方趋于样本最小值，密度中的 \((x_{(1)}-\gamma)^{\beta-1}\) 可使似然无界。因此普通全域“全局MLE”不能直接作为保证返回有限最优的算法。这个问题由搜索域决定，不只发生在真β<1的模拟格子。文献报告的MLE常是局部极大、受限解或指定方程分支；理论讨论见[MPS原文](https://doi.org/10.1111/j.2517-6161.1983.tb01268.x)和[DMMLE原文](https://doi.org/10.3390/e27050485)。

已核论文的处理并不统一：182-096只统计某些收敛且满足条件的样本；182-091限制形状区间并报告未得估计次数；MDM论文30组n=15样本有6组MLE未得解，图上零值是标记；182-101剔除形状估计>5的输出。这些做法会改变比较对象或分母，不能不加解释地继承。

本文采用**有限局部剖面似然参照Local-ML**，把计算搜索失败与数学不存在区分。所有方法均报告全体生成数、有效率、各自有效集误差、固定主组共同有效集和成对共同有效集误差。误差表明确是条件结果；有效极端估计不因接近真值与否筛除。失败不填零、真值或其他方法结果，回退另命名为一个完整估计流程。

## 5. 最终应选择什么组合，实验怎样安排？

### 5.1 两种问题设定下的明确组合

| 研究任务 | 本调研推荐的benchmark | 选择依据与约束 |
|---|---|---|
| 一般移位：β>0、η>0、γ∈R，完整连续小样本 | **Local-ML、WMLE-J、MPS、LSPF** | 通行似然参照、有限样本修正、间距准则、变换后的形状似然。LSPF承担近20年直接相关竞争者；不以有争议的后续采用计数证明其地位 |
| 非负起点寿命：真γ≥0 | **上述四种＋Park2017 Proposed+Plot** | 增加常见概率图路线与近10年具体版本。Park使用非负信息，其他法保留原定义；差异不能全归因于估计准则 |

四方法是面向一般移位问题的基础组，五方法是面向非负寿命问题的较完整建议，均不是唯一充分集合。若新法依赖概率图而又声称任意位置适用，须另加相同位置域的概率图版本，明确命名为扩展，不能让Park原版的域限制成为回避该路线的理由。

若研究要求所有输出位置非负，另报告受限／投影版本敏感性，说明改变的规则。允许负位置的方法给出负估计，在一般移位或保留原规则的寿命比较中均不自动算失败。

### 5.2 固定到哪个版本？

| 名称 | 固定定义 | 为什么不是其他同名版本 |
|---|---|---|
| Local-ML | 固定γ求条件二参数MLE，检查剖面有限局部极大；多个验收候选取似然最大 | 不冒充不受限全局MLE；网格、扩展与接受规则是本调研公开实现建议 |
| WMLE-J | Cousineau式(3)—(4)，W1=J1(n)、W2=J2(n)、W3=J3(n,β)，在求解中更新候选β | 构造论文推荐中位权重；不沿用不明W3代入或夹到表域边界的实现 |
| MPS | Cheng–Amin的n+1个CDF间距对数和，包含两端 | 普通连续无重复样本版；不把CDF最小二乘或删掉端点称同一MPS |
| LSPF | Nagatsuka等§2，标准化次序统计量的形状似然及原文§2.3恢复公式 | 形状涉及原文双重积分；不是先做二参数MLE再代入恢复公式 |
| Park2017 Plot | n≤10用(i−3/8)/(n+1/4)，n≥11用(i−1/2)/n；γ∈[0,x(1))最大化相关系数；回归z对ln(x−γ) | 固定Plot分支；不与MLE2、Bernard绘图位置或反向回归混用 |

LSPF恢复顺序为：先由 \(\tilde\eta=[n^{-1}\sum(x_i-x_{(1)})^{\hat\beta}]^{1/\hat\beta}\)，得 \(\hat\gamma=x_{(1)}-\tilde\eta n^{-1/\hat\beta}\Gamma(1+1/\hat\beta)\)，再按 \(\hat\eta=[n^{-1}\sum(x_i-\hat\gamma)^{\hat\beta}]^{1/\hat\beta}\) 恢复尺度。原文n>2、非全相等的理论条件，与本调研建议正式n≥5不同。WMLE权重预计算必须独立于测试数据，覆盖候选估计形状范围，不能使用真β选权重。

### 5.3 根据什么主张增补谁？

| 新方法的主张或继承关系 | 必须补足的比较 | 本次取舍 |
|---|---|---|
| 改进已有估计器 | 对应原版母方法及被修改分支 | 只有存在继承关系才要求母方法；MDM不普遍必选 |
| 非负位置、n=5—20、最小次序统计量／顺序估计 | SAM2023非固定真形状分支 | 首选近期近邻；公开停止及越界处理，不把尚未解决的规则声称原样复现 |
| 条件似然与位置修正，或区间推断 | PM2024；覆盖率与长度 | 需修正已确认伪代码问题并披露，不因更新就替代SAM |
| 似然偏差修正 | DMMLE2025 DM2 | 原n≥50；极小样本适用性必须新检验 |
| 矩／概率加权或高形状域优势 | 对应PWM／L矩原版；高形状参照Akram–Hayat2014所比较LM | 不额外凑多个等价表示 |
| 伪参数一致性或MDM改进 | Yang等MDM构造，明确绘图概率和偏移规则 | 不用某个项目固定偏移冒充全部原法 |
| 学习映射、训练信息或快速推断 | BPNN等直接学习近邻，配同训练信息／独立测试 | 补特征和训练配置；另训版本如实命名 |
| 更强数值搜索或智能组合 | 同一目标的可靠常规求解器；HGLM/AIMGC等匹配组合全文 | 先分目标改变与求解改变，再比较统计风险和成本 |

### 5.4 可直接用于制定实验配置的推荐表

以下参数点和精度阈值是本调研的设计决定，不是“文献统一规范”，亦不是已运行实验。

| 项目 | 推荐设置 |
|---|---|
| 形状轴 | β=0.5、0.8、1、1.2、1.5、2、3、5，覆盖低形状与1、2附近的非正则变化 |
| 样本量 | n=5、10、20、30、50；n=100作趋势补充 |
| 一般移位主分析 | η=1、γ=0，8×5=40格；先验证公式及实现的位置尺度等变性，再解释标准化 |
| 非负寿命主分析 | η=1、γ/η=0、0.5、2，8×5×3=120格；Park的0边界要求改变位置比 |
| 补充敏感性 | β=0.8、2、5及n=5、20上检查γ/η=−1；同一标准随机样本尺度乘0.01、100并作平移检查。仅运行适用方法 |
| 重复次数 | 每格先R=10000，按预先规定每次加10000、最多100000；同时给Monte Carlo误差。失败比例最坏情形SE≤0.005只是起始精度说明 |
| 共享与盲化 | 同格各法使用相同全部样本，保存种子、生成器和重复ID；优化初值、权重与训练均不能读取测试真参数 |
| 主输出 | 各参数Bias、RMSE、SD及有效率；报告各自、固定主组共同和成对共同有效集的数量 |
| 归一化 | eβ=(β̂−β)/β，eη=(η̂−η)/η，eγ=(γ̂−γ)/η；γ为0或负时均有定义 |
| 联合摘要 | 可附JRMSE=√mean(eβ²+eη²+eγ²)，明确等权；逐参数结果仍为主体 |
| 按主张追加 | 可靠寿命：目标分位点Bias/RMSE；区间：覆盖率＋长度；计算：调用次数、时间和失败状态；学习：训练成本、域内／域外分别报告 |

先做实现验证和少量固定样本检查，再启动上述规模。样本重尾或矩不稳定时，报告RMSE的Monte Carlo不稳定性，补中位绝对误差与误差分位数，不能删除合法极值使排名稳定。停止追加不能以“新方法终于显著”为条件。

### 5.5 求解、失败与真实数据的统一规则

Local-ML使用无量纲 \(d=(x_{(1)}-\gamma)/(x_{(n)}-x_{(1)})\)，初始d∈[10⁻⁸,10⁴]的241点对数网格，再扩展至[10⁻¹²,10⁸]核查覆盖；每点条件形状用括根与log-sum-exp稳定计算，条件残差≤10⁻⁸。检测剖面局部极大并精化，标准搜索后允许一次扩展／加密补救，每条件括根和每邻域精化最多200次。接受有限、支持域合法且加密后稳定的候选；未找到写`no_local_max_found`，人工端点漂移写`search_limit`，不当作数学无解证明。完整步骤见[实施核查§5](资料/通用比较方案核查.md)。

其他方法按自己的目标／方程验收，记录迭代、积分或搜索预算。不能给所有方法一刀切要求γ̂<x(1)，例如DMMLE按定义把位置定在最小观测。WMLE多根、LSPF积分及SAM重试规则须完成实施前验证；本报告确定了统计版本，**尚未提供五法全部验证通过的生产程序**。若复现失败，公布失败与影响，不能悄悄换弱版本后声称战胜该原法。

正式结果状态区分输入不适用、预算到限、未收敛、验收失败、支持域违反、有效内点、有效物理边界和有效极端估计。所有方法共用记录规则，计算预算可按结构设置并披露，不要求积分法与闭式法使用相同迭代次数。

真实数据至少选一份完整寿命数据和一个公开困难样本，统一重跑参数、状态、用时、经验CDF与KS／AD统计量。历史参数旁列，不混成同协议结果。需要p值时校准；需要稳定性时先定义重复值与端点处理；需要预测结论时使用足够的独立观测。真实数据承担的结论始终与已知真参数Monte Carlo分开。
