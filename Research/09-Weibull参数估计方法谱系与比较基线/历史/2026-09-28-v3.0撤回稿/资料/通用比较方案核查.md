# 通用比较方案核查与明确推荐

> 2026-09-28。为 Research09 报告收口提供独立方法判断；暂与 Study01 脱钩。本文是调研建议与原文核查结果，不是已经运行的新比较实验，也不宣称存在领域统一名单。β、η、γ依次表示形状、尺度、位置。

## 1. 先确定要比较的统计问题

目标是评价无先验真参数、独立同分布、完整、连续且无重复观测的小样本三参数 Weibull 点估计。原文中的“寿命位置非负”和统计模型中的“位置可为任意实数”必须区分；不能把项目已有 γ≥0 搜索范围当作所有原方法的定义。

**建议作出两个明确而相连的决定：**

- **一般移位模型的基础组：局部剖面似然参照（Local-ML）、Cousineau WMLE-J、Cheng–Amin MPS、Nagatsuka–Kamakura–Balakrishnan LSPF。** β>0、η>0、γ∈R；n≥5 是推荐研究范围，LSPF原文理论条件是 n>2、样本非全相等。
- **非负起点寿命问题的推荐主组：上述四种＋Park（2017）Proposed+Plot。** 真参数 γ≥0；Park按原文在[0,x₍₁₎)搜索，其他四种保留原定义。这组比较的是各自公开估计规则在同一寿命任务上的表现，不能把可能的差异全部归因于估计准则，因为对非负位置知识的利用并不相同。

若论文要求所有估计输出都必须非负，应另列所有方法的受限／投影版本敏感性分析，且写明它改变了估计器。不要在主表中偷偷截零，也不要把允许负位置的方法的负估计直接归为数值失败。若论文声称对任意实数位置通用，主要结论以第一组为依据；Park原版仅在其适用子域展示，或者把放宽位置域的版本明确命名为“基于Park构造的扩展”，不能继续称原版复现。

选择LSPF进入主组的理由，是它直接针对普通完整三参数问题，提供近20年的估计构造及存在性／一致性动机。后续低形状论文182-050虽使用LSPF标签，所列对手公式与182-113规范构造有差异；**本轮撤回“它足以证明规范LSPF已获后续采用”的论据**，该记录只支持有版本争议的引用／采用线索。任务匹配与原始构造仍支持纳入本调研建议。**不是因为它已被本项目实现，也不是认定它小样本最强。** 原论文已有 n=10、20 的比较；n=5 是建议补充的更小样本检验，应单独说明其与原文证据的区别。

非负寿命五方法组覆盖通行似然参照、有限样本偏差修正、不同目标准则、变换消去干扰参数、概率图回归；一般移位四方法组没有原版概率图代表，原因是目前已选定的Park版本有位置域限制。四方法是有适用域的起始主组，不是全部路线的唯一充分集合：若研究的创新主张涉及回归、绘图位置或宣称跨全部估计路线的优越性，必须补明确允许负位置的回归构造，或公开并验证Park扩展版。不能以四方法结果承担这类更强主张。主组不再同时塞入多个回归变体、多个逐次逼近法或所有矩方法。新提出的方法另列，不计入benchmark数量。

## 2. 推荐版本与原文依据

| 推荐对象 | 固定的统计构造 | 为什么采用这一版 | 必须保留的边界 |
|---|---|---|---|
| Local-ML | 在完整三参数对数似然的剖面中寻找有限局部极大；有限候选中选对数似然最大者 | MLE仍是连接既有比较的共同参照；Cheng–Amin（1983）§4给出固定位置、条件估计其余参数、检查剖面局部极大的做法 | 下文给出本调研数值规则；不是无限制全局MLE，不宣称复现Hirose程序 |
| WMLE-J | Cousineau（2009）式(3)–(4)，W₁、W₂、W₃分别用J₁(n)、J₂(n)、J₃(n,β)；求解时更新候选β对应的J₃ | 182-088 §6联合三参数比较与§7结论明确推荐中位权重。该选择来自构造原文，并非“项目已有J表” | 不把Nagatsuka文按Ng等方式先估β再代入W₃的版本混为同一个实现；权重域、精度与插值须公开 |
| MPS | Cheng–Amin（1983）的 n+1 个CDF间距对数和，包括两端 | 目标不同于密度似然；后续比较中持续采用，非正则边界问题与本研究直接相关 | 严格递增观测；重复值扩展需另定义，不能随机抖动后仍称原版 |
| LSPF | Nagatsuka等（2013）§2：标准化次序统计量 Wᵢ=(x₍ᵢ₎−x₍₁₎)/(x₍ₙ₎−x₍₁₎) 的形状似然；再按原文顺序恢复位置和尺度 | 原文有估计存在、唯一及一致性论证，并覆盖完整小样本；提供2006年以来的明确新构造 | 位置可负，不能裁零；n>2且样本非全相等是原文假设，数值积分仍要验证；数学存在不等于程序必然成功 |
| Park2017 Proposed+Plot | pᵢ在n≤10时为(i−3/8)/(n+1/4)，n≥11时为(i−1/2)/n；在[0,x₍₁₎)最大化相关系数，再回归z=ln[−ln(1−p)]对ln(x−γ) | 原文明确分支且后续文献采用；代表概率图路线，不必同时加入条件MLE2分支 | 非负位置是原构造的一部分。当前项目Bernard绘图位置LRE不等于此版 |

LSPF原文§2.3顺序恢复为：先令 η̃={n⁻¹Σ(xᵢ−x₍₁₎)^β̂}^(1/β̂)，再令 γ̂=x₍₁₎−η̃n^(−1/β̂)Γ(1+1/β̂)，最后 η̂={n⁻¹Σ(xᵢ−γ̂)^β̂}^(1/β̂)。形状似然为原文式(4)及其双重积分；不要拿一个普通二参数MLE形状代入后称LSPF。原文理论覆盖 β>0、η>0、γ∈R，其假设与 n≥5 的实验建议不是同一层内容。作者机构出版记录确认论文发表于2013年58卷210–226页；在线日期为2012-09-13。[出版记录](https://experts.mcmaster.ca/scholarly-works/277077)

“存在唯一”应分层引用：原文§2.2 Theorem 1及Corollary 1针对形状似然方程唯一根／单峰性，Theorem 2针对形状一致性；§2.3明确列Property 1、2，并在式(8)–(9)后说明所构造的位置与尺度估计同样存在唯一且一致。因此可以说**该完整顺序估计器在文中条件下被论证存在唯一**，不能把“形状似然单峰”说成原始三参数联合密度似然全域单峰，也不能把数学性质升级成现有数值积分实现已获验证。

WMLE原文并未保证任意样本均存在唯一解；应披露多根和求解失败。J₁可由Gamma(n,1/n)分布中位数求得，J₂、J₃按原文标准指数抽样构造或可靠原表求得；**权重预计算必须独立于测试集**。本调研不建议把现有J₃表形状0.1—5之外全部夹到端点，也不接受以真β选权重。较大形状估计即使来自较小真β也可能出现，所以测试真参数落在表域内仍不足以保证权重覆盖。[构造来源](https://doi.org/10.1348/000711007X270843)

### WMLE多根：待验证的实现选项

原文方程不足以自动规定多根时的输出。下面只是一项**待验证的WMLE-J多根选择选项，不是当前主组已经冻结的默认规则**：同一权重表与搜索设置下，先收集满足支持域、正形状／尺度及归一方程残差≤10⁻⁸的所有已发现根；以归一参数坐标的最大差≤10⁻⁶合并数值重复根，再从剩余根选经验CDF的KS距离最小者。KS距离定义为 maxᵢ{ i/n−F(x₍ᵢ₎), F(x₍ᵢ₎)−(i−1)/n }；最小距离差≤10⁻¹⁰时依次选较小β、较小γ。这里使用样本CDF只是多根确定性选取，不作为独立验证该方法优越的评价证据。

这是**本调研提出的选择选项**，没有发现Cousineau原文使用它，也没有证据证明它最优或继承原文偏差性质。正式实施先核原论文／可获得程序的初始化与选根规则，再决定是否需要扩展；若采用本选项，必须另命名并公开敏感性，不能直接挂原版WMLE-J标签。无论采用何规则，主表都应报告多根比例，不能用测试真参数挑根；有限搜索只得到“发现的根”，不声称穷尽数学上全部根。

建议求解在log β与log[(x₍₁₎−γ)/s]坐标中进行，s为样本极差，初始正β网格{0.1,0.3,0.7,1,2,5,10,30}、相对位置间隙网格{10⁻⁶,10⁻³,0.1,1,10,10³}，每起点至多2000次残差调用；首次无有效根或根靠近人工搜索边缘时，仅作一次更宽网格补救。停止不仅看优化器成功，还核验两条方程及权重插值误差；全部起点、补救和耗时须入总预算。正式权重表应覆盖实际搜索域；超出已校准域记`weight_domain_limit`，不夹端点冒充成功。这个搜索配置是可执行的公开建议，仍需在原文实例及困难样本上校验后冻结。

## 3. SAM与PM：明确去留，不勉强二选一塞入主组

**默认通用主组不选SAM或PM；在“非负位置＋n=5—20的近期逐次估计”这一特定主张下，首选SAM 2023作增补，先解决其执行规则缺口。** 选择依据是SAM原文直接覆盖n=5、10、15、20，点估计与可靠寿命比较更贴近该增补问题，而不是已有两个示例可运行。PM 2024用于方法结合条件似然或区间推断的近邻比较；它目前没有足够证据成为SAM的通用替代。

SAM采用最小值期望关系＋回归更新；PM采用最小值中位数关系＋固定位置的似然更新。二者作者相同，没有查得两版直接性能比较，因此不能说PM更新一年就更强。

SAM已核示例及停止异常详见附录B §10：有符号位置增量可能提前满足停止式；后期越域时如何回到初始尺度调整框仍不明确。正式比较可定义“按原统计更新、绝对增量与不动点残差验收的SAM实现”，把差异与预算公开；如果不能确认原作者边界重试，不宣称逐项原版复现。此时仍可完成通用主组，不能为了避免复现工作而把需要该近邻比较的科学主张写成已被验证。

本轮进一步核对PM的PDF第5与7页（印刷页3284、3286），发现：

1. Algorithm 1第19行确实印为 φ(β_mid)φ(β_U)>0 时令β_L=β_mid。对原文单调递增且异号括根的φ，这不能正确保留根；不是OCR单独造成。正确二分应按与左端同号／与右端异号更新左端。可以修正数值求根以忠实求解式(8)，但必须注明修正，不照抄伪代码。
2. Algorithm 2第7行：当γⱼ<γⱼ₋₁时，替换成γⱼ₋₁+0.001 min(x)。这一步没有在该算法框中给出防止越过min(x)的保护，也未给出独立迭代预算。由此不能把PM当成天然消除了SAM边界风险的方案。
3. PM停止条件用三参数最大绝对增量<ε，论文取ε=10⁻⁶；它依赖参数单位。在规范化数值实现中采用无量纲残差与相对／绝对混合容差属于实现说明，不能悄悄改后仍称完全原样。

## 5. MLE推荐实施规则：局部剖面参照，不伪造全域最优

### 统计定义

允许β>0、η>0、γ<x₍₁₎时，只要允许固定β<1并令γ↑x₍₁₎，原密度似然便可无界。这是搜索域性质，不由生成样本的真β决定。**不得把真β<1的整批模拟删除以“解决MLE”。** 全部真β条件都运行同一个预先规定的局部候选搜索，找到有效有限局部极大就报告；没有找到则报告数值搜索状态。

采用局部剖面定义：每个γ下求唯一的条件二参数MLE β̂(γ)、η̂(γ)，形成ℓₚ(γ)；仅接受有限局部极大或预先声明的物理约束边界极大，不接受任意似然方程根。有限搜索中有多个通过验收的候选时，选ℓ最大者。原文依据为Cheng–Amin（1983）§4的剖面说明，求解网格／预算是下述本调研建议，不冒充作者算法。

### 可执行的数值配置建议

1. 输入排序；n<3或全部相等单列。令s=x₍ₙ₎−x₍₁₎>0、d=(x₍₁₎−γ)/s，避免绝对寿命单位决定位置容差。
2. 初始log d网格覆盖d∈[10⁻⁸,10⁴]，241点；分别向两端扩至[10⁻¹²,10⁸]作覆盖核查。约束寿命版另限制γ≥0并显式检查γ=0。一般移位版不添加该限制。网格和扩展上限是公开计算设置，不是统计参数空间。
3. 每个γ，令aᵢ=xᵢ−γ>0；以正形状域括根求解1/β+mean(log a)−Σa^βlog a/Σa^β=0，再恢复η=(mean a^β)^(1/β)。采用log-sum-exp避免幂溢出；括根区间按倍增扩展，不按真β选初值或删根。形状安全上下界触发时记计算限制，不称无解。
4. 在剖面网格上定位上升转下降的邻域，用有界一维优化精化。验收要求有限参数、支持域、条件形状方程归一残差≤10⁻⁸、剖面导数从正到负的局部证据，且局部参数／目标在加密网格和容差收紧后稳定。γ=0的受限候选按单侧局部最大验收并单列边界。
5. 一次标准搜索＋一次扩展／加密补救；不得因结果离真值远反复加算到“满意”。建议条件括根每点最多200次，局部精化每邻域最多200次；总目标调用和时间记录下来。扩展后候选仍随端点漂移，标记`search_limit`；没有发现有限局部极大标记`no_local_max_found`，不得把它改写为已证明任何局部极大都不存在。
6. 同一似然目标的多起点直接优化可用于小规模实现校验，不作为“另一个估计方法”。推荐正式实施前以文献10点、4点困难样本及少量固定样本验证；不要求现在启动大规模性能实验。

若研究的真正科学问题是**已知β≥β₀>1**的受限模型，可以另给受限MLE，并在名称和全体对手的任务描述中声明这项知识。对于普通β>0问题，不默认强行加β≥1后仍称一般MLE。直接给所有β<1候选贴失败标签、保留未经局部最大核验的β≥1输出，并不是上面定义的Local-ML。

## 6. 推荐Monte Carlo方案

下表是独立于现有Study的设计建议。参数点围绕β=1、β=2的非正则变化和小样本任务选择，文献说明其必要性，但具体网格不是文献共识或已运行配置。

| 项目 | 推荐设置 | 理由与边界 |
|---|---|---|
| 形状β | 主轴0.5、0.8、1、1.2、1.5、2、3、5 | 包含低形状、临界邻域、中等和较高形状；不只挑新方法有利的一段 |
| 样本量n | 5、10、20、30、50；n=100作趋势补充 | n=5覆盖极小样本，10—30覆盖常见小样本，50/100显示收益是否随n变化；不要求为凑文献把所有n都纳入 |
| 尺度η、位置γ | 一般移位基础组先η=1、γ=0；非负寿命五方法主组η=1、γ/η∈{0,0.5,2} | 第一组若公式及实现满足位置尺度等变，可减少冗余；Park的0边界破坏平移等变，需位置比条件 |
| 广义移位敏感性 | 在β∈{0.8,2,5}、n∈{5,20}上加γ/η=−1；仅检验适用的方法 | 负位置不是一般移位模型的异常样本；原版Park、SAM、PM不在此处强行运行或计失败 |
| 单位敏感性 | 对同一组标准化随机数，将η乘0.01、100，γ同步缩放；另作确定性平移检查 | 用于查数值容差和等变性，不当成独立重复证据；学习方法还需单独区分训练域内和域外 |
| 重复与精度 | 先每格R=10000；按Monte Carlo SE决定是否追加 | 对失败比例最坏情形SE≤0.005；Bias SE=SD(error)/√R。RMSE须同时给MC误差或重复批次稳定性，不只引用R够大 |
| 随机样本 | 同格各方法共享全部生成样本；固定生成器与种子，保留重复编号 | 降低差异比较方差，明确失败发生在什么样本；不共用真参数作为优化初值 |
| 参数主指标 | 每参数Bias、RMSE；SD分解波动；有效率 | 不把拟合R²代替参数风险，不用只比较均值距真值来冒充逐次MSE |
| 单位一致的误差 | eβ=(β̂−β)/β，eη=(η̂−η)/η，eγ=(γ̂−γ)/η | γ可能为0或负，因此位置误差不除以γ；原始单位指标可同时报告 |
| 联合指标 | 可附JRMSE=√mean(eβ²+eη²+eγ²)，明确等权 | 联合量只作摘要，三参数不能藏在一个总分内；原文量纲混合距离不照抄 |
| 尾部诊断 | 误差分位数及极端有效值比例作补充 | 重尾误差会使RMSE的MC估计不稳定；不能为了好看删掉合法极端估计 |

重复追加建议按预先规定的批次，例如每次10000、最多100000；达到上限而MC精度仍不足时，报告不稳定，不以继续生成到结论显著为停止规则。若RMSE矩不存在或样本中重尾迹象明显，不能仅靠常规SE宣称精度已保证；保留Bias/RMSE估计及其局限，同时增加中位绝对误差／分位数诊断，不替换掉不利主指标。

若论文只声称β在某一区间可用，可缩小主分析域，但仍在该区间两端给敏感性；若声称任意β>0普适，上述有限网格也仅是有代表性的有限设计，不能证明全参数空间一致占优。

## 7. 失败和真实数据：从原则变成输出规则

每格保存生成总数N、各方法有效数Nₘ、各自有效集误差、事先固定主组的共同有效集误差与N_common。主组新增方法后共同集变化须另报；最好同时给新方法与每个对手的成对共同有效差，避免一个高失败方法决定整张性能表。失败参数不填零、不填真值、不用前端或其他方法静默回退。

状态至少区分：输入不适用、搜索／积分预算到限、数值未收敛、方程或目标验收失败、支持域违反、有效内点、有效且触物理边界、有效极端估计。人工计算域端点不是自然物理边界。WMLE方程解与DMMLE调整得分解各按本方法定义验收，不给所有方法套同一严格γ<x₍₁₎规则：DMMLE本来令γ̂=x₍₁₎。

**真实数据默认承担“应用可行性＋拟合诊断＋算法表现”三个任务。** 推荐预先选至少一份完整寿命数据与一个文献公认困难样本（例如LSPF原文10个轴承寿命／4点样本），统一重跑，报告参数、有效状态、时间、经验CDF与拟合CDF、KS或AD统计量。历史论文参数可以旁列，但不能与本轮运行伪装为同一求解协议。

估参后的KS／AD普通已知参数临界值不能直接使用；如需要p值，应按拟合参数生成、重新估参、重新计算统计量的参数bootstrap进行校准，并明确校准失败的处理。仅展示拟合统计量也可，不必为每个实例堆p值。

不要把普通非参数bootstrap当作默认成功的稳定性检验：重抽样必然产生重复值，普通MPS不适用，而位置端点的非正则性还影响区间有效性。首选如实报告原样本诊断；若加参数bootstrap，说明它以拟合Weibull为条件、并非模型正确性的独立确认。需要非参数重抽样时先定义重复值与端点问题的有来源处理版本。

留出预测只在论文有预测主张和足够数据时加入，用预先指定的分位数损失／概率评分，并记录测试观测落在估计支持之外的情况；负无穷对数分数不可截断后隐瞒。真实数据没有参数真值，不能据拟合更好或全样本参数更接近来宣称参数估计更准。
