## 先回答用户的四个问题

**研究的交付目标是：提出一种新估计方法之后，可以有根据地确定对照组，说明新旧方法的估计机制，并在部分方法不返回有效估计时完成公平比较。** 方法分类和文献统计用于支撑这项决策。v0.1主要完成了分类、候选及指标提取，对算法解释和失败统计交代不够，本版补齐。

### 问题一：现在具体选谁？

以三参数Weibull、完整独立样本、n约5—20为当前任务，建议第一组比较对象为：**MLE、WMLE、MPS、一个明确版本的CCM/概率图回归、MDM（2022在线/2023）、SAM（2023）、BPNN（2025）**。其中被研究方法本身若为其中之一，就不重复计数；其改进版仍应保留原版。

这七项各有比较责任：通行参照、有限样本修正、不同统计准则、工程回归路线，以及近年的差异准则、逐次逼近和学习估计。LM用于补充矩类及宽形状域覆盖。它们是目前已有正文支持的首批组，尚不是经完整十年检索后认证的最终集合。

### 问题二：近十年有新方法，为什么选或不选？

**近期方法应进入比较，不应以“经典方法够用了”为由省略。** MDM、SAM、BPNN已经与当前三参数小样本问题直接重合，应优先核对实现并比较。PITE（2025）针对污染，ICP-CDF-LS（2026）针对删失，适合对应扩展实验。ADGBO（2026）主要改进MLE求解，当论文声称求解更可靠或更快时应优先比较；AICQME（2025在线/2026）是二参数风速研究，不能原样当作三参数疲劳小样本对手。

另外，DMMLE（2025）与三参数偏差修正直接相关，是尚须完成全文算法核查的高优先级缺口。未纳入首批不能解释为它不重要，也不能仅凭当前首批比较就宣称超过了近十年全部代表方法。Tsukada（2025）低形状组合估计因原文指标和对手定义疑点，须先审计后采用。每个近期候选的去留理由应保留，不能按复现便利程度选择性忽略强对手。

### 问题三：这些方法究竟怎么估计？

以下是估计机制说明，不替代原文公式及可运行复现。

| 方法 | 从样本到参数的主要步骤 | 实现时最关键的定义 |
|---|---|---|
| MLE | 写出样本联合密度，求使似然最大的参数；常借助剖面优化或似然方程求解 | 三参数似然的边界行为、局部极大与全局极大必须区分，不能把找到任一驻点都叫MLE |
| Cousineau WMLE（2009） | 在MLE估计方程中加入针对有限样本偏差的权重修正，再联立求参数 | 权重随n及形状变化；不同逐观测加权似然不是同一个WMLE |
| MPS | 将排序样本代入候选CDF，计算相邻CDF值的间距，最大化间距乘积（通常求对数和） | 端点间距、并列值处理与参数可行域；不是对样本点密度求乘积 |
| CCM/概率图回归 | 给排序样本分配经验概率；调整位置参数，使变换后的Weibull概率图尽量线性，再由斜率/截距等求形状与尺度 | 经验概率公式、相关系数或残差目标、回归方向；选定一个有来源的版本 |
| MDM（2022/2023） | 对每个样本点与经验概率构造一个伪尺度，寻找使这些伪尺度差异尽量小的形状/位置，再得到尺度 | 差异准则与偏移构造是方法定义，不能任意换成一般CDF最小二乘 |
| SAM（2023） | 利用最小次序统计量与位置参数的关系构造更新式；从位置初值出发，交替更新位置、尺度、形状直至停止 | 原文位置限制、调节因子和停止规则；具有显式更新式仍需检查收敛与结果有效性 |
| BPNN（2025） | 用已知真参数生成训练样本，提取最小值、最大值、均值等统计特征及n，训练网络直接预测三个参数 | 训练参数域、输入、损失及独立测试；没有迭代报错不等于输出一定合法或准确 |
| LM（补充） | 用样本L矩与Weibull理论L矩匹配，求得参数 | 样本L矩比值的可行范围、位置约束与具体解法 |

上述构造来源及实验支持见第3节。近期路线并不限于神经网络：MDM改变估计准则，SAM改变位置与其余参数的构造更新，PITE用概率变换的估计方程控制对污染的敏感性。

### 问题四：部分样本没有解，结果怎么算？

**先报告能不能给出有效估计，再比较能给出估计时的精度。无返回值没有可直接计算的普通参数RMSE；必须明确统计对象或补充可执行的回退规则。**

先把记录分成以下状态：

| 状态 | 判定含义 | 处理 |
|---|---|---|
| 数学上无目标解/估计式不定义 | 在指定参数域和方法定义下不存在所要求的有限最优解或合法方程解，需要理论或可验证的分析支持 | 记方法在该输入上的不可用；不能用优化器超时证明无解 |
| 数值求解失败或未确认 | 达到预算、溢出、未收敛，或未找到满足条件的结果 | 先排除实现问题；按预定策略重试，仍失败则单独计数；原因不明就写未确认 |
| 无效输出 | 非有限数、违背方法/问题规定的参数域或样本支持约束 | 计无效输出；训练网络也适用相同检查 |
| 有效但误差很大 | 参数有效且通过方法相应的求解检查，估计偏离真值很大 | 保留在误差统计中；不能因结果难看就归为失败或剔除 |

不违反定义的边界解不能一律判失败；求解器返回success也不能直接等同于有效估计。适用参数域来自所研究问题与方法原始定义：例如位置非负并非所有三参数Weibull模型共有的假设。若加入约束、截断或改变目标，应标为明确的受限/修改版本。

下面是本Research建议的实验协议，未声称存在唯一通用处理法：

1. **冻结同一批R组样本。** 所有方法使用相同输入，保留重复编号和全部输出；失败不能重新抽样顶替。先在开发样本排查程序，再冻结正式测试的初值、重试、容差和预算，禁止用真实参数帮某方法选解。
2. **每个场景逐方法报告失败率。** 失败率=无有效估计的组数/R，另列已证实无解、数值失败、无效输出。有限预算内没找到解只计数值失败。运行成本包括预定重试。
3. **在共同有效样本上比较精度。** 对新方法A与对照B，令S_AB为二者均有效的重复编号，计算各自在S_AB上的Bias和RMSE，并报告|S_AB|/R。不同对手的S_AB可能不同，不能把这些数值拼成统一总体排行榜；若做多方法同表，另使用全体共同有效集合并报告保留比例。
4. **保留各自有效样本的结果作诊断。** 它们回答各方法成功时的条件精度；因为样本集合不同，不单凭这列直接判总体优劣。对“A成功、B失败”的样本，保留A的实际误差，帮助说明失败发生在哪里。
5. **需要覆盖全部R组的实际使用评价时，预先定义完整流程。** 例如B失败就调用一个事先选定且经验证的可用回退估计器；重新计算全部样本误差，名称必须写成“B+回退”。若回退仍失败，仍记录失败，不能伪造全样本RMSE。

例：1000组样本，A全部有效，B只有900组有效。应报告A失败率0%、B失败率10%；在这900组上比较条件RMSE；另外给出A在其余100组上的表现。**不能把B的900组RMSE直接与A的1000组RMSE排名。** B若失败更少但有效结果误差更大，或反过来，就分别呈现可用性与精度；没有事先定义的使用代价，不能强行压成唯一总分。

可选的全样本辅助量是“有效且误差达标的比例”：指定同一无量纲误差L与事先确定的阈值t，计算N(有效且L≤t)/R。也可画随t变化的曲线，避免只挑一个有利阈值。这是同时反映可用性和精度的操作性评价，不能命名为全样本RMSE。失败填0、填真值、随意填巨大误差，均不作为默认方案。

仿真失败处理的近期方法学研究指出，删除失败记录可能改变所评价的样本总体，回退则改变所评价的方法；建议明确报告失败及处理依据。参见[Pawel等，2024预印本，§4与§6](https://arxiv.org/html/2409.18527v1)。本节的状态字段、共同有效集合和辅助达标量是据当前任务提出的具体协议，尚未运行验证。

## 1. 现在可以作出的判断

**对三参数 Weibull、完整独立样本、小样本点估计，已有文献足以支持建立第一版比较组。** 建议保留 MLE、Cousineau WMLE、MPS，并覆盖明确版本的回归/相关系数方法；研究 MDM 改进时保留原始 MDM。近期方法优先考虑2025年的小样本 BPNN，2023年的 SAM 也是现成候选。L-moments 应进入候选池，不能因为已有代码里没有就忽略。

这份推荐按“共同参照、同任务竞争、近期进展”确定比较责任，并不声称这些方法共同构成一个公认的性能排行榜。已有比较论文恰好表明，形状参数范围、位置约束、样本量、评价对象和失败样本处理都会改变排序。具体证据见第3—5节。

**经典方法仍是近期论文实际使用的参照。** 2025年PITE论文比较MLE、WMLE、MPSE和MOM；2026年删失CDF改进论文比较MLE与LS；2023年SAM比较MLE、CCWP与PWM。因此，“方法提出得早”本身不是剔除依据。需要补上的，是与自己的研究问题相匹配的近期竞争方法，而不是单纯增加新缩写。

**近年的实质工作至少沿六条路线展开：** 小样本和位置参数处理、偏差与估计方程修正、污染稳健估计、删失信息利用、学习型估计及统计与学习混合、数值求解改进。这是本轮正文支持的方向归纳；各方向在整个领域的份额和增长速度尚未统计。

## 2. 方法谱系：七类估计原理，另外记录求解方式与场景

杨小玉等的181-004综述提供了广泛入口，但其八类框架同时包含目标函数、统计思想和计算工具。用于选比较方法时，需要把这些层次分开，否则“PSO-MLE”和“MLE”容易被统计成两个独立估计原理。

| 原理家族 | 代表方法或构造 | 对比较组的作用 |
|---|---|---|
| 似然与估计方程 | MLE、Cousineau WMLE、偏差修正与惩罚似然 | 共同参照与有限样本改进；不同MMLE/WMLE必须核对公式 |
| 概率间距 | MPS/MPSE | 与似然不同的目标；已有三参数独立比较与近期采用证据 |
| 概率图、回归与相关系数 | 概率图LS、CCM/CCWP、秩回归 | 覆盖传统工程路线；绘图位置、回归方向和位置参数处理须明确 |
| 分布距离与差异准则 | CDF残差、分位点匹配、MDM的伪尺度差异 | 不能只按“最小二乘”或“最小差异”合并 |
| 矩、分位数及构造统计量 | MOM、PWM、L-moments、MVLUE及组合估计 | 提供非似然路线；部分近期方法在位置估计与组合步骤上创新 |
| 贝叶斯推断 | 指定先验和损失下的后验估计、区间 | 属于完整谱系；本轮尚无充分正文比较证据确定一个必比版本 |
| 学习型及混合估计 | BPNN直接输出参数、AICQME分位数匹配后校正 | 近期直接竞争路线；训练域和训练信息构成比较条件 |

稳健、小样本、删失、区间推断作为场景或目标标签；PSO、ADGBO、Newton等作为求解器标签。混合方法允许多个原理标签，统计时保留唯一的主类和构造说明。灰色方法等继续保留待核标签，本轮没有足够证据把它列为三参数小样本必比项。

这里尤其要避免混用“LS”：182-025中的CDF残差最小二乘、182-030的Weibull概率图相关路线，以及182-103的对数线性化概率图残差，目标并不相同。论文和代码应写出目标函数及经验CDF/绘图位置，不能只写“与LS比较”。

## 5. 评价指标：文献中反复出现什么，自己的论文应怎样用

### 5.1 已有文献支持的主干

| 评价对象 | 本轮证据 | 当前采用建议 |
|---|---|---|
| 单个参数的系统误差 | 182-101、182-096、182-025、182-050、182-103报告Bias | 对β、η、γ分别报告有符号Bias，保留误差方向 |
| 单个参数的总体均方风险 | 上述多篇及PITE、BPNN使用RMSE | 作为主指标；从每次估计与真值的平方差直接计算 |
| 重复抽样波动 | 182-101的efficiency、BPNN的Std、SAM的MSD | 报告SD，帮助区分偏差与方差；不要仅凭SD小就说更准确 |
| 三参数联合表现 | Cousineau的联合距离、PITE的Def、SAM的MAD/MSD、Tsukada的Joint | 原文定义不统一；逐参数结果应保留，联合指标作为明确声明的汇总 |
| 寿命/可靠性目标 | BPNN的99%可靠度寿命，SAM的MTTF和可靠度寿命 | 若论文面向寿命预测，同时评估实际目标，不能由参数RMSE直接代替 |
| 真实数据拟合 | AICQME与风能综述的RMSE、MAE、R²、K-S；其他论文亦用K-S | 真参数未知时只能说明拟合/预测表现，不可写成已证明真实参数估计更准 |
| 数值可用性与成本 | 经典比较的样本过滤、ADGBO求解路线 | 自己的比较应显式记录失败率、极端误差和时间，避免隐性筛样 |

对R次重复，建议主报告统一为：

\[
\operatorname{Bias}(\hat\theta)=R^{-1}\sum_r\hat\theta_r-\theta,\qquad
\operatorname{RMSE}(\hat\theta)=\sqrt{R^{-1}\sum_r(\hat\theta_r-\theta)^2}.
\]

SD以估计均值为中心计算，并注明分母。采用R分母时，RMSE²=SD²+Bias²。RMSE与SD不可互换，围绕真值的平方差已经是MSE，不能再次加入Bias²。

### 5.2 联合指标目前没有从这些论文中得到统一标准

PITE的Def是三个原始RMSE的平均；SAM的MAD是三个参数平均绝对误差的平均；Cousineau采用原始参数空间距离；Tsukada的Joint bias为三个绝对偏差之和，Joint RMSE为MSE矩阵迹的平方根。这些指标在数学形式和量纲处理上不同。

形状无量纲，尺度与位置有时间单位。直接求和会受时间单位及参数尺度影响。因此当前建议是：**主表保留逐参数Bias/RMSE，另报告预先定义的无量纲联合指标。** 例如在仿真中可令eβ=(β̂−β)/β，eη=(η̂−η)/η，eγ=(γ̂−γ)/η，再汇总三项平方误差；用η标准化位置误差可避免γ=0时相对误差无定义。这是本Research的实验设计建议，不是文献公认标准，也不应不经核对就等同于项目已有J1/J3等指标。

99%可靠度寿命对应1%失效分位点：q₀.₀₁=γ+η[−ln(0.99)]^(1/β)。参数表现和该分位点表现应分别报告。若论文提出区间保证，还应补覆盖率及区间长度；本轮文献提取没有建立区间方法的完整比较组。

### 5.3 不能沿用的三种隐含处理

1. **只比较共同成功样本。** 182-096原文第248页明确采用ML收敛与L-skewness阈值筛选。这能研究条件性能，却不能说明所有输入上的总体表现。自己的研究应同时交代失败数、共同成功条件结果及预先规定的回退策略；不能给失败随意填一个误差后混算。
2. **静默剔除极端估计。** 182-101第284页明确剔除形状估计>5。自己的结果可提供截断敏感性分析，但主结果不能隐藏极端尾部。分位数误差、尾部发生率可作为补充。
3. **把低波动称作污染稳健。** SAM的MSD与BPNN的Std测量重复抽样波动；PITE研究的是显式污染。要主张抗离群点，应另设污染实验，并说明污染比例与生成机制。

学习方法另需报告训练域、训练样本预算、调参规则、训练成本与单次推断成本；测试集不得用于选网络或调阈值。对BPNN原文中输入特征及“test MSE”的表述，应先澄清再冻结复现协议，不能用推测填补。

## 6. 近十年动向：已经看到了哪些实质进展

| 方向 | 已有近期证据 | 对论文定位的启发 |
|---|---|---|
| 小样本与位置参数困难 | SAM 2023、MDM 2022/2023、Tsukada 2025 | 新工作继续围绕位置处理、构造统计量及组合步骤展开，不能只查神经网络 |
| 有限样本偏差和估计方程修正 | 近期论文继续采用WMLE；Tsukada把位置与形状/尺度估计组合 | 新方法与经典修正思想有延续关系；已入库的182-111 DMMLE可进一步补强这一分支 |
| 污染与异常样本 | PITE 2025的ρ参数、敏感性与污染实验 | 优势可能以干净模型效率为代价，应比较风险权衡 |
| 不完整观测下的概率构造 | ICP-CDF-LS 2026 | 信息利用方式本身是创新来源，评价须和删失机制匹配 |

| 优化初始化与求解可靠性 | ADGBO 2026；风能综述中的多种元启发式求解 | 计算进步与统计风险改善应分别展示 |

以上支持“近年来有新方法，也有明确的问题导向”。尚不能回答“其中哪一条占比最高”。180库由既有研究兴趣积累，本轮又有意选取高相关文献；直接用这些篇数推断整个领域趋势会产生选择偏差。

可继续积累的统计单位应是：独立论文、独立方法构造、论文—方法采用关系、论文—指标对象关系。后续计数要区分“提出某方法”和“把某方法作为对照”，还要分离同团队自比较与独立团队采用。当前已发现，MDM、CCM比较、BPNN及SAM的作者存在重叠；它们能证明近期路线存在，不能全部算成相互独立的确认。
