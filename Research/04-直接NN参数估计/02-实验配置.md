## 共用样本、模型与评分

| 配置 | 已执行取值 |
|---|---|
| 分布 | 三参数 Weibull，完整独立同分布正寿命；γ≥0 |
| 基础开发设计 | β=1.5—5.0，步长0.5；η=1000；γ/η=0.10/0.25/0.50/0.75/1.00；n=7/10/15/20 |
| 基础开发资源 | 每单元300次，160单元、48,000样本；每n 12,000（拟合10,200，内部验证1,800） |
| 测试设计 | β=0.75—5.75，步长0.25；其余因素同基础开发，每单元300次，126,000样本 |
| 测试类别 | 已见网格48,000；域内未训练42,000；近域外1.25/5.25共12,000；远域外0.75/1.00/5.50/5.75共24,000 |
| 抽样 | 开发 `study01_nrmc_v1`；测试 `research04_generalization_v1`；键为β、η、γ、n、repeat_id |
| 网络/优化 | 每n独立MLP；256—128—64、ReLU；seed=42；学习率0.001、batch256、正则0.0001；最多300轮，早停耐心20 |
| 输入 | sort(X)/mean(X)，逐位置标准化；编码统计使用完整开发资源，之后内部划分 |
| Direct-P | PyTorch；编码 inverse-softplus(β)、inverse-softplus(η/mean(X))、γ/η；解码及相对参数平方损失见[方法2.1](03-稿件-直接神经估计与结构保留路线比较-v0.2.md#main-2-1)；验证参数损失选点，阈值10⁻⁶，恢复最佳权重 |
| 自适应 MDM | sklearn MLPRegressor，标准化26点候选损失；预测逆变换后截负为零，argmin选δ；δ=0—0.5，步长0.02；验证R²选点 |
| 固定 MDM | δ=0.1；两条MDM路线使用相同求解实现 |

框架、内部划分、正则、输出头及选点不同，相同seed不意味着相同初始化。完整开发资源参与标准化，内部验证未与标准化统计完全隔离；最终测试未参与。因此比较完整方案，不声称求解结构的净效应。

有效估计的联合损失为 ((β̂−β)/β)²+((η̂−η)/η)²+((γ̂−γ)/η)²；J₁为全样本平均损失的平方根。未收敛、非有限、β̂/η̂非正、γ̂<0或γ̂进入样本最小值边界容差的估计记为失败；容差10⁻¹⁰ max(|t₍₁₎|,|η|,1)。基础及训练域/传统参照固定失败损失 **2.670433491321633**（开发阶段四个n的P99惩罚取最大）。参数和寿命Bias/SD/RMSE仅用各方法有效子集，并列失败率；混合SD包含单元间差异。寿命 x_R=γ+η[−ln(R)]^(1/β)，R=0.90/0.95/0.99，不参与训练。R04-06有自己的探索评分来源，不跨协议混排。

复用[共享抽样](../../python/studies/common/sample.py)、[共享方法入口](../../python/studies/common/runner.py)及[Study01源码依赖](code/README.md#dependencies)。原算法版本以各manifest及Git基点为准。
