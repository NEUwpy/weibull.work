## 修改范围与理由

| 审查问题 | v0.2 的处理 |
|---|---|
| 路线性能差被解释成求解结构的净效应 | 方法中披露不同监督目标、验证选点、训练实现和内部划分；结论限定为完整方案的条件比较 |
| 训练域扩宽同时混入中心变化 | 同中心双预算实验成为主结果；早期嵌套域及同宽平移移至附录并保留其解释限制 |
| 局部导数被扩展为可识别性或偏差成因 | 保留解析诊断和参数误差方向，将因果说法改为待区分的解释线索；说明混合相关包含单元间差异 |
| 参数误差与寿命误差被混在一起 | 分开联合风险、逐参数误差和三个可靠度寿命点；并列成功子集指标与失败率 |
| 方法与文献定位不充分 | 补全实际归一化、目标编码、参数解码、失败惩罚及预算定义；参考文献由2项补至7项，区分方法来源与本文实现 |
| 图面、符号和量程不一致 | 重绘5张主图与4张附图；统一方法配色、规范γ标准化RMSE与ΔJ₁、共用可比面板纵轴；明确CI、IQR及局部量程 |
| 读者正文混入执行记录 | 方法细节、证据索引与支撑结果移至附录，修订及核验过程留在本记录 |

保留 v0.1 原稿、旧图及所有正式 artifacts。仅新增 v0.2 稿件、独立图件目录和两个有界脚本，并同步研究入口；历史实验计划仅增加当前阅读指引。

## 本轮核验的界限

本轮复用了封存汇总，没有新增训练、抽样、置信区间计算或原始逐样本指标复算。当前checkout缺少部分正式模型与逐样本数据，后续端到端复现须先定位对应封存位置。已有独立复算记录是此前实验的证据，本轮不将其改称新完成的复算。

稿件现在能够说明条件性能、方向性外推、同中心扩宽的局部代价，以及参数目标与寿命量的差别；尚未分别估计训练目标/选点、模型逼近、优化和求解结构对差距的贡献。区间覆盖、真实场景、自动切换与更大网络的作用也未被本轮验证。上述缺口已落实到正文，不以文字修改替代新增证据。
