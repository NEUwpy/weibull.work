# 传统估计方法风险地形

> 成熟度：`COMPLETE`
>
> 关系角色：`INDEPENDENT`
>
> 当前版本：`risk_landscape_v1`（2026-08-10 冻结）

## 研究问题

在 Study01 已冻结的三参数 Weibull 小样本设计中，不同传统估计方法之间是否存在稳定、非平凡的条件风险差异，足以继续研究样本自适应的方法选择？

本 Research 只回答“选择空间是否存在”。它不训练推荐模型，不提前建立 Study03，也不修改任何 Study01 formal artifact。

## 当前合同

### 设计与数据

- 复用 Study01 E6 的 160 个组合：`beta=1.5...5.0`、`gamma/eta={0.1,0.25,0.5,0.75,1.0}`、`n={7,10,15,20}`；
- 每组合 300 个共享样本，共 48,000 个样本，seed namespace 为 `study01_nrmc_v1`；
- 参数风险使用 Study01 的逐样本平方损失：三个标准化参数误差平方和；
- 所有候选方法使用同一样本键。生产方法统一在“千小时”单位下运行，即样本除以固定单位换算 1000，再把估计量放回同一标准化风险口径；该换算不使用逐样本未知真参数。

### 方法角色

| 方法 | 角色 | 原因 |
|---|---|---|
| MDM-0.1 | primary candidate | Study01 冻结默认方法，直接复用现有逐样本结果 |
| WMLE | primary candidate | 已有同设计完整外部参照，失败率接近 0 |
| LSE | primary candidate | 已有同设计完整外部参照，无失败 |
| MLE | diagnostic only | 既有固定组合中无界失败较多，不能在通过失败审查前进入推荐集合 |
| LRE | diagnostic only | 既有实现存在尺度与位置边界异常，不能在方法身份复核前进入推荐集合 |

不因为诊断方法偶然赢得某些样本，就把它自动升级为 primary candidate。

### 选择层次

采用 `repeat_id mod 5` 五折选择/评价分离：每折只用其余四折估计风险并冻结选择，在留出折评价。

| 层次 | 可用信息 | 作用 |
|---|---|---|
| Fixed | 无分层信息 | 训练折选择的最佳统一方法 |
| n | 样本量 | 当前可直接观测的简单规则 |
| beta | 真形状参数 | 不可部署的机会参照 |
| beta+n | 真形状参数、样本量 | 不可部署的机会参照 |
| cell | beta、gamma/eta、n | 完整设计单元机会参照 |
| sample hindsight | 当前样本的事后真实损失 | 只作绝对上限，不是可执行方法 |

### 失败合同

- 失败必须单列并报告；primary candidate 的总体失败率若超过 1%，停止其选择排名并先处理方法有效性。
- 主分析对失败使用固定损失 `L_fail=3.0`，避免惩罚随 `gamma/eta` 改变。
- 零估计自然损失作为敏感性分析保留，不用它替代主失败合同。

### 决策门

只有当交叉评价的 `cell` 选择相对最佳固定方法满足以下条件，才继续可观测方法选择 Research：

1. pooled J1 相对改善至少 3%；
2. 设计单元 bootstrap 95% 区间下界大于 0；
3. 收益不是由单一失败方法、单一样本量或极少数边界单元驱动；
4. 至少两个 primary candidate 在可复核区域中稳定占优。

否则关闭复杂“智能推荐”方向，或先转为方法实现/有效性研究。

## 结论

`risk_landscape_v1` 已完成，预先冻结的继续门全部通过。

### 核心结果

| 策略 | 可用信息 | pooled J1 | 相对最佳固定方法 | 设计单元 bootstrap 95% 区间 |
|---|---|---:|---:|---:|
| Fixed | 无 | 0.630409 | 0 | 0 |
| n | 样本量 | 0.630409 | 0 | 0 |
| beta | 真形状参数 | 0.601689 | 4.56% | [3.38%, 5.76%] |
| beta+n | 真形状参数、样本量 | 0.599448 | 4.91% | [3.63%, 6.16%] |
| cell | beta、gamma/eta、n | 0.592141 | 6.07% | [4.85%, 7.30%] |
| sample hindsight | 逐样本事后损失 | 0.502640 | 20.27% | [18.90%, 21.68%] |

最佳固定方法在五折中始终为 MDM-0.1。`n` 单独不能改变选择；真 `beta` 已恢复完整 cell 选择约四分之三的 J1 收益。cell 选择恢复了逐样本 hindsight MSE 空间的 32.3%，说明还有更大的逐样本差异，但其中多少可辨识仍未知。

五折至少 4/5 一致的稳定区域中，MDM-0.1、WMLE 分别占 72、78 个 cell；LSE 只在高 `beta`、低 `gamma/eta` 的 5 个 cell 形成小范围稳定区域。按完整 cell 汇总，低 `n`、低 `gamma/eta` 的选择收益更大，但四个样本量上的方向均为正。

primary candidate 共 144,000 个结果无失败。诊断性 MLE 失败率为 23.1%，不能进入选择集合；LRE 虽无显式失败，但既有方法身份/尺度问题尚未关闭，当前数值不用于决策。WMLE/LSE 的共同单位结果与 Study01 B2 直接尺度汇总只相差 −0.31% / +0.69%，cell 机会不是由总体尺度差异制造。

### 科学判断

**结论：继续进入“可观测方法选择”Research，但暂不升级为 Study。**

下一阶段应先检验排序样本、少量等变统计量或简单可解释规则能否识别以 `beta` 为主的风险分区，并与最佳固定 MDM-0.1 比较。复杂模型只有在超过这些简单规则且能在未见参数单元保持收益后才有必要。

本结论限于当前离散网格、完整样本、共同单位、三种 primary candidate 和等权参数损失。设计单元 bootstrap 区间描述当前固定网格中的稳定性，不代表连续 Weibull 参数空间的抽样推断；sample hindsight 也不代表可学习上限。
