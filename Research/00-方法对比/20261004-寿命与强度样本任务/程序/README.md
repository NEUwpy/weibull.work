## 程序

八组小提琴图均用普通线性坐标，显示主体分布。β统一显示0–10；η显示0至真尺度的2倍，即强度0–200、寿命0–2000；γ显示0至真位置与真尺度之和，即强度0–600、寿命0–1500。同一背景的四个β条件、三个样本量共用范围和刻度。超范围估计只在图示中省略。核密度及散点使用显示范围内数据，轮廓不外延尾部；中位数和四分位数仍由全部成功估计计算，γ=0保留散点。

- [运行任务.py](运行任务.py)：调用八个组合的独立计算入口，已完成组合不重算。
- [生成表图.py](生成表图.py)：生成Excel、MDM图和小提琴图，图片仅输出PNG。
- [调整小提琴显示范围.py](调整小提琴显示范围.py)：按固定线性显示窗重绘八幅小提琴图，不重算估计，不重绘MDM图。
- [核验任务.py](核验任务.py)：核对样本、表格值、来源、曲线与散点，另复算每组合每样本量第1组的五法估计。
- [封存任务.py](封存任务.py)：写入SHA256清单；加`--verify`核对已封存文件。
- [核查估计边界.py](核查估计边界.py)：核查实际重复端点、零位置边界及MDM形状搜索边界，结果见[边界核查汇总](边界核查汇总.json)。
- 本目录各W组合：保存参数专用入口、配置、母体和冻结依赖。之后释放组合时，程序与结果须成对保留。

失败记录不补估计，小提琴使用返回了参数的记录，完整记录保留在Excel和JSON/CSV。标准指标由冻结共用模块产生，保存在summary.json。返回参数与质量检查通过并不等价：12条MDM端点病态候选保留在表图取数中，但被标准汇总排除。

本批360组参数分布内没有重复的非零估计值，MDM形状估计未接近0.1或15的搜索边界。零位置估计确有聚集：LSE、LRE、MLE分别为158、157、165条；W(5,1000,500)、n=15下分别为19/50、19/50、20/50。LSE/LRE搜索包含零边界候选，MLE还将小于10⁻⁵的位置结果归零。轮廓的平截口本身不能据以认定极值重复。

W(5,100,500)、n=15的LSE有12组γ=0，η范围596.6—611.0、β中位数37.7；其余38组η中位数88.5。η右端聚集与零位置子组对应，支持位置被压到零后由尺度及形状补偿的解释。分组数值及组号保存在各组合中间数据的边界核查.json。
