# 寿命与强度样本任务

2026-10-04。任务包暂存8个参数组合，尚未释放到Research00根目录。

寿命尺度η=1000，强度尺度η=100；位置γ=500，形状β=1.5、2、3、5。每组合n=7、15、30各50组，MDM补偿阈值δ=0.20；共1200组、20800个观测、6000条五法估计。抽样种子20261004，同一n及组号跨β与尺度共用潜在指数变量。

## 程序

线性坐标试画：[W(5,1000,500)](../结果/W(5,1000,500)/估计分布_线性坐标试画.png)。三列均用线性坐标及原尺度核密度，端点截断规则沿用原设置；正式图暂保留。脚本为[试画线性小提琴.py](W(5,1000,500)/试画线性小提琴.py)。

- [运行任务.py](运行任务.py)：调用八个组合的独立计算入口，已完成组合不重算。
- [生成表图.py](生成表图.py)：生成Excel、MDM图和小提琴图，图片仅输出PNG。
- [核验任务.py](核验任务.py)：核对样本、表格值、来源、曲线与散点，另复算每组合每样本量第1组的五法估计。
- [封存任务.py](封存任务.py)：写入SHA256清单；加`--verify`核对已封存文件。
- 本目录各W组合：保存参数专用入口、配置、母体和冻结依赖。之后释放组合时，程序与结果须成对保留。

失败记录不补估计，小提琴仅使用成功返回，完整记录保留在Excel和JSON/CSV。标准指标由冻结共用模块产生，保存在summary.json。

## 复核

[核验结果](核验结果.json)记录全部1200组样本重建、20800个观测及18000个Excel参数单元格核对、120次五法抽样复算。实际检查了48页表格预览和32张图，结果见[显示检查](显示检查.json)。封存清单使用任务包相对路径；移动整个任务包仍可核对。
