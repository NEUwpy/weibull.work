# W(2,100,500)

强度分布；形状β=2、尺度η=100、位置γ=500。n=7、15、30各50组，MDM δ=0.20，种子20261004。五法为MDM、LSE、LRE、WMLE、MLE，LRE使用当前Park实现。

- [估计结果与样本](../../结果/W(2,100,500)/W(2,100,500).xlsx)：三个估计结果页、三个样本页；β、η、γ分别为形状、尺度、位置，“—”为未返回估计。
- MDM梯度图：[n=7](../../结果/W(2,100,500)/样本量7_偏移量0.20.png)、[n=15](../../结果/W(2,100,500)/样本量15_偏移量0.20.png)、[n=30](../../结果/W(2,100,500)/样本量30_偏移量0.20.png)。各图包含50组实际梯度曲线，红横线为0.20阈值，灰竖点线为真位置500；三个样本量共用坐标与刻度。纵轴为条件伪尺度标准差对γ的导数。
- [估计分布小提琴图](../../结果/W(2,100,500)/估计分布_小提琴图.png)：三行为n=7、15、30，三列为β、η、γ。全部成功估计以中心线散点显示，白菱形为中位数，细灰线为第25–75百分位，黑竖虚线为真值。同一参数三行共用坐标。三个参数均用普通线性坐标与原尺度Scott核密度，轮廓限于该组实际估计范围，不外延尾部；γ=0保留散点，不混入正值密度。宽度各自归一，不能用宽度判断成功数量。
