## 解释边界

1. 初始归档做复制完整性校验；后续已增加全量样本、表格来源核对及100次估计抽样复算，仍不是每个估计值全量重算或数学正确性认证。
2. 原表的参数符号有历史差异；判断形状、尺度、位置时以表头、原脚本和 manifest 为准，不单凭 α/β 字母对号入座。
3. W5 的 20260929 新抽样使用种子 2026092903，其结果 JSON 明确注明 LRE 已改为 Park（2017）Proposed+Plot；早期 Bernard 版本结果没有重算。不能把它们解释成完全相同实现下仅改变随机种子的比较。
4. 现平台求解器后来仍有更新；历史失败、零边界值和离谱估计按原件保留，不能直接认定为方法数学上必然无解，也不代表最新实现性能。
5. 批次主入口已适配当前目录并固定本地依赖，写入 `结果/复算输出`；历史原件和辅助诊断脚本仍可能含旧路径，不要混作运行入口。本目录仍需Python/Node等外部运行环境；没有把全部当前依赖冒充当时的原版代码。
6. 已被覆盖而未保留的早期随机批次不在本目录；“全部”指本次能找到的这 8 个组合及现存相关批次，不声称恢复所有曾生成的数据。

## 后续批次保存约定：程序与结果一一对应

每次生成样本或调用计算，都建立一个独立批次，在同一批次下配对保存 `程序` 和 `结果`，不只保留输出，也不只引用可能继续修改的平台代码。

```text
W(5,1000,500)/
└─ 日期-批次说明/
   ├─ 程序/
   └─ 结果/
```

- **程序**：复制当次实际使用的样本生成、估计调用、表图制作脚本，以及依赖的方法实现、权重文件和配置。记录分布参数及其含义、样本量、组数、随机种子、MDM 偏移量、运行命令和必要的运行环境版本。无需复制虚拟环境、依赖安装目录或缓存。
- **结果**：保存本批次使用的样本、估计表和所需图；保留失败状态，不用补值掩盖失败。只生成样本的批次无需制造估计结果；复用旧样本的计算批次须保留对应输入及其来源，不标作重新抽样。
- **对应关系**：在批次说明或配置中写清程序入口、输入样本和输出文件的对应关系，并记录关键代码、输入和结果的哈希。运行时使用该批次保存的代码与配置；不能仅复制调用脚本，却仍无记录地调用后来变化的平台实现。
- **批次隔离**：更换随机种子、样本或方法实现后另建批次；同一天多次运行用序号或时间区分，默认不覆盖已有结果。
- **历史材料**：现有 11 个样本/估计批次及 1 个跨组合诊断单元已按此结构配对；纯历史压缩包、旧版本和共用参考资料不伪装成新计算批次。历史程序原样保留，找不到当时依赖版本的在批次说明中明确注明，不拿当前代码冒充历史版本，也不声称已经完整复现。
