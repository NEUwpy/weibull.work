5. 复制的程序是历史来源快照，一些含原工作区绝对路径或依赖平台模块。本目录**不保证脱离原仓库即可独立运行**；复现前须按原 manifest、代码版本及结果 JSON 中的代码哈希匹配依赖。未把当前代码冒充旧计算时的代码。
