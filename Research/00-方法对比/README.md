## 解释边界

1. 初始归档做复制完整性校验；后续已增加全量样本、表格来源核对及100次估计抽样复算，仍不是每个估计值全量重算或数学正确性认证。
2. 原表的参数符号有历史差异；判断形状、尺度、位置时以表头、原脚本和 manifest 为准，不单凭 α/β 字母对号入座。
3. W5的20260929新抽样使用种子2026092903；原结果JSON及旧n30表记录Park LRE，026后的当前主表改为Bernard。原Park材料仅作历史证据，不能用于解释当前主表；032后五组仍使用Park，版本边界见当前十三组合交付。
4. 现平台求解器后来仍有更新；历史失败、零边界值和离谱估计按原件保留，不能直接认定为方法数学上必然无解，也不代表最新实现性能。
5. 批次主入口已适配当前目录并固定本地依赖，写入 `结果/复算输出`；历史原件和辅助诊断脚本仍可能含旧路径，不要混作运行入口。本目录仍需Python/Node等外部运行环境；没有把全部当前依赖冒充当时的原版代码。
6. 已被覆盖而未保留的早期随机批次不在本目录；初始归档的“全部”指当时找到的8个组合及相关批次；当前交付另列十三组合，不声称恢复所有曾生成的数据。

Research00 也用于后续指定 W 的计算任务。每个新计算任务保存自己的专用入口脚本、实际程序、输入配置和结果，使每次任务都能单独复核。新的W计算默认新建批次；同一研究的不同抽样协议可放在同一研究目录内的独立结果分项，分别记录种子、方法版本和脚本，不混合统计。报告补图、写作修订和整理沿用该研究目录，工作区保留最新版本，旧版本先提交Git再删除。

可以维护一个固定的**母体脚本或母体程序**，复用抽样、估计、建表和绘图流程。每次计算从母体生成新的任务脚本，并在对应研究／批次内保存实际母体和方法依赖；同一研究的依赖经SHA核对完全相同，可共用一份冻结快照。母体或方法版本改变时分别保留依赖与配置，不影响已保存任务。旧报告和重复生成副本由Git追溯，不靠堆积多个版本目录保存历史。

2026-10-04确定后续计算规则：LRE使用新版Park实现；WMLE沿用原程序的五个固定起点、接受阈值与失败判定，正式结果直接采用原程序输出，独立复查找到的根不补入统计，也不因复查修改求解器。寿命与强度任务已使用新版LRE，无需重算。历史批次保留各自冻结版本。

对外发送的计算任务，结果根目录只放参数组合目录，每组合仅保留交付Excel和PNG。完整中间数据、样本记录、失败状态、表格预览及复核日志统一放入对应程序目录；复核与版本比较的生成路径也位于程序目录。阶段性材料用Git追溯。

```text
W(5,1000,500)/
└─ 日期-时间或序号-任务说明/
   ├─ README.md                 # 本次配置、运行命令和复核说明
   ├─ 程序/
   │  ├─ 本次任务脚本.py         # 每次新建，固定本次输入与配置
   │  ├─ 建表与绘图脚本          # 保存本次实际使用的程序
   │  ├─ 依赖快照/              # 含使用的母体代码、方法实现和权重
   │  └─ 中间数据/              # 输入样本、估计记录、失败状态及检查记录
   └─ 结果/
      ├─ Wβ,η,γ.xlsx
      └─ 所需图像.png
```

- **常规任务规格**：未另行指定时，W的参数依次为形状、尺度、位置；n=7、15、30各50组；八方法为MDM δ=0.10、0.15、0.20，LSE、LRE、MLE、WMLE、MMLE。每组合交付一份六sheet主Excel与11张PNG（小提琴、有解率、九张MDM图），具体名称见当前交付清单。具体任务要求优先，并在批次README中记录。
- **任务脚本与程序**：每次新建专用入口脚本，可以由母体复制后适配，无需从头重写算法。保存当次实际使用的样本生成、估计调用、表图制作程序，以及母体副本、方法实现、权重文件和配置；不能只保留一个指向可变共用程序的入口。无需复制虚拟环境、依赖安装目录或缓存。
- **配置与版本**：记录分布参数及其含义、样本量、组数、随机种子、MDM 偏移量、方法版本（尤其 LRE 的 Bernard 或 Park 实现）、母体来源和版本、运行命令及必要的运行环境版本。新任务采用的方法版本须明确保存，不根据历史目录名称猜测。
- **结果**：保存本批次使用的样本、估计表和所需图；保留失败状态，不用补值掩盖失败。只生成样本的批次无需制造估计结果；复用旧样本的计算批次须保留对应输入及其来源，不标作重新抽样。
- **图像格式与目录**：常规任务图片仅保存PNG。多组合任务在任务包内只设“程序”和“结果”两个目录，两边按参数组合一一对应；结果只含交付Excel和PNG，说明、配置、中间数据、预览和复核记录全部归入程序目录。
- **小提琴图规范**：估计分布采用普通线性坐标；同一背景、同一参数跨β与n共用显示范围和刻度。β为0–10；η为0至真尺度的2倍，强度0–200、寿命0–2000；γ为0至真位置与真尺度之和，强度0–600、寿命0–1500。显示范围内散点沿方法中心线排列，不随机抖动；四分位线约0.5pt，粉点标中位数、红点标均值，细黑虚线标真值。密度仅用显示范围内的成功估计，Scott带宽，轮廓止于实际最小值和最大值；γ=0保留散点、排除于正值密度。完整估计、失败状态及基于全部成功估计的统计量保留，省略数量和值记在程序的绘图记录里。图内不加说明框、长备注或重复阈值，口径及必要解释放图注。该显示规则用于估计分布，不用于强制改变各方法准则曲线的坐标类型。
- **对应关系与复核**：在批次 README 中写清任务脚本、计算程序、输入样本、表图输出的对应关系，记录关键代码、输入和结果的 SHA256，以及实际完成的检查及其范围。复核时使用该批次保存的代码与配置，输出写入程序目录内的复核目录，保留原交付结果。
- **任务隔离与版本**：每次计算保留独立入口、配置与结果；新研究／新W默认另建批次，同一研究内可分项保存不同种子或方法版本。原结果不被复算覆盖。报告修订和补图不另建重复批次；先提交Git，再删除旧稿和已确认不需要的副本，工作区保留最新可复核交付。
- **历史材料**：初始整理的11个样本/估计批次及1个跨组合诊断单元按此结构配对；当前十三组合及主批次以本页当前索引为准；纯历史压缩包、旧版本和共用参考资料不伪装成新计算批次。历史程序原样保留，找不到当时依赖版本的在批次说明中明确注明，不拿当前代码冒充历史版本，也不声称已经完整复现。
