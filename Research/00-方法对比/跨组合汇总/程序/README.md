有解沿用主Excel展示规则：三参数均为有限数值；每个组合、n、方法的分母为50。边际有解率=相关条件的有解数之和/总次数之和：按β，2与3各450、5为300；按γ，500与3000各450、1000为300；按n，每档400，均为每个方法的分母。缺少β=5、γ=1000的组合，未补值。

小提琴图：粉点为中位数，红点为均值，细虚线为真值；线性坐标，同参数三档n同刻度。显示范围β0–10、η0–2000、γ0至真γ+真η；窗外估计只从图中省略，完整数值仍在Excel。散点不抖动、四分位线0.5pt，Scott密度止于窗内实际观测范围；γ=0只画散点。均值、中位数和四分位数使用全部成功估计，省略记录保存在各批绘图核验中。

有解率热力图：每面行=八方法、列=n7/15/30，统一Blues与0–100%色阶，格内显示比例。八组合各一面；所有比例均与192行统计逐格对应。
