# Research00 方法统一核对与接入方案

> 2026-10-10。范围：报告1、报告2使用的六类方法，以及现有方法系统的公式、流程和共享程序。用户本轮要求先查清差异、形成方案，暂不改计算程序。本文是待实施方案，不表示接入已经完成。

## 1. 判断

两份报告应引用同一套方法定义和计算核心。方法系统负责回答“依据哪篇论文的哪个分支、公式怎样进入计算、程序实际采用什么配置”；研究报告负责回答“这组样本为什么使这些步骤产生偏移或异常”。两份报告的问题可以重合，其共同方法的定义不应随报告重新编写。

目前并非每份报告都重新实现了估计器。两份报告主要复用共享方法的冻结副本，真正分散的是过程诊断函数、公式解释和版本身份。统一工作的重点是把这三者接回已有方法系统，而不是另建一套方法框架。

“标准化”应固定到具体文献分支。MDM的精确中位秩与Bernard近似、LRE的Bernard与Park绘图位置、MMLE的Kundu–Raqab与Cohen–Whitten构造不能仅凭方法简称混为一套。公式等价改写不构成新方法；改变绘图位置、偏移值、参数域或数值求解规则，则须说明实际差异。

## 3. 需要统一的具体内容

### 3.1 公式与计算步骤的共同定义

统一使用β、η、γ表示形状、尺度和位置，`d_i=x_(i)−γ`表示排序观测的平移距离；局部回归斜率另记为b，避免与形状混淆。具体来源、推导、差异与验证继续维护在现有方法文档，不复制到新的总规范中。

| 方法及现有说明 | 应固定的核心计算关系 | 必须同时说明的实现条件 |
|---|---|---|
| [MDM](../../src/content/algorithms/mdm.md) | 给定γ，最小化伪尺度的样本标准差以确定β；用条件最小标准差的梯度与δ定位；η取伪尺度均值 | 秩规则、δ、β范围、差分步长与单边处理、零边界、Brent交点及右端回退分支 |
| [LSE](../../src/content/algorithms/lse.md) | 参考坐标为对数顺序统计量期望；回归`ln d=a+bz`，β=1/b、η=exp(a)；用F比定位 | F比与1−R²的等价关系、位置范围、候选网格与精化规则 |
| [LRE](../../src/content/algorithms/lre.md) | 参考坐标为绘图位置的双对数变换；回归`z=a+b ln d`，β=b、η=exp(−a/b)；用相关性定位 | Bernard/Park身份、Park的n=10/11分段、边界及位置搜索；正相关时ρ、ρ²和1−R²的最优位置关系 |
| [MLE](../../src/content/algorithms/mle.md) | 标准三参数对数似然及其得分；联合搜索后选择接受候选 | 非负位置、β≥1的候选接受规则、多初值及收敛判据；Hirose为基准来源，不把本实现称为其完整求解流程 |
| [WMLE](../../src/content/algorithms/wmle.md) | J₂修正形状方程、J₃修正位置方程；尺度含J₁校准 | 权重表哈希、插值与表外规则、形状上界10、双方程残差与接受规则；代码中的paper gamma为系统β，paper alpha为系统γ |
| [MMLE](../../src/content/algorithms/mmle.md) | γ取原最小值，删除一个最小观测；保留距离上作固定点迭代，按n−1恢复尺度 | Kundu–Raqab单样本化简身份、初值与停止条件、重复最小值失败、保留观测支持、R²占位含义 |

### 3.2 分散的过程诊断

报告1的[剖面母体.py](20261001-高形状参数补偿报告/程序/剖面母体.py)中`profile()`重新计算回归、条件形状、似然、MDM标准差及梯度；[过程曲线入口](20261001-高形状参数补偿报告/程序/计算逐法过程曲线.py)据此生成解释曲线。报告2的[准则关系.py](跨组合诊断/20261009-形状异常退化解/附录/程序/准则关系.py)、[逐方法机制复核.py](跨组合诊断/20261009-形状异常退化解/附录/程序/逐方法机制复核.py)又分别实现了条件得分、回归、MDM梯度和WMLE残差。

这些程序有既有对拍记录，不能据“重新写了公式”就判定结果错误；但维护时需要多处核对，确实存在漂移风险。例如：

- 报告1的MLE条件形状限定β>1；报告2部分条件曲线允许正β并展示β<1区间。它们的诊断域不同，均不能自动读作生产MLE的候选接受过程。
- 报告1的MDM曲线采用自行实现的中心／前向差分；共享程序另有近右端的后向差分。报告2还有解析包络梯度用于机制解释。这三者应明确类型和适用区间。
- WMLE的条件曲线先解T₁再评价T₂；生产程序联合最小化两项残差平方和。条件零线解释方程平衡，不能替代实际搜索、容差接受或漏解记录。

报告2已有[六方法公式实现核验](跨组合诊断/20261009-形状异常退化解/附录/程序/20261010-六方法公式实现核验.json)和[MDM原文对应记录](跨组合诊断/20261009-形状异常退化解/附录/程序/20261010-MDM公式逐项对应原文.json)。这些是此前验证的记录，本轮未重新执行；可以作为接入时的对拍输入与参照。

### 3.3 方法系统现有缺口

1. **MDM文字与实际分支没有完全对应。** 方法文档顶部及第二节仍有“对β、γ二维最小化”的概括，而当前程序采用条件形状优化加正梯度阈值定位；“始终有解”、负半轴交点及右端必有交点的说明也过强。报告2已记录梯度非单调、内部交点被右端探测错过的案例。后续应先修正文档与流程说明，分别展示实际交点、零边界返回、右端回退及实测残差；是否改求解器是另一项实验。
2. **流程页面已接源代码，但完整度不同。** [流程接口](../../src/app/api/method-flow/%5BmethodId%5D/route.ts)直接读取`python/methods/{id}.py`的`@step/@formula`注释，已有接入基础。MMLE没有`@step`注释，虽有迭代trace仍无法据此生成步骤；LRE有步骤注释，但`run()`不接受`trace`，也不记录逐点搜索trace。不能把“有代码”“有流程文字”和“能输出实际轨迹”等同。
3. **统一入口尚未完整记录生效配置。** [runner](../../python/studies/common/runner.py)已有`method_id`、`method_variant`、`extra.solution_info`，但会过滤方法不接受的参数。未来版本记录应保存实际生效配置，不能只把传入参数写进manifest。
4. **MMLE的支持口径需要接入质量检查。** 通用[metrics](../../python/studies/common/metrics.py)仍按原样本最小值检查γ，而MMLE取γ=x₍₁₎并删去该观测，应按保留观测最小值检查。其数学构造、求解收敛、通用统计准入须分别说明；接入时不能简单关闭所有方法的支持检查。

## 4. 接入方案：沿用现有职责，只补缺口

```text
方法文档：文献分支、公式、适用条件、当前实现差异
                         ↕ 公式与函数对应
python/methods：准则评价、实际求解、过程记录
          ├─ registry → runner → 计算器／新研究估计
          ├─ @step/@formula → 方法系统流程页面
          └─ 共享准则评价 → 两份报告的机制分析与绘图

历史报告：指定冻结版本及配置 → 原结果与诊断
```

**方法定义。** 继续以`src/content/algorithms/*.md`保存来源和公式，补齐所选文献分支及“数学式 → 函数 → 过程量”的对应。报告引用这一定义，再展开与问题有关的步骤；报告中的公式允许按叙述需要重述，但不能引入未声明的规则。

**计算核心。** 在各方法现有文件内按实际需要提取可调用的准则函数，使估计器与诊断共同调用。优先处理两个报告都使用的MDM条件标准差／数值梯度、回归参考坐标与条件拟合、MLE似然／得分、WMLE残差／权重；MMLE提供保留样本与迭代中间量。只共享确有共同消费者的计算，不强迫六类方法采用同一个求解流程。

**过程输出。** 分清三种用途：给定候选点的准则评价、为解释机制而求的条件最优剖面、实际求解器访问的点与最终选择。每种输出带方法版本、配置和范围；解析导数与数值差分分别标识。读过程和画图不应自动重新估计参数。

**版本和配置。** 复用已有manifest，记录方法ID、文献分支／变体、源码及依赖哈希、实际生效配置、求解分支和质量检查口径。MDM的δ与秩规则、LRE的绘图位置、WMLE的权重表、MMLE的保留样本规则必须可追溯。新研究默认走`registry → run_method()`，历史复现明确指定冻结版本。

**两个报告。** 保留目前数据和版本身份，先补方法来源与差异索引。共同方法尽量复用同一诊断函数；需要跨报告比较时，匹配版本、δ及诊断域。若将来要求所有LRE均为Park，应另算相同存档样本上的新版结果，再更新对应证据，不能用当前方法页替代旧数据的定义。

## 5. 实施顺序与验收

| 顺序 | 最小工作 | 验收条件 |
|---|---|---|
| 1 | 六方法定义、变量及实际分支对应；优先修正MDM说明、补齐MMLE流程 | 文献原式、等价改写、工程变体和数值分支能明确区分；两份报告方法来源可查 |
| 2 | 提取已有准则计算供估计器和诊断共用；补必要的实际配置与过程输出 | 同一存档样本的参数、成功／失败集合、关键中间量对拍；预定范围内保留原结果 |
| 3 | 让两份报告的过程分析调用共享评价，保留报告特有统计和图形 | 相同版本、配置、候选点得到相同过程量；条件剖面和实际轨迹明确标识；既有图数据对拍 |
| 4 | 接入方法系统流程和计算过程；单独处理MMLE支持检查 | 页面与报告读取同一计算来源；支持规则按方法生效；占位R²不作为拟合结果解释 |
| 5 | 如需标准原版或求解改进，再单独开展版本对照 | 新旧规则、同样本参数差异、失败率及异常率分开保存，不覆盖历史证据 |

提取函数时，保持原运算顺序、容差和边界处理；源码哈希会改变，应以数值对拍证明行为保持。改差分规则、搜索范围、回退或权重属于算法行为变化，不与纯共享接入混在一起。优先复用现有测试和报告核验数据，仅补覆盖真实差异所需的验证。
