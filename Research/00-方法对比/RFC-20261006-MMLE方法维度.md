## 2. 方法程序（`python/methods/`）

| 文件 | 动作 |
|---|---|
| `mmle.py` | 改写为 **K-R 原版**（正身）；`"mmle"` 语义随之变更 |
| `mmle_ch.py` | 新增：迁入原 Cohen–Whitten MMLE-I（内容不变，仅移位），注册名 `mmle_ch` |
| `registry.py` | `"mmle"→K-R`、新增 `"mmle_ch"→CH` |
| `README_DEV.md` / 算法文档 | 补两版口径、出处（K-R 2009 印刷页 1840 式(4)、1841 式(6)(9)–(11)） |

算法规范：

```
x1 = x[0]; γ̂ = x1（deleted_observations=1）
y = x[1:]; logs = ln y; q = n−1; β₀ = 1
迭代 β ← (q + β·Σlogs) / (q·Σ w·logs)，w ∝ exp(β·(logs−max))
停止：|Δβ| ≤ 1e-8 或 10000 次；未达标 → status='fixed_point_not_converged' → 判失败
η̂ = exp((logsumexp(β·logs) − ln q) / β)
返回 [β̂, η̂, γ̂, R², ok]；last_solution_info 记 status/iterations/…/no_firth=True/no_fallback=True
```
