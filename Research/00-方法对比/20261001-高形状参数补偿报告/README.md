# 高形状参数下的位置与尺度补偿报告批次

日期：2026-10-01。[三章报告放在Research00根目录](../高形状参数下的位置与尺度补偿报告.md)。本批次独立保存任务脚本、实际程序、输入、结果和封存清单。

## 配置与口径

原案例复制前批次已经核验的β=2/5估计与样本，β=5的n7/15各50组用于现象展示。原种子、表列映射和1000次五法复算属于已有证据，不作为新的独立实验。

新实验：β=2、2.5、3、3.5、4、4.5、5，η=1000、γ=500，n7/15各50组，共700组。共享抽样器generate_sample(1.,1.,0.,n,repeat_id,seed=20261001)生成单位指数顺序统计量E，再变换为500+1000*E**(1/beta)。同一n/组号跨β共用E，保存E与实际样本。

历史MDM δ=0.10、LSE、Bernard LRE、WMLE、MLE及单列的Park LRE共4200条估计。实际方法代码和J3权重固定在程序/依赖快照/python，没有从实时平台导入方法。

成功返回候选进入描述性中位数/IQR，失败留空，γ=0边界保留；各β成功子集可能变化。严格端点配对只统计两端均成功的共同组号。共享Bias/SD/RMSE/MAE另存在汇总JSON的标准指标块。

## 已核验范围与数值限制

700组逆变换恢复E的最大差3.55×10⁻¹⁵，独立重建E与x逐值差0；12条端点配对的交集、方向计数和分位数独立核对一致。4041个成功返回的条件β/η公式最大绝对差8.24×10⁻⁴、0.01334；小条件参数差不能保证位置根很近。

WMLE β真3.5、n7、#39的原β=3.3、γ=678.31，原T1/T2约−8.21×10⁻⁵/−4.05×10⁻⁵，平方残差8.37×10⁻⁹通过原10⁻⁸容差。细化根γ=700.19，差21.88，原候选保留。WMLE候选β<10，J3在β>5夹表；真γ处n7β4.5/5分别有2/5组条件形状超出支持，保留缺失。MLE只解释β>1有限剖面及零边界。

新实验支持MDM/WMLE的γ上移、η下降中心趋势，回归法与MLE出现双侧、反向和零边界。报告没有把原五法共同偏移推广为所有方法随β严格单调的普遍规律。
