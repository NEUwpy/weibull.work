## 结论口径保持一致

MDM δ=0.10、γ≥0；WMLE候选β<10、J3在β>5夹表；MLE只解释当前有限局部分支和零边界。共同实验支持MDM/WMLE的位置上移、尺度下降中心趋势，其他方法有反向或边界解，不能写成全部方法随β必然同向。

LSE实际最大White F，与最小1−R²等价；LRE最大变换点回归的决定系数R²。这里的R²与表中的CDF拟合R²评价对象不同。共同潜在样本在真γ处的相关性不随β改变，数值最大差约10⁻¹⁵；差别来自离开真γ后的对数距离变换和最优位置。图3–7的e/f均为配对曲线直接展开，五法所有单例的G号都对应公式计算点，完整编号及来源见配对单例与推导核验.json。补充图6的LSE/LRE七点及两种γ下的同号观测来自原批次，γ=500的直线也是条件拟合；WMLE联合零线同样来自原批次，不是主图的配对例。两类示例分开解释，均不冒充优化器迭代轨迹。WMLE实际联合最小化T1²+T2²，主图展示T1=0分支上的T2；MLE实际联合优化，主图由尺度／形状方程消元得到有限似然高点。MDM解析梯度及权重标准差检查仍保存于mdm_envelope。

图8使用一组完整实际参数，样本绘图位置不是独立验证；精确63.2%概率为1−exp(−1)，1%位于该组绘图位置覆盖之外。固定真γ只是机制诊断。原漏解和容差近似解仍单列，整理不改变统计与数值问题的区别。

以后同一研究的补图、报告修订和整理在本目录完成，任务入口分别保存，版本交给Git；新样本协议／新方法版本单独记录配置、脚本和结果，避免产生多个内容相同的同级目录。
