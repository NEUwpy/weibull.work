# E01-6 三方法蒙特卡洛（双视角）— 修订版

## 实验设计

- 真值：β=2.5, η=1000, γ=100
- 样本量：n ∈ {5, 7, 10, 15, 20, 50}
- 重复：2000 次（全部 n 统一）
- 种子：SEED=2024，可复现
- 方法：MDM(δ=0.1) / MLE / LSE
- LSE：**研究用本地对照实现**（`程序/lse_weibull.py`），平台 `python/methods/lse.py` 仍为 NotImplementedError
- 同一批样本上三种方法配对估计

## 指标口径

调用 `python/studies/common/metrics.py::aggregate_standard_metrics()`，输出：
- n_total / n_valid / n_failure / valid_rate / failure_rate
- 参数视角：Bias / SD / RMSE / MAE（β,η 补充相对指标，γ 禁用相对指标）
- 工程视角：x̂₀.₉₅ / x̂₀.₉₉ 的 Bias / SD / RMSE / MAE / 相对指标
- γ̂=0 截断率（严格 < 1e-10）与 γ̂ 近零率（< tol=0.01，即 < 1% 真值）分开统计

## 调用链

- MDM/MLE：`sys.path → D:/weibull/python` → `run_method()`
- LSE：本地 `程序/lse_weibull.py` → `fit_weibull3_lse()`
- 样本生成：`studies/common/sample.py` → `generate_sample()`
- 指标聚合：`studies/common/metrics.py` → `aggregate_standard_metrics()`

## 运行方式

分n逐个运行（避免超时）：
```
python E01-6_single_n.py 5 2000
python E01-6_single_n.py 7 2000
python E01-6_single_n.py 10 2000
python E01-6_single_n.py 15 2000
python E01-6_single_n.py 20 2000
python E01-6_single_n.py 50 2000
```
然后合并：
```
python E01-6_merge.py
```
