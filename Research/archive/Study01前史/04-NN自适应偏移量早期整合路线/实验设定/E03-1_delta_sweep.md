# E03-1 δ扫描蒙特卡洛

## 目的
扫描不同 δ 值，生成各 (β, n, γ/η) 配置下的 MDM 估计结果，为后续层级最优分析提供数据基础。

## 配置

| 参数 | 取值 | 说明 |
|------|------|------|
| β | 2, 2.5, 4 | 形状参数，覆盖常见范围 |
| n | 7, 10, 20 | 样本量，小样本到中等样本 |
| γ/η | 0.1, 0.5, 1.0 | 位置参数与尺度参数比值，决定分布形状 |
| δ | 0, 0.02, 0.04, ..., 0.50 | 偏移量扫描范围，26个点 |
| 重复 | 500次/配置 | 蒙特卡洛重复次数 |
| η | 1.0（固定） | 利用尺度不变性 |

## 总计算量
- 配置数：3×3×3 = 27 个 (β, n, γ/η) 组合
- 每个配置：500 样本 × 26 δ = 13,000 次 MDM 拟合
- 总拟合次数：27 × 13,000 = **351,000 次**
- 预估时间：~4.5 小时

## 方法
1. 固定 η=1，按 γ/η 计算 γ_true
2. 对每个 (β, n, γ/η) 组合：
   - 生成 500 个样本（种子由参数唯一确定，可复现）
   - 对每个样本，扫描 26 个 δ 值
   - 调用 MDM.run(offset=δ)，记录 (β̂, η̂, γ̂, status)
3. 保存到分片文件 + 汇总文件

## 与 02 的衔接
- 02 证明了 MDM 始终有解（截断+拟合方案）
- 03 直接使用 02 的工程方案，所有 δ 值下 MDM 都能给出合法估计
- 03 专注于优化 δ 的选取，而非解决有解性问题

## 产物

### 分片文件（27个）
文件命名：`E03-3_delta_sweep_beta{β}_n{n}_gamma{γ/η}.csv`

示例：
- `E03-3_delta_sweep_beta2.0_n7_gamma0.1.csv`
- `E03-3_delta_sweep_beta2.5_n10_gamma0.5.csv`

每个文件结构：
```csv
delta,rep,beta_hat,eta_hat,gamma_hat,status
0.00,0,2.123,987.6,45.2,True
0.00,1,1.987,1023.4,32.1,True
...
0.50,499,2.456,876.5,67.8,True
```

### 汇总文件
`E03-3_summary.csv`

每个 (β, n, γ/η, δ) 组合一行，包含：
- bias_beta: E[β̂] - β_true
- sd_beta: std(β̂)
- bias_eta, sd_eta: 同上
- bias_gamma, sd_gamma: 同上
- n_valid: 有效样本数

## 最优定义
使 **J_param** 最小的 δ 为最优 δ*。J_param = √( mean( ((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)² ) )，三参数综合相对RMSE，无量纲化后可跨参数比较。

## 层级定义

| 层级 | 含义 | 部署可行性 |
|------|------|-----------|
| L0 | 全局共用一个 δ* | ✅ 可直接部署 |
| L1 | 按 n 分组：δ*(n) | ✅ n 已知 |
| L2 | 按 β 分组：δ*(β) | ⚠️ 需先估计 β |
| L3 | 按 (β,n) 分组：δ*(β,n) | ⚠️ 需先估计 β |
| L4 | 按 (β,n,γ/η) 分组：δ*(β,n,γ/η) | ⚠️ 需先估计所有参数 |
| L5 | 逐样本 Oracle（仅 n=7） | ❌ 不可实现，仅作参考 |
