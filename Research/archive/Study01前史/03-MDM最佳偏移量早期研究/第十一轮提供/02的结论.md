# 02 结论：MDM怎么算

## 算法

给定样本，构建廓线S(γ)后，解 g(γ̂) = δ 定位γ̂，其中廓线梯度有解析式：

g(γ) = (γC_vv − C_uv) / S(γ)

g在(−∞, t₍₁₎)上单调上升，自−sᵥ到+sᵥ，只要sᵥ > δ就有唯一根。

## 会遇到的问题及解法

**网格漏检**：根贴近t₍₁₎时，均匀网格的离散梯度抬不过δ，检测不到根。

**解法**：不用网格，直接用Brent定根法在g(γ)=δ上精确定位根。

**γ≥0下界切除**：解出来的根可能为负（无约束根落在γ<0区域）。

**解法**：根为负则截断到γ̂=0。这样保证始终给出[0, t₍₁₎)内的合法估计。

**一句话**：Brent定根＋负则截断到0 = 100%有解（12000次验证，中位20次求值）。
