一、研究背景

研究对象是三参数 Weibull 分布：

F(t) = 1 - exp(-((t - γ) / η)^β), t > γ

其中：
β 是形状参数；
η 是尺度参数；
γ 是位置参数；
t 是失效时间样本。

本研究关注 MDM 方法，即 Minimum Discrepancy Method，中文可称为最小差异法。MDM 的基本思想是：如果 β 和 γ 选得正确，那么每个样本点反算出来的尺度参数 η 应该尽可能一致。因此，MDM 通过让这些“伪尺度参数”的差异最小来估计 β、η、γ。

二、MDM 方法的公式和算法

给定一组失效时间样本，先排序：

t_(1) ≤ t_(2) ≤ ... ≤ t_(n)

对第 i 个样本点，用中位秩估计经验累积分布函数。常用 Bernard 近似：

F_i = (i - 0.3) / (n + 0.4)

令：

x_i = -ln(1 - F_i)

对于任意给定的 β 和 γ，可以由 Weibull 分布反推出第 i 个样本点对应的伪尺度参数：

η_i(β, γ) = (t_i - γ) / x_i^(1/β)

如果 β 和 γ 合理，那么所有 η_i 应该尽量接近。定义伪尺度参数标准差：

S_η(β, γ) = sqrt(1/(n-1) * Σ(η_i - mean(η_i))^2)

对于每一个固定的 γ，先寻找使 S_η 最小的 β：

β*(γ) = argmin S_η(β, γ)

然后定义条件最小标准差函数：

σ_min(γ) = min_β S_η(β, γ) = S_η(β*(γ), γ)

位置参数 γ 必须满足：

γ < t_min

其中 t_min = t_(1)，即最小样本值。

然后计算 σ_min(γ) 关于 γ 的梯度：

∇(γ) = dσ_min(γ) / dγ

传统极值思想会取：

∇(γ) = 0

这表示 σ_min(γ) 的极值点，也就是伪尺度参数标准差最小的位置。但实际中发现，直接取 ∇(γ)=0 时，估计出的 γ 可能波动很大，尤其可能非常贴近最小样本值 t_min，导致 β、η、γ 的估计不稳定。

因此，MDM 中引入一个梯度偏移量 δ，不再取 ∇(γ)=0，而是寻找：

∇(γ) = δ

例如工程或文献中可能使用 δ = 0.1。

三、需要重点研究的问题

现在的问题是：δ 到底应该取多少才最好？

请注意，“最好”不能只用一句话定义。你需要研究不同层面的“最佳偏移量”：

1. 单一样本最佳  
   对一组具体样本，哪个 δ 使估计误差最小？

2. 真值参数条件最佳  
   在给定真实参数 β、η、γ 的情况下，多次模拟后哪个 δ 平均表现最好？

3. 样本量条件最佳  
   在给定样本量 n 的情况下，跨多个真实参数场景，哪个 δ 平均表现最好？

4. 全局固定最佳  
   如果必须使用一个固定 δ，哪个 δ 在所有测试场景中整体最好？

5. 自适应最佳  
   是否可以根据样本特征自动选择 δ，而不是固定取 0.1？

四、关键前提和判断口径

请区分以下两件事：

1. 严格求 ∇(γ)=δ 的交点，可能在某些样本中找不到内点交点。
2. MDM 作为约束优化或数值估计方法，仍然应当可以给出可行域内的解。

因此，本研究中请采用以下口径：

MDM 方法应被视为在 γ < t_min 的可行域中寻找估计结果。即使 ∇(γ)=δ 没有严格内点交点，也不应简单说 MDM 无解，而应讨论约束意义下的解，例如：
取可行域边界解；
取 σ_min(γ) 最小点；
取最接近目标梯度 δ 的点；
或使用其他合理的 constrained solution。

报告中需要明确解释：  
“严格交点不存在”不等于“MDM 方法没有估计结果”。
