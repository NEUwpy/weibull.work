## 一、研究定位

Study1.5 是 Study01 派生出的独立机制研究单元，归属于总体研究规划中的“样本处理与表征”节点。它不改变 Study01“样本自适应选择 MDM 偏移量”的研究主线，而是补清该任务中尚未回答的神经网络输入表示与样本量问题。

Study1.5 不以改变既有研究决策、证明13特征正确或直接服务 Study02 为目的。它要说明：在同一 delta 风险曲线任务中，不同输入表示让受控神经网络获得了什么可利用信息，这些差异如何随训练和测试样本量变化。

它作为独立证据单元保存结果，但不预设形成独立论文，也不进入 Study01 或 Study02 的 formal 证据链。

## 二、研究对象

研究任务固定为：

```text
样本可观测信息
  -> 受控 Vector-MLP
  -> 26点 MDM delta 预测风险曲线
  -> argmin
  -> 样本自适应 delta
```

模型输入不包含真实参数、`repeat_id`、seed、delta 或其他部署时不可见字段。真实参数和真实风险曲线只用于监督标签与评价。

第一阶段复用 Study01 Formal E3b 的既有数据基础：

- 三参数 Weibull 完整小样本；
- `n=7,10,20`；
- 现有 `(beta, gamma/eta)` 网格；
- 45,000个样本及其26点风险曲线；
- 已有 combo split 和样本重建机制。

所有源数据和 formal artifacts 只读复用，Study1.5 的派生产物写入自身目录。

## 三、研究目的与问题

### RQ1 输入表示差异

在数据、目标、训练协议和模型总容量近似相同的条件下，现有13个统计特征与排序原始样本表示在以下方面相差多少：

- 26点风险曲线预测误差；
- 最终 selected `J1`；
- 相对同域参考或 hindsight 最优选择的 regret；
- 不同 `n` 下的表现和训练稳定性。

RQ1 只评价指定受控网络和原始样本编码，不外推到所有原始样本网络。

### RQ2 样本量信息

回答两个相互区别的问题：

1. 删除显式 `n` 后，12个统计特征在多大程度上仍携带可识别的样本量信息；
2. 在 delta 风险曲线任务中，显式加入 `n` 是否仍提供可见的增量价值。

该问题不把“能够识别 `n`”等同于“delta任务需要显式 `n`”。

### RQ3 跨样本量学习

比较三种训练组织：

- 单一 `n` 训练后迁移到其他 `n`；
- 多个 `n` 联合训练后预测留出的未见 `n`；
- 联合模型与按 `n` 专用模型在各样本量上的差异。

主要判断迁移代价如何随输入表示、训练—测试样本量组合和距离变化，以及联合训练带来共享收益还是负迁移。

RQ3 是 Study1.5 的核心问题，RQ1提供表示基线，RQ2提供机制解释。

## 四、固定输入方案

| 方案 | 输入 | 作用 |
|---|---|---|
| `F13` | Study01 现有13个统计特征，含显式 `n` | 当前特征方案 |
| `F12` | 从 `F13` 中仅删除 `n` | 检查隐式样本量信息和显式 `n` 的增量作用 |
| `RAW` | 排序原始观测、padding、有效位置 mask | 原始样本受控表示；mask 自然表达样本长度 |

不新增候选特征。`RAW` 不重复加入数值字段 `n`，也不引入复杂集合网络。

三类输入使用深度、优化设置和训练规则一致、总可训练参数量近似匹配的网络。具体层宽、允许偏差和训练随机性由实验合同冻结。

## 五、第一阶段计划

### P0 复核既有探索证据

把 `fd38faf` 中的一折一seed输入表示 pilot 固定为探索依据，不升级其证据等级，不把既有结果与后续确认结果混合计算。

### P1 建立问题结构

在已看过的探索范围内完成最小诊断：

- `F13 / F12 / RAW` 的受控输入表示比较；
- 12特征中的样本量可识别性；
- 单一 `n` 的定向迁移；
- 留一 `n` 的联合训练泛化；
- 联合模型与专用模型的方向性比较；
- 输入分布、真实风险曲线和迁移 regret 的对应关系。

这一阶段用于发现结构和冻结比较，不产生确认性结论。

### P2 冻结最小确认合同

具体合同见 `03-第一阶段执行合同.md`。在查看新的确认结果前冻结：

- 核心比较及其主次关系；
- 模型容量与训练设置；
- 训练/测试样本量组合；
- 评价指标和聚合单位；
- 多折、多seed范围；
- 失败处理、产物路径与声明边界。

合同只确认核心结论，不升级全部诊断为完整全因子实验。

### P3 确认核心结论

使用未纳入探索判断的既有折和预设 seeds，确认：

1. `F13` 与 `RAW` 的跨样本量迁移差异；
2. 联合训练相对专用训练是否出现稳定的共享收益或负迁移；
3. `F12` 与 `F13` 的差异能否支持对显式 `n` 作用的解释。

确认完成后停止第一阶段，不因结果方向不理想继续增加模型、seed、特征或样本量。

## 六、评价结构

### 主要结果

- 风险曲线预测误差；
- selected `J1`；
- 相对同 `n` 参考模型的迁移 regret；
- 相对同一样本 hindsight 最优 delta 的 excess loss 或 regret。

### 分层结果

- 按测试 `n`；
- 按训练 `n -> 测试 n` 方向；
- 按输入表示；
- 按 seed；
- 必要时按 `(beta, gamma/eta)` 组合检查方向一致性。

绝对 `J1` 随 `n` 改善不能单独证明网络成功泛化。跨样本量判断必须以同一测试 `n` 上的相对差异或 regret 为主。

### 解释性诊断

- 12特征对 `n` 的可识别程度；
- 不同 `n` 下特征分布变化；
- 不同 `n` 下真实风险曲线变化；
- 输入分布偏移与迁移 regret 的关系。

这些诊断用于解释结果，不扩展为新的模型竞赛。

## 七、证据边界

### 允许回答

- 在指定 delta 风险曲线任务和受控 Vector-MLP 下，`F13` 与 `RAW` 的差异及其大小；
- 12特征中是否存在可识别的样本量信息，显式 `n` 是否提供增量价值；
- `n=7,10,20` 之间的单向迁移、留一 `n` 泛化和联合训练性质；
- 当前输入方案在哪些 `n` 上出现共享收益、接近、退化或负迁移。

### 禁止外推

- 不声称13特征是充分统计量、无损表示或普遍最优；
- 不把排序、padding、mask 的受控输入代表为所有原始样本网络；
- 不外推到未测试样本量、连续 `n`、网格外参数或真实工程数据；
- 不外推到直接参数估计、目标分位数或其他任务；
- 不把 Study1.5 结果作为 Study02 accreditation、scheduler、unseal 或 formal 证据；
- 不修改或重新解释 Study01 已封存 formal artifacts。

## 八、明确不做

- 第一阶段不生成 `n=15` 或其他新样本量；
- 不增加统计特征或重新开展特征筛选；
- 不引入 DeepSets、Transformer、CNN 等新架构；
- 不扩展 Study02、直接参数估计或目标分位数任务；
- 不新增通用实验基础设施；
- 不做完整全因子训练矩阵；
- 不为追求正向结果追加模型、seed 或后验阈值；
- 不预设独立论文、博士论文章号或平台模块。

## 九、停止条件

第一阶段在以下条件满足后结束：

1. `F13` 与 `RAW` 的任务内差异及按 `n` 变化已量化；
2. 隐式样本量信息与显式 `n` 的增量作用已区分；
3. 单一迁移、留一 `n` 泛化和联合/专用训练的主要方向已确认；
4. 结论能够区分估计任务固有难度与神经网络迁移代价；
5. 结果边界和失败情形已记录。

差异很小、迁移失败或证据不支持当前13特征，都属于允许的终点。是否新增 `n=15`、形成论文或开展第二阶段，必须在第一阶段结束后另行评估，不自动触发。

## 十、与组会和既有研究的关系

Study1.5 来源于 Study01 实施过程中暴露出的认识缺口，但不是为了临时回答导师问题而设置。组会仍按 Study01 研究主线推进；Study1.5 只在解释“为什么使用统计特征、样本量信息是否丢失”时提供机制背景。

导师此前提出的问题不是 Study1.5 的研究目的。Study1.5 的独立价值在于系统说明输入表示与样本量如何共同影响当前 delta 风险曲线学习任务。
