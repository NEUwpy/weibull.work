# MDM 方法现有算法与无解问题说明

> 用途：为后续“MDM 方法理论修正 / 有解性证明 / 算法重构”提供当前口径说明。
> 本文只描述当前主线程序的计算逻辑和已暴露的问题，不把旧 S4.7 结论作为当前最终结论。
> 当前正式评价体系已切换为 S2R；旧 NE / NQE_R / RE_R / Outlier Rate 口径只作历史背景。

---

## 1. 方法定位

MDM（Minimum Discrepancy Method，最小差异法）用于三参数威布尔分布的参数估计。

三参数威布尔分布的累积分布函数为：

```text
F(t) = 1 - exp(-((t - gamma) / eta)^beta),  t > gamma
```

其中：

| 符号 | 含义 |
|------|------|
| beta | 形状参数 |
| eta | 尺度参数 |
| gamma | 位置参数 |
| t_i | 第 i 个失效时间样本 |
| F(t_i) | 第 i 个样本点对应的经验累积失效概率 |

MDM 的基本思想是：

```text
如果 beta 和 gamma 取值正确，那么每个样本点反推出的伪尺度参数 eta_i 应该尽量一致。
```

因此，MDM 不直接对三参数威布尔似然函数求极大，而是构造每个样本点对应的伪尺度参数，并让这些伪尺度参数之间的差异尽量小。

## 2. 基本计算公式

设样本排序后为：

```text
t_(1) <= t_(2) <= ... <= t_(n)
```

当前程序默认使用 Bernard 中位秩近似：

```text
F_i = (i - 0.3) / (n + 0.4)
```

并定义：

```text
x_i = -ln(1 - F_i)
```

对给定的 beta 和 gamma，每个样本点可以反推出一个伪尺度参数：

```text
eta_i(beta, gamma) = (t_i - gamma) / x_i^(1 / beta)
```

用伪尺度参数的样本标准差衡量差异：

```text
sigma_eta(beta, gamma)
  = std(eta_1, eta_2, ..., eta_n)
```

当前程序使用无偏样本标准差，即 `ddof=1`。

对固定 gamma，程序先求使 `sigma_eta` 最小的 beta：

```text
beta*(gamma)
  = argmin sigma_eta(beta, gamma),  beta in [0.1, 15.0]
```

得到一条关于 gamma 的条件最小差异曲线：

```text
sigma_min(gamma)
  = sigma_eta(beta*(gamma), gamma)
```

然后计算该曲线关于 gamma 的数值梯度：

```text
grad(gamma) = d sigma_min(gamma) / d gamma
```

MDM 当前主程序不是直接取 `sigma_min(gamma)` 的最小点，而是引入 offset 判据：

```text
grad(gamma) = delta
```

当前研究默认：

```text
delta = offset = 0.1
```

找到 gamma 后，再重新计算对应的 beta，并用所有伪尺度参数的均值作为 eta：

```text
eta_hat = mean(eta_i(beta_hat, gamma_hat))
```

## 3. 当前主程序的算法流程

当前主线 MDM 类位于：

```text
python/methods/mdm.py
```

核心入口为：

```python
MDM.run(trace=False, offset=None, gamma_steps=60, rank_method="bernard")
```

需要注意：

- `offset` 在程序中是必填参数；不传会抛出 `ValueError`。
- `gamma_steps=60` 是类方法默认值。
- S4.5 / S4.7 研究中实际使用的默认实验配置是 `offset=0.1, gamma_steps=20`。
- 默认中位秩方法是 `bernard`；也支持 `exact`，但当前主线实验默认用 `bernard`。

当前算法步骤如下。

### 3.1 数据预处理

程序通过 `WeibullBase` 做基础处理：

```text
1. 删除非正样本值；
2. 对样本升序排序；
3. 记录样本量 n。
```

因此当前 MDM 实现默认处理的是正的完全失效时间样本。

### 3.2 计算中位秩

默认使用 Bernard 公式：

```text
F_i = (i - 0.3) / (n + 0.4)
x_i = -ln(1 - F_i)
```

### 3.3 给定 gamma 时搜索 beta

对每一个 gamma 候选点，程序调用：

```python
scipy.optimize.minimize_scalar(..., bounds=(0.1, 15.0), method="bounded")
```

目标函数为：

```text
minimize sigma_eta(beta, gamma)
```

也就是说，beta 不是网格搜索，而是在 `[0.1, 15.0]` 上做一维有界连续优化。

### 3.4 第一轮 gamma 搜索

设：

```text
t_min = min(sample)
```

第一轮 gamma 候选范围为：

```text
gamma in [0, 0.99 * t_min]
```

程序使用等距网格：

```python
np.linspace(0, 0.99 * t_min, gamma_steps)
```

对每个 gamma 计算：

```text
beta*(gamma)
sigma_min(gamma)
```

然后用：

```python
np.gradient(sigma_mins, gammas)
```

计算 `sigma_min(gamma)` 的离散数值梯度。

### 3.5 offset 交点检测

程序定义：

```text
diff(gamma) = grad(gamma) - offset
```

然后检测相邻网格点之间是否存在符号变化：

```python
sign_changes = np.where(np.diff(np.sign(diffs)))[0]
```

如果存在符号变化，说明程序在离散网格上检测到：

```text
grad(gamma) = offset
```

的交点。

### 3.6 第二轮 gamma 搜索

如果第一轮没有交点，程序会在靠近 `t_min` 的区域再搜索一次：

```text
gamma in [0.99 * t_min, 0.999999 * t_min]
```

同样使用：

```python
np.linspace(0.99 * t_min, 0.999999 * t_min, gamma_steps)
```

第二轮只在第一轮无交点时执行。

执行后，程序把第一轮和第二轮结果拼接，再重新检测 `diff(gamma)` 的符号变化。

### 3.7 交点插值

如果最终存在交点，程序选择最后一个符号变化点，也就是最靠近 `t_min` 的交点。

假设交点位于两个网格点之间：

```text
(gamma_i, diff_i)
(gamma_(i+1), diff_(i+1))
```

程序使用线性插值：

```text
gamma_hat
  = gamma_i - diff_i * (gamma_(i+1) - gamma_i)
              / (diff_(i+1) - diff_i)
```

然后在该 `gamma_hat` 上重新优化 beta：

```text
beta_hat = beta*(gamma_hat)
```

最后计算：

```text
eta_hat = mean(eta_i(beta_hat, gamma_hat))
```

并返回：

```text
(beta_hat, eta_hat, gamma_hat, r_squared, True)
```

### 3.8 无交点返回

如果两轮搜索后仍然没有检测到 offset 交点，当前原始 MDM 类返回：

```text
(None, None, None, None, "no_intersection")
```

在统一 runner 中，这会被标准化为：

```text
converged = False
extra = {"raw_status": "no_intersection"}
```

## 4. 当前程序中的“无解”问题

当前程序所谓“无解”，准确说是：

```text
在当前 gamma 搜索范围、当前 gamma 离散网格、当前 offset 判据下，
没有检测到 grad(gamma) - offset 的符号变化。
```

这对应程序状态：

```text
no_intersection
```

它不应直接理解为：

```text
三参数威布尔估计问题数学上无解。
```

也不应直接理解为：

```text
样本无法给出任何合法的 beta_hat、eta_hat、gamma_hat。
```

因为即使没有 offset 交点，程序通常仍然已经计算出了一整条：

```text
gamma -> sigma_min(gamma)
gamma -> beta*(gamma)
```

曲线。只是严格 offset 交点法没有得到它要求的内点交点。

### 4.1 典型无交点情形

在当前诊断中，常见情形是：

```text
grad(gamma) 在所有采样点上都高于 offset
```

即：

```text
diff(gamma) = grad(gamma) - offset >= 0
```

这时严格交点法无法找到 `grad(gamma)=offset` 的交点，于是返回 `no_intersection`。

另一个理论上可能的情形是：

```text
grad(gamma) 在所有采样点上都低于 offset
```

即：

```text
diff(gamma) <= 0
```

此时也没有符号变化，严格交点法同样会返回 `no_intersection`。

### 4.2 该问题造成的影响

在原始严格算法中，无交点样本会被记为 failure。

这会影响：

- Valid Rate / Failure Rate；
- 后续 S2R 指标聚合；
- 方法横向比较；
- 默认 MDM 变体选择。

但这些样本不一定是数值异常样本。很多无交点样本仍可通过边界规则或最小 sigma 规则得到合法参数估计。

因此，后续理论修正需要明确：

```text
no_intersection 到底应该是方法失败，
还是 offset 判据下的边界解情形。
```

## 5. 当前已有 MDM 变体

当前研究变体位于：

```text
python/methods/mdm_variants.py
```

统一 runner 已支持通过 variant 名直接调用这些变体。

### 5.1 mdm_offset_strict

严格 offset 交点法。

逻辑：

```text
有 offset 交点 -> 使用交点解
无 offset 交点 -> 返回 (None, None, None)
```

这是原始 `MDM.run()` 的行为等价版本，用于诊断和对比。

### 5.2 mdm_offset_constrained

约束 offset 交点法。

逻辑：

```text
有 offset 交点 -> 使用交点解
无 offset 交点 -> 根据 diff 分布返回约束域内的替代解
```

当前程序中的无交点处理规则为：

| 情形 | 程序处理 | fallback_reason |
|------|----------|-----------------|
| `diff >= 0` 对所有采样点成立 | 取 gamma 最小端，通常为 `gamma=0` | `boundary_left` |
| `diff <= 0` 对所有采样点成立 | 取离散网格上 `sigma_min` 最小点 | `boundary_right` |
| 有正有负但没检测到符号变化 | 取最接近 offset 的点 | `closest_offset` |
| 找到交点 | 使用交点 | `root` |

该变体不会返回 `None`。

在 runner 中，如果成功返回参数，会被记为：

```text
converged = True
extra = {"fallback_reason": "..."}
```

注意：目前这个变体是工程研究变体。后续理论修正需要判断它是否应成为“理论修正后的默认 MDM”，还是只保留为对照。

### 5.3 mdm_min_sigma

最小 sigma 网格解。

逻辑：

```text
不使用 offset 判据；
直接在 gamma 网格上寻找 sigma_min(gamma) 最小的点。
```

当前搜索范围为：

```text
gamma in [0, 0.999999 * t_min]
```

使用：

```python
np.linspace(0, 0.999999 * t_min, gamma_steps)
```

这个变体返回的是离散网格上的最小 sigma 解，不是连续意义上严格证明的全局最小解。

`offset` 参数在该函数中只用于兼容统一调用接口。

### 5.4 mdm_allow_negative_gamma

允许负 gamma 的严格 offset 交点法，仅用于诊断。

当前下界用样本均值粗略给出：

```text
gamma_min = -mean(sample)
```

搜索范围扩展为：

```text
gamma in [-mean(sample), 0.999999 * t_min]
```

如果仍然没有 offset 交点，则返回 `None`。

该变体不是当前默认工程方法。

## 6. 当前研究默认配置

需要区分两个层级。

### 6.1 MDM 类方法默认值

`python/methods/mdm.py` 中：

```python
MDM.run(trace=False, offset=None, gamma_steps=60, rank_method="bernard")
```

含义：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| offset | `None` | 必须由调用方显式传入，否则报错 |
| gamma_steps | `60` | 每轮 gamma 搜索步数 |
| rank_method | `bernard` | 中位秩计算方式 |
| beta 搜索范围 | `[0.1, 15.0]` | 使用 `minimize_scalar` 连续优化 |
| gamma 搜索范围 | `[0, 0.999999 * t_min]` | 原始 MDM 分两轮搜索 |

### 6.2 S4.5 / S4.7 研究默认配置

当前 MDM 研究默认实验配置为：

```text
offset = 0.1
gamma_steps = 20
```

S4.7 修正版研究脚本位于：

```text
python/studies/s4_7_mdm_constrained_study.py
```

其参数空间为：

```text
beta in {1.5, 2.0, 3.0}
eta = 100
gamma / eta in {0.0, 0.10, 0.50, 1.00}
n in {7, 10, 30}
repeat_id = 0..99
```

注意：S4.7 旧结论是在 S2R 统一评价体系之前形成的。当前主线要求用 S2R 重新计算后，才能重新判断默认 MDM 变体。

## 7. 当前算法的关键待修正问题

后续理论文档最好明确回答以下问题，算法才能按理论重构。

### 7.1 MDM 的核心准则是什么

需要明确修正后的 MDM 到底是：

```text
1. 严格寻找 grad(gamma) = offset 的内点交点；
2. 寻找 sigma_min(gamma) 的最小点；
3. 寻找满足 KKT / 约束边界规则的解；
4. 还是 offset 交点 + 边界解的统一准则。
```

如果无交点时使用边界解，需要说明这不是临时 fallback，而是理论准则的一部分。

### 7.2 gamma 的合法范围

当前主程序默认：

```text
0 <= gamma < t_min
```

但诊断变体曾测试：

```text
gamma < 0
```

理论修正需要明确：

```text
gamma 是否允许为负？
gamma = 0 是否是合法边界解？
gamma 接近 t_min 是否应视为病态？
```

### 7.3 无交点样本如何定性

当前严格算法把无交点样本记为 failure。

理论修正需要明确：

```text
no_intersection 是方法失败，
还是约束优化中的边界解情形？
```

如果是边界解情形，应给出选择边界点的数学依据。

### 7.4 计算程序应输出哪些诊断字段

为了后续 S2R 重算和分层分析，建议修正后的 MDM 至少保留：

```text
solution_type      # root / boundary_left / boundary_right / closest_offset / failure
has_offset_root    # 是否存在 offset 交点
fallback_reason    # 如果不是 root，说明原因
gamma_search_min
gamma_search_max
gamma_steps
offset
grad_min
grad_max
sigma_min
sigma_min_gamma
```

这些字段可以帮助判断：

```text
算法到底是在用内点交点，还是在用边界解。
```

## 8. 与 S2R 重算的关系

当前项目已经废止旧 NE / NQE_R / RE_R / Outlier Rate 体系。

因此，MDM 理论修正和算法修改完成后，不能直接沿用旧 S4.7 表格做结论。

下一步应使用 S2R 重新计算 S4.7，至少比较：

```text
mdm_offset_strict
mdm_offset_constrained
mdm_min_sigma
必要时：理论修正后的新默认 MDM
MLE 参考方法
```

并按以下视角判断：

```text
参数视角：MdAPE / MedRel / RelIQR / P95(|e|) / P99(|e|)
分位点视角：R = {0.50, 0.90, 0.95, 0.99, 0.999}
可用性：Valid Rate / Failure Rate
分层：gamma/eta、n、beta
```

尤其要避免只用单个平均误差或旧综合指标判断默认变体。

---

## 9. 一句话总结

当前程序中的 MDM 无解问题，本质上是：

```text
严格 offset 交点搜索在约束区间和离散搜索网格上没有检测到 grad(gamma)=offset 的交点。
```

它不是三参数威布尔参数估计问题本身无解，也不一定意味着无法得到合法参数估计。

后续理论修正需要决定：

```text
无交点时应判为 failure，
还是应作为约束边界解纳入 MDM 的正式定义。
```

这个决定会直接影响默认 MDM 算法、runner 状态、S2R 重算结果和 S4.7 后续结论。
