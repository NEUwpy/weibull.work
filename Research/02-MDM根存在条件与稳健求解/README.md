# MDM 根存在条件与稳健求解

> 成熟度：`COMPLETE`
> 关系角色：`SUPPORTING`

## 研究问题

MDM 位置参数的“梯度等于偏置量”方程为什么会在合法区间内表现为无解？哪些情形是边界约束、网格漏检或真正不可达，怎样稳定求出可用估计？

## 已有答案

现有研究把无解现象拆分为位置下界切除无约束根、靠近最小观测处的网格漏检，以及极少量固有不可达情形；给出了固定形状参数下的结构分析和“一次探测、括弧/Brent 定根、必要时边界处理”的稳健流程。该流程已经支撑当前 MDM 实现。

这里的 `COMPLETE` 表示这个有界问题已有理论、数值与实现答案，不等于证明任意样本都存在合法内点根。工程流程“始终返回合法估计”包含明确的边界处理，不能改写成“方程始终有解”。
