# Weibull Analysis Platform

**威布尔参数估计方法的研究与实践平台**

围绕三参数威布尔估计，支持从方法选型、样本计算到结果验证，并以案例数据和学术文献提供依据。[线上站点](https://weibull.work)

## 主要功能

| 模块 | 用途 |
|------|------|
| [威布尔计算器](07-用户手册.md#威布尔计算器) | 输入或抽取样本，估计参数并对比拟合结果 |
| [参数估计方法](07-用户手册.md#参数估计方法) | 查阅原理、计算过程、程序流程、结果分析及可信性验证 |
| [人工智能方法](07-用户手册.md#人工智能方法) | 查看过程量优化、直接估计和自适应选择的产品入口 |
| [案例数据库](07-用户手册.md#案例数据库) | 查看实测样本、蒙特卡洛数据及估计结果，追溯数据来源 |
| [可靠性图书馆](07-用户手册.md#可靠性图书馆) | 检索文献，浏览论文集、原译文和文献问答 |

方法开放情况见[建设状态](05-状态.md)，软件进度见[目标与待办](04-目标与待办.md)，发布记录见[更新日志](08-更新日志.md)。

## 本机启动

Windows 可双击桌面 **Weibull调试**，或运行项目根目录的 `Weibull本地启动器.exe`。也可[手动启动前后端](03-维护.md#手动启动开发服务)。安装依赖、端口和日志位置见[本机调试说明](03-维护.md#windows-一键调试)。

本仓维护网站、API、共享算法、蒙特卡洛公共流程和产品资源。前端使用 Next.js 与 TypeScript，计算后端使用 Python 与 FastAPI。[系统架构](01-结构.md#1-系统架构) · [代码位置](01-结构.md#5-目录结构) · [部署与维护](03-维护.md)
