## 评价指标定义（D1 决策，2026-07-03）

### 主指标 J₁

$$J_1 = \sqrt{\frac{1}{R}\sum_{i=1}^{R}\left[\left(\frac{\hat\beta_i-\beta}{\beta}\right)^2 + \left(\frac{\hat\eta_i-\eta}{\eta}\right)^2 + \left(\frac{\hat\gamma_i-\gamma}{\eta}\right)^2\right]}$$

- R = 蒙特卡洛重复次数
- β/η/γ = 真值，β̂/η̂/γ̂ = 第 i 次重复的估计值
- γ 归一化除 η（尺度参数真值），不除 γ 自身
- 等权（w_β = w_η = w_γ = 1）
- 文献先例：182-050 / 182-097 的 Joint RMSE；J₁ 为相对误差变体

### 辅助指标（同时报告，不做排名）

- **每参数 Bias**：mean(θ̂) − θ
- **每参数 SD**：std(θ̂)
- **失败率**：收敛失败 / 总重复次数 → gate 条件，不参与排名

### 注意

- 旧文档中的 `J_param` = J₁ 的前身。正式实验统一使用 J₁ 命名。
- J₁ 是逐样本计算后开方的（not 先开方再平均）。

## 正式实验分组

### Formal E1：δ 扫描与 L1-L2 层级

目标：

- 回答 δ=0.1 是否为最优全局常数。
- 找到 L1（全局最优常数）。
- 评估 L2（按 n 查表）相比 L1 的收益。

比较：

- Default δ=0.1（基线）
- L1：全局最优常数 δ*
- L2：每个 n 的最优 δ*

候选 `delta` grid：

```text
0.00, 0.02, 0.04, ..., 0.50
```

最低输出：

- δ-risk 曲线（全局 + 分 n）
- L1 最优 δ* 值
- L1 vs Default 对比
- L2 按 n 的 δ* 查表
- L2 vs L1 边际收益

STOP 条件：

- 若 L1 最优 δ* 与 0.1 几乎相同（差异 <阈值），说明 0.1 已接近全局最优，但仍可继续看 L2+。
- 正式结果与 pilot 冲突时，以正式结果为准。

### Formal E2：L3-L6 Oracle 层级

目标：

- 在真参数已知的 oracle 条件下，计算 L3-L6 的精度上限。
- 找到边际递减点——从哪一级开始精度提升不再显著。

信息层级：

| 层级 | 决策粒度 | 性质 |
|------|---------|------|
| L3 | 按真 β | oracle |
| L4 | 按真 β+n | oracle |
| L5 | 按真 β,γ/η,n | oracle |
| L6 | 逐样本 | hindsight oracle |

最低输出：

- L3-L6 阶梯表（每级的精度 + 相比上一级的边际收益）
- 边际递减点标注
- L6 逐样本最优 δ 分布

> 注：L3-L6 在论文中作为精度上限（oracle），实际部署需要 NN（见 E3）。

### Formal E3：NN 样本→δ 映射

目标：

- L3 起 β 不可知，只能从样本特征学习映射。
- 验证 NN 能否从样本可观测特征预测接近 oracle 的 δ。

输入约束：

- 只能使用样本值和样本量 n 导出的可观测特征。
- 禁止输入真 β、真 η、真 γ、γ/η、配置 ID。

NN 目标：

- 建立"样本特征 → 最优 δ"的映射。
- 训练标签来自 oracle（L4 或 L5 层级的 δ*）。

最低输出：

- 多 seed 主结果（NN 预测 δ → MDM 精度）
- NN 精度 vs oracle 精度（L3-L5）的差距
- NN 精度 vs Default 0.1 和 L1 的提升
- 特征重要性 / 消融

主成功标准：

- 全样本有效。
- 多 seed 平均精度优于 Default δ=0.1。
- NN 精度合理逼近 oracle 层级。

### Formal E4：边界与稳健性

目标：

- 明确方法在哪些条件下有效，哪些条件下不应主张。

最低检查：

- cross beta
- cross n
- cross gamma/eta
- 极小样本或边界参数
- 失败样本处理
- 计算成本

> ~~旧 E5 的 x0.95 工程视角~~ → 暂不讨论，如后续需要可补。

写法原则：

- 边界结果进入 Discussion，不藏到附录。

## 参数网格草案

正式网格需要在计算预算确定后冻结。建议先分两层：

### 主网格

| 参数 | 候选 |
|------|------|
| `beta` | `{1.5, 2.0, 2.5, 4.0, 5.0}` |
| `eta` | `{1.0}` |
| `gamma/eta` | `{0.1, 0.5, 1.0}` |
| `n` | `{7, 10, 20}` |
| repeats | 至少 `500`，正式主表建议 `1000` 或按预算确定 |

### 稳健性网格

| 参数 | 候选 |
|------|------|
| `n` | 加入 `{5, 50}` |
| `beta` | 可加入边界点 `{1.2, 6.0}` |
| `gamma/eta` | 可加入 `{0.0}` 或更接近边界的值 |

## STOP 条件

1. 发现正式脚本使用了旧 CSV 作为结果来源，停止。
2. 发现 NN 输入包含真参数或配置 ID，停止。
3. 发现层级聚合直接平均已开方 `J₁`，停止。
4. 发现 MDM 语义与 `python/methods/mdm.py` 不一致，停止。
5. 发现主结果只有单 seed 且波动未知，不能写“稳定优于”。
6. 正式实验推翻 pilot 结论时，修改论文主张，不修饰结果。
