# 02 实验协议

> 创建日期：2026-07-02  
> 修订口径：本文正式实验重新设计、重新写代码、重新验证。旧 `docs/research` 结果只作为 pilot，不进入正文主证据。

## 总原则

1. 正式实验产物必须由 `Study/01-study-MDM最小偏移量优化研究/code/` 下的新脚本生成。
2. 新脚本可以调用平台生产方法和共享研究工具，但不能直接把旧 `docs/research/04.../程序` 当作正式入口。
3. 每个正式实验必须输出 `manifest.json`、`results.csv`、`summary.json`。
4. 每个主张都必须能追溯到正式实验编号、脚本、配置、seed、数据和图表。
5. 若正式结果与 pilot 结果冲突，以正式结果为准，并修改论文主张。

## 正式实验分组

### Formal E1：MDM 基线表现

目标：

- 回答 MDM 在小样本和不同参数组合下表现如何。
- 给后续 `delta` 优化提供 baseline。

比较方法：

- MDM，默认 `delta=0.1`
- MLE
- LSE 或研究用 LSE 对照
- 可选：PWM / MM / Bayesian 等当前平台可稳定调用的方法

最低输出：

- 失败率 / 有效率
- `Bias/SD/RMSE` for `beta, eta, gamma`
- `J_param`
- `RMSE_x95`
- 按 `beta/n/gamma_eta` 分组汇总

STOP 条件：

- 若某比较方法失败率极高，必须单独报告，不可只报 valid-only。
- 若 LSE 是研究脚本而非平台生产方法，必须在论文中说明。

### Formal E2：`delta` 扫描与信息层级

目标：

- 回答 `delta` 是否影响精度。
- 正式重算 `Default/L0/L1/L2/L3/L4/L5`。
- 检验 `delta=0.1` 是否仍是强全局基线。

候选 `delta` grid：

```text
0.00, 0.02, 0.04, ..., 0.50
```

信息层级：

| 层级 | 信息 | 部署性质 |
|------|------|----------|
| Default | 固定 `delta=0.1` | 可部署 |
| L0 | 全训练集共用一个 `delta*` | 可部署或近可部署 |
| L1 | 按 `n` | 可部署 |
| L2 | 按真 `beta` | oracle |
| L3 | 按真 `beta,n` | oracle |
| L4 | 按真 `beta,n,gamma/eta` | oracle / 训练标签来源 |
| L5 | 逐样本事后最优 | hindsight oracle |

最低输出：

- 每个配置的 `delta-risk` 曲线
- L0-L5 阶梯表
- 边际收益
- `delta*` 驱动因素分析
- L5 逐样本分布

聚合合同：

```text
loss_i(delta) =
  ((beta_hat_i(delta) - beta_i) / beta_i)^2
  + ((eta_hat_i(delta) - eta_i) / eta_i)^2
  + ((gamma_hat_i(delta) - gamma_i) / eta_i)^2

J_param = sqrt(mean_i loss_i(delta))
```

层级聚合必须先聚合 `mean_loss`，最后只开方一次。

### Formal E3：可部署显式规则

目标：

- 检验不使用神经网络时是否能稳定选出更优 `delta`。

候选策略：

- Default `delta=0.1`
- L0 全局最优
- L1 按 `n`
- 自迭代 MDM
- 外部 `beta` 预估 + 查表
- 双 `delta` / 多 `delta` 试探 + 查表
- fallback 规则

最低输出：

- 全样本性能
- valid-only 性能
- 有效率
- fallback 后性能
- 计算成本
- 按配置改善/恶化热力图

STOP 条件：

- valid-only 优于 Default 但有效率低，不能写成可部署改进。
- 若 fallback 后收益小于 2%，该策略降级为负结果。

### Formal E4：样本特征驱动策略

目标：

- 检验样本可观测特征是否能学习更优偏移量选择。

输入约束：

- 只能使用样本值和样本量 `n` 导出的可观测特征。
- 禁止输入真 `beta`、真 `eta`、真 `gamma`、`gamma/eta`、配置 ID。

标签路线：

- L4 hard label
- L5 hard label
- risk curve label

最低输出：

- 多 seed 主结果
- 同分布 split
- blocked split
- 标签消融
- 特征消融
- 架构消融
- 推理成本

主成功标准：

- 全样本有效。
- 多 seed 平均 `J_param` 优于 Default。
- risk curve 优于或至少不弱于 hard label。
- 不存在真值泄漏。

### Formal E5：边界与稳健性

目标：

- 明确方法在哪些条件下有效，哪些条件下不应主张。

最低检查：

- cross beta
- cross n
- cross gamma/eta
- `RMSE_x95`
- 极小样本或边界参数
- 失败样本处理
- 计算成本

写法原则：

- 边界结果进入 Discussion，不藏到附录。
- 若 `x0.95` 收益小，主文明确说明参数风险收益不等于工程寿命收益。

## 参数网格草案

正式网格需要在计算预算确定后冻结。建议先分两层：

### 主网格

| 参数 | 候选 |
|------|------|
| `beta` | `{1.5, 2.0, 2.5, 4.0, 5.0}` |
| `eta` | `{1.0}` |
| `gamma/eta` | `{0.1, 0.5, 1.0}` |
| `n` | `{7, 10, 20}` |
| repeats | 至少 `500`，正式主表建议 `1000` 或按预算确定 |

### 稳健性网格

| 参数 | 候选 |
|------|------|
| `n` | 加入 `{5, 50}` |
| `beta` | 可加入边界点 `{1.2, 6.0}` |
| `gamma/eta` | 可加入 `{0.0}` 或更接近边界的值 |

## STOP 条件

1. 发现正式脚本使用了旧 CSV 作为结果来源，停止。
2. 发现 NN 输入包含真参数或配置 ID，停止。
3. 发现层级聚合直接平均已开方 `J_param`，停止。
4. 发现 MDM 语义与 `python/methods/mdm.py` 不一致，停止。
5. 发现主结果只有单 seed 且波动未知，不能写“稳定优于”。
6. 正式实验推翻 pilot 结论时，修改论文主张，不修饰结果。
