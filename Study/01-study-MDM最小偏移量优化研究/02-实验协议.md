## 评价指标定义（D1 决策，2026-07-03）

### 主指标 J₁

$$J_1 = \sqrt{\frac{1}{R}\sum_{i=1}^{R}\left[\left(\frac{\hat\beta_i-\beta}{\beta}\right)^2 + \left(\frac{\hat\eta_i-\eta}{\eta}\right)^2 + \left(\frac{\hat\gamma_i-\gamma}{\eta}\right)^2\right]}$$

- R = 蒙特卡洛重复次数
- β/η/γ = 真值，β̂/η̂/γ̂ = 第 i 次重复的估计值
- γ 归一化除 η（尺度参数真值），不除 γ 自身
- 等权（w_β = w_η = w_γ = 1）
- 文献先例：182-050 / 182-097 的 Joint RMSE；J₁ 为相对误差变体

### 辅助指标（同时报告，不做排名）

- **每参数 Bias**：mean(θ̂) − θ
- **每参数 SD**：std(θ̂)
- **失败率**：收敛失败 / 总重复次数 → gate 条件，不参与排名

### 注意

- 旧文档中的 `J_param` = J₁ 的前身。正式实验统一使用 J₁ 命名。
- J₁ 是逐样本计算后开方的（not 先开方再平均）。

## 实验编号与层级映射（D4 决策，2026-07-04）

| 实验 | 层级 | 性质 | 核心问题 | 对应章节 |
|------|------|------|----------|----------|
| **E1** | Default + L1 + L2 | 可部署 | δ=0.1 是否最优全局常数？L1/L2 收益多少？ | Ch4 |
| **E2** | L3 + L4 + L5 + L6 | oracle / hindsight | 参照精度在哪？边际递减点在哪一级？ | Ch5 |
| **E3** | 样本自适应 δ 选择（NN 为候选实现） | 可部署 | 真参数不可见时，仅凭样本值和 n 能逼近 oracle 到什么程度？ | Ch6 |
| **E4** | 跨参数稳健性 | 验证 | 边界条件是否成立？ | Ch7 |

设计原则：
- **E1/E2 共用同一批 MC 扫描数据**：共用数据生成脚本，独立分析脚本按不同粒度聚合。保证 L1-L6 在同一份数据上可比，且省一半计算量。
- **Default δ=0.1 是所有实验的共用基线**，每个实验报告时均带 Default 列对比。
- **E2 已完成；样本自适应训练标签（L4 还是 L5）仍需在 E3 启动前根据精度-成本权衡确认**，不以 L6 作为主要训练目标。
- **所有主结果必须报告 pooled 结果和按 n 分层结果**，因为 n 既是 L2 的可部署查表变量，也是小样本估计的关键审稿视角。

## 正式实验分组

### Formal E1：δ 扫描与 L1-L2 层级

目标：

- 回答 δ=0.1 是否为最优全局常数。
- 找到 L1（全局最优常数）。
- 评估 L2（按 n 查表）相比 L1 的收益。

比较：

- Default δ=0.1（基线）
- L1：全局最优常数 δ*
- L2：每个 n 的最优 δ*

候选 `delta` grid：

```text
0.00, 0.02, 0.04, ..., 0.50
```

最低输出：

- δ-risk 曲线（全局 + 分 n）
- L1 最优 δ* 值
- L1 vs Default 对比
- L2 按 n 的 δ* 查表
- L2 vs L1 边际收益

STOP 条件：

- 若 L1 最优 δ* 与 0.1 几乎相同（差异 <阈值），说明 0.1 已接近全局最优，但仍可继续看 L2+。
- 正式结果与 pilot 冲突时，以正式结果为准。

### Formal E2：L3-L6 Oracle 层级

目标：

- 在真参数已知的 oracle 条件下，计算 L3-L5 的参照精度，并给出 L6 的扫描网格内 hindsight benchmark。
- 找到边际递减点——从哪一级开始精度提升不再显著。

**数据来源**：与 E1 同一批 MC 扫描（共用数据生成脚本），本实验为独立分析脚本，按不同聚合粒度提取各层级最优 δ。

信息层级：

| 层级 | 决策粒度 | 性质 |
|------|---------|------|
| L3 | 按真 β | oracle |
| L4 | 按真 β+n | oracle |
| L5 | 按真 β,γ/η,n | oracle |
| L6 | 逐样本 | hindsight benchmark |

最低输出：

- L3-L6 阶梯表（每级的精度 + 相比上一级的边际收益）
- 边际递减点标注
- L6 逐样本最优 δ 分布

> 注：L3-L5 在论文中作为 oracle 参照；L6 是扫描网格内逐样本 hindsight benchmark。实际部署若要逼近这些层级，需要样本自适应 δ 选择方法（见 E3）。

### Formal E3：样本自适应 δ 选择

目标：

- L3 起需要真参数信息，不能直接部署。
- 验证能否仅凭样本值和样本量 n 导出的可观测特征，预测接近 oracle 参照的 δ。
- NN 是候选实现，不是必须成立的论文目的；若收益不足，应保留负结果并回到 L1/L2 实践推荐。

输入约束：

- 只能使用样本值和样本量 n 导出的可观测特征。
- 禁止输入真 β、真 η、真 γ、γ/η、配置 ID。

样本自适应目标：

- 建立"样本特征 → 最优 δ"的映射。
- 训练标签来自 oracle 层级的 δ*。**具体选 L4 还是 L5 作为标签，E2 已提供对比依据，但需在 E3 启动前正式冻结**（L4 和 L5 的精度差异是标签选择的关键依据）。

最低输出：

- 多 seed 主结果（预测 δ → MDM 精度）
- 自适应方法精度 vs oracle 精度（L3-L5）的差距
- 自适应方法精度 vs Default 0.1、L1 和 L2 的提升
- 按 n 分层的精度、失败率和 δ 分布
- 特征重要性 / 消融

主成功标准：

- 全样本有效。
- 多 seed 平均精度优于 Default δ=0.1，并与 L1/L2 比较。
- pooled 结果和按 n 分层结果方向一致，或明确说明在哪些 n 条件下不成立。
- 自适应方法精度合理逼近 oracle 层级。

### Formal E4：边界与稳健性

目标：

- 明确方法在哪些条件下有效，哪些条件下不应主张。

最低检查：

- cross beta
- cross n
- cross gamma/eta
- 极小样本或边界参数
- 失败样本处理
- 计算成本

## 对比方法（D5 决策，2026-07-04）

论文只放 **标准 MLE** 作为参照系锚点：

- **定位**：MLE 不作为论文主线，仅作为精度参照锚点，让读者判断 MDM 优化后的绝对水平。
- **出现位置**：Table 3（L1-L6 阶梯表）和 Table 4（样本自适应主结果）各加一列 MLE 精度。
- **不单独开章节**，不做 MDM vs MLE vs LSE 的方法横评。
- **实现**：标准 maximum likelihood，γ < x_(1) 约束，不引入修正版（MMLE 等）。
- **同一协议**：MLE 用与 MDM 相同的参数网格、同一 MC seed 协议跑，报告失败率。
- **预期表现**：主网格 β∈{1.5, 2.0} 处于 MLE 不稳定区间，MLE 失败率/bias 会较高——这恰好展示 MDM 的优势（MDM 原文卖点之一），无需额外辩护。

## 参数网格（E1/E2 已冻结并执行）

主网格已冻结并用于 Formal E1/E2；稳健性网格用于 E4 启动前再确认。

### 主网格

| 参数 | 候选 |
|------|------|
| `beta` | `{1.5, 2.0, 2.5, 4.0, 5.0}` |
| `eta` | `{1.0}` |
| `gamma/eta` | `{0.1, 0.5, 1.0}` |
| `n` | `{7, 10, 20}` |
| repeats | **E1/E2 主网格 R=1000**（D6 决策，2026-07-04） |

**计算量**：参数组合 45（β5 × η1 × γ/η3 × n3）× δ grid 26 × R1000 = 117 万次 MDM 估计。MLE 锚点 4.5 万次。E1/E2 已按该规模执行；如扩展网格需重新评估计算预算。

### 稳健性网格

| 参数 | 候选 |
|------|------|
| `n` | 加入 `{5, 50}` |
| `beta` | 可加入边界点 `{1.2, 6.0}` |
| `gamma/eta` | 可加入 `{0.0}` 或更接近边界的值 |
| repeats | **E4 稳健性网格 R=500**（D6 决策，趋势够用） |

### E3 样本自适应训练数据

E3 训练数据独立生成，不跟 E1/E2 共用 R。需要覆盖连续参数空间（而非 E1/E2 的离散网格），具体数据量由样本自适应方法设计决定，待 E3 设计时冻结。

## STOP 条件

1. 发现正式脚本使用了旧 CSV 作为结果来源，停止。
2. 发现 NN 输入包含真参数或配置 ID，停止。
3. 发现层级聚合直接平均已开方 `J₁`，停止。
4. 发现 MDM 语义与 `python/methods/mdm.py` 不一致，停止。
5. 发现主结果只有单 seed 且波动未知，不能写“稳定优于”。
6. 正式实验推翻 pilot 结论时，修改论文主张，不修饰结果。
