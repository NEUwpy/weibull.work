## 评价指标定义（D1 决策，2026-07-03）

### 主指标 J₁

$$\ell_i(\delta)=\left(\frac{\hat\beta_i(\delta)-\beta}{\beta}\right)^2+\left(\frac{\hat\eta_i(\delta)-\eta}{\eta}\right)^2+\left(\frac{\hat\gamma_i(\delta)-\gamma}{\eta}\right)^2$$

$$J_1(\{\hat\delta_i\})=\sqrt{\frac{1}{R}\sum_{i=1}^{R}\ell_i(\hat\delta_i)}$$

- R = 蒙特卡洛重复次数
- β/η/γ = 真值，β̂/η̂/γ̂ = 第 i 次重复的估计值
- γ 归一化除 η（尺度参数真值），不除 γ 自身
- 等权（w_β = w_η = w_γ = 1）
- 文献先例：182-050 / 182-097 的 Joint RMSE；J₁ 为相对误差变体

### 辅助指标（同时报告，不做排名）

- **每参数 Bias**：mean(θ̂) − θ
- **每参数 SD**：std(θ̂)
- **失败率**：收敛失败 / 总重复次数 → gate 条件，不参与排名

### 注意

- 旧文档中的 `J_param` = J₁ 的前身。正式实验统一使用 J₁ 命名。
- $\ell_i(\delta)$ 是逐样本未开方损失；J₁ 是先对已选偏移量下的 $\ell_i$ 取平均，再统一开方。不先对单样本开方后再平均。
- L1–L5 在各自分组 $G_L(g)$ 内最小化 $R_L(g,\delta)=\sqrt{|G_L(g)|^{-1}\sum_{i\in G_L(g)}\ell_i(\delta)}$；L6 逐样本最小化 $\ell_i(\delta)$。J₁ 是选择规则产生后的最终汇总评价，不是单样本损失的名称。
- 每个正式 $(\beta,\gamma/\eta,n)$ 组合使用相同的 $R=1000$，因而 pooled 风险对 45 个设计格点等权。L1 的“全局最优”仅指这一 formal design-grid measure 下的最优常数，不代表真实应用参数分布下的普遍最优。
- 正式网格固定 $\eta=1$ 依据 MDM 尺度等变性：寿命数据及 $(\eta,\gamma)$ 同比例缩放时，$\hat\beta$ 和 δ 判据不变，$(\hat\eta,\hat\gamma)$ 同比例缩放，归一化损失不变。公式推导见 Ch2，数值回归合同见 `python/tests/test_mdm_s49.py` 中 $c=1000$、$\delta\in\{0,0.1,0.5\}$ 的尺度测试。

## 实验编号与层级映射（D4 决策，2026-07-04）

| 实验 | 层级 | 性质 | 核心问题 | 对应章节 |
|------|------|------|----------|----------|
| **E1** | Default + L1 + L2 | 可部署 | δ=0.1 是否最优全局常数？L1/L2 收益多少？ | Ch4 |
| **E2** | L3 + L4 + L5 + L6 | oracle / hindsight | 参照精度在哪？边际递减点在哪一级？ | Ch5 |
| **E3** | 样本自适应 δ 选择（NN/Vector-MLP 为当前主要求解器） | 可部署 | 真参数不可见时，仅凭样本值和 n 能逼近 oracle / hindsight 参照阶梯中的可学习部分到什么程度？ | Ch6 |

设计原则：
- **E1/E2 共用同一批 MC 扫描数据**：共用数据生成脚本，独立分析脚本按不同粒度聚合。保证 L1-L6 在同一份数据上可比，且省一半计算量。
- **Default δ=0.1 是所有实验的共用基线**，每个实验报告时均带 Default 列对比。
- **E3 已按 existing-grid 路线形成 E3a/E3b 两级证据**：E3a 是轻量 risk-curve pilot，E3b 是严格离散组合 holdout follow-up；二者回答当前正式离散网格内的样本自适应可达性，不自动外推为连续空间泛化结论。
- **所有主结果必须报告 pooled 结果和按 n 分层结果**，因为 n 既是 L2 的可部署查表变量，也是小样本估计的关键审稿视角。

## 正式实验分组

### Formal E1：δ 扫描与 L1-L2 层级

目标：

- 回答 δ=0.1 是否接近正式设计网格等权 pooled 口径下的最优常数。
- 找到 L1（formal design-grid pooled optimum）。
- 评估 L2（按 n 查表）相比 L1 的收益。

比较：

- Default δ=0.1（基线）
- L1：正式设计网格等权 pooled 最优常数 δ*
- L2：每个 n 的最优 δ*

候选 `delta` grid：

```text
0.00, 0.02, 0.04, ..., 0.50
```

网格边界口径：$δ=0$ 是有方法含义的“无偏移”候选；$δ=0.50$ 是人为设定的当前扫描上界。所有网格边缘诊断必须分开报告 exact $P(δ=0)$、exact $P(δ=0.50)$ 和预先定义的 near-boundary/extreme rate；不得用一个合并比例替代两个端点的不同含义。

最低输出：

- δ-risk 曲线（全局 + 分 n）
- L1 最优 δ* 值
- L1 vs Default 对比
- L2 按 n 的 δ* 查表
- L2 vs L1 边际收益

STOP 条件：

- 若 L1 最优 δ* 与 0.1 几乎相同（差异 <阈值），说明 0.1 已接近正式设计网格等权 pooled 最优，但仍可继续看 L2+；不外推到未加权检验的真实参数分布。
- 正式结果与 pilot 冲突时，以正式结果为准。

### Formal E2：L3-L6 Oracle 层级

目标：

- 在真参数已知的 oracle 条件下，计算 L3-L5 的参照精度，并给出 L6 的扫描网格内 hindsight benchmark。
- 找到边际递减点——从哪一级开始精度提升不再显著。

**数据来源**：与 E1 同一批 MC 扫描（共用数据生成脚本），本实验为独立分析脚本，按不同聚合粒度提取各层级最优 δ。

信息层级：

| 层级 | 决策粒度 | 性质 |
|------|---------|------|
| L3 | 按真 β | oracle |
| L4 | 按真 β+n | oracle |
| L5 | 按真 β,γ/η,n | oracle |
| L6 | 逐样本 | hindsight benchmark |

最低输出：

- L3-L6 阶梯表（每级的精度 + 相比上一级的边际收益）
- 边际递减点标注
- L6 逐样本最优 δ 分布
- L6 网格边界拆分：pooled $P(δ^*=0)=0.4746$、$P(δ^*=0.50)=0.0657$，并按 $n$ 报告上端点率（4.24% / 5.85% / 9.63%）。当前只将 L6 称为 existing-grid hindsight benchmark，不将 0.50 写为已证明充分的搜索上界。

> 注：L3-L5 在论文中作为 oracle 参照；L6 是扫描网格内逐样本 hindsight benchmark。实际部署若要逼近这些层级，需要样本自适应 δ 选择方法（见 E3）。

### Formal E1/E2 cross-fit 敏感性验证

目标：检查 L1–L5 在同一批 $R=1000$ 重复中同时选择 $δ^*$ 和报告 $J_1$ 所可能引入的网格择优乐观偏差。

协议：

- 复用 `artifacts/formal/shared_data/mc_scan_raw.csv`，不重跑 MDM。
- 固定 5 折规则 `fold = repeat_id mod 5`。每折用 800 个 repeat id 选择 L1–L5 的组级 $δ^*$，用未参与选点的 200 个 repeat id 评价，再汇总 5 个留出折。
- Default $δ=0.1$ 无需选点，作为共同基线。
- L6 是逐样本 hindsight benchmark，明确排除在 cross-fit 可部署层级之外；不将 L6 包装成留出规则。
- 原 E1/E2 产物保留为全缓存经验风险和网格 argmin 描述；cross-fit 作为选点/评价分离的敏感性证据。

产物：`artifacts/formal/E1_E2_crossfit/`；代码：`code/analyze_E1_E2_crossfit.py`；契约测试：`python/tests/test_study01_e1_e2_crossfit.py`。

结果：L1 和 L3 的 cross-fit J₁ 与全缓存值一致；L2/L4/L5 分别从 0.632541 / 0.582090 / 0.571170 调整为 0.632732 / 0.582585 / 0.571924，相对变化仅 +0.030% / +0.085% / +0.132%。L2→L3→L4→L5 阶梯结构保持。

### Formal E3：样本自适应 δ 选择

目标：

- L3 起需要真参数信息，不能直接部署。
- 验证能否仅凭样本值和样本量 n 导出的可观测特征，预测接近 oracle 参照的 δ。
- NN/Vector-MLP 是当前 Formal E3 的主要求解方法，但不是论文目的本身；若该类样本自适应方法收益不足，应保留负结果并回到 L1/L2 实践推荐。

输入约束：

- 只能使用样本值和样本量 n 导出的可观测特征。
- 禁止输入真 β、真 η、真 γ、γ/η、配置 ID。

样本自适应目标：

- 建立"样本特征 → δ 风险曲线 → δ 选择"的映射。
- E3a 采用 scalar risk-curve 形式：输入 `sample_features + candidate delta`，输出候选 δ 的单样本未开方损失 $\ell_i(\delta)$（raw loss）。
- E3b 采用 vector-output MLP：输入样本可观测特征，一次性输出 26 维 loss curve，再用 `argmin_delta` 选择 δ；不把 candidate `delta` 放进 vector 模型输入。
- 当前保留 L4/L5/L6 监督粒度比较，其中 `Vector-MLP-L6` 是 Ch6 existing-grid 主证据。L6 在这里是 sample-level hindsight target test / 监督粒度压力测试，不是部署目标或理论上限。

最低输出：

- 多 seed 主结果（预测 δ → MDM 精度）
- 自适应方法精度 vs oracle / hindsight 参照（L3-L6）的差距
- 自适应方法精度 vs Default 0.1、L1 和 L2 的提升
- 按 n 分层的精度、失败率和 δ 分布

主成功标准：

- 全样本有效。
- 多 seed 平均精度优于 Default δ=0.1，并与 L1/L2 比较。
- pooled 结果和按 n 分层结果方向一致，或明确说明在哪些 n 条件下不成立。
- 自适应方法精度合理逼近 oracle 层级。

### 真实场景重复小样本留出验证（实验编号与章节位置待确认）

状态：已确认纳入全文规划；数据集、重复次数和最终章节位置待冻结。

目标：

- 在没有已知真参数的真实寿命数据上，检验 Default、L2 与 NN 自适应 offset 规则能否从小样本得到对未参与估计数据更有解释力的三参数 Weibull 分布。

基本设计：

- 优先选择包含较多完整寿命观测的公开数据集或既有论文原始数据。
- 先检查三参数 Weibull 假设是否基本合理，再决定数据能否进入正式比较。
- 重复抽取 `n=7/10/20` 小样本；Default、L2 与 NN 必须使用同一批小样本，形成配对比较。
- 每次抽样只用小样本估计参数；未进入该次小样本的剩余寿命数据作为留出评价集。

主指标：留出经验 CDF 距离

\[
D_{\mathrm{CDF}}
=
\frac{1}{m}
\sum_{i=1}^{m}
\left[
\hat F(x_{(i)})-\frac{i-0.5}{m}
\right]^2,
\]

其中 `m` 是留出样本量，`x_(i)` 是留出寿命的次序统计量，`F_hat` 是由该次小样本估计得到的三参数 Weibull CDF。指标越小，表示小样本估计分布越接近未参与估计的真实寿命经验分布。

辅助指标：

- 支撑集违规率：`gamma_hat >= min(留出样本)`。
- B10/B50 等寿命分位数与留出经验分位数的差异。
- 与完整样本拟合参数的距离，仅作辅助参照。
- 重复抽样分布的中位数、四分位距和相对 Default/L2 的配对胜率。

写法原则：

- 完整样本或剩余大样本只提供经验参照，不称为真参数。
- 不只展示单次有利抽样；正式判断必须来自预先冻结的重复抽样合同。
- 不以 valid-only 结果替代全样本结论；支撑集违规和算法失败必须计入总体报告。
- 留出负对数似然可作补充，但不作为唯一主指标，避免位置参数越过留出最小值时的无穷惩罚支配全部比较。

## 对比方法（D5 决策，2026-07-04）

论文只放 **标准 MLE** 作为参照系锚点：

- **定位**：MLE 不作为论文主线，仅作为精度参照锚点，让读者判断 MDM 优化后的绝对水平。
- **出现位置**：Table 4（L1-L6 阶梯表）和 Table 5（样本自适应主结果，Ch6 初稿已写；出版表格待冻结）各保留 MLE 精度锚点。
- **不单独开章节**，不做 MDM vs MLE vs LSE 的方法横评。
- **实现**：标准 maximum likelihood，γ < x_(1) 约束，不引入修正版（MMLE 等）。
- **同一协议**：MLE 用与 MDM 相同的参数网格、同一 MC seed 协议跑，报告失败率。
- **预期表现**：主网格 β∈{1.5, 2.0} 处于 MLE 不稳定区间，MLE 失败率/bias 会较高——这恰好展示 MDM 的优势（MDM 原文卖点之一），无需额外辩护。
