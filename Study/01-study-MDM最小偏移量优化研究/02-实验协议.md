## 1. 目标

在不改变既有 MDM 偏移量主线的前提下，用最少必要实验支撑论文主张：

1. 核心结果：E1/E2 潜在空间证据 + 新设计域样本自适应方法（Dimensional-RAW-MLP：排序原始样本 → 分 n MLP → 26 点损失曲线 → 偏移量选择 → MDM）；L1–L6 在新 160 组合设计上统一以既有正式 cross-fit 定义重算；
2. 支撑验证：泛化、seed 稳定性与输入表示尺度性质、与传统方法的参照、工程寿命分位点；

## 2. 统一定义

### 2.1 参数损失与主指标

对第 `i` 个样本：

$$
\ell_i=
\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2+
\left(\frac{\hat\gamma_i-\gamma_i}{\eta_i}\right)^2.
$$

主指标：

$$
J_1=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\ell_i}.
$$

J1 是统一评价准则，不是方法创新。失败惩罚必须在正式运行前由合同冻结，所有方法使用相同规则。

### 2.2 参数诊断

- 每参数相对 Bias、RMSE、MAE；
- 单样本 `ell_i` 的中位数、IQR、P90、P95、P99；
- 收敛失败率、非法参数率和支撑集违规率。

### 2.3 稳定性

- **抽样稳定性**：同一方法在 Monte Carlo 重复上的误差分布、尾部和失败；
- **训练稳定性**：学习方法在 5 folds × 3 seeds 上的模型级指标分布。

禁止把 15 个模型对同一样本的预测当作 15 个独立样本。先计算每个模型的完整评价，再汇总模型间分布。

### 2.4 工程寿命分位点

$$
x_R=\gamma+\eta[-\ln(R)]^{1/\beta}
$$

- 主指标：`x_0.95`；
- 补充：`x_0.90`、`x_0.99`；
- 已删除原规划中的 `x_0.50`；
- 由 P4 已有逐样本三参数估计直接派生，不重跑估计器、不反向调参；
- 不训练直接分位点网络。

### 2.5 真实数据指标（如后置执行）

真实数据没有已知真参数，不计算 J1。主指标使用已冻结的单样本双侧 KS 距离，并补充：

- 留出经验分位点差；
- 配对胜率、负率和平率；
- 支撑集违规率和失败率；
- 完整样本参数距离，仅作经验参照。

## 3. 主设计域与统一样本

样本自适应方法的正式设计（冻结）为：

| 参数 | 取值 |
|---|---|
| `beta` | `{1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0}` |
| `eta` | `{1000}` |
| `gamma/eta` | `{0.10, 0.25, 0.50, 0.75, 1.00}` |
| `n` | `{7, 10, 15, 20}` |
| repeats | 每组合 300 |

正式设计共 160 个参数—样本量组合、48,000 个样本和 1,248,000 次候选偏移量估计；必须包含 `(beta, eta, gamma) = (2, 1000, 1000)`。尺度参数 `eta=1000` 是本研究的代表性工程尺度（MDM 本身在同比例缩放下尺度等变，`eta` 不由偏移量判据的绝对阈值属性决定）。学习方法使用每个 `n` 内冻结的 full-combo 五折划分和 seeds `42/2026/3407`；每个 `n` 训练独立网络，并在全开发集上训练固定种子的部署模型。有量纲排序原始样本输入不具备单位不变性，结论限于训练单位与尺度范围。

## 4. 核心实验口径

### 4.1 E1：固定全局偏移量

- 内容：Default（`delta=0.1`）、L1（全局最优常数）、L2（按 n 查表）；
- 产物：`artifacts/formal/E1_baseline/`（已封存）；
- 回答：`delta=0.1` 是否已接近最佳统一常数，L1/L2 能否带来收益。

### 4.2 E2：信息层级

- 内容：L3–L6 oracle/hindsight 层级；
- 产物：`artifacts/formal/E2_oracle_layers/`（已封存）；
- 回答：从 L3 到 L6 增加真参数信息的收益，边际递减点；
- 边界：L3–L5 只能称为 oracle 参照，L6 只能称为固定候选网格内的 hindsight 参照。

### 4.3 样本自适应选择（最终方法）

- 内容：每个样本量 `n` 训练独立 MLP，输入为排序的原始样本 $X_n=\operatorname{sort}(x_1,\ldots,x_n)$（有量纲，不除以样本均值），预测 26 维损失曲线，`argmin` 选择偏移量，最终三参数仍由 MDM 估计；
- 产物：`artifacts/formal/E6_dimensional_raw/specialist/`（训练与评价）；复用数据 `artifacts/formal/E5_normalized_raw/shared_data/`（160 组合新设计，不重跑/不复制）；
- 输入标准化：每位置 StandardScaler 仅由该样本量训练折拟合，测试折不参与；
- 边界：输入仅排序原始样本 $X_n$，不含手工统计特征、真参数、组合 ID、repeat ID、显式 `n` 或测试标签；不使用 padding/mask/跨 n 联合网络；有量纲输入不具备单位不变性，结论限于与训练一致的物理单位及尺度范围；
- 参照：同测试样本上的 Default、L6 hindsight 与候选对照 Normalized-RAW（已标记为未采用，不进入论文主证据）。

## 5. 支撑验证口径

### 5.1 泛化分轴

新增分析必须按以下互斥或明确重叠的标签报告，不以混合 off-grid 总数代替：

1. **参数插值**：`beta` 与 `gamma/eta` 位于主域范围内但不在训练格点；`n` 属于已训练集合；
2. **样本量插值/外推**：`n` 不在 `{7,10,15,20}` 训练集合；`n=15` 已在正式设计域内直接训练；
3. **参数外推**：`beta` 或 `gamma/eta` 超出主域范围；
4. **样本量外推**：`n<7` 或 `n>20`；
5. **多轴外推**：同时超出两个或以上轴。

每个轨道分别比较样本自适应方法、Default 和 L1；成功口径不预设必须优于，给出保留收益 / 与基线相当 / 失去收益 / 证据不足之一。

### 5.2 seed 稳定性与输入表示尺度性质

- 报告 60 个 fold×seed 模型级 J1 分布（4 n × 5 fold × 3 seed）；
- 输入表示检查：确认输入为排序原始样本（未除以均值），每位置 StandardScaler 仅由训练折拟合；有量纲输入不具备单位不变性，结论限于训练单位与尺度范围；
- 产物：`artifacts/formal/E6_dimensional_raw/specialist/`（`seed_stability.csv`、`representation_check.json`）。

### 5.3 传统方法外部参照

- 传统方法只作**外部参照**，不决定论文主结论；
- **WMLE** 为主要传统方法参照，**LSE** 为另一类参照；同一样本、同一划分、同一失败合同；
- **MLE 不再审查、不再补跑、不进入论文结果表**；已封存 MLE 结果不得删除或篡改；
- **Direct-MLP 与 MDM 的完整比较属于独立 Research**，其公平比较合同见 `Research/README.md`，不进入本文主结果链。

### 5.4 工程寿命分位点

- 从 P4 逐样本三参数估计派生 `x_0.90`/`x_0.95`/`x_0.99`；
- 报告相对 Bias、RMSE、MAE 和 P95 绝对相对误差；按 `n` 和 `beta` 分层；
- 检查参数 J1 排名与分位点排名是否一致；
- 不以工程结果反向调节偏移量或训练模型。

### 5.5 域匹配真实案例（后置，不阻塞写作）

- 候选数据集在运行相对方法比较前冻结准入（来源与 SHA256、样本量、三参数 Weibull 适配、参数域重叠、特征覆盖；准入判断不读取方法结果）；
- 评价复用重复无放回小样本/留出设计；
- NIST 6061-T6 既有封存负结果保留，不进入本文；
- 一个真实案例只支持“在该案例和指标下有用或无用”。

## 6. 输出与 provenance

- 正式入口位于 Study01 `code/`，可复用 `python/methods` 和 `python/studies/common` 的稳定实现；
- 每个正式轨道输出逐样本结果、汇总、manifest、运行日志和哈希；
- manifest 至少记录：generation code commit 与 artifact seal commit、工作树状态、Python/numpy/scipy/sklearn 版本、输入文件真实 SHA256、样本键与 split 哈希、方法版本和失败合同、输出文件 SHA256；
- 正式数据原则上留在原路径，不复制、不重封存。

## 7. 执行自治与审批

执行者可以：选择符合现有项目模式的最小实现；复用已封存样本和公共指标；将互不依赖的分析组织为小提交；为 fail-closed 合同增加必要测试。

执行者不得：

- 覆盖现有正式产物；
- 自行扩大方法池、网络搜索、参数空间、seed 或真实数据集；
- 自评 `APPROVE`；
- 在真实数据准入冻结前查看相对方法结果；
- 因结果不符合预期修改指标、阈值或纳入规则；
- 重跑已封存实验或重封存正式产物。

## 8. STOP 条件

遇到以下任一条件立即停止当前阶段并报告：

1. 既有样本键、split、风险曲线或 manifest 无法独立核验；
2. 训练输入含真参数、组合 ID、repeat ID、测试标签或真实数据留出信息；
3. 方法不能在相同样本和失败合同下公平比较；
4. 泛化轨道无法把变化轴分开，且最小补点仍不足以识别；
5. 真实数据来源、许可、失效含义、样本量或域匹配 gate 不满足；
6. 正式运行可能覆盖已有批准产物；
7. 结果与预期相反——第 7 项意味着停止扩张并修改主张，不意味着实验失败。
