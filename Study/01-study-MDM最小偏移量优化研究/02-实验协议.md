> 当前修订：2026-08-24
> 职责：保留论文仍会使用的实验定义。正式 E8 产物只读；剩余验证默认采用足以回答问题的最小脚本，不为单次实验新建控制平台。

## 1. 主指标

对第 $i$ 个样本，三参数联合损失为

$$
\ell_i=
\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2+
\left(\frac{\hat\gamma_i-\gamma_i}{\eta_i}\right)^2.
$$

汇总指标为

$$
J_1=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\ell_i}.
$$

所有方法在同一比较中必须使用相同样本、相同损失和相同失败处理。$J_1$ 用作统一选择目标；最终结果另报告每参数标准化 Bias、SD、RMSE、失败率以及按 $n$ 分层结果。

为验证正偏移量本身的稳定性作用，正文在每个 $(\beta,\gamma/\eta,n)$ 参数组合内，分别用 300 次重复抽样计算 $\beta$、$\eta$ 和 $\gamma$ 的标准化估计 SD，再比较 $\delta=0$ 与固定 $\delta=0.1$ 在 160 个组合上的分布。不同真参数组合的估计值不得直接混合计算 SD。自适应方法与固定规则的最终比较另用逐参数 Bias、SD 和 RMSE 表核验，不以该稳定性图代替主结果。

主结果的 Monte Carlo 不确定性采用配对 repeat-block bootstrap 量化。每个 repeat 块在 160 个设计单元中各含一个样本，重采样同时保留方法配对、设计平衡和 $J_1$ 的非线性汇总；重采样次数为 20,000，随机数种子为 20260824。另对 160 个设计单元均值进行配对 bootstrap，只作设计构成敏感性分析。前者的 95% 区间以已固定的 seed 42 选择器和当前参数网格为条件，不包含表示/模型选择或训练初始化不确定性；后者不称为连续参数总体的置信区间。

## 2. 偏移量选择的信息条件

| 层级 | 选择规则 | 评价方式 |
|---|---|---|
| Default | 固定 $\delta=0.1$ | 全部样本 |
| L1 | 全局统一 $\delta$ | repeat-id 五折选点/评价分离 |
| L2 | 按 $n$ 选择 | 同上 |
| L3 | 按 $\beta$ 选择 | 同上；oracle 参照 |
| L4 | 按 $\beta,n$ 选择 | 同上；oracle 参照 |
| L5 | 按 $\beta,\gamma/\eta,n$ 选择 | 同上；oracle 参照 |
| L6 | 每个样本取预设 26 点网格内的实际最小损失 | hindsight 参照，不训练，不是连续空间下界 |

L1–L5 由 `code/analyze_E1_E2_crossfit.py` 实现。L3–L5 用条件平均损失考察不同参数条件之间的差异；其中 L5 在给定真参数组合与样本量时选择条件平均损失最小的偏移量。L6 在当前样本的真参数和 26 个实际损失均已知时事后选择，用于考察同一参数条件内的样本差异。两者不是同一信息轴上的相邻可执行方法。不同评价划分得到的数值可以并列说明，但不能省略协议后直接排名。

## 3. 当前主设计

| 项目 | 取值 |
|---|---|
| $\beta$ | 1.5、2.0、2.5、3.0、3.5、4.0、4.5、5.0 |
| $\eta$ | 1000 |
| $\gamma/\eta$ | 0.10、0.25、0.50、0.75、1.00 |
| $n$ | 7、10、15、20 |
| 重复数 | 每组合 300 |
| $\delta$ | 0.00 到 0.50，步长 0.02，共 26 点 |

共 160 个参数—样本量组合、48,000 个样本和 1,248,000 次候选偏移量估计。正式数据来自 `artifacts/formal/E5_normalized_raw/shared_data/`；E8 复用已封存的均值归一化折外选择结果和共享候选估计，不重跑 MDM、不重训练主模型。

$\eta=1000$ 是 Monte Carlo 设计中的代表性基准尺度。正式输入 $X/\bar X$ 移除样本的整体比例；MDM 本身的尺度等变性由既有固定 $\delta$ 测试与 E8 端到端检查分别支持。

### 3.1 统一偏移量的参数域敏感性

为检验统一低风险偏移量是否随研究域改变，E13 只加密 $\beta$ 轴，其余设计保持不变。$\beta$ 取 1.50—5.00、步长 0.25；在该网格上构造包含 5 个连续水平、宽度固定为 1.00 的滑动区间，区间中心由 2.00 移至 4.50。每个区间均保留全部 5 个 $\gamma/\eta$、4 个 $n$ 和 26 个 $\delta$，各参数条件等权。既有半步长 $\beta$ 水平复用封存扫描的 repeats 0—99，仅对 7 个新增水平按同一 seed namespace、共享样本生成器和生产 `run_method("mdm")` 入口补算 100 次重复。

每个滑动区间分别计算 26 点汇总 $J_1(\delta)$、离散最低点、$\delta=0.10$ 相对最低点的超额 $J_1$ 和 1% 近优区间。最低点的离散选择稳定性另用 5,000 次 repeat-block bootstrap 描述。该实验只改变纳入汇总的 $\beta$ 参数域，用于检验统一取值对参数域的依赖；它不替代主设计上的 L1—L6 和样本自适应方法评价。

## 4. Mean-Normalized-MLP

### 输入与输出

- 每个 $n$ 训练一个独立网络；
- 先对样本升序排列，再用当前样本均值归一化：$Z_n=\operatorname{sort}(x_1,\ldots,x_n)/\bar X_n$；
- 不输入真参数、组合 ID、repeat ID、显式 $n$、手工统计特征、padding 或 mask；
- 每个位置使用 StandardScaler，且只在该 $n$ 的训练折拟合；
- 输出为 26 维预测损失曲线；
- 选择 $\hat\delta=\arg\min_\delta\widehat\ell(\delta\mid X_n)$；
- 最终 $\hat\beta,\hat\eta,\hat\gamma$ 仍由 MDM 在 $\hat\delta$ 下计算。

### 网络与训练

| 项目 | 冻结值 |
|---|---|
| hidden layers | 256–128–64 |
| activation | ReLU |
| solver | Adam |
| learning rate | 0.001 |
| alpha | 0.0001 |
| batch size | 256 |
| max iterations | 300 |
| early stopping | validation fraction 0.15，patience 20 |
| seeds | 42 为正文固定主报告；2026、3407 仅作初始化敏感性，不集成预测 |

训练目标是每个样本的 26 点损失向量，不是最佳偏移量的硬标签。目标标准化和失败惩罚只用训练折确定。

### 留出评价

对每个 $n$，五折分别留出一个完整 $\gamma/\eta$ 水平作为测试集；测试折覆盖全部 8 个 $\beta$，训练折包含其余四个 $\gamma/\eta$ 水平下的全部 $\beta$。

该划分检验“未见 $\gamma/\eta$ 水平”，不检验“未见 $\beta$”。同测试样本比较 Mean-Normalized、Default 和 L6。E7 先比较了均值、样本标准差和 RMS 三种尺度不变表示；均值与 RMS 的 $J_1$ 分别为 0.5850 和 0.5854，属近似并列。选择均值归一化是因为它观测值略低、定义简单且精确复现 E5 已有结果，不声称其普遍优于其他归一化。

### 尺度等变检查

- 现有 `python/tests/test_mdm_s49.py` 负责固定 $\delta$ 下 MDM 的尺度等变性；
- `code/check_mean_normalized_e2e_scale.py` 进一步检验“均值归一化选择器→选定 $\delta$→生产 MDM”的组合路径；
- 4 个代表参数/样本量条件各在 $10^{-3}$、1、$10^3$ 三个整体缩放下运行，检查预测曲线、所选 $\delta$、$\hat\beta$、$\hat\eta$、$\hat\gamma$、$R^2$ 和归一化联合损失；
- 结果为 12/12 通过；该有限检查不替代未见 $\beta$、未见 $n$ 或连续参数空间的泛化证据。

### 5.3 可靠度寿命

由 E8 选择结果与共享候选估计中的对应三参数估计派生。$x_R$ 定义为满足 $P(T>x_R)=R$ 的可靠度寿命：

$$
x_R=\gamma+\eta[-\ln(R)]^{1/\beta}.
$$

- 主可靠度寿命：$x_{0.95}$；补充：$x_{0.90},x_{0.99}$；
- 比较 Mean-Normalized、Default 和 L6；WMLE/LSE 一并列出；
- 报告相对 Bias、RMSE、MAE、P95 和失败率；
- 不重跑 MDM，不反向根据可靠度寿命结果调 $\delta$，不训练直接预测 $x_R$ 的网络。

已执行：`code/derive_mean_normalized_quantiles.py` → `artifacts/formal/E8_mean_normalized_selector/quantiles/`；正文主报告从 `seed42_primary/quantiles.csv` 读取固定 seed 42 的结果。Mean-Normalized 在 $x_{0.90}/x_{0.95}/x_{0.99}$ 的相对 RMSE 为 0.1608/0.2136/0.3753，Default 为 0.1607/0.2142/0.3777，L6 为 0.1613/0.2123/0.3576。参数 $J_1$ 收益向可靠度寿命的传递有限，不预设一致。WMLE/LSE 行经输入哈希和样本键核对后原样复用，其自身数值未改。

### 5.5 利用初估参数选择偏移量（Phase A 可行性探索）

目的：检验“用估计参数代替真参数做 plug-in 选点”能否保留 L3–L5 的 oracle 收益。冻结设计（任务 study01-param-guided-01，Phase A 版本）：

- 选择族（条件集＝真参数网格上的 L3/L4/L5 分组）：
  - `PG-beta`：仅 $\beta$（oracle 参照 L3）；
  - `PG-beta-n`：$\beta,n$（参照 L4）；
  - `PG-full`：$\beta,\gamma/\eta,n$（参照 L5）。
- 初始估计量：`MDM-0.1`（复用缓存 $\delta=0.1$ 的 MDM 估计）；`WMLE`（生产实现；B2 逐样本 `estimation.csv` 缺失，缓存确属不足，仅在 pilot 子集重算）。
- 估计→曲线映射：`nearest-grid`（最近网格单元的条件均值曲线）与 `interpolated`（连续估计处对损失曲线做多重线性插值，只在训练支持域外截断并逐次记录）；插值对象是损失曲线，不是选中的 $\delta$。
- 迭代：初始估计→选 $\delta$→读同一样本该 $\delta$ 的 MDM 估计→重选；$\delta$ 不变（fixed point）、出现循环、或达到 10 次更新即停；循环不取平均、不强制收敛。初始估计无效则回退 $\delta=0.1$ 并记录原因。
- 划分：既有 `repeat_id mod 5` cross-fit；条件均值曲线只用训练折。$J_1=\sqrt{\mathrm{mean}_i L_i}$（三参数损失，无 /3）。

已执行两个阶段：Phase A pilot（repeats 0–99，16,000 样本）与 Phase B 全量 48,000 样本。正式运行命令：`python code/run_pg_selector.py --full --workers 8`；`artifacts/formal/pg_selector/` 为最终全量包（pilot 事实保留在本节与复核清单）。

最终结论（48,000 样本，repeat-id 五折 cross-fit，oracle 与密封 `crossfit_layers` 完全一致：Default=0.630409、L2=0.623035、L3=0.590526、L4=0.588514、L5=0.581294）：

- 全部 12 个单步 PG 变体的 $J_1$ 均高于 Default（最佳：WMLE/`PG-beta`/interpolated 单步 0.650696 vs Default 0.630409；差距 +0.020287）。
- 配对 repeat-block bootstrap（固定 seed，300 块）：全部 12 个单步变体 95% CI 严格为正，95.3%–99.0% 的 repeat 块更差 → 负结果稳健。
- oracle-gap 回收率为负（−50.9% 至 −130.1%）：估计参数未保留 oracle 收益。
- 迭代（terminal）一致劣于单步；`PG-full` 最差（$\gamma/\eta$ 估计噪声大）。
- 分 $\beta$（`summary_by_beta.csv`，96 行单步）：最佳单步规则（WMLE/`PG-beta`/interpolated）仅在 $\beta=1.5$ 优于 Default（0.53727 vs 0.54770，差 −0.01043），$\beta=2.0$–5.0 均更差。pooled 负结论不以抹平此例外为代价，正文应如实表述。
- 机制诊断：WMLE 的 $\hat\beta$ 只有 16.5% 落入正确 $\beta$ 网格单元（按真 $\beta$：5.9%–29.9%），且初估误差与最终损失正相关。这些证据与“初估噪声/偏倚使样本被错误路由、从而削弱 plug-in 选点”的解释一致（supports the interpretation），但不构成对该唯一机制的证明：连续插值同样失效，且误差分层可能与真 $\beta$ 混杂。

定位（Mentor 复核定调）：本路线作为简洁的负向支撑实验保留在 Study01——不是新主方法（主方法为 Mean-Normalized-MLP），也不作为 Research 旁路移出。它回答“为什么初步参数估计不能自动恢复 L3–L5 oracle 收益”。详细 12 变体、迭代、bootstrap 和分 $\beta$ 结果归附录 C；正文只使用最佳 plug-in 结果与负结论。

### 5.6 仅依据观测样本的条件风险参照

目的：区分论文 MLP 的学习或协议差距，与 L6 所使用的不可获得事后信息。理想的样本规则为

$$
\delta_Z^*(Z)=\arg\min_{\delta\in\mathcal D}
\operatorname{E}\!\left[\ell(\delta,X,\theta)\mid Z\right],
\qquad Z=\operatorname{sort}(X)/\bar X.
$$

当前实验不计算精确 $\delta_Z^*$，而以一组预先声明的回归器构造已实现的 $Z$-only 经验参照。数据仍为当前 160 组合、300 次重复和 26 点损失缓存，不重跑 MDM。对每个 $n$，repeats 0–159 拟合，160–199 选择 Ridge、KNN、ExtraTrees、当前 MLP 或较宽 MLP，200–299 作为未触及确认集。候选选择与确认严格分开，所有输入和目标标准化仅在拟合子集上估计。

确认集共 16,000 个样本。风险分解使用 $R=\operatorname{E}(\ell)=J_1^2$，因为 $R$ 的差可加，不直接加减 $J_1$。Default、论文 MLP、同域重训当前结构、灵活 $Z$-only 经验参照和 L6 的 $R$ 分别为 0.39269、0.33953、0.32267、0.31566 和 0.24065。从 Default 到 L6 的观测风险差中，34.96% 已由论文 MLP 取得，11.09% 与评价协议、参数覆盖和重拟合共同相关，4.61% 在灵活经验规则下进一步降低，剩余 49.34% 仍混合可学习部分与完全信息差，不作更细归因。

学习曲线只用于诊断数据敏感性，不用于选模型或声称接近 Bayes 最优。逐样本风险差的主要不确定性使用 100 个 repeat 块的 20,000 次配对 bootstrap 描述。正式支撑产物位于 `artifacts/formal/E10_z_only_benchmark/`。

### 5.7 MDM 梯度曲线机制诊断

目的：说明同一 $(\beta,\gamma/\eta,n)$ 条件内，抽样结果如何通过 MDM 的经验位置搜索曲线改变低风险偏移量。设计固定为参数域四角 $(1.5,0.1)$、$(1.5,1.0)$、$(5.0,0.1)$、$(5.0,1.0)$ 与中心 $(3.0,0.5)$，分别与 $n=7,10,15,20$ 交叉，共 20 个单元。每单元使用 repeats 200—299，共 2,000 个确认样本；这些 repeat 未参与 E10 的拟合或选模。

26 点损失和 L6 偏移量复用 E5 正式分片，不重跑候选扫描。每个样本按相同 seed namespace 重建一次，运行固定 $\delta=0.1$ 的 MDM trace，记录 $\nabla_X(0)$、$\nabla_X(\gamma_{\mathrm{true}})$、局部斜率、$\hat\gamma_{0.1}/\eta$、边界状态和简单样本形态。主要汇总为各参数单元内 $\nabla_X(0)$ 与 L6 偏移量、$\hat\gamma_{0.1}/\eta$ 与 L6 偏移量的 Spearman 相关，以及按 $\hat\gamma_{0.1}/\eta$ 三分位分组的平均超额损失曲线。正式支撑产物位于 `artifacts/formal/E11_profile_mechanism/`。

该诊断不训练新模型，也不把数值相关解释为闭式因果分解。边界解比例用于判断观察到的变化是否主要由 $\hat\gamma=0$ 截断造成。

### 5.8 L6 候选上边界敏感性

目的：检查 $\mathcal D=\{0,0.02,\ldots,0.50\}$ 是否将 L6 事后参照截断在右端。该诊断不重训练选择器，也不改变主方法的 26 点部署网格。

先在 48,000 个原样本中选出 $\ell(0.50)<\ell(0.48)$ 的 2,186 个样本，再使用相同样本生成器、seed namespace、生产 MDM 与损失公式，仅计算 $\delta=0.52,0.54,\ldots,1.00$。$0.48$ 与 $0.50$ 同时重算用于核对原扫描，最大损失差不得超过 $10^{-9}$；新旧损失差不超过 $10^{-12}$ 视为平局。

诊断结果为：2,063 个样本在 $0.50$ 之外获得实质改善，全样本 L6 $J_1$ 从 0.492297 降至 0.490848；但仍有 590 个样本在 $1.00$ 取最小损失。因此该结果只证明原网格存在轻微右截断，不定义无约束 L6。候选产物位于 `artifacts/candidate/E12_delta_upper_boundary/`。

## 6. 最小可复现要求

论文实验不自动等同于生产系统。每个剩余任务只需满足：
