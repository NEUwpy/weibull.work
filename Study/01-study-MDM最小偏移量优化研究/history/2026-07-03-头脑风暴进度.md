### C2. 六级分级框架（替代旧文档的 Default/L0-L5）

| 层级 | 偏移量决策粒度 | 实现方式 | 说明 |
|------|--------------|---------|------|
| L1 全局 | 一个常数（替代 0.1） | 直接取 | 全局最优常数是多少？是否比 0.1 好？ |
| L2 按 n | 每个 n 一个值 | 查表 | 精度提升多少？ |
| L3 按 β | 每个 β 一个值 | oracle 分组 / 可作为标签参照 | β 不可知，不能直接部署 |
| L4 按 β+n | 每个 β,n 组合一个值 | oracle 分组 / 可作为标签参照 | n 可知，β 不可知 |
| L5 按 β,γ/η,n | 每个 β,γ/η,n 组合一个值 | oracle 分组 / 可作为标签参照 | 真参数不可知，不能直接部署 |
| L6 逐样本 | 每个样本一个值 | hindsight benchmark | 扫描网格内事后参照，不作为部署目标 |

**关键约束：L3 起需要真参数信息，不能直接查表部署。** 后续可尝试用样本可观测特征和 n 逼近 L3-L5；NN 是候选实现，但不是唯一逻辑，也不是论文目的本身。

## 待讨论清单（尚未固定）

### D1. 评价指标具体选哪个？ ✅ 已定（2026-07-03）
- **选 J1（相对误差型）**：J₁ = √(mean[(Δβ/β)² + (Δη/η)² + (Δγ/η)²])
- γ 归一化：除尺度参数真值 η（不除 γ 自身）
- 参数权重：等权（w_β = w_η = w_γ = 1）
- 辅助指标：每参数 Bias + SD（诊断用）、失败率（gate 用）
- 文献先例：182-050 / 182-097 的 Joint RMSE 列；J1 为相对误差变体
- 详见：`Research/评价指标与其他估计路线/调研-评价指标/01-调研报告.md`

### D2. 样本自适应 δ 选择的候选输入特征 ✅ 已定（2026-07-03）
- **特征集 A3（8 个）**：n, x_(1), x_(n), Med, x̄, s, CV, g₁（偏度）
- **消融实验 5 组**（A0-A4，附录）：
  - A0: {n, x̄} | A1: {n, x̄, s, g₁} | A2: Yang 复现 {n, x_(1), x_(n), Med, x̄, Mode, CV} | A3: 推荐集 | A4: 全集
- **预处理**：有量纲特征（x_(1), x_(n), Med, x̄, s）做 z-score；无量纲（CV, g₁, n）不动；标准化参数从训练集计算
- 文献依据：184-009（Yang Xiaoyu, PEM 2025）7 特征方案 + Pearson 相关性筛选；Abbasi 5 特征方案
