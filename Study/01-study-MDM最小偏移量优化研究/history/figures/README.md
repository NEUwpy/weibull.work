# 历史图表归档规则

> 本目录只用于旧版论文图表的追溯与恢复，不是当前正文或正式证据源。当前图表仍以 `artifacts/formal/figures/` 为准。

替换或重绘一张已进入论文工作流的图表时：

1. 先将旧版完整导出包（至少包含已有的 PNG/SVG/PDF）复制到 `YYYY-MM-DD-<figure>-<revision>/`。
2. 在该子目录放置 `README.md`，记录来源提交、归档日期、旧版内容、替换原因和恢复方法。
3. 确认旧版可读取后，才允许覆盖当前 `artifacts/formal/figures/` 中的活动版本。
4. 不把历史图重新引用为当前证据；需要恢复时先复制回活动目录，再重新进行正文、图注和来源复核。

禁止直接删除旧图或只保留新版导出。
