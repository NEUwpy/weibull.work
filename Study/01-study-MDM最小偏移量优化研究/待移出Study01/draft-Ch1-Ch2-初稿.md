# 第1章 引言

三参数 Weibull 分布能够分别用形状参数 β、尺度参数 η 和位置参数 γ 描述失效机理、特征寿命与安全阈值，因而被广泛用于疲劳寿命和可靠性分析。由于寿命试验成本较高，参数估计往往需要在有限样本下进行；此时，位置参数 γ 对分布支撑集的改变会加剧三个参数联合估计对样本波动的敏感性(182-022; 182-090; 182-099)。极大似然估计的部分常规渐近条件在三参数 Weibull 情形下不再自动成立，围绕 MLE、LSE、MPS、PWM、WMLE、Bayesian 及偏差修正方法也因此形成了持续的小样本改进研究(182-029; 182-060; 182-088; 182-090; 182-091; 182-096)。这些工作确立了三参数 Weibull 小样本估计的普遍困难，但本文不再展开一般估计方法的全面比较。

谢里阳等在前两篇工作中提出并发展了 Minimum Discrepancy Method（MDM）(182-030; 182-046)。第一篇工作提出最小差异原理，通过构造尺度参数伪估计量并搜索使其差异最小的参数组合完成估计。第二篇工作进一步指出，在位置参数 γ 的搜索过程中，原始 $\nabla\gamma=0$ 判据可能使有限样本估计落入判据曲线的局部平坦区域，从而造成 γ 估计波动。为降低这种不稳定性，原作者引入偏移量 δ，将判据由 $\nabla\gamma=0$ 调整为 $\nabla\gamma=\delta$，并采用经验值 `δ = 0.1` 改善估计精度和稳定性。

然而，前述工作证明了 `δ = 0.1` 的有效性，却没有系统回答偏移量本身的选择问题。谢里阳等(182-046)将 `0.1` 表述为“根据 120 个参数估计案例得到的经验值”，并指出更适当的偏移值与分布特征和样本大小有关。因此，MDM 的进一步发展需要回答：偏移量是否存在操作意义上的最优值；这种最优性应在全局、按样本量、按真参数条件还是逐样本层级上定义；不同信息层级能够带来多大收益；以及在真参数不可见时，如何获得更合适的偏移量。

本文接续 MDM 的前两篇工作，把经验偏移量从“`δ = 0.1` 有效”推进为一个可按信息层级定义、评估和优化的决策问题。本文首先在统一 Monte Carlo 框架下检验 `δ = 0.1` 是否接近最优全局常数，继而建立从全局常数、按样本量查表、真参数 oracle 到逐样本 hindsight 的六级信息层级，并量化各层级的精度收益；随后，在真参数不可见的部署条件下，以神经网络为主要实现方法，学习从样本可观测特征到离散候选偏移量风险曲线的映射，并据此选择更合适的 δ；最后，通过边界稳健性和真实寿命数据验证限定方法的适用范围。本文的目的在于完善 MDM 的偏移量选择机制，而非重新开展 MDM 与一般估计方法的全面比较，或将问题改写为孤立的神经网络优化任务。

# 第2章 MDM 方法与偏移量问题

## §1 MDM 的基本步骤

三参数 Weibull 分布的累积分布函数为

$$F(t) = 1 - \exp\left[-\left(\frac{t - \gamma}{\eta}\right)^{\beta}\right], \quad t > \gamma$$

其中 β > 0 为形状参数，η > 0 为尺度参数，γ 为位置参数（失效阈值）。给定有序失效时间 $t_{(1)} \leq t_{(2)} \leq \cdots \leq t_{(n)}$，用 Bernard 中位秩公式估计经验累积概率 $\hat{F}(t_{(i)}) = (i - 0.3)/(n + 0.4)$，并令变换值 $x_i = -\ln(1 - \hat{F}(t_{(i)}))$。Weibull 分布经此变换可写为 $t_{(i)} = \gamma + \eta\, x_i^{1/\beta}$，这是 MDM 构造尺度参数伪估计量的基础。

MDM 的核心是尺度参数的伪估计量(182-030)。对于给定的候选参数 (β, γ)，每个样本点可反解出一个伪尺度参数估计：

$$\hat{\eta}_i = \frac{t_{(i)} - \gamma}{x_i^{1/\beta}}, \quad i = 1, 2, \ldots, n$$

当 (β, γ) 接近真值时，$n$ 个 $\hat{\eta}_i$ 应当一致——它们之间的差异源于样本波动。MDM 的核心判据是最小化这组伪尺度参数的条件标准差：

$$\sigma_\eta(\beta, \gamma) = \text{std}\left(\hat{\eta}_1, \hat{\eta}_2, \ldots, \hat{\eta}_n\right)$$

MDM 采用两步搜索策略。**内层**：对给定 γ，搜索使 $\sigma_\eta$ 最小的 β，$\beta^*(\gamma) = \arg\min_{\beta \in [0.1, 15.0]} \sigma_\eta(\beta, \gamma)$，得到 profile 标准差曲线 $\sigma_{\eta,\min}(\gamma)$。**外层**：在 γ 方向上搜索 $\sigma_{\eta,\min}(\gamma)$ 的极值点确定 γ̂，进而回代得到 (β̂, η̂)。

与需要联立求解非线性方程的估计方法不同，MDM 采用 profile 搜索，但这并不意味着约束域 `0 <= gamma < t_(1)` 内总存在内部 offset root。当前工程实现按 `python/methods/mdm.py` 的统一语义，在可达时求内部根，并在根落到约束域外或逼近搜索边界时采用相应边界规则，从而始终返回一个候选估计；其中 `gamma = 0` 截断不能被写成内部方程有解。前作已围绕 MDM 与 MLE/LSE 的比较给出讨论，本文只把这些结果作为背景，重点转向 MDM 内部 offset 判据的性质。Ch2 只保留这一区别，边界策略的发生率与稳健性影响交由 Ch7；完整实现见 `python/methods/mdm.py`。

## §2 γ 搜索的不稳定来源与梯度偏移判据

在 MDM 的外层 γ 搜索中，原始思路是寻找 profile 标准差曲线 $\sigma_{\eta,\min}(\gamma)$ 的极值点，即使用一阶导数等于零的梯度判据。为保持与第二篇 MDM 原文一致，本文沿用原文记号 $\nabla\gamma$ 表示 $\sigma_{\eta,\min}(\gamma)$ 关于位置参数 γ 的离散梯度；这里的 $\nabla\gamma$ 是原文定义的判据记号，并非 γ 自身的梯度。在确定性或理想样本意义下，$\sigma_{\eta,\min}(\gamma)$ 在真实 γ 附近应达到极值，因而原判据写为 $\nabla\gamma=0$。

但谢里阳等(182-046)指出，有限随机样本会破坏这一理想关系：真实 γ 附近的梯度未必等于零，且在不同样本下可能大于零，也可能小于零。若直接以零梯度为判据，某些样本的位置参数估计会产生较大误差。这一不稳定来源与判据曲线在局部平坦谷底附近的形态有关。

第二篇 MDM 工作的修正是将判据从 $\nabla\gamma = 0$ 改为 $\nabla\gamma = \delta$（δ > 0）：

$$\left.\nabla\gamma\right|_{\gamma=\hat{\gamma}} = \delta$$

引入 δ > 0 的作用，是把“寻找零梯度极值点”改为“寻找达到一个小正梯度阈值的位置”，即用一条 $\nabla\gamma=\delta$ 的水平判据线替代 $\nabla\gamma=0$ 判据线。谢里阳等取 δ = 0.1（经验值，来自 120 个参数估计案例），并报告该修正在总体上缩小了位置参数估计的离散范围。换言之，偏移量改变的是 γ 搜索判据的位置，而不是后处理修正。

本文的研究对象即此 δ：它是经验常数，还是可优化的决策变量？若是后者，最优值应在什么信息层级上定义、能带来多少改善、能否在真参数不可见的部署条件下逼近？

### 尺度等变性

偏移量 δ 的判据在寿命尺度变换下保持不变。设所有寿命观测值同乘 $c>0$，并令 $t_i'=ct_i$、$\gamma'=c\gamma$。对固定 $\beta$ 和中位秩 $F_i$，缩放后的伪尺度参数为

$$
\eta_i'(\beta,\gamma')=
\frac{ct_i-c\gamma}{[-\ln(1-F_i)]^{1/\beta}}
=c\eta_i(\beta,\gamma).
$$

因此其标准差满足 $\sigma_\eta'(\beta,\gamma')=c\sigma_\eta(\beta,\gamma)$。对给定 $\gamma$ 的 $\beta$ 极小化不因正的常数倍数而改变，故 profile 标准差满足 $\sigma'_{\eta,\min}(\gamma')=c\sigma_{\eta,\min}(\gamma'/c)$，进而

$$
\frac{\partial\sigma'_{\eta,\min}(\gamma')}{\partial\gamma'}
=
\frac{\partial\sigma_{\eta,\min}(\gamma)}{\partial\gamma}.
$$

所以同一 $\nabla\gamma=\delta$ 判据在缩放前后选出相同的 $\hat\beta$ 和同比例缩放的 $(\hat\eta,\hat\gamma)$；以真值 $\beta$ 和 $\eta$ 归一化的联合损失也保持不变。这一性质使第 3 章可以将 $\eta=1$ 作为尺度归一化基准，同时为 Figure 1 在 $W(2,1,1)$ 与 $W(2,1000,1000)$ 之间的尺度转换提供依据。当前数值实现已通过 $c=1000$ 且 $\delta\in\{0,0.1,0.5\}$ 的自动尺度等变回归测试（`python/tests/test_mdm_s49.py`）。

## §3 为什么 δ 不是任意小正数

一个自然的直觉是：既然 $\nabla\gamma=0$ 判据不稳定，那只要取一个很小的正 δ 就能避开不稳定区域。但这一直觉并不成立。

δ 是稳定性收益与过度移动代价之间的折中。从 §2 的判据构造可以直接看出，δ 决定的是 $\nabla\gamma=\delta$ 水平线与梯度曲线的交点位置，即 γ 搜索落在哪个判据位置。δ 太小，搜索位置仍靠近 $\nabla\gamma=0$ 判据下的不稳定区域，对梯度的随机正负波动依然敏感；δ 太大，搜索位置整体移动过度，使 γ̂ 系统性地偏离真值并引入新的偏差。

因此 δ 的取值是一个真实的决策问题，而不是"取一个小正数即可"。本章只给出这一机制理由；δ = 0.1 是否在数值上接近某个有意义的折中点、平坦区间有多宽、不同参数条件下最优 δ 朝哪个方向移动，这些正式数值证据留给第 4 章。
