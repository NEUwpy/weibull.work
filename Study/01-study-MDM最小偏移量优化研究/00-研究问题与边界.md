## 主问题

本文聚焦两个主问题：

1. **偏移量问题**：`delta` 是否显著影响 MDM 估计精度？固定 `delta = 0.1` 是否仍是最优全局常数？更优的全局常数是多少？
2. **层级与决策问题**：从 L1（全局常数）到 L6（逐样本 oracle），逐级提升精度的收益如何？在哪个层级出现边际递减？当真参数不可见（L3 起）时，用 NN 学习"样本→delta"映射能否逼近 oracle 层级的精度？

## 工作假设

以下内容不是论文结论，而是正式实验要检验的工作假设：

1. `delta = 0.1` 不是最优全局常数；存在比它更好的 L1 全局固定值。
2. 从 L1 到 L6 逐级细化，精度逐步提升，但存在边际递减点。
3. L2（按 n 查表）相比 L1 有可见收益，且可直接部署（查表）。
4. L3 起 β 不可知，NN 学习"样本→delta"映射可以逼近 oracle 层级精度。
5. 精度提升在某个层级后不足以抵消计算成本的增加——这个拐点就是实践推荐层级。

## 预期贡献

### 贡献 1：偏移量最优性的正式评估

用统一的 Monte Carlo 协议评估 `delta` 对 MDM 精度的影响，回答"固定 0.1 是否最优"以及"最优全局常数是多少"。

### 贡献 2：六级信息层级框架

建立 L1-L6 偏移量决策层级，量化每一级的精度收益，找到精度与计算成本的平衡点。

| 层级 | 决策粒度 | 实现方式 | 性质 |
|------|---------|---------|------|
| L1 | 全局一个常数 | 直接取 | 可部署 |
| L2 | 按 n | 查表 | 可部署 |
| L3 | 按 β | NN | β 不可知 → 需 NN |
| L4 | 按 β+n | NN | β 不可知 → 需 NN |
| L5 | 按 β,γ/η,n | NN | β 不可知 → 需 NN |
| L6 | 逐样本 | NN | hindsight oracle，上限 |

### 贡献 3：NN 驱动的样本→偏移量映射

L3 起 β 不可知，提出用 NN 从样本可观测特征学习"样本→最优 delta"的映射，验证其能否逼近 oracle 层级精度。

## 硬边界

1. MDM 当前默认语义以 `python/methods/mdm.py` 为准：`gamma >= 0`，负 offset-root 截断到 `gamma = 0`，默认 `delta = 0.1`。
2. 正式实验应在 `Study/01-study-MDM最小偏移量优化研究` 下组织代码、配置、结果和图表。
3. 正式实验可以调用 `python/methods` 与 `python/studies/common`，但不能把旧研究脚本原样当正式代码。
4. 训练标签可以使用真参数或 oracle 风险；部署输入只能使用样本可观测特征。
5. L2-L5 必须标注为 oracle 或训练标签来源，不得写成直接部署策略。
