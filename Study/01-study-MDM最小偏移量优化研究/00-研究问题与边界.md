1. 第一篇论文提出 MDM / MDE 思想：通过最小化尺度伪估计量差异来估计三参数 Weibull 参数。

## 主问题

本文压缩为三个主问题：

1. **性能问题**：MDM 在小样本和不同参数组合下的估计表现如何？
2. **偏移量问题**：`delta` 是否显著影响 MDM 估计精度？固定 `delta = 0.1` 在正式实验中是否仍是强基线？
3. **决策问题**：当真参数不可见时，能否用可部署规则或样本可观测特征选择更优偏移量？

## 工作假设

以下内容不是论文结论，而是正式实验要检验的工作假设：

1. `delta = 0.1` 可能是一个强全局固定基线。
2. 按 `beta`、`n`、`gamma/eta` 或逐样本形态分层后，可能存在额外精度空间。
3. 自迭代和显式 `beta` 预估可能难以稳定部署。
4. 基于样本特征的 risk curve 学习可能优于硬标签回归。
5. 参数视角收益可能大于工程寿命分位点 `x0.95` 的收益。

这些假设只能在 `02-实验协议.md` 所定义的正式实验完成后升级为论文结论。

## 预期贡献

### 贡献 1：正式评估 MDM 偏移量的作用

用统一的 Monte Carlo 协议评估 `delta` 对 MDM 的影响，报告参数视角和工程视角的差异。

### 贡献 2：建立偏移量信息层级

用 `Default / L0 / L1 / L2 / L3 / L4 / L5` 表示不同可用信息条件下的最优偏移量。该层级必须由正式实验重新计算，旧值只能作为 sanity check。

### 贡献 3：比较可部署规则

系统比较固定 `delta=0.1`、按 `n` 查表、自迭代、外部 `beta` 预估等策略，明确计算成本、失败率、fallback 后性能和精度收益。

### 贡献 4：检验样本特征驱动策略

在训练时可用 oracle 风险生成标签，在部署时只允许样本可观测特征输入，检验 hard label 与 risk curve 标签的性能、稳定性和泛化能力。

## 主指标与辅助指标

参数视角：

- 诊断指标：`Bias`、`SD`、`RMSE`
- 排序或训练指标：`J_param`

工程视角：

- 指定可靠寿命分位点 `x_R`
- 当前重点：`x0.95`
- 单目标排序指标：`RMSE_xR`

原则：

1. 稳定性和有效率是 gate；精度是 ranking。
2. 不把 `x0.95` 与 `x0.99` 强行合并成一个工程综合指标。
3. 若工程视角收益很小，应作为边界写出，不强行包装成主贡献。

## 硬边界

1. MDM 当前默认语义以 `python/methods/mdm.py` 为准：`gamma >= 0`，负 offset-root 截断到 `gamma = 0`，默认 `delta = 0.1`。
2. 正式实验应在 `Study/01-study-MDM最小偏移量优化研究` 下组织代码、配置、结果和图表。
3. 正式实验可以调用 `python/methods` 与 `python/studies/common`，但不能把旧研究脚本原样当正式代码。
4. 训练标签可以使用真参数或 oracle 风险；部署输入只能使用样本可观测特征。
5. L2-L5 必须标注为 oracle 或训练标签来源，不得写成直接部署策略。

## 不写什么

本文不写成：

1. `docs/research/01-04` 的整理版。
2. 仅展示旧阶段汇报数字的论文。

4. 宣称彻底替代 `delta=0.1` 的论文。
5. 未经正式重跑就声称“稳定优于”的论文。
