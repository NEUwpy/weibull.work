## 主问题

本文聚焦两个主问题：

1. **偏移量问题**：`delta` 是否显著影响 MDM 估计精度？固定 `delta = 0.1` 是否已接近最优全局常数？如果只能使用一个全局常数，极限在哪里？
2. **层级与决策问题**：从 L1（全局常数）、L2（按样本量 `n` 查表）到 L3-L5（真参数 oracle）和 L6（逐样本 hindsight），逐级提升精度的收益如何？在哪个层级出现边际递减？当真参数不可见时，能否仅凭样本值和 `n` 逼近更低层级的参照精度？

## 工作假设

以下内容不是论文结论，而是正式实验要检验的工作假设：

1. `delta = 0.1` 可能是强经验基线，但仍需要正式验证其是否接近最优全局常数。
2. 从 L1 到 L6 逐级细化，精度可能逐步提升，但存在边际递减点。
3. L2（按 n 查表）是最简单的可部署分层策略，即使总体收益很小，也必须报告其按 n 的表现。
4. L3-L5 使用真参数信息，只能作为 oracle 参照或训练标签来源；实际部署必须从样本可观测特征和 n 近似这些层级。
5. 精度提升在某个层级后可能不足以抵消计算成本的增加——这个拐点就是实践推荐层级。

## 预期贡献

### 贡献 1：偏移量最优性的正式评估

用统一的 Monte Carlo 协议评估 `delta` 对 MDM 精度的影响，回答"固定 0.1 是否最优"以及"最优全局常数是多少"。

### 贡献 2：六级信息层级框架

建立 L1-L6 偏移量决策层级，量化每一级的精度收益，找到精度与计算成本的平衡点。

| 层级 | 决策粒度 | 实现方式 | 性质 |
|------|---------|---------|------|
| L1 | 全局一个常数 | 直接取 | 可部署 |
| L2 | 按 n | 查表 | 可部署 |
| L3 | 按 β | oracle 分组 | 真 β 不可知，作为参照/标签来源 |
| L4 | 按 β+n | oracle 分组 | n 可知，β 不可知，作为参照/标签来源 |
| L5 | 按 β,γ/η,n | oracle 分组 | 真参数不可知，作为参照/标签来源 |
| L6 | 逐样本 | hindsight | 扫描网格内事后参照，不作为部署目标 |

### 贡献 3：真参数不可见条件下的样本自适应偏移量选择

L3 起需要真参数信息，实际部署时不可直接查表。本文据此提出用样本可观测特征和样本量 `n` 学习"样本→delta"映射，并验证其能否逼近 oracle 层级精度。神经网络是候选实现，不是本文的目的本身。

## 硬边界

1. MDM 当前默认语义以 `python/methods/mdm.py` 为准：`gamma >= 0`，负 offset-root 截断到 `gamma = 0`，默认 `delta = 0.1`。
2. 正式实验应在 `Study/01-study-MDM最小偏移量优化研究` 下组织代码、配置、结果和图表。
3. 正式实验可以调用 `python/methods` 与 `python/studies/common`，但不能把旧研究脚本原样当正式代码。
4. 训练标签可以使用真参数或 oracle 风险；部署输入只能使用样本可观测特征。
5. L1/L2 是可部署层级；L3-L5 必须标注为 oracle 或训练标签来源，不得写成直接部署策略；L6 只能作为扫描网格内 hindsight benchmark。
