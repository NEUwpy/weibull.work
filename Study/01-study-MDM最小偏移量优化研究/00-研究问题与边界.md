# 研究问题与边界

2026-09-07；对应正文 v1.12、附录 v1.10。配置只在[实验配置](02-实验配置.md)维护，数值出处见[证据索引](01-证据索引.md)。

## 研究目的

在保留正偏移量改善估计稳定性作用的基础上，理解 MDM 偏移量的有限样本风险，并检验未知总体参数时的样本自适应选择。主要决策变量是 δ，MDM 参数求解骨架和三参数联合损失保持固定。MLP 用于预测候选损失，不作为论文的研究主题。

## 当前证据支持的主张

1. [S01-01/02](02-实验配置.md#s01-01)：正偏移量改变条件偏差与抽样方差；合适的统一值依赖参数域。在现有宽混合域中，经验值 0.1 已接近较低风险区。
2. [S01-03/05](02-实验配置.md#s01-03)：总体条件与样本实现对应不同的信息。真参数条件平均规则与逐样本事后选择不同；样本轨迹和候选损失会随抽样改变。
3. [S01-04](02-实验配置.md#s01-04)：归一化排序样本可提供选择信息，现有折外评价中的 J1 降低 7.27%。这是当前设计及选定方法下的参数估计收益。

## 影响解释的边界

| 边界 | 当前事实 |
|---|---|
| 数据与参数域 | 完整、独立同分布的模拟样本；非负位置参数；160 个离散单元；n=7/10/15/20 |
| 方法定义 | 每个 n 独立网络，26 点候选 δ；未知 n 需要另定义方法 |
| 验证独立性 | 表示筛选复用了主折外样本；主区间不包含筛选/重训练不确定性；S01-05 的内部确认不能替代冻结后新生成的确认集 |
| 信息参照 | L3—L5 使用真参数；L6 使用已实现全部候选损失；均不可作为直接部署策略 |
| 异质性 | 汇总改善不保证每单元改善；主设计有 35 个退化单元 |
| 工程用途 | 参数误差收益向三个可靠度寿命点传递有限；WMLE 在这三个点更好 |
| 因果解释 | 梯度关联和同域经验参照支持有界解释；尚未分离所有模型、协议与信息贡献 |

## 当前取舍

保留偏移量风险、参数域依赖、样本自适应收益与必要负结果。旧 P4、多网络变体、旧特征泛化和不匹配案例不再扩充 Study01。具体试错结果见[认识快照](07-认识清单与研究快照-20260907.md)。

可靠性用途和冻结后的独立确认仍需补强；它们决定后续投入与期刊适配。直接寿命优化、任意样本量、删失、混合失效、区间覆盖及 Direct-MLP 完整比较属于另一个问题，不能作为当前稿件的默认补丁。
