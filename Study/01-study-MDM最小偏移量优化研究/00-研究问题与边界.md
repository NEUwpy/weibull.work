# 00 研究问题与边界

> 当前修订：2026-08-20
> 职责：冻结论文要回答的问题、可使用的结论和明确边界。数值来源见 `01-证据索引.md`，执行细节见 `02-实验协议.md`。

## 一句话定位

在三参数 Weibull 小样本 MDM 估计中，偏移量 $\delta$ 如何影响有限样本估计风险，其合理取值受哪些因素决定，以及在总体参数未知时能否仅依据观测样本实现有效选择。

## 为什么这个问题值得研究

前期研究通过在三参数 Weibull MDM 的位置参数搜索判据中引入正偏移量，改善了有限样本下估计的稳定性，但偏移量仍主要依靠经验设定。偏移量太小可能不足以缓解有限样本估计的不稳定，过大又可能带来不必要的估计误差。因此，更合适的偏移量选择应在保持稳定性的同时尽量降低三参数联合估计误差。

$J_1$ 汇总三个参数的标准化误差；在相同失败规则下，较小的 $J_1$ 表示当前偏移量选择取得了更好的综合估计表现。

## 核心问题

1. 在预设参数空间和评价准则下，$\delta$ 如何改变有限样本估计风险，经验值 $\delta=0.1$ 处在什么位置？
2. 样本量和总体参数等条件如何影响合理偏移量的取值，增加可用信息能够带来多大改善？
3. 总体参数未知时，能否只依据当前观测样本实现有效选择？

## 论文主线

### 第一步：比较不同信息条件下的选择

用 Default 和 L1–L6 比较固定规则、总体参数条件规则和逐样本事后参照：

| 规则 | 选择偏移量时可用的信息 | 作用 |
|---|---|---|
| Default | 无，固定 $\delta=0.1$ | 经验基线 |
| L1 | 全部样本共用一个偏移量 | 最佳统一常数 |
| L2 | $n$ | 样本量规则 |
| L3 | $\beta$ | 形状参数参照 |
| L4 | $\beta,n$ | 形状与样本量参照 |
| L5 | $\beta,\gamma/\eta,n$ | 完整参数组合参照 |
| L6 | 当前样本在 26 个候选偏移量下的实际损失 | 逐样本 hindsight 参照 |

L3–L5 依赖实际应用中未知的真参数，描述各参数条件下的平均低风险偏移量。L6 则在当前样本已经产生、真参数和 26 个实际损失均已知时事后选择。两者的信息条件不同，不能将 L1–L6 简化为一条可执行的递进阶梯，也不能把 Default–L6 的全部差距称为现实方法的可实现空间。

### 第二步：实现可执行选择

对每个样本量分别训练 MLP，以均值归一化的排序样本 $X_n/\bar X_n$ 为输入，预测 26 个候选偏移量的损失曲线，选择预测损失最小的 $\delta$，再由 MDM 完成三参数估计。

```text
Z_n = sort(x_1,...,x_n) / mean(x_1,...,x_n)
  -> per-n MLP
  -> predicted loss(delta_1,...,delta_26)
  -> delta_hat = argmin predicted loss
  -> MDM(beta_hat, eta_hat, gamma_hat | delta_hat)
```

网络不直接估计 Weibull 参数，也不改变 MDM 的参数估计过程。

## 能主张什么

- 在当前 160 组合、固定 $\eta=1000$ 的设计中，整体误差曲线最低点为 $\delta=0.06$，$\delta=0.08$ 与其几乎相同；$\delta=0.1$ 的 $J_1$ 仅比最低点高约 0.93%，因此已接近最佳统一常数。
- 偏移量选择风险会随参数条件改变；同一参数条件内，不同抽样结果会移动 MDM 的经验梯度曲线及搜索交点，事后低风险偏移量也随之改变。
- Mean-Normalized-MLP 在 seed 42 的同测试样本上将 pooled $J_1$ 从 0.6304 降至 0.5846，相对改善 7.2740%，失败率为 0%。
- seed 2026/3407 的辅助结果与 seed 42 接近，只用于说明总体收益不依赖某一次初始化；论文不采用三模型集成。
- 当前按每个 $n$ 的一个完整 $\gamma/\eta$ 水平留出，说明方法能在训练未包含该水平时进行当前离散设计内的预测。
- 未见 $\beta$ 留出（B1）显示 pooled 收益保留：seed 42 下 $J_1=0.5841$，相对 Default 0.6304 改善 7.347%，失败率 0%。$\beta=1.5$ 层略差，因此不声称每个未见层均改善；结果仅限于当前离散 8 点 $\beta$ 网格。
- WMLE/LSE 同条件参照（B2）提供外部坐标：参数层面 Mean-Normalized seed 42（0.5846）优于 WMLE（0.7288）和 LSE（0.8725），不决定偏移量方法是否成立。
- $x_{0.90}/x_{0.95}/x_{0.99}$ 派生（B3）显示参数改善传递有限：Mean-Normalized seed 42 相对 RMSE 为 0.1608/0.2136/0.3753，Default 为 0.1607/0.2142/0.3777；三个可靠度点中 WMLE 均最低，因此不预先声明工程寿命指标改善。
- E7 候选筛选中均值与 RMS 归一化几乎并列；选择均值归一化是因为观测 $J_1$ 略低、定义简单且精确复现既有 E5 结果，不声称它对所有任务普遍更优。
- 4 个代表条件在 $10^{-3}$、1 和 $10^3$ 三个整体缩放下，预测损失曲线与所选 $\delta$ 一致，生产 MDM 给出不变的 $\hat\beta$ 与按比例变化的 $\hat\eta,\hat\gamma$。
- 利用初估参数选择偏移量（plug-in）的负向支撑实验：把初步参数估计当作真参数沿用 L3–L5 规则，总体不能恢复 oracle 收益（最优单步变体 pooled $J_1=0.6507$ vs Default 0.6304；配对重复块 95% CI 全部为正），且迭代一致变差；该负结果仅在 $\beta=1.5$ 有例外。
- 在同一 $(\beta,\gamma/\eta,n)$ 条件内，L5 与 L6 的偏移量只有 12.6% 完全一致，各条件内 L6 偏移量的中位有效候选数为 6.09。这表明低风险偏移量除了随总体参数改变，也随有限样本的随机实现而变化。
- 在固定的 160 组合等权设计、相同可观测输入 $Z=\operatorname{sort}(X)/\bar X$ 下，一个独立筛选并在 16,000 个未触及样本上确认的灵活经验规则将 $J_1$ 降至 0.5618，低于同确认集上论文 MLP 的 0.5827。这说明当前 MLP 与 L6 的差距不能全归因于网络能力，也不能全解释为不可获得的完美信息。
- 较灵活的 $Z$-only 规则实际风险更低，但对 L6 偏移量的精确命中率并未更高（0.2178 vs 0.2301）。因此，损失曲线预测应以所选偏移量的实际风险评价，不应把是否命中事后最优格点当作唯一目标。

## 不能主张什么

- 不声称 $\delta=0.1$ 在任意参数空间、任意损失或任意样本量下全局最优。
- 不把 L3–L6 写成真参数未知时可直接使用的方法。
- 不把当前离散留出结果写成连续参数空间的普遍泛化。
- 不声称对未训练样本量可以直接使用。当前方法按 $n$ 训练独立网络，只定义于 $n\in\{7,10,15,20\}$。
- 不把有限的整体尺度检查扩大为对任意参数分布、任意单位定义或任意数值环境的普遍保证。
- 不把 $Z$-only 经验参照称为精确 Bayes 风险或严格有限样本界；它只是一个已实现规则在确认集上的风险估计。
- 不把 $Z$-only 经验参照到 L6 的剩余差距全部称为完美信息差；其中仍混合了进一步的模型、样本和不可观测信息影响。
- 不声称神经网络直接提高 MDM 的参数计算能力；它只选择 $\delta$。
- 不把 Direct-MLP、E6 Dimensional-RAW、旧特征路线或 NIST 案例作为本文主结果。E6 只说明在固定 $\eta=1000$ 与当前单位中保留绝对尺度可将 $J_1$ 降至 0.5543，不改变正式方法的选择。
- 不把参数 $J_1$ 的改善预先等同于可靠度寿命改善。
- 不声称初步参数估计可以直接代替真参数恢复 L3–L5 收益：利用初估参数选择偏移量的负向实验（C9/C11）显示总体失败且迭代更差，只作为本文转向直接预测样本级损失曲线的比较依据。
- 不把"初估噪声导致错误路由"当作已被证明的唯一机制：邻近 $\beta$ 网格单元正确率与初估误差—损失关联仅与该解释一致（C12）。
- 不把 E11 的数值相关写成闭式因果分解：它说明梯度曲线、默认位置估计和低风险偏移量在 20 个预设单元内共同变化，但未穷举全部 160 个单元，也未推导连续参数域中的解析关系。

## 指标边界

单样本损失为

$$
\ell_i=\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2+
\left(\frac{\hat\gamma_i-\gamma_i}{\eta_i}\right)^2,
$$

主指标为

$$
J_1=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\ell_i}.
$$

$J_1$ 是本文统一使用的评价准则，不是新提出的估计方法。正文同时报告每参数 Bias/RMSE、失败率和按 $n$ 结果，以防一个汇总指标掩盖局部问题。

可靠度寿命 $x_R$ 满足 $P(T>x_R)=R$，因此

$$
x_R=\gamma+\eta[-\ln(R)]^{1/\beta},
$$

其中 $x_{0.95}$ 为主，$x_{0.90}$ 和 $x_{0.99}$ 为补充；下标表示可靠度而非累积分布概率。各可靠度寿命只从同一组三参数估计派生，不训练直接预测 $x_R$ 的网络。
