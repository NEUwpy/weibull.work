# 执行合同

## 1. 数据合同

### 1.1 固定参数组

正式计算源使用：

\[
(\beta,\eta,\gamma/\eta)=(2,1,1),\qquad n\in\{7,10,20\}.
\]

每个 `n` 使用正式 seed namespace 下的 `repeat_id=0...999`，共 3000 个样本。所有方法必须共享同一个样本对象或同一个确定性重建结果，不得按方法重新抽样。

### 1.2 展示尺度

汇报表展示：

\[
(\beta,\eta,\gamma)=(2,1000,1000).
\]

默认在归一化尺度完成公平计算，再将样本、`eta_hat` 和 `gamma_hat` 乘 1000；`beta_hat` 不变。执行者须用预先选定的少量 repeat 对四种新增方法做双尺度复算，验证实现层面的尺度转换误差并记录容差。若某方法不满足预设容差，不得直接变换其结果，必须改为在 1000 尺度运行并报告偏离。

### 1.3 复用源

- `artifacts/formal/shared_data/mc_scan_raw.csv`
- `artifacts/formal/E3b_vector_mlp/vector_mlp_results.csv`

## 3. 评价合同

### 3.1 单样本误差

\[
e_{\beta i}=\frac{\hat\beta_i-\beta}{\beta},\qquad
e_{\eta i}=\frac{\hat\eta_i-\eta}{\eta},\qquad
e_{\gamma i}=\frac{\hat\gamma_i-\gamma}{\eta}.
\]

\[
L_i=e_{\beta i}^2+e_{\eta i}^2+e_{\gamma i}^2.
\]

### 3.2 总表指标

在 3000 个样本上先汇总平方误差，再统一开平方：

\[
J_1=\sqrt{\frac{1}{3000}\sum_iL_i}.
\]

\[
RMSE_k=\sqrt{\frac{1}{3000}\sum_i e_{ki}^2},
\quad k\in\{\beta,\eta,\gamma\}.
\]

禁止先计算三个 `n` 的 J1 或 RMSE 再做算术平均。

### 3.3 失败

- 非有限参数、违反方法定义域、显式失败状态或抛出异常均记为失败。
- 分表的描述统计只对有限成功估计计算，同时必须列出 `成功数/1000` 和失败率。
- 总表不得通过只统计成功样本使高失败方法获得虚假优势。执行者应复用 Study01 现有正式失败惩罚口径；若无法无歧义复用，停止总表 J1 排名并在报告中提出单一待决问题，不得自行发明有利于某方法的惩罚。
- **本固定参数组合 (β=2,η=1000,γ=1000) 的失败惩罚约定**：方法失败时 runner 返回 `converged=False`且估计值为 `None`（或带有 `raw_status` 如 `unbounded`）。为计算总表 J₁ 与 RMSE，评价层将此类失败统一按零估计 (β̂=η̂=γ̂=0) 处理。按合同 §3.1 的标准化误差公式，零估计对应 e_β=-1, e_η=-1, e_γ=-1，因此 L_i=3.0。该 L_i 计入总表分子求和，分母始终为 n_total=3000。此约定仅适用于本参数组，不承诺迁移到其他真参数组合。

## 6. 执行与停止条件

- 使用方法 × n 检查点，支持安全续跑；已完成且哈希匹配的单元不得无理由重算。
- 正常开发、测试、运行和分析过程中不设置中途人工审核点，连续完成后统一交付。
- 仅在样本键无法对齐、正式缓存来源冲突、方法身份回退、必须覆盖封存证据、或失败惩罚合同无法确定时停止。
- 某方法科学上表现差或失败率高不是停止理由；应忠实记录。
