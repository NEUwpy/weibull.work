# 神经网络验证输入输出与数据集详情

> 日期：2026-07-19
> 状态：PILOT_ONLY 方法详情
> 用途：集中说明“样本特征选取与样本量关系”验证使用的神经网络、输入、输出、数据集、训练切分和评价流程。前两份文档负责研究问题与结果解释，本文件负责可复核的方法细节。

## 一、一句话说明

本验证复用 Study01 Formal E3b 的三参数 Weibull 模拟样本和逐样本26点真实损失曲线，使用 `scikit-learn MLPRegressor` 构建全连接 Vector-MLP，以样本可观测信息为输入、26个候选 delta 的损失曲线为输出，再选择预测损失最小的 delta。

```text
一个样本的可观测信息
  -> Vector-MLP
  -> 26个候选delta的预测损失
  -> argmin
  -> 当前样本的选择delta
```

## 二、使用的神经网络

| 项目 | 设置 |
|------|------|
| 实现 | `sklearn.neural_network.MLPRegressor` |
| 类型 | 全连接前馈、26维向量输出的 Vector-MLP |
| 隐藏层 | `(256, 128, 64)` |
| 激活函数 | ReLU |
| 优化器 | Adam |
| 训练损失 | 26维标准化目标上的平方误差（MSE） |
| 初始学习率 | `1e-3` |
| L2正则化 | `alpha=1e-4` |
| batch size | 256 |
| 最大迭代 | 300 |
| early stopping | 开启 |
| 内部验证比例 | 15%，只从训练折中划分 |
| 提前停止条件 | 连续20轮无改善 |
| pilot训练seed | 42 |

模型配置直接复用 Formal E3b 的 `train_vector_mlp()`，没有为了本次输入表示比较单独调参。实际实现见 `../code/run_E3b_vector_mlp.py`；pilot调用见 `../code/run_input_representation_pilot.py`。

## 三、数据集是什么

这不是公开数据集，也不是真实工程数据，而是 Study01 正式蒙特卡洛实验生成并缓存的三参数 Weibull 模拟数据。

### 3.1 参数网格

| 项目 | 取值 |
|------|------|
| 形状参数 `beta` | 1.5、2.0、2.5、4.0、5.0 |
| 尺度参数 `eta` | 1.0 |
| 位置尺度比 `gamma/eta` | 0.1、0.5、1.0 |
| 样本量 `n` | 7、10、20 |
| 设计组合数 | `5 × 1 × 3 × 3 = 45` |
| 每个组合重复 | 1,000次 |
| 样本总数 | 45,000 |
| delta候选集 | 0.00至0.50，间隔0.02，共26点 |

每一行对应一个独立模拟样本，由 `(beta, eta, gamma/eta, n, repeat_id)` 和正式 seed namespace 确定性重建。

### 3.2 两个输入缓存

| 文件 | 行数 | 内容 |
|------|-----:|------|
| `../artifacts/formal/E3b_vector_mlp/sample_features.csv` | 45,000 | 样本键、真实参数及由原始样本计算的13个候选统计特征 |
| `../artifacts/formal/E3b_vector_mlp/risk_curves.csv` | 45,000 | 同一样本在26个 delta 下的真实参数估计损失 `loss_d0.0` 至 `loss_d0.5` |

pilot按照 `(beta, gamma/eta, n, repeat_id)` 一对一合并两个缓存。真实参数列只用于样本对齐、生成监督标签和最终评价，不进入模型输入。

## 四、训练集和测试集怎样划分

本次小验证只使用 Formal E3b 既有的 `combo_fold_1` 和训练seed 42：

| 数据 | 参数组合 | 样本数 | 各样本量数量 |
|------|---------:|-------:|---------------:|
| 训练集 | 36 | 36,000 | `n=7/10/20` 各12,000 |
| 测试集 | 9 | 9,000 | `n=7/10/20` 各3,000 |

留出的9个完整 `(beta, gamma/eta, n)` 组合为：

| n | 留出 `(beta, gamma/eta)` |
|---:|--------------------------|
| 7 | `(1.5,0.1)`、`(2.0,1.0)`、`(4.0,0.5)` |
| 10 | `(2.0,0.1)`、`(2.5,1.0)`、`(5.0,0.5)` |
| 20 | `(1.5,0.5)`、`(2.5,0.1)`、`(4.0,1.0)` |

因此测试样本不是从训练组合中随机抽出的重复样本，而是来自完整留出的参数组合。该设计检验 existing-grid 组合留出表现，但不是连续参数空间或真实数据泛化。

## 五、输入具体是什么

### 5.1 当前13个统计特征

| 类别 | 输入字段 | 处理 |
|------|----------|------|
| 位置、尺度与分位数 | `x_min, x_max, range, Q1, Med, Q3, IQR, x_bar, s` | 只使用训练折均值和标准差做z-score |
| 样本量与无量纲形状信息 | `n, CV, g1, g2` | 原值输入 |

其中：

- `CV` 为变异系数；
- `g1` 为偏度；
- `g2` 为峰度；
- 输入中不包含 `beta、eta、gamma、gamma/eta、repeat_id、seed、delta`。

### 5.2 去掉显式n的12特征输入

从上述13特征中只删除 `n`，其余字段和预处理不变，用于检查统计特征本身是否已经携带样本量相关的抽样波动信息。

### 5.3 排序原始样本输入

为使 `n=7/10/20` 能进入同一个普通MLP，原始样本表示为：

```text
20个排序观测位置 + 20个有效位置mask + n = 41维
```

具体处理为：

1. 按正式seed机制重建每个原始样本并升序排列；
2. 只用全部训练观测值计算一个均值和标准差，完成z-score；
3. 右侧padding至20个位置；
4. 用20维mask区分真实观测和padding；
5. 额外输入样本量 `n`。

排序用于消除原始观测顺序的任意性。该方案只代表一种简单、可审计的原始样本MLP输入，不代表DeepSets等所有集合网络。

### 5.4 分样本量专用模型输入

分别为 `n=7、10、20` 训练三个模型。每个模型使用相应样本量的12个不含 `n` 的统计特征，并只用本模型训练数据计算z-score参数；测试时根据已知 `n` 路由到对应模型。

## 六、输出具体是什么

模型不直接输出一个delta，而是输出26维预测损失曲线：

```text
[L_hat(0.00), L_hat(0.02), ..., L_hat(0.50)]
```

对于第 `i` 个样本和候选delta，监督标签为：

```text
loss_i(delta)
= ((beta_hat-beta)/beta)^2
+ ((eta_hat-eta)/eta)^2
+ ((gamma_hat-gamma)/eta)^2
```

其中 `beta_hat、eta_hat、gamma_hat` 是使用该delta进行MDM估计得到的结果。训练时使用训练折的26维标签分别进行标准化；预测后还原到真实损失尺度，并将数值截断为非负。

真实 `beta、eta、gamma` 在模拟训练阶段用于构造监督标签，但部署时不可见，也不进入模型输入。

## 七、怎样从输出得到delta

对每个测试样本：

1. 网络预测26点损失曲线；
2. 选择预测损失最小点的下标；
3. 将该下标映射到对应delta；
4. 从该样本的真实风险曲线读取所选点的真实损失；
5. 在测试集上聚合：

```text
J1 = sqrt(mean_i true_loss_i(selected_delta_i))
```

网络训练MSE评价“26点风险曲线拟合得怎样”，selected `J1`评价“最终选出的delta实际表现怎样”，二者不是同一个指标。本调研以selected `J1`作为输入表示比较的主要结果。

## 八、四种验证方案的唯一差别

| 方案 | 模型数量 | 输入维度 | 训练样本 | 测试样本 | 目的 |
|------|---------:|---------:|---------:|---------:|------|
| 统一13特征 | 1 | 13 | 36,000 | 9,000 | 当前方案 |
| 统一12特征去n | 1 | 12 | 36,000 | 9,000 | 检查显式n的增量作用 |
| 三个按n专用模型 | 3 | 各12 | 各12,000 | 各3,000 | 检查联合训练是否负迁移 |
| 排序原始样本 | 1 | 41 | 36,000 | 9,000 | 检查当前统计特征是否明显损失选择信息 |

除输入表示或训练组织方式外，各方案使用相同的26维监督目标、组合留出、seed、MLP隐藏层、训练设置和selected `J1`评价。

## 九、证据边界

- 可以说：这是在同一模拟数据、同一组合留出和同一Vector-MLP配置下进行的输入表示敏感性比较。
- 可以说：模型输入均为样本可观测信息，真参数只用于模拟监督标签和评价。
- 不能说：该数据集代表真实工程样本。
- 不能说：一折一seed结果证明统计特征或联合训练普遍最优。
- 不能说：当前排序/padding MLP代表所有原始样本神经网络结构。
