# 样本特征选取与样本量关系

> 本目录是 Study01 的专题调研记录，用于回答神经网络输入表示、样本量信息与训练组织方式之间的关系。当前结果均为组会前 pilot，不自动升级为正式 E3/E4 证据。

## 调研问题

1. 为什么当前模型使用统计特征，而不是直接输入原始样本？
2. 统计特征能否保留完成 delta 选择所需的信息？
3. 统计特征是否会掩盖小样本参数估计更困难的事实？
4. 显式输入样本量 `n` 是否必要？
5. 联合训练 `n=7/10/20` 是否会拖累某个固定样本量，是否应改为分样本量专用模型？

## 文档顺序

| 文档 | 内容 |
|------|------|
| `01-原始样本与统计特征输入验证.md` | 比较13特征、去掉 `n` 的12特征与排序原始样本输入；解释为什么特征没有抹掉小样本差异 |
| `02-联合样本量与分样本量训练验证.md` | 比较统一模型与按 `n` 分别训练的三个专用模型，检查跨样本量负迁移 |
| `03-神经网络验证输入输出与数据集详情.md` | 集中记录Vector-MLP实现、四种输入、26维输出、模拟数据集、组合留出、预处理、训练与评价流程 |

前置文献与候选变量依据仍保留在上一级 `调研-NN输入特征/`。该目录回答“为什么这些统计量具有候选合理性”；本目录进一步回答“这些特征在当前 delta 风险曲线任务中表现如何，以及它们与样本量的关系”。

## 当前总判断

- 一种排序原始样本表示没有显示出相对统计特征的精度优势；
- 三种输入均保留了 `n=7` 误差较高、`n=20` 误差较低的规律；
- 去掉显式 `n` 后本次结果没有变差，但不足以修改正式13特征方案；
- 在相同12特征的比较中，联合模型在三个样本量上均略优于专用模型，本次未观察到跨样本量负迁移；
- 以上均是一折一 seed 的 pilot，正式论文结论需多折多seed确认。
