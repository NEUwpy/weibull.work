# Study01 联合样本量与分样本量训练验证

> 日期：2026-07-19
> 状态：PILOT_ONLY
> 用途：回答“联合使用 `n=7/10/20` 训练，是否会降低某一固定样本量、尤其 `n=20` 的选择精度”。不升级 E3/E4 正式证据。

## 一、问题

当前 Vector-MLP 将 `n=7/10/20` 的样本联合训练。因为样本量在部署时必然已知，另一种可行方案是分别训练三个模型，再根据当前 `n` 调用相应模型。

需要检验：联合训练带来的共享学习收益，是否会被不同样本量之间的任务冲突抵消，即是否出现跨样本量负迁移。

## 二、比较合同

主比较只改变训练组织方式：

| 项目 | 联合模型 | 分样本量专用模型 |
|------|----------|------------------|
| 输入 | 相同的12个统计特征，不含 `n` | 相同的12个统计特征，不含 `n` |
| 模型 | 一个 MLP | `n=7/10/20` 各一个 MLP |
| 训练数据 | 三个 `n` 合计36,000条 | 每个模型12,000条，合计36,000条 |
| 测试数据 | 9,000条，按 `n` 分层报告 | 每个模型3,000条，按已知 `n` 路由，合计9,000条 |
| 切分与标签 | `combo_fold_1`、seed 42、相同26点损失曲线 | 完全相同 |
| 评价 | 真实 selected `J1` | 完全相同 |

每个专用模型只使用相应样本量的训练数据计算特征标准化参数。该设计对应自然部署方案，但三个专用模型的总参数量约为统一模型的三倍，因此不是严格的参数量控制实验。

同时报告当前13特征统一模型，帮助判断现有方案；但它包含显式 `n`，不能替代上述12特征的干净主比较。

## 三、结果

`J1` 越低越好。

| 训练方案 | pooled J1 | n=7 | n=10 | n=20 |
|----------|----------:|----:|-----:|-----:|
| 统一13特征（含 `n`，当前方案） | 0.530403 | 0.615673 | 0.563518 | 0.383896 |
| 统一12特征（不含 `n`） | **0.524485** | **0.611602** | **0.553986** | **0.379865** |
| 三个12特征专用模型 | 0.531443 | 0.624057 | 0.559222 | 0.380943 |

主比较中，专用模型相对统一12特征模型：

| 指标 | 专用模型相对变化 |
|------|-----------------:|
| pooled J1 | +1.33% |
| n=7 | +2.04% |
| n=10 | +0.95% |
| n=20 | +0.28% |

三个变化均为正，即专用模型误差更高。本 pilot 没有观察到联合训练拖累某一样本量；联合模型反而在三个 `n` 上都略好，其中 `n=20` 的差距很小。

若把专用模型与当前13特征模型比较，专用模型在 `n=10/20` 分别略好约0.76%和0.77%，在 `n=7` 略差约1.36%，pooled略差约0.20%。但该比较同时改变了训练组织方式和是否输入 `n`，不能据此认定“单独训练 `n=20` 更好”。

## 四、怎样解释

联合训练不必然降低固定样本量的精度。三个样本量虽然抽样波动不同，但“样本分布特征到26点风险曲线”的映射仍可能共享大量位置、尺度和形状规律。联合训练提供更多跨条件样本，可能起到多任务共享与正则化作用。

专用模型的任务更单纯，但每个模型只看到12,000条训练样本，且只能从该样本量的12个训练参数组合中学习。统一模型则看到36,000条样本和36个训练组合，可能更有利于学习共同结构。因此“专用模型更聚焦”和“统一模型数据更多、共享更充分”是相反作用，必须由留出结果判断。

本次结果只说明：**在当前一折一 seed、当前网络与特征下，没有发现跨样本量负迁移；不存在证据支持为了保护 `n=20` 精度而立即拆成三个模型。**

## 五、与“小样本误差更大”的关系

联合训练是否负迁移，与小样本参数估计是否更困难是两个问题。

- 三种训练方案均显示 `n=7` 的最终 `J1` 最高、`n=20` 最低，说明小样本固有困难仍然存在。
- 联合模型在各层都略优于专用模型，说明本次小样本高误差不是由联合训练造成的，而主要来自小样本本身的信息不足。
- 模型的职责是为给定样本选择更合适的 delta，不可能消除由样本量决定的全部参数估计不确定性。

## 六、组会可直接回答

> 我专门比较了联合训练和按样本量分别训练。为了只检验训练组织方式，两边都使用不含 n 的同一组12个特征、相同网络、组合留出、seed和26点风险曲线标签。结果联合模型在 n=7、10、20 下的 J1 分别是0.6116、0.5540、0.3799；三个专用模型分别是0.6241、0.5592、0.3809。也就是说，本次没有看到 n=7和10拖累 n=20，联合模型在三个样本量上都略好。但这只是一折一 seed，且三个专用模型总参数量更大，正式结论仍需要多折多seed验证。

## 七、证据边界与后续

当前结论为 `CAUTION`，不能表述为“联合训练已被证明普遍优于专用模型”。主要限制：

1. 只有一折一 seed，没有折间、seed间变异和预设等效界值；
2. 专用方案总参数量约为统一方案三倍，模型容量没有严格匹配；
3. 当前只覆盖 `n=7/10/20`，不能推出对其他样本量仍可共享；
4. 当前比较的是 selected `J1`，没有将风险曲线预测误差作为独立主结论；
5. 结果是在同一模拟参数网格的 existing-grid组合留出上获得，不是连续空间或真实数据泛化。

若论文需要正式决定统一模型还是专用模型，应将本比较扩展到5折×3 seeds，并预先报告 pooled与按 `n` 的 `J1`。若专用模型只在个别 `n` 略好，还需结合维护三个模型的复杂度判断实际意义。

## 八、统计解释与谬误检查

- Overall Confidence: CAUTION。
- Reproducibility: PARTIALLY_REPRODUCIBLE。统一模型指标与前次同代码同seed运行精确一致；新增加的三个专用模型尚未独立复跑。
- Fallacy Scan: 11/11 checked。

| 检查项 | 结论 |
|--------|------|
| Simpson's paradox | pooled与三个分层方向一致：统一12特征均更低；仍同时报告分层，未以pooled替代各层。 |
| Ecological fallacy | 未从组均值推断每个单独样本必然受益。 |
| Berkson's paradox | 无结果筛选入组；限于预定模拟网格。 |
| Collider bias | 未增加回归控制变量。 |
| Base-rate neglect | 不涉及诊断率。 |
| Regression to the mean | 未依据极端表现选择比较组。 |
| Survivorship bias | 所有训练/测试键完整路由，无失访。 |
| Look-elsewhere effect | 同时报告全部三个样本量和pooled结果，没有只选择有利组。 |
| Garden of forking paths | CAUTION：专用模型的容量、缩放和网络选择仍有自由度，正式比较需预冻结。 |
| Correlation != causation | 这是受控训练方案比较；不把单一特征解释为因果机制。 |
| Reverse causality | 不适用于模拟输入到风险曲线的预测合同。 |
