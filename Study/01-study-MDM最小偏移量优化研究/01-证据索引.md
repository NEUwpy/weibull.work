## 正式代码计划

正式代码建议放在：

```text
Study/01-study-MDM最小偏移量优化研究/code/
```

建议模块：

| 模块 | 责任 |
|------|------|
| `config.py` | 参数网格、delta grid、seed、输出路径 |
| `metrics.py` | `loss_i`、`J_param`、`Bias/SD/RMSE`、`x_R`、`RMSE_xR` |
| `sampler.py` | 调用共享采样函数并记录 seed |
| `run_mdm_grid.py` | 正式 MDM delta grid 扫描 |
| `run_baselines.py` | MDM/MLE/LSE/其他方法基线比较 |
| `layers.py` | L0-L5 层级聚合和 oracle 计算 |
| `deployable_rules.py` | 自迭代、外部 beta 估计、查表和 fallback |
| `features.py` | 样本可观测特征提取 |
| `train_offset_model.py` | hard label / risk curve 模型训练 |
| `summarize.py` | 生成 summary、tables、figures 所需汇总 |

正式代码必须调用当前生产实现或共享流水线：

- `python/methods/mdm.py`
- `python/studies/common/sample.py`
- `python/studies/common/metrics.py`

旧 `docs/research/04.../程序` 可参考，但不得作为正式代码入口。
