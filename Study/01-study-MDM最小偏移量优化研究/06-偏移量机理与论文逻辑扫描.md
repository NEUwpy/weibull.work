# AMDM 机制解释与证据缺口

2026-09-08 规划审阅稿。现有机制来自[S01-01](02-实验配置.md#s01-01)、[S01-03](02-实验配置.md#s01-03)、[S01-05](02-实验配置.md#s01-05)，本轮未新增分析。

## 怎么论述

给定样本X，MDM对候选位置计算条件形状与尺度，形成三参数候选解路径。δ改变位置搜索判据的落点，三个参数随之共同变化；它控制的是搜索规则中的调节水平。

固定参数只规定抽样分布。不同样本的次序统计量、间距和相对位置不同，对应的廓线、梯度和候选损失也不同。固定δ使用相同判据水平，但选出的参数值本来就随样本变化；不能把固定偏移说成所有样本选同一个位置。

现有固定δ分解表明，从0到0.1时，条件方差下降超过偏差平方增加；更大δ可能使偏差代价占优。这个经验关系解释为何需要平衡，不意味着每条曲线或AMDM都必然更稳定。

AMDM以归一化样本预测候选损失并选择δ，再由MDM给出参数。样本路径用于解释结果；现网络不直接观察轨迹，也不闭环迭代。损失曲线预测近似给定可观测输入下、当前设计分布中的候选风险，不恢复真参数已知的逐样本最优。

## 哪些已经成立，哪些还没有

| 问题 | 已有证据 | 待补/解释边界 |
|---|---|---|
| 固定调节改变风险 | S01-01条件偏差—方差 | 不把数值稳定性、抽样SD和初始化波动混同 |
| 参数条件影响低风险δ | S01-02窗口、S01-03条件规则 | 域依赖不自动给出任意域的最佳δ |
| 同条件样本路径不同 | S01-05a；现图7与附图F4 | 路径差异是随机性，不是原MDM算法错误 |
| AMDM整体有收益 | S01-04旧折外改善7.27% | 125/160改善；新独立确认未做 |
| 实际AMDM点是否匹配当前路径 | 有折外记录与机制数据 | 现图7画固定点/L6点，缺实际AMDM点；P01连接验证 |
| 收益是否来自同条件的匹配 | 现有相关、选点差异支持动机 | 尚无严格贡献分解；若需要可审议条件内打乱诊断 |
| 是否保持稳定性 | 已有RMSE/失败记录和固定δ的SD | P02/P03需AMDM单元内Bias/SD及尾部比较 |

L5使用真参数条件的平均风险，L6查看当前样本全部真实损失。L5→L6同时涉及事后信息，不能说这段差距全可学习。AMDM与L5的现有评价划分不同，数值接近只可描述，不能写成获得L5收益后再叠加样本收益。
