## 一句话论证

在当前设计域中，经验偏移量 $\delta=0.1$ 已接近最佳统一常数，但逐样本仍有明显选择空间；以均值归一化的排序样本预测候选偏移量的损失曲线，可以在不改变 MDM 参数估计过程的情况下进一步降低三参数联合估计误差，并使整体缩放不改变所选偏移量、MDM 参数估计按尺度等变。

## 核心研究问题

在三参数 Weibull 小样本 MDM 估计中，偏移量 $\delta$ 如何影响有限样本估计风险，其合理取值受哪些因素决定，以及在总体参数未知时能否仅依据观测样本实现有效选择。

## 论证链

```text
正偏移量改善有限样本稳定性，但取值依赖经验
  -> 先用统一指标比较不同 delta
  -> 统一常数收益很小，参数条件平均与逐样本事后选择显示偏移量并非固定不变
  -> 直接 plug-in：把初步参数估计当作真参数沿用 L3–L5 规则
       —— 被检验且总体失败（全部单步变体劣于 Default，仅 beta=1.5 例外）
  -> 真参数和事后结果在应用中不可得
  -> 将排序样本除以其均值，再预测整条候选损失曲线
  -> 由 MDM 在选定 delta 下完成参数估计
  -> 主结果显示精度改善且训练稳定
  -> 区分参数条件、当前样本和事后完全损失所带来的风险差异
  -> 用参数留出、传统方法和可靠度寿命补充可信性
  -> 最后补充域匹配的真实案例（尚未完成）
  -> 讨论结果含义、有效原因、边界与实际价值
```

## 第一部分 引言

### 要回答的问题

为什么在已有正偏移量方案的基础上，还需要研究偏移量怎样选择？

### 叙事顺序

1. 三参数 Weibull 分布在寿命和可靠性分析中的作用。
2. 前期 MDM 工作及正偏移量的来源。
3. 经验设定的不足：正偏移量有助于稳定估计，但不同 $\delta$ 也会产生不同估计误差。
4. 研究缺口：尚不清楚偏移量如何影响有限样本风险、合理取值受哪些因素决定，以及总体参数未知时能否仅根据观测样本实现有效选择。
5. 本文做法：先界定从统一规则到逐样本选择的潜在收益，再用当前样本预测候选损失曲线。
6. 贡献概括：
   - 统一评价不同偏移量选择规则；
   - 量化不同信息下可以获得的精度收益；
   - 提出以均值归一化排序样本为输入的样本自适应选择方法；
   - 用未见形状参数、多初始化、尺度等变、传统方法和可靠度寿命检查说明结果的可信程度与适用边界。

### 建议开头表述

> 前期研究通过在三参数 Weibull MDM 的位置参数搜索判据中引入正偏移量，改善了有限样本下估计的稳定性，但偏移量仍主要依靠经验设定。不同偏移量会改变有限样本估计风险，因此有必要考察其合理取值受哪些因素影响，以及总体参数未知时能否仅依据观测样本实现有效选择。

## 第二部分 方法

### 2.1 MDM 与偏移量

#### 目的

用与 MDM 原文一致的符号说明 $\delta$ 在判据中的位置、为什么需要正偏移量，以及它不会改变最终三参数估计任务。

#### 必须包含

- 三参数 Weibull 分布与参数含义；
- MDM 原始判据、搜索变量和估计步骤；
- 正偏移量版本的定义；
- 前作为什么使用 $\delta=0.1$；
- 本文只研究 $\delta$ 的选择，不改写 MDM 的其他部分。

公式和术语以 182-030、182-046 原文为准，正文写作前逐式核对。

### 2.2 如何评价偏移量

#### 目的

把“偏移量好不好”变成可比较的问题，并区分可执行规则与信息参照。

#### 内容

1. 定义单样本三参数联合损失 $\ell_i$ 与汇总 $J_1$。
2. 说明 $J_1$ 由三个参数的标准化平方误差汇总得到，数值越小表示联合估计误差越小。
3. 定义 Default、L1–L6：

| 层级 | 信息 | 论文中的角色 |
|---|---|---|
| Default | 固定 $\delta=0.1$ | 经验基线 |
| L1 | 全局 | 最佳统一常数 |
| L2 | $n$ | 简单可执行规则 |
| L3 | $\beta$ | oracle 参照 |
| L4 | $\beta,n$ | oracle 参照 |
| L5 | $\beta,\gamma/\eta,n$ | 参数条件下的平均低风险参照 |
| L6 | 真参数与当前样本的 26 点已实现损失 | 逐样本事后参照 |

4. 说明 L1–L5 选点和评价分离；L6 不训练，也不是可部署上限。

### 2.4 利用初估参数选择偏移量（负向验证，方法一段）

正文用一段说明：先以固定 $\delta=0.1$ 的 MDM 或 WMLE 得到初步 $\hat\beta,\hat\eta,\hat\gamma$，再把这些估计当作真参数去查询 L3–L5 对应的条件均值损失曲线并选择 $\delta$。条件集与 L3–L5 相同（仅 $\beta$；$\beta,n$；$\beta,\gamma/\eta,n$），查询方式为就近网格点或对损失曲线连续插值；曲线只用训练折构成。迭代（用新估计重选）在偏移量不变、循环或 10 次更新时停止。本检验只量化“用估计代替真值”损失多少收益，提供负向参照，不与 MLP 排名。

### 2.5 样本自适应选择

#### 目的

说明如何在真参数未知时，仅凭当前样本选择 $\delta$。

#### 输入、网络和输出

对每个样本量训练一个独立 MLP：

$$
Z_n=\frac{\operatorname{sort}(x_1,\ldots,x_n)}{\bar X_n},
$$

$$
Z_n \longrightarrow \operatorname{MLP}_{n}\longrightarrow
\left(\widehat\ell_{\delta_1},\ldots,\widehat\ell_{\delta_{26}}\right),
$$

$$
\hat\delta=\arg\min_{\delta_j}\widehat\ell_{\delta_j},
\qquad
(\hat\beta,\hat\eta,\hat\gamma)=\operatorname{MDM}(X_n;\hat\delta).
$$

- 输入是排序样本除以当前样本均值，不是手工统计特征；
- 每位置 StandardScaler 只在训练折拟合；
- 网络结构为 256–128–64，ReLU，Adam；
- 输出整条 26 点风险曲线，而不是单个 hard label；
- MLP 负责选择，MDM 负责估计。

#### 必需图 1：方法结构图

```text
样本 x1...xn
   -> 排序并除以样本均值
   -> 训练折标准化
   -> per-n MLP (256-128-64)
   -> 26 个候选 delta 的预测损失
   -> argmin
   -> 选定 delta 下运行 MDM
   -> beta_hat, eta_hat, gamma_hat
```

图中明确区分“训练标签来自 Monte Carlo 真值”和“应用时只输入当前样本”，并标出均值归一化与训练折 StandardScaler 是两个不同的步骤。

### 2.6 只使用当前样本的条件风险参照

为区分当前 MLP 的学习差距与 L6 所使用的事后信息，定义只允许观测当前归一化样本 $Z$ 时的理想决策：

$$
\delta_Z^*(Z)=\arg\min_\delta E\{\ell(\delta,X,\theta)\mid Z\}.
$$

正文只解释该决策与 L6 的信息差异。实验不尝试精确计算该条件期望，而是在拟合、模型选择和确认三个不交叠的 repeat 分区上构造较灵活的 $Z$-only 经验参照。候选回归器、数据分区、确认风险、配对 bootstrap 与学习曲线均放入附录 F。

### 3.1 不同信息条件下的偏移量选择

#### 结果顺序

1. 展示 $\delta$ 的整体误差曲线：当前 26 点网格最低点为 $\delta=0.06$（$J_1=0.624518$），$\delta=0.08$ 与其几乎相同（0.624666）；经验值 $\delta=0.1$ 为 0.630409，仅比最低点高约 0.93%，已接近最佳统一常数，但 $\delta=0.12$ 已升至 0.638755，不能再概括为“0.08–0.12 均处于同一平缓区”。
2. 用 L1–L6 表展示信息增加后的 $J_1$：0.6252、0.6230、0.5905、0.5885、0.5813、0.4923。
3. 直接结论：改变统一常数收益有限；按形状参数区分后出现明显改善；L6 展示了逐样本事后选择的低风险结果，但它使用的信息在实际选择时不可得。

## 第四部分 讨论

第四部分承接第三部分，讨论“这些结果说明什么、为什么可能如此、边界在哪里、实际有什么用”，不重复一遍结果表。

### 4.1 不同可用信息下的偏移量选择

本节不再复述 L1—L6，而是把第三部分的结果转化为实际选择规则：

- 若只能采用一个统一偏移量，当前设计内的网格最低点为 $\delta=0.06$，但 $\delta=0.1$ 的 $J_1$ 仅高约 0.9%；前者适合针对当前参数域进行专门设置，后者仍可作为简洁的默认值；
- 样本量 $n$ 在应用时通常已知，但仅按 $n$ 设置固定偏移量相对 $\delta=0.1$ 只改善约 1.2%，相对最佳统一常数的进一步改善不足 0.4%，没有显示出单独维护多套固定规则的明显必要性；
- 真参数未知时，可利用当前均值归一化排序样本预测 26 点损失曲线并选择偏移量；在当前离散设计中，seed 42 主模型相对 $\delta=0.1$ 将汇总 $J_1$ 降低约 7.3%；
- 均值归一化解决了样本整体缩放下的输入一致性；对未训练样本量或超出当前离散参数设计的数据，仍不直接外推 MLP，应保留固定规则或重新训练。

### 4.2 样本信息与偏移量选择

讨论保持诚实、不过度证明：

1. 不同 $\delta$ 对有限样本误差的影响并不相同，形成可学习的样本级损失曲线；
2. 排序后除以样本均值，保留样本内部的相对位置、形状和离散信息，同时移除整体比例；
3. 预测整条损失曲线比直接预测最佳格点保留了候选之间的相对风险信息；
4. 最终仍由 MDM 估计参数，因此方法只改变估计器族中的选择规则。

机制诊断表明，L5 与 L6 的选点只在 12.6% 的确认样本上完全一致，同一参数条件内的 L6 有效偏移量数中位数为 6.09。偏移量选择因此同时受参数条件和有限样本实现影响。灵活 $Z$-only 经验参照的确认风险低于论文 MLP，却没有提高与 L6 偏移量的完全命中率。这一结果支持以实际选择风险而非最佳格点分类准确率作为主要评价。

正偏移量会共同改变三个参数的估计结果，本文通过 $J_1$ 比较不同选择规则下的三参数联合估计误差。

输入表示的讨论只作选择依据和边界说明：E7 中均值与 RMS 归一化的 $J_1$ 几乎相同，选用均值是因为数值略低、定义直接且可精确复现既有 E5 结果。这不是对均值归一化普遍优越性的证明。E6 Dimensional-RAW 在固定 $\eta=1000$ 下的 $J_1=0.5543$ 低于归一化方法，说明绝对水平在该固定尺度设计中包含可利用信息；但它依赖训练单位和尺度，因此只作敏感性对照。

利用初估参数选择偏移量的负结果在讨论中作对比解读：直接 plug-in 总体失败且迭代变差，初步 $\hat\beta$ 正确路由率仅约 17%–20%，与初估噪声导致错误路由的解释一致但不构成唯一机制（连续插值同样失败、误差分层可能与真 $\beta$ 混杂）；这为本文转向直接预测样本级损失曲线提供比较依据，在已检验方案中风险曲线预测获得了 plug-in 未能获得的总体收益。

### 4.3 与传统方法和工程指标的关系

- WMLE 和 LSE 只为当前设计中的三参数联合误差提供外部参照，不参与决定偏移量选择是否成立；
- $J_1$ 与可靠度寿命衡量的问题不同，较低的三参数联合误差不保证每一个 $x_R$ 的误差都更低；
- 当前结果显示参数误差改善向 $x_{0.90}$、$x_{0.95}$ 和 $x_{0.99}$ 的传递有限：前者略差于 Default，后两者仅小幅改善。若实际任务主要关心某一工程量，应直接用该工程量评价方法。

### 4.4 适用边界

- 参数空间和 $\delta$ 均为离散设计，未见参数水平验证不代表连续空间外推；
- 均值归一化与端到端检查支持对整体缩放的等变关系，但检查只覆盖 4 个代表条件与 3 个尺度，不是对所有参数组合或数值环境的穷尽证明；
- 每个 $n$ 独立训练，当前方法只适用于 $n\in\{7,10,15,20\}$；
- L6 是 26 点候选网格内的 hindsight 参照，不是理论最优；
- $Z$-only 参照是已实现规则的确认集风险，不是精确 Bayes 风险，其与 L6 的剩余差距同时包含模型/数据限制和事后信息差；
- 当前没有域匹配的真实数据验证，Monte Carlo 结论不能直接推广到所有工程数据。

## 第五部分 结论

结论只保留四件事：

1. $\delta=0.1$ 已接近最佳统一常数；
2. 偏移量选择既随参数条件改变，也受同一条件内的样本实现影响；
3. seed 42 的 Mean-Normalized-MLP 在当前设计中相对 Default 将 pooled $J_1$ 降低约 7.3%，另外两个预设初始化得到相近结果，且选择器与 MDM 组合后的代表性尺度检查通过；
4. 该收益限于当前离散参数域与已训练样本量，未见 $\beta$ 仅在 pooled 层面保留改善，可靠度寿命传递有限，真实数据仍待验证。
