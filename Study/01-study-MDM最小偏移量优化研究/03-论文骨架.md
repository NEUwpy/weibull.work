## 一句话论证

在当前设计域和组合等权准则下，经验值 $\delta=0.1$ 位于统一取值误差曲线的低值区；以均值归一化的排序样本预测候选损失曲线，可以在不改变 MDM 参数估计过程的情况下进一步降低三个参数的偏差、标准差和均方根误差，并使整体缩放不改变所选偏移量、MDM 参数估计按尺度等变。正偏移量相对于无偏移判据的稳定性作用只作为这一选择问题的前提证据。

## 核心研究问题

在三参数 Weibull 小样本 MDM 估计中，偏移量 $\delta$ 如何影响有限样本估计风险，其合理取值受哪些因素决定，以及在总体参数未知时能否仅依据观测样本实现有效选择。

## 论证链

```text
正偏移量改善有限样本稳定性，但取值依赖经验
  -> 先用参数组合内的重复抽样离散程度验证正偏移量的稳定性作用
  -> 再用统一损失比较不同 delta
  -> 统一常数收益很小，参数条件平均与逐样本事后选择显示偏移量并非固定不变
  -> 直接 plug-in：把初步参数估计当作真参数沿用 L3–L5 规则
       —— 被检验且总体失败（全部单步变体劣于 Default，仅 beta=1.5 例外）
  -> 真参数和事后结果在应用中不可得
  -> 将排序样本除以其均值，再预测整条候选损失曲线
  -> 由 MDM 在选定 delta 下完成参数估计
  -> 主结果用联合损失完成选择，并用逐参数 Bias、SD、RMSE 验证实际改善
  -> 区分参数条件、当前样本和事后完全损失所带来的风险差异
  -> 用参数留出、传统方法和可靠度寿命补充可信性
  -> 最后补充域匹配的真实案例（尚未完成）
  -> 讨论结果含义、有效原因、边界与实际价值
```

## 第二部分 问题定义与方法

### 2.1 MDM 与偏移量

#### 目的

用与 MDM 原文一致的符号说明 $\delta$ 在判据中的位置、为什么需要正偏移量，以及它不会改变最终三参数估计任务。

#### 必须包含

- 三参数 Weibull 分布与参数含义；
- MDM 原始判据、搜索变量和估计步骤；
- 正偏移量版本的定义；
- 前作为什么使用 $\delta=0.1$；
- 本文只研究 $\delta$ 的选择，不改写 MDM 的其他部分。

用一个局部扰动关系连接“正偏移量为什么可能改善有限样本表现”和“为什么还要继续选择偏移量”：写成 $g_X(\gamma)=\bar g_{\theta_0}(\gamma)+\varepsilon_X(\gamma)$，并在 $\bar g_{\theta_0}(\gamma_\delta)=\delta$ 附近给出 $\hat\gamma_\delta-\gamma_\delta\approx-\varepsilon_X(\gamma_\delta)/\bar g_{\theta_0}'(\gamma_\delta)$。正文只据此说明 $\delta$ 同时改变目标交点和抽样扰动的传递，实际优劣仍由有限样本联合风险决定；不另建复杂理论章节。

公式和术语以 182-030、182-046 原文为准，正文写作前逐式核对。

### 2.2 如何评价偏移量

#### 目的

把“偏移量好不好”变成可比较的问题，并区分选择目标、最终评价及信息参照。

$J_1$ 负责把三个参数误差合并成一个可用于选点和训练的标量目标；最终参数效果另用标准化 Bias、SD 和 RMSE 逐项评价。无偏移判据与固定偏移量的稳定性比较，必须先在每个参数组合内根据重复抽样计算 SD，再汇总参数组合分布，不能把不同真值条件的估计值直接混合。

#### 内容

1. 定义单样本三参数联合损失 $\ell_i$ 与汇总 $J_1$。
2. 说明 $J_1$ 由三个参数的标准化平方误差汇总得到，数值越小表示联合估计误差越小。
3. 定义 Default、L1–L6：

| 层级 | 信息 | 论文中的角色 |
|---|---|---|
| Default | 固定 $\delta=0.1$ | 经验基线 |
| L1 | 当前设计全部训练样本 | 统一低风险候选 |
| L2 | $n$ | 简单可执行规则 |
| L3 | $\beta$ | oracle 参照 |
| L4 | $\beta,n$ | oracle 参照 |
| L5 | $\beta,\gamma/\eta,n$ | 参数条件下的平均低风险参照 |
| L6 | 真参数与当前样本的 26 点已实现损失 | 逐样本事后参照 |

4. 说明 L1–L5 选点和评价分离；L6 不训练，是预设网格内的事后参照，不是可部署方法或理论下界。

### 2.5 利用初估参数选择偏移量（负向验证，方法一段）

正文用一段说明：先以固定 $\delta=0.1$ 的 MDM 或 WMLE 得到初步 $\hat\beta,\hat\eta,\hat\gamma$，再把这些估计当作真参数去查询 L3–L5 对应的条件均值损失曲线并选择 $\delta$。条件集与 L3–L5 相同（仅 $\beta$；$\beta,n$；$\beta,\gamma/\eta,n$），查询方式为就近网格点或对损失曲线连续插值；曲线只用训练折构成。迭代（用新估计重选）在偏移量不变、循环或 10 次更新时停止。本检验只量化“用估计代替真值”损失多少收益，提供负向参照，不与 MLP 排名。

### 2.6 样本自适应选择

#### 目的

说明如何在真参数未知时，仅凭当前样本选择 $\delta$。

#### 输入、网络和输出

对每个样本量训练一个独立 MLP：

$$
Z_n=\frac{\operatorname{sort}(x_1,\ldots,x_n)}{\bar X_n},
$$

$$
Z_n \longrightarrow \operatorname{MLP}_{n}\longrightarrow
\left(\widehat\ell_{\delta_1},\ldots,\widehat\ell_{\delta_{26}}\right),
$$

$$
\hat\delta=\arg\min_{\delta_j}\widehat\ell_{\delta_j},
\qquad
(\hat\beta,\hat\eta,\hat\gamma)=\operatorname{MDM}(X_n;\hat\delta).
$$

- 输入是排序样本除以当前样本均值，不是手工统计特征；
- 每位置 StandardScaler 只在训练折拟合；
- 网络结构为 256–128–64，ReLU，Adam；
- 输出整条 26 点风险曲线，而不是单个 hard label；
- MLP 负责选择，MDM 负责估计。

#### 必需图 2：方法结构图

```text
样本 x1...xn
   -> 排序并除以样本均值
   -> 训练折标准化
   -> per-n MLP (256-128-64)
   -> 26 个候选 delta 的预测损失
   -> argmin
   -> 选定 delta 下运行 MDM
   -> beta_hat, eta_hat, gamma_hat
```

图中明确区分“训练标签来自 Monte Carlo 真值”和“应用时只输入当前样本”，并标出均值归一化与训练折 StandardScaler 是两个不同的步骤。

### 2.7 只使用当前样本的条件风险参照

为区分当前 MLP 的学习差距与 L6 所使用的事后信息，定义只允许观测当前归一化样本 $Z$ 时的理想决策：

$$
\delta_Z^*(Z)=\arg\min_\delta E\{\ell(\delta,X,\theta)\mid Z\}.
$$

正文只解释该决策与 L6 的信息差异。实验不尝试精确计算该条件期望，而是在拟合、模型选择和确认三个不交叠的 repeat 分区上构造较灵活的 $Z$-only 经验参照。候选回归器、数据分区、确认风险、配对 bootstrap 与学习曲线均放入附录 F。

### 2.8 样本实现的机制诊断

用 MDM 的经验梯度曲线回答“同一参数条件下为什么低风险偏移量仍随样本改变”。预先选取参数域四角与中心的 5 个 $(\beta,\gamma/\eta)$ 位置，与 4 个样本量交叉，共 20 个参数单元；每单元使用未参与训练和选模的 100 个确认样本。复用 26 点损失扫描，每个样本只重建一条 $g_X(\gamma)=\partial\sigma_{\min,X}(\gamma)/\partial\gamma$ 轨迹。正文报告 $g_X(0)$、固定 $\delta=0.1$ 下的 $\hat\gamma_{0.1}/\eta$ 与 L6 偏移量的单元内关系；完整逐样本表和边界比例放入附录 F。

## 第三部分 结果
### 3.1 不同信息条件下的偏移量选择

#### 结果顺序

1. 以固定 $\delta=0.1$ 为经验基准，先报告 L1/L2：当前设计内改变统一取值或只按 $n$ 查表，改善较小。
2. 再报告 L3–L5：加入真值 $\beta$、$n$ 和 $\gamma/\eta$ 后 $J_1$ 依次为 0.5905、0.5885 和 0.5813，说明平均损失曲线随参数条件改变。不宣称已单独证明参数间的统计交互作用。

本节不再复述 L1—L6，而是把第三部分的结果转化为实际选择规则：

- 图 1 已完成“为什么采用正偏移量”的前提验证，本节不再展开 $\delta=0$；后续讨论从固定 $\delta=0.1$ 出发，说明统一设置、按已知样本量设置和样本自适应选择各自适用的条件；
- 若只能采用一个统一偏移量，其取值应对应预期的参数范围、样本量构成和条件权重。当前设计内的描述性网格最低点为 $\delta=0.06$，但 $\delta=0.1$ 的 $J_1$ 仅高约 0.9%；这说明重新优化一个固定常数改善较小，不将 $0.06$ 写成通用推荐；
- 样本量 $n$ 在应用时通常已知，但仅按 $n$ 设置固定偏移量相对 $\delta=0.1$ 只改善约 1.2%，相对当前设计的统一选择只进一步改善不足 0.4%，没有显示出单独维护多套固定规则的明显必要性；
- 真参数未知时，可利用当前均值归一化排序样本预测 26 点损失曲线并选择偏移量；在当前离散设计中，seed 42 主模型相对 $\delta=0.1$ 将汇总 $J_1$ 降低约 7.3%；
- 均值归一化解决了样本整体缩放下的输入一致性；对未训练样本量或超出当前离散参数设计的数据，仍不直接外推 MLP，应保留固定规则或重新训练。

### 4.2 样本信息与偏移量选择

讨论保持诚实、不过度证明：

先解释两种变化及其意义：L3–L5 反映参数条件之间的平均损失曲线差异；L5/L6 的低一致率和 E11 梯度曲线诊断反映同一条件内的样本差异。样本层面的机制链必须集中写清：次序统计量与样本间距变化 $\rightarrow$ 伪尺度参数与 $S_X(\gamma)$ 变化 $\rightarrow$ 经验梯度曲线及搜索交点移动 $\rightarrow$ $\hat\gamma$ 及联合参数估计变化 $\rightarrow$ 26 点损失曲线与低风险偏移量变化。该链条用 MDM 定义和 E11 数值诊断支撑，不写成连续参数域中的闭式因果证明。然后按以下顺序讨论：

1. 真参数未知时有两条可执行路线：利用初估参数查询条件规则，或直接从当前样本预测候选损失曲线；
2. plug-in 路线把样本先压缩为有误差的参数初估，再查询条件平均规则；已检验变体均未改善总体误差，初估错误查表是与结果一致的解释，但不写成唯一机制；
3. 损失曲线预测不经过参数条件硬分配，均值归一化的排序样本保留样本内相对位置、间距和离散结构，同时移除整体比例；
4. 预测整条损失曲线比直接预测最佳格点保留更多候选间的相对损失信息；格点命中率不代替实际选择风险；
5. 当前 MLP 仍未用尽可观测样本信息，$Z$-only 经验参照与 L6 的剩余差距也不能全部归因于网络不足或不可观测信息；
6. 最终仍由 MDM 估计参数，方法改变的是偏移量选择规则。

正偏移量会共同改变三个参数的估计结果，本文通过 $J_1$ 比较不同选择规则下的三参数联合估计误差。

输入表示的讨论只作选择依据和边界说明：E7 中均值与 RMS 归一化的 $J_1$ 几乎相同，选用均值是因为数值略低、定义直接且可精确复现既有 E5 结果。这不是对均值归一化普遍优越性的证明。E6 Dimensional-RAW 在固定 $\eta=1000$ 下的 $J_1=0.5543$ 低于归一化方法，说明绝对水平在该固定尺度设计中包含可利用信息；但它依赖训练单位和尺度，因此只作敏感性对照。附录 B 只在表示与决策层面解释网络输入；排序位置不是彼此独立的手工特征，不用逐位置权重或简单置换重要性冒充 MDM 机制。

利用初估参数选择偏移量的负结果在讨论中作对比解读：直接 plug-in 总体失败且迭代变差，初步 $\hat\beta$ 正确路由率仅约 17%–20%，与初估噪声导致错误路由的解释一致但不构成唯一机制（连续插值同样失败、误差分层可能与真 $\beta$ 混杂）；这为本文转向直接预测样本级损失曲线提供比较依据，在已检验方案中风险曲线预测获得了 plug-in 未能获得的总体收益。

### 4.3 与传统方法和工程指标的关系

- WMLE 和 LSE 只为当前设计中的三参数联合误差提供外部参照，不参与决定偏移量选择是否成立；
- $J_1$ 与可靠度寿命衡量的问题不同，较低的三参数联合误差不保证每一个 $x_R$ 的误差都更低；
- 当前结果显示参数误差改善向 $x_{0.90}$、$x_{0.95}$ 和 $x_{0.99}$ 的传递有限：前者略差于 Default，后两者仅小幅改善。若实际任务主要关心某一工程量，应直接用该工程量评价方法。

### 4.4 适用边界

- 参数空间和 $\delta$ 均为离散设计，未见参数水平验证不代表连续空间外推；
- 均值归一化与端到端检查支持对整体缩放的等变关系，但检查只覆盖 4 个代表条件与 3 个尺度，不是对所有参数组合或数值环境的穷尽证明；
- 每个 $n$ 独立训练，当前方法只适用于 $n\in\{7,10,15,20\}$；
- L6 是 26 点候选网格内的 hindsight 参照，不是理论最优；
- $Z$-only 参照是已实现规则的确认集风险，不是精确 Bayes 风险，其与 L6 的剩余差距同时包含模型/数据限制和事后信息差；
- 当前没有域匹配的真实数据验证，Monte Carlo 结论不能直接推广到所有工程数据。

## 第五部分 结论

结论只保留四件事：

1. 在当前设计域和组合等权准则下，$\delta=0.1$ 位于统一取值误差曲线的低值区，重新选择一个固定常数改善较小；
2. 偏移量选择既随参数条件改变，也受同一条件内的样本实现影响；
3. seed 42 的 Mean-Normalized-MLP 在当前设计中相对 Default 将 pooled $J_1$ 降低约 7.3%，另外两个预设初始化得到相近结果，且选择器与 MDM 组合后的代表性尺度检查通过；
4. 该收益限于当前离散参数域与已训练样本量，未见 $\beta$ 仅在 pooled 层面保留改善，可靠度寿命传递有限，真实数据仍待验证。
