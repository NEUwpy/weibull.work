# 03 论文骨架

> 本文件只回答一件事：每一章要写什么问题，以及上一章如何推出下一章。
> 实验细节看 `02-实验协议.md`；证据状态看 `01-证据索引.md`。

## 工作题目

三参数 Weibull MDM 偏移量的层级优化与样本自适应选择

## 总问题链

MDM 已有两篇前作：第一篇提出 MDM，第二篇引入 `delta = 0.1` 的 offset 判据以缓解 `gamma` 搜索波动。但前作没有系统回答 `delta` 本身的性质。

本文要回答：

1. `delta` 是否存在最优值？
2. 最优 `delta` 应该在什么信息层级上定义？
3. 不同层级能带来多少估计精度或稳定性改善？
4. 在真参数不可见时，能否用样本信息接近更优 `delta`？

核心逻辑：

```text
前作留下 offset 经验值
  -> 本文追问 delta 的性质
  -> “最优 delta”必须按信息条件分层
  -> L1-L6 给出层级定义
  -> E1 检验简单可部署层级
  -> E2 检验 oracle / hindsight 层级
  -> E3/E4 检验现实部署能否逼近更优层级
```

## 章节问题链

### Ch1 Introduction

写什么：提出缺口。

前作已经提出 MDM，并用 `delta = 0.1` 解决 `y = 0` 判据导致的 `gamma` 估计波动问题。但 `delta` 为什么取这个值、是否存在更优值、在哪些条件下更优，仍没有系统研究。

本章最后提出本文问题：`delta` 有没有最优值，最优值在哪个信息层级上定义，能改善多少，现实中怎么取到。

### Ch2 MDM and the Offset Question

写什么：说明这个缺口为什么成立。

交代 MDM、`gamma` 搜索、`y = 0` 与 `y = delta` 的关系。重点不是重新证明 MDM 有效，而是说明前作解决了“`delta = 0.1` 有效”，但没有回答“`delta` 的性质是什么、是否可优化”。

本章推出：研究最优 `delta` 是 MDM 方法继续发展的自然问题。

### Ch3 Experimental Design

写什么：定义怎么研究这个问题。

“最优 `delta`”不能笼统谈，必须先说明可获得什么信息。因此本章提出 L1-L6 信息层级：全局常数、按 `n`、按真参数 oracle、逐样本 hindsight。

本章还定义主指标、参数网格、`delta` 网格和正式实验映射。它的任务是建立测量框架，不提前解释结果。

### Ch4 Is `delta = 0.1` Optimal? L1 and L2

写什么：回答简单可部署层级。

检验全局最优常数 L1 和按 `n` 查表 L2 能不能超过 `delta = 0.1`。

本章结论应服务一个判断：如果 L1/L2 几乎不能超越 `0.1`，说明前作经验值是强基线，不是容易被另一个全局常数或简单查表替代的值。

### Ch5 The Oracle Hierarchy: L3 to L6

写什么：回答更高信息层级。

检验如果知道 `beta`、`n`、`gamma/eta` 或逐样本 hindsight，最优 `delta` 的空间在哪里。

本章结论应服务两个判断：真正的改进空间主要来自 `beta` 相关层级；L6 只是扫描网格内 hindsight 参照，不是部署目标。

### Ch6 Sample-Adaptive Offset Selection

写什么：把 oracle 空间转向现实部署。

既然 L3 起需要真参数，而真参数部署时不可见，本章问：能否仅凭样本可观测特征和 `n` 选择更合适的 `delta`，逼近 L3-L5 的参照精度。

NN 只是候选实现，不是论文目的。

### Ch7 Boundaries and Robustness

写什么：说明方法边界。

检查样本自适应策略是否跨 `beta`、`n`、`gamma/eta` 稳定，极小样本和边界参数是否可靠，计算成本和失败处理是否影响部署建议。

### Ch8 Discussion

写什么：解释这些结果对 MDM 的意义。

讨论 `delta = 0.1` 为什么仍然重要，L1-L6 如何改变我们对 offset 的理解，以及现实使用时应在固定 `0.1`、简单查表、样本自适应之间如何取舍。

### Ch9 Conclusion

写什么：收束贡献。

本文把 MDM 的 offset 从经验值推进为可分层评估、可解释边界、可讨论部署策略的方法组成部分。
