## 工作题目

三参数 Weibull MDM 偏移量的层级优化与样本自适应选择

## 一句话论证

本文把 MDM 第二篇留下的经验 offset `delta = 0.1`，推进为一个按信息层级定义、用正式实验量化、并可讨论部署边界的决策问题。

## 总体逻辑

```text
MDM 已提出并采用 delta = 0.1
  -> delta 的最优性尚未系统研究
  -> 最优 delta 必须按信息层级定义
  -> E1 检验 Default/L1/L2：简单可部署层级
  -> E2 检验 L3-L6：oracle 与 hindsight 参照
  -> E3 检验样本自适应 risk-curve：真参数不可见时能否用样本可观测特征选择更合适的 delta
  -> E4 检验边界与稳健性
  -> 得出固定 0.1、查表、自适应三类使用建议
```

## 章节写法

每章固定回答五个问题：

1. **目的**：本章要准确建立什么判断，或完成什么逻辑功能。
2. **内容**：本章实际使用哪些材料和要点，不展开成正文。
3. **手段**：说明本章需要怎样的叙述、证明、验证、图表或证据形式来组织这些内容。
4. **边界**：本章明确不做什么、不提前主张什么、不误用什么证据。
5. **承接**：本章如何推出下一章。

必要性原则：任何叙述、证明、验证、图表或引用都必须服务本章目的。只有当它能减少歧义、压缩证据、区分层级或支撑判断时才写入；不要因为形式完整而添加。

图表细化规则：图表需求优先写入对应章节的 `手段` 字段，因为图表是章节完成逻辑任务的方式。单独图表表格只作校验索引，不作为第二事实源。尚未确认的建议必须写入 `待确认问题`，不要伪装成已定骨架。

### Ch2 MDM and the Offset Question

**目的**：建立 `delta` 是 MDM 搜索判据中的决策量，并说明它不是任意小正数或外部调参，而是针对 `y = 0` 判据下 `gamma` 搜索波动的判据移动。

**内容**：三参数 Weibull 与 MDM 基本步骤；`gamma` 搜索中的不稳定来源；`y = 0` 与 `y = delta` 判据；offset 如何改变搜索位置；为什么太小的 `delta` 仍可能靠近不稳定区域，太大的 `delta` 又可能移动过度。

**手段**：

- 机制叙述：用足够读懂 `gamma` profile 的 MDM 步骤解释 `delta` 改变的是搜索判据，不是后处理修正。
- 直觉反驳段：回应“偏移是不是随便取一个小正数即可”。说明 `delta` 是稳定性和过度移动之间的折中；本章只给机制理由，正式数值证据留给 Ch4。
- 主图为一张三子图机制/波动诊断图，代表配置固定为 `W(2, 1000, 1000), n = 7`，贴近 182-046 语境：
  - Panel A：真实 MDM `gamma` profile / 梯度判据图。横轴 `gamma`，纵轴 profile gradient / 判据值；标出 `y = 0` 与 `y = 0.1`，以及二者对应的搜索位置。
  - Panel B：同一配置下 `delta = 0` 与 `delta = 0.1` 的 `gamma_hat` 分布，并标出真值 `gamma = 1000`。
  - Panel C：同一配置下 `delta = 0` 与 `delta = 0.1` 的归一化误差 `(gamma_hat - gamma) / eta` 分布。

**边界**：不重做 MDM 整体优劣比较；不讲 L1-L6 层级框架；不使用 E1 正式数字；不证明 `delta = 0.1` 全局最优；不把本章写成新的实验结果章。

**承接**：既然 `delta` 是决策量，下一章必须先定义“在什么信息条件下最优”。

### Ch3 Experimental Design

**目的**：建立本文的最优 `delta` 操作性定义、信息层级框架和正式实验合同，使后续结果可比较、可复现、可防误读。

**内容**：最优 `delta` 的 grid-level 风险最小化定义；L1/L2 是简单可部署层级；L3-L5 是真参数 oracle；L6 是逐样本 hindsight benchmark；E1/E2 共用正式 MC 数据；E3a/E3b 已形成 existing-grid 样本自适应证据；E3c/E4 仍作为边界扩展待决策。

**手段**：

- 操作性定义段：本文不证明连续空间中唯一理论最优 `delta`，而是在给定信息层级、`delta` grid 和正式 MC 风险函数下定义 grid argmin：`delta*_L(g) = argmin_{delta in D} J1(g, delta)`，其中 `D = {0.00, 0.02, ..., 0.50}`。若风险曲线平坦或多个 `delta` 接近，只报告平坦性和边际收益，不夸大唯一最优。
- 核心表：L1-L6 层级/实验合同表。列应包括：层级、可用信息、决策粒度、`delta*` 定义、性质、后续用途、禁止误读。表中必须显式区分 L1/L2 可部署、L3-L5 oracle 参照、L6 扫描网格内 hindsight benchmark。
- 辅助框架图：表现 Default/L1/L2 可部署层级、L3-L5 oracle 参照、L6 hindsight benchmark，以及 E3 从样本可观测特征桥接到更细 `delta` 选择的角色。图中必须区分 E3a/E3b existing-grid 已完成与 E3c/E4 待决策，不能把 L6 画成部署目标。
- 协议段/表：参数网格、`delta` grid、J1 指标、R、seed、manifest 和正式产物合同。

**边界**：不解释结果；不把旧 `docs/research` 结果写成正式证据；不提前承诺 E3c/E4 结论。

**承接**：层级定义后，先回答最简单的问题：`delta = 0.1` 在 L1/L2 层级是否已经足够强。

### Ch4 Is `delta = 0.1` Optimal? L1 and L2

**目的**：建立 `delta = 0.1` 在简单可部署层级上是强基线；另一个全局常数或按 `n` 查表几乎不能系统改进，但这不等于 `0.1` 是严格最优。

**内容**：全局风险曲线在 `0.06-0.12` 附近平坦；L1 `delta* = 0.08` 与 Default `0.10` 几乎相同；`delta = 0`、过小 `delta` 和过大 `delta` 都更差；L1/L2 相比 Default 收益极小；不同 `beta` 下最优 `delta` 方向相反，同一 `n` 内仍被 `beta` 异质性抵消。

**手段**：

- E1 全局 `delta` risk 曲线：横轴 `delta`，纵轴 J1；标出 L1 `delta* = 0.08`、Default `delta = 0.10`、低风险平台 `[0.06, 0.12]`，并在正文说明 `delta = 0`、过小 `delta`、过大 `delta` 都不是更优。
- E1 异质性图：主角是 `beta`，`n` 作为部署和审稿分层维度保留。可采用两层结构：Panel A 展示按 `n` pooled 的 `delta` risk，说明 L2 收益小；Panel B 在每个 `n` 内按 `beta` 分解，说明同一 `n` 内最优 `delta` 方向仍相反，pooled by `n` 会抵消。
- 对比表：列出 Default / L1 / L2 的 `delta` 或规则、J1、相对 Default 的改善百分比。表的任务是压缩核心数字，不单独引出新主张。

**边界**：不写 `delta = 0.1` 是严格最优；不把 L1/L2 收益有限写成“没有改进空间”；不把 Ch4 写成按 `n` 查表的主要改进故事；不使用 E2 oracle 结果替代 E1 证据。

**承接**：简单层级收益有限，下一章转向更高信息层级，寻找真正改进空间。

### Ch5 The Oracle Hierarchy: L3 to L6

**目的**：建立 oracle 层级证明 offset 的真实改进空间存在，最大 oracle 增益来自 `beta` 信息；但 L3-L5 主要是参照/标签来源，L6 是 hindsight benchmark，不是部署方案。

**内容**：L3-L5 逐步加入真参数信息；L1->L3 是主要跳点；L3 之后在 pooled J1 下边际收益降低；`n` 仍是部署变量和审稿分层维度，`gamma/eta` 是次级调节项；L4/L5 是 E3 标签候选；L6 是扫描网格内 hindsight 参照，不是部署目标。

**手段**：

- 阶梯收益图/表：展示 Default/L1/L2/L3/L4/L5/L6 的 J1 阶梯和相对 Default、相对上一级的边际收益，用于定位 L1->L3 大跳、L3->L5 边际递减、L5->L6 hindsight 大跳。
- L4 `beta × n` 热力图进入主文：显示 `beta` 是最优 `delta` 方向的主效应，`n` 是调节项且仍必须保留为部署和审稿维度。
- L6 `delta*` 分布图进入主文：展示逐样本 `delta*` 分布，尤其是 `delta* = 0` 堆积和右偏结构，用于说明 L6 有逐样本偶然性，不能作为部署目标、理论上限或单一正确训练目标；后续 E3 只能把它作为 sample-level hindsight target test。
- L5 `beta × gamma/eta × n` 热力图作为补充/附录或备查，不放主文核心。

**边界**：不把 oracle 层级写成可部署方案；不把 L6 hindsight 写成理论上限、部署目标或单一正确训练目标；不写“只需要 beta 就够了”；不把 `n` 从正文解释中拿掉。

**承接**：oracle 层级需要真参数，现实部署不可直接使用，下一章转向样本可观测特征。

### Ch6 Sample-Adaptive Offset Selection

**目的**：解释 existing-grid 证据显示样本可观测特征确实含有可部署的 `delta` 选择信号：在不输入真参数的条件下，E3b 的重型 vector-output MLP 明显优于 Default/L1/L2，并接近 L6 hindsight；同时限定这一结论只覆盖当前正式离散网格，不自动外推到连续参数空间。

**内容**：E3a 作为轻量 risk-curve pilot，E3b 作为严格 full `(beta, gamma/eta, n)` combo holdout follow-up；主证据取 E3b `Vector-MLP-L6`、`Vector-MLP-L4/L5`、`Tabular-L6` 与 Default/L1/L2/L3-L6 参照；报告 pooled 和按 `n` 分层 J1、失败率、3 seed 稳定性、endpoint 选择率、near-optimal/regret 诊断、feature ablation；说明 `sample_features.csv` / `risk_curves.csv` 是 45,000 样本全 folds 同轮生成的证据缓存。

**手段**：

- 开篇承接 Ch5：L3-L5 需要真参数，L6 是 hindsight；Ch6 的问题是样本特征能否在部署可见信息下逼近这些参照，而不是证明 NN 本身。
- 方法简述用一张流程图承担：样本统计特征 -> 26 维风险曲线预测 -> `argmin_delta` 选择 -> 用真实 selected-loss J1 评价。图中应标注 E3b vector-output MLP 不输入候选 `delta`，区别于 E3a scalar risk-curve pilot。
- 主结果表承担核心判断：列出 Default/L1/L2、L3/L4/L5 oracle、L6 hindsight、`Vector-MLP-L4/L5/L6`、`Tabular-L6`，并显示 `Vector-MLP-L6` pooled J1=0.547003，优于 L2=0.632541，也优于 L5-oracle=0.571170，但仍未达到 L6-hindsight=0.494530。
- 分层解释段必须保留 `n`：`Vector-MLP-L6` 在 `n=7/10/20` 的 J1 分别为 0.657558 / 0.549815 / 0.403679，方向上均优于 L2，对应 L2 为 0.739286 / 0.644520 / 0.488235。
- 稳定性段用 3 seed 表压缩：seed 42/2026/3407 pooled J1 为 0.547003 / 0.546133 / 0.544009，说明主 J1 结论稳定；同时保留 endpoint rate 波动（0.4881 / 0.4884 / 0.5624）作为选择分布仍需解释的边界。
- 解释段处理“超过 L5-oracle”的潜在误读：L5 是真参数分组查表 oracle，不是样本特征方法的上界；样本统计特征携带逐样本形状/尺度信息，因此可以在 existing-grid 上数值上超过 L5，但这不等于使用了真参数或达到理论上界。
- 诊断段只作必要解释：endpoint 选择在 `Vector-MLP-L6` 中较高（pooled extreme rate 0.4881），但 L6-hindsight 本身也高度 endpoint 化（0.6474），因此 endpoint 不是自动缺陷；仍需用 near-optimal/regret 和 E4/E3c 判断是否稳健。
- 章末决策门槛：若论文主张限定为“formal existing-grid 上存在可部署样本自适应信号”，E3b 已足够支撑；若要写成“连续参数空间可泛化的部署推荐”，必须另行启动 E3c 或纳入 E4 边界验证。

**边界**：不允许真参数、`gamma/eta`、配置 ID、seed 或 `repeat_id` 进入模型输入；允许真参数和 `repeat_id` 仅用于复现样本、计算可观测统计特征和离线 loss 标签；不把 NN 写成论文目的；不把 L6 写成理论上限；不把 existing-grid 结果写成 continuous-space 泛化结论；不把 endpoint 选择率单独写成成功或失败，必须结合真实 selected-loss 和 near-optimal/regret。

**承接**：Ch6 证明 existing-grid 上样本自适应有实质信号；下一章必须决定是否需要 E3c/E4 来支撑更宽参数空间、失败处理和计算成本边界。
