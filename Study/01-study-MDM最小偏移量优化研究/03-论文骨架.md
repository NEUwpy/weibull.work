## 一句话论证

本文表明，三参数 Weibull MDM 的经验偏移量 `delta=0.1` 虽已接近全局最优，但样本间损失曲线的异质性仍形成了可利用的选择空间；通过由可观测样本统计量预测不同候选偏移量的损失，可以在保留 MDM 估计框架的同时实现样本自适应偏移量选择，并用必要的支撑验证界定其收益与边界。

## 总体逻辑

```text
经验 delta=0.1 有效但最优性未知
  -> 定义候选网格、损失和 L1-L6 信息层级
  -> 证明全局规则收益有限而条件异质性存在（E1+E2）
  -> 用可观测样本信息预测 26 点损失曲线并选择 delta（E3b）
  -> 简要验证泛化、稳定性、传统方法参照和工程分位点（支撑验证，细节进补充材料）
  -> 讨论强全局基线与条件异质性的关系、样本信息为何能帮助选择、适用范围与局限
```

## 第二部分 问题定义与方法

### 2.1 MDM 偏移量问题

**目的**：说明 `delta` 改变的是位置参数搜索判据，而不是对估计结果进行事后补偿。

**内容**：三参数 Weibull CDF、MDM 伪尺度差异、位置参数搜索、尺度等变性和候选偏移量网格。

**手段**：用机制图展示 `delta` 改变搜索位置及估计分布，同时保留改善和变差样本，避免把 `0.1` 画成必然正确。

**边界**：不重新证明完整 MDM；不把机制示意当作最优性证据。

### 2.2 最优偏移量及信息层级

**目的**：把“多个样本得到多个最优偏移量，最终选哪个”转化为明确的统计决策问题。

**内容**：单样本损失、汇总 J1、L1–L6 信息层级、设计域等权测度、cross-fit 选择/评价分离。J1 只是统一评价准则，不是方法创新。

**手段**：用一张紧凑层级表区分全局规则、按 `n` 规则、oracle 参照和 hindsight 参照。

**边界**：不把 L3–L5 写成可执行查表法；不把 L6 写成理论下界或部署目标；不把正式网格的 pooled optimum 写成真实应用分布中的普遍最优。

### 2.3 样本自适应损失曲线选择方法

**目的**：定义从样本统计量到完整损失曲线再到偏移量的可执行映射。

**内容**：13 个样本统计量、26 维损失曲线、`argmin delta`、网络结构、fold/seed、标准化、失败标签和数据隔离。

**手段**：流程图分开离线训练和实际推断；明确网络不直接输出 Weibull 参数，最终估计仍由 MDM 完成。

**边界**：不把网络结构选择包装为论文贡献；不输入真参数、组合 ID、repeat ID 或测试标签；结果限于正式离散网格组合留出评价。

### 2.4 精简实验设计

**目的**：保证核心结果与支撑验证来自同样本、同划分、同指标和可复现的比较。

**内容**：

- 主网格与泛化轴；
- 核心实验 E1/E2/E3b；
- 支撑验证（泛化、稳定性与消融、传统方法参照、工程分位点）；
- 后置真实案例的准入与评价（正文简述）。

**手段**：用协议表压缩呈现方法角色、输入、输出、是否训练和评价范围；详细失败合同、哈希与运行环境放补充材料。

**边界**：不在方法部分预写新增实验结果；不将不同有效样本子集进行主排名；传统方法只作外部参照。

**承接**：结果按研究问题依次回答，而不按内部实验编号展开。

## 第三部分 结果

### 3.1 E1+E2：固定规则与信息增加后的潜在收益

**目的**：先界定偏移量选择问题中“还有多少可以改进”，再为可执行的样本自适应方法建立参照。

**内容**：

1. 全局固定偏移量：`delta=0.08–0.12` 位于平缓低风险区，经验值 `delta=0.1` 已接近全局最优，重新寻找另一个统一常数的收益有限；
2. 完整参数组合条件下的选择：联合估计误差可降低约 `9.8%`，说明全局平均掩盖了条件异质性；
3. 逐样本事后选择：潜在误差降幅可达约 `21.9%`，给出当前候选网格和评价准则下的事后参照；
4. 明确可优化空间主要来自条件化和逐样本差异，而不是把 `0.1` 替换为另一个全局常数。

**手段**：用全局风险曲线说明固定常数的低风险平台，用简化信息层级表依次展示全局固定规则、参数组合条件规则和逐样本事后参照。

**边界**：不把 `0.08` 写成替代 `0.1` 的新普遍常数；`9.8%` 和 `21.9%` 用于描述潜在收益层级，不代表实际应用中均可取得；逐样本事后参照依赖估计完成后才能知道的真实损失，不是可部署方法。

### 3.2 E3b：可观测样本信息恢复部分潜在收益

**目的**：回答真参数和真实损失不可见时，能否利用样本可观测信息取得上一节所揭示的部分潜在收益。

**内容**：

1. 可执行方法：Vector-MLP 根据样本统计量预测 26 个候选偏移量对应的完整损失曲线，再选择预测损失最小的偏移量；
2. 核心效果：在正式离散设计域的组合留出评价中，相对固定规则降低联合估计误差；
3. 参照位置：将实际取得的收益置于参数组合条件规则和逐样本事后参照之间，说明回收了部分而非全部潜在空间；
4. 一致性：报告分 `n` 结果和不同 fold/seed 的模型级分布，避免用单次训练或 pooled 均值代替稳定性证据。

**手段**：主结果表同时列出固定规则、Vector-MLP、参数组合条件规则和逐样本事后参照；另用紧凑的决策路径图表示“样本统计量—预测损失曲线—候选偏移量排序—MDM 参数估计”。

**边界**：不称为连续空间泛化或已部署；不把预测损失曲线等同于真实损失曲线；不把相关诊断写成严格因果机制。

### 3.3 支撑验证与适用性

**目的**：用必要但克制的验证排除三项主要疑问：输入特征是否确实包含有效信息，结果是否依赖某次随机训练，离开训练格点后收益是否仍保留，以及与传统方法和工程目标的关系。本节只为核心方法提供可信性支撑，不另建研究主线。

**正文内容**：

1. 一句话概括特征消融：所用统计特征能够支持偏移量选择，并说明哪些特征组贡献较明显，不作因果解释；
2. 简要报告 fold/seed 模型级波动；
3. 用一张紧凑汇总表报告参数插值、样本量插值以及域外条件下，相对固定规则的收益是否保留，并区分绝对性能退化与相对改善；
4. 简述与传统方法（WMLE、LSE 外部参照）和工程寿命分位点（`x_0.90`/`x_0.95`/`x_0.99`）的关系；
5. 正文只保留直接支持主张的数字、区间和失败情况。

**补充材料内容**：

- 四组特征保留/消融的完整模型级分布；
- 15 个 fold/seed 模型的 min/Q1/median/Q3/max/mean/SD；
- 按 `n`、`beta` 和参数状态拆分的全部结果；
- 参数插值、样本量插值、参数外推、样本量外推和多轴外推的逐轨道配对胜率、失败率与尾部误差；
- delta 上界审计及其他边界诊断；
- 工程分位点的完整分层结果。

**手段**：正文采用一张“验证问题—主要结果—结论边界”的汇总表；完整图表和逐模型数据转入补充材料。

**边界**：不称消融为单特征因果贡献；不把混合 off-grid 笼统称为域内非格点；绝对性能下降与相对基线保留改善必须分开描述；不因正文压缩而省略失败结果和不支持泛化的轨道；不把传统方法外部参照升级为方法排名。
