## 工作题目

三参数 Weibull MDM 偏移量的层级优化与样本自适应选择

## 一句话论证

本文把 MDM 第二篇留下的经验 offset `delta = 0.1` 推进为一个按信息层级定义的决策问题：正式实验先量化各层级的最优值与收益，再证明真参数不可见时，样本可观测特征能够在现有正式参数网格内支持更优的自适应选择；更宽空间的稳健性和真实场景适用性由后续章节继续限定。

## 总体逻辑

```text
MDM 已提出并采用 delta = 0.1
  -> delta 的最优性尚未系统研究
  -> 最优 delta 必须按信息层级定义
  -> E1 检验 Default/L1/L2：简单可部署层级
  -> E2 检验 L3-L6：oracle 与 hindsight 参照
  -> E3 检验样本自适应 risk-curve：以 NN/Vector-MLP 作为当前主要求解器，验证真参数不可见时能否用样本可观测特征选择更合适的 delta
  -> E4 检验边界与稳健性
  -> 真实寿命数据的重复小样本/大样本留出验证检验外部适用性（已确认纳入，评价口径与章节位置待确认）
  -> 得出固定 0.1、查表、自适应三类使用建议
```

## 章节写法

每章固定回答五个问题：

1. **目的**：本章要准确建立什么判断，或完成什么逻辑功能。
2. **内容**：本章实际使用哪些材料和要点，不展开成正文。
3. **手段**：说明本章需要怎样的叙述、证明、验证、图表或证据形式来组织这些内容。
4. **边界**：本章明确不做什么、不提前主张什么、不误用什么证据。
5. **承接**：本章如何推出下一章。

必要性原则：任何叙述、证明、验证、图表或引用都必须服务本章目的。只有当它能减少歧义、压缩证据、区分层级或支撑判断时才写入；不要因为形式完整而添加。

图表细化规则：图表需求优先写入对应章节的 `手段` 字段，因为图表是章节完成逻辑任务的方式。单独图表表格只作校验索引，不作为第二事实源。尚未确认的建议必须写入 `待确认问题`，不要伪装成已定骨架。

### Ch2 MDM and the Offset Question

**目的**：建立 `delta` 是 MDM 搜索判据中的决策量，并说明它不是任意小正数或外部调参，而是针对原文 `nabla gamma = 0` 判据下 `gamma` 搜索波动的判据移动。

**内容**：三参数 Weibull 与 MDM 基本步骤；内部 offset root 与工程求解器返回候选估计的区别；`gamma` 搜索中的不稳定来源；原文 `nabla gamma = 0` 与 `nabla gamma = delta` 判据；offset 如何改变搜索位置；为什么太小的 `delta` 仍可能靠近不稳定区域，太大的 `delta` 又可能移动过度。

**手段**：

- 机制叙述：用足够读懂 `gamma` profile 的 MDM 步骤解释 `delta` 改变的是搜索判据，不是后处理修正。
- 直觉反驳段：回应“偏移是不是随便取一个小正数即可”。说明 `delta` 是稳定性和过度移动之间的折中；本章只给机制理由，正式数值证据留给 Ch4。
- 主图为一张三子图机制/波动诊断图，代表配置固定为 `W(2, 1000, 1000), n = 7`，贴近 182-046 语境：
  - Panel A：真实 MDM `gamma` profile / 梯度判据图。横轴 `gamma`，纵轴原文记号 `nabla gamma`；标出 `nabla gamma = 0` 与 `nabla gamma = 0.1`，以及二者对应的搜索位置。
  - Panel B：同一配置下 `delta = 0` 与 `delta = 0.1` 的 `gamma_hat` ECDF，并标出真值 `gamma = 1000` 和 `delta=0` 的边界质量，避免直方图尖峰遮蔽主体分布。
  - Panel C：按 `repeat_id` 严格配对两种判据的绝对归一化误差；对角线下方为改善，上方为变差，并报告两类比例。
- Figure 1 的核心结论锁定为：`delta` 会改变 `gamma` 搜索判据并系统性改变有限样本估计分布；`delta=0.1` 总体缓解部分不稳定情况但并非逐样本都改善，因此 `delta` 是需要正式优化的决策变量。图中必须同时保留改善与变差证据，不能画成 `0.1` 必然更优。
- Figure 1 的展示尺度保留第二篇原文语境 `W(2,1000,1000), n=7`；Panel B/C 从尺度等价的正式 `W(2,1,1)` MC 数据筛选，将 `gamma_hat` 乘 1000 后显示，图注必须说明不是另行重跑。
- Ch2 在偏移判据后给出尺度等变性短推导：$t_i'=ct_i$、$\gamma'=c\gamma$ 时，伪尺度标准差乘 $c$，其对缩放后 $\gamma'$ 的梯度不变，因而同一 `delta` 使 `beta_hat` 不变、`eta_hat/gamma_hat` 同比例缩放。该性质同时支撑 Figure 1 尺度转换和 Ch3 固定 `eta=1`。

**边界**：不重做 MDM 整体优劣比较；不讲 L1-L6 层级框架；不使用 E1 正式数字；不证明 `delta = 0.1` 全局最优；不把工程求解器“始终返回候选估计”误写成“约束域内始终存在内部 root”；不在本章展开边界策略发生率和稳健性统计。

**承接**：既然 `delta` 是决策量，下一章必须先定义“在什么信息条件下最优”。

### Ch3 Experimental Design

**目的**：建立本文的最优 `delta` 操作性定义、信息层级框架和正式实验合同，使后续结果可比较、可复现、可防误读。

**内容**：最优 `delta` 的 grid-level 风险最小化定义；L1/L2 是简单可部署层级；L3-L5 是真参数 oracle；L6 是逐样本 hindsight benchmark；E1/E2 共用正式 MC 数据；E3a/E3b 已形成 existing-grid 样本自适应证据，且 E3b 当前主要方法为 vector-output MLP；E3c/E4 仍作为边界扩展待决策。

**手段**：

- 操作性定义段：本文不证明连续空间中唯一理论最优 `delta`。先定义单样本未开方损失 `ell_i(delta)`；L1-L5 在各自分组内最小化 `R_L(g,delta)=sqrt(mean ell_i(delta))`，L6 则逐样本最小化 `ell_i(delta)`。对已选规则的最终跨样本比较才称为 `J1=sqrt(mean ell_i(delta_hat_i))`。`D = {0.00, 0.02, ..., 0.50}`；45 个正式设计格点因 repeats 相同而在 pooled 风险中等权，因此 L1 的“全局”只是 formal design-grid measure，不代表真实应用频率。若组级风险曲线平坦或多个 `delta` 接近，只报告平坦性和边际收益，不夸大唯一最优。
- 核心表是层级定义的权威合同：L1-L6 层级/实验合同表。列应包括：层级、可用信息、决策粒度、`delta*` 定义、性质、后续用途、禁止误读。表中必须显式区分 L1/L2 可部署、L3-L5 oracle 参照、L6 扫描网格内 hindsight benchmark。
- 辅助框架图只承担极简视觉路线图：表现 Default/L1/L2 可部署层级、L3-L5 依赖真参数的 oracle 参照、L6 hindsight benchmark，以及 E3 的“样本可观测特征 -> 26 点风险曲线 -> 选择 `delta`”桥接路径和 E1-E4-真实数据的最终论文验证链。图中删除所有 J1、改善百分比、完成/待办状态和结果性语言；不能写 L3-L5 “requires NN”，不能把 L6 写成 upper bound 或部署目标。
- 协议段/表：参数网格、`delta` grid、J1 指标、R、seed、manifest 和正式产物合同。
- 选点偏差审计：全缓存 E1/E2 风险曲线用于定义和描述层级；L1-L5 另用 `repeat_id mod 5` 做五折 cross-fitting，每折用 800 repeats 选点、200 repeats 评价。Default 不选点，L6 保持定义上的 hindsight，不伪装为 cross-fitted 部署表现。

**边界**：不解释结果；不把旧 `docs/research` 结果写成正式证据；不提前承诺 E3c/E4 结论。

**承接**：层级定义后，先回答最简单的问题：`delta = 0.1` 在 L1/L2 层级是否已经足够强。

### Ch4 Is `delta = 0.1` Optimal? L1 and L2

**目的**：建立 `delta = 0.1` 在简单可部署层级上是强基线；另一个全局常数或按 `n` 查表几乎不能系统改进，但这不等于 `0.1` 是严格最优。

**内容**：全局风险曲线在 `0.06-0.12` 附近平坦；L1 `delta* = 0.08` 与 Default `0.10` 几乎相同；`delta = 0`、过小 `delta` 和过大 `delta` 都更差；L1/L2 相比 Default 收益极小；不同 `beta` 下最优 `delta` 方向相反，同一 `n` 内仍被 `beta` 异质性抵消。

**手段**：

- E1 全局 `delta` risk 曲线：横轴 `delta`，纵轴 J1；标出 L1 `delta* = 0.08`、Default `delta = 0.10`、低风险平台 `[0.06, 0.12]`，并在正文说明 `delta = 0`、过小 `delta`、过大 `delta` 都不是更优。
- E1 异质性图：主角是 `beta`，`n` 作为部署和审稿分层维度保留。可采用两层结构：Panel A 展示按 `n` pooled 的 `delta` risk，说明 L2 收益小；Panel B 在每个 `n` 内按 `beta` 分解，说明同一 `n` 内最优 `delta` 方向仍相反，pooled by `n` 会抵消。
- 对比表：列出 Default / L1 / L2 的 `delta` 或规则、J1、相对 Default 的改善百分比。表的任务是压缩核心数字，不单独引出新主张。
- cross-fit 敏感性表：对照全缓存同批选点/评价与五折留出 J1。L1 五折均选 0.08；L2 cross-fit J1=0.632732，相对 Default 改善仍仅 0.077%，使“0.1 是强基线”的结论不依赖同批择优。

**边界**：不写 `delta = 0.1` 是严格最优；不把正式设计网格的等权 pooled 结果写成任意真实参数分布下的普遍结论；不把 L1/L2 收益有限写成“没有改进空间”；不把 Ch4 写成按 `n` 查表的主要改进故事；不使用 E2 oracle 结果替代 E1 证据。

**承接**：简单层级收益有限，下一章转向更高信息层级，寻找真正改进空间。

### Ch5 The Oracle Hierarchy: L3 to L6

**目的**：建立 oracle 层级证明 offset 的真实改进空间存在，最大 oracle 增益来自 `beta` 信息；但 L3-L5 主要是参照/标签来源，L6 是 hindsight benchmark，不是部署方案。

**内容**：L3-L5 逐步加入真参数信息；L1->L3 是主要跳点；L3 之后在 pooled J1 下边际收益降低；`n` 仍是部署变量和审稿分层维度，`gamma/eta` 是次级调节项；L4/L5 是 E3 标签候选；L6 是扫描网格内 hindsight 参照，不是部署目标。

**手段**：

- 阶梯收益图/表：展示 Default/L1/L2/L3/L4/L5/L6 的 J1 阶梯和相对 Default、相对上一级的边际收益，用于定位 L1->L3 大跳、L3->L5 边际递减、L5->L6 hindsight 大跳。
- L1-L5 cross-fit 审计表：五折留出 J1 为 L1=0.632913、L2=0.632732、L3=0.585068、L4=0.582585、L5=0.571924；同批选点/评价偏差仅使 L2/L4/L5 上调 0.030% / 0.085% / 0.132%，阶梯结构不变。L6 不进入该留出比较。
- L4 `beta × n` 热力图进入主文：显示 `beta` 是最优 `delta` 方向的主效应，`n` 是调节项且仍必须保留为部署和审稿维度。
- L6 `delta*` 分布图进入主文：展示逐样本 `delta*` 分布，并严格分开下端点 $P(\delta^*=0)=0.4746$、上端点 $P(\delta^*=0.50)=0.0657$ 和 near-upper 质量。下端点代表有方法含义的无偏移候选，上端点代表人为网格截断风险。L6 有逐样本偶然性，不能作为部署目标或理论上限；E3 可以把 L6 作为 sample-level hindsight target test / 监督粒度压力测试，但必须用 selected-loss、near-optimal 和边界诊断解释。
- L5 `beta × gamma/eta × n` 热力图作为补充/附录或备查，不放主文核心。

**边界**：不把 oracle 层级写成可部署方案；不把 L6 hindsight 写成理论上限或部署目标；不写“只需要 beta 就够了”；不把 `n` 从正文解释中拿掉。

**承接**：oracle 层级需要真参数，现实部署不可直接使用，下一章转向样本可观测特征。

### Ch6 Sample-Adaptive Offset Selection

**目的**：解释 existing-grid 证据显示样本可观测特征确实含有可部署的 `delta` 选择信号：在不输入真参数的条件下，E3b 以重型 vector-output MLP 作为当前主要求解器，明显优于 Default/L1/L2，并落在 oracle/hindsight 参照阶梯内；同时限定这一结论只覆盖当前正式离散网格，不自动外推到连续参数空间。

**内容**：E3a 作为轻量 risk-curve pilot，E3b 作为严格 full `(beta, gamma/eta, n)` combo holdout follow-up；主证据取 E3b `Vector-MLP-L6`、`Vector-MLP-L4/L5`、`Tabular-L6` 与 Default/L1/L2/L3-L6 参照；报告 pooled 和按 `n` 分层 J1、失败率、3 seed 稳定性、exact 上下端点与 extreme/near-boundary 选择率、near-optimal/regret 诊断；说明 NN/Vector-MLP 是本章解决样本自适应 offset selection 的主要方法，而不是为了使用 NN 而另立的论文目的；说明 `sample_features.csv` / `risk_curves.csv` 是 45,000 样本全 folds 同轮生成的证据缓存。特征组贡献不在 Ch6 用单 fold pilot 定论，正式消融交给 Ch7/E4a。

**手段**：

- 开篇承接 Ch5：L3-L5 需要真参数，L6 是 hindsight；Ch6 的问题是样本特征能否在部署可见信息下解决更细的 `delta` 选择问题。NN/Vector-MLP 要作为本章主要方法讲清楚，但其逻辑位置是求解器，不是论文目的本身。
- 方法简述由 Figure 8 流程图承担：样本统计特征 -> vector-output MLP 预测 26 维风险曲线 -> `argmin_delta` 选择 -> 用真实 selected-loss J1 评价。图中标注 E3b vector-output MLP 不输入候选 `delta`，并将部署推断与 formal MC 离线训练/评价分开；模型结构写到 13–256–128–64–26 即可，不展开成 ML 调参论文。原 pooled J1 柱状图降为补充图，避免与主结果表重复。
- 主结果表承担核心判断：列出 Default/L1/L2、L3/L4/L5 oracle、L6 hindsight、`Vector-MLP-L4/L5/L6`、`Tabular-L6`，并显示 `Vector-MLP-L6` pooled J1=0.547003，优于 L2=0.632541，也优于 L5-oracle=0.571170，但仍未达到 L6-hindsight=0.494530。
- 分层解释段必须保留 `n`：`Vector-MLP-L6` 在 `n=7/10/20` 的 J1 分别为 0.657558 / 0.549815 / 0.403679，方向上均优于 L2，对应 L2 为 0.739286 / 0.644520 / 0.488235。
- 稳定性段用 3 seed 表压缩：seed 42/2026/3407 pooled J1 为 0.547003 / 0.546133 / 0.544009，说明主 J1 结论稳定；同时保留 extreme/near-boundary rate 波动（0.4881 / 0.4884 / 0.5624）作为选择分布仍需解释的边界。该指标定义为 $\delta\in\{0,0.02,0.48,0.50\}$，不得称为 exact endpoint rate。
- 解释段处理“超过 L5-oracle”的潜在误读：L5 是真参数分组查表 oracle，不是样本特征方法的上界；样本统计特征携带逐样本形状/尺度信息，因此可以在 existing-grid 上数值上超过 L5，但这不等于使用了真参数或达到理论上界。
