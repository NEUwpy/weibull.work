# 第3章 实验设计

## §1 MDM 参数估计的数学推导

### 3.1.1 三参数 Weibull 分布

三参数 Weibull 分布的累积分布函数为

$$F(t) = 1 - \exp\left[-\left(\frac{t - \gamma}{\eta}\right)^{\beta}\right], \quad t > \gamma$$

其中 β > 0 为形状参数，η > 0 为尺度参数，γ 为位置参数（失效阈值）。经分布函数变换，令

$$x = -\ln(1 - F(t)), \quad y = t$$

则 Weibull 分布可线性化为 $y = \gamma + \eta \, x^{1/\beta}$。这一线性关系是 MDM 的几何基础。

### 3.1.2 伪尺度参数与最小差异原理

给定一组有序失效时间 $t_{(1)} \leq t_{(2)} \leq \cdots \leq t_{(n)}$，用 Bernard 中位秩公式估计各点的经验累积概率：

$$\hat{F}(t_{(i)}) = \frac{i - 0.3}{n + 0.4}$$

对应的变换值为 $x_i = -\ln(1 - \hat{F}(t_{(i)}))$。对于给定的候选参数 (β, γ)，每个样本点可反解出一个伪尺度参数估计：

$$\hat{\eta}_i = \frac{t_{(i)} - \gamma}{x_i^{1/\beta}}, \quad i = 1, 2, \ldots, n$$

当 (β, γ) 取真值时，$n$ 个 $\hat{\eta}_i$ 应当一致——它们之间的差异源于样本波动。MDM 的核心判据是最小化这组伪尺度参数的条件标准差(182-030)：

$$\sigma_\eta(\beta, \gamma) = \text{std}\left(\hat{\eta}_1, \hat{\eta}_2, \ldots, \hat{\eta}_n\right)$$

### 3.1.3 两步 profiling 搜索

MDM 采用两步搜索策略：

**内层**：对给定 γ，搜索使 $\sigma_\eta$ 最小的 β：

$$\beta^*(\gamma) = \arg\min_{\beta \in [0.1, 15.0]} \sigma_\eta(\beta, \gamma)$$

得到 profile 标准差曲线 $\sigma_{\eta,\min}(\gamma)$。

**外层**：在 γ 方向上搜索 $\sigma_{\eta,\min}(\gamma)$ 的极值点确定 γ̂，进而回代得到 (β̂, η̂)。

### 3.1.4 梯度偏移判据

理论上，$\sigma_{\eta,\min}(\gamma)$ 在真实 γ 处的梯度应为零。但谢里阳等(182-046)发现：由于有限样本不确定性，统计最小差异点相对于确定性极值点存在系统性正偏移——即梯度在真实 γ 处并不恰好为零，而是偏大于零。若以零梯度为判据，某些样本（尤其小样本、低 β 场合）的 γ̂ 会产生巨大误差。

修正方案(182-046)：将判据从"梯度 = 0"改为"梯度 = δ"（δ > 0）：

$$\left.\frac{\partial \sigma_{\eta,\min}(\gamma)}{\partial \gamma}\right|_{\gamma=\hat{\gamma}} = \delta$$

引入 δ > 0 的效果是使搜索点从极值谷底向 γ 增大方向（即靠近 $t_{(1)}$）移动一小步，补偿有限样本的系统性正偏。谢里阳等取 δ = 0.1（经验值），显著提升了位置参数估计的稳健性。

**本文的研究对象即此 δ**：它是经验常数，还是可优化的决策变量？

## §2 六级信息层级框架

### 3.2.1 定义

δ 的最优值取决于"决策时掌握多少信息"。本文将 δ 的决策粒度定义为六个层级：

| 层级 | 决策粒度 | 实现方式 | 性质 |
|------|---------|---------|------|
| **Default** | δ = 0.1（固定） | 原文经验值 | 基线 |
| **L1** | 全局最优常数 δ* | 直接取 | 可部署 |
| **L2** | 每个 n 一个 δ* | 查表 | 可部署 |
| **L3** | 每个 β 一个 δ* | — | oracle（真 β 不可知） |
| **L4** | 每个 (β, n) 一个 δ* | — | oracle |
| **L5** | 每个 (β, γ/η, n) 一个 δ* | — | oracle |
| **L6** | 逐样本 δ* | — | hindsight oracle（精度上限） |

层级从上到下，决策时使用的信息量递增，可实现的精度上限也递增（**图 1**）。

![Figure 1: 六级框架示意图](artifacts/formal/figures/fig1_framework.png)

**Figure 1.** 六级信息层级框架与实验映射。左侧：Default→L6 层级（灰=可部署，蓝=oracle，橙=hindsight），每层标注 J₁ 和相对 Default 的改善幅度。右侧：E1–E4 实验对应章节。蓝色虚线表示 NN 的桥接角色——从样本可观测特征学习 oracle 层级的 δ\* 映射，实现可部署的高精度选择。

### 3.2.2 可部署层级与 oracle 层级

**L1、L2 为可部署层级**：决策只需样本量 n 或全局统计，实际使用中可直接查表。

**L3–L6 为 oracle 层级**：决策需要真参数（β, γ/η），而真参数在实际中不可知。这四个层级的作用是量化"如果拥有相应信息，精度上限在哪里"，为评估可部署方案（L1/L2/NN）提供参照。

### 3.2.3 NN 的角色

L3 起真 β 不可知，因此 L3–L5 无法直接部署。本文在第 6 章提出用神经网络从样本可观测特征学习"样本 → 最优 δ"映射，目标是逼近 oracle 层级的精度。L6（逐样本 hindsight）是不可逾越的精度上限——即使逐样本选最优 δ，也不存在更好的选择。

## §4 评价指标

### 3.4.1 主指标 J₁

$$J_1 = \sqrt{\frac{1}{R}\sum_{i=1}^{R}\left[\left(\frac{\hat{\beta}_i - \beta}{\beta}\right)^2 + \left(\frac{\hat{\eta}_i - \eta}{\eta}\right)^2 + \left(\frac{\hat{\gamma}_i - \gamma}{\eta}\right)^2\right]}$$

J₁ 为三参数相对误差的联合均方根。设计要点：

- **γ 归一化除 η**（尺度参数真值），不除 γ 自身——避免 γ → 0 时分母奇异。
- **等权**（$w_\beta = w_\eta = w_\gamma = 1$）——三参数贡献等价。
- **聚合规则**：先对所有重复的未开方贡献取均值，再开方。即 $\sqrt{\text{mean}(j_{1,i}^2)}$，而非 $\text{mean}(\sqrt{j_{1,i}^2})$。前者是 RMS，后者会低估极端误差。
- **文献先例**：182-050 / 182-097 的 Joint RMSE 列；J₁ 为其相对误差变体。

### 3.4.2 辅助指标

- **每参数 Bias**：$\text{mean}(\hat{\theta}) - \theta$，诊断系统偏差方向。
- **每参数 SD**：$\text{std}(\hat{\theta})$，诊断估计波动。
- **失败率**：收敛失败次数 / 总重复次数。失败率为 gate 条件（过高则该参数组合的结论需附说明），不参与排名。

## §5 对比方法：标准 MLE 锚点

本文不进行 MDM vs MLE vs LSE 的方法横评——这一比较在原文中已有充分论证(182-030; 182-046)。标准 MLE 仅作为精度参照锚点出现在主结果表中，让读者判断 MDM 优化后的绝对水平。

MLE 实现：标准极大似然，约束 γ < $t_{(1)}$，不引入修正版（MMLE、WMLE 等）。MLE 使用与 MDM 相同的参数网格和同一 MC 种子协议。

预期表现：主网格 β ∈ {1.5, 2.0} 处于 MLE 不稳定区间(182-090; 182-091)，MLE 的失败率和偏差将较高——这恰好展示 MDM 的优势（MDM 原文卖点之一），无需额外辩护。
