# 第3章 实验设计

## §1 最优 δ 的操作性定义

本文不证明连续 δ 空间中存在唯一的理论最优值。相反，给定信息层级 L、偏移量网格 D 和正式 Monte Carlo 风险函数 J₁，本文在网格上定义最优 δ 为风险最小化问题的 argmin：

$$\delta^*_L(g) = \arg\min_{\delta \in D} J_1(g, \delta)$$

其中 D = {0.00, 0.02, 0.04, …, 0.50}（26 点，步长 0.02），g 标识参数条件（如 (β, γ/η, n) 组合，或逐样本索引），L 标识决策时可用的信息层级（见 §2）。J₁ 的定义见 §4。

这一定义有几个重要性质。第一，δ* 是网格 argmin，不是连续空间最优；网格外的 δ 值未被检验，本文不外推。第二，δ* 依赖于信息层级 L：同一组数据，在不同层级（全局、按 n、按 β、逐样本）下会得到不同的 δ* 和不同的 J₁。本文的"最优"始终是"在某个信息层级下的网格 argmin"，不存在脱离层级的唯一最优。第三，若某层级下的风险曲线 J₁(δ) 在 δ* 邻域平坦，或多个 δ 对应的 J₁ 接近，本文只报告这种平坦性和相应边际收益，不夸大 δ* 的唯一性。

层级 L 的具体定义、各级 δ* 的决策粒度和后续用途见 §2。

## §2 六级信息层级框架

δ 的最优值取决于"决策时掌握多少信息"。本文将 δ 的决策粒度定义为六个层级（**表 1**）。

**Table 1.** L1–L6 信息层级与实验合同

| 层级 | 可用信息 | 决策粒度 | δ* 定义 | 性质 | 后续用途 | 禁止误读 |
|------|---------|---------|---------|------|---------|---------|
| **Default** | 无 | δ = 0.1（固定） | 原文经验值，非 argmin | 基线 | E1/E2 对照锚点 | 不写为"已证明最优" |
| **L1** | 无（全局） | 一个全局常数 δ* | argmin over D，g = 全部 | 可部署 | E1；回答"全局最优常数是多少" | 不写为"严格最优"；L1 收益小不等于无改进空间 |
| **L2** | n | 每个 n 一个 δ* | argmin over D，g = (n) | 可部署 | E1；回答"按 n 查表能改善多少" | 不写为"n 是 δ* 的主效应" |
| **L3** | β | 每个 β 一个 δ* | argmin over D，g = (β) | oracle（真 β 不可知） | E2；E3 学习标签候选 | 不写为"可部署"；不写为"只需要 β" |
| **L4** | β + n | 每个 (β, n) 一个 δ* | argmin over D，g = (β, n) | oracle | E2；E3 主标签候选 | 不写为"可部署"；不写为"n 不重要" |
| **L5** | β + γ/η + n | 每个 (β, γ/η, n) 一个 δ* | argmin over D，g = (β, γ/η, n) | oracle | E2；E3 标签候选 | 不写为"可部署"；γ/η 是次级调节项 |
| **L6** | 逐样本 | 每个 MC 重复一个 δ* | argmin over D，g = 样本索引 | hindsight benchmark | E2；sample-level hindsight target test；诊断消融 | 不写为"可部署"或"理论上限"；含逐样本偶然性 |

表中 Default/L1/L2 为可部署层级——决策只需样本量 n 或全局统计，实际使用中可直接查表。L3–L5 为 oracle 参照层级——决策需要真参数（β, γ/η），实际部署中不可知，其作用是量化"如果拥有相应信息，参照精度在哪里"。L6 为扫描网格内的逐样本 hindsight benchmark——事后回看每个样本在哪个离散网格点上 J₁ 最低；它是离散网格上的参照基准，而非连续 δ 空间内的全局最优，网格外的 δ 值未被检验。

层级从上到下，决策时使用的信息量递增，对应的参照精度也逐级提高（**图 2**）。

### 样本自适应方法的角色

L3 起需要真 β 或更多真参数信息，因此 L3–L5 不能直接作为部署查表方案。第 6 章要回答的不是"神经网络能否改进 MDM"这一孤立问题，而是：在实际部署只能看到样本值和样本量 n 的条件下，是否能构造一个样本自适应选择器，使预测的 δ 接近 L3–L6 参照阶梯中的一部分收益。神经网络在本文 Formal E3 中是这一选择器的主要候选实现，因为它可以从样本统计特征中学习非线性风险曲线；但它服务的是样本自适应 δ 选择问题，而不是为了把论文写成单独的 ML 模型论文。若结果显示收益不足，论文结论也应如实回到固定常数或按 n 查表策略。

## §3 Monte Carlo 实验协议

### 3.3.1 参数网格

实验覆盖三参数 Weibull 的典型小样本应用区间（**表 2**）。

**Table 2.** 参数网格与实验配置

| 参数 | 符号 | 取值 | 说明 |
|------|------|------|------|
| 形状参数 | β | {1.5, 2.0, 2.5, 4.0, 5.0} | 覆盖早期失效（β < 2，MLE 不稳定区间）到老化失效 |
| 尺度参数 | η | {1.0} | 归一化基准（Weibull 尺度不变性） |
| 位置参数比 | γ/η | {0.1, 0.5, 1.0} | 失效阈值相对于特征寿命的比例 |
| 样本量 | n | {7, 10, 20} | 典型小样本范围 |
| 参数组合数 | — | 45 | 5β × 1η × 3γ/η × 3n |
| 偏移量网格 | δ | {0.00, 0.02, …, 0.50} | 26 点，步长 0.02 |
| 蒙特卡洛重复 | R | 1000 | E1/E2 主网格 |
| 种子命名空间 | — | study01_v1 | 可复现 |

共 45 参数组合 × 26 δ × R=1000 = **117 万次 MDM 估计**。

数据溯源：`code/config.py`，`artifacts/formal/E1_baseline/manifest.json`

样本量 n 是本文必须保留的分层视角。它既对应 L2 的直接部署方式（按 n 查表），也决定小样本估计问题的工程语境。因此，后续 E1/E2 的主表可报告 pooled 结果，但正文解释、附表或稳健性检查必须保留按 n 分解的诊断；E3/E4 也应检查不同 n 下样本自适应策略是否表现一致。

### 3.3.2 δ 搜索网格

$$\delta \in \{0.00, 0.02, 0.04, \ldots, 0.50\}$$

共 26 个点，步长 0.02。范围覆盖原文 δ = 0.1 的邻域，并延伸到 δ = 0（无偏移）和 δ = 0.50（过大偏移）以刻画完整的 δ-risk 曲线。

### 3.3.3 蒙特卡洛重复

每个参数组合 × 每个 δ 重复 $R = 1000$ 次。E1 和 E2 共用同一批 MC 扫描数据，由统一的数据生成脚本产出（`code/generate_mc_data.py`），两个独立分析脚本按不同粒度聚合。

总计算量：45 组合 × 26 δ × 1000 重复 = **117 万次 MDM 估计**，另含 MLE 锚点 4.5 万次。

### 3.3.4 随机种子

所有实验使用统一种子命名空间 `study01_v1`，保证 (参数组合, δ, 重复序号) 到随机种子的映射确定且可复现。

## §4 评价指标

### 3.4.1 主指标 J₁

$$J_1 = \sqrt{\frac{1}{R}\sum_{i=1}^{R}\left[\left(\frac{\hat{\beta}_i - \beta}{\beta}\right)^2 + \left(\frac{\hat{\eta}_i - \eta}{\eta}\right)^2 + \left(\frac{\hat{\gamma}_i - \gamma}{\eta}\right)^2\right]}$$

J₁ 为三参数相对误差的联合均方根。设计要点：

- **γ 归一化除 η**（尺度参数真值），不除 γ 自身——避免 γ → 0 时分母奇异。
- **等权**（$w_\beta = w_\eta = w_\gamma = 1$）——三参数贡献等价。
- **聚合规则**：先对所有重复的未开方贡献取均值，再开方。即 $\sqrt{\text{mean}(j_{1,i}^2)}$，而非 $\text{mean}(\sqrt{j_{1,i}^2})$。前者是 RMS，后者会低估极端误差。
- **文献先例**：182-050 / 182-097 的 Joint RMSE 列；J₁ 为其相对误差变体。

### 3.4.2 辅助指标

- **每参数 Bias**：$\text{mean}(\hat{\theta}) - \theta$，诊断系统偏差方向。
- **每参数 SD**：$\text{std}(\hat{\theta})$，诊断估计波动。
- **失败率**：收敛失败次数 / 总重复次数。失败率为 gate 条件（过高则该参数组合的结论需附说明），不参与排名。

## §5 对比方法：标准 MLE 锚点

本文不进行 MDM vs MLE vs LSE 的方法横评——这一比较在原文中已有充分论证(182-030; 182-046)。标准 MLE 仅作为精度参照锚点出现在主结果表中，让读者判断 MDM 优化后的绝对水平。

MLE 实现：标准极大似然，约束 γ < $t_{(1)}$，不引入修正版（MMLE、WMLE 等）。MLE 使用与 MDM 相同的参数网格和同一 MC 种子协议。

MLE 锚点的作用是给出绝对精度参照，而不是重新展开 MDM 与 MLE 的优劣论证。若 MLE 在 β 较小区间出现较高失败率，应在结果表中报告，但不把它作为本文主问题。
