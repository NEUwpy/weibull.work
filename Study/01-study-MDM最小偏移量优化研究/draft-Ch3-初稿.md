# 第3章 实验设计

## §1 最优 δ 的操作性定义

本文不证明连续 δ 空间中存在唯一的理论最优值。为了严格区分“逐样本选择目标”与“多样本汇总评价指标”，先定义第 i 个 Monte Carlo 样本在偏移量 δ 下的未开方联合损失：

$$
\ell_i(\delta)=
\left(\frac{\hat\beta_i(\delta)-\beta}{\beta}\right)^2+
\left(\frac{\hat\eta_i(\delta)-\eta}{\eta}\right)^2+
\left(\frac{\hat\gamma_i(\delta)-\gamma}{\eta}\right)^2.
$$

对 L1–L5，令 $G_L(g)$ 表示由层级 L 和分组条件 g 确定的重复样本集，定义组级风险

$$
R_L(g,\delta)=
\sqrt{\frac{1}{|G_L(g)|}\sum_{i\in G_L(g)}\ell_i(\delta)},
\qquad
\delta_L^*(g)=\arg\min_{\delta\in D}R_L(g,\delta).
$$

对 L6，不再对多个重复先聚合，而是对每个样本单独选择

$$
\delta_i^*=\arg\min_{\delta\in D}\ell_i(\delta).
$$

其中 $D=\{0.00,0.02,0.04,\ldots,0.50\}$（26 点，步长 0.02），g 在 L1–L5 中分别标识全局、$n$、$\beta$、$(\beta,n)$ 或 $(\beta,\gamma/\eta,n)$ 分组，L 标识决策时可用的信息层级（见 §2）。最终用于跨样本比较各种选择规则的 $J_1$ 见 §4；$J_1$ 不作为“单个样本的损失”名称。本文所说的“全局”限定为正式设计网格：45 个 $(\beta,\gamma/\eta,n)$ 组合均有相同的 Monte Carlo 重复数，因而在 pooled 风险中等权。这是设计网格测度，不代表真实应用中各参数条件的出现频率。

这一定义有几个重要性质。第一，δ* 是网格 argmin，不是连续空间最优；网格外的 δ 值未被检验，本文不外推。第二，δ* 依赖于信息层级 L：同一批数据，在不同层级（全局、按 n、按 β、逐样本）下会得到不同的 δ* 选择规则和最终 $J_1$。本文的"最优"始终是"在某个信息层级下的网格 argmin"，不存在脱离层级的唯一最优。第三，若 L1–L5 的组级风险曲线 $R_L(g,\delta)$ 在 δ* 邻域平坦，或多个 δ 对应的风险接近，本文只报告这种平坦性和相应边际收益，不夸大 δ* 的唯一性。

层级 L 的具体定义、各级 δ* 的决策粒度和后续用途见 §2。

## §2 六级信息层级框架

δ 的最优值取决于"决策时掌握多少信息"。本文将 δ 的决策粒度定义为六个层级（**表 1**）。

**Table 1.** L1–L6 信息层级与实验合同

| 层级 | 可用信息 | 决策粒度 | δ* 定义 | 性质 | 后续用途 | 禁止误读 |
|------|---------|---------|---------|------|---------|---------|
| **Default** | 无 | δ = 0.1（固定） | 原文经验值，非 argmin | 基线 | E1/E2 对照锚点 | 不写为"已证明最优" |
| **L1** | 无（形式设计网格等权） | 一个 pooled 常数 δ* | $\arg\min_{\delta\in D}R_{L1}(\delta)$ | 可部署 | E1；回答"设计网格的等权最优常数是多少" | 不写为真实应用分布或所有 Weibull 条件下的普遍最优；L1 收益小不等于无改进空间 |
| **L2** | n | 每个 n 一个 δ* | $\arg\min_{\delta\in D}R_{L2}(n,\delta)$ | 可部署 | E1；回答"按 n 查表能改善多少" | 不写为"n 是 δ* 的主效应" |
| **L3** | β | 每个 β 一个 δ* | $\arg\min_{\delta\in D}R_{L3}(\beta,\delta)$ | oracle（真 β 不可知） | E2；E3 组级监督参照 | 不写为"可部署"；不写为"只需要 β" |
| **L4** | β + n | 每个 (β, n) 一个 δ* | $\arg\min_{\delta\in D}R_{L4}(\beta,n,\delta)$ | oracle | E2；E3 组级监督参照 | 不写为"可部署"；不写为"n 不重要" |
| **L5** | β + γ/η + n | 每个 (β, γ/η, n) 一个 δ* | $\arg\min_{\delta\in D}R_{L5}(\beta,\gamma/\eta,n,\delta)$ | oracle | E2；E3 组级监督参照 | 不写为"可部署"；γ/η 是次级调节项 |
| **L6** | 逐样本事后损失 | 每个 MC 重复一个 δ* | $\arg\min_{\delta\in D}\ell_i(\delta)$ | hindsight benchmark | E2；sample-level hindsight target test；诊断消融 | 不写为“单样本 $J_1$”、"可部署"或"理论上限"；含逐样本偶然性 |

表中 Default/L1/L2 为可部署层级——决策只需样本量 n 或全局统计，实际使用中可直接查表。L3–L5 为 oracle 参照层级——决策需要真参数（β, γ/η），实际部署中不可知，其作用是量化"如果拥有相应信息，参照精度在哪里"。L6 为扫描网格内的逐样本 hindsight benchmark——事后回看每个样本在哪个离散网格点上 $\ell_i(\delta)$ 最低；它是离散网格上的参照基准，而非连续 δ 空间内的全局最优，网格外的 δ 值未被检验。

层级从上到下，决策时使用的信息量递增，对应的参照精度也逐级提高（**图 2**）。

![Figure 2: 六级框架示意图](artifacts/formal/figures/fig1_framework.png)

**Figure 2.** 信息层级与验证路径。左侧概括 Default–L6 的逻辑关系：Default、L1 和 L2 不需要真参数，L3–L5 是依赖真参数的 oracle 参照，L6 是使用事后逐样本损失的 hindsight 参照；各层级的精确定义以表 1 为准。右侧给出最终论文的验证逻辑：E1 评估简单可部署层级，E2 建立 oracle/hindsight 参照，E3 用样本可观测特征预测 26 点风险曲线并选择 δ，E4 考察稳健性与边界，真实数据再以重复小样本留出验证检验外部适用性。图中不呈现内部实验进度或结果数字。

### 样本自适应方法的角色

L3 起需要真 β 或更多真参数信息，因此 L3–L5 不能直接作为部署查表方案。第 6 章要回答的不是"神经网络能否改进 MDM"这一孤立问题，而是：在实际部署只能看到样本值和样本量 n 的条件下，是否能构造一个样本自适应选择器，学习从可观测样本特征到 26 点风险曲线的映射，再由曲线的网格 argmin 选择 δ，以获得 L3–L6 参照阶梯中的一部分收益。神经网络是 Formal E3 的主要实现方法；它服务的是样本自适应 δ 选择问题，而不是为了把论文写成单独的 ML 模型论文。

## §3 Monte Carlo 实验协议

### 3.3.1 参数网格

实验覆盖三参数 Weibull 的典型小样本应用区间（**表 2**）。

**Table 2.** 参数网格与实验配置

| 参数 | 符号 | 取值 | 说明 |
|------|------|------|------|
| 形状参数 | β | {1.5, 2.0, 2.5, 4.0, 5.0} | 覆盖早期失效（β < 2，MLE 不稳定区间）到老化失效 |
| 尺度参数 | η | {1.0} | 归一化基准（MDM 尺度等变性，见 Ch2） |
| 位置参数比 | γ/η | {0.1, 0.5, 1.0} | 失效阈值相对于特征寿命的比例 |
| 样本量 | n | {7, 10, 20} | 典型小样本范围 |
| 参数组合数 | — | 45 | 5β × 1η × 3γ/η × 3n |
| 偏移量网格 | δ | {0.00, 0.02, …, 0.50} | 26 点，步长 0.02 |
| 蒙特卡洛重复 | R | 1000 | E1/E2 主网格 |
| 种子命名空间 | — | study01_v1 | 可复现 |

共 45 参数组合 × 26 δ × R=1000 = **117 万次 MDM 估计**。

每个参数组合的重复数相同，因而 pooled 指标对 45 个设计格点等权。这一等权统计定义了本文 L1 的“全局”口径；若真实应用中的参数分布不同，应用加权风险可能对应不同的最优 δ。

尺度参数只取 $\eta=1$ 并非忽略尺度效应。Ch2 已证明：对寿命数据及 $(\eta,\gamma)$ 同乘任意 $c>0$，MDM 在固定 δ 下保持 $\hat\beta$ 不变，$\hat\eta$ 和 $\hat\gamma$ 同比例缩放，而 $\ell_i(\delta)$、风险排序和网格最优 δ 不变。因此，在保留 $\gamma/\eta$ 的条件下，$\eta=1$ 是对所有正尺度的合法归一化。对应数值合同由 `python/tests/test_mdm_s49.py::test_default_mdm_is_scale_equivariant_for_fixed_offset` 锁定。

数据溯源：`code/config.py`，`artifacts/formal/E1_baseline/manifest.json`

样本量 n 是本文必须保留的分层视角。它既对应 L2 的直接部署方式（按 n 查表），也决定小样本估计问题的工程语境。因此，后续 E1/E2 的主表可报告 pooled 结果，但正文解释、附表或稳健性检查必须保留按 n 分解的诊断；E3/E4 也应检查不同 n 下样本自适应策略是否表现一致。

### 3.3.2 δ 搜索网格

$$\delta \in \{0.00, 0.02, 0.04, \ldots, 0.50\}$$

共 26 个点，步长 0.02。范围覆盖原文 δ = 0.1 的邻域，并延伸到 δ = 0（无偏移）和 δ = 0.50（过大偏移）以刻画完整的 δ-risk 曲线。

### 3.3.3 蒙特卡洛重复

每个参数组合 × 每个 δ 重复 $R = 1000$ 次。E1 和 E2 共用同一批 MC 扫描数据，由统一的数据生成脚本产出（`code/generate_mc_data.py`），两个独立分析脚本按不同粒度聚合。

E1/E2 的全缓存风险曲线和网格 argmin 用于定义层级及展示经验设计风险。为检查“在同一批重复中选点又评价”可能带来的择优偏差，本文另对 L1–L5 进行 5 折 `repeat_id` cross-fitting：每折用 800 个 repeat id 选择各层级 δ，在未参与选点的 200 个 repeat id 上评价，最后汇总所有留出损失。Default 不需选点；L6 是定义上的逐样本 hindsight benchmark，故不伪装为 cross-fitted 部署性能。该审计复用现有 MC 缓存，不重跑 MDM；产物见 `artifacts/formal/E1_E2_crossfit/`。

总计算量：45 组合 × 26 δ × 1000 重复 = **117 万次 MDM 估计**，另含 MLE 锚点 4.5 万次。

### 3.3.4 随机种子

所有实验使用统一种子命名空间 `study01_v1`，保证 (参数组合, δ, 重复序号) 到随机种子的映射确定且可复现。

## §4 评价指标

### 3.4.1 主指标 J₁

$$J_1(\{\hat\delta_i\}) = \sqrt{\frac{1}{R}\sum_{i=1}^{R}\ell_i(\hat\delta_i)}$$

J₁ 为某一偏移量选择规则 $\{\hat\delta_i\}$ 在多个重复样本上的三参数联合均方根误差。对固定或组级规则，多个样本可共用同一 $\hat\delta_i$ 值；对样本自适应规则，$\hat\delta_i$ 可随样本变化。设计要点：

- **γ 归一化除 η**（尺度参数真值），不除 γ 自身——避免 γ → 0 时分母奇异。
- **参数分量等权**（$w_\beta = w_\eta = w_\gamma = 1$）——单样本损失中三个参数贡献等权。这与 45 个设计格点在 pooled 风险中等权是两个不同层面。
- **聚合规则**：先对所有重复的未开方贡献取均值，再开方。即 $\sqrt{\text{mean}(j_{1,i}^2)}$，而非 $\text{mean}(\sqrt{j_{1,i}^2})$。前者是 RMS，后者会低估极端误差。
- **对象区分**：$\ell_i(\delta)$ 是单样本损失，$R_L(g,\delta)$ 是 L1–L5 的组级选择风险，$J_1$ 是对已选规则的最终跨样本评价；三者不互换命名。
- **文献先例**：182-050 / 182-097 的 Joint RMSE 列；J₁ 为其相对误差变体。

### 3.4.2 辅助指标

- **每参数 Bias**：$\text{mean}(\hat{\theta}) - \theta$，诊断系统偏差方向。
- **每参数 SD**：$\text{std}(\hat{\theta})$，诊断估计波动。
- **失败率**：收敛失败次数 / 总重复次数。失败率为 gate 条件（过高则该参数组合的结论需附说明），不参与排名。

## §5 对比方法：标准 MLE 锚点

本文不进行 MDM vs MLE vs LSE 的方法横评——这一比较在原文中已有充分论证(182-030; 182-046)。标准 MLE 仅作为精度参照锚点出现在主结果表中，让读者判断 MDM 优化后的绝对水平。

MLE 实现：标准极大似然，约束 γ < $t_{(1)}$，不引入修正版（MMLE、WMLE 等）。MLE 使用与 MDM 相同的参数网格和同一 MC 种子协议。

MLE 锚点的作用是给出绝对精度参照，而不是重新展开 MDM 与 MLE 的优劣论证。若 MLE 在 β 较小区间出现较高失败率，应在结果表中报告，但不把它作为本文主问题。
