# 第5章 Oracle 层级——L3 到 L6 的参照精度

第 4 章表明，全局常数（L1）和按 n 查表（L2）均无法系统性超越经验值 δ = 0.1。一个自然的问题是：如果**知道更多**——不仅知道 n，还知道 β、γ/η，甚至逐样本——精度能提升多少？本章在 oracle 条件下（真参数已知）回答这一问题，量化每一级信息的边际价值，并给出扫描网格内的逐样本 hindsight 参照。

**图 5** 和 **表 4** 展示了从 Default 到 L6 的完整精度阶梯。

阶梯呈现两个特征性跳变和一段平坦区：

- **L2→L3：+7.5%**——这是第一个大跳，即可部署层级与 oracle 层级之间的跨越。仅引入 β 信息（每个 β 对应一个最优 δ\*），就获得了全部可部署层级（Default/L1/L2，合计改善 ≤0.11%）无法触及的精度增益。
- **L3→L4→L5：+0.5% 和 +1.9%**——边际递减区。在 β 的基础上继续加入 n 和 γ/η，精度提升迅速衰减。
- **L5→L6：+13.4%**——第二个大跳。逐样本 hindsight 在本文扫描网格内给出了最低 J₁，但这一跳的特殊性质需要谨慎解读（§4）。

以下各节逐层分析。

## §2 L3：β 信息是主要驱动因素

L3 为每个 β 值分配一个最优 δ\*。结果如下：

| β | δ\*(L3) | J₁(L3) |
|---|--------|--------|
| 1.5 | 0.36 | 0.4689 |
| 2.0 | 0.20 | 0.5004 |
| 2.5 | 0.12 | 0.5397 |
| 4.0 | 0.04 | 0.6611 |
| 5.0 | 0.04 | 0.7161 |

**最优 δ\* 与 β 呈强负相关**：β = 1.5 时 δ\* = 0.36（需要大偏移补偿），β = 5.0 时 δ\* = 0.04（几乎不需要偏移）。这一单调趋势与第 4 章 §3 的分 β 分析完全一致——L1 全局 δ\* = 0.08 是这些方向相反的 δ\* 在聚合后抵消的结果。

**为什么 β 会成为主要分层变量？** 当前结果直接支持的是经验关系：β 越小，最优 δ 越大；β 越大，最优 δ 越接近低值。一个合理解释是，β 控制 Weibull 分布的形状曲率和尾部形态，进而影响有限样本下 profile 标准差曲线在极值附近的形态。但这一解释仍是机制假说，而不是独立证明；本文在主结论中只把 β 作为观测到的主要信息层级。

L3 以仅 5 个 δ\* 值（每个 β 一个）就获得了 +7.6% 的改善，说明**当前主网格中最大的 oracle 收益来自对 β 条件的自适应**。这为第 6 章提供了任务方向：样本自适应方法应优先学习与 β 相关的可观测形态特征，同时必须检查这种学习在不同 n 下是否稳定。

## §3 L4–L5：n 和 γ/η 的边际贡献

### L4（按 β+n）

L4 在 L3 基础上加入 n 信息，为每个 (β, n) 组合分配 δ\*。从 L3 到 L4，J₁ 仅从 0.5851 降至 0.5821（+0.5%）。

观察 L4 的 δ\* 表（**图 6**）可发现：β 是 δ\* 的主效应，n 是调节项。

![Figure 6: β×n δ* 热力图](artifacts/formal/figures/fig_l4_beta_n_heatmap.png)

**Figure 6.** L4 层级最优 δ\* 的 β×n 结构（数据来自 L4_by_beta_n.csv）。行为形状参数 β（1.5–5.0），列为样本量 n（7/10/20），颜色和数值为该 (β, n) 组合的最优 δ\*。行方向（固定 n，变 β）的 δ\* 跨度远大于列方向（固定 β，变 n）——β 的平均跨度为 0.37（如 n=10 时 β=1.5→δ\*=0.42，β=5.0→δ\*=0.04），而 n 的平均跨度仅 0.08。这说明 β 是决定 δ\* 方向的主效应，n 仅在固定 β 后起微弱调节作用。

对小 β（β = 1.5–2.0），n 越大 δ\* 略大（如 β=1.5：n=7→0.30，n=20→0.50）；对大 β（β = 4.0–5.0），n 几乎不影响 δ\*（β=4.0 各 n 均为 0.04–0.06，β=5.0 均为 0.02–0.04）。因此，n 可以作为分层诊断和部署变量保留，但它不是当前主网格中决定 δ\* 方向的主效应；从全局 J₁ 看，L3→L4 的收益仍只有 0.5%。

### L5（按 β+γ/η+n）

L5 进一步加入 γ/η 信息，J₁ 从 0.5821 降至 0.5712（+1.9%）。γ/η 的效应同样微弱：对固定 (β, n)，γ/η = 0.1（小位置参数）时 δ\* 通常略小于 γ/η = 1.0。例如 β = 5.0, n = 7 时，γ/η = 0.1 → δ\* = 0.00，γ/η = 1.0 → δ\* = 0.04。

### 边际递减的解读

L3→L4→L5 的边际收益（7.6% → 0.5% → 1.9%）表明：**在 β 之外继续添加参数信息，pooled J₁ 的回报迅速衰减**。这对实际部署有直接含义——样本自适应方法的首要任务是捕捉与 β 相关的形态信息，而不是追求逐参数 oracle 的完全复刻。但这并不等于 n 可以忽略：n 是实际使用时已知且低成本的信息，也是小样本可靠性估计中最容易被审稿人要求分层说明的变量。因此，后续 NN 或其他自适应策略即使以 β 相关特征为主，也必须报告不同 n 下的表现。

## §4 L6：逐样本 hindsight benchmark（扫描网格内）

L6 为每个 MC 重复样本单独选取最优 δ\*，是本文 δ 扫描网格（0.00–0.50，步长 0.02）上的逐样本 hindsight benchmark——事后回看每个样本在哪个离散网格点上 J₁ 最低。它反映的是离散网格上的参照基准，而非连续 δ 空间内的全局最优；网格外的 δ 值未被检验。

**图 7** 展示了 L6 的 δ\* 分布。

![Figure 7: L6 分布](artifacts/formal/figures/fig4_l6_distribution.png)

**Figure 7.** L6 逐样本最优 δ\* 分布。(a) 全样本直方图：47.5% 的样本最优 δ\* = 0，分布高度右偏。(b) 分 β 的 boxplot：β 越大，δ\* 分布越集中于低值。β = 1.5 的中位数为 0.04 但 IQR 延伸至 0.46，β = 5.0 的中位数为 0 且 IQR 仅到 0.04。

L6 的 J₁ = 0.4945，相比 L5 改善 13.4%——看似可观，但需要谨慎解读：

1. **δ\* = 0 的堆积**。47.5% 的样本最优 δ\* 恰好为零。这不是说"这些样本不需要偏移"，而是 δ grid 上 δ = 0 恰好对这些 MC 样本给出了最低 J₁；这一现象提示 L6 含有较强的逐样本偶然性。

2. **L6 的不可部署性**。L6 的最优 δ\* 是事后（hindsight）选出的——实际使用中不可能事先知道某个新样本的最优 δ。L6 的价值在于给出扫描网格内的 hindsight 参照，而非作为部署目标。

3. **L6 可以作为压力测试参照，但不能写成部署目标**。L5 的 J₁ = 0.5712 是"组级真参数信息能达成的参照"，而样本自适应方法的任务是用可观测样本特征尽量逼近或解释 oracle/hindsight 阶梯中的可学习部分。L6 的 +13.4% 中有相当部分来自逐样本差异和偶然性，因此它适合作为 sample-level hindsight target test 或诊断上界参照；若 E3 使用 L6 监督粒度，必须用真实 selected-loss J₁、near-optimal/regret 和边界诊断解释结果，不能把 L6 写成实际部署目标。

## §5 MLE 锚点

标准 MLE 在同一参数网格上的表现为 J₁ = 1.1009（仅算收敛样本），失败率 30.4%。这一数值只作为绝对精度锚点：它说明 Default MDM（J₁ = 0.6332）已经处在较低误差水平，而本文讨论的是在 MDM 内部继续选择 δ 能否进一步降低误差。本文不把 MLE 作为新的横向比较主线。

## §6 本章小结

- **精度阶梯的两个跳点**：L2→L3（+7.5%，β 信息是主要驱动因素，即可部署层级到 oracle 的跨越）和 L5→L6（+13.4%，逐样本 hindsight benchmark）。
- **边际递减点在 L3**：在 β 基础上继续加入 n（L4）和 γ/η（L5），pooled J₁ 每级改善 ≤1.9%。精度提升的核心是 β 自适应，但 n 仍应作为可部署查表变量和小样本诊断维度保留。
- **L6 是扫描网格内的 hindsight benchmark 但不可部署**：47.5% 的样本 δ\* = 0 反映了逐样本 hindsight 的偶然性和边界性。它可以作为 E3 的 sample-level target test，但结果必须回到 selected-loss 和边界诊断解释，不能被写成可直接部署的目标。

结论：**oracle 精度的最大增益来自 β 信息，但 n 仍是部署和审稿解释中不可省略的维度。** L3 以 5 个 δ\* 值获取了大部分收益，L4/L5 的 pooled 边际改善有限，L6 则给出逐样本 hindsight 的压力测试参照。这意味着第 6 章的样本自适应方法应优先学习与 β 相关的样本形态，同时按 n 分层检验其收益是否稳定，并清楚区分可部署输入、oracle 参照和 hindsight 诊断。
