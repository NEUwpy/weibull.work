# 第5章 Oracle 层级——L3 到 L6 的精度上限

第 4 章表明，全局常数（L1）和按 n 查表（L2）均无法系统性超越经验值 δ = 0.1。一个自然的问题是：如果**知道更多**——不仅知道 n，还知道 β、γ/η，甚至逐样本——精度能提升多少？本章在 oracle 条件下（真参数已知）回答这一问题，量化每一级信息的边际价值，识别精度天花板。

## §1 阶梯总览：Default → L6

**图 3** 和 **表 3** 展示了从 Default 到 L6 的完整精度阶梯。

阶梯呈现两个特征性跳变和一段平坦区：

- **L1→L3：+7.6%**——这是第一个大跳。仅引入 β 信息（每个 β 对应一个最优 δ\*），就获得了全部可部署层级无法触及的精度增益。
- **L3→L4→L5：+0.5% 和 +1.9%**——边际递减区。在 β 的基础上继续加入 n 和 γ/η，精度提升迅速衰减。
- **L5→L6：+13.4%**——第二个大跳。逐样本 hindsight 将精度推至本文扫描范围内的 hindsight 上限，但这一跳的特殊性质需要谨慎解读（§4）。

以下各节逐层分析。

## §2 L3：β 信息是决定性因素

L3 为每个 β 值分配一个最优 δ\*。结果如下：

| β | δ\*(L3) | J₁(L3) |
|---|--------|--------|
| 1.5 | 0.36 | 0.4689 |
| 2.0 | 0.20 | 0.5004 |
| 2.5 | 0.12 | 0.5397 |
| 4.0 | 0.04 | 0.6611 |
| 5.0 | 0.04 | 0.7161 |

**最优 δ\* 与 β 呈强负相关**：β = 1.5 时 δ\* = 0.36（需要大偏移补偿），β = 5.0 时 δ\* = 0.04（几乎不需要偏移）。这一单调趋势与第 4 章 §3 的分 β 分析完全一致——L1 全局 δ\* = 0.08 是这些方向相反的 δ\* 在聚合后抵消的结果。

**为什么 β 是 δ 的决定性因素？** β 控制 Weibull 分布的形状曲率。小 β（分布右偏严重，尾部衰减缓慢）时，σ_η profile 在真实 γ 附近的梯度较大，需要更大的 δ 来补偿系统性正偏移；大 β（分布接近对称）时，profile 更尖锐，梯度偏差小，δ\* 趋近于零。n 和 γ/η 对 profile 梯度的影响是二阶的，因此它们在 L4/L5 中的边际贡献远小于 β。

L3 以仅 5 个 δ\* 值（每个 β 一个）就获得了 +7.6% 的改善，说明**精度提升的关键不在数据量的增加，而在对 β 条件的自适应**。这正是 NN 方案（第 6 章）的科学基础：只要 NN 能从样本特征准确推断 β 类别，就能获取 L3 级别的绝大部分精度收益。

## §3 L4–L5：n 和 γ/η 的边际贡献

### L4（按 β+n）

L4 在 L3 基础上加入 n 信息，为每个 (β, n) 组合分配 δ\*。从 L3 到 L4，J₁ 仅从 0.5851 降至 0.5821（+0.5%）。

观察 L4 的 δ\* 表可发现一个微弱趋势：对固定 β，n 越大 δ\* 略大。例如 β = 1.5 时，n = 7 → δ\* = 0.30，n = 20 → δ\* = 0.50。这与 MDM 的搜索机制一致：n 越大，样本信息越充分，σ_η profile 越尖锐，最优偏移略增以进一步抑制残余偏差。但这一效应量级很小——在大多数 (β, n) 组合中，L4 的 δ\* 与 L3 差不超过一个 δ grid 步长（0.02）。

### L5（按 β+γ/η+n）

L5 进一步加入 γ/η 信息，J₁ 从 0.5821 降至 0.5712（+1.9%）。γ/η 的效应同样微弱：对固定 (β, n)，γ/η = 0.1（小位置参数）时 δ\* 通常略小于 γ/η = 1.0。例如 β = 5.0, n = 7 时，γ/η = 0.1 → δ\* = 0.00，γ/η = 1.0 → δ\* = 0.04。

### 边际递减的解读

L3→L4→L5 的边际收益（7.6% → 0.5% → 1.9%）表明：**在 β 之外继续添加参数信息，回报迅速衰减**。这对实际部署有直接含义——NN 只需从样本特征推断 β 的粗粒度类别（如"低 β / 高 β"），就能获取 oracle 精度的大部分收益。精确推断 n 和 γ/η 的需求不强。

## §4 L6：逐样本 hindsight 上限（扫描范围内）

L6 为每个 MC 重复样本单独选取最优 δ\*，是本文 δ 扫描网格（0.00–0.50，步长 0.02）和 MDM 偏移量机制内的 hindsight 上限（在该扫描范围内，逐样本 hindsight 不存在更好的选择）。

**图 4** 展示了 L6 的 δ\* 分布。

![Figure 4: L6 分布](artifacts/formal/figures/fig4_l6_distribution.png)

**Figure 4.** L6 逐样本最优 δ\* 分布。(a) 全样本直方图：47.5% 的样本最优 δ\* = 0，分布高度右偏。(b) 分 β 的 boxplot：β 越大，δ\* 分布越集中于低值。β = 1.5 的中位数为 0.04 但 IQR 延伸至 0.46，β = 5.0 的中位数为 0 且 IQR 仅到 0.04。

L6 的 J₁ = 0.4945，相比 L5 改善 13.4%——看似可观，但需要谨慎解读：

1. **δ\* = 0 的堆积**。47.5% 的样本最优 δ\* 恰好为零。这不是说"这些样本不需要偏移"，而是 δ grid 上 δ = 0 恰好对这些 MC 样本给出了最低 J₁——部分原因是采样噪声（单个样本在某次 MC 重复中碰巧 δ = 0 最优）。

2. **L6 的不可部署性**。L6 的最优 δ\* 是事后（hindsight）选出的——实际使用中不可能事先知道某个新样本的最优 δ。L6 的价值在于**定义精度天花板**，而非作为部署目标。

3. **实际可部署目标应锁定 L3–L5**。L5 的 J₁ = 0.5712 是"组级信息能达成的最优"，而 NN 的任务是从样本特征逼近这一水平。L6 的 +13.4% 中有相当部分来自逐样本噪声，不应作为 NN 的训练标签或评估基准。

## §5 MLE 锚点

标准 MLE 在同一参数网格上的表现为 J₁ = 1.1009（仅算收敛样本），失败率 30.4%。按 β 分解：

| β | MLE J₁ | MLE 失败率 |
|---|--------|-----------|
| 1.5 | 1.1091 | 54.1% |
| 2.0 | 1.0665 | 35.5% |
| 2.5 | 1.0298 | 27.6% |
| 4.0 | 1.1185 | 18.8% |
| 5.0 | 1.1628 | 15.9% |

MDM 在任何层级（含 Default δ = 0.1, J₁ = 0.6332）均显著优于 MLE。β < 2 区间 MLE 失败率超过 35%——这正是 Smith(182-090) 从理论上预测的 MLE 不稳定区间（β < 2 时 Fisher 信息矩阵发散），也是 MDM 原文(182-046)强调的优势区域。MLE 在 β ≥ 4 时失败率下降但 J₁ 仍高于 1.1，说明即使收敛，MLE 的估计偏差也远大于 MDM。

这一对比的意义不在于"MDM 击败 MLE"（原文已充分论证），而在于**标定 MDM 优化后的绝对水平**：Default MDM（J₁ = 0.63）已远优于 MLE（J₁ = 1.10），而 L6 oracle（J₁ = 0.49）进一步将这一优势扩大了 2.2 倍。

## §6 本章小结

- **精度阶梯的两个跳点**：L1→L3（+7.6%，β 信息是关键驱动因素）和 L5→L6（+13.4%，逐样本 hindsight 的扫描范围内上限）。
- **边际递减点在 L3**：在 β 基础上继续加入 n（L4）和 γ/η（L5），每级改善 ≤1.9%。精度提升的核心是 β 自适应，而非更细粒度的参数查表。
- **L6 是扫描范围内的 hindsight 上限但不可部署**：47.5% 的样本 δ\* = 0 反映了逐样本 hindsight 的噪声成分。实际可部署目标应锁定 L3–L5（J₁ ≈ 0.57–0.59）。
- **MDM 全层级优于 MLE**：即使不优化（Default），MDM 的 J₁ = 0.63 也远优于 MLE 的 J₁ = 1.10（失败率 30%）。

结论：**oracle 精度的关键信息是 β，而非 n 或 γ/η。** L3 以 5 个 δ\* 值获取了大部分收益，L4/L5 的边际改善有限。这意味着 NN 只需具备粗粒度的 β 推断能力，即可逼近 oracle 精度——第 6 章验证这一假设。
