## 研究要回答什么

三参数 Weibull 最小差异法（MDM）通过正偏移量 $\delta$ 改善有限样本估计的稳定性，但既有工作主要使用经验值 $\delta=0.1$。本研究回答两个问题：

1. 经验值是否已经接近合适的统一偏移量，进一步按不同信息选择偏移量还能改善多少？
2. 真参数未知时，能否只根据当前样本选择更合适的偏移量，同时仍由 MDM 完成三参数估计？

神经网络只是预测候选偏移量损失曲线的工具，不是论文主题。本文研究的是 MDM 估计器族内部的偏移量选择。

## 一句话结论

在当前设计域中，整体误差曲线在 $\delta=0.06$ 处最低，$\delta=0.08$ 与其几乎相同；经验值 $\delta=0.1$ 的 $J_1$ 仅比最低点高约 0.93%，因此仍可视为接近最佳统一常数。逐样本仍存在明显选择空间；以排序原始样本预测 26 个候选偏移量的损失曲线，可在不改变 MDM 参数估计过程的情况下，将 pooled $J_1$ 相对 $\delta=0.1$ 降低约 12.1%。

## 当前正式结果

### 1. 偏移量选择空间

同一套 160 组合新设计中，L1–L5 采用 repeat-id 五折交叉评价，L6 为逐样本事后参照：

| 规则 | 可用信息 | pooled $J_1$ |
|---|---|---:|
| Default | 固定 $\delta=0.1$ | 0.6304 |
| L1 | 全部样本共用一个偏移量 | 0.6252 |
| L2 | 样本量 $n$ | 0.6230 |
| L3 | 形状参数 $\beta$ | 0.5905 |
| L4 | $\beta,n$ | 0.5885 |
| L5 | $\beta,\gamma/\eta,n$ | 0.5813 |
| L6 | 每个样本的事后最优候选 | 0.4923 |

这说明重新寻找一个统一常数的收益很小，但根据更具体的信息选择偏移量仍有空间。L3–L5 依赖未知真参数，只是潜在收益参照；L6 使用事后结果，只是固定候选网格内的下界参照。

直接汇总全部样本的 26 点误差曲线时，$\delta=0.06,0.08,0.10$ 的 $J_1$ 分别为 0.624518、0.624666 和 0.630409。这里的最低点是描述性结果；经过选择/评价分离的 L1 交叉评价结果为 0.625198。

### 2. 可执行的样本自适应选择

最终方法按 $n\in\{7,10,15,20\}$ 分别训练网络：

```text
排序原始样本 X_n
  -> 训练折内逐位置标准化
  -> MLP (256-128-64)
  -> 26 点损失曲线
  -> argmin 选择 delta
  -> MDM 给出 beta、eta、gamma
```

正式设计固定 $\eta=1000$，取 8 个 $\beta$、5 个 $\gamma/\eta$ 水平和 4 个样本量，共 160 个组合、48,000 个样本、1,248,000 次候选偏移量估计。

| 方法 | pooled $J_1$ | $n=7$ | $n=10$ | $n=15$ | $n=20$ |
|---|---:|---:|---:|---:|---:|
| Dimensional-RAW-MLP | 0.5543 | 0.6901 | 0.5761 | 0.4855 | 0.4300 |
| Default ($\delta=0.1$) | 0.6304 | 0.7633 | 0.6571 | 0.5651 | 0.5058 |
| L6 hindsight | 0.4923 | 0.6083 | 0.5159 | 0.4319 | 0.3831 |

三 seed 的 pooled $J_1$ 为 0.5545、0.5523 和 0.5560，均值 0.5543，失败率为 0%。相对 Default 改善 12.08%。

### 3. 写作前支撑验证

#### B1：未见 $\beta$ 留出验证

按 $\beta$ 水平留出 8 折，每个留出 $\beta$ 用其余 7 个 $\beta$ 训练 per-n 网络，与 Default/L6 在同一留出样本上比较（`artifacts/formal/E6_dimensional_raw/unseen_beta/`）：

| 指标 | 数值 |
|---|---:|
| Dimensional-RAW 三 seed pooled $J_1$ | 0.5418（0.5388/0.5438/0.5428） |
| Default | 0.6304 |
| L6 hindsight | 0.4923 |
| 相对 Default 改善 | 14.06% |
| 失败率 | 0% |

每个留出 $\beta$ 上 Dimensional-RAW 均优于 Default（$\beta=1.5$：0.487 vs 0.548；$\beta=5.0$：0.652 vs 0.790），说明样本自适应收益在未见 $\beta$ 水平下保留。结果只限定于当前 8 点离散 $\beta$ 网格。pooled $J_1$ 按冻结定义 $\sqrt{\mathrm{mean}(\text{逐样本损失})}$ 直接汇总逐样本损失，不是各留出 $\beta$ 的 $J_1$ 平均。

#### B2：WMLE/LSE 同条件外部参照

使用当前 160 组合、同一 48,000 样本运行生产 WMLE/LSE（`artifacts/formal/E6_dimensional_raw/traditional_ref/`）：

| 方法 | pooled $J_1$ | $n=7$ | $n=10$ | $n=15$ | $n=20$ | 失败率 |
|---|---:|---:|---:|---:|---:|---:|
| WMLE | 0.7288 | 0.8125 | 0.7573 | 0.6902 | 0.6441 | 1/48000 |
| LSE | 0.8725 | 1.0417 | 0.9118 | 0.7858 | 0.7150 | 0% |

与 Dimensional-RAW（0.5543）同样本比较，参数层面当前方法明显更优；该参照只作外部坐标，不决定偏移量方法是否成立。按冻结同一失败处理，WMLE 未收敛的那 1 例（零估计损失计入）保留在 primary all-sample $J_1$ 中；完整案例 $J_1$（0.7288）另作标注灵敏度。

#### B3：可靠度寿命 $x_{0.90}/x_{0.95}/x_{0.99}$

由 E6 选择结果与共享候选估计派生（不重跑 MDM），见 `artifacts/formal/E6_dimensional_raw/quantiles/`。这里 $x_R$ 满足 $P(T>x_R)=R$，下标表示可靠度。$x_{0.95}$ 相对 RMSE：Dimensional-RAW 0.2131（三 seed 模型优先均值）、Default 0.2142、L6 0.2123、WMLE 0.1986、LSE 0.2133。参数 $J_1$ 的改善只很小地传递到可靠度寿命，WMLE 的相对 RMSE 反而最低；因此不把参数改善预先写作工程寿命改善。分 `n` 明细见 `summary_by_n.csv`。

### 4. 利用初估参数选择偏移量（plug-in）的负向支撑实验

检验“把初步参数估计直接当作真参数选择偏移量”能否恢复 L3–L5 收益（`code/run_pg_selector.py`，`artifacts/formal/pg_selector/`；48,000 样本、repeat-id 五折 cross-fit，条件均值曲线只用训练折）：

| 关键数值 | 结果 |
|---|---|
| 最优单步变体（WMLE 初估/仅 $\beta$/连续插值）pooled $J_1$ | 0.6507（Default 0.6304） |
| 配对 repeat-block bootstrap 95% CI（固定 seed，300 块） | $[0.0186,\,0.0219]$，全部 12 个单步变体 CI 严格为正 |
| 分 $\beta$ 例外 | 仅在 $\beta=1.5$ 改善（$J_1$ 差 −0.0104），$\beta=2.0$–5.0 更差 |
| 迭代（terminal） | 一致劣于单步，作反馈恶化诊断而非方法候选 |
| 初步 $\hat\beta$ 正确路由率 | MDM-0.1 19.8%、WMLE 16.5%（诊断性，非唯一机制证明） |

结论：直接 plug-in 总体不能恢复 oracle 收益，为本文转向直接预测样本级损失曲线提供比较依据；在已检验方案中，风险曲线预测获得了 plug-in 未能获得的总体收益。详细方法、变体、CI 与分 $\beta$ 结果见外部写作工作区 `Study01论文附录-v1.0.md` 的附录 C。

## 已经证明到哪里

- 已完成：当前 160 组合设计、按每个 $n$ 的 $\gamma/\eta$ 水平留出评价、未见 $\beta$ 水平留出（B1）、多 seed 稳定性、按 $n$ 的结果、与 Default/L6 的同样本比较、WMLE/LSE 同条件外部参照（B2）、$x_{0.90}/x_{0.95}/x_{0.99}$ 可靠度寿命派生（B3）。
- 未证明：跨单位或跨尺度泛化、未训练样本量的直接应用、连续参数空间或任意 Weibull 场景中的普遍有效性。
- 方法边界：每个 $n$ 使用独立网络，所以当前方法只定义于 $n\in\{7,10,15,20\}$。未见 $n$ 不是现有模型的“泛化测试”，而是需要另建网络或改变模型结构的新问题。
- 有量纲输入保留绝对水平信息，但不具备单位不变性。论文结论限于训练使用的物理单位和尺度范围。
- 未见 $\beta$ 与可靠度寿命验证均为当前离散网格上的结果，不是连续外推；参数 $J_1$ 改善不预先等价于工程寿命改善（B3 显示传递有限）。
