# Study01：MDM 偏移量选择研究

当前稿：[正文 v1.12](manuscript/Study01论文初稿-v1.12.md)、[附录 v1.10](manuscript/Study01论文附录-v1.10.md)。说明文档于 2026-09-07 按当前稿件重写，实验采用 S01-01—S01-08 编号。

研究的问题是：三参数 Weibull 小样本估计中，正偏移量怎样改变 MDM 的有限样本误差，其合适取值受什么影响，以及未知真参数时能否根据当前样本选择。

当前认识是：统一偏移量随参数域改变；样本信息可在现有离散设计内进一步降低联合参数误差。主方法 Mean-Normalized-MLP 的 J1 从 0.6304 降至 0.5846，改善 7.27%；160 单元中 125 个改善、35 个退化。参数收益向三个可靠度寿命点的传递有限。表示筛选复用了折外评价样本，冻结后的新增独立重复确认仍未执行。

目前是有价值的有界方法研究，暂缓定刊和投稿制作。下一步先明确可靠性用途，再决定最小独立确认；不继续扩大网络和试错分支。
