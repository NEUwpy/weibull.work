# Study 01：MDM 偏移量选择研究

> 当前状态：论文正式方法已收口为 **Mean-Normalized-MLP**：对排序样本作 $X/\bar X$ 处理，再预测候选偏移量的损失曲线。主结果、未见 $\beta$、可靠度寿命和尺度等变检查均已形成 E8 证据包；E13 已补充参数域改变时最佳统一偏移量随之改变的证据。E6 Dimensional-RAW 仅保留为固定尺度的敏感性与历史对照。

## 研究要回答什么

三参数 Weibull 最小差异法（MDM）通过正偏移量 $\delta$ 改善有限样本估计的稳定性，但既有工作主要使用经验值 $\delta=0.1$。本研究的问题是：在三参数 Weibull 小样本 MDM 估计中，偏移量 $\delta$ 如何影响有限样本估计风险，其合理取值受哪些因素决定，以及在总体参数未知时能否仅依据观测样本实现有效选择。

神经网络只是预测候选偏移量损失曲线的工具，不是论文主题。本文研究的是 MDM 估计器族内部的偏移量选择。

## 一句话结论

在当前设计域中，$\delta=0.1$ 相对无偏移判据使 $\beta$、$\eta$ 和 $\gamma$ 的组合内标准化估计 SD 中位数分别下降 57.0%、39.0% 和 40.9%，首先改善了重复抽样稳定性；固定宽度 $\beta$ 参数域平移时，最佳统一偏移量由 0.18 移至 0.04，说明统一值是给定参数域下的折中，而 $\delta=0.1$ 在较宽混合设计中仍接近低风险区。以均值归一化的排序样本预测 26 个候选偏移量的损失曲线，可在不改变 MDM 参数估计过程的情况下，把 pooled $J_1$ 从 0.6304 进一步降至 0.5846，且三个参数的标准化 Bias 绝对值、SD 和 RMSE 均下降。

## 当前正式结果

### 1. 偏移量选择空间

同一套 160 组合新设计中，L1–L5 采用 repeat-id 五折交叉评价，L6 为逐样本事后参照：

| 规则 | 可用信息 | pooled $J_1$ |
|---|---|---:|
| Default | 固定 $\delta=0.1$ | 0.6304 |
| L1 | 全部样本共用一个偏移量 | 0.6252 |
| L2 | 样本量 $n$ | 0.6230 |
| L3 | 形状参数 $\beta$ | 0.5905 |
| L4 | $\beta,n$ | 0.5885 |
| L5 | $\beta,\gamma/\eta,n$ | 0.5813 |
| L6 | 每个样本在预设 26 点网格内的事后最优候选 | 0.4923 |

这说明重新寻找一个统一常数的收益很小，而偏移量选择会随参数条件和样本实现改变。L3–L5 依赖未知真参数，表示各参数条件下的平均低风险选择；L6 还使用当前样本在 26 个候选点上已实现的全部损失，是逐样本事后参照。两者的信息性质不同，Default–L6 差距不是现实方法可必然获得的收益。

直接汇总全部样本的 26 点误差曲线时，$\delta=0.06,0.08,0.10$ 的 $J_1$ 分别为 0.624518、0.624666 和 0.630409。这里的最低点是描述性结果；经过选择/评价分离的 L1 交叉评价结果为 0.625198。

E13 将 $\beta=1.50,1.75,\ldots,5.00$ 划为 11 个宽度均为 1.00 的滑动参数域，同时保持 $\gamma/\eta$、$n$、候选偏移量和各参数条件权重不变。参数域由 $[1.50,2.50]$ 移至 $[4.00,5.00]$ 时，最佳统一偏移量由 0.18 依次移至 0.04；$\delta=0.1$ 相对各域最低 $J_1$ 的差距为 0%—9.16%。因此，脱离参数域讨论唯一最佳统一偏移量并不完整；宽混合参数域中的固定值只能解释为面向该域的汇总折中。证据见 `artifacts/formal/E13_beta_domain_sensitivity/`。

### 2. 可执行的样本自适应选择

最终方法按 $n\in\{7,10,15,20\}$ 分别训练网络：

```text
排序样本 X_n / 样本均值
  -> 训练折内逐位置标准化
  -> MLP (256-128-64)
  -> 26 点损失曲线
  -> argmin 选择 delta
  -> MDM 给出 beta、eta、gamma
```

正式设计固定 $\eta=1000$，取 8 个 $\beta$、5 个 $\gamma/\eta$ 水平和 4 个样本量，共 160 个组合、48,000 个样本、1,248,000 次候选偏移量估计。

| 方法 | pooled $J_1$ | $n=7$ | $n=10$ | $n=15$ | $n=20$ |
|---|---:|---:|---:|---:|---:|
| Mean-Normalized-MLP（seed 42） | 0.5846 | 0.7013 | 0.6071 | 0.5294 | 0.4756 |
| Default ($\delta=0.1$) | 0.6304 | 0.7633 | 0.6571 | 0.5651 | 0.5058 |
| L6 hindsight | 0.4923 | 0.6083 | 0.5159 | 0.4319 | 0.3831 |

论文主结果固定使用 seed 42：pooled $J_1=0.5846$，失败率为 0%，相对 Default 改善 7.2740%。在保持当前 160 个设计单元等权的配对 repeat-block bootstrap 中，该降幅的 95% CI 为 6.9448%—7.6376%；设计单元重采样的 95% 敏感性范围为 6.0367%—8.4603%，160 个单元中 125 个改善、35 个退化。seed 2026 和 3407 只用于初始化敏感性核查；三个 seed 的 pooled $J_1$ 范围为 0.5846—0.5855，标准差为 0.0004，不对三条预测曲线作平均或集成。派生主结果包见 `artifacts/formal/E8_mean_normalized_selector/seed42_primary/`，不确定性产物见 `artifacts/formal/E8_mean_normalized_selector/main_uncertainty/`。

### 3. 条件风险与样本实现

E10 机制实验在独立的 16,000 个确认样本上区分参数条件平均、可观测样本决策与逐样本事后选择。同一 $(\beta,\gamma/\eta,n)$ 条件内，L5 与 L6 的偏移量完全一致率仅为 12.6%，L6 事后选择的有效候选数中位数为 6.09，说明有限样本的具体实现会改变低风险偏移量。

同一确认集上，Default、论文 MLP、按当前全部设计单元重训的同结构 MLP、较灵活的 $Z$-only 经验参照与 L6 的 $J_1$ 分别为 0.6267、0.5827、0.5680、0.5618 和 0.4906。经验参照显示可观测样本中还有未被当前 MLP 充分利用的信息；它不是精确 Bayes 风险，其与 L6 的剩余差距也不能全部归因于完全信息差。证据见 `artifacts/formal/E10_z_only_benchmark/`。

E11 进一步在参数域四角与中心、四个样本量组成的 20 个预设单元中分析 2,000 个确认样本。$\nabla_X(0)$ 与 L6 偏移量的单元内 Spearman 相关中位数为 0.652；固定 $\delta=0.1$ 时的 $\hat\gamma_{0.1}/\eta$ 与 L6 偏移量相关中位数为 $-0.765$，20/20 个单元方向一致。按 $\hat\gamma_{0.1}/\eta$ 分组后，平均超额损失曲线最低点从 0.10 依次移至 0.04 和 0.02，而 L6 边界解仅占 7.1%。这说明样本实现主要通过改变经验梯度曲线和交点影响偏移量，证据见 `artifacts/formal/E11_profile_mechanism/`。

### 4. 写作前支撑验证

#### B1：未见 $\beta$ 留出验证

按 $\beta$ 水平留出 8 折，每个留出 $\beta$ 用其余 7 个 $\beta$ 训练 per-n 网络，与 Default/L6 在同一留出样本上比较（`artifacts/formal/E8_mean_normalized_selector/unseen_beta/`）：

| 指标 | 数值 |
|---|---:|
| Mean-Normalized（seed 42）pooled $J_1$ | 0.5841 |
| Default | 0.6304 |
| L6 hindsight | 0.4923 |
| 相对 Default 改善 | 7.347% |
| 失败率 | 0% |

seed 42 下，除 $\beta=1.5$ 外，其他 7 个留出层均优于 Default；$\beta=1.5$ 层略差，但 pooled 结果仍保留改善。因此证据只支持“当前离散 8 点 $\beta$ 网格上的整体收益保留”，不声称每个未见层均改善。pooled $J_1$ 按冻结定义 $\sqrt{\mathrm{mean}(\text{逐样本损失})}$ 直接汇总逐样本损失，不是各留出 $\beta$ 的 $J_1$ 平均；另外两个 seed 的完整分层只作附录敏感性证据。

#### B2：WMLE/LSE 同条件外部参照

使用当前 160 组合、同一 48,000 样本运行生产 WMLE/LSE（`artifacts/formal/E6_dimensional_raw/traditional_ref/`）：

| 方法 | pooled $J_1$ | $n=7$ | $n=10$ | $n=15$ | $n=20$ | 失败率 |
|---|---:|---:|---:|---:|---:|---:|
| WMLE | 0.7288 | 0.8125 | 0.7573 | 0.6902 | 0.6441 | 1/48000 |
| LSE | 0.8725 | 1.0417 | 0.9118 | 0.7858 | 0.7150 | 0% |

与 Mean-Normalized seed 42（0.5846）同样本比较，参数层面当前方法优于 WMLE/LSE；该参照只作外部坐标，不决定偏移量方法是否成立。按冻结同一失败处理，WMLE 未收敛的那 1 例（零估计损失计入）保留在 primary all-sample $J_1$ 中；完整案例 $J_1$（0.7288）另作标注灵敏度。

#### B3：可靠度寿命 $x_{0.90}/x_{0.95}/x_{0.99}$

由 E8 选择结果与共享候选估计派生（不重跑 MDM），见 `artifacts/formal/E8_mean_normalized_selector/quantiles/`。这里 $x_R$ 满足 $P(T>x_R)=R$，下标表示可靠度。Mean-Normalized seed 42 在 $x_{0.90}/x_{0.95}/x_{0.99}$ 上的相对 RMSE 为 0.1608/0.2136/0.3753，Default 为 0.1607/0.2142/0.3777。前者在 $x_{0.90}$ 略差，在 $x_{0.95}$ 和 $x_{0.99}$ 仅小幅改善，说明参数 $J_1$ 收益向可靠度寿命的传递有限。WMLE 在三个可靠度点的相对 RMSE 仍最低。分 `n` 明细见 `summary_by_n.csv`。

### 5. 利用初估参数选择偏移量（plug-in）的负向支撑实验

检验“把初步参数估计直接当作真参数选择偏移量”能否恢复 L3–L5 收益（`code/run_pg_selector.py`，`artifacts/formal/pg_selector/`；48,000 样本、repeat-id 五折 cross-fit，条件均值曲线只用训练折）：

| 关键数值 | 结果 |
|---|---|
| 最优单步变体（WMLE 初估/仅 $\beta$/连续插值）pooled $J_1$ | 0.6507（Default 0.6304） |
| 配对 repeat-block bootstrap 95% CI（固定 seed，300 块） | $[0.0186,\,0.0219]$，全部 12 个单步变体 CI 严格为正 |
| 分 $\beta$ 例外 | 仅在 $\beta=1.5$ 改善（$J_1$ 差 −0.0104），$\beta=2.0$–5.0 更差 |
| 迭代（terminal） | 一致劣于单步，作反馈恶化诊断而非方法候选 |
| 初步 $\hat\beta$ 正确路由率 | MDM-0.1 19.8%、WMLE 16.5%（诊断性，非唯一机制证明） |

结论：直接 plug-in 总体不能恢复 oracle 收益，为本文转向直接预测样本级损失曲线提供比较依据；在已检验方案中，风险曲线预测获得了 plug-in 未能获得的总体收益。详细方法、变体、CI 与分 $\beta$ 结果见 `manuscript/Study01论文附录-v1.3.md` 的附录 C。

## 已经证明到哪里

- 已完成：当前 160 组合设计、按每个 $n$ 的 $\gamma/\eta$ 水平留出评价、未见 $\beta$ 水平留出（B1）、多 seed 稳定性、按 $n$ 的结果、与 Default/L6 的同样本比较、WMLE/LSE 同条件外部参照（B2）、$x_{0.90}/x_{0.95}/x_{0.99}$ 可靠度寿命派生（B3）、4 个代表条件×3 个尺度的端到端等变检查、区分参数条件/可观测样本/事后信息的 E10 诊断、连接 MDM 梯度曲线与样本级低风险偏移量的 E11 诊断，以及约束 L6 解释的 E12 候选上边界敏感性诊断。
- 未证明：未训练样本量的直接应用、连续参数空间或任意 Weibull 场景中的普遍有效性。
- 方法边界：每个 $n$ 使用独立网络，所以当前方法只定义于 $n\in\{7,10,15,20\}$。未见 $n$ 不是现有模型的“泛化测试”，而是需要另建网络或改变模型结构的新问题。
- 均值归一化表示使样本整体缩放不改变选择器输入；端到端检查也验证了 MDM 估计中 $\beta$ 不变、$\eta$ 与 $\gamma$ 按比例变化。这不等于已证明任意参数分布或未见 $n$ 下的泛化。
- 未见 $\beta$ 与可靠度寿命验证均为当前离散网格上的结果，不是连续外推；参数 $J_1$ 改善不预先等价于工程寿命改善（B3 显示传递有限）。
