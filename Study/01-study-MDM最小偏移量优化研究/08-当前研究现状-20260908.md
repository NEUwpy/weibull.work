## 当前动机与背景

三参数 Weibull 的位置参数会改变估计问题的几何结构。MDM 通过在位置参数搜索中引入偏移量 δ 来避免边界和数值不稳定，但固定 δ 是否适合不同参数条件、不同样本，以及能否由观测样本选择，仍缺少系统证据。

Study01 当前聚焦的问题是：在既定三参数 Weibull 模拟域内，能否利用样本的可观测形态选择 MDM 的离散偏移量，从而降低参数估计风险；同时解释固定偏移量的偏差—方差机制、参数域依赖和收益边界。MLP 是实现样本自适应选择的工具，研究对象仍是 MDM 偏移量选择。

当前证据域为 β={1.5,2,2.5,3,3.5,4,4.5,5}、η=1000、γ/η={0.10,0.25,0.50,0.75,1.00}、n={7,10,15,20}，共160个参数单元、每单元300个样本，候选 δ 为0.00—0.50（步长0.02）。结论限于该离散设计，不外推到连续参数空间、未见样本量、任意 Weibull 分布或真实数据。

## 已取得的主要结果

- 固定 δ 的 pooled J1：δ=0 为 **0.948149**，δ=0.10 为 **0.630409**，δ=0.50 为 **0.761885**。当前设计中，适度正偏移明显优于零偏移，但过大偏移又使风险上升。
- 参数域敏感性：β 窗口从[1.5,2.5]移至[4,5]时，经验最佳 δ 从 **0.18** 移至 **0.04**，说明不存在与参数域无关的统一最优值。
- 信息条件比较：Default/L1/L2/L3/L4/L5/L6 的 J1 分别为 **0.630409/0.625198/0.623035/0.590526/0.588514/0.581294/0.492297**。真参数信息和事后损失参照提供的收益不能视为可部署方法。
- 主方法：均值归一化 MLP 的 seed 42 主值为 **J1=0.584553**，相对固定 δ=0.10 改善 **7.274%**，失败率为0%；160个单元中 **125个改善、35个退化**。配对 bootstrap 改善区间为 **6.9448%—7.6376%**。
- β 留出：pooled J1=**0.584091**，但 β=1.5 层出现轻微退化；这只支持当前离散 β 网格内的有限留出。
- 可靠性寿命：MLP 与 Default 的相对 RMSE 在 R=0.90/0.95/0.99 分别为 **0.1608/0.2136/0.3753** 与 **0.1607/0.2142/0.3777**，参数精度收益向寿命指标的传递有限。
- 传统参照：WMLE/LSE 的 J1 为 **0.728842/0.872520**；WMLE 有1/48,000次未收敛，按既定评分规则计入主表并另报完整案例敏感性。
- 仅观测样本的候选比较中，论文 MLP、同域重训 MLP、灵活样本规则的 J1 为 **0.582693/0.568039/0.561835**。该确认划分来自原300次扫描，不是冻结主方法后的新独立重复。
- 初估参数查表的最佳已检验单步变体 J1=**0.650696**，高于 Default，构成负向结果。
- L6 上界敏感性使全样本 J1 从 **0.492297** 降至 **0.490848**，表明部分样本受候选上界影响；这不定义无约束最优偏移量。
- 四个样本在三种尺度下的尺度等变检查 **12/12通过**，属于实现一致性验证，不是域外准确性证明。

## 已取得的结论

1. **偏移量是有用但依赖条件的控制量。** 在当前设计中，适度正偏移相较 δ=0 可显著降低 MDM 风险；偏移过大则收益消失。
2. **统一固定偏移量存在参数域依赖。** β 域变化会改变经验最佳 δ，因此单一默认值只能被理解为当前设计下的折中。
3. **样本自适应选择具有实际收益，但收益是有限且异质的。** 均值归一化 MLP 在当前160个单元上相对 δ=0.10 有约7.27%的 pooled J1 改善，但仍有35个单元退化，不能表述为普遍优越。
4. **可观测信息只能逼近部分可用选择空间。** L3—L6使用真参数或事后损失，属于参照上界；现有结果支持研究“可观测样本能否逼近风险差异”，不支持部署自动推荐。
5. **参数收益不会自动转化为可靠性寿命收益。** 当前寿命 RMSE 几乎与 Default 接近，论文结论应把寿命收益写成有限或未充分改善。
6. **方法机制和工程一致性已有支持，外部有效性仍不足。** 梯度诊断、尺度等变和 β 留出补充了机制与实现证据，但尚未完成冻结后的新独立重复、真实数据或与目标应用严格匹配的可靠性案例。

因此，Study01 当前可以作为一项有界的“MDM 偏移量风险结构与样本自适应选择”研究继续收口；下一步应优先决定是否进行最小的冻结后独立确认，并据此再判断投稿定位，不宜继续堆叠新的试错实验。
