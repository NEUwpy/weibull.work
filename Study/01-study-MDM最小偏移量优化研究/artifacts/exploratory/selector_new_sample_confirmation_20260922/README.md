# 冻结最终模型的新样本确认

2026-09-22。状态：完成。**冻结最终AMDM在16,000个新样本上优于固定0.1；大δ回退没有改善最终模型，暂不采用。**

## 结果

| 规则 | J1（越小越好） | 相对固定0.1改善 | 改善率95%配对区间 |
|---|---:|---:|---:|
| 固定δ=0.1 | 0.634999 | — | — |
| 冻结最终AMDM，seed=1 | 0.569355 | 10.34% | 9.83%—10.89% |
| 最终AMDM的大δ回退 | 0.575739 | 9.33% | 8.84%—9.89% |

回退相对原最终AMDM使J1增加1.12%，配对95%区间为增加0.90%—1.36%。它在本轮检验中明确牺牲了总体精度，不能因为旧折外数据中有收益就加入正式方法。

原最终AMDM在n=7/10/15/20下分别改善11.00%/9.95%/10.43%/9.35%；三个参数的标准化RMSE均降低。160单元中142个改善、18个退化（点估计，非逐单元显著性结论）。16,000样本中10,793个改善、3,796个退化、1,411个损失相同。因此支持的是当前设计内的平均优势，不是逐样本必优。

原最终AMDM联合损失P99为1.774271，低于固定规则的1.859740；回退后为1.832903。回退虽把退化单元数降为15个，但平均误差与总体P99均劣于原最终AMDM。三种规则均未出现求解失败。共享选点去重后共执行30,808次MDM，保留48,000条规则结果。

## 为什么与旧诊断不同

两次使用的网络身份不同：旧诊断评价60个参数层留出折模型的预测，本次评价4个在全部开发数据上训练的最终模型。这不是同一组权重在新旧样本上的严格对照，不能把结果差异全归因于抽样波动或全归因于训练覆盖。

旧seed42折预测中，选δ>0.20的样本组平均联合损失增加0.0355；本次最终模型选δ>0.20的2,055个新样本，固定与自适应的平均联合损失分别为0.2657和0.2087，大δ调整在这个选中组中反而有收益。旧数据找到的错误模式未直接迁移到最终模型，因此简单回退撤销了一部分有效调整。

旧折外评价的低γ/η层在对应折训练中完全留出；最终模型训练则包含这些设计层。训练覆盖差异是可能解释，但本次没有对相同权重和训练条件做消融，不能把它宣布为已证实原因。

原图所在的(β,η,γ,n)=(2,1000,1000,7)单元，本轮100个新样本J1为固定0.708583、自适应0.653092、回退0.675718。仅作补充描述：新样本及网络均不同，不能据此抹去旧图的退化结果，也不应重新挑图隐藏旧结果。

## 决定

保留当前自适应路线，不加入δ>0.20回退；本轮不继续调整阈值，不用这批新数据反复挑选新策略。三模型平均因原折权重未保存，没有完成新样本确认，不能作为已验证改进。

下一步优先把“折外模型用于泛化评价”和“全开发集最终模型用于实际应用”在正文中区分，并分别呈现旧折外结果与本次冻结最终模型的新样本结果。若再改网络或规则，另留新的确认数据。无需为了让30条曲线看起来都变好而修改方法。

## 设计与复核

本轮回答：当前AMDM方案的平均优势能否在新样本上出现；根据旧折外预测提出的大δ回退是否仍有收益。

使用Git `ddc75754` 中4个完整最终模型（每n一个、seed=1、全开发集训练）。此前60个折模型JSON只有元数据，没有网络权重，不能据它们在新样本上原样验证seed42折外模型或三种子平均。本次没有重训，也不是旧7.27%数值所对应折模型的完全复验。

验证前固定：原160单元×每单元100次，共16,000个新样本；抽样命名空间 `study01_selector_confirmation_20260922_v1`，区别于旧数据。三规则共用样本：固定δ=0.1；冻结最终AMDM；最终AMDM选择δ>0.20时回退0.1。阈值来自旧数据探索，新样本不用于调阈值。模型只由已知样本量n选择，不以真参数路由。

12个预测案例中，JSON权重的NumPy前向与sklearn前向一致；12个既有MDM案例重算与冻结候选估计一致。正式计算前8个新样本smoke通过，只用于执行检查，仍按原定样本数完整计入，未据其结果调整方案。

主指标J1为平均三参数标准化平方误差和的平方根。按参数单元内配对重采样2000次，保持设计权重和模型固定，给出改善率95%区间；同时报告失败、分层和尾部误差。该验证支持当前离散参数设计内的新样本表现，不证明连续域、未知n或所有单元都优越。

复现：[程序](../../../code/verify_selector_new_samples_v1.py)，依次运行 `--stage prepare`、`--stage smoke`、`--stage run --workers 4`；`--stage summary`只重算汇总。代码会校验冻结合同、模型及来源。每个参数单元的结果保存在cells/，支持继续未完成单元。原始权重从Git读取，不复制整个历史实验包。
