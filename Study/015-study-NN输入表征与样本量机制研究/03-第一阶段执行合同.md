## 一、执行目标

1. 在同一任务和近似相同模型容量下，`F13 / F12 / RAW` 的风险曲线预测和 delta 选择差异有多大；

## 四、固定输入合同

### 4.1 F13

字段顺序固定为：

```text
x_min, x_max, range, Q1, Med, Q3, IQR, x_bar, s,
n, CV, g1, g2
```

`x_min` 至 `s` 使用当前训练子集的均值和标准差做 z-score；`n, CV, g1, g2` 按 Study01 当前合同原值输入。

### 4.2 F12

仅从 F13 删除显式 `n`，其余字段顺序和预处理完全相同。不得为 F12 重新选择特征。

### 4.3 RAW

RAW 固定为40维：

```text
20个排序观测位置 + 20个有效位置 mask
```

处理规则：

1. 原始样本升序排列；
2. 仅用训练行的真实观测值计算一个标量均值和标准差；
3. 观测值 z-score 后右侧 padding 到20；
4. padding值为0，由mask区分真实观测和padding；
5. mask中1的数量必须等于该行 `n`；
6. 不额外输入数值字段 `n`。

### 4.4 禁止字段

任何模型输入均不得包含：

```text
beta, eta, gamma, gamma_over_eta, repeat_id,
sample-generation seed, model seed, delta, true loss, oracle label
```

## 八、评价合同

### 8.1 单样本量指标

对每个模型、seed、测试 `n` 计算：

```text
curve_RMSE_i = sqrt(mean_delta((pred_loss_i(delta) - true_loss_i(delta))^2))
selected_delta_i = argmin_delta pred_loss_i(delta)
selected_loss_i = true_loss_i(selected_delta_i)
hindsight_loss_i = min_delta true_loss_i(delta)
regret_i = selected_loss_i - hindsight_loss_i
J1 = sqrt(mean_i(selected_loss_i))
J1_hindsight = sqrt(mean_i(hindsight_loss_i))
```

汇总报告：mean curve RMSE、`J1`、`J1-J1_hindsight`、mean regret、median regret、95% regret分位数和near-5% hit rate。

### 8.2 核心比较

所有差异在相同测试键上配对计算：

1. 表示差异：`RAW-F13`、`F12-F13`；
2. 单一迁移代价：`T(source->target)-S(target)`；
3. 留一泛化代价：`L(target)-S(target)`；
4. 联合训练净效果：`J(target)-S(target)`。

主要效应同时报告绝对 `ΔJ1`、相对 `ΔJ1/J1_reference` 和 `Δmean_regret`。

J与S训练样本量不同，因此 `J-S` 只解释为“联合训练的操作性净效果”，不得单独归因为共享表示或训练数据增加。若J更差，可视为存在净负迁移；若J更好，只能说联合方案总体受益。

### 8.3 不确定性

不以单个样本行作为独立领域证据，不做普通样本级t检验。对每个目标 `n`：

- 以15个 `(beta, gamma_over_eta)` 组合为cluster；
- 对组合进行10,000次配对bootstrap；
- 每次保留所抽组合内全部200个TEST repeats；
- 表示和模型对比使用同一bootstrap索引；
- 报告seed分别结果、三seed平均效应和95% bootstrap区间。

区间只描述当前15个existing-grid组合上的异质性，不外推连续参数空间。第一阶段不预设等效阈值，也不以显著性决定是否继续扩展。

## 九、最小机制诊断

### 9.1 n线性可识别性

在F12上训练一个多分类logistic-regression probe：

- TRAIN/TEST与主实验相同；
- 特征标准化只拟合TRAIN；
- 固定 `C=1.0, max_iter=1000, random_state=42`；
- 报告accuracy、balanced accuracy、macro-F1和3×3 confusion matrix；
- 机会水平为1/3。

该结果只说明样本量的线性可解码程度。低准确率不能证明F12完全不含样本量信息。

### 9.2 输入与目标描述

在固定TEST上按 `n` 报告：

- F12各特征的分布摘要；
- 26点真实风险曲线的均值和分位带；
- hindsight最优delta分布和 `J1_hindsight`；
- 表示/训练组织的迁移regret随源—目标 `n` 变化。

不新增聚类、表征学习或第二套分类器。
