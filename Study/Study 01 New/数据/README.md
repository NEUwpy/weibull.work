## 覆盖与使用

旧主体结果覆盖β=1.5、2、2.5、3、3.5、4、4.5、5，γ/η=0.1、0.25、0.5、0.75、1，n=7、10、15、20，η=1000。E01—E04主要共用48,000组开发样本；E05使用另行生成的16,000组样本。E06加密β用于固定规则分析，不代表这些条件已完成全部方法比较。

本轮按作者决定，主体不增加n=5、β=1、γ/η=0。余下参数水平尚待最终确定。复制保留原有覆盖及汇总口径；若新稿选择子集，必须从对应行级数据重新汇总，不能将旧全域数值直接冠以新设计。

E03的选点可按β、η、γ、γ/η、n、repeat_id及selected_delta关联E01，恢复所选候选的三参数估计。E04缺失行级结果，不能仅用总体均值反推新参数子集的结果。E05包含未采用的回退对照，是同一次运行的完整记录，不表示正式方法采用回退。
