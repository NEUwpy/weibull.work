## 新增方法的实现与核查

- LRE：中位秩线性化，以相关系数平方选择位置参数，再用OLS恢复形状与尺度；是系统Li/Park思路组合实现，并非完整复现Park的后续两参数极大似然步骤。
- MM：Cran（1988）的Weibull矩估计，采用1、2、4阶相关矩与系统位置修正。232组因矩条件不可容许而失败。有效记录中存在极大形状估计，未删除或截尾；例如β真值2、γ/η=1、n=15、repeat=60得到β估计5166.1846，其两项矩差为0.2776166和0.2775793，接近相等导致形状公式分母接近零。已独立复算该记录。本档案汇总使用全部相应有效记录。
- MLE：系统五起点Nelder–Mead求解，选收敛且β≥1的有限候选；1,368组返回`unbounded`状态，论文表述为“未返回本实现接受的有限解”，不据此断言这些样本的所有数值方法都会失败。起点、精度与约束见系统代码及正文3.3。

三种方法均先将寿命除以固定1000，再将尺度与位置估计转换回原单位，求解器不接收真参数。原六方法估计及四个模型未改；新增方法已有30项系统测试通过，复核包含4,800个样本哈希与24个生产求解器抽查，见`verification.json`和`extension_manifest.json`。

开发样本与测试样本分别使用`study01_nrmc_v1`和`study01_selector_confirmation_20260922_v1`命名空间。按n固定偏移仅在E01对应48条件的开发样本上选取，每条件300组；n=7、10、15、20分别选择0.08、0.10、0.10、0.08。该开发集与AMDM训练来源重叠，独立性指它与测试样本独立。

AMDM沿用seed=1的四个冻结模型。网络及标准化参数存于`models/`，哈希与E05冻结合同一致。历史训练的160条件/48,000样本是开发范围，不作为当前测试样本数。未执行连续参数再训练或模型改选。

重算入口依次为`python run_e09.py`、`python extend_conventional.py`、`python paired_uncertainty.py`、`python verify_e09.py`、`python summarize_e09.py`。`run_e09.py`可合并已有新增方法文件；新增方法从头重算或随源代码更新时由`extend_conventional.py`执行并更新来源哈希。`repair_wmle_rows.py`用于初次接入时仅修复旧失败记录；从头重算时`run_e09.py`已使用相同的修复求解器。`audit_wmle.py`复查初始拒绝集合，不改估计结果。最多使用2个进程，输出写在本目录。

`per_sample.csv.gz`、新增方法记录、冻结模型、配置、程序及紧凑汇总纳入Git保存范围；可再生成的`cells/`与`extension_cells/`分片忽略。E01及E05原大体积来源仍保留在本地。初始交付记录与修复后的正式结果通过manifest区分，旧Study01保持冻结。
