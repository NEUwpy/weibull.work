# E09 六方法共同测试

当前版本：**v0.3-260923**。新稿第四章与后续结果图统一使用本目录数据。48个条件：β=1.5、2、3、5，γ/η=0.1、0.5、1，n=7、10、15、20，η=1000；每条件100组，共4,800个共同样本、28,800条方法结果。

样本来自E05冻结模型测试的对应条件。此次保留其AMDM和固定0.1结果，补齐其他方法，并修复WMLE数值漏解。当前测试样本独立于模型开发数据，但已被本项目使用过；本次统一不把它重新命名为从未查看的新测试。

## 当前结果

| 方法 | 有效样本J1 | 有效/总样本 | 失败率 | 失败记平方损失3的辅助汇总 |

AMDM相对固定0.1和按n优化固定偏移的J1改善为8.45%和8.35%，配对重抽样95%区间分别为[7.47%,9.44%]与[7.44%,9.23%]。WMLE有效样本集合不同；在共同4,566组有效样本上，AMDM的J1为0.568899，对应相对改善13.57%。全体精度、逐参数误差、配对有效样本结果及失败率一起解释，不以惩罚值决定唯一排名。

WMLE原406次失败中恢复172组，剩余234组；详见[WMLE核查](WMLE核查.md)。非负位置约束下的数值结果不概括为原始WMLE的普遍性能。LSE使用当前项目的White—Soman/Misra实现，其β=5条件属于该实现的延伸比较。

## 数据与程序

| 文件 | 用途 |
|---|---|
| [实验配置](实验配置.json) | 参数条件、模型、比较规则与执行入口 |
| `per_sample.csv.gz` | 唯一当前逐样本结果；包含三个参数、失败状态及样本哈希 |
| `pooled.csv`、`pooled_parameter_metrics.csv` | 整体及逐参数汇总 |
| `by_n.csv`、`by_beta.csv`、`by_gamma_over_eta.csv`、`by_cell.csv` | 按样本量、形状、位置比及单元展开 |
| `within_cell_stability.csv` | 同参数重复抽样的标准差汇总；区别于混合条件的总体SD |
| `paired_valid_and_failure_sensitivity.csv` | 共同有效样本比较和失败惩罚敏感性 |
| `paired_interval.json` | 固定设计内的配对区间 |
| `models/` | 四个冻结模型及实际训练来源 |
| `wmle_failure_audit.csv`、`wmle_recovery.csv` | 初始拒绝样本的原因核查与恢复记录 |
| `verification.json`、`manifest.json` | 样本、模型选择、方程核验及文件哈希 |
| `imported_manifest.json` | 补实验窗口初始交付的来源哈希，不是当前结果清单 |

开发样本与测试样本分别使用`study01_nrmc_v1`和`study01_selector_confirmation_20260922_v1`命名空间。按n固定偏移仅在E01对应48条件的开发样本上选取，每条件300组；n=7、10、15、20分别选择0.08、0.10、0.10、0.08。该开发集与AMDM训练来源重叠，独立性指它与测试样本独立。

AMDM沿用seed=1的四个冻结模型。网络及标准化参数存于`models/`，哈希与E05冻结合同一致。历史训练的160条件/48,000样本是开发范围，不作为当前测试样本数。未执行连续参数再训练或模型改选。

重算入口依次为`python run_e09.py`、`python paired_uncertainty.py`、`python verify_e09.py`、`python summarize_e09.py`。`repair_wmle_rows.py`用于初次接入时仅修复旧失败记录；从头重算时`run_e09.py`已使用相同的修复求解器。`audit_wmle.py`复查初始拒绝集合，不改估计结果。最多使用2个进程，输出写在本目录。

`per_sample.csv.gz`、冻结模型、配置、程序及紧凑汇总随Git保存；可再生成的`cells/`分片忽略。E01及E05原大体积来源仍保留在本地。初始交付记录与修复后的正式结果通过manifest区分，旧Study01保持冻结。
