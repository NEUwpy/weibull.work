# E10 n=100 单独扩展结果

本目录只记录 n=100 新增实验。原 E10 的 n=30/50 样本、模型、逐样本估计和区间保持原值；[`n100_baseline_hashes.json`](../n100_baseline_hashes.json) 记录其 114 个交付文件的扩展前 SHA-256，`verification.json` 已逐一核对全部未变。没有追加 n>100。

## 相对 MLE 的三参数结果

下表为三参数标准化 RMSE 相对 MLE 的降幅 `100×(1−RMSE_method/RMSE_MLE)`。四方法共同有效观测为 **1,177/1,200** 组，按每个条件实际保留数合并；2,000 次条件内配对重抽样给出逐点 95% 区间。每个 n 内的 `β`、`η`、`γ` 分别以真 β、真 η、真 η 标准化。

| 参数 | AMDM | 固定 δ=0.1 MDM | WMLE |
|---|---:|---:|---:|
| β | 18.98% [11.12%, 25.29%] | 9.06% [0.33%, 16.19%] | 24.92% [18.08%, 30.91%] |
| η | 20.78% [14.63%, 26.11%] | 12.46% [5.99%, 18.28%] | 20.25% [14.43%, 25.45%] |
| γ | 23.38% [16.29%, 29.35%] | 13.44% [5.72%, 20.14%] | 23.28% [16.51%, 29.27%] |

点估计和完整精度见 `parameter_vs_mle.csv`；该文件包含 MLE 自身的零线、共同有效数及每条件保留数。`four_method_common_samples.csv` 保存曲线使用的样本键与 SHA-256。区间反映固定模型和本次离散测试设计下的 Monte Carlo 抽样波动，不包含训练种子波动；不同 n 的共同有效集合也不同。n=100 的 β 降幅中 WMLE 高于 AMDM，不能概括为 AMDM 在每个参数上最优。

## 相对固定 MDM 的联合误差

在 AMDM 与固定 MDM 共同有效的全部 1,200 组观测上，AMDM 的 `J1=0.239223`，固定 MDM 的 `J1=0.268015`，相对降幅 **10.74% [8.78%, 12.47%]**。`paired_interval.csv` 保存精确值。这项比较的参照是固定 MDM，使用 1,200 组配对观测；上表参照是 MLE，使用 1,177 组四方法共同有效观测，两个百分比不能直接互换。

四方法失败数：AMDM 0、固定 MDM 0、WMLE 23（1.92%，均为 `equation_residual`）、MLE 0。失败记录保留在 `per_sample.csv.gz`；有效估计的逐参数 Bias、SD、RMSE 及 J1 见 `by_n.csv` 和 `by_cell.csv`。WMLE 的 23 次失败只表示当前实现未通过方程残差接受准则。

## 执行与核查

开发域为 β=1.5、2、2.5、3、3.5、4、4.5、5 与 γ/η=0.1、0.25、0.5、0.75、1 的 40 条件，每条件 300 组；12,000 组开发样本产生 312,000 个偏移候选损失，全部有效。候选 0:0.02:0.50，输入为升序样本除以样本均值，26 维联合损失为标签。候选失败的填充值按 n=100 完整开发集有效损失第 99 百分位计算为 0.642582，但本次零候选失败，因此未写入任何训练标签。模型使用与 n=30/50 相同的 MLP 和标准化设置，seed=1，内部早停于第 36 次迭代（300 次上限，内部验证分数 0.53052）；序列化推断与 sklearn 输出最大绝对差 `4.58e-16`。模型在 `../models/n100_final.json`。

测试域为 β=1.5、2、3、5 与 γ/η=0.1、0.5、1 的 12 条件，每条件 100 组。开发和测试使用 `实验配置.json` 中不同的确定性随机命名空间，模型冻结后才生成测试样本。生产 MDM 的缓存候选计算与原求解器在 16 个 n=100 抽查点逐值一致。WMLE/MLE 的实现、单位换算及有效解判据沿用原 E10；估计器不接收测试真参数。

`../dev_cells/n100_cell*.npz` 保留开发原始样本、26 个估计/损失及样本哈希；`../test_cells/n100_cell*.csv` 保留测试原始分片与样本哈希。`per_sample.csv.gz` 为 n=100 四方法共 4,800 条结果。`bootstrap_draws.npz` 保存 J1 主比较与相对 MLE 各参数的 2,000 次重抽样降幅。`manifest.json` 保存代码、模型与结果哈希；`verification.json` 记录 1,200 个测试样本重建、1,200 次模型选点复核、12 条测试求解重算、开发测试零重合、汇总复算和旧文件哈希核对。

从仓库根目录依次运行 `python "Study/Study 01 New/数据/E10_样本量扩展/run_e10_n100.py" verify`、`scan`、`train`、`test`、`summarize`、`audit`。`scan` 与 `test` 的已完成条件分片会跳过，可断点恢复；最多两个工作进程。运行前设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`NUMEXPR_NUM_THREADS=1`。本次只执行固定 seed=1 的最终模型，不估计重复训练不确定性；新旧 n 的横向趋势仍限于这套离散条件及各自有效样本集合。
