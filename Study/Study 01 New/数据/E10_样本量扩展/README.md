# E10：样本量扩展

研究问题：在与 E09 相同的离散参数测试域内，AMDM 相对固定 `δ=0.1` MDM 的联合误差 `J1` 额外收益是否随样本量增大而明显减弱。基础阶段扩展 n=30、50，以下结果、文件和配置均属于该阶段；随后单独补做的 n=100 见 [n100/README.md](n100/README.md)。两个阶段均不以事先举例的 2% 作为已冻结判断阈值。

## 已完成结果

| n | AMDM J1 | 固定 MDM J1 | 相对降幅 | 条件内配对重抽样 95% 区间 | 四方法共同有效样本 |
|---:|---:|---:|---:|---:|---:|
| 30 | 0.388407 | 0.416966 | 6.85% | 5.37%–8.30% | 1,098/1,200 |
| 50 | 0.316385 | 0.343647 | 7.93% | 6.37%–9.52% | 1,149/1,200 |

主比较每个 n 使用 AMDM 与固定 MDM 共同有效的全部 1,200 组观测。n=50 相对 n=30 的降幅差为 +1.08 个百分点，独立的条件内重抽样 95% 区间为 −1.06 至 +3.22 个百分点。未观察到 n=50 收益明显减弱的证据，也不足以断言收益真正增加。每个 n 有 8/12 个单元的 AMDM J1 优于固定 MDM；合并 J1 按观测而非单元百分比的等权平均计算，故不能把 8/12 解释为总体改善幅度。

四方法失败数：n=30 的 AMDM 0、固定 MDM 0、WMLE 63、MLE 39；n=50 分别为 0、0、46、5。WMLE 失败状态均为方程残差未达接受阈值；MLE 均为本实现未返回可接受有限解（`unbounded`）。不能据此推断这些样本在所有数值方法下均无解。逐参数 Bias/SD/RMSE 见 `by_n.csv` 和 `by_cell.csv`；四方法共同有效集合上的相对 MLE 三参数曲线数值见 `parameter_vs_mle.csv`。

旧 E09 的 n=7/10/15/20 共同测试中，AMDM 相对固定 MDM 的同口径 J1 降幅分别为 10.06%、7.84%、7.67%、6.63%。E10 的新测试使用另一独立随机命名空间；新模型的失败损失填充值从本次两个 n 的开发集取得，而旧模型来自四个旧 n 的开发集。不过 E10 的全部候选有效，填充值未实际进入训练标签。跨旧新 n 只能作为描述性趋势并列。新 n 的收益没有继续下降到接近零，2% 也不是证据支持的边界。

## 协议

- 开发域：每个 n 均为 β=1.5、2、2.5、3、3.5、4、4.5、5 与 γ/η=0.1、0.25、0.5、0.75、1 的 40 条件，每条件 300 组，η=1000；两个 n 共 24,000 组、624,000 个候选损失。
- 测试域：每个 n 均为 β=1.5、2、3、5 与 γ/η=0.1、0.5、1 的 12 条件，每条件 100 组，η=1000；共 2,400 组。开发与测试使用配置中不同的确定性随机命名空间。
- 候选偏移为 0:0.02:0.50。每个 n 独立训练一个 seed=1 模型，使用升序样本除以样本均值的输入、26 维候选联合损失标签、逐位置/逐目标标准化及历史 MLP 设置。预测损失逆标准化并截断于零后取最小候选，平局取最小偏移。模型冻结后才生成测试结果。
- MDM 使用系统生产求解器。开发集的候选扫描仅在同一样本内缓存与偏移无关的剖面计算，省去不参与最终估计的诊断网格；[`cached_mdm_verification.json`](cached_mdm_verification.json) 记录与生产求解器的逐值比较。
- WMLE 使用 E09 已修复的数值漏解流程，MLE 使用系统对有限解的接受规则；两者的观测除以固定 1000，估计的尺度和位置再乘 1000。求解器不接收测试真参数。

## 评价口径

三参数标准化误差分别为 `(β̂−β)/β`、`(η̂−η)/η`、`(γ̂−γ)/η`；`J1` 是三项误差平方和的样本均值开方。主比较在 AMDM 与固定 MDM 共同有效的观测上计算 `1−J1_AMDM/J1_MDM`，按每个条件保持原样本量进行 2,000 次配对重抽样，给出条件于固定设计与冻结模型的逐点 95% 区间。失败率单列，不用指定惩罚值决定主比较。

逐参数 Bias、SD、RMSE 和失败率按方法及 n、条件保存。相对 MLE 的三参数 RMSE 曲线使用四方法共同有效观测，汇总权重为各条件保留的样本数；因此其有效样本集合与主比较不同，也可能随 n 改变。

## 文件及复现

`实验配置.json` 固定设计与训练/评价口径；`run_e10.py` 提供 `verify`、`scan`、`train`、`test`、`summarize`、`audit` 分阶段入口。按此顺序执行；`all` 可一次执行全流程。最多两个扫描/测试工作进程，建议在启动前设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`。`dev_cells/*.npz` 保存原始训练样本、全部 26 个候选的三参数估计、损失及样本哈希；`test_cells/*.csv` 保存可恢复的按条件测试分片。两个阶段均跳过已完成分片，可从中断处继续。`models/n{30,50}_final.json` 保存冻结模型权重、标准化参数、收敛记录及开发分片哈希。

`per_sample.csv.gz` 是四方法逐样本结果与样本哈希；`by_n.csv`、`by_cell.csv` 是精度与失败汇总；`paired_interval.csv` 是主比较；`parameter_vs_mle.csv` 提供三参数相对 MLE 折线图数值及各条件保留数；`manifest.json`、`verification.json` 保存来源、产物哈希与复核记录。

`gain_difference.json` 给出 n=50 与 n=30 的收益差及其重抽样区间。开发集 624,000 个候选全部返回有效数值，两个模型的失败损失填充值同为 1.097266。n=30 模型内部早停于第 30 次迭代，内部验证分数 0.54123；n=50 于第 35 次迭代停止，验证分数 0.51632，均未碰到 300 次上限。序列化模型输出与训练时 sklearn 输出最大绝对差小于 `6e-16`。`cached_mdm_verification.json` 的 24 个跨样本量/参数/偏移抽查点与生产 MDM 输出完全一致；`verification.json` 记录 240 个开发样本重建、2,400 个测试样本哈希检查与模型选点复核、24 条测试求解独立复算、零开发测试重合和逐 n 汇总复算通过。
