## F01来源与口径

依据新稿文献[4]、[5]的最小差异原理重绘，未复制、描摹或数字化原论文图片。伪尺度的一致性关系与原论文原理一致；联图按文献[5]“固定位置参数、搜索形状参数”的顺序组织，以便衔接后文的偏移判据。

- 三参数、样本和差异量记号沿用文献[5]；秩概率采用文献[4]和当前研究实现的近似式`(i−0.3)/(n+0.4)`，并非文献[5]的精确中位秩。
- 以`W(2,1000,1000)`、`n=7`的理想秩分位点样本作代数示例。没有随机抽样，也不构成新的性能实验。
- 标准差取`ddof=1`。形状参数网格为0.6—6.0，步长0.005；位置参数网格为400—1250，步长2。两网格均包含真值，所有位置参数小于最小样本值。
- a展示三种参数设置下的伪尺度；b展示四个固定位置参数下的差异曲线与最小点；c使用同一计算结果连接各条件最小值。图中没有误差条、统计检验或性能排名。
- CSV中`panel`对应子图，`series`对应曲线，`kind`区分曲线与标记点。a的x/y为样本序号/伪尺度，b为形状参数/标准差，c为位置参数/条件最小标准差；`beta`、`gamma`保存对应参数设置。JSON保存7个样本值、秩概率、网格、版本和文件校验值。

## 重绘

在本目录执行：

```powershell
python "绘图程序/F01_MDM原理联图.py"
```

依赖Python、NumPy、Matplotlib及中文字体（Microsoft YaHei、Noto Sans CJK SC或SimHei之一）。程序重新计算数据并更新同编号PNG、SVG、PDF、CSV和JSON。输出尺寸183×86 mm，PNG为400 dpi；SVG保留文本，PDF嵌入字体。图中文字、公式和颜色对应关系已目视检查，程序同时核对理想样本的三参数恢复与文字画布边界。
