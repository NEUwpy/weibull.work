## F01来源与口径

依据[2025年MDM原论文](../../../src/content/182-046-pdf原文.md)的条件形状搜索与梯度判据重绘。当前图以公式、曲线和传递量展示单样本估计：排序样本与秩概率 → 伪尺度差异及条件最小差异 → 梯度选定位置 → 回代形状 → 伪尺度均值 → 三参数输出。a、b曲线直接位于求解流程中。本版只展示零梯度规则。以下c、d及30组样本的记录对应保留的v14及更早联图，不属于当前v16。当前总图以PPT为编辑入口，数据与独立子图来源继续保留。

| 子图 | 内容 | 对应关系 |
|---|---|---|
| a | 位置求解节点内的一条梯度曲线，零水平交点给出γ̂=974.4 | 输出γ̂，通过箭头传递至b |
| b | 形状回代节点内的一条标准差—β曲线，最低点给出β̂=2.471 | 输入a得到的γ̂，后接尺度计算与输出节点 |
| c | 30条样本梯度曲线及δ=0下的全部位置估计 | 显示同参数下的抽样分散性，保留10个下界估计 |
| d | 与c相同的30条曲线及δ=0.1下的全部位置估计 | 相同坐标与样本，比较偏移后的估计波动 |

上排不比较偏移规则。下排灰色空心圆和蓝色方块分别表示δ=0和0.1；散点横坐标为位置估计，竖向错开只为避免重叠，竖虚线为真值1000。

- 数据条件为W(2,1000,1000)、n=7，来自项目[已有样本文件](../../../public/case-studies/mdm/verification-182-046/data.csv)。a、b用其中的`Sample-1-3`；c、d用全部30行，未按结果筛选，也未生成新样本。[源配置](../../../public/case-studies/mdm/verification-182-046/config.md)记录总体设置。这不是原论文样本的精确复现。
- 秩概率沿用正文式(3)的`(i−0.3)/(n+0.4)`，并非2025原论文的精确中位秩。标准差取`ddof=1`。
- 使用`python/methods/mdm.py`重算，形状搜索范围[0.1,15]；单样本记录1800点位置网格，多样本每组600点，并加入实际求解点。所有区间内交点梯度残差小于`1e-6`，条件形状最优值及伪尺度均值与求解器一致。
- 两种规则各保留全部30个位置估计。其样本标准差为595.5257／300.5995，范围为[0,1561.3821]／[517.5435,1628.9911]。零梯度下的10个边界估计保留在c下方散点与汇总中，不伪画成交点。这一示例比较位置估计波动，三参数性能由后续实验评价。
- CSV中`panel/series/kind`区分面板、样本及数据用途；`x/y`为坐标，另保留β、γ、δ。`cd`为c、d共用梯度曲线，`support`为不单独成图的中间计算及额外偏移结果。显示面板a只有零梯度选点，b只有δ=0的条件形状曲线。
- a显示γ∈[700,1250]；c、d统一显示γ∈[−45,1800]，负向留白仅为完整显示零边界标记；梯度范围[−0.035,0.34]聚焦判据附近。完整计算轨迹保留在CSV，未人工平滑、插入断点或移动交点。
- JSON保存样本ID、数值口径、全部估计与汇总、软件版本和来源/程序/数据SHA-256。
