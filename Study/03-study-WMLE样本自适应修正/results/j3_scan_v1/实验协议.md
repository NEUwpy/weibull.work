# S03-J3-01：固定 J1/J2 的 J3 调整改进空间实验

状态：探索性机会检验。用户已确认先做 J3 改善空间、再训练网络。本协议和候选系数在完整扫描前写入 protocol.json；现有样本曾用于动机探索，本轮不属于预注册独立确认。

## 问题与干预

保持原 WMLE 的 J1、J2、五初值求解器、形状与位置边界、残差阈值和解的选择规则不变，仅令 J3*(n,β)=c×J3(n,β)。每次拟合中 c 固定，β 仍随原求解过程更新；没有将 J3 固定在真形状或基线估计形状处。

这改变的是位置方程的目标值，不是给残差平方项乘权重。脚本在独立进程的隔离模块中调用生产代码快照，不改动生产 WMLE 文件。每个候选从同一套初值重新求解，不采用前一个系数结果作为暖启动。

候选集合：0.70、0.80、0.85、0.90、0.92、0.94、0.96、0.98、1.00、1.02、1.04、1.06、1.08、1.10、1.15、1.20、1.30、1.50。

范围只界定当前机会检验；不是连续最优范围或理论上限。若事后最优大量集中在端点，必须报告截断，再以新协议扩展；不能悄悄改变当前候选集。

## 样本与计算规模

- 历史复核及 n=30 补齐组：24格，每格50组，共1,200组。
- 统一模拟组：11个不同真参数组合×3种n，每格100组，共3,300组。
- 合计4,500组×18候选=81,000次拟合；c=1也重新计算，逐组核对原估计与状态。
- 样本量为7、15、30；β/η/γ三条控制变量轴继续沿用原基线设计。两组分开统计，不以历史数据重复验证新模拟。

样本索引保存原 row_id、cohort、真参数、n、repeat_id、seed_namespace和cell_id；原观测值可从上一阶段样本文件核对，生成器被快照与哈希固定。

## 指标与失败合同

eβ=(β̂−β)/β，eη=(η̂−η)/η，eγ=(γ̂−γ)/η；E=max(|eβ|,|eη|,|eγ|)。

主要风险事件为“拟合失败或 E≥0.5”，分母为全部样本。另报失败率、有效解中的 E≥0.5/1发生率、平均E、E的95%分位数、各参数RMSE。这样不会因丢掉失败样本而奖励某个系数。

固定系数按以下顺序选择：风险事件比例最低；并列时取平均截断损失最低（有效样本min(E,2)，失败记2）；再取失败率低者；最后取最接近1者。截断损失只作并列规则，未用它替代原始误差报告。

## 比较对象

| 对象 | 系数选择信息 | 用途 |
|---|---|---|
| 原WMLE | c=1 | 基线 |
| 全组最佳固定c | 同一cohort全部样本真值 | 统一校正常数能改善多少；同数据最佳 |
| 按n最佳固定c | 同一cohort/n全部样本真值 | 仅按样本量调整是否足够；同数据最佳 |
| 按真参数格最佳固定c | 同一cohort/真参数/n内真值 | 排除单纯参数区域差异后的样本自适应空间；不可部署参照 |
| 逐样本事后最优c | 本次样本真值 | 在候选集合内选有效结果中E最低者；全失败时保留c=1 |
| 五折固定c | 其余4折真值选统一c，应用于本折 | 固定规则的补充折外检查 |
| 五折按n固定c | 其余4折同n样本真值选c，应用于本折 | 可观测n规则的补充折外检查 |

五折通过每格 repeat_id % 5 分配，保留每格比例；没有跨真参数留出，因此不能声称外推。对同数据最佳固定与逐样本事后最优，不把差异当作实际网络提升；对于真参数格固定参照，不声称真参数部署时已知。

## 核验与输出

扫描前：63组冒烟复现覆盖所有57格、5个失败样本和第47组案例。完整扫描：4,500个c=1复现检查全部执行；每格单独检查点保存，协议哈希不同不能复用。

分析输出：原方法与各参照的配对统计、每格/每n的系数风险曲线、事后系数分布、原好样本变差与原坏样本获救的数量、端点命中统计、第47组案例曲线。失败保留具体原因。

后续是否训练网络，需要结合逐样本最优与最佳固定（尤其格内固定）的差距，以及候选系数能否从观测样本中识别。没有充分空间时应保留负面结果，并再讨论是否扩展其他权重。
