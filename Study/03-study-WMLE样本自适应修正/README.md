## 研究动机与主线

历史参数估计案例显示，同一真参数、同一样本量下，WMLE 在部分抽样样本上会给出偏离较大的估计。Study03 从这个现象出发，先统计它的频率、程度和样本结构，再解释 WMLE 方程如何把抽样波动传递到参数估计，最后研究是否能用神经网络选择更适合本次样本的内部过程量。

主线暂定为路线 B：**原 WMLE 现象核查 → 方程与样本结构分析 → 内部权重/过程量的改善空间 → 神经网络实现样本自适应 → 配对评价改进结果。** 路线 A 是估计结果的后处理修正，可在后续作比较，不作为当前核心。两条路线的优劣须由实验检验。

需要准确表达的是：原 WMLE 的权重表没有直接以本次样本的间隔、尾部等结构为输入；J3 随求解中的形状参数变化，因此它也不是完全与数据无关的常数。不能从个别大误差就断言“原权重设计错误”，也不能预先断言网络一定能消除误差。[作者官方实现说明](https://github.com/dcousin3/wMLE)。

同一总体下的样本异质性在这里指不同有限样本 realization 的结构差异，不表示来自不同总体或受到污染。网络最终只能使用观测样本；真参数、真实误差和事后最优权重仅用于仿真标签或机会分析。相似样本可能来自不同真参数，学习更多模拟样本不能保证每一组都估得准。

为进行控制变量分析，另建统一模拟组，seed namespace=20260922，每格 100 次，n=7、15、30：

| 比较轴 | 固定参数 | 变化水平 |
|---|---|---|
| β | η=1000、γ=1000 | 2、3、5 |
| η | β=2、γ=1000 | 500、1000、2000 |
| γ | β=2、η=1000 | 500、1000、3000 |
| β/γ 补充 | η=1000 | β∈{2,3,5} × γ∈{500,1000,3000} |

合计 11 个不同组合、33 格、3,300 组，其中新增 W(5,1000,1000)、W(2,500,1000)、W(2,2000,1000)。它与历史复核组分开统计。总归档为 4,500 次估计；不是 4,500 次同一协议独立确认。

统一 seed namespace 不等于共享随机数：公共样本生成器也将真参数和 n 写入种子，各格是独立抽样；本轮未作同一组标准化样本的平移/缩放对照。

## 评价合同

归一化分量误差定义为 eβ=(β̂−β)/β，eη=(η̂−η)/η，eγ=(γ̂−γ)/η；综合量 E=max(|eβ|,|eη|,|eγ|)。γ 误差按 η 归一化，避免位置平移改变分母。它不是“γ 的百分比误差”。

探索性大误差阈值暂用 E≥0.5，并同时提供 E≥1。报告有效解中的发生比例、95% Wilson 区间、失败率、失败或大误差的全样本比例，以及各参数的偏差、标准差、RMSE、分位数。失败不以零估计进入误差统计，也不悄悄从总数中删除。阈值是本次诊断口径，不是已经冻结的最终训练损失。

基线是本仓库的 Cousineau WMLE 实现：固定原权重表，五个确定性初值，形状上界 10，位置约束 0≤γ̂<最小观测值，方程残差平方和≤1e-8 才算有效。当前结果同时反映权重方法与此求解合同；正式归因需要排除约束、插值、外推和优化器等替代解释。

## 后续方法问题

用户确认的“先扫描J3，再训练网络”已完成首轮：S03-J3-01检出事后空间；S03-J3-02在1,650组新抽样上，网络加失败回退的风险事件率为19.82%，原WMLE31.03%，按n固定加回退27.03%，测试事后参照5.39%，约恢复43.7%的风险改善空间。当前仍有40个原好样本变成风险样本，n=7同一有效样本的E≥1由7例升至27例。下一阶段应先完善尾部损失与好样本保护，并以新测试集确认，而非宣称全面降低灾难估计。

事后最优权重是知道真值的参照，不能当作可部署策略。评价要在训练/验证/测试分离且真参数、seed 未泄漏的情况下进行，并比较“恢复了多少改善空间”和“平均误差/失败是否恶化”。J3 单独不足时，再讨论联合调整；不为维持预设结论隐去负面结果。
