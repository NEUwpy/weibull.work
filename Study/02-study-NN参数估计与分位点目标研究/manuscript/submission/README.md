# Study02 v2.7.0 英文投稿工作包

该包包含通用英文正文、附录、英文图件和投稿附件草稿，供作者复核。当前没有指定期刊，尚未投稿或上传公开资料库。

| 文件 | 内容 |
|---|---|
| [English manuscript](Study02-manuscript-v2.7.0-en.md) | 英文正文，采用与中文稿相同的证据边界 |
| [Supplement](Study02-supplement-v2.7.0-en.md) | 英文附录A–F |
| [Highlights](Highlights.md) | 五条简短研究要点 |
| [Title page](Title-page.md) | 标题页及待作者提供的身份、贡献与声明字段 |
| [Cover letter](Cover-letter.md) | 已写研究内容和意义，期刊适配及投稿声明待确认 |
| [Terminology and status](terminology-and-status.md) | 术语、论证结构与未提供的信息 |
| [完整19条RIS书目](Study02-references-v2.7.0.ris) | 从当前正文导出，可导入EndNote等文献管理器；逐条保留原书目文本 |
| `figures/main/`、`figures/appendix/` | 与中文图同一计算对象生成的英文PNG/PDF/SVG |

下一步定稿所需真实信息：目标期刊及文章类型；作者顺序、单位和通讯信息；作者贡献、基金、利益冲突与其他投稿声明；公开代码数据的存储地址。期刊字数、参考文献格式、图幅和附录规则应在期刊明确后核对。当前工作包不包含虚构作者或自动作出的无利益冲突声明。

可复核的本地复现包与执行说明见 [reproducibility](../../reproducibility/README.md)。文稿、可编辑图源和核验记录均保留；v2.6.0完整快照位于 [历史归档](../../归档/旧稿/v2.6.0/)。
