# Study02 网络与监督原理图

用户指出上一版只像PPT分类框，未画出神经网络和三种方案原理。本版按该反馈重画，文档仍以Markdown交付；源图为draw.io。

| 科学依据 | 图中编码 |
|---|---|
| 正文2.1–2.2 | 排序样本、训练集标准化、n–256–128–64–3全连接网络、ReLU、三输出与参数解码 |
| 位置解码公式 | 原始样本最小值旁路进入解码器，s为有边界余量的sigmoid |
| 参数损失LP | 三个归一化误差分别平方，汇总取平均，反向传播到参数θ |
| 目标损失LQ | 三参数经Weibull公式形成目标寿命点，与真寿命点比较，再回传 |
| QCP增广拉格朗日训练 | LP,b−τ形成约束违反量，Ψ与LQ,b合成训练损失，参考阈值单独输入 |
| 验证检查点 | P/Q取各自最低验证损失；QCP先判断平均参数损失可行，再选目标损失最低者 |

所有网络点、连接、计算模块、公式标签和小图均为可编辑矢量。顶层圆点只示意神经元，不能按圆点数解释实际层宽；下方网络为同一网络的缩略符号，不是两层替代网络。底部全部为构造的规则示意，非实验数据。实验图2–4不修改。没有外部照片、生成图像或HTML文档交付。
