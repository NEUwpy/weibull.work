## 1. 方法

### 1.1 分析对象与配对

- 逐 held-out 预测：P 与 Q 各 60 个模型（4 n × 5 fold × 3 seed）× 2400 行 = **144,000 行/路线**；
  同一 `(n, fold, seed)` 的 P/Q 行一一配对（样本身份、输入、真值完全一致，唯一差异为 loss）。
- 所有量在**每个真值样本**上计算，再做 pooled 与按 β / γ/η / n 的区域聚合。

### 1.2 冻结的公式（真值处）

目标可靠度寿命点（`09` §1.1）：
\[
x_p = \gamma + \eta\,[-\ln p]^{1/\beta},\qquad p=0.95,\quad a=-\ln(0.95)\approx 0.0513,\quad
\ln a\approx -2.970.
\]

无量纲参数误差（与 P 损失同构，任务冻结定义）：
\[
u=\left(\frac{\hat\beta-\beta}{\beta},\;\frac{\hat\eta-\eta}{\eta},\;\frac{\hat\gamma-\gamma}{\eta}\right)
\]
无量纲敏感度向量（相对 x 误差的一阶系数，真值处解析）：
\[
s=\left(s_\beta=\frac{\partial x}{\partial\beta}\frac{\beta}{x},\;
     s_\eta=\frac{\partial x}{\partial\eta}\frac{\eta}{x},\;
     s_\gamma=\frac{\partial x}{\partial\gamma}\frac{\eta}{x}\right),
\]
\[
\frac{\partial x}{\partial\beta}=-\eta\,a^{1/\beta}\,\frac{\ln a}{\beta^2}>0,\qquad
\frac{\partial x}{\partial\eta}=a^{1/\beta}>0,\qquad
\frac{\partial x}{\partial\gamma}=1.
\]
（`\ln a<0`，故 dx/dβ>0；实现 `mechanism.analytic_sensitivity`，与有限差分 rtol 1e-6 一致。）

### 1.3 分解与机制量（逐样本）

- **实际误差** `actual = rel_err`（保存的 `(\hat x_{0.95}-x_{0.95})/x_{0.95}`）。
- **一阶投影** `proj = s·u = s_β·u_β + s_η·u_η + s_γ·u_γ`（component contributions
  `c_β,c_η,c_γ` 即 `s_β·u_β` 等）。
- **非线性余项** `rem = actual − proj`（吸收二阶及以上、有限参数效应、float32 存储）。
- **目标对齐 vs 等分位点切向/噪声**：
  `u_par = proj/‖s‖`（沿 ŝ 的分量，目标对齐）、`u_perp = √(‖u‖² − u_par²)`、
  `align = |u_par|/‖u‖`（对齐度，`u=0` 时置 0）。
- **分量抵消指数**（显式定义，零分母处理）：
  `cancel = (|c_β|+|c_η|+|c_γ| − |proj|) / (|c_β|+|c_η|+|c_γ|)`；
  `|c_β|+|c_η|+|c_γ| = 0` 时 `cancel = 0`（`np.divide(where=...)`，不产生 NaN）。含义：
  三个一阶分量的内部抵消程度，0 = 无抵消（同向），1 = 完全抵消（proj=0）。
- **解码器边界诊断**：`γ̂/min_x ≥ 0.9999` 计数（与 r4 `boundary_diagnostic.json` 同阈值）。
- 参数误差模长 `u_beta, u_eta, u_gamma, u_norm` 的 RMS 与分位点分布。

### 1.4 推断与测试

- **设计级配对区间**：复用 S1 冻结的 `EVAL.primary_design_bootstrap`
  （fold 按 n 分层 × seed 全局，rng 20260805，B=20,000），对机制量（rms_actual、rms_proj、
  rms_rem、mean_align、mean_cancel、rms_u_par、rms_u_perp）的逐 `(n,fold,seed)` cell 值
  求 Q−P 配对差值与 95% CI。
- **S1 交叉校验**：机制 `rms_actual` 与封存 `summary_iid.json` 的 pooled rRMSE 对照。
- **区域符号翻转复现**：每个区域 bin 的机制 `delta_rms_actual` 符号 vs 封存 S1 `s1_mean_diff`
  符号（17 个 bin：8 β + 5 γ/η + 4 n）。
- 12 项聚焦测试（`test_pq_mechanism.py`）：解析导数 vs 有限差分、proj=s·u 恒等式、
  rem=actual−proj、Pythagoras、align 几何、cancel 零分母/极端值、真实证据配对与有限性
  （subprocess 隔离 iid 协议）。全套 58 passed。

## 3. 解释

### 3.1 机制（与分解事实区分：以下为解释）

**Q 的增益来自「沿等分位点曲面的非线性补偿」，不是一阶投影、也不是分量抵消。**

1. **P 是「小参数误差 + 一阶主导」路线**：参数误差小（u_norm 0.23）、近似各向同性，
   一阶投影解释 98.9% 的实际误差。P 的 x 误差 ≈ 敏感度加权后的参数误差。
2. **Q 是「大参数误差 + 非线性补偿」路线**：参数误差大 ~39×（u_norm 9.13），集中在
   u_beta（9.08）与 u_eta（0.93），即沿等分位点曲面移动（β̂↑、η̂↓、γ̂↑，维持 x_0.95）。
   一阶投影预测 6.37 的 RMS（远比 P 差），但非线性余项 −6.36 与之 corr −0.9995 地抵消，
   净剩 0.1611。
3. **为什么这样是可能的**：x_0.95 是一个标量目标对三维参数，解不唯一；Q 只受
   x_0.95 误差约束，可自由游走等分位点曲面。曲面在参数空间是**弯曲**的，切平面（一阶）
   在远处离开曲面，而实际 x 误差随曲率回到近零。Q 正是利用了这一曲率。

**已测事实直接排除的三类朴素解释**（不是仅靠推理）：

- **「Q 靠一阶投影更小」——排除**：Q 的一阶投影 6.37 ≫ P 的 0.166，R²=−1556（比常数预测还差）。
- **「Q 靠分量抵消指数」——排除**：Q 的 cancel 指数 pooled 反而略低于 P（0.342 vs 0.357）；
  且按 β、γ/η，Q 的 cancel 相对 P 越高（delta_mean_cancel 越大）的区域恰好是 Q 更差的区域
  （corr +0.81 / +0.98）。
- **「Q 更垂直（u_perp 大）所以更优」——不充分**：γ/η=1.0 处 Q 的对齐差最大
  （delta_mean_align=−0.169，最垂直），却是 Q 输的区域；γ/η=0.1 处 Q 对齐差小
  （−0.072），却是 Q 赢的区域（corr(delta_align, γ/η)=−0.98）。垂直性本身不决定胜负，
  决定胜负的是曲率补偿能否压过 P 的小误差一阶路线。

### 3.2 区域反转（解释，探索性标注）

**翻转处**：β=3.5 与 γ/η=0.5 处 Q 的优势转为 P 更优；n 从不翻转。三个维度中，β 与 γ/η
改变**等分位点曲面的形状**，n 只改变估计精度（不改变曲面形状）——与「n 从不翻转、β/γ/η
翻转」的观察一致：

- **低 β / 低 γ/η（Q 赢）**：x 对参数敏感、曲面曲率大，Q 的曲率补偿空间大，压过 P 的
  小误差一阶路线（β=1.5：Q 0.254 vs P 0.282，−10%；γ/η=0.1：−10.6%）。
- **高 β / 高 γ/η（P 赢）**：`a^{1/β}→1`（β↑），x 对 β 的依赖减弱、曲面趋于更平/更近线性
  （γ/η↑ 时 γ 项主导，x≈γ+η·小量）；Q 的曲率补偿空间缩小，抵消后净残差不再低于 P 的
  一阶路线（β=5：Q 0.110 vs P 0.103，+6.7%；γ/η=1.0：+8.2%）。
- **n（Q 恒赢）**：曲面形状与 n 无关；n 增大只让两条路线误差都收敛（0.161→更小），
  Q 的相对优势随 n 缩小但符号不变。与 S1 的按 n CI 全不含 0 一致。

这一解释与 17/17 符号复现、以及「n 不翻转 vs β/γ/η 翻转」的异质性一致，但**区域相关仅
覆盖少量 bin（8+5+4），未加权，属探索性**；不作因果主张。

## 4. 限制

- **分解不证明因果**：proj/rem 分解与区域相关是观察性证据；「曲率补偿」是符合全部已测
  事实的解释，未经干预实验（M3 之后才可能）确认。
- **一阶投影在真值处取敏感度**：余项吸收二阶及以上、有限参数效应与 float32 存储；对
  远离真值的 Q，余项的量级大（6.36），其「抵消」依赖 x_0.95 公式的特定曲率，推广到其他
  分位点/结构需 M3 验证。
- **3 个 seed、训练折重叠**（每个 repeat 在 5 折的 3 折训练）；seed 维度欠采样。
- **区域相关是描述性/探索性**：少量 bin、未加权、不逐 cell 做显著性（避免大量未校正的
  cell 显著主张）。
- Q 的极端参数（β̂/β 中位 6.9、η̂/η 中位 0.06）说明 Q 的**单个参数估计不可靠**；本分析
  只评价 x_0.95，不主张 Q 的其他量（与 S1「Q 以退化内部表示达到分位点目标」一致）。
- 环境/复现：同 `configs/pq-environment-v2.json`（Python 3.11.9 / torch 2.12.0+cpu /
  numpy 2.4.6）；分析为 numpy 纯计算，确定性。
