## 2. E1 目标可靠度水平（x0.90 / x0.95 / x0.99）

### 2.1 设计（冻结 §2 E1）

- 复用 S1 的 P 与 Q0.95 证据；新训目标特异 Q0.90、Q0.99（4 n × 5 fold × 3 seed × 2 目标 = **120 新 fits**）。
- 每个保存模型在全部三个水平解析重算评价（`x_p = γ + η·(−ln p)^(1/β)`，R(x_p)=p 可靠度寿命点）。
- 目标特异比较：Q_p vs 同一 P 路线在 p；交叉目标表现是特异性/权衡的描述性证据。

### 2.2 目标特异结果（confirmatory primary = x0.95）

| 水平 p | P pooled rRMSE | Q_p pooled rRMSE | rel_change (Q−P)/P | pooled Δ (95% CI, B=200k) | 按 n 方向 |
|---|---|---|---|---|---|
| 0.90 | 0.13834 | 0.13490 | **−2.49%** | −0.00094 [−0.00121, −0.00069] | 4/4 n 均负，CI 全不含 0 |
| 0.95 | 0.16633 | 0.16111 | **−3.14%** | −0.00171 [−0.00225, −0.00119] | 4/4 n 均负，CI 全不含 0 |
| 0.99 | 0.22239 | 0.20792 | **−6.50%** | −0.00622 [−0.00749, −0.00502] | 4/4 n 均负，CI 全不含 0 |

- **x0.95 复算与 S1 封存一致**：`s1_sealed_cross_check.match_within_1e6 = true`（recomputed P 0.166326839 / Q 0.161111663 vs sealed 0.166326836 / 0.161111668）。
- 单元方向：57–58/60 cell 为 Q 更优、2–3 为正、0 零（`direction_by_cell`）。
- 失败与边界：每水平 60 fits 全部 converged、0 NaN、0 非有限、0 非法、0 支撑违规；144,000 行 0 边界。
- 结论：任务对齐训练在 x0.90 与 x0.99 仍然有用，且**更极端的可靠度寿命点收益更大**。

### 2.3 交叉目标矩阵（特异性/权衡，描述性）

全部路由在三个水平评价（Q 路由只在其训练水平上训练）：

| 训练路由 | eval 0.90 | eval 0.95 | eval 0.99 |
|---|---|---|---|
| P（参数精度） | 0.13834 | 0.16633 | 0.22239 |
| Q95（S1） | 0.18680 (+35.0%) | 0.16111 (−3.1%) | 0.35856 (+61.2%) |
| Q90 | 0.13490 (−2.5%) | 0.21789 (+31.0%) | 0.53982 (+142.7%) |
| Q99 | 0.34340 (+148.2%) | 0.27413 (+64.8%) | 0.20792 (−6.5%) |

- 离目标退化（off-target minus diagonal）：Q90→0.95 +61.5%、Q90→0.99 +300.2%；Q95→0.90 +15.9%、Q95→0.99 +122.6%；Q99→0.90 +65.2%、Q99→0.95 +31.8%。
- 解读：目标特异 Q 在**自身水平**获得明确收益，但泛化到其他可靠度水平是**坏的**——Q 对齐是窄带、非分位点通用的。P 在跨水平上最稳健（monotonic 随 p 增大），代价是目标点处精度不如对齐 Q。

## 3. E2 网络容量敏感度

### 3.1 设计（冻结 §2 E2）

- 仅 iid x0.95，全部 n 与 3 seed，固定 folds {1,3}（1-based）；基线容量复用 S1 对应结果。
- small `64-32` 与 large `512-256-128`，P/Q 配对。新 fits：2 容量 × 4 n × 2 fold × 3 seed × 2 route = **96**。
- 有限 fold 稳健性检查：报 route 效应、跨容量方向、参数计数与失败；不做正式显著性主张。

### 3.2 结果（fold {1,3} 描述性）

| 容量 | 参数数（n=7..20） | P pooled rRMSE | Q pooled rRMSE | rel_change | 方向 cell |
|---|---|---|---|---|---|
| small 64-32 | 2,691–3,523 | 0.16700 | 0.16438 | **−1.57%** | 20/24 负 |
| baseline 256-128-64 | 43,395–46,723 | 0.16762 | 0.16218 | **−3.25%** | 23/24 负 |
| large 512-256-128 | 168,707–175,363 | 0.16640 | 0.16190 | **−2.70%** | 19/24 负 |

- 全部 4 n 上 Q 均更优（rel −0.5%~−4.7%）。
- 失败与边界：每容量 48 fits 0 失败、0 支撑违规、0 边界行。
- 结论：P–Q 优势**不依赖**基线容量是特殊点——64× 更小或 ~4× 更大的网络下 Q 仍更优。容量不改变方向，效应量在 three 档间相近（未发现单调容量依赖）。

## 4. E3 域内插值

### 4.1 设计（冻结 §2 E3；R2 修订重跑）

- x0.95、基线容量、全部 4 n、全部 5 fold、3 seed、P/Q 配对。
- 训练严格保持 S1 冻结网格；测试为**确定性新鲜样本**：beta 中点 {1.75..4.75 step 0.5}（7 个）、
  gamma/eta 中点 {0.175,0.375,0.625,0.875}（4 个）、eta=1000、每中点组合 300 repeats，
  命名空间 `study01_nrmc_v1`，共 33,600 样本；每 fit 取其 n 对应 8,400 行。
- 模型 state 未保存：在**独立插值产物根** `pq_s3_interp` 确定性重训 120 基线 P/Q fit 并评价；
  **不修改、不假装复用 S1 模型文件**。新 fits：**120**。
- **R2（S3-001）**：初版插值评价把**原始（未标准化）中点样本**直接送入仅在 (n,fold) 标准化
  输入上训练的网络 → 伪 130%/40% rRMSE 与 37.7% γ 边界。修复：`eval_interp` 接收调用方传入的
  `PerPositionScaler` 并在推理前 `scaler.transform(X_n)`（commit `4cf482f7`）。**仅重跑 E3**
  （120 基线确定性重训 + 插值评价），E1/E2 结果不变、未重跑。以下全部为修复后数值。

### 4.2 确定性同一性（关键约束）

- **`s1_evidence_identity`：120/120 重训 iid-test 证据与 S1 `pq_iid_main` 字节一致（PASS）**——
  插值根中的基线重训是 S1 训练的确定性复制（初始/批/缩放合同逐字节复现）。
- 插值样本生成确定性：`build_interp_master()` 两次重建字节一致；样本按行升序（`np.diff≥0` 断言）。
- 新增回归测试 `test_eval_interp_applies_caller_scaler`：断言模型输入 == `scaler.transform(X_n)`
  且 ≠ 原始 `X_n`（非恒等 scaler 下）。

### 4.3 结果（配对模型级平方相对误差，x0.95；B=200k bootstrap）

- **域内中点与网格点同量级**：pooled rRMSE（8,400 中点样本/fit × 120 fits）**P 0.14349 /
  Q 0.14617**（网格点 x0.95 ~0.16）。rel_change (Q−P)/P = **+1.86%**（P 更优）；pooled Δ
  +0.000775，95% CI **[+0.000539, +0.000985]**（不含 0）——Q 在网格点上的优势在**中点**反转，
  与 E1「Q 窄带对齐」一致。
- 按 n：rel +2.06%（n7）/ +1.73%（n10）/ +2.10%（n15）/ +1.25%（n20），全为正（P 更优）。
- 按 beta 中点：仅最低 β=1.75 Q 优 −1.73%；β≥2.25 全部 P 更优（+0.69% → +8.62%，随 β 增大）。
- 按 gamma/eta 中点：仅最低 γ/η=0.175 Q 优 −7.67%；0.375/0.625/0.875 全部 P 更优
  （+9.87% / +9.89% / +4.03%）。低 β、低 γ/η 中点保留 Q 优势——与网格点区域模式
  （低 β、低 γ/η Q 更优）一致。
- **解码器边界**：**0 / 504,000 行**落在 γ 边界（γ̂/min(X) ≥ 0.9999）——初版的 37.7% 为
  未标准化评价的伪影，已撤回。
- 失败：120 fits 0 失败、0 支撑违规、0 非有限。

### 4.4 解读（科学问题 3）

- **域内插值推广成立（R2 后）**：位于 Study01 网格内部的 β、γ/η 中点，P 与 Q 的 rRMSE
  （0.143–0.146）与网格点（~0.16）同量级——模型对未见过的参数组合**保持**域内精度，
  无 γ 解码器塌缩。S3 此前基于未标准化评价主张的「灾难性插值失效」**撤回**。
- **所测联合中点上 Q 优势未保持**：Q 在中点不再更优，反而整体 P 优 1.86%（CI 不含 0）。
  Q 的目标对齐是窄带的（E1 交叉目标矩阵一致：目标特异 Q 离自身水平即退化 +16%~+300%）。
  仅低 β/低 γ/η 中点（‖s‖ 高、网格点上 Q 优势最强的区域）Q 保留优势。不把该反转归因为
  网格过拟合或笼统的网格特异性（S3-002，未经进一步实验）。
- 插值**不是** OOD：中点与网格点同属 iid 数据合同（同分布、repeat-stratified 拆分；仅参数值
  落在网格单元内部）。真正的边界实验是 E4（gamma 层级 holdout）。
- 该结论与 E4 的 gamma 层级 OOD 反转共同刻画边界：**域内网格点与域内中点为可靠精度区
  （Q 仅在网格点占优）；gamma-holdout OOD 劣化且 Q 优势反转（Q 高 P 8.77%（(Q−P)/P），
  P 更优）**。

## 5. E4 OOD 边界（复用封存 r4/v3，不重训）

- 复用已封存 `pq_v3`/`pq_v2` gamma-holdout 结果作为独立边界实验：iid x0.95 **Q 优 3.1%**；
  gamma 层级 **OOD Q 高 P 8.77%（(Q−P)/P；P 更优）**（r4 合同，direct-P + domain-explicit
  解码器；历史口径 (Q−P)/Q = 8.07% 为“P 相对 Q 的误差降低”，分母不同）。
- 审计：iid、插值、OOD 是**不同 estimand/数据合同**，**不**池化进同一 pooled 结论；
  gamma-holdout OOD 与 iid repeat-stratified 的差异见 `02/03/04-PQ` 既有记录。
- S3 只引用该封存结论以回答「gamma 层级 OOD 下哪里失效」；未重训、未修改封存证据。

## 6. 机制一致性（S2 机制 × S3 目标结果）

- **精确分解在每个目标水平成立**：`exact_identity_at_p` max|残差| ~1e-15（P/Q 均）——
  `actual = C_β + C_η + C_γ` 在 p=0.90/0.95/0.99 下逐行成立（从存储 hat + 真键在 p 处解析重算）。
- **Q 的目标收益来自参数误差精确分量补偿**：pooled `cancel_exact`

  | 水平 | P | Q_p | Δ（95% CI） |
  |---|---|---|---|
  | 0.90 | 0.3625 | 0.9267 | +0.564 [0.557, 0.571] |
  | 0.95 | 0.3518 | 0.9149 | +0.563 [0.556, 0.570] |
  | 0.99 | 0.3290 | 0.7153 | +0.386 [0.379, 0.393] |

  Q 的 C 分量抵消约 2.2–2.6× P 的（x0.99 最小）。`mean_s_norm` P/Q 严格相等（只依赖真值参数，Δ=0）。
- **收益集中在高敏感度区域**（探索性相关，不主张因果）：区域 mean‖s‖ 与区域 (Q−P) 目标误差改进的
  相关：β −0.94（0.9）/ −0.95（0.95）/ −0.97（0.99）；γ/η −0.91 / −0.87 / −0.88。低 β、低 γ/η
  （‖s‖ 高）区域 Q 受益最大——与 S2 的敏感度机制一致：**x_p 对参数越敏感，允许参数误差在目标点
  抵消的价值越大**。
- 机制上 x0.99 收益最大（−6.50%）与其 ‖s‖ 整体更高、抵消对极值点更关键的几何一致。

## 8. 边界与限制

1. **目标水平族系**：x0.90/x0.99 为预指定 robustness 结果，报效应量与设计级区间；三个 95% 区间
   不构成新的族系显著性主张（confirmatory primary 仅 x0.95）。
2. **容量实验两折设计**：E2 仅 fold {1,3}，效应量与方向可靠，不做两折正式显著性/架构优越性主张。
3. **R2 撤回的初版 E3 主张**：初版把未标准化中点样本送入标准化训练的网络，产生伪
   130%/40% rRMSE 与 P 37.7% γ 边界，已撤回；修订后 E3（本节）为最终结论。
   对**域内中点**不主张 OOD 类劣化；γ 边界饱和在新证据中为 0/504,000 行。
4. **模型 state 未保存**：插值用独立重训（已验证字节同一性），不是 S1 权重在同一模型上的评价；
   不假装复用 S1 模型。
5. **机制相关是探索性**：‖s‖ 依赖 P-loss 继承的归一化参数坐标；对称精确分配是精确但非唯一的
   分配方式（S2 告诫，S4/S5 须陈述）。
