# Study/02 C 阶段：机制分析与补充证据（修正版）

> 状态：2026-08-02（R1 修正后重写）。原 C2–C4 基于 B4/B5 的无效 P 预处理（未施加 A-E1 输入 scaler），其"D 相对 P 更优"的机制解释**已被取代**。本文按修正后权威证据（`05-B-增量实验报告.md`、`BINC-20260802-02`）重写当前机制分析。
> 口径：\(x_{0.95}=\gamma+\eta[-\ln(0.95)]^{1/\beta}\)；P=NN 参数路线，D=NN 直接分位点路线。

## C-1：修正后 core 上 P 与 D 的实际关系

**观察**（paired-seed hierarchical bootstrap，corrected P with A-E1 scaler）：
- core 5-n equal-per-n pooled：P 0.2709 / D 0.3034 / **I=−0.120（P 更好）**；密集 19-n pooled I=−0.0745。
- per-n：P 在 n=5–9、12 **显著更优**（BH supported）；n=10–30 无确认差异；**无任何 n D 优于 P**。

**机制解释（数据一致，非唯一因果）**：
- 原"C2-1：n=5 D 强优来自 P 灾难性负偏"**失效**。修正后 n=5 P bias +0.054（原 −0.916）、γ/η 反事实 0.457/0.148（原 2.445/1.719）、非加性 0.061（原 0.642）。P 的 n=5 参数估计并不灾难，只是原评估喂错了输入。
- D 的直接标量预测未带来超越 P 的精度：D 各 n 轻微负偏（低估），P 轻微正偏，RMSE 上 P 略优或持平。

## C-2：参数边界（修正后）

- **β 主轴**：所有 n 上低 β → P 显著更好（n=6 β0.9 I=−0.70；n=15 β0.9 I=−1.11）；高 β → 无差异（I≈0，**无 D 更好区域**）。原"低 β P、高 β D"的穿越**失效**（那是 raw-P 伪影）。
- 异质性信号（描述性）：between-region 方差 / within-cell 9–72×；但因 P 各区域均不劣于 D，区域差异表现为"P 优势的程度不同"，而非"方向相反的区域平均抵消"。原 C2-1 的"参数区混合抵消 n=7/10"**不再适用**（n=7/10 修正后 P 显著更优）。

## C-3：哪些机制可由证据支持，哪些只是假设

**支持（反事实/参数误差证据）**：
- P 保留完整参数结构，在正确输入下其参数误差随 n 缩小（γ 反事实 n5 0.457 → n20 0.229），未为"直接分位点目标"付出 x0.95 精度代价。
- D 在训练支持外（stress low/loc、NIST 真实数据）有部分优势：low n5–10 D 更优、loc D 更优、NIST D pinball 略优——说明"目标对齐"在**域外/真实数据**上可能带来小收益。

**假设（未消融识别）**：
- "为何低 β P 更优"的机制（表示/目标编码差异）是候选，未做目标/架构消融。
- **原"目标对齐收益"不可保留**：原 P 0.6943 vs Dctrl 0.3296 基于无效 P 比较；修正后 P 0.2709，该归因无法从错误比较中继承，**当前按未识别处理**（除非用修正输入重新形成受控证据）。

## C-4：信息取舍（保留边界）

- **P 的功能价值保留**：P 输出完整合法 β/η/γ（100% 合法、0 γ 支持违规）——这是 D 不提供的功能；且修正后 P 不为此付 core 精度代价。
- **域外边界保留**：stress 只诊断 OOD 失效、不提供 OOD 保证；NIST 无已知真 x0.95、只作比较性外部一致；conformal 只在 core 有效。D 在域外/NIST 有轻微优势但两者均 anti-conservative。
- **传统方法基线保留**：core 上 MDM、LRE 在共同有效行更优，D 相对传统方法无全面优势。

## 一句话机制判断（修正后）

| 范围 | 判断 | 证据等级 |
|---|---|---|
| core（训练支持内） | P 不劣于 D（n=5–9/12 显著更优，无 D 优势）；D 的直接目标未带来 x0.95 精度收益 | 高（paired bootstrap + 反事实，共享 n 复现修正 B4） |
| 低 β | P 显著更优（n≥8 全域） | 高（参数网格 stratum-pooled） |
| 训练支持外（stress low/loc、NIST） | D 有部分优势（可用率/精度条件性） | 中（域外，条件于有效行） |
| 原"目标对齐收益" | **未识别**（旧比较无效，未用修正输入重做受控） | — |
