## 三、执行约定

- Codex 为 reviewer/controller，Claude Code 或 OpenCode 为 executor；同一工作树同一时刻只有一个写入者；
- 正式执行从 B0 精确提交创建新分支，建议名 `codex/study02-quantile-formal-20260731`；不得在旧 A 分支上混写运行结果；
- 每阶段形成一个 coherent commit，再通过 mailbox 提交 exact tip、改动文件、检查结果、运行路径、异常和下一阶段建议；
- reviewer 只在 executor 发出完成报告后检查实际 diff、测试和证据，使用 APPROVE / REVISE / BLOCK；
- 阶段内部的普通实现选择由 executor 自主决定，但不得扩大研究问题、候选搜索、训练 fit 或数据范围；
- 大型运行写外部目录，Git 中只放必要的可审计摘要；不得为协调消息、审批回执或 heartbeat 创建 tracked 文件。
