## 一、C 要回答的科学问题

C 阶段不提出新的实验主张，而是把 B 的确认性结果组织成一个可审查的科学论证。它必须回答六个问题：

| 问题 | C 的答案（对现有证据的最小充分表达） |
|---|---|
| **Why** 为什么研究这个问题 | 可靠性工程最终关心寿命分位点而非分布参数本身。若只需 \(x_{0.95}\)，保留完整 Weibull 参数化是否是工程上不必要的中间表示？研究检验：训练目标与工程目标对齐能否带来可量化、可泛化、边界清楚的收益。 |
| **What** 结果为什么呈现当前规律 | B 显示直接路线 D 相对参数路线 P 在 core pooled 上改善 I=0.3926 [0.3444,0.4347]（supported and material），但优势分层且非全域：n=5/15/20 支持、n=7/10 无确认差异；压力层 D 可用率下降；core 上 MDM/LRE 仍更优。规律本身必须分层报告，不能折叠成单一平均。 |
| **How** 收益来自哪里 | 受控归因（B3）指向**训练目标对齐**为主：匹配 P 骨干的直接目标控制 Dctrl（RMSE 0.3296）相对 P（0.6943）改善巨大，而选中 D 架构 [64,32]（0.3290）与 Dctrl 几乎相同，说明架构/资源配置只解释很小部分。 |
| **替代解释** 哪些需要排除 | 资源配置/骨干差异（B3 部分排除但 seed 数不对称）、输出可用率差异造成的行级偏差、MLE 失败行的存活者偏差、以及"直接路线总体更优"本身（B4 已排除）。目标编码隐式先验无可复用预测与数据检查，只作为讨论限制，不作为 C 必做分析。 |
| **边界** 在哪些条件下有效/不确定 | 有效：core 域、n=5/15/20、高 β 压力层、同域 conformal 覆盖。不确定：n=7/10 无确认差异、低 β/location 压力层可用率下降、污染分条件混合、NIST 无已知真值。 |
| **取舍** 牺牲了什么信息 | D 牺牲 P 提供的完整 β/η/γ 输出、100% 合法率与 0 支持集违规的诊断能力，换取支持分层上的目标分位点精度改善；P 保留完整分布信息但付出约 39% 的 x0.95 相对 RMSE 代价。 |

**中心定位**：本研究不是宣称存在普遍最优估计器，而是说明"面向目标量 \(x_{0.95}\) 的直接学习"相对"先学习完整参数、再推导目标量"的收益、机制、边界及信息取舍。任何超出该定位的表述（普遍最优、全域可用、OOD 保证、跨材料普适）都不属于可主张范围。

## 二、核心主张及明确边界

### 主张

| 编号 | 主张 |
|---|---|
| C-A | 在 core 支持分层（n=5/15/20、高 β）上，直接路线 D 是相对 NN 参数路线 P 更优的 \(x_{0.95}\) 路线：pooled I=0.3926 [0.3444,0.4347]。 |
| C-B | 该收益主要来自训练目标与工程目标对齐，而非架构/资源配置：受控归因 P 0.6943 vs Dctrl 0.3296；D 0.3290 与 Dctrl 几乎相同。 |
| C-C | 收益在 core 上分层：n=5/15/20 支持、n=7/10 无确认差异；压力层 D 可用率下降（low n5 58.4%），不合并为全域平均优势。 |
| C-D | D 不是总体精度最优方法：core shared-valid 行上 MDM、LRE 更优，D 仅对 MLE 无差异。 |
| C-E | P 保留完整 β/η/γ 与 100% 合法/0 支持集违规的诊断，是 D 不提供的功能收益；但 n=5 参数精度受限（η RMSE 5.136、γ 1.863）。 |
| C-F | core 上 split-conformal 90%/95% 区间覆盖接近标称，是有效的域内风险提示；压力层只诊断域外覆盖失效，不构成 OOD 保证。 |

### 边界（不可主张）

- 不可从 \(x_{0.95}\) 推断任意分位点成立；
- 不可将压力层与 core 合并后声称全域平均优势；
- 不可用单一 NIST 数据集证明跨材料普适性（无已知真值）；
- 不可声称 D 提供 β/η/γ 或非目标分位点；
- 不可将 stress 覆盖、可用率或"输出有限/合法"写成精度/鲁棒/保证；
- 不可在 MLE 32% 失败行上静默存活者偏差后宣布 NN 全面获胜。

## 五之一、C2 结果索引

C2 机制分析修订版已完成，详细结论见 `07-C-机制分析与补充证据.md`；机器可读 summary 与图见 `artifacts/c/C2-mechanism-20260801-152548/`（summary `8e6e9b19…`，manifest `885e8690…`，两图 SHA256 见该 manifest；manifest 绑定 code commit `8cc93147`，code_tree_clean=true）。核心结果：

- **C2-1（n 异质性）**：n=5 D 强胜由 P 灾难性负偏驱动（P bias −0.916、SD 1.131、RMSE 1.455 vs D 0.508；**cluster-RMSE D-better 64/64**，cluster I 中位 0.612）；n=7/10 无确认差异（**无确认差异 ≠ 等价**；cluster-RMSE D-better 49/64、38/64，cluster I 中位 0.021/0.032，β 分层存在方向相反 cell）；n=15/20 D 再胜（P 偏正漂移 + D 略小离散，cluster I 中位 0.051/0.151）。
- **归一化 seed spread**：n=5 P 的 ensemble SD / true_x095 均值 **0.209**（D 仅 0.013），P spread–误差 Spearman 0.778；n 增大后 P spread 快速下降（0.209→0.022）。
- **C2-2（参数→x0.95 传播，相对口径）**：n=5 时 P 的 γ/η 相对单参数贡献巨大（γ 2.445、η 1.719 倍目标量）且方向相反、部分抵消（组合 0.949）；非加性 0.642；雅可比相对残差 0.664（n=5 强非线性下不可靠）。**组合相对误差与 B4 P_rel_err 逐行比对 max diff 2.7×10⁻¹⁵**（口径完全对齐）。
- **C2-3（目标对齐归因）**：相同骨干 m12 上 P 0.6943 vs Dctrl 0.3296（相差 52% RMSE）；Dctrl seed RMSE [0.3255,0.3321] 全部低于 P 任一 seed [0.5371,0.8387]；方向对 seed 重采样稳健。**direct-target treatment package 的方向性受控证据**（输出维度与损失属处理本身，非可拆解残余混淆）。
- **P 参数推断验证**：64,000 per-seed 推断与 B4 NPZ 最大相对差 5.9×10⁻⁸；equal-per-n I=0.3926 与 B1 一致。
- **未触发新增训练门**：Dctrl seed 分布不足以让 0.3296 vs 0.6943 方向反转，本轮未补 Dctrl seeds。
