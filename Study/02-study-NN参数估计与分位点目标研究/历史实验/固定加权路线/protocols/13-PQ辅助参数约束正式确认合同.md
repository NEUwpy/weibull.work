# Study02：P+Q 辅助参数约束正式确认合同

> 状态：`USER AND MENTOR APPROVED / FROZEN`（2026-08-27）。
> 本合同在任何正式测试结果产生前冻结。结果先进入独立报告，不自动改写论文。

## 1. 固定候选

验证专用筛选在测试访问为0的条件下选择：

\[
L_{QP}=L_Q+1.0L_P,
\]

训练预算保持 max epochs 300、patience 20。训练目标包含 P，但 early stopping 与 checkpoint
仍只看 validation (L_Q)。不再搜索新的 \(\lambda\)、epoch、网络或数据量。

## 2. 正式设计

使用既有同分布 repeat-stratified 180/60/60 合同、四个样本量、五折和预先固定的10个训练种子，
新增200个 QP fit。P/Q 的400个既有 fit 从 `pq_iid_main` 与 `pq_s5b_revision/grid_extra`
只读复用，不重训。

每个 QP 必须与对应 Q/P 共享训练、验证和测试行，初始化、首轮batch顺序、网络、scaler、优化器和
训练预算；任何配对不一致均停止分析。

## 3. 成功标准

最终目标只有独立测试 (x_{0.95}) 相对平方误差。正式结论要求以下两个命题同时成立：

1. QP−Q 的设计级配对95%经验 bootstrap 区间完全低于0；
2. QP−P 的设计级配对95%经验 bootstrap 区间完全低于0。

区间以四个 n、每个 n 内五折、全局10个训练种子的交叉配对重采样计算，B=200,000。
同时报告 P/Q/QP pooled rRMSE、QP相对两者的rRMSE改善、10个seed方向和200个模型单元方向。

只有两个命题都通过，才支持“在当前冻结域和当前网络下，加入分位点视角并以参数误差辅助选择，
最终优于纯参数P和纯目标Q”。任一命题未通过，就不能称 P+Q 新路线胜出。

## 4. 结论边界

- 不声称 \(\lambda=1\) 是连续域全局最优；它只是冻结离散筛选的胜出候选；
- 不声称对其他分位点、其他网络、其他参数域或真实数据自动成立；
- P 是辅助约束，参数精度只作机制诊断；
