> 状态：2026-08-02（R1 修正后重写）。原 C5（绑定 commit `8cc93147`）基于 B4/B5 的无效 P 预处理，其核心结论（"D 相对 P 更优、目标对齐收益"）**已被取代**。本文为当前论文直接加工底稿，依据修正后权威证据（`05-B-增量实验报告.md`、`BINC-20260802-02`）。Git history 保存原版全文。
> 口径：\(x_{0.95}=\gamma+\eta[-\ln(0.95)]^{1/\beta}\)，R=0.95 为失效 CDF 下侧 5% 分位点。

## 研究问题与一句话答案

**问题**：如果工程上只需要 \(x_{0.95}\)，先估计完整三参数 Weibull、再推导该分位点（P 路线），与直接以该分位点为训练目标（D 路线）——是否产生目标精度差异？

**一句话答案（修正后）**：**在正确评估下（P 施加其训练输入 scaler），D 相对 P 无精度优势**：core 上 P 不劣于 D（pooled I=−0.120，n=5–9/12 P 显著更优、无任何 n D 更优）。原报告的"D 更优、目标对齐收益"结论是 P 预处理伪影。D 仅在**训练支持外**（stress 低 β/loc、NIST 真实数据）有轻微条件优势，且两者在真实数据上均 anti-conservative。**论文主线从"直接分位点学习的收益"改为"完整参数保留 P 不付 x0.95 精度代价；直接分位点学习无 core 内收益"。**

## Claim 1（修正）：core 上 D 无相对 P 的精度优势

- **Claim**：core 5-n equal-per-n pooled I=−0.120（P 更好，paired hierarchical bootstrap 95% CI [−0.129, −0.049]）；P 在 n=5–9、12 显著更优（BH），无任何 n D 更优。原 I=0.3926 是 raw-P 伪影。
- **Evidence**：`BINC-20260802-02/b4_correction` 与 `analysis_summary.json`；n5 P RMSE 0.403（=Controller 复核 0.402965）vs D 0.508。
- **Reasoning**：P 模型在标准化 sorted-z 上训练；B4 未施加该 scaler 导致 P 被严重低估。施加后 P 的参数误差不灾难（n=5 γ/η 反事实 0.457/0.148 vs 原 2.445/1.719）。
- **Alternative/Boundary**：core 内成立；不扩展到删失/截断/多分位点；D 在域外有部分优势（见 Claim 4）。

## Claim 2（修正）：低 β 是 P 优势所在，高 β 持平

- **Claim**：参数网格上，所有 n 的低 β（重尾）区域 P 显著更好，高 β 无差异；无 D 更好区域。
- **Evidence**：grid stratum-pooled β 边际（n=15 β0.9 I=−1.11 → β4.4 I≈+0.03）。
- **Reasoning**：P 保留完整参数结构，低 β 时对形状参数 β 的估计更稳；D 的标量目标编码在该区域无优势。
- **Alternative**：机制（表示/目标编码）是候选，未消融。

## Claim 3（修正）：P 的完整参数输出是功能价值，且不付 core 精度代价

- **Claim**：P 输出完整合法 β/η/γ（100% 合法、0 γ 违规），且在正确输入下不因保留参数化而在 core 上付 x0.95 精度代价。
- **Evidence**：P core RMSE 0.2709 ≤ D 0.3034（equal-per-n）。
- **Reasoning**：原"P 为参数化付出 39% RMSE"失效；修正后 P 反而略优。

## Claim 4（修正，描述性）：D 的优势仅在训练支持外/真实数据上数值出现

- **Claim（描述性，无 CI/BH）**：stress low（β 0.6–1.2）n5–10、loc（ρ −0.5–2）上 D RMSE 数值更低；NIST 真实数据 D pinball 数值略优；两者 exceedance 均 <0.95（anti-conservative）。**这是数值/描述性观察，不构成"显著支持"；目标对齐机制属候选假设，未识别。**
- **Evidence**：`B5_correction`（stress/contamination/conformal/NIST 修正，frozen-identity 校验通过）；NIST n5 P pinball 50.7 vs D 48.5。
- **Reasoning**：域外（训练支持外）P 泛化受限，D 的端到端目标在部分域外数值上更低；但不构成 core 内主张。

## 可主张 / 不可主张（修正后）

**可主张**：
1. core 上 P 不劣于 D（pooled I=−0.120）；直接分位点学习在训练支持内无精度收益。
2. P 提供完整合法 β/η/γ 且不付 core x0.95 精度代价。
3. 低 β 区域 P 显著更优。
4. D 在训练支持外（stress low/loc、NIST）数值上有部分条件优势（描述性，非显著性支持）。
5. 传统方法 MDM/LRE 在 core 上是更强基线；core conformal 覆盖近标称。

**不可主张**：
1. D 相对 P 在 core 更优（伪影）。
2. "目标对齐收益"（旧 P 0.6943 vs Dctrl 0.3296）——旧比较无效，未识别。
3. "P 的 n=5 参数灾难"（伪影）。
4. D 全域可用/更优；stress 覆盖提供 OOD 保证；NIST 证明跨材料普适性。
