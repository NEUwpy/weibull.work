## 研究问题与一句话答案

**问题**：如果工程上只需要可靠度 95% 的寿命 \(x_{0.95}\)，先估计完整三参数 Weibull 分布、再推导该分位点，与直接以该分位点为训练目标学习——这两种路线是否产生目标精度差异？如果产生，差异在哪些条件下出现、以何种信息代价，机制证据到什么强度？

**一句话答案**：是的，存在目标精度差异。**core 五个 n 的 equal-per-n pooled 结果支持 D 相对 P 更优**（I=0.3926 [0.3444,0.4347]，supported and material）；**异质性分析显示只有 n=5/15/20 的 per-n 推断支持 D、n=7/10 未确认差异**。收益的证据指向训练目标与工程目标对齐、绕过 P 在小样本下严重的 η/γ 参数不稳定；但该优势**分层且非全域**——n=7/10 无确认差异、core 上 MDM/LRE 仍更强、压力层 D 可用率下降——因此 D 只能被称为"相对 P 更优的 NN 路线"，不是普遍最优估计器，也不是默认总体首选。

**口径提示**：I=0.3926 是 **core 五个 n 的 equal-per-n pooled** 效应，不是只在"支持分层"上计算的 39%；每条 per-n 层有自己的 CI/verdict，不为 pooled CI 单独背书（见 Claim 1）。

## Claim 1：core pooled 支持 D 相对 P 更优；异质性分析显示支持集中在 n=5/15/20

**Claim**：在 core 参数域、6,400 个配对数据集上，五个 n 等权的 pooled 改善率 I=0.3926（95% CI [0.3444,0.4347]，supported and material）；per-n 推断只在 n=5/15/20 支持 D、n=7/10 无确认差异。

**Evidence**（[B 正式报告](05-B-正式实验报告.md) B1/B2；[B 证据索引](04-B-证据索引.md)；[C2–C4 机制报告](07-C-机制分析与补充证据.md) C2-1）：
- pooled I=0.3926 [0.3444,0.4347]（equal-per-n）；per-n I 与各自的 BH verdict：n5 0.6506 **supported**、n7 −0.0035 **not significant**、n10 −0.0409 **not significant**、n15 0.0564 **supported**、n20 0.1721 **supported**。
- 对应 per-n RMSE（P/D）：n5 1.455/0.508、n7 0.380/0.382、n10 0.260/0.271、n15 0.201/0.189、n20 0.202/0.167。

**Reasoning**：pooled 效应与分层形态分开陈述：pooled 支持总体差异存在；分层显示该差异在 n 上不均匀。二者都是证据，但**不能**用 pooled CI 为"支持分层"单独背书——每层引用自己的 CI/verdict。

**Alternative explanations**：n=7/10 的无差异可能是局部参数区方向混合的平均抵消，也可能只是精度不足；两者与数据一致，尚未完全区分（见 Claim 3）。

**Boundary**：本主张只在 core 域成立；不扩展到任意分位点、删失/截断或多目标联合训练。**core D 可用率 100%**，因此 pooled I 不受 D 有效行选择夸大（[C3-1](07-C-机制分析与补充证据.md)）。

## Claim 2：n=5 的相对差距主要由 P 的大负偏、尾部和 seed 不稳定构成

**Claim**：n=5 时 D 相对 P 的差距（I=0.651）主要由 P 对 \(x_{0.95}\) 的大负偏（signed relative bias −0.916）与尾部/离散（SD 1.13、q90 2.03）构成；P 的参数估计在 n=5 极不稳定（归一化 seed spread 0.209）。**这描述差距的构成，不推断 D 没有自身的误差机制。**

**Evidence**（[C2–C4 机制报告](07-C-机制分析与补充证据.md) C2-1/C2-2）：
- n=5：P bias −0.916、SD 1.131、RMSE 1.455、q90 2.034；D bias −0.137、SD 0.490、RMSE 0.508。
- P 归一化 seed spread（SD/true_x095）=0.209（D 0.013），P spread–误差 Spearman 0.778。
- 相对反事实（n=5）：只换 γ 的绝对相对贡献 2.44、只换 η 为 1.72；组合 signed −0.916、abs 0.949；非加性 0.642。

**Reasoning**：n=5 时 P 的 γ/η 单参数误差在 \(x_{0.95}\) 上产生巨大且方向相反的贡献（η 高估推高、γ 低估压低），部分抵消后净误差仍为 −0.916。D 不经过中间参数表示，因此不受该不稳定主导。雅可比在 n=5 强非线性下不可靠（残差 0.664≈组合误差），以精确反事实为准。

**Alternative explanations**：反事实依赖替换基准（真参数为基准）；目标编码/任务复杂度差异（D 单标量 vs P 三维参数）可能部分解释，但 Dctrl 已控制 backbone（输出维度与损失属于 treatment package 本身，见 Claim 5）。

**Boundary**：这是 P 参数误差到目标误差的**传播路径**描述，不是 β/η/γ 三者对 P 误差的独立因果份额（误差高度相关，无法从反事实推出独立因果贡献）。

## Claim 3：n=7/10 无确认差异 = bias/dispersion 接近与参数区方向混合；候选机制仅是与数据一致的解释

**Claim**：n=7/10 时 P 的 bias 与 dispersion 收缩到与 D 几乎重合，paired D-better 比例≈0.53/0.52、cluster 级 I 中位仅 0.021/0.032；这是"证据不足以确认差异"，**不是"确认无差异/等效"**。

**Evidence**（[C2–C4 机制报告](07-C-机制分析与补充证据.md) C2-1）：
- n=7 P bias −0.063/SD 0.375 vs D bias −0.050/SD 0.379；n=10 P −0.013/0.260 vs D −0.021/0.270。
- β 分层：n=10 q0 I=−0.117 与 q3 I=+0.049 方向相反 → 参数区方向混合的证据。
- cluster 级 I 的 IQR：n=7 [0.002,0.046]（全为正但极小）、n=10 [−0.048,0.061]（跨 0）。

**Reasoning**：**已确认的事实**是 bias/dispersion 接近与参数区方向混合。"参数瓶颈收缩后 D 优势被抵消"是**与数据一致的解释**，不是已证明的过程；不得把候选机制写成确定因果。

**Alternative explanations**：a) 局部参数区混合（q0 vs q3 方向相反）；b) 仅精度不足。两者不互斥，当前数据不足以完全区分。

**Boundary**：n=7/10 上**不按精度强行排 D/P**；选择应由信息需求与风险决定（见 Claim 7）。cluster I 的 IQR 是描述性区间，不是置信区间，不当作显著性证据。

## Claim 4：n=15/20 的 D 再胜伴随 P 的偏正漂移与 observed RMSE plateau

**Claim**：n=15/20 时 D 再次优于 P，伴随 P 的 signed relative bias 转正（+0.042/+0.079）而 D 保持在 −0.01 附近，且 D 的 dispersion 略小（n20 SD 0.167 vs 0.186）。

**Evidence**（[C2–C4 机制报告](07-C-机制分析与补充证据.md) C2-1）：
- n=15：P bias +0.042、D −0.023，cluster-RMSE D-better 47/64、cluster I 中位 0.051；n=20：P bias +0.079、D −0.010，cluster-RMSE D-better 59/64、cluster I 中位 0.151。
- P 的 per-n RMSE：n15 0.201、n20 0.202 → **observed RMSE plateau**（n15≈n20），仅作描述，**无 plateau 显著性检验**。

**Reasoning**：随着 n 增大，P 的 \(x_{0.95}\) 偏正漂移（高估）持续，而 D 直接最小化目标误差、bias 保持在零附近。P 在 n15/n20 出现 observed RMSE plateau，但这是描述性观察，**不得写"不再显著下降"**。

**Alternative explanations**：这是与数据一致的**经验机制**，不是唯一因果来源；β 分层不呈单调高-β 趋势（n20 q0 I=0.270 最高），故不预设单调机制。

**Boundary**：n=15/20 的收益幅度远小于 n=5（cluster I 中位 0.05–0.15 vs 0.61），是中等效应；不可据此宣称 D 在全部 core 域"整体最优"（见 Claim 6）。

## Claim 5：P vs Dctrl vs D 提供 direct-target treatment package 的方向性受控归因

**Claim**：在**相同骨干 m12**上，参数路线 P（RMSE 0.6943）与 direct-target treatment package 的 Dctrl（0.3296）相差约 52%；选中的更小 D 架构 [64,32]（0.3290）与 Dctrl 几乎相同。收益随训练目标改变而出现、不随骨干缩减而消失。

**Evidence**（[B 正式报告](05-B-正式实验报告.md) B3；[C2–C4 机制报告](07-C-机制分析与补充证据.md) C2-3）：
- P 0.6943 / Dctrl 0.3296 / D 0.3290（与 B4 per_route 完全一致）。
- Dctrl seed RMSE 范围 [0.3255,0.3321]，P seed 范围 [0.5371,0.8387]；worst Dctrl seed < best P seed。

**Reasoning**：Dctrl 与 P 共用 m12 骨干，**骨干被控制**；输出维度与损失属于 **direct-target treatment package** 的一部分。收益随该 package 出现、不随骨干缩减消失，故目标对齐是主效应。**不声称从当前设计拆出了独立的纯 loss 因果份额。**

**Alternative explanations**：Dctrl 仅 5 seeds vs P/D 10 seeds，存在 seed 不对称；输出维度与损失属于 treatment package，无法在当前设计内单独拆解。但 Dctrl 的 5 个 seed RMSE 极窄且全部低于 P 任一 seed，方向对 seed 重采样稳健。

**Boundary**：这是 **direct-target treatment package 的方向性受控证据**，不是完美单因子因果识别；只覆盖 m12 骨干与 core 域。

## Claim 6：availability、stress、MLE shared-valid、conformal 与传统方法共同限定整体结论

**Claim**：整体结论是一组强边界约束的集合：core 上 D 的收益不被可用率夸大，但 D 不是总体精度最优；stress 上 D 的条件精度与可用率分离；MLE shared-valid 选择较易子集；区间证据只在 core 域有效；传统方法是不可忽视的更强基线。

**Evidence**（[C2–C4 机制报告](07-C-机制分析与补充证据.md) C3-1/C3-2/C4；[B 正式报告](05-B-正式实验报告.md) B4/B6/B7）：
- **core availability**：core D 可用率 100%（6,400 行 0 失败）→ pooled I 不受 D 有效行选择夸大。
- **stress 逐 cell（B5-v6 BH 权威，主证据为 common-valid RMSE）**：
  - D supported + avail risk：low n5、loc n5；
  - D supported + avail ok：low n20、high 全部 n、loc n20；
  - **P better**：low n10（BH-supported）；
  - no confirmed difference：low n7/n15、loc n7/n10/n15（含 loc n15 未校正方向为 D better 但 BH 不显著）。
  - `0.90` 是工程分类阈值，非自然/统计断点。
- **route-valid vs common-valid**：分母不同（各自有效行），route-valid 只作为不同分母的选择诊断，不可与 common-valid 直接横比。
- **MLE shared-valid**：MLE 失败率 n5 51.5%→n20 10.6%，集中于低 β/低 η；MLE-valid 子集对 D/P/MDM/LRE 都是更易行（n5 D RMSE MLE-valid 0.386 vs MLE-invalid 0.602）。
- **传统基线**：core 上 MDM、LRE 在 shared-valid 行更优（D−MDM +0.0438、D−LRE +0.0723），D 仅对 MLE 无差异。
- **conformal**：core 90/95 覆盖近标称；stress 覆盖只诊断失效、不提供 OOD 保证。

**Reasoning**：每一个边界都必须与核心主张同时陈述：D 是相对 P 更优的 NN 路线，但面对生产级传统方法不是默认首选；D 的条件精度优势在压力层以可用率为代价；shared-valid 比较选择的是 MLE 可行区域。

**Alternative explanations / 边界**：NIST 单材料与污染结果不能替代已知真值的跨材料精度验证；stress 摘要按 BH 方向解读（low n10 P better），这是对 B 摘要的解释修正，不改写 B 原始行级证据。

## Claim 7：信息取舍与条件选择规则

**Claim**：D 不提供完整参数及其合法性/支持集诊断，并在 stress 有自身的 availability 风险；P 保留完整 β/η/γ 与 100% 合法诊断。选择规则是非万能排名。

**Evidence**（[B 正式报告](05-B-正式实验报告.md) B5；[C2–C4 机制报告](07-C-机制分析与补充证据.md) C4）：
- P 提供完整 β/η/γ；其 RMSE 为**归一化**误差（β、η 为相对误差，γ 以 η 归一），不是原始单位直接可比（β 0.325、η 2.466、γ/η 0.880）；合法率 100%、γ 支持集违规 0。
- n=5 的 P 参数误差较大（η 相对 RMSE 5.136、γ/η 1.863），**限制基于这些参数做精细下游推断**；合法输出 ≠ 参数准确。

**Reasoning**：
- 只需 x0.95：core 支持分层上 D 是相对 P 更优的 NN 路线；但 MDM/LRE 更强，D 非默认总体首选。
- 需要完整 β/η/γ：P 有功能价值；小样本下 P 的参数误差较大。
- n=7/10 无确认差异：由信息需求与风险决定，不按精度强行排 D/P。
- stress-low/loc：**仅 BH 支持且方向为 D better 的 cell**（low n5、loc n5）有 D 的条件精度支持但可用率是部署风险；low n10 是 P better、low n7/n15 与 loc n7/n10/n15 为 no-confirmed，不泛化到整域；high 域全部 cell 支持且可用。
- 区间证据：core conformal 是域内风险提示；stress 无 OOD 保证。

**Alternative explanations / 边界**：完整参数的下游需求是任务定义边界，C 不用本项目数据证明实际消费需求；目标编码隐式先验、任意架构稳健性只作 limitation 或 C 外扩展项，不通过新增实验处理。

## 已确认事实 / 机制支持的解释 / 不可识别的限制

**已确认事实（可直接引用）**：
- core equal-per-n pooled I=0.3926 [0.3444,0.4347]（supported and material）；per-n 支持仅 n=5/15/20。
- n=5 P bias −0.916、归一化 seed spread 0.209、反事实 η/γ 相对贡献 1.72/2.44。
- 相同骨干 m12 P 0.6943 vs Dctrl 0.3296；Dctrl seed [0.326,0.332] 全部低于 P 任一 seed [0.537,0.839]。
- core D 可用率 100%；low n10 BH-supported **P better**；loc n15 BH 不显著。
- MLE 失败率与 shared-valid 选择较易子集。

**机制支持、与数据一致但未证实的解释**：
- n=7/10 无差异 = "bias/dispersion 接近 + 参数区混合 + 精度不足"的组合（各分量未完全区分）。
- n=15/20 再胜 = P 偏正漂移 + observed RMSE plateau + D 较小离散（经验机制，非唯一因果来源）。
- D 收益机制 = direct-target treatment package 绕过中间参数不稳定（方向性归因成立，非纯 loss 因果份额）。

**不可识别的限制**：
- MLE 在失败行的精度（不可补未知精度）。
- β/η/γ 对 P 误差的独立因果份额（误差高度相关）。
- 目标编码隐式先验、任意架构/损失稳健性、完整参数的实际下游消费需求。

## 论文可主张 / 不可主张清单

**可主张**：
1. **core 五个 n 的 equal-per-n pooled 结果支持 D 相对 P 更优**（I=0.3926 [0.3444,0.4347]）；异质性分析显示支持集中在 n=5/15/20。
2. 收益主要来自 direct-target treatment package（训练目标与工程目标对齐）；相同骨干 m12 上 P vs Dctrl 相差约 52% RMSE，方向对 seed 稳健。
3. P 保留完整合法 β/η/γ 输出（100% 合法、0 支持违规），是 D 不提供的功能收益；但小样本参数误差较大。
4. core 上 split-conformal 90/95 区间是有效的域内风险提示。
5. 收益分层且非全域：n=7/10 无确认差异；stress 条件精度支持但可用率是部署风险（low n5、loc n5）；core 上 MDM/LRE 仍是更强传统基线。

**不可主张**：
1. D 是总体精度最优估计器（core 上 MDM/LRE 更优）。
2. D 在全部压力层可用（low n5 可用率 58%）。
3. n=7/10 无差异 = 等效（≠ 等价）。
4. 单一 NIST 材料证明跨材料普适性（无已知真值）。
5. stress 覆盖提供 OOD 保证。
6. D 能输出 β/η/γ 或非目标分位点。
7. 从 \(x_{0.95}\) 结论推断任意分位点成立。
