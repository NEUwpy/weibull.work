## 1. 科学合同（P–Q 控制变量）

### 1.1 输出网络与合法化（v2 修正）

- 输入：升序排序原始样本 \(X_n\)，经仅训练折拟合的逐位置 StandardScaler 标准化。
- 网络：`MLP(n → 256 ReLU → 128 ReLU → 64 ReLU → 3)`，float64。
- **合法化（location-scale decode，参考 `study02a/representations.decode_targets`）**：
  \[
  \hat\beta=\mathrm{softplus}(o_1)+\varepsilon,\quad
  \hat\eta=\mathrm{softplus}(o_2)+\varepsilon,\quad
  \hat\gamma=\min(X)-\eta\,(\exp(o_3)+\delta),\quad
  \varepsilon=10^{-6},\ \delta=10^{-7}
  \]
  - `min(X)` 为逐样本最小值（location 锚点，常量，无梯度）；η = 设计固定 scale = 1000。
  - **结构性保证** \(\hat\gamma<\min(X)\)：gap = η(exp(o₃)+δ) ≥ ηδ = 1e-4 > min(X) 的 ulp，
    即使 o₃→−∞ 也严格成立（非事后 clipping）。
  - 固定 scale 而非模型自身 η̂，避免 η̂ 快速增长把 o₃ 拖入 exp 死区（v2 经验性验证）。
- 初始化：`torch.manual_seed(seed)` 后默认 Kaiming 构建。

### 1.2 P 损失（参数精度；v2 修正 γ 项）

\[
L_P
=
\operatorname{mean}_i
\left[
\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2
+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2
+
\left(\log\frac{\min(X)_i-\hat\gamma_i}{\min(X)_i-\gamma_i}\right)^2
\right]
\]

γ 项为**平方 log-gap 误差**（带支撑约束位置参数的自然相对误差尺度）。v2 修正原因：v1 的
相对 γ 误差在 γ̂→min(X)（exp 死区）处梯度消失，模型会塌缩到 γ̂=min(X) 并卡住；log-gap
误差在该区域梯度非零且损失极大，消除塌缩陷阱（见 §11 v1→v2 差异）。

### 1.3 Q 损失（目标分位点；与 v1 相同）

\[
L_Q=\operatorname{mean}_i\left[\left(\frac{\hat{x}_{0.95,i}-x_{0.95,i}}{x_{0.95,i}}\right)^2\right],
\qquad
\hat{x}_{0.95,i}=\hat\gamma_i+\hat\eta_i[-\ln(0.95)]^{1/\hat\beta_i}
\]

梯度经 Weibull 公式（含 softplus + location-scale 合法化）传播到三个输出。

### 1.4 控制变量（P/Q 配对，与 v1 相同）

batch 顺序、网络结构 SHA 全部一致；唯一预期差异为 loss route（`pairing_report.csv`）。

## 6. 正式评价与统计推断（v2 修正）

### 6.1 主指标

held-out \(x_{0.95}\) 相对 RMSE；P/Q 配对差值（逐样本 `rel_sq_Q − rel_sq_P`）；
相对改善比例。报告每 n、seed、fold、三 seed 合并。等权，失败项保留计数。

### 6.2 推断层级（Codex R1 REVISE 修正）

- **主推断（设计单元 × seed 聚类）**：先对每个 `(n, fold, seed)` 模型在它自己的 2,400
  held-out 配对样本上求模型级差值 \(d_{n,f,s}=\mathrm{mean}(rel\_sq_Q-rel\_sq_P)\)；
  再按 n 分层、对 fold 有放回重采样、**seed 块内保持**（同一 fold 的三个 seed 不拆开，
  因共享测试数据），得到 pooled 效应与 95% CI。设计单元数 = 20（4 n × 5 fold）。
- **次要（固定模型逐样本 MC）**：cell 内逐样本 bootstrap 只在固定模型条件下给 Monte Carlo
  区间，不作主推断。
- **不再报告**未经多重校正的 60-cell “显著数量”。
- 报告：effect size（pooled 差值 + 相对改善）、按 n 分层方向、seed 变异（3 seed 太少，
  只作描述）、3-seed 限制。
