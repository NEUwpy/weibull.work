## 当前结论

在 Study01 冻结参数网格、相同三输出网络和相同训练配置下，只改变训练与验证损失：

- `P_equal`：优化三个归一化参数误差的等系数和；
- `Q_param`：直接优化目标可靠度寿命点 \(x_{R=0.95}\) 的相对误差。

10-seed 主实验共 200 个 P/Q 配对模型单元（400 fits）：

- P rRMSE = 0.166059；
- Q rRMSE = 0.161075；
- 绝对降低 0.004983，相对改善 3.001%；
- 95% 设计级经验 bootstrap 区间 [2.195%, 3.793%]；
- 10/10 seed 的 pooled 方向均有利于 Q，184/200 个模型单元有利于 Q。

这支持的是：**对当前冻结的 `P_equal` 参照，直接训练明确目标可以让该目标的均方误差平均降低，
并通过目标敏感度几何避免人工固定一组全域参数权重。**

3% 不是全面精度改善。探索性工程审计显示：Q 的 MAE 略差，但寿命高估 >10% 从 14.47% 降至
13.21%，高估 >20% 从 6.90% 降至 6.01%，cell-wise CVaR90 改善 4.61%；代价是
寿命低估 >10% 从 25.40% 增至 28.70%。当 \(x_{0.95}\) 被用作保证寿命阈值时，这提示 Q 的
潜在应用价值是**减少高估与极端尾部，同时接受更多低估**。Q 本身没有显式优化非对称
风险；它不表示 Q 在每个参数区域都赢，也不表示 Q 的三个内部参数估计更准。

## “Q 自动传梯度”是什么

简单说，梯度就是：**要让损失下降，每个参数应往哪个方向改、改动信号有多强。**

Q 的计算链是：

```text
样本 → 神经网络 → β̂,η̂,γ̂ → x̂R → Q 损失
```

反向传播时，链式求导会自动计算“\(β,η,γ\) 分别变一点，\(x_R\) 会变多少”。对 \(x_R\) 影响大的方向
得到更强的目标信号，影响小的方向得到更弱的信号；不同参数方向还可以按它们对同一目标的共同作用
发生补偿。这不是人工先定一组参数权重，也不是网络额外学了三个“神秘权重”，而是 \(x_R\) 公式和
链式求导在当前预测位置自然产生的局部几何。

更完整、带例子的说明见 [`docs/研究说明.md`](docs/研究说明.md)。
