# Study02：任务对齐的收益、参数代价与修复

当最终关心可靠度寿命点时，直接优化该点能改善多少误差，又会付出什么参数恢复和跨寿命点代价？当前以三参数 Weibull 的 $x_{0.95}$ 为例，按 P → Q → QCP 展开，并以简单固定加权 QP 和协议25补充检验修复的必要性。

当前中英文正文、附录均为 v2.7.0。固定尺度160个真值单元、48,000组样本、10个训练种子形成200个配对模型单元。Q相对P的目标RMSRE改善2.07%，同时引起另外两点退化；QP与QCP均修复跨点误差，二者精度差异没有明确证据。共同验证下Q仍有1.322%目标改善。现有资料足以支持有界机制研究；下一步先明确参数解释与寿命决策的使用要求，再决定是否需要一次冻结后的新样本确认。
