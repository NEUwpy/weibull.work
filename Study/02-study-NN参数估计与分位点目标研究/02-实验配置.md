## 共用数据、网络与评价

| 项目 | 配置与来源 |
|---|---|
| 真参数 | β=1.5、2、2.5、3、3.5、4、4.5、5；η=1000；γ/η=0.10、0.25、0.50、0.75、1.00 |
| 样本 | n=7、10、15、20；每真值单元300次，合计48,000组独立未删失样本 |
| 划分 | repeat_id mod 5：测试一类、验证下一类、训练其余三类；每组合180/60/60；训练折重叠 |

| 网络 | 各n独立MLP：n–256–128–64–3，ReLU、float64；正β/η、0<γ̂<min(X)合法解码 |
| 优化 | Adam，lr=0.001，weight_decay=0.0001，batch=256；共享初始化、数据、scaler、首轮batch顺序 |
| 两套预算 | 当前共同预算600 epochs/patience 60；早期P参考及C/D探索300/20，不混池 |
| P | 三项归一化参数平方误差求和再平均；β误差除β，η/γ误差除η；训练、选点、早停按LP |
| Q | 目标x0.95相对平方误差均值LQ；训练、选点、早停按LQ |

| 区间 | 按n分层重采样fold并交叉重采样全局seed，路线配对，通常200,000次；种子及具体规则以各输出manifest/代码为准 |

## S02-02 参数补偿与QCP修复

对应[正文3.2](manuscript/Study02论文初稿-v2.7.0.md#main-3-2)、方法2.3—2.4、图1—2；附录A、B.1、C.1—C.2。

- [筛选配置](configs/qcp-constrained-pilot-v1.json)：8个验证单元、48次训练选择c和ρ；[资源配置](configs/qcp-constrained-resource-v1.json)：另8次训练检查预算。对应[筛选](code/study02pq/constrained_pilot.py)、[资源](code/study02pq/constrained_resource.py)入口，原验证摘要保留。
- [冻结QCP配置](configs/qcp-constrained-confirm-v1.json)：c=1.5、ρ=0.1、600/60；阈值为匹配早期300/20 P的最佳验证LP×1.5。该配置中的早期比较对象不能代替S02-01的共同预算对象。
- [训练入口](code/study02pq/constrained_confirm.py)：小批量增广拉格朗日、非负乘子每轮更新；验证平均LP满足阈值后选最低验证LQ。保留[200份预测及元数据](artifacts/qcp_constrained_confirm/)。阈值依赖[前三seed早期P](artifacts/pq_iid_main/fit_metadata/)和[其余七seed早期P](artifacts/pq_s5b_revision/grid_extra/fit_metadata/)。
- [精确贡献分解](manuscript/tools/figures_v260.py)及[当前派生](manuscript/tools/figures_v270.py)把同一预测的目标误差分成β、η、γ三项，不用跨样本正负抵消替代逐预测补偿。

QCP目标RMSRE=15.841%，200/200选中checkpoint满足验证平均约束；分解残差1.33×10⁻¹⁵，补偿指数P/Q/QCP约0.332/0.915/0.345。原确认时序保留在附录A.2；共同预算后的QP差异接近零，见S02-05。几何在输出误差空间成立；这些终态结果不能单独识别训练目标、选点和优化动态的因果贡献。

## S02-05 QP、共同验证与替代修复

对应[正文3.5](manuscript/Study02论文初稿-v2.7.0.md#main-3-5)、附录B.9/F、表B10/F1/F2。

| 路线 | 训练/选点/早停 | 来源与规模 |
|---|---|---|
| QP | LQ+LP，权重1.0；验证LQ | [早期筛选配置](归档/旧实验/固定加权路线/configs/pq-regularized-pilot-v1.json)，S02-01共同预算200模型 |
| P_QSELECT | LP训练，验证LQ选点及早停 | 协议25，200条新训练轨迹 |
| Q重跑/Q_FEAS | 原LQ训练和早停，旁路记录同轨迹内LP≤原QCP阈值的最低验证LQ | 200条Q轨迹；Q_FEAS不是另200条训练，不可行不回退 |
| QMULTI | 三点等权平均相对平方误差，按同损失训练/选点/早停 | 200条新训练轨迹；三个点均被直接监督 |

[原协议25](protocols/25-投稿修订补充对照.md)、[训练入口及固定常数](code/study02pq/submission_controls.py)、[共同训练器](code/study02pq/training.py)、[分析入口](code/study02pq/submission_controls_analysis.py)、[完整预测/逐轮历史/汇总](artifacts/submission_controls_v1/)。新训练共600条，数据仍为原48,000样本，600/60预算。Q重跑的200个目标指标及最佳epoch复现原Q。选中权重600份拟退出活动目录，已由清理前Git快照保全；现已按用户要求移到外部待删除目录；分析使用保留预测与逐轮历史，无需恢复权重。旧运行manifest原样保存，完整旧包验证须先恢复权重。

共同验证Q比P_QSELECT改善1.322%；原Q轨迹内Q_FEAS为0/200，最小验证LP/阈值=10.268。QMULTI缓解跨点误差，但当前等权设置的参数恢复与三点精度弱于QP/QCP。QCP相对QP目标改善0.0623%，经验区间跨0；[QP三点复算](manuscript/tools/qp_comparison_v270.py)及[结果](artifacts/qp_comparison_v270/)保留。

共同验证仍允许训练更新与实际停止轮次不同；0/200只限原Q早停轨迹。协议在旧结果已知后确定，不宣称新数据独立确认。
