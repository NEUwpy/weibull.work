这里的 protocol 指研究方案，不是网络协议。它说明研究问题、数据与划分、训练设置、评价指标，以及哪些分析是在看结果之后追加的。文件名中的“合同”是既有内部叫法，不是法律合同。

阅读当前论文时先看 18、22、23、24；09 说明基础数据拆分，16 记录 QCP 正式确认。其余文件保存训练开发、机制分析或旧研究域的方案，不代表还有一批实验等着做。文件名和路径暂时保留，避免影响配置引用及冻结记录。

## 新研究准入规则

新问题不得改写已冻结方案；确需新方案时使用未占用编号，不与既有文件重名，并按以下状态推进：

```text
DRAFT → USER APPROVED / FROZEN → RUNNING → COMPLETE / NOT PAPER EVIDENCE → USER ADMITTED
```

实验完成和论文准入必须分开提交。新结果默认 `EXCLUDED`；只有用户查看独立结果报告并明确批准后，
才允许修改论文正文、补充材料、论文图和证据白名单。
