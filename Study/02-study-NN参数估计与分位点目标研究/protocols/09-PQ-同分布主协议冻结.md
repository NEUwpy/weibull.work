## 1. 研究问题（RQ，冻结）

> 在冻结设计域内，当训练与测试覆盖相同的 \((\beta,\gamma,n)\) 参数组合、但使用相互独立的
> 重复样本时，以目标可靠度寿命点 \(x_{0.95}\) 的相对误差训练的三参数 Weibull 网络（Q）
> 是否比以三参数精度误差训练的网络（P）得到更准确的 \(x_{0.95}\)？准确到多少（效应量）、
> 跨 n/参数区域/种子是否稳定（不确定性）、由什么机制实现（见 M2）？
> \(x_{0.95}\) 是可靠度寿命点（定义见 §1.1），**不是**通常的 CDF 分位点。

论文预注册式方向假设：Q 在同分布目标任务上更优；正式结论必须由效应量、不确定性、
机制证据与边界实验共同支持，不得写成“由定义必然更优”。

### 1.1 \(x_p\) 的定义（可靠度寿命点，全文档统一用语）

本文的 \(x_p\) 是**可靠度寿命点**（100p% 可靠寿命）：满足可靠度/生存函数
\[
R(x_p)=P(X>x_p)=\exp\left[-\left(\frac{x_p-\gamma}{\eta}\right)^{\beta}\right]=p
\]
的寿命值，等价于 CDF 的 \(1-p\) 分位点。它**不是**通常的 CDF \(p\)-分位点
（后者应使用 \(-\ln(1-p)\)）。公式恒为
\[
x_p=\gamma+\eta[-\ln p]^{1/\beta},\qquad p=0.95.
\]
M3 的多分位点水平 \(0.90,0.95,0.99\) 因此是**可靠度水平**（生存概率），不是 CDF 概率。
P/Q 损失与所有评价指标都以该 \(x_p\) 定义为准；本协议不改公式、不改变既有科学目标。

合法化（domain-explicit 共享解码器，同 r4）：\(\hat\beta=\mathrm{softplus}(o_1)+\varepsilon\)、
\(\hat\eta=\mathrm{softplus}(o_2)+\varepsilon\)、
\(\hat\gamma=\min(X)\,\big(\delta+(1-2\delta)\,\mathrm{sigmoid}(o_3)\big)\)，
\(\delta=10^{-7}\)，结构性严格 \(0<\hat\gamma<\min(X)\)（依赖冻结正位置域
\(\gamma\in[100,1000]\)，所有样本 \(\min(X)>\gamma\)；不声称负位置问题成立）。

P 损失（direct，同 r4 approved 形式）：
\[
L_P=\operatorname{mean}_i\left[
\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2+
\left(\frac{\hat\gamma_i-\gamma_i}{\eta_i}\right)^2\right]
\]

Q 损失（与正式评价一致、可微的相对平方误差；\(x_{0.95}\) 定义见 §1.1）：
\[
L_Q=\operatorname{mean}_i\left[
\left(\frac{\hat{x}_{0.95,i}-x_{0.95,i}}{x_{0.95,i}}\right)^2\right],\quad
\hat{x}_{0.95,i}=\hat\gamma_i+\hat\eta_i[-\ln(0.95)]^{1/\hat\beta_i}
\]
梯度经 Weibull 公式（含合法化）传播到三个输出。

## 3. Estimand（新增，冻结）

### 3.1 记号

- 单元 cell \(c=(\beta,\gamma,n)\)；cell 的重复层分布 \(P_c\)（同组合的独立新重复样本）。
- 模型 \(M_{n,f,s,r}\)：固定训练协议下，由 fold-\(f\) 训练重复与训练种子 \(s\) 确定的
  route-\(r\) 网络（确定性）。对某 held-out 样本 \(X\) 给 \(\hat{x}_{n,f,s,r}(X)\)。
- fold 定义见 §4；train/val/test 拆分与 seed、route 无关。

### 3.2 cell 误差与模型级配对差值

对 fold \(f\) 内 cell \(c\) 的 60 个 test repeats 定义经验误差：
\[
\hat\theta_r(c,f,s)
=\frac{1}{60}\sum_{t\in\mathrm{test}(c,f)}
\left(\frac{\hat{x}_{n(c),f,s,r}(X_{c,t})-x_{0.95}(c)}{x_{0.95}(c)}\right)^2
\]

模型级配对差值（主推断单元；与 `evaluate.cell_paired_diff` 一致）：
\[
d_{n,f,s}
=\frac{1}{40}\sum_{c:\,n(c)=n}\big[\hat\theta_Q(c,f,s)-\hat\theta_P(c,f,s)\big]
=\frac{1}{2400}\sum_{c:\,n(c)=n}\;\sum_{t\in\mathrm{test}(c,f)}
\Big(\mathrm{rel\_sq}_Q(c,t)-\mathrm{rel\_sq}_P(c,t)\Big)
\]
（每个 held-out 配对样本等权；负值 = Q 更优。）

### 3.3 科学 estimand 与有限估计（R1 S0-002 修订）

**科学目标（超总体式 estimand）**：冻结参数域等权；在给定 180/60/60 训练规模下，对
独立重复样本生成**与**训练随机性（权重初始化、batch 顺序、优化器轨迹，由训练种子决定）
的算法性能差：
\[
\Delta^{*}=\frac{1}{4}\sum_{n}\;\frac{1}{40}\sum_{c:\,n(c)=n}
\mathbb{E}\big[\theta_Q(c)-\theta_P(c)\big],
\]
其中 \(\theta_r(c)\) 为 route-\(r\) 网络在该 cell 上对一个**独立新鲜 held-out 重复样本**
的期望相对平方误差。\(\Delta^{*}\) 是算法/过程的性能差距，**不是**已实现 fold/seed 网格
的性质。

**有限估计（Monte Carlo / CV）**：已实现的 5 folds × 3 seeds 是 \(\Delta^{*}\) 的有限
估计——fold 是 train/test 重复拆分的有限复制，seed 是训练随机性的有限抽样。观测到的
\[
\hat\Delta=\frac{1}{4\cdot 5\cdot 3}\sum_{n,f,s} d_{n,f,s}
\]
（\(d_{n,f,s}\) 定义见 §3.2，即 60 个模型级差值、20 设计单元 × 3 seed）就是该网格上的
等权均值；每个 \(d_{n,f,s}\) 还用其 60 个 test repeats 对 \(\theta_Q-\theta_P\) 作有限样本
近似。

**加权的正确表述**：在当前完全平衡设计下（每个模型 2400 held-out、每 cell 60 repeats、
每 n 等权），\(\hat\Delta\) 与 pooled 逐样本 MSE 差的加权**相同**；rel_change（下式）与
\(\hat\Delta\) 的差别是**函数形式**（rRMSE 比值 vs rel_sq 线性差），**不是**“样本等权 vs
设计单元等权”。

描述性效应量（分母显式，与 fold-1 pilot 同式）：
\[
\mathrm{rel\_change}=\frac{\mathrm{rRMSE}_Q-\mathrm{rRMSE}_P}{\mathrm{rRMSE}_P}
\]
其中 pooled \(\mathrm{rRMSE}_r=\sqrt{\frac{1}{144000}\sum_{144000} \mathrm{rel\_sq}_r}\)
（144,000 = 60 模型 × 2400 held-out 样本，全部等权）。两者都报告并显式标注分母。

**设计级不确定性与覆盖限制**：§6 的 fold×seed 交叉 bootstrap 是对 \(\hat\Delta\) 作为
\(\Delta^{*}\) 估计的**设计级经验不确定性近似**（反映“抽到哪一组 fold/seed 实现”的变异），
**不是**超总体区间。已知覆盖限制须显式报告：(a) 训练折重叠（每个 repeat 在 5 折中约 3 折
作 train）；(b) 仅 3 seeds，seed 维度严重欠采样；(c) 单元内逐样本 MC 噪声被吸收（设计级
只重采样单元均值）。固定模型的逐样本 bootstrap 仍为条件性补充（§6 Level 2）。

### 3.4 不主张

Q 的单个参数准确、Q 对其他分位点准确、Q 恢复完整分布、Q 跨单位/跨尺度泛化。
参数误差只用于诊断（M2），不作 Q 的成功标准。

## 4. repeat-stratified 5-fold 拆分（冻结）

每个组合的 300 个 repeats 按 `repeat_id` 的余数类分配到 5 折（**与 seed、route 无关**）：

- test：`repeat_id % 5 == fold_idx`（60 repeats/cell）
- val：`repeat_id % 5 == (fold_idx+1) % 5`（60 repeats/cell）
- train：其余 3 个余数类（180 repeats/cell）

性质（实现于 `data.split_repeat_fold`，测试见 `test_pq_iid.py`）：

- 每 \((n,\mathrm{fold})\) 模型：train 7200 / val 2400 / test 2400 样本，**每折覆盖该 n 的
  全部 40 个 \((\beta,\gamma)\) 组合**（同分布保证）；
- 跨 5 折，每个 repeat 恰在某一折作为 test（test 集合互斥且并集 = 全部 repeats）；
- scaler 只在 train 行拟合（val/test 不参与）；
- 与 r4/v3 的“每 n 内按 γ/η 水平五折留出”是**两种不同拆分**，后者保留为 OOD 补充，
  二者不得混用作主推断样本。

## 5. P/Q 等价控制（冻结）

对每个 \((n, f, s)\)，P/Q 两个 fit 共享：数据行（train/val/test）、初始化
（`torch.manual_seed(s)` + `Generator(s)`）、batch 顺序、scaler、网络结构、训练预算、
early stopping 与 checkpoint 选择。唯一预期差异为 **loss route**。逐 fit 断言并记录：
`init_param_sha`、`batch_order_sha`、`network_sha`、`scaler_sha`、
`train/val/test_rows_sha` 全部一致（`pairing_report.csv` 输出 all_match）。

## 6. 统计层级与推断（冻结）

- **主推断（Level 1）**：以 60 个模型级差值 \(d_{n,f,s}\) 为单元，按 n 分层对 fold
  有放回重采样 + **全局对 seed 有放回重采样**（fold×seed 交叉，`evaluate.primary_design_bootstrap`）；
  \(\hat\Delta\)（§3.3）的 95% CI。**B=200,000**（最终报告；smoke/测试用 2,000）。
  设计单元数 20，seed 3。该区间是 **设计级经验不确定性近似**（对 \(\hat\Delta\) 作为
  \(\Delta^{*}\) 估计的抽样变异，见 §3.3），随报告须附覆盖限制：训练折重叠、仅 3 seeds、
  单元内 MC 噪声被吸收。
- **次要（Level 2）**：固定模型条件下 cell 内逐样本 bootstrap（Monte Carlo 区间），
  只作条件性补充，不作主推断。
- **报告项**：效应量（\(\hat\Delta\) + rel_change，分母显式）、按 n 分层方向、按 seed 变异
  （描述，3 seed 太少）、按参数区域（β/γ）方向、3-seed 限制、设计级覆盖限制（§3.3）。
- **不报告**未经多重校正的逐 cell “显著数量”。

**预注册决策规则**：主结论由 \(\hat\Delta\) 的 CI 是否含 0 决定方向性；方向一致性
（by-n / by-seed / by-region）只作描述性支持；CI 含 0 时记为“未能排除无差异”。

### M2 机制（复用 M1 逐样本预测，**不新增训练**）

1. 局部敏感度：\(\nabla x_{0.95}\) 在真值处的解析梯度
   \(\partial x/\partial\gamma=1\)、
   \(\partial x/\partial\eta=(-\ln p)^{1/\beta}\)、
   \(\partial x/\partial\beta=-\eta\,(-\ln p)^{1/\beta}\,\frac{\ln(-\ln p)}{\beta^2}\)
   （\(\ln(-\ln 0.95)\approx-2.970\)，故 \(\partial x/\partial\beta>0\)）。
2. 参数误差投影：对每个样本比较 P/Q 的参数误差向量在分位点梯度方向上的投影
   （explained 线性误差 \(g\cdot e\)）与实际误差；报告投影占比/相关（R²）。
3. 等分位点抵消检验：Q 是否把参数误差放在梯度方向（对齐）或放在零空间（等分位点曲面
   上的抵消）；区分“对齐改善”与“抵消改善”两种机制。
4. 区域关联：把机制量（梯度模长、投影残差）与按 (β,γ) 区域、n 的 Q 改善关联，
   区分证据支持、描述性解释与假说。
