## 1. 科学合同（P–Q 控制变量）

### 1.1 输出网络与合法化（v3/r4，Codex 合同决策）

- 输入：升序排序原始样本 \(X_n\)，经仅训练折拟合的逐位置 StandardScaler 标准化。
- 网络：`MLP(n → 256 ReLU → 128 ReLU → 64 ReLU → 3)`，float64。
- **合法化（有界 domain-explicit 共享解码器，Codex mailbox 000003 授权）**：
  \[
  \hat\beta=\mathrm{softplus}(o_1)+\varepsilon,\quad
  \hat\eta=\mathrm{softplus}(o_2)+\varepsilon,\quad
  s=\delta+(1-2\delta)\,\mathrm{sigmoid}(o_3),\quad
  \hat\gamma=\gamma_{\mathrm{lower}}+(\min(X)-\gamma_{\mathrm{lower}})\,s
  \]
  其中 \(\gamma_{\mathrm{lower}}=0.0\)，\(\delta=10^{-7}\)，故
  \(\hat\gamma=\min(X)\,s\in(\delta\min(X),(1-\delta)\min(X))\)，**结构性严格
  \(0<\hat\gamma<\min(X)\)（非事后 clipping）**。
  - 依赖冻结正位置域：真 \(\gamma\in[100,1000]\)，所有样本 \(\min(X)>\gamma\)，故每个真
    \(\gamma\) 都在 \((0,\min(X))\) 内可表示；**不声称对负位置问题成立**。
  - r4 依据：preflight 显示 direct-P + exp 解码器会塌缩（γ̂ 停在 min(X)，exp 死区）；
    Codex 决策采用此有界 domain-explicit 解码器；不采用 tanh 上界（避免排除
    \((min(X)-\gamma)/\eta>1\) 的合法真值）。
- 初始化：`torch.manual_seed(seed)` 后默认 Kaiming 构建；P/Q 完全共享，无 route 特定初始化。

### 1.2 P 损失（参数精度；r4 恢复 approved direct 形式）

\[
L_P
=
\operatorname{mean}_i
\left[
\left(\frac{\hat\beta_i-\beta_i}{\beta_i}\right)^2
+
\left(\frac{\hat\eta_i-\eta_i}{\eta_i}\right)^2
+
\left(\frac{\hat\gamma_i-\gamma_i}{\eta_i}\right)^2
\right]
\]

（\(\gamma\) 误差以 η 归一，与 Study01 J1 逐样本项同形。**不加 log-gap、辅助 γ 损失、
直通梯度或 route 特定解码器**。）

### 1.3 Q 损失（目标分位点；与 v1 相同）

\[
L_Q=\operatorname{mean}_i\left[\left(\frac{\hat{x}_{0.95,i}-x_{0.95,i}}{x_{0.95,i}}\right)^2\right],
\qquad
\hat{x}_{0.95,i}=\hat\gamma_i+\hat\eta_i[-\ln(0.95)]^{1/\hat\beta_i}
\]

梯度经 Weibull 公式（含 softplus + location-scale 合法化）传播到三个输出。

### 1.4 控制变量（P/Q 配对，与 v1 相同）

对每个 `(n, fold, seed)` 保存/验证：初始参数张量、训练/validation/held-out 行、scaler、
batch 顺序、网络结构 SHA 全部一致；唯一预期差异为 loss route（`pairing_report.csv`）。

## 6. 正式评价与统计推断（v2 修正）

### 6.1 主指标

held-out \(x_{0.95}\) 相对 RMSE；P/Q 配对差值（逐样本 `rel_sq_Q − rel_sq_P`）；
相对改善比例。报告每 n、seed、fold、三 seed 合并。等权，失败项保留计数。

### 6.2 推断层级（Codex R1 REVISE 修正）

- **主推断（设计单元 × seed 聚类；Codex R2 修正为 fold×seed 交叉）**：先对每个
  `(n, fold, seed)` 模型在它自己的 2,400 held-out 配对样本上求模型级差值
  \(d_{n,f,s}=\mathrm{mean}(rel\_sq_Q-rel\_sq_P)\)；再按 n 分层对 fold 有放回重采样，
  **同时全局对 seed 有放回重采样**（两个维度都纳入不确定性），得到 pooled 效应与 95% CI。
  设计单元数 = 20（4 n × 5 fold），seed 数 = 3。
- **次要（固定模型逐样本 MC）**：cell 内逐样本 bootstrap 只在固定模型条件下给 Monte Carlo
  区间，不作主推断。
- **不再报告**未经多重校正的 60-cell “显著数量”。
- 报告：effect size（pooled 差值 + 相对改善）、按 n 分层方向、seed 变异（3 seed 太少，
  只作描述）、3-seed 限制。
