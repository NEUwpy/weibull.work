# Study/02 主研究 B：正式实验协议

> 本文件定义怎样产生可用于 B1–B7 的证据，不记录执行进度。执行阶段见 `03-B-执行计划与状态.md`。

## 一、比较路线

| 路线 | 输入与输出 | 训练/估计规则 | 角色 |
|---|---|---|---|
| P：NN 参数路线 | 排序样本 V → β、η、γ → \(x_{0.95}\) | 复用前置研究冻结的等变锚定、变换目标标准化、Huber、m12 joint fixed-n；优先只读复用 10-seed checkpoint | 核心比较 |
| D：NN 直接路线 | 排序样本 V → \(x_{0.95}\) | 目标编码为 \((x_{0.95}-a)/s\)，其中 a 为样本最小值、s 为 IQR；再按训练集统计量标准化，解码为 \(a+s\hat y\) | 核心比较 |
| T：传统参数路线 | 样本 → β、η、γ → \(x_{0.95}\) | 项目生产实现 MDM(offset=0.1)、MLE、LRE；不在主分析中使用真实范围裁剪 | 背景基线 |

D 的锚定目标在单位缩放和平移下保持等变。实现必须用单元测试验证编码/解码往返、尺度等变和平移等变，再进入训练。

## 二、模型选择与资源公平

P 路线不重新搜索。D 路线只做一次紧凑 validation 搜索：

- 隐层：[64,32] 与 m12 [128,64,32]；
- 激活：SiLU；dropout=0.1；
- 损失：Huber 与 MSE；
- 固定 n=10、core 连续训练分布、100k 训练行、3 个 screening seed；
- 按 validation 的 \(x_{0.95}\) 相对 RMSE 选择；差异不足 1% 时选参数更少者。

搜索上限为 12 个 fit，不追加候选。入选 D 配置在五个 n 上各训练 10 个 seed。若入选配置不是 m12，再以 m12、每个 n 5 个 seed 做受控比较；所有新增 NN fit 总数不得超过 100。P 的既有 checkpoint 若缺失、哈希不符或与协议不兼容，停止并请求重新规划，不得悄悄重训后冒充复用。

主比较回答“各路线在对等且合理预算下能达到什么表现”；受控比较回答“相同骨干时训练目标是否仍造成差异”。两者不得混成一个结论。

## 三、数据角色

| 角色 | 用途 | 规则 |
|---|---|---|
| training | 拟合 P/D | 每个 n 独立生成 100k core 连续样本；不同训练 seed 可重复 |
| validation | D 配置选择、早停 | 与 training 参数点和 seed namespace 分离；可重复查看，但只用于选择 |
| calibration | conformal 阈值 | 选择冻结后生成；不得参与配置选择或主效应估计 |
| test | B1–B7 的仿真结论 | 全部配置、checkpoint、指标代码和分析代码冻结后一次性运行 |
| real holdout | 外部一致性 | 仓库冻结的 NIST 6061-T6 数据；仅评价预测损失与校准，不提供真参数 |

B 使用全新的 seed namespace，不访问、启封或消费前置研究 A 的 formal test。这里的数据隔离只靠冻结配置、测试和 manifest 记录，不新增 scheduler、authority、lease、unseal/consume、capsule 或攻击防护系统。

## 四、仿真设计

### 4.1 Core 主分析

- 参数域：β∈[1.2,4]、η∈[100,10000]、ρ=γ/η∈[0,1]；
- n={5,7,10,15,20}；
- 64 个独立 Sobol 参数簇 × 每簇 20 个样本重复 × 5 个 n，共 6,400 个配对测试数据集；
- 所有路线评估完全相同的数据集；训练 seed 与数据 seed 分层保存。

### 4.2 压力层

前三个参数压力域各使用 32 个参数簇 × 10 个重复 × 5 个 n：

- boundary-low：β∈[0.6,1.2]；
- boundary-high：β∈[4,8]；
- location-stress：ρ∈[-0.5,2]。

污染层使用 32 个 core 参数点 × 10 个重复，固定 n=20，对同一干净样本配对施加 high×3、high×10、低端 −0.5 IQR 和 10% 双侧污染。

压力层只描述边界，不参与 D 配置选择，不与 core 汇总为一个总平均。

### 4.3 真实数据

对 NIST 6061-T6 的 101 条寿命数据，在 n={5,7,10,15,20} 下各做 500 个确定性 train/holdout 拆分。主指标为 τ=0.05 的 holdout pinball loss；同时报告 holdout 寿命超过预测 \(x_{0.95}\) 的比例及其与 95% 的偏差。结果按拆分配对比较，并明确其不是“真 \(x_{0.95}\)”误差。

## 五、指标与统计分析

### 5.1 指标

复用 `python/studies/common/metrics.py` 的 \(x_R\) 公式和标准指标；如直接路线不能进入现有参数行结构，只增加薄适配器，不复制指标公式。

- 确认性主指标：core pooled \(x_{0.95}\) 相对 RMSE；
- 次指标：相对 Bias、SD、MAE；
- 风险诊断：MdAPE、P95/P99 绝对相对误差、valid/failure rate；
- P 路线诊断：β/η/γ 的 Bias、SD、RMSE、MAE，参数合法率和 γ 支持集违规；
- 不确定性：90%/95% 覆盖率、标准化区间宽度和宽度—绝对误差 Spearman；
- 真实数据：pinball loss、95% 超越率校准、有限/有效预测率。

D 的有效预测定义为有限且在当前正寿命域内大于 0；它没有 β/η/γ 合法性指标。P/T 继续使用参数合法性与样本支持约束。不同输出路线不得用不适用的合法性条件互相处罚。

### 5.2 推断

- 核心 D 对 P 比较使用配对、按参数簇聚类的 2,000 次 bootstrap；训练 seed 在第二层成对重采样；
- 报告效应点估计与 95% CI，不用单独的 p 值替代效应量；
- pooled core 是唯一确认性比较；五个 n 和各压力层是次级比较，使用 Benjamini–Hochberg FDR 标记多重比较后的支持状态；
- 每个参数域单独报告，检查聚合方向与分层方向是否冲突；
- 传统方法的失败率与有效行误差分开报告。失败率高时不得仅按存活行排序，也不使用事后挑选的惩罚常数制造单一赢家。

## 六、不确定性

两条 NN 路线都以 10-seed ensemble 形成点预测分布，并在独立 calibration 上按 n 校准 split-conformal 90%/95% 区间。core test 检查覆盖和宽度；压力层只检查覆盖失效程度。若压力层需要有效区间，必须另行校准，不得复用 core 保证。

## 八、验证与停止条件

进入 test 前必须满足：

1. 目标公式、编码/解码、尺度/平移等变和指标适配器测试通过；
2. 小型 pilot 证明数据、训练、checkpoint、传统基线和汇总链路可运行；
3. D 配置选择完成，P/D checkpoint 清单与 SHA256 冻结；
4. test 配置、分析代码和输出 schema 冻结；
5. 从干净 checkout 可运行全部测试和一个微型端到端复现。

硬停止并请求用户/Codex 重新规划：主问题或 \(x_{0.95}\) 定义需改变；P 基线不可复用；新增 NN fit 预计超过 100；任一阶段预计超过 24 小时且无法通过减少非必要重复解决；test 数据被提前用于选择；结果溯源不可恢复；需要范围外数据、删失模型、外部上传或产品部署。

普通代码错误、训练失败、无显著差异、负结果或传统方法失败不是硬停止，应修复、记录并继续。
