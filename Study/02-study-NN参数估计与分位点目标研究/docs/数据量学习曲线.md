# Study02 数据量学习曲线：最小筛选

> 状态：SCREENING COMPLETE。该任务是描述性筛选，不替换当前10-seed主实验，也不自动进入论文主结论。

## 问题

在Study01冻结参数范围、当前网络和固定验证/测试样本不变时，把每个参数组合的训练重复数从180增加到360或720，是否能进一步降低Q的测试误差？

## 最小合同

| 项目 | 冻结值 |
|---|---|
| 训练重复/组合 | 180（复用）、360、720 |
| 参数范围 | 与Study01相同 |
| 网络 | 256–128–64，三参数输出 |
| seed | 42 |
| 样本量 | 7、10、15、20 |
| folds | 1、3（1-based） |
| 路线 | P/Q成对 |
| 固定验证 | 原始300 repeats中的60条/组合 |
| 固定测试 | 原始300 repeats中的60条/组合 |
| 新增训练 | 只使用新的独立repeat_id，不进入验证或测试 |
| 新训练量 | 32 fits |

180档直接复用现有证据。360和720档使用完全相同的验证集、测试集、初始化、网络和训练预算；每档P/Q仅损失不同。

## 判断规则

1. 先看Q的pooled rRMSE是否随180→360→720持续下降；
2. 再看P/Q方向是否保持，以及改善是否只是某个n造成；
3. 本轮不做显著性主张；
4. 若无清晰单调改善，停止；若有，只选择最小的有效数据量另行确认；
5. 不追加网络档位、混合专家、OOD或新目标。

## 筛选结果

32个新fits全部完成，无NaN、未收敛、非有限预测、非法参数或支持域违规。

| 训练重复/组合 | P rRMSE | Q rRMSE | Q相对P改善 | Q相对180档改善 |
|---:|---:|---:|---:|---:|
| 180 | 0.166340 | 0.162276 | 2.44% | — |
| 360 | 0.165957 | 0.160630 | 3.21% | 1.01% |
| 720 | 0.165616 | 0.159722 | 3.56% | 1.57% |

Q随训练数据增加严格单调下降。相对180档，360档在4/4个n和7/8个模型单元改善；720档在4/4个n和8/8个模型单元改善。720相对360只再降低约0.57%，已经出现边际递减。

完整性复核：67/67个pilot文件SHA通过；180/360/720的固定测试键16/16一致；360/720档P/Q的初始化、batch顺序、网络、scaler和训练/验证/测试行身份16/16配对一致。

## 判断

筛选回答了“增加独立训练样本是否值得继续看”：**值得，但收益温和且边际递减**。

- 若目标只是完成当前论文，现有10-seed主实验和网络容量验证已经充分，本筛选作为探索性结果保存即可；
- 若目标是把“训练数据量影响”写成正式补充结论，推荐只确认360档：它是最小有效数据量，训练成本约为基线2倍；
- 720档不自动进入确认，因为相对360的新增收益仅约0.57%，却把训练量再翻倍；
- 当前只有1个seed和2个fold，不对1.01%或1.57%作正式推断。

在用户决定是否确认360档之前停止，不扩展网络、参数网格或混合专家。
