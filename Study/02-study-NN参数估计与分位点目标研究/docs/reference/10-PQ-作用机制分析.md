\[
u=\left((\hat\beta-\beta)/\beta,(\hat\eta-\eta)/\eta,

\[
\nabla_uL_Q=2e\,\tilde s(\hat\theta),\qquad
\nabla_uL_P=2u,
\]

其中 \(e=(\hat x_R-x_R)/x_R\)、\(\tilde s_j=(1/x_R)\partial\hat x_R/\partial u_j\)。真值处
\(H_Q=2s_0s_0^\mathsf T\)、\(H_P=2I\)。这是公平的损失层比较，而不是把 Q 的有量纲导数与 P 的归一化误差

- \(s_\beta=0.2113\text{--}1.1483\)，\(s_\eta=0.1213\text{--}0.8466\)，
  \(s_\gamma=0.6443\text{--}4.2008\)；
- \(\|s\|=0.7657\text{--}4.3933\)（跨度 5.74 倍），方向最大相差 20.3°；
- 因为 Q 的真值 Hessian 具有 \(s_0s_0^\mathsf T\) 交叉项，且敏感度的大小与方向均随网格点改变，一组全域固定的对角
  参数权重不能逐点复制 Q 的局部几何。

保存预测的精确无余项分解在每路 480,000 行上成立，最大恒等式误差 P 2.01e-7、Q 2.27e-7。
精确抵消指数均值 P=0.3512、Q=0.9149，且 200/200 个 `(n,fold,seed)` 配对单元均为 Q>P。
这确立了**已拟合结果的补偿结构**，不单独识别训练为何达到该解。

按 \(\beta\) 和 \(\gamma/\eta\) 分区后，\(\|s\|\) 与区域 Q 绝对 rRMSE 优势的 Pearson \(r\)
为 0.946（八个 bin）和 0.860（五个 bin）。该关联与敏感度解释相容，但样本点少、未加权、未干预，

## 1. 方法

### 1.1 分析对象与配对

- 逐 held-out 预测：P 与 Q 各 60 个模型（4 n × 5 fold × 3 seed）× 2400 行 = **144,000 行/路线**；
  同一 `(n, fold, seed)` 的 P/Q 行一一配对（样本身份、输入、真值完全一致，唯一差异为 loss）。
- 所有量在**每个真值样本**上计算，再做 pooled 与按 β / γ/η / n 的区域聚合。

### 1.2 冻结的公式与严格损失几何

目标可靠度寿命点（`09` §1.1）：
\[
x_p = \gamma + \eta\,[-\ln p]^{1/\beta},\qquad p=0.95,\quad a=-\ln(0.95)\approx 0.0513,\quad
\ln a\approx -2.970.
\]

无量纲参数误差（与 P 损失同构，任务冻结定义）：
\[
u=\left(\frac{\hat\beta-\beta}{\beta},\;\frac{\hat\eta-\eta}{\eta},\;\frac{\hat\gamma-\gamma}{\eta}\right)
\]
以下所有关于“等权”“敏感度”和 Hessian 的比较都在这个共同坐标中进行。换回原参数坐标时，
`P_equal` 对三个平方误差的系数为 \(1/\beta^2,1/\eta^2,1/\eta^2\)，所以本文的“等权”
特指 \(u\) 坐标中的等系数，不是原参数单位中的等系数，也不代表三个参数具有相同工程重要性。

令
\[
e(u)=\frac{\hat x_p(u)-x_p}{x_p},\qquad g(u)=\nabla_u e(u),\qquad s_0=g(0).
\]
为与既有机器字段保持一致，下文结果表中的 `s`、`s_norm` 和 `mean_s_norm` 均指这里的真值点
敏感度 \(s_0\)，不是当前预测点敏感度 \(g(u)\)。
下述微分等式要求 \(u\) 与从 0 到 \(u\) 的线段位于合法解码域内；三参数 Weibull 目标在该域内
光滑。真值处的无量纲敏感度向量（相对 \(x_p\) 误差的一阶系数）为
\[
s_0=\left(s_\beta=\frac{\partial x}{\partial\beta}\frac{\beta}{x},\;
     s_\eta=\frac{\partial x}{\partial\eta}\frac{\eta}{x},\;
     s_\gamma=\frac{\partial x}{\partial\gamma}\frac{\eta}{x}\right),
\]
\[
\frac{\partial x}{\partial\beta}=-\eta\,a^{1/\beta}\,\frac{\ln a}{\beta^2}>0,\qquad
\frac{\partial x}{\partial\eta}=a^{1/\beta}>0,\qquad
\frac{\partial x}{\partial\gamma}=1.
\]
（`\ln a<0`，故 dx/dβ>0；实现 `mechanism.analytic_sensitivity`，与有限差分 rtol 1e-6 一致。）

#### 1.2.1 P 是固定欧氏几何

`P_equal` 在 \(u\) 坐标中的单样本损失严格为
\[
L_P(u)=\|u\|_2^2,
\qquad \nabla_uL_P=2u,
\qquad H_P=2I_3.
\]
因此 P 在整个合法域中使用同一个单位矩阵度量：无交叉项，且不随目标可靠度水平、当前预测位置
或目标函数的局部敏感度改变。这是“固定欧氏几何”的精确定义；它不是在价值判断上宣称 P
不合理，而是说明其几何由预先选择的参数坐标与归一化决定。

#### 1.2.2 Q 在当前预测点传播目标敏感度

对单行

\[
L_Q=\left(\frac{\hat x_p-x_p}{x_p}\right)^2,
\]

链式法则给出
\[
\nabla_u L_Q(u)=2e(u)g(u),
\qquad
H_Q(u)=2g(u)g(u)^\mathsf T+2e(u)H_e(u).
\]
这里 \(g(u)\) 在**当前预测参数点**计算，会随样本、参数区域、可靠度水平和当前 \(u\) 改变。
若网络原始输出为 \(z\)，合法解码为 \(u=u(z)\)，则真正回传给网络的是
\[
\nabla_zL_Q=J_{u\leftarrow z}^\mathsf T\,[2e(u)g(u)],
\]
即目标误差、当前点目标敏感度与合法解码器 Jacobian 的共同作用。本文把这一精确链式法则简称为
“动态目标敏感度传播”；“自动加权”只是一种直观简称，**不表示** Q 等价于三个固定的对角权重。

等价地，在解码参数坐标中，任一方向满足

\[
\frac{\partial L_Q}{\partial\hat\theta_j}
=\frac{2(\hat x_p-x_p)}{x_p^2}
\frac{\partial\hat x_p}{\partial\hat\theta_j},
\qquad \hat\theta_j\in\{\hat\beta,\hat\eta,\hat\gamma\}.
\]

#### 1.2.3 真值 Hessian、秩一结构与二维零空间

真值处 \(e(0)=0\)，故一般 Hessian 中的第二项消失：
\[
H_Q(0)=2s_0s_0^\mathsf T.
\]
由于 \(s_\gamma=\eta/x_p>0\)，必有 \(s_0\ne0\)，所以 \(H_Q(0)\) 的秩严格为 1，零空间
\[
\mathcal N(s_0^\mathsf T)=\{v:s_0^\mathsf Tv=0\}
\]
严格为二维。也就是说，Q 在真值处的二阶几何只惩罚沿 \(s_0\) 的一个方向；在其正交二维空间中，
目标相对误差的一阶变化为零。这是目标为一维而参数为三维所产生的局部欠定性，不等于说有限距离上
的真实 Q 损失恒为零。

#### 1.2.4 M95 只是 Q 的真值点局部二次代理

在真值邻域内，Taylor 展开给出
\[
e(u)=s_0^\mathsf Tu+\tfrac12u^\mathsf TH_e(0)u+O(\|u\|^3),
\]
从而
\[
L_Q(u)=(s_0^\mathsf Tu)^2+O(\|u\|^3).
\]
因此
\[
L_{M95}(u)=(s_0^\mathsf Tu)^2=u^\mathsf T(s_0s_0^\mathsf T)u
\]
是 Q 在真值处的二阶 Taylor 项。`M95` 的 \(s_0\) 随每条训练标签的真值参数点变化，但在该条样本
上不随当前预测位置 \(u\) 更新；准确术语是“**逐真值点固定、对预测位置静态的秩一局部
敏感度矩阵**”，而不是“全数据共用一个固定矩阵”。

对任意 \(v\in\mathcal N(s_0^\mathsf T)\)，M95 对所有步长都有
\(L_{M95}(\varepsilon v)=0\)。真实 Q 则一般满足
\[
e(\varepsilon v)=\tfrac12\varepsilon^2v^\mathsf TH_e(0)v+O(\varepsilon^3),
\qquad
L_Q(\varepsilon v)=\tfrac14\varepsilon^4[v^\mathsf TH_e(0)v]^2+O(\varepsilon^5).
\]
若该方向的二阶项也为零，首个非零项会出现在更高阶；无论哪种情形，M95 都没有保留有限位移下
由高阶项产生的目标误差。这界定了静态局部代理的数学缺口，但不预先断言该缺口在训练结果中占多大比例。

#### 1.2.5 路径平均割线矩阵：Q 的精确重写

对连接真值与当前预测的合法线段应用微积分基本定理：
\[
\bar s(u)=\int_0^1g(tu)\,dt,
\qquad
e(u)=e(0)+\int_0^1g(tu)^\mathsf Tu\,dt=\bar s(u)^\mathsf Tu.
\]
于是有精确恒等式
\[
L_Q(u)=u^\mathsf T\!\left[\bar s(u)\bar s(u)^\mathsf T\right]u.
\]
这不是近似；但矩阵本身依赖 \(u\)。只有在计算图中保留 \(\bar s(u)\) 对 \(u\) 的导数，上式的
前向值与梯度才都与 Q 恒等。若把 \(\bar s(u)\) `detach`，前向值在该点仍可相同，回传梯度却变成
\(2e(u)\bar s(u)\)，一般不等于 Q 的 \(2e(u)g(u)\)；此时得到的是另一个 surrogate，不能称为
“精确 Q”。因此，“存在精确动态矩阵表达”不构成一种独立于 Q 的新训练方法，而是 Q 本身的
另一种数学写法。

#### 1.2.6 B1、B5、B10 的目标特异性

令可靠度水平为 \(R\)，\(c_R=-\ln R\)、\(t_R=c_R^{1/\beta}\)，则
\[
s_{R,\beta}=-\frac{\eta t_R\ln c_R}{\beta x_R},\qquad
s_{R,\eta}=\frac{\eta t_R}{x_R},\qquad
s_{R,\gamma}=\frac{\eta}{x_R}.
\]
本文的 B1、B5、B10 分别对应 \(R=0.99,0.95,0.90\)。因为
\[
\frac{s_{R,\eta}}{s_{R,\gamma}}=t_R,
\qquad
\frac{s_{R,\beta}}{s_{R,\eta}}=-\frac{\ln c_R}{\beta},
\]
敏感度的大小和方向都随 \(R\) 改变，故 \(s_Rs_R^\mathsf T\) 是目标特异的。B5 的局部矩阵
不能被不加验证地解释为 B1 或 B10 的工程权重；多个目标的联合损失则对应多个目标敏感度的组合，
是另一份科学合同。

#### 1.2.7 术语与证据边界

- **数学恒等式**：P 的固定欧氏几何、Q 的梯度与一般 Hessian、真值秩一 Hessian、路径平均割线表达。
- **局部近似**：M95 是 Q 在真值处的二阶项；其二维零空间与 Taylor 余阶是解析性质。
- **终态观察**：保存预测中的参数误差补偿、误差分解和分区差异，描述训练完成后的解，不识别 SGD 路径。
- **探索性消融**：M95 与 P/Q 的匹配 pilot 只能检验该静态代理在冻结合同中的表现。
- **未识别因果**：零空间、高阶非线性、优化轨迹或网络容量各自对 Q−P 差异贡献多少，当前证据不能分摊。

因此本文可论证 Q **在数学上实施动态目标敏感度传播**，并可报告 Q 终态解与 M95 消融的观察；
不能把二者合写成“动态性已经被证明导致了全部 Q 收益”。

**目标敏感度范数**（只依赖真参数，与估计无关）：
\[
\|s_0\|=\sqrt{s_\beta^2+s_\eta^2+s_\gamma^2}
\]
——用于把区域 Q−P 差异与「参数误差→目标误差」的放大倍数联系起来。

### 1.3 分解与机制量（逐样本）

- **实际误差** `actual = rel_err`（保存的 `(\hat x_{0.95}-x_{0.95})/x_{0.95}`）。
- **一阶投影** `proj = s·u = s_β·u_β + s_η·u_η + s_γ·u_γ`（component contributions
  `c_β,c_η,c_γ` 即 `s_β·u_β` 等）。
- **非线性余项** `rem = actual − proj`。**局部线性诊断**：当 `rms(proj) ≫ rms(actual)`
  时 `corr(proj, rem) ≈ −1` 在代数上近乎被强制（见 §4 限制），故 proj/rem 的负相关
  只说明「真值处一阶 Taylor 在远离真值时失效」，**不作为 Q 优势的原因**。
- **均方比量（origin-anchored）** `r2_origin = 1 − mean(rem²)/mean(actual²)`。这是
  以原点为基准的均方比，**不是**方差形式的 R²（仅当 mean(actual)=0 时才等价）；文档
  不称其为 R²，避免误导。
- **精确无余项分解**（对称精确分解，恒等式精确到浮点精度）。令 `t(β)=a^{1/β}`，
  `x_0=γ_0+η_0 t_0`（真值）、`x_1=γ_1+η_1 t_1`（估计），则
  \[
  C_\gamma=\frac{\gamma_1-\gamma_0}{x_0},\qquad
  C_\eta=\tfrac12\frac{(\eta_1-\eta_0)(t_0+t_1)}{x_0},\qquad
  C_\beta=\tfrac12\frac{(\eta_0+\eta_1)(t_1-t_0)}{x_0},
  \]
  且 **精确成立** `actual = C_β + C_η + C_γ`（验证：展开右式得 `(x_1-x_0)/x_0`，浮点残差
  ~1.8e-7，由 float32 存储主导，见 §2.1 / 测试）。三个分量分别归因于 γ 位移、η 变化 ×
  平均 t、平均 η × t 变化——是对 `x_0.95` 相对变化的**完全无余项**分解。
- **精确分量抵消指数**（显式定义，零分母处理）：
  `cancel_exact = (A_exact − B_exact)/A_exact`，其中
  `A_exact = |C_β|+|C_η|+|C_γ|`、`B_exact = |C_β+C_η+C_γ|`；`A_exact=0` 时 `cancel_exact=0`
  （`np.divide(where=...)`，不产生 NaN）。`B_exact ≡ |actual|` 到浮点存储精度。含义：
  精确分量内部抵消程度，0 = 无抵消（同向），1 = 完全抵消（actual=0）。**注意这与一阶
  `cancel` 指数不同**：cancel 只看一阶分量，不能据此排除精确级抵消（§2.1 显示两者结果相反）。
- **目标对齐 vs 真值点局部切空间近似**：
  `u_par = proj/‖s‖`（沿 ŝ 的分量，目标对齐）、`u_perp = √(‖u‖² − u_par²)`、
  `align = |u_par|/‖u‖`（对齐度，`u=0` 时置 0）。`u_perp` 是**真值点局部切空间近似**
  的垂直分量——Q 远离真值，`u_perp` 不是到弯曲等分位点流形的全局距离，只是把
  真值处切平面当作局部坐标后的残差。
- **解码器边界诊断**：`γ̂/min_x ≥ 0.9999` 计数（与 r4 `boundary_diagnostic.json` 同阈值）。
- 参数误差模长 `u_beta, u_eta, u_gamma, u_norm` 的 RMS 与分位点分布（分位点已存入
  机器可读输出 `mechanism_summary.json` 的 `u_quantiles`，见 §2.2）。

## 3. 解释

### 3.1 机制（与分解事实区分：以下为有界解释）

**已测事实（§2）**：Q 参数误差大（u_norm 9.13，u_beta 9.08），但精确分量高度抵消
（cancel_exact 0.915 vs P 0.352，恒等式逐行成立至 1.8e-7）；Q 精确分量 RMS
（0.49/0.82/0.42）远大于 P（0.11/0.01/0.14）。

**有界解释——两个互补陈述**：

1. **Q 通过精确参数补偿维持 x_0.95**（"如何"达到目标）。x_0.95 是标量目标对三维参数，
   解不唯一；Q 只受 x_0.95 误差约束，可沿等分位点流形大幅移动参数。精确无余项分解
   显示这些大参数变化在精确意义上几乎完全相互抵消（`cancel_exact` 0.87–0.94 于每个区域），
   净剩的目标误差与 P 相当或更小。这是**直接结果空间证据**，且不依赖一阶近似——一阶分量
   的 cancel 指数甚至显示 Q 略低于 P（0.342 vs 0.357），仅凭一阶分量会得出相反结论。
2. **任务对齐优势与参数误差放大较强的区域相伴出现**（"在哪些区域"，探索性）。
   目标敏感度范数 `‖s‖` 只依赖真参数，随 β、γ/η **单调下降**（β=1.5: 2.165 → β=5:
   1.222；γ/η=0.1: 2.593 → γ/η=1: 0.825），与区域 Q−P 实际误差差负相关（β: −0.952，
   γ/η: −0.872）。已测现象是：**低 β / 低 γ/η 区域参数误差到目标误差的局部放大倍数较大，
   同时观察到更大的 Q 优势；高 β / 高 γ/η 区域敏感度较低，同时观察到 P 略优。**这一共变
   与任务对齐解释相容，但不证明敏感度差异导致区域胜负。`‖s‖` 对 n 恒定（由构造），Q 在各 n
   恒优、优势随 P 估计改善而收窄——与「n 从不翻转」一致。

**对 proj/rem 与 `u_perp` 的定位**：Q 的 corr(proj,rem)≈−0.9995 在 `rms(proj)≫rms(actual)`
时是代数上近乎被强制的，仅作为**真值点局部线性失效的诊断**；`u_perp` 大只说明 Q 远离真值
处的局部切空间，不是到等分位点流形的全局距离。两者均**不作为** Q 优势的原因。

### 3.2 区域反转（解释，探索性标注）

**翻转处**：β=3.5 与 γ/η=0.5 处 Q 的优势转为 P 更优；n 从不翻转。三个维度中，β 与 γ/η
改变**真值点目标敏感度 `‖s‖`**（即目标误差对参数误差的放大倍数），n 只改变估计精度
（不改变 `‖s‖`）——与「n 从不翻转、β/γ/η 翻转」的观察一致：

- **低 β / 低 γ/η（Q 赢）**：`‖s‖` 大（2.16 / 2.59），且观察到较大的 Q 优势
  （β=1.5：Q 0.2543 vs P 0.2816；γ/η=0.1：0.2354 vs 0.2634）。
- **高 β / 高 γ/η（P 赢）**：`‖s‖` 小（1.22 / 0.83），且观察到 P 略优
  （β=5：Q 0.1099 vs P 0.1030；γ/η=1.0：0.0823 vs P 0.0761）。
- **n（Q 恒赢）**：`‖s‖` 与 n 无关（由构造）；n 增大只让两条路线误差都收敛（0.161→更小），
  Q 的相对优势随 n 缩小但符号不变。与 S1 的按 n CI 全不含 0 一致。

这一解释与 17/17 符号复现、`‖s‖` 区域负相关、以及「n 不翻转 vs β/γ/η 翻转」的异质性一致。
**但 `‖s‖` 与 delta 的相关基于少量 bin（8+5），未加权，属探索性关联，不作因果主张**。

## 4. 限制

- **proj/rem 反相是代数强制的诊断，不是机制证据**：`rms(proj)≫rms(actual)` 时
  `corr(proj,rem)≈−1` 近乎必然；不能据此宣称「曲率补偿导致 Q 优势」。本分析不量化
  曲率，也不以曲率作为因果主张。
- **精确分解是恒等式，不是因果分解**：`actual = C_β+C_η+C_γ` 对任何参数都成立，它证明
  Q 的参数变化在精确意义上相互抵消（"如何"），但**不单独证明**"为什么"这种补偿对
  Q 更有利——后者仅有 `‖s‖` 区域关联（探索性）；若未来要识别完整训练因果，需另立问题做干预验证，
  不是当前成稿前置。
- **`‖s‖` 区域关联是描述性/探索性**：少量 bin（8 β + 5 γ/η）、未加权、不逐 cell 做
  显著性（避免大量未校正的 cell 显著主张）；对 n 维度 `‖s‖` 恒定，相关未定义。
- **分解不证明因果**：proj/rem 分解、精确分解与区域相关都是观察性证据；机制解释未经
  干预实验确认；该工作若开展应作为后续独立研究。
- **一阶投影在真值处取敏感度**：余项吸收二阶及以上、有限参数效应与 float32 存储；对
  远离真值的 Q，余项的量级大（6.36），其「抵消」依赖 x_0.95 公式的特定结构，推广到
  其他分位点/结构需另立问题验证，不是当前论文必做项。
- **先期 S2 表格只有 3 个 seed**；当前论文机制派生物已重算全部 10 seeds，但五折训练集仍重叠，
  10 seeds 仍是有限算法重复。
- Q 的极端参数（β̂/β 中位 6.9、η̂/η 中位 0.06）说明 Q 的**单个参数估计不可靠**；本分析
  只评价 x_0.95，不主张 Q 的其他量（与 S1「Q 以退化内部表示达到分位点目标」一致）。
- 环境/复现：同 `configs/pq-environment-v2.json`（Python 3.11.9 / torch 2.12.0+cpu /
  numpy 2.4.6）；分析为 numpy 纯计算，确定性。
