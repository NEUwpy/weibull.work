## 1. 要回答的问题

`P_equal` 在无量纲参数误差坐标

\[
u=\left((\hat\beta-\beta)/\beta,(\hat\eta-\eta)/\eta,
(\hat\gamma-\gamma)/\eta\right)
\]

中使用固定欧氏损失 \(L_P=\lVert u\rVert^2\)。`Q_param` 则仍输出三个参数，
但使用 B5（\(R=0.95\)）寿命点的相对平方误差 \(L_Q=e(u)^2\)。本轮闭环回答：

1. Q 传回网络的“自动权重”究竟是什么；
2. 真值点敏感度矩阵 \(s_0s_0^T\) 能否替代 Q；
3. 已观察到的 Q 收益与哪些可验证的机制现象一致。

## 2. 数学结论

令 \(g(u)=\nabla_u e(u)\)，则

\[
\nabla_uL_Q=2e(u)g(u),\qquad
\nabla_wL_Q=2e(u)J_w^Tg(u).
\]

因此 Q 不是给三个参数一组永久不变的标量权重，而是在当前预测位置传播目标误差
\(e(u)\)和动态目标敏感度 \(g(u)\)。在真值 \(u=0\) 处，

\[
H_Q(0)=2s_0s_0^T,\qquad s_0=g(0).
\]

因而 `M95` 损失 \((s_0^Tu)^2\) 是 Q 的真值点局部二次代理；它是秩一矩阵，存在二维零空间。
三个自动有限步反例证明，某些方向上 M95 可以在数值精度内为 0，但真实 B5 相对误差
仍为 0.21%–0.59%。数值扫描的小步长 Q-loss 阶数约为 4，符合零空间内一阶项消失后的高阶曲率误差。

沿 \(0\to u\) 的路径平均敏感度

\[
\bar s(u)=\int_0^1g(tu)\,dt
\]

满足

\[
e(u)=\bar s(u)^Tu,\qquad
L_Q=u^T[\bar s(u)\bar s(u)^T]u.
\]

这是 Q 的精确动态矩阵表达。只有保留 \(\bar s(u)\) 对 \(u\) 的导数时，前向和反向传播
才都与 Q 完全相同；将矩阵 `detach` 后已是另一个代理损失。

## 3. 证据与结果

完整审计了 424 个 fit、1,017,600 行 held-out 证据：200 个 P/Q 配对单元和 24 个
P/M95/Q 匹配单元。SHA、metadata SHA、参数键、非有限值和 Weibull 支撑域检查全部通过。

### 3.1 主 P/Q 证据（200 单元）

| 指标 | P | Q |
|---|---:|---:|
| B5 rRMSE | 0.166059 | 0.161075 |
| 精确抵消指数 | 0.3512 | 0.9149 |
| 当前点与真值点敏感度平均夹角 | 4.45° | 26.18° |

Q 的 rRMSE 相对 P 降低 3.001%。Q 预测在结果空间呈现更强的参数误差抵消，
且更常离开真值点的静态敏感度方向。这是终态几何证据，不是 SGD 轨迹的因果识别。

### 3.2 M95 探索性消融（24 单元）

| 路线 | B5 rRMSE |
|---|---:|
| P | 0.167623 |
| M95 | 0.200492 |
| Q | 0.162182 |

M95 相对 P 变差 19.61%，24/24 单元均未优于 P 或 Q。M95−P 的真实 B5 MSE 差
\(+0.0120997\) 精确分解为：

| 分量 | M95−P |
|---|---:|
| 真值点局部项 | −0.0097557 |
| 局部项×非线性余项交叉项 | +0.0041514 |
| 非线性余项平方 | +0.0177040 |
| 总和 | +0.0120997 |

即 M95 确实学会了更小的静态局部代理，但它未约束的高阶几何使真实 B5 误差更大。
这排除了“Q 只是一个真值点静态矩阵”的简单解释。

## 4. 论文可用结论

P 在归一化参数坐标中使用固定欧氏几何；Q 根据当前预测位置，将实际目标误差和
目标敏感度动态传回网络。真值点静态秩一矩阵虽包含敏感度和交叉项，但它仅是局部代理，
无法跟随有限误差区域的弯曲目标几何。现有主实验则显示，Q 的终态参数误差更强地围绕 B5 目标
发生抵消，与这一动态目标几何解释相容。

本轮没有分别估计零空间、非线性曲率或优化轨迹各自的因果份额，也不否定其他专门设计的
目标感知参数度量。这些不是当前论文主结论所必需的前置实验。
