# Study/02 主研究 B：研究问题与结论边界

> 状态：2026-07-31 冻结为正式实验起点。前置依据见 `06-A-前置研究报告.md`；实验口径见 `02-B-实验协议.md`。

## 一、核心问题

工程目标为可靠度 95% 时的寿命

\[
x_{0.95}=\gamma+\eta[-\ln(0.95)]^{1/\beta},
\]

即失效分布的下侧 5% 分位点。主研究只回答一个论文问题：

> 如果工程上只需要 \(x_{0.95}\)，先估计完整 Weibull 参数再换算分位点，相比直接预测 \(x_{0.95}\) 付出了多少精度代价；这种差异在什么条件下成立？

## 二、必须回答的问题

| 编号 | 问题 | 结论所需证据 |
|---|---|---|
| B1 | 在 core 参数域内，直接分位点路线是否比 NN 参数路线具有更低的 \(x_{0.95}\) 样本外误差？ | 相同测试样本上的配对相对 RMSE 差及 95% CI；同时报告 Bias、SD、MAE 和尾部误差 |
| B2 | 差异是否随样本量和参数区域变化？ | n={5,7,10,15,20} 分层结果；低 β、高 β、位置偏移压力层结果 |
| B3 | 差异来自训练目标对齐，还是来自网络与资源配置不同？ | 两条路线分别优化的主比较，加一组相同输入、骨干和训练预算的受控比较 |
| B4 | 直接路线相对传统参数估计后换算分位点是否有实际收益？ | 与 MDM、MLE、LRE 的配对比较；失败率与有效行误差分开报告 |
| B5 | 参数路线保留完整分布信息是否带来可量化价值？ | 参数路线的 β/η/γ 误差、合法率、支持集违规和 CDF 诊断；直接路线明确不产生参数结论 |
| B6 | 两条 NN 路线在域外、污染和真实数据上是否仍可用？ | 压力层敏感性；NIST train/holdout 的 pinball loss 与 95% 超越率校准；不得把单一真实数据集当作已知真值 |
| B7 | 单次预测的风险能否被识别？ | 同域 calibration 上的 90%/95% split-conformal 覆盖与宽度；域外只检查失效，不外推保证 |

## 三、预注册判定

### 3.1 唯一确认性主张

B1 是唯一确认性主张。主效应定义为 pooled core 上直接路线 D 相对参数路线 P 的 \(x_{0.95}\) 相对 RMSE 改善率；五个 n 等权：

\[
I=\frac{\operatorname{RMSE}_{P}-\operatorname{RMSE}_{D}}
        {\operatorname{RMSE}_{P}}.
\]

- `supported and material`：\(I\) 的 95% CI 下界大于 0，且点估计至少为 5%；
- `supported but small`：95% CI 下界大于 0，但点估计小于 5%；
- `no confirmed difference`：95% CI 跨 0；
- `parameter route better`：95% CI 上界小于 0。

5% 是实际意义阈值，不是为了追求显著性而事后调整的门槛。B2–B7 为解释性或边界性问题，不因局部显著结果改写 B1。

### 3.2 完成不等于得到正结果

下列任一结果都允许研究完成：直接路线更好、两者无可确认差异、参数路线更好，或优势只在局部成立。完成标准是数据角色未混用、比较公平、全部预注册问题有证据、负结果和失败结果被保留。

## 四、允许与禁止的结论

允许：

- 在已评估的参数域、样本量和数据条件下比较路线；
- 区分统计支持与实际意义；
- 将真实数据结果表述为外部一致性或预测校准证据；
- 将参数路线的完整分布输出视为功能收益，同时量化其目标分位点代价。

禁止：

- 从 \(x_{0.95}\) 结果推断任意分位点都成立；
- 将 stress 层与 core 合并后声称全域平均优势；
- 把 validation、pilot 或 calibration 结果写成最终测试结论；
- 把“输出有限/合法”写成“估计准确/鲁棒”；
- 用单一 NIST 数据集证明跨材料普适性；
- 声称直接路线能提供 β、η、γ 或非目标分位点；
- 将传统方法失败行静默删除后宣布 NN 全面获胜。

## 五、范围

纳入完整、独立同分布的小样本三参数 Weibull 数据；主目标仅为 \(x_{0.95}\)。删失、截断、条件可靠度、多个目标分位点联合训练、任意深度架构搜索和产品部署均不属于本轮正式实验。
