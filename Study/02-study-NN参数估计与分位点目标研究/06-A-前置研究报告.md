# Study/02 前置研究 A 报告：NN 三参数 Weibull 参数估计基础

> 完成日期：2026-07-31
> 目的：为 Study/02 的正式实验确定参数估计路线、比较基线和适用边界。本文只保留研究问题、实验、结果与决策；逐题证据和复现位置见 `05-A-证据索引.md`。

## 一、研究结论

前置研究要判断的不是“能否训练一个 NN”，而是：NN 参数估计能否作为 Study/02 中“先估计参数、再计算寿命分位点”的可信基线，以及正式实验应如何设计。

实验支持采用一个明确而有限的 NN 参数基线：排序样本值经等变归一化后输入 joint fixed-n MLP，预测变换并标准化的三参数，使用 Huber 损失和约 100k 训练样本。该模型跨训练 seed 稳定，输出在已评估域内合法，并满足尺度和平移等变。

实验不支持把 NN 定义为普遍更优的 Weibull 估计器。NN 在 core 参数域内优于 MLE 和 LRE，但没有整体胜过 MDM；在低 β 边界域表现较弱，对强异常值不稳健，真实数据上的 γ 支持边界也不可靠。因此，Study/02 正式实验应比较“参数路线与直接分位点路线对目标寿命分位点的实际误差”，而不是预设 NN 参数估计优于传统方法。

## 二、研究设计

前置研究将 19 个问题压缩为五组可判定问题。核心参数域为 β∈[1.2,4]、η∈[100,10000]、ρ=γ/η∈[0,1]，并另设低 β、高 β 和位置偏移压力域。主要误差指标 `L_param` 聚合 β、η、γ 的标准化误差，同时报告单参数误差、失败率和合法率。

| 模块 | 要解决的问题 | 实验做法 |
|---|---|---|
| 表示与模型 | 输入样本还是特征，怎样定义目标、损失、网络和输出形式 | 复用已批准的输入、损失、架构、joint/independent、fixed/shared 对照实验 |
| 训练设计 | 训练量、参数采样分布和范围先验是否影响结论 | 固定模型，只改变训练行数、参数分布或传统法裁剪策略；用同一独立确认集比较 |
| 比较与泛化 | NN 在哪里优于传统法，能否泛化到新参数、样本量和训练 seed | 只读评估 60 个冻结 NN checkpoint；对比 MLE、MDM、LRE，共 111,200 条结果 |
| 数学性质与污染 | 单位变化、平移和异常值是否破坏估计 | 对 1,600 个配对数据集施加尺度、平移和四类污染变换，共 20,800 条结果 |
| 工程可信度 | 仿真训练能否迁移到真实寿命数据，单次估计如何表达不确定性 | NIST 6061-T6 数据 2,500 次拆分；另做 ensemble + split-conformal 校准与域外检查 |

## 三、问题、实验、结果与结论

### 3.1 输入表示、损失和模型形式（A1、A4、A7、A8、A17、A18）

| 问题 | 实验与关键结果 | 结论 |
|---|---|---|
| 人工特征是否优于原始样本 | 在 n=10、core 域和 10 个 seed 下比较排序样本值 V 与 15 个工程特征 F2。两者均无失败，`L_param` 差为 8.5×10⁻⁵，95% CI [−5.8×10⁻⁴, 7.4×10⁻⁴]。 | F2 没有可确认优势。正式实验直接使用排序样本值，减少人为特征设计。该实验没有识别单个特征贡献，因此 A4 仅能回答到“整套 F2 不必要”。 |
| 三个不同尺度的参数如何共同训练 | 比较变换目标 + 标准化 + Huber、未标准化 MSE 和原始参数 MSE。验证 `L_param` 分别为 0.275019、0.276771、0.277075。 | 采用 log β、log(η/scale)、log((min−γ)/scale)，按训练集标准化并使用 Huber。 |
| 三参数联合估计还是分别估计 | 在匹配参数预算下，跨五个 n 和 10 个 seed 比较 joint 与 independent；`L_param` 为 0.278041 对 0.278844。 | joint 略优且更简单，作为参数路线基线。 |
| 每个 n 单独训练还是共用模型 | fixed-n MLP 与 shared DeepSets 的聚合 `L_param` 为 0.278041 对 0.279911。架构筛选得到 fixed-n 的 m12 和 shared 的 d12，但未检验任意架构家族。 | 正式主分析用 fixed-n m12；只有需要处理任意 n 时才使用 shared。A8 不能上升为“结论与架构无关”。 |

### 3.2 训练量、训练分布与范围先验（A5、A6、A13）

| 问题 | 实验与关键结果 | 结论 |
|---|---|---|
| 需要多少训练数据 | 固定 n=10、V、m12 和 Huber，比较 7k、25k、100k、400k。25k→100k 改善 0.829%（95% CI [0.342%, 1.386%]）；100k→400k 为 −0.255%（95% CI [−0.841%, 0.352%]）。 | 100k 是当前模型的实用平台点；正式实验无需用 400k 堆算力。 |
| 参数如何采样 | 在相同 7k 训练量和 3 个 seed 下比较 core 连续采样、旧离散网格和过宽分布。后两者的 `L_param` 分别高 0.04177 [0.02809, 0.05708] 和 0.08204 [0.06188, 0.10884]。 | 训练分布必须与主张域匹配。core 结论使用 core 连续采样；边界域作为独立压力层，不能混入后宣称全域平均优势。 |
| NN 优势是否只是利用已知参数范围 | 给传统估计加入真实 core 边界裁剪。MDM 从 0.322517 改善至 0.296330，优于 NN 的 0.311821；NN 与原始或裁剪 MDM 的差异 CI 都跨 0。 | 范围先验能改善传统法，但现有证据本就不支持 NN 普遍胜过 MDM，因而不能把所谓普遍优势归因于范围先验。正式比较应同时保留未裁剪生产法和明确标注的 oracle 敏感性分析。 |

### 3.3 方法比较、泛化和稳定性（A2、A3、A9、A10、A19）

| 问题 | 实验与关键结果 | 结论 |
|---|---|---|
| NN 在哪些区域优于传统估计 | 对 core、低 β、高 β、位置压力域和 n={5,7,10,15,20} 做 60 个配对比较。core 中 NN 对 MLE/LRE 全部 n 整体更好，但对 MDM 没有任何 n 达到整体更好；低 β 域中 NN 明确弱于 MDM。 | NN 的优势依参数域、样本量和对手而变。MDM 必须作为正式实验的强基线，结果必须分域报告。 |
| 新参数组合和新样本量能否使用 | confirmation 参数点与训练/验证分离。shared 模型在未见 n={6,8,12,25,30,50} 上合法率均为 100%，`L_param` 从 0.3923 降至 0.2082 后在 n=50 回升至 0.2258。 | 域内插值和中度外推可用，但不能假设样本量增加后无限、严格单调改善。 |
| 重训练是否稳定 | 10 个 seed 下 `L_param` 的 CV 为 0.69%–0.83%；seed 方差份额为 0.033%–0.069%；参数点难度排序 Spearman 均值为 0.991–0.995。 | 当前训练方案的随机波动很小。正式实验仍应保留多 seed，但无需用大量 seed 弥补模型不稳定。 |
| 输出是否合法 | fixed、shared、core 和压力层中的 NN 输出合法率均为 100%（有限、β>0、η>0、γ<样本最小值）。 | 变换解码有效。这里是已评估域的实证结果，不是任意输入的形式保证。 |
| n 增大是否稳定变准 | fixed core 平均 `L_param` 为 0.4301→0.3645→0.3209→0.2738→0.2366，但 26.56% 的参数点在相邻 n 上误差反而增加。 | 只能报告聚合改善趋势，不能对单个参数点作单调性承诺。 |

### 3.4 尺度、平移与异常值（A14、A15、A16）

| 问题 | 实验与关键结果 | 结论 |
|---|---|---|
| 改变单位是否改变估计 | 将样本和参数同时缩放 10⁻³ 或 10³。NN 最大等变残差分别为 1.35×10⁻⁷ 和 9.20×10⁻⁸。 | 当前归一化设计满足数值尺度等变，可以跨合理工程单位使用。 |
| 整体平移是否改变形状参数 | 平移 −0.5η、0.5η、5η，最大残差为 9.47×10⁻⁸、1.26×10⁻⁷、3.28×10⁻⁷。 | 模型能保持 β、η 并同步移动 γ，满足数值平移等变。 |
| 异常值是否破坏估计 | 干净 `L_param` 为 0.2300；high×3、high×10、低端和 10% 双侧污染后分别为 0.3144、0.7763、0.5101、0.9790，四个增量 CI 均高于 0；输出仍 100% 合法。 | 合法不等于准确。该 NN 不是鲁棒估计器，正式实验若涉及污染场景，必须单独报告并配置异常值诊断。 |

### 3.5 真实数据迁移与单次估计可信度（A11、A12）

| 问题 | 实验与关键结果 | 结论 |
|---|---|---|
| 仿真训练模型能否用于真实寿命数据 | 对 NIST 6061-T6 的 101 条寿命数据做 2,500 个 train/holdout 拆分。NN 的平均 holdout KS 随 n=5→20 从 0.2172 降至 0.1383，与 MDM/LRE 相当或略好；但 γ 支持集违规率为 74.8%–82.2%。 | NN 对真实 CDF 拟合有竞争力，但 γ 的工程解释不可靠。真实数据评价必须同时报告分布拟合与支持集违规，不能只报聚合误差。 |
| 单次点估计能否判断可信度 | 在 core 域校准 90%/95% ensemble + split-conformal 区间。core 覆盖接近标称值；95% 不确定性与实际误差 Spearman=0.325，最低不确定性 25% 样本的平均 `L_param` 为 0.2100，全部样本为 0.2785。低 β/高 β 域覆盖严重不足。 | 区间宽度和 ensemble 分歧可做域内风险排序，但不能跨域使用。正式实验应把“是否处于校准域”作为区间解释的前提。 |

19 个问题均得到证据覆盖，其中 A4 和 A8 保留为部分结论：现有实验没有识别单个特征的独立贡献，也没有证明科学结论对任意网络架构不敏感。这两个问题不阻塞 Study/02 正式实验。

## 四、对 Study/02 正式实验的结论与建议

### 4.1 正式实验应回答的核心问题

正式实验比较三条得到目标寿命分位点 \(x_{0.95}\) 的路线：

1. **NN 参数路线**：估计 \((\beta,\eta,\gamma)\)，再计算 \(x_{0.95}\)；
2. **NN 直接路线**：直接预测 \(x_{0.95}\)；
3. **传统参数路线**：用 MDM、MLE、LRE 估计参数后计算 \(x_{0.95}\)。

主结论应是“哪条路线对 \(x_{0.95}\) 更准、在哪些域成立、代价是什么”，而不是“哪种方法的参数总误差最低”。参数误差、合法率和 CDF 拟合作为解释性次指标。

### 4.2 应冻结的参数路线基线

- 输入：排序样本值 V，以样本最小值和 IQR 做等变锚定；
- 输出：log β、log(η/scale)、log((min−γ)/scale)，使用训练集统计量标准化；
- 模型：m12 MLP、joint、fixed-n；需要任意 n 时另设 d12 shared DeepSets；
- 损失：Huber；
- 训练量：以每个固定 n 约 100k 作为初始预算，再用主研究的小规模 pilot 核查参数路线和直接分位点路线是否都已进入平台；
- 重复：多 seed 用于估计训练波动，10 个 seed 已足够稳定；
- 解码与报告：强制参数合法，并同时报告支持集违规，不能以“可解码”替代“估计可靠”。

这些结论直接约束 NN 参数路线。直接分位点路线可以在相同资源上独立优化，但正式实验还应增加一组相同输入、相同骨干和相同训练预算的受控比较，以区分“训练目标改变”与“模型资源不同”造成的差异。

### 4.3 最小但充分的正式实验结构

1. 在 core 域和 n={5,7,10,15,20} 比较三条路线，以独立 confirmation 上的 \(x_{0.95}\) 误差为主指标。
2. 将低 β、高 β、位置偏移和异常值作为分开的压力层，不与 core 合并成单一平均结论。
3. 对每条路线报告目标分位点误差、失败/合法率、训练 seed 波动；参数路线另报 β/η/γ 误差和支持集违规。
4. 若输出区间，只在与 calibration 同域的 confirmation 上评价覆盖率与宽度；域外必须重新校准或明确标记无保证。
5. 用真实寿命数据验证工程可用性，但只把它作为外部一致性证据。单一 NIST 数据集不能替代仿真中已知真值的主比较。

### 4.4 不需要继续投入的前置工作

- 不需要为把 A4 从 partial 改为 answered 而做完整逐特征消融；正式路线已经选择不依赖人工特征的 V 输入。
- 不需要证明结论跨所有架构成立；正式实验只需固定一条合理参数基线，并用受控骨干比较回答训练目标问题。
- 不需要继续扩建通用实验调度、授权或证据流水线。现有脚本、固定配置、独立确认集和哈希工件足以支撑复现。
- 不应再花算力证明 400k 比 100k 更好，除非主研究的新目标或模型规模使既有平台结论失效。

## 五、适用边界

前置研究主要覆盖小样本、三参数 Weibull、指定 core/压力域和当前 MLP/DeepSets 家族。真实数据证据来自单一 NIST 材料数据集；conformal 覆盖仅在校准同域时成立；异常值实验评估的是敏感性，没有训练鲁棒模型。因此，本报告为 Study/02 正式实验冻结起点，而不是对所有数据域、网络架构或工程材料的普遍保证。

逐题统计量、置信区间、运行工件和复现脚本分别记录在 `05-A-证据索引.md`、`artifacts/lean/`、`code/` 与 `configs/`。
