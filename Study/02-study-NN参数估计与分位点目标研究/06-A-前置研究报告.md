## 研究目的与方法

本研究在进入寿命分位点主研究前，回答 NN 三参数 Weibull 参数估计的 19 个基础问题。采用最小可复现路线：只读复用已批准的 A-E1 r5 / A-E3 r2 证据，再以 E1–E4 四组针对性实验补足训练敏感性、方法比较与泛化、等变性与污染稳健性、真实数据与不确定性。研究不追求建设通用论文流水线，也没有为得到“全部肯定”的结论扩大实验。

## 结论

前置研究 A 已按最小可复现路线完成：19/19 问均有证据覆盖，其中 17 个为 `answered`，A4/A8 为 `partial`。partial 是结论边界，不是待建大型流水线：当前证据不能识别单个特征贡献，也不能证明科学结论跨架构不变；为把标签改成 answered 而新增大消融不符合比例原则。

推荐的后续 Study/02 参数估计基线为：

- 输入：排序样本值 V，经样本最小值/IQR 等变锚定；
- 目标：log β、log(η/scale)、log((min−γ)/scale)，训练集标准化；
- 损失：Huber；
- 模型：m12、joint、fixed-n；
- 训练量：100k；更大到 400k 未确认收益；
- 可变 n 时可用 d12 shared DeepSets，但 fixed 的验证结果略优；
- 输出必须伴随合法性、calibration 域、ensemble/conformal 区间、区间宽度和支持集违规提示。

不能声称：

- NN 普遍优于传统方法（core 中 MDM 仍是强基线）；
- NN 对异常值鲁棒；
- core 校准区间能覆盖 boundary-low/high；
- 真实数据上的 γ 支持边界可靠；
- 单个工程特征有已证实的独立贡献；
- 结论对任意网络架构不敏感。

## 关键发现

1. 100k 训练量进入平台；训练参数分布对 core 性能有实质影响。
2. NN 的优势按参数层/对手变化：对 MLE/LRE 常有优势，但 core 未整体胜过 MDM；boundary-low 明显较弱。
3. 10-seed 波动小；未见 n 可用但 n=50 有回退；样本量总体改善不等于逐参数点单调。
4. NN 在当前评估域 100% 合法并满足尺度/平移等变，但强异常值显著增大误差。
5. NIST 真实数据 holdout CDF 拟合有竞争力，但 γ 支持集违规率高。
6. core conformal 边际覆盖接近标称值，区间较宽且能提供有限风险排序；boundary-low/high 覆盖严重不足。

## 19 个问题的结论摘要

| 问题 | 状态 | 结论 |
|---|---|---|
| A1 | answered | 排序样本值 V 不低于 F2 工程特征，不支持“必须使用人工特征”。 |
| A2 | answered | NN 优势依参数层和比较方法而变，core 未整体胜过 MDM。 |
| A3 | answered | 未见参数组合和样本量可用，但较远外推会回退。 |
| A4 | partial | F2 整体无优势；当前证据不能识别单个特征的独立贡献。 |
| A5 | answered | 100k 训练量是实用平台点，增加至 400k 未确认收益。 |
| A6 | answered | 训练参数分布会实质影响目标域表现。 |
| A7 | answered | 变换目标标准化配合 Huber 是当前最合适的损失方案。 |
| A8 | partial | 已选出 m12/d12，但未证明结论对任意架构不敏感。 |
| A9 | answered | 10-seed 波动较小，参数点难度排序高度一致。 |
| A10 | answered | 当前评估域内输出全部合法，但不构成任意输入上的保证。 |
| A11 | answered | 真实数据 CDF 拟合有限可用，γ 支持边界不可靠。 |
| A12 | answered | ensemble + conformal 能提供域内风险提示，域外覆盖明显失效。 |
| A13 | answered | 范围先验可改善传统法，但不能据此声称 NN 普遍占优。 |
| A14 | answered | 单位缩放等变残差低于 1e-6。 |
| A15 | answered | 整体平移等变残差低于 1e-6。 |
| A16 | answered | 污染后输出仍合法，但强污染会显著增大误差。 |
| A17 | answered | 匹配参数预算下，joint 略优于 independent。 |
| A18 | answered | fixed 略优于 shared；shared 可作为变样本量替代。 |
| A19 | answered | 聚合误差通常随 n 改善，但单参数点和远外推不保证单调。 |

A4/A8 的 `partial` 是已识别的证据边界，不是未完成的任务。若主研究不依赖逐特征归因或跨任意架构的普适性，就没有必要为改变标签追加大型消融。
