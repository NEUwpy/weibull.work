## 一、协议目标与边界

本协议服务于前置研究 A 的 19 个必答问题，目标是选出可供 Study/02 主研究使用的 NN 参数估计基线，并说明其适用边界，而不是预设 NN 优于传统方法。

- 分布：三参数 Weibull，可靠度寿命为 \(x_R=\gamma+\eta(-\log R)^{1/\beta}\)。
- 样本：完整、独立同分布的小样本。
- 任务：由寿命样本估计 \((\beta,\eta,\gamma)\)。
- 数据角色：仿真数据检验统计性质；真实寿命数据只检验外部工程表现，不把完整真实样本估计值当成真参数。
- 排除：删失、截断；计算速度不作为独立研究问题。
- 当前主输出仍是三参数点估计及可信性信息；\(x_{0.95}\) 只作工程相关次要指标，不在研究 A 中改成训练主目标。
- 所有优劣结论必须带参数空间、样本量、数据角色和失败口径。

## 二、G2 设计选择

### 2.1 比较过的三种路线

1. **旧论文离散网格重建**：最接近已有脚本，但随机行切分会混入相同参数组合，参数范围先验也无法单独识别。只保留为 `Yang-style reconstruction` 历史对照。
2. **固定全因子网格**：解释简单，但网格边界效应强、训练样本重复且难代表连续工程参数空间。只用于边界切片和传统方法可视化。
3. **连续参数设计 + 参数组合留出 + 等变参数化**：能直接回答 A3、A6、A13、A14、A15，并降低单位与位置选择造成的伪差异。冻结为 Study/02 主方案。

用户已授权在既定 19 问和持续目标内自主推进；本选择不改变研究范围。旧实现只作为线索，不继承其结论。

### 2.2 参数化与参数空间

用 \(\rho=\gamma/\eta\) 表示相对位置。参数点由 scrambled Sobol 序列在变换空间中生成，并保存点表与 seed；同一参数点可生成多次 MC 样本，但不得跨数据角色复用。

| 层 | \(\beta\) | \(\eta\) | \(\rho=\gamma/\eta\) | 用途 |
|----|-------------|------------|-------------------------|------|
| core | log-uniform `[1.2, 4.0]` | log-uniform `[100, 10000]` | uniform `[0, 1]` | 模型选择与主结论 |
| boundary-low | log-uniform `[0.6, 1.2)` | 同 core | uniform `[0, 1]` | 低形状、MLE 非正则/无界风险 |
| boundary-high | log-uniform `(4.0, 8.0]` | 同 core | uniform `[0, 1]` | 训练范围上界外推 |
| location-stress | log-uniform `[1.2, 4.0]` | 同 core | uniform `[-0.5, 2.0]` | 位置边界与平移压力测试 |

core 主空间以疲劳寿命文献中 \(\beta\approx1-4\) 为锚点，同时避开 \(\beta=1\) 附近三参数 MLE 的特殊非正则性；该区域不被删除，而是作为独立 boundary-low 层透明报告。

正式 core 样本量为 `n={5,7,10,15,20}`。共享样本量模型另测未见插值 `n={6,8,12}` 与外推 `n={25,30,50}`。`n=30,50` 只用于 A3/A18/A19，不改变“小样本”为主的结论边界。

### 2.3 数据角色隔离

- 角色与隔离：training、validation、calibration、`confirmation` 各自使用独立 seed namespace 与互斥参数点表（独立 Sobol 点集，非逐行随机拆分；任何精确参数三元组不得跨角色出现）。
- validation 只做超参数、特征和模型选择；calibration 只用于 A12 的区间/风险分数校准；`confirmation` 是精简路线的独立留出评估集，仅在相关模型/分析选择冻结后评估一次，为 19 个结论提供独立确认，不参与模型选择。
- formal 时期的 test namespaces **永久 sealed、永不触碰**；其“一次启封 / 启封台账 `artifacts/run_ledger.jsonl`”程序已随 formal 引擎冻结为只读历史，精简路线不执行、不新增记录。

## 三、输入、目标与模型候选

### 3.1 强制等变锚点

对 Study/02 主候选路线，每个样本定义位置锚点 \(a=\min x\)。尺度锚点优先取 \(s=Q_{0.75}-Q_{0.25}\)；若 IQR 为 0，则取 \(s=\max x-\min x\)；若 range 仍为 0，则把该常量样本标记为 `degenerate_sample`，不进入网络。该分支不引入依赖绝对位置或固定单位的 epsilon。主候选网络只读取 \(z_i=(x_i-a)/s\)，并预测

\[
\log\beta,\qquad \log(\eta/s),\qquad \log((a-\gamma)/s).
\]

反变换保证 \(\beta>0\)、\(\eta>0\)、\(\gamma<a\)。尺度变化 `x -> c*x (c>0)` 与平移 `x -> x+d` 在数学上保持等变；A14/A15 仍用数值回归测试验证浮点实现。

### 3.2 输入路线

| ID | 输入 | 角色 |
|----|------|------|
| H0-hsm / H0-kde | Yang 六个原始尺度特征 + n，两种 mode ID | 历史端到端重建；标准化/目标未知部分按本协议补全，不作输入因果归因 |
| H1 | Abbasi 五个原始尺度特征 + n | 历史端到端重建；不作输入因果归因 |
| F0eq-hsm / F0eq-kde | 在统一等变管线下抽取 Yang 对应信息组 | 与 V 的公平输入信息比较 |
| F1eq | 在统一等变管线下抽取 Abbasi 对应信息组 | 与 V 的公平输入信息比较 |
| F2 | 预冻结候选全集 | Study/02 等变特征路线 |
| V | 排序后的完整归一化样本值 | 固定 n 的样本值路线 |
| S | mask-aware DeepSets 对完整归一化样本建模，显式输入 n | 变样本量路线 |

F2 候选全集为：`n, max, mean, median, SD, CV, skewness, excess-kurtosis, Q10, Q25, Q75, Q90, IQR, MAD, half-sample-mode`。除 `n` 外均由 \(z\) 计算；常量 `min(z)=0` 不进入主模型。历史重建与统一管线归因不能混称为同一输入。quantile、SD、CV、skewness、kurtosis、HSM、KDE 网格和零分母规则全部以 `configs/A-g2-search-v1.json` 为准。候选特征必须在 training/validation 内用 group permutation、逐组消融和稳定选择判断；test 不参与删选。

### 3.3 网络与搜索预算

- MLP 候选宽度：`[64,32]`、`[128,64,32]`、`[256,128,64]`；激活 `ReLU` 或 `SiLU`；dropout `{0,0.1}`。
- DeepSets 候选：逐点编码宽度 `{32,64}`，sum/mean pooling 后接与 MLP 相同规模的头部。
- 优化器为 AdamW；学习率 `{3e-4,1e-3,3e-3}`，weight decay `{0,1e-4}`，batch `{128,512}`。
- 每条主要输入路线恰好使用 24 个 screening 配置：阶段 1 的 12 个固定架构，随后取 validation 前 4 个架构并各跑 3 个固定优化器配置。每个配置使用相同 3 个 screening seed，因此是 72 次实际训练；最终入选配置再用 10 个正式 seed。排序、平局规则和完整候选在 `configs/A-g2-search-v1.json` 冻结。
- 参数路线之间以相同候选配置数、训练样本预算与训练 seed 数比较；运行时间不是配额依据。
- 早停只看 validation，最大 500 epochs、patience 40、最少 50 epochs；保存最佳 validation checkpoint。

### 3.4 训练量与目标损失

A5 使用嵌套训练集规模 `{7000,25000,100000,400000}`；同一大训练池按确定性顺序取前缀，避免不同规模混入不同参数分布。

主要损失为三个训练集标准化后的变换目标的等权 Huber loss，`delta=1.0`。A7 比较：

1. 原始参数标准化 MSE（历史基线）；
2. 未标准化变换目标的等权 MSE；
3. 训练集标准化变换目标的等权 MSE；
4. 训练集标准化变换目标的等权 Huber（主候选）。

四个损失的精确定义见机器配置；标准化量只从 training 得到。联合三输出与三个独立网络使用相同输入、训练样本和总参数预算回答 A17：三个独立网络的参数总数选择同预算档中不超过联合模型 105% 且最接近的配置；若不存在则选最接近且不超过联合模型的配置。不得把三个独立网络的三倍参数量伪装成同容量比较。

## 四、传统方法池与准入

### 4.1 方法池

- 主方法池：MLE、MPS、WMLE、MDM(`offset=0.1`)、LRE。
- 扩展诊断池：MMLE、LSE、MM、PWM。
- 不纳入：Grey GM(1,1) 与 Bayesian 当前实现。前者不是通用三参数点估计基线，后者的先验与采样合同尚未固定；二者不能作为“传统方法”混入排名。
- CCM 未在仓库中实现且公开配置不足，只在文献审计中保留，不伪造实现。

### 4.2 实现准入门

进入 formal 排名的方法必须在 pilot 前通过：固定样本回归、有限输出、支持集合法性、确定性、支持域内尺度/平移回归和失败状态传播测试。每种方法先在 admission manifest 声明参数/样本支持域；只有支持域内合同决定 core 准入。变换后落到声明域外的条件记为 `out_of_declared_domain`，作为 A14/A15 的边界证据，不得因此把该方法从其支持域内的 core 排名整体删除。未通过支持域内合同者保留失败证据并标记 `implementation_not_admitted`，不得静默换成其他算法。准入判断只检查实现合同，不以结果好坏决定是否纳入。

所有传统方法与 NN 在 test 上共享同一份样本，使用配对比较。传统估计不得借用真参数、训练参数范围或 NN 输出。

## 五、评价指标与统计比较

### 5.1 主指标

逐样本归一化参数误差为

\[
e_\beta=(\hat\beta-\beta)/\beta,\quad e_\eta=(\hat\eta-\eta)/\eta,\quad e_\gamma=(\hat\gamma-\gamma)/\eta,
\]

复合参数损失为 \(L_{param}=\sqrt{(e_\beta^2+e_\eta^2+e_\gamma^2)/3}\)。

主报告同时给出三个分量的 Bias、SD、RMSE、MAE；不得只报复合分数。合法率/失败率与 `L_param` 并列为共同主结果。合法条件为有限值、\(\hat\beta>0\)、\(\hat\eta>0\)、\(\hat\gamma<\min x\) 且算法声明收敛。

### 5.2 失败口径与次要指标

- 条件指标：只在合法估计上计算，但必须与失败率并列。
- 无条件敏感性：失败样本的 `L_param` 预赋值 10，并以 2 和 5 作敏感性分析；不能把失败行删除后宣称优胜。
- 工程次要指标：\(x_{0.95}\) 的相对 Bias、RMSE、MAE；`R={0.90,0.99}` 只作跨分位点诊断，不参与研究 A 模型选择。
- A9：10 个训练 seed 的均值、SD、最差 seed、seed 方差占比和排序稳定性。
- A19：按 n 的趋势及单调违例比例，不要求每个有限样本点严格单调。

### 5.3 推断

- 差异以同参数点、同 MC 样本的配对差为单位。
- 95% CI 用按参数点聚类的 bootstrap（至少 2000 次）；NN 比较再把训练 seed 作为第二层重采样单位。
- 主结论报告效应量与 CI，不以单一 p 值裁决；同一问题内多重主比较使用 Holm 校正，探索性比较标记为 exploratory。
- “整体更好”要求：失败率差的 95% CI 上界不超过 1 个百分点，配对 `L_param` 改善的 95% CI 下界大于 0，且任一单参数 RMSE 的相对恶化 95% CI 上界不超过 5%。只改善某一个参数而不满足这些条件，只能写成该参数上的局部优势或权衡。

## 六、模块级实验

### A-E1 输入与特征（A1、A4）

历史层单独报告 H0-hsm、H0-kde、H1：按旧 100 格点的确定性 80/20 参数组合拆分训练/验证，共享 n 模型使用 7000 条训练行、2000 条验证行、固定历史 recipe 和 10 个正式 seed；该层只作诊断，不参与主基线选择。统一因果归因层比较 F0eq-hsm、F0eq-kde、F1eq、F2、V，并在固定 n 上保持训练量、目标、输出约束与搜索预算相同。F2 的特征作用用分组消融、group permutation 和跨 seed 稳定选择三种证据；单一相关系数不能回答“有用”。

### A-E2 训练数据与参数空间（A5、A6、A13）

- 训练量使用四级嵌套规模并绘制 learning curve；若相邻两级 `L_param` 改善小于 2% 且 CI 跨 0，记为当前空间内平台期。
- 比较 `legacy_grid`、`core_continuous` 和 `extended_wide` 三个机器配置中冻结的训练分布；三者使用相同训练行数和搜索预算。
- A13 的 `range-clipped traditional oracle` 只处理原本有限且 \(\hat\eta>0\) 的传统估计：\(\beta_c=clip(\hat\beta,1.2,4)\)，\(\eta_c=clip(\hat\eta,100,10000)\)，\(\rho_c=clip(\hat\gamma/\hat\eta,0,1)\)，\(\gamma_c=\rho_c\eta_c\)。原始失败保持失败。它不是可部署方法，只量化“知道 core 范围”本身能带来多少收益。

### A-E3 目标与模型形式（A7、A8、A17、A18）

比较四类损失、三档 MLP、联合/独立输出、固定 n 专用模型与共享 DeepSets。主模型选择用 validation 的失败惩罚 `L_param`，test 只评价一次。

### A-E4 方法表现与泛化（A2、A3、A9、A19）

分别报告 core、未见 core 参数点、boundary-low、boundary-high、location-stress，以及未见 n。不得把外推层与 core 汇总成一个“总体更好”。

### A-E5 合法性、等变性与稳健性（A10、A14、A15、A16）

- 数值等变测试：缩放 `c={1e-3,1e3}`；平移 `d={-0.5*eta,0.5*eta,5*eta}`；NN 主参数化的相对残差容限 `1e-6`，传统方法按各自数值误差另报。
- 异常值：每个干净 test 样本配对生成高端乘性异常 `x_max <- a+{3,10}(x_max-a)`、低端异常 `x_min <- a-0.5*IQR`，以及 10% 双侧污染。报告相对干净样本的误差增量和合法率变化。
- 鲁棒预处理/特征路线只作为预注册敏感性分析，不用污染 test 重新选模型。

### A-E6 可信度与真实数据（A11、A12）

- A12：10-seed deep ensemble + split conformal，在 calibration 上校准变换参数的 90%/95% 区间；test 报 marginal coverage、按 n/参数层 coverage、标准化宽度和 selective-risk curve。calibration 不参与点模型选择。
- A11 主数据：NIST 6061-T6 aluminum fatigue-life data，101 个完整失效寿命，单位为千循环。每次只用 `n={5,7,10,15,20}` 的小样本估计，剩余观测作留出评价；500 个预冻结拆分。
- 真实数据主指标：留出经验 CDF 距离；次要指标为留出 CRPS/分位点差、支持集违规和配对胜率。完整 101 点的拟合参数只作辅助描述，不称为真值。
- Yang 2025 的 6A02、140 MPa、15 点数据只有在取得可再分发的原始数值与来源许可后作外部复核；缺失不阻塞 A11。

NIST 来源：<https://www.itl.nist.gov/div898/handbook/eda/section4/eda4291.htm>。

### 7.2 Pilot 与停止

每模块先运行 32 个参数点 × 4 重复 × 2 个 n 的 pilot。pilot 只检查：数据角色互斥、字段/哈希、数值合法性、方法准入、运行时间/磁盘估计和明显实现错误。pilot 不回答研究问题。

formal 启动后不按结果优劣提前停止。仅在以下情况停止并留痕：数据角色泄漏、配置哈希不符、实现合同失败、资源预测超过可用磁盘的 80%、或数值错误导致某预注册方法无法产生任何合法输出。修复后必须新 run ID，不覆盖旧产物。
