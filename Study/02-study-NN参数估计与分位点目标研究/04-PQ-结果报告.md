## 0iid. 同分布主协议（iid-v1）主效应结果（S1，2026-08-07 封存）

> 主实验回答：训练与测试覆盖相同参数组合（180/60/60 repeat 分层五折）时，目标分位点损失 Q
> 相对直接参数精度损失 P，在目标分位点 \(x_{0.95}\) 相对 RMSE 上的表现。estimand 为超总体
> 模型级配对差值 Δ\*；有限估计 = 5 fold × 3 seed × 4 n × 2 route = 120 个配对 fit 的
> 模型级差值等权均值（hat_Δ），主区间 = fold×seed 交叉 bootstrap（B=200,000）的设计级经验
> 不确定性近似（覆盖限制见下）。证据 `artifacts/pq_iid_main/`；结果 tip `5a90f1f7`。

**结论（同分布目标）：Q（目标分位点损失）优于 P（参数精度损失），hat_Δ 95% CI 不含 0。**

- pooled P rRMSE = **0.1663**，Q rRMSE = **0.1611**（144,000 held-out 配对样本）；
- **hat_Δ（Q−P，平方误差空间）= −0.00171**，95% fold×seed 交叉 CI **[−0.00225, −0.00119]**
  （不含 0，负值 = Q 更优）；
- **效应量（分母显式）**：`rel_change = (rRMSE_Q − rRMSE_P) / rRMSE_P = −3.1%`（负 = Q 更优，
  论文主描述）；`q_improvement_vs_p = (rRMSE_P − rRMSE_Q) / rRMSE_P = +3.1%`（描述性）。
- **按 n**：n=7 −0.00268 [−0.00402, −0.00158]、n=10 −0.00250 [−0.00391, −0.00117]、
  n=15 −0.00108 [−0.00197, −0.00028]、n=20 −0.00057 [−0.00075, −0.00041] —— **4 个 n 的 CI
  全部不含 0**，方向全部 Q 更优。
- **按 seed（描述）**：42 −0.00149、2026 −0.00174、3407 −0.00189（全部 Q 更优）。
- **按 fold（描述）**：fold1 −0.00225 … fold5 −0.00195（全部 Q 更优）。
- **按区域（描述，by_region.csv）**：方向存在翻转 —— 低 β（1.5–3.0）与低 γ/η（0.1–0.25）为
  Q 更优（β=1.5 −0.01464、γ/η=0.1 −0.01394，且 26/32 cell 为 Q 更优）；高 β（3.5–5.0）与
  高 γ/η（0.5–1.0）为 **P 更优**（β=5.0 +0.00147、γ/η=0.5 +0.00546）。pooled 的 Q 优势由低
  β、低 γ/η 区域驱动；区域方向仅描述性，不作主推断。
- **失败 0/120；支撑违规 0；非有限 0；非法 0；NaN 0**（120 fits 全部明确终态，总运行 1224 s，
  均 10.2 s/fit）。
- **独立复算**：`verify_iid.py` 从 saved evidence 独立重算 pooled rRMSE / rel_change /
  hat_Δ / 95% CI / 按 n，**hat_Δ 与 CI 逐位一致**（rRMSE 差为 float32 累加伪影 ~1e-8 rel）；
  SHA256SUMS 249 项全验（`git archive HEAD` 干净副本）。

**与 r4 OOD 的对照（不合并为单一主张）**：同一数据、同一网络、同一配对控制下，**同分布**
主问题 Q 更优（−3.1%，CI 不含 0）；**跨 gamma 外推**（r4）P 更优（8.1%）。两者测量不同
问题（同分布准确 vs 未见 gamma 层级外推），须分开表述，不互相推翻。

**覆盖限制（协议内显式，`summary_iid.json`）**：训练折重叠（每个 repeat 在 5 折中的 3 折
训练）、仅 3 个训练 seed（seed 维度严重欠采样）、设计级 bootstrap 只重采样单元均值（单元内
逐样本 MC 噪声被吸收）。区域方向翻转（高 β/高 γ/η 为 P 更优）为描述性观察；其机制解释见
下述 §0iid-S2。

## 0iid-S2. 机制解释（S2，2026-08-07；`10-PQ-作用机制分析.md`）

S2 复用 S1 封存证据（未重训任何 fit）做逐样本机制分解，对区域反转给出**更尖锐的解读**：

- **Q 的 pooled 增益来自「沿等分位点曲面的非线性补偿」，而非一阶投影**：P 的参数误差小
  （u_norm 0.23）且一阶投影解释实际误差的 98.9%（R²=0.989）；Q 的参数误差大 ~39×
  （u_norm 9.13，β̂/β 中位 6.9、η̂/η 中位 0.06），一阶投影灾难性高估（rms_proj 6.37，
  R²=−1556），但非线性余项与之近完全反相抵消（corr(proj,rem)=−0.9995），净剩
  rms_actual 0.1611。
- **区域反转 = 曲面曲率随 β、γ/η 的消长**：低 β/低 γ/η 处 x 对参数敏感、等分位点曲面曲率
  大，Q 的曲率补偿压过 P 的小误差一阶路线；高 β（`a^{1/β}→1`）/高 γ/η（γ 项主导）处曲面
  趋于平直，补偿空间缩小，P 反超。机制 `delta_rms_actual` 与封存 S1 `s1_mean_diff` 的
  符号翻转复现 **17/17** 区域 bin；n 从不翻转（曲面形状与 n 无关）。
- **已排除的朴素解释**：一阶投影更小（否，R²=−1556）、分量抵消指数（否，Q pooled 略低）、
  单纯垂直性（否，Q 最垂直的 γ/η=1.0 区域反而是 P 更优）。
- 该解读为观察性/描述性，分解本身不证明因果；不做逐 cell 显著性主张。完整方法、公式、
  表与限制见 `10-PQ-作用机制分析.md`。

## 0. 结论（仅限跨 gamma 外推）

> 在完全相同的数据、三参数 Weibull 输出网络、容量、初始化、训练预算、划分与训练程序下，
> 仅改变训练目标。r4 恢复 **approved direct-P**（`((β̂-β)/β)² + ((η̂-η)/η)² + ((γ̂-γ)/η)²`），
> 与 Q（目标分位点损失）在同一共享、结构性支撑合法、domain-explicit 解码器下比较。

**Pooled（三 seed，144,000 held-out 配对观测；主推断 = fold×seed 交叉 200,000 次）：
P（参数精度损失）在 \(x_{0.95}\) 相对 RMSE 上优于 Q（目标分位点损失）**。

- pooled P rRMSE = **0.2008**，Q rRMSE = **0.2184**；
- 主推断模型级配对差值（Q−P，平方误差空间）= **+0.00738**，95% CI **[+0.00223, +0.01268]**
  （不包含 0，正值 = P 更优）；
- **效应量（分母显式，R4-03）**：`p_error_reduction_vs_q = (Q−P)/Q ≈ 8.1%`（P 相对 Q 的误差
  下降，论文主描述）；`q_error_excess_vs_p = (Q−P)/P ≈ 8.8%`（不同 estimand，仅附录）。
- **Q 解码器边界（R4-05）**：45/144,000 行 γ̂/min_x ≥ 0.9999（3 cell，Q 平方误差 ~0.08%），
  为 Q quantile-only 目标下的参数边界行为，非非法拟合；配对移除后方向不变（8.06%）。
  详见 §5.1。

**方向一致性（r4）**：P 更优在**所有分层一致成立**：
- **按 n**：n=7 −6.5%、n=10 −7.4%、n=15 −9.5%、n=20 −11.7%（全部 P 更优）；主推断 CI：
  n=7 [0.0001, 0.0197]（显著）；n=10/15/20 为正值但 CI 跨 0（方向一致，单元数有限）。
- **按 seed（描述）**：42 −10.5%、2026 −6.5%、3407 −7.1%（全部 P 更优）。
- **按 fold（描述）**：fold1 −5.9% … fold3 −12.8%（全部 P 更优）。
- **12 个 n×seed 组合方向全部 P 更优**。
- 失败 0/120；**支撑违规 0**；非有限 0；非法 0。

**一句话（r4）**：当测试完整留出训练中未见的 gamma/eta 层级时，直接参数精度损失 P 的
外推表现优于目标分位点损失 Q（pooled 约 8.1%）。该结果不能回答训练与测试覆盖相同参数
组合时，哪种损失的分位点估计更准确。

## 5. v2/P_loggap → r4 direct-P（如实报告；Codex R4-06 不过度因果归因）

| 项 | v2/P_loggap（sensitivity） | r4 direct-P（primary） |
|---|---|---|
| P 损失 | γ 项 = 平方 log-gap | **γ 项 = ((γ̂-γ)/η)²（approved direct）** |
| 共享解码器 | v2 exp-gap | **v3 domain-explicit（Codex 授权）** |
| pooled 方向 | Q 更优 10.4%（P 0.2403 / Q 0.2152） | **P 更优 8.1%（P 0.2008 / Q 0.2184）** |
| 结论 | Q 优于 P_loggap（在 v2 解码器下） | **P（direct-P）优于 Q（在 v3 解码器下）** |

**主张边界（R4-06）**：
- **有效 primary 主张**：在 r4/v3 内，单一共享解码器、其余控制全部固定，direct-P 优于 Q。
- **有效 sensitivity 主张**：在 v2 内（v2 exp-gap 解码器），Q 优于 P_loggap。
- **未识别**：跨版本反转的孤立原因，因为 v2→r4 **同时改了 P 损失与共享解码器**（Q 本身也
  从 0.2152 变为 0.2184）；"direct-P 恢复导致反转"只是跨合同描述性观察，不是隔离的损失效应。

v2/P_loggap 保留为 sensitivity 证据，不进入 r4 主结论；历史 R3 APPROVE（针对 v2）已被 r4
合同复核取代/撤回，不得视为对 r4 的批准。

## 7. 结论支持范围（r4）

**能支持**（冻结设计域内）：pooled 水平 P（direct-P）优于 Q 约 8.1%（主推断 CI 不含 0），
方向在 n/seed/fold 分层全部一致；n=7 显著，n=10/15/20 方向一致但不显著。

**不能支持**：P 普遍优于 Q 的跨域推广；Q 的单个参数估计准确（Q 以退化内部表示达到分位点
目标）；Q 对其他分位点/完整分布准确；跨单位/跨尺度泛化；真实/删失数据结论；3-seed 之外
的训练随机性。

**限制**：主推断设计单元 20 个（4 n × 5 fold），seed 3 个（描述性）；解码器依赖冻结正位置
域；n=10/15/20 分层 CI 跨 0。
