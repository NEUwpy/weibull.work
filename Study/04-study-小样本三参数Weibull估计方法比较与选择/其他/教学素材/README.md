# 教学素材

[样本与Weibull分布入门](样本与Weibull分布入门.html)是学习入口：每次只显示一个主题，依次理解样本与模型、PDF与CDF、三个参数、报告中的散点与拟合曲线。支持阈值面积联动、参数拖动，以及存档案例中样本量和方法切换。

[绘图位置为何随样本量变化](绘图位置为何随样本量变化.html)：解释寿命观测、样本绘图位置和真实CDF的区别。提供10→5点的简单演示，以及报告中随机删点路径474的50→7点演示；步骤③暂留旧纵坐标帮助追踪，步骤④按新样本重算。本页只供理解，不并入报告正文。

HTML含所需数据，可直接离线打开；原始路径来自`结果呈现/分析数据/嵌套样本拟合.csv`，源文件指纹嵌入页面，不重新抽样或估计。
