## 上篇结构与两幅图的职责

2026-10-23按审阅意见统一以下要求：

1. **开头先给路线与方法总览。** 总图展示几条估计路线，以及对应方法的位置与联系。方法标识统一为“简称＋中文名称＋年份”；作者信息在对照表独立列出，采用完整姓氏，不混用K–R等缩写。年份标明对应构造的文献年；已确认首提时才写首提年，泛称或尚未核实的时间统一写“待核”。具体版本与通用方法分开。
2. **总图承担导航。** 浅色色块标明路线，方法放在相应路线，跨路线组合在区域间连接；总图不展开各方法的公式推导。图题及箭头、颜色的统一图例置于图外。
3. **每条路线独立成节，固定两幅图。** 第一幅是核心机理图，用连续的图像解释样本信息怎样转成参数；不再在图底堆放各种方法的公式卡。
4. **第二幅是具体方法机理图。** 顶部先将第一幅的核心机理压缩为几个横向步骤，下方围绕这些步骤展开各方法。要看得出每种方法保留、替换或增添了哪个环节。
5. **用小图讲清差别。** 优先用数据点、密度或分布曲线、回归残差、概率间距、尺度散布、矩差、秩权重、标准化点列、联合密度峰或网络映射表现机制。分布匹配图中的两种回归方向和概率间距是可沿用的表达形式。
6. **公式只保留必要关系。** 可由图像解释的部分先画出来；公式用于定义对象、关键关系和必要条件，不以大段公式替代图像。统计关系路线尤须呈现特征、消元、理论关系和反演之间的图形过程。
7. **共同制图要求继续适用。** 图面无防御性备注和赘余讲解，横向高∶宽7∶16；英文及拉丁数学字形用Times New Roman，数学用LaTeX标准排版，draw.io源与SVG保持一致。

## 机制标识与关系读法

| 路线 | 第一图与第二图完全相同的主步骤 |

| 贝叶斯后验推断 | B1 构造后验 → B2 后验决策 |

**两幅图必须同名、同数、同序、同编号。** 第二幅图顶部仅压缩第一幅的图形细节，不能另拆、合并或替换主步骤。第一幅具体算例内部的概率点与候选分布、反解形状与恢复位置尺度、似然与先验等，只作为所属主区域内的无编号子过程。方法面板用同一编号标明其改变或采用的环节，不把数值求解另立为估计原理。

主步骤名称集中定义于[v2.2-路线步骤.py](v2.2-路线步骤.py)，生成器共同读取；两幅图每块主区域的XML属性`routeStep`和`stepLabel`记录同一编号及名称。五对图为07/01、08/02、09/03、10/04、11/05，分别应检出2、3、3、2、2个主区域。总图也读取同一名称表。

代表例子不规定整条路线的唯一算法流程。主图、机制细图与总图用一致的机制标识衔接，方法按实际对象和确定原则接入；参数消除等策略不单独决定归属。

总图保留原30项证据ID，细分为28项方法间关系和2项LSPF/LPF内部机制说明。实线、虚线和点划线分别区分有据的扩展／修正、数学联系与借用／组合；新增机制骨架及阶段连接另标，不能当作新增历史沿袭。金色标记继续对应本次七种实现。

## 三参数联合似然场的显示口径

图07固定一组示意样本，用三个参数轴表示候选参数位置，以相对似然R=exp(ℓ−ℓ★)的颜色和等值面表达函数值。L1在左侧交代样本与联合密度的构造，中央主体呈现整体三参数函数，L2对应数值最大化与参数输出。密度因子的逐个计算不再占据主图。

等值面由真实Weibull联合似然的三维网格采样和插值生成；各面使用draw.io原生内联stencil矢量多边形，源与预览共用顶点及透明度。坐标范围和归一化必须明确，数值路径来自同一个目标的实际迭代记录。窗内数值极大点只描述有限参数窗；相对似然等值面表示函数值，不自动解释为置信域或后验概率。公式、参数窗与样本保存在生成程序及数值核验记录中。

### 图07的数值示例与核验

固定样本n=24、NumPy随机种子7，由形状2.5、尺度3、位置2的Weibull模型生成。显示窗为β∈[1.2,4.2]、η∈[1.5,4.2]、γ∈[0.7,2.4]；三个坐标轴按各自范围线性缩放，轴交点对应三个下界。窗内最高已寻数值候选为(2.5541,2.9717,1.9670)，对数似然约−36.106113。该示例用于解释整体似然与联合最大化，不并入七法比较实验。

等值面R=0.25、0.60、0.85分别用蓝、绿、橙编码；两外层在显示窗处截断。41³网格以步长2提取等值面，共2521个原生三角面；网格边交点再依据真实联合似然精修，三角面内部仍为分片线性近似。红线连接同一目标的一次Nelder–Mead迭代中选出的实际记录点，完整记录保存在[数值核验](v2.0-07-联合似然数值核对.json)。多起点和全窗搜索用于核对数值候选，不作为唯一性或无约束全局MLE的证明。

除已有渲染环境外，联合参数场生成需要NumPy、SciPy和scikit-image；网格形状、参数次序、投影矩阵、等值面误差和迭代目标值均写入数值核验JSON。
