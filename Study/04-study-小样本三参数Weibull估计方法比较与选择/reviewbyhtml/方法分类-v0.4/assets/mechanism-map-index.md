# Study04 方法机制图 v1.1

本目录是报告上篇 v1.1 的当前机制图源文件，全部使用 draw.io 格式；`预览/` 保存由源图生成的静态 SVG，供报告和 HTML 审阅页直接阅读。

## 公式与字体

当前11张图统一使用LaTeX标准数学排版，英文、数字和拉丁数学变量使用Times New Roman，中文使用微软雅黑。draw.io保留可编辑数学源，SVG保留实际排好字形的矢量轮廓；分式、求和、上下标和帽号不以普通文字拼接。后续修改按[制图与公式排版规范](制图与公式排版规范.md)执行，并检查[排版核验记录](排版核验.json)及逐图预览。

## 信息处理流程

各路线先用带有观测、曲线、特征和反馈图像的流程解释基本原理，步骤编号保持清楚，供后续定位方法差异；机制细图再展开各方法的具体方程、关系和改动。曲线与图形均为原生draw.io对象，示意图不作为实验结果。

| 文件 | 处理逻辑 |
|---|---|
| `07-似然估计路线-信息处理流程.drawio` | 观测点 → 候选密度曲线上的高度 → 各点贡献组合 → 候选整体评分；标出四步改动位置 |
| `08-分布匹配路线-信息处理流程.drawio` | 以经验概率点、候选CDF、逐点偏离与总差异比较解释匹配骨架；其他评分在细图展开 |
| `09-统计关系反演路线-信息处理流程.drawio` | 以样本形态、位置尺度消元、样本与理论特征匹配、参数恢复解释统计关系反演 |

## 完整地图

`06-完整机理地图-五簇分类与方法关系.drawio` 在各区域入口展示统计对象和参数确定原则，区域内外以具体方法节点相连。实线箭头表示扩展／修正，虚线表示数学联系，点划线箭头表示局部借用／组合。金色节点为MLE、WMLE、K–R、Soman LSE、Park LRE、MDM和Cran MM七种比较实现。

可以沿Jacquelin→WMLE→形状修正、White→Soman、L矩→TL矩和LSPF→LPF读连续改进；沿K–R与Firth汇入DMMLE读两个来源的组合；沿LSPF→Yang迭代、WMLE→MVLE-H扩展和Park定位→Proposed+MLE2读具体步骤的借用。LSPF／LPF节点同时注明其使用的是不变统计量的联合密度最大化。

## 源文件与核对

`生成机制图.ps1`依次运行三个细图生成器（`生成似然细图.py`、`生成分布与统计细图.py`、`生成后验与学习细图.py`）、`生成路线流程图.py`、`生成完整机理地图.py`和预览生成器。路线流程入口调用`生成似然可视流程.py`、`生成分布统计可视流程.py`、`生成后验学习可视流程.py`。`细图绘制.py`提供可编辑节点、折线、公式框和连接对象；完整地图生成器逐条定义具体方法的关系。`生成预览图.py`从draw.io源生成SVG，按背景、连线、方法节点、关系标签的顺序绘制，并将箭头落在节点边缘。重新生成后应检查：

1. 五张流程图、五张细图与一张总图共11个`.drawio`文件均可解析；
2. 每个节点 ID 唯一，所有连线的 source/target 都存在；
3. 五类细图中，信息构造、关键方程和三参数恢复步骤清晰，曲线与残差示意含义准确；
4. 完整地图包含五个工作簇以及代表方法关系；
5. 当前报告使用 `预览/` 中的静态图；可编辑源仍保留为 `.drawio`，不在 HTML 审阅页中作为下载链接；
6. 关系线的标签说明是沿袭、数学联系、局部借用还是组合。

旧版机制图和 HTML 审阅材料已经移入 `其他/历史版本/reviewbyhtml-方法分类-v0.2/`，不作为 v1.1 的内容来源入口。
