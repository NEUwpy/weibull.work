## 机制标识与关系读法

| 路线 | 机制标识 |
|---|---|
| 似然构造与优化 | L1构造似然，L2最大化或相应修正。 |
| 分布关系匹配 | D1分布表示／概率结构，D2指定准则，D3据此确定参数。 |
| 统计特征关系匹配与反演 | S1选定特征，S2理论关系，S3匹配、求解或反演识别。 |
| 贝叶斯后验推断 | B1先验与似然形成后验，B2后验决策。 |
| 学习型参数映射 | N1跨样本训练映射，N2固定映射用于新样本。 |

代表例子不规定整条路线的唯一算法流程。主图、机制细图与总图用一致的机制标识衔接，方法按实际对象和确定原则接入；参数消除等策略不单独决定归属。

总图保留原30项证据ID，细分为28项方法间关系和2项LSPF/LPF内部机制说明。实线、虚线和点划线分别区分有据的扩展／修正、数学联系与借用／组合；新增机制骨架及阶段连接另标，不能当作新增历史沿袭。金色标记继续对应本次七种实现。

## 公式、生成与核验

全部公式采用LaTeX标准排版；英文、数字与拉丁数学变量使用Times New Roman，中文使用微软雅黑。draw.io保留可编辑数学源，SVG保留排好字形的矢量轮廓。规范见[制图与公式排版规范](制图与公式排版规范.md)。

运行本目录`生成机制图.ps1`，依次调用原生成器与预览管线。环境仍为Python/PyMuPDF、Node/KaTeX/Playwright、Chromium和本机字体；渲染链仍为LaTeX→MathML→矢量PDF→SVG。检查11个XML的ID、端点与边界，核对[排版记录](预览/排版核验.json)及逐图预览，再同步原HTML任务素材并实际刷新检查。
