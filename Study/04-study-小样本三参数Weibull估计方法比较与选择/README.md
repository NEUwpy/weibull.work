# Study04：小样本三参数Weibull参数估计方法的比较与选择

> 更新：2026-10-16。n=50已补齐，形成8个形状参数×5个样本量的完整网格，共40个条件、每条件1200次、48000组样本及336000条方法尝试。计算与数值核验完成，结果按参数保存为CSV；方法关系梳理与性能结论待分析。

## 报告场景

在可靠性会议的分会场3“装备寿命与可靠性评估”作报告，时长10—20分钟，按20分钟准备。报告人为魏鹏宇，单位为东北大学机械工程与自动化学院。

## 动机与目的

寿命试验受成本与周期限制，样本往往较少。现有三参数Weibull参数估计方法较多，提出背景、改进目的和适用场景各不相同，实际使用时需要知道怎样选择。

本报告希望形成两方面的贡献：

1. **理清方法之间的关系。** 在已有分类的基础上，进一步展示类内与跨类的方法联系，辨明不同名称背后的估计思路、共有构造及具体差别，让繁杂的方法形成容易理解的整体。
2. **给出统一条件下的系统比较。** 将所选方法放入共同的比较框架，在比单篇论文各自展示更系统的参数与样本条件下，独立考察估计精度、稳定性与异常估计风险，形成对适用条件和实际选用的整体认识。

最终希望回答：给定样本量，当使用者能预估形状参数的大致范围时，该怎样选方法；当缺少这类范围认识时，又该怎样选。

## 内容取向与参考

- 喜欢用大类和树状结构组织方法全貌，进一步展示归属、继承、修正、组合及共享构造等联系；需要时用交叉连线表达跨类关系，同时说明各方法面向的场景。
- 根据方法关系与研究问题选择比较对象。重点考察形状参数与样本量的变化，通过蒙特卡洛重复抽样展示估计结果的分布、误差与波动，并分析异常估计的原因及其对选用的影响。
- 当前先固定位置参数与尺度参数，只改变形状参数和样本量，控制研究规模；具体范围与旧材料采用规则在[实验设置](实验设置.md)维护。
- 让方法介绍、比较结果、异常分析与选择建议自然衔接，形成完整的报告逻辑。
- 分类与综述可参考师姐的会议成果：[181-004：Xiaoyu Yang等，2023 ISSSR](../../src/content/181-004-pdf原文.md)；结合[Research09](../../Research/09-Weibull参数估计方法谱系与比较基线/研究报告.md)及本次比较，形成自己的判断。
