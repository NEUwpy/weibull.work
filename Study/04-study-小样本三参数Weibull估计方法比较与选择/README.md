# Study04：小样本三参数Weibull参数估计方法的比较与选择

> 更新：2026-10-18。已分别保存[报告上（方法分类）v0.1](报告上（方法分类）-v0.1.md)与[报告下（方法对比）v0.2](报告下（方法对比）-v0.2.md)，各自维护讲稿及对应图表。现有文献的分类与关系梳理、40条件每条件1200次的七法比较及27张结果图已完成；下篇以n=50至7的RMSE玫瑰图引入方法差异，再用分布解释偏移与波动。方法总图与具体选法规则仍待完善。数值结果按参数保存为CSV，由Git忽略。

## 报告场景

在可靠性会议的分会场3“装备寿命与可靠性评估”作报告，时长10—20分钟，按20分钟准备。报告人为魏鹏宇，单位为东北大学机械工程与自动化学院。

## 动机与目的

寿命试验受成本与周期限制，样本往往较少。现有三参数Weibull参数估计方法较多，提出背景、改进目的和适用场景各不相同，实际使用时需要知道怎样选择。

本报告希望形成两方面的贡献：

1. **按原理分类，梳理文献之间的沿袭与联系。** 这是报告前半部分的中心：一方面根据参数估计方法的原理归纳类别，另一方面追溯相关文献如何承接、修改或组合已有研究，以及文献中方法构造之间的联系，帮助理解繁杂的方法及其来由。
2. **给出统一条件下的系统比较。** 将所选方法放入共同的比较框架，在比单篇论文各自展示更系统的参数与样本条件下，独立考察估计精度、稳定性与异常估计风险，形成对适用条件和实际选用的整体认识。

最终希望回答：给定样本量，当使用者能预估形状参数的大致范围时，该怎样选方法；当缺少这类范围认识时，又该怎样选。

## 内容取向与参考

- 喜欢用大类和树状结构组织方法全貌，进一步展示归属、继承、修正、组合及共享构造等联系；需要时用交叉连线表达跨类关系，同时说明各方法面向的场景。
- 根据方法关系与研究问题选择比较对象。重点考察形状参数与样本量的变化，通过蒙特卡洛重复抽样展示估计结果的分布、误差与波动，并分析异常估计的原因及其对选用的影响。
- 当前先固定位置参数与尺度参数，只改变形状参数和样本量，控制研究规模；具体范围与旧材料采用规则在[实验设置](实验设置.md)维护。
- 让方法介绍、比较结果、异常分析与选择建议自然衔接，形成完整的报告逻辑。
- 方法分类随底层原理与沿袭关系的梳理逐步调整；参考来源与具体梳理范式见[方法分类与沿袭关系](方法分类/README.md)。

## 后续方向与报告收尾

先完善现有比较、系统性偏移与异常风险的呈现，再推进分层选法：仅知道样本量n；知道n和β的大致范围；进一步利用实际样本中的可观测信息，研究AI自适应选法。最后一层属于后续研究，目前尚无已验证可用的自动选法。

报告末尾简要介绍[weibull.work](https://weibull.work)：平台仍在建设，提供已开放方法的计算、结果分析及部分过程展示，邀请同行试用。未来希望把根据样本选择方法、方法内部过程量优化与数值求解改进结合起来，寻求在给定信息、候选方法和评价目标下更适宜的估计结果。具体开放方法及实现版本以[项目状态](../../README.md#当前状态快照)为准；本次比较的七种实现与线上开放范围分别说明。
