# Study04：小样本三参数Weibull参数估计方法的比较与选择

## 报告场景

在可靠性会议的分会场3“装备寿命与可靠性评估”作报告，时长10—20分钟，按20分钟准备。报告人为魏鹏宇，单位为东北大学机械工程与自动化学院。上下两部分各按约10分钟组织。

## 背景与研究问题

寿命试验受成本与周期限制，实际可获得的样本往往有限。三参数Weibull估计方法较多，各自的提出背景、改进目的和验证条件不同，需要先理清构造与联系，再在统一条件下认识其性能。

本研究关注：**方法在构造上有哪些共性与差别；这些共性与差别在不同样本量和形状条件下体现为怎样的性能关系；其中哪些典型现象能够得到机制上的解释。**

整体研究链为：**方法机理与文献关系 → 组内及组间的代表性对照 → 性能的条件变化规律 → 典型现象的机制解释 → 评价与选择依据。**

性能比较是基础，性能规律是核心发现，典型现象的机制解释是研究深度，方法选择依据是应用落点。

## 上下两部分的联系

**上篇建立理解方法的依据。** 根据估计原理分类，结合文献与构造证据梳理沿袭、改进和组合关系，说明共同依据及关键差别。由此确定有比较意义的代表方法：组内比较构造的改动，组间比较不同估计依据。文献沿袭与数学联系分别核对。

**下篇考察这些关系怎样体现于性能。** 在统一条件下比较代表方法，沿n和β观察性能差距、误差表现及风险的变化。相近构造可能分化，不同路线也可能表现接近；由结果归纳共性与分歧，再用具体构造解释少数代表性现象。

现有七种固定实现可作为比较起点，按已核对的原理与构造关系组织组内及组间对照。代表方法的选择与对照关系在上篇说明，下篇从实验设置接续；后续是否补方法取决于研究问题。

上篇材料在[方法分类](方法分类/README.md)，现稿为[报告上v0.2](报告上（方法分类）-v0.2.md)；下篇现稿为[报告下v1.0](报告下（方法对比）-v1.0.md)。

## 下篇希望形成的认识

重点认识性能关系怎样随条件改变：差距是否扩大或缩小、优势是否保留，误差增长体现为怎样的波动、偏移或分布变化。具体方法用于支撑这些发现，叙述以少数重要的性能规律与现象组织。

先由比较建立事实，再提炼需要解释的现象，随后进入机制解释。规律的方向和子节名称由证据确定；图表形式在内容清楚后选择。

解释强度与证据对应：理论关系可直接推出的结论明确说明；诊断结果表述为支持某种机制参与；尚待验证的解释保留待核状态。共同的估计困难与方法间的响应差别分别理解，允许对典型现象作部分解释。

方法选择承接前面的发现。评价目标决定关注哪些误差，极端结果与失败带来风险取舍，参数条件的已知程度限制可采用的条件优势。应用部分据此讨论应优先关注哪些性能特征。

## 比较范围与后续方向

已有统一比较固定η=1000、γ=500，β取1.5—5的八个值，n取7、10、15、20、50，每条件1200组共同样本。数据、计算版本与统计约定以[实验设置](实验设置.md)为准。本轮变化的参数维度为β。

后续考虑利用样本自身的可观测信息辅助选择方法、优化过程量与求解。目前尚无已验证可用的自动选法。报告末尾简要介绍[weibull.work](https://weibull.work)，作为方法实现与研究成果的展示载体；开放范围以[项目状态](../../README.md#当前状态快照)为准。
