# Study04 方法机制图 v1.0

本目录是报告上篇 v1.0 的当前机制图源文件，全部使用 draw.io 格式；`预览/` 保存由源图生成的静态 SVG，供报告和 HTML 审阅页直接阅读。

## 五类机制图

| 文件 | 作用 |
|---|---|
| `01-似然估计路线-机制图.drawio` | 从观测密度、联合似然到修正方程、求解诊断 |
| `02-分布匹配路线-机制图.drawio` | 概率图、分布距离、概率间距和尺度一致性 |
| `03-统计关系反演路线-机制图.drawio` | 矩、PWM/L矩、次序统计量、枢轴和条件线性估计 |
| `04-后验推断路线-机制图.drawio` | 似然、先验、后验规则与后验计算 |
| `05-学习映射路线-机制图.drawio` | 训练样本、特征、损失、训练域和参数映射 |

每张图都按“样本信息 → 参数确定原则 → 参数输出 → 方法分支 → 实现与改进标签 → 解释边界”的结构绘制。横向改进不另立一级分类。

## 分类前后预览

## 完整地图

`06-完整机理地图-五簇分类与方法关系.drawio` 在各区域入口展示统计对象和参数确定原则，区域内外以具体方法节点相连。实线箭头表示扩展／修正，虚线表示数学联系，点划线箭头表示局部借用／组合。金色节点为MLE、WMLE、K–R、Soman LSE、Park LRE、MDM和Cran MM七种比较实现。

可以沿Jacquelin→WMLE→形状修正、White→Soman、L矩→TL矩和LSPF→LPF读连续改进；沿K–R与Firth汇入DMMLE读两个来源的组合；沿LSPF→Yang迭代、WMLE→MVLE-H扩展和Park定位→Proposed+MLE2读具体步骤的借用。LSPF／LPF节点同时注明其使用的是不变统计量的联合密度最大化。

## 源文件与核对

`生成机制图.ps1` 生成五类机制图并调用 `生成完整机理地图.py`；后者逐条定义具体方法的关系。`生成预览图.py` 从 draw.io 源生成 SVG，按背景、连线、方法节点、关系标签的顺序绘制，并将箭头落在节点边缘。重新生成后应检查：

1. 六个 `.drawio` 文件都能被 XML 解析；
2. 每个节点 ID 唯一，所有连线的 source/target 都存在；
3. 五类机制图各自包含信息、原则、输出、分支、标签和边界；
4. 完整地图包含五个工作簇以及代表方法关系；
5. 当前报告使用 `预览/` 中的静态图；可编辑源仍保留为 `.drawio`，不在 HTML 审阅页中作为下载链接；
6. 关系线的标签说明是沿袭、数学联系、局部借用还是组合。

旧版机制图和 HTML 审阅材料已经移入 `其他/历史版本/reviewbyhtml-方法分类-v0.2/`，不作为 v1.0 的内容来源入口。
