## 上篇要让听众形成什么认识

整场报告围绕“小样本三参数Weibull参数估计方法的比较与选择”展开，按约20分钟准备；上篇服务于约5—10分钟的方法地图，后篇在共同样本上比较代表实现。三参数分别描述形状、尺度和位置，未知位置又影响分布的支持边界。文献围绕不同统计构造、改进环节和使用条件形成了许多名称，需要先建立整体认识，再讨论它们的性能差异。

上篇希望把听众对一个个离散方法的认识，转成“有基本原理、有主要归属、能看到彼此联系”的地图。分类依据应比单纯罗列名称更严谨，每条路线又能用清晰语言说明：究竟利用什么样本信息，通过什么原则得到三个参数。进一步沿着方法之间的连线，理解哪些构造被保留、修改或组合，以及改进针对什么困难。

这一部分期待形成的价值，是在已有分类与文献基础上把估计依据及方法联系讲清楚。五条路线是当前报告的组织框架，每个方法保留一个主要位置，共享构造和跨路线联系继续用线表达。后验推断会使用似然，组合方法也会借用其他路线的步骤；这些联系属于地图需要呈现的内容。

讲完上篇，听众应能说明三件事：主要路线各按什么原理估计；典型方法在哪个环节改变了原有构造；本轮七种比较实现落在地图的什么位置、能够形成哪些构造对照。

## 当前报告的骨架与讲述逻辑

**方法很多且命名层次不同 → 回到估计依据进行归纳 → 先给五条路线的总览 → 逐条讲清共同机制和具体改动 → 回到完整地图读方法关系 → 定位七种比较实现 → 转入性能比较。**

下表对应当前v1.1的实际章节，记录各段讲什么、为什么放在这里，以及希望听众形成的认识。

| 对应章节 | 当前讲述内容 | 叙述目的与前后衔接 |
|---|---|---|
| 第1节：先看现有方法 | 用代表文献、方法名和主要构造的清单呈现已有方案，包括同名不同构造、同一方法的改进与组合。 | 先让听众感受到方法多、名称强调的层次不同，产生归纳这些方法的需要；引出“应根据什么分类”。 |
| 第2节：分类依据与结果 | 区分样本信息、参数确定原则、实现与改进；以前两者确定主要归属，给出五条路线及分类后的地图总览。 | 交代分类从何而来，让听众先获得整体方位，再进入各区域理解原理；跨类别联系从这里保留。 |
| 第3节：似然估计 | 固定观测，将各密度因子视为同一组参数的函数，逐点相乘形成联合似然并求最大值，再看似然项、估计方程和位置处理的变化。 | 讲清从观测到参数函数、再到估计值的完整机制，区分统计构造的变化与实现最大化的求解程序。 |
| 第4节：分布匹配 | 说明样本的分布表示与理论分布怎样形成可比较的关系，再介绍概率图、距离、概率间距和尺度一致性等分支。 | 让听众理解这一类共同在匹配什么，以及各方法改变了哪种表示、判据或恢复步骤，建立与似然路线的区别。 |
| 第5节：统计关系反演 | 从矩、分位数、次序统计量或不变统计量出发，接到理论关系，通过匹配、消元、反解或条件组合恢复参数。 | 展示由样本统计特征到参数的另一条基本路径；结合具体方法理解共享统计材料与不同确定原则的联系。 |
| 第6节：后验推断与学习映射 | 分别说明似然与先验形成后验后怎样给出估计，以及如何通过多组训练样本学习从样本特征到参数的映射。 | 补全三条经典路线之外的两种扩展范式，让听众理解新增信息或学习环节的作用，并保留它们与经典方法的联系。 |
| 第7节：完整机理地图 | 回到总图，沿代表性的扩展、修正、数学联系与组合路径读具体方法，例如二参数构造向WMLE扩展、K–R与Firth型修正汇入DMMLE。 | 将前面各区域的局部认识重新连成整体，使听众看到方法怎样发展、跨路线怎样借用；详细关系留在图和底稿中供阅读。 |
| 第8节：七种实现的位置 | 将MLE、WMLE、K–R单样本形式、Soman LSE、Park LRE、MDM-0.1和Cran MM放回三条经典路线，说明具体版本与构造对照。 | 从较完整的方法地图收束到本轮可比较的实现，解释比较对象的代表意义与覆盖范围。七种实现是比较样本，不能据此限定整个分类体系。 |
| 第9节：转入统一比较 | 将判据、信息利用、位置处理、参数恢复与约束等构造差别，转成后篇观察偏差、波动、异常和失败的角度。 | 给性能比较建立认识基础。具体差异和机制解释由后篇结果及相应证据支持。 |

## 图像怎样服务这条叙述

- **分类前的呈现**：当前第1节以方法与文献清单展示原先分散的名称和构造。分类后在第2节给总览，使听众看到这些材料怎样被组织起来；当前分类前的载体是表格。
- **路线原理图**：每条路线的主图要将同一份样本信息怎样转为参数估计连成一个整体机制。曲线、数据点、函数和连线应共同解释这条路线，不能把密度、求根、优化等独立知识图并排拼成“原理图”。
- **路线机制细图**：在基本机制已经清楚的基础上，展开代表方法修改了哪个数据、方程、目标或参数恢复环节，为之后解释方法差异提供接口。

## 分类问题的明确表述

本部分先不预设最终有多少类，而是对每个估计方法连续回答三个问题：

1. **利用样本中的什么信息？** 例如观测密度、累计概率及其间距、矩、次序统计量、概率图关系或样本特征。
2. **通过什么原则把这些信息转化为三个分布参数的估计值？** 例如最大化似然、最小化分布差异、匹配理论统计关系、反演枢轴关系或更新后验。
3. **实现与改进发生在哪里？** 例如加权、偏差修正、位置处理、约束、数值优化、交替求解和多种构造的组合。

一级归属主要依据前两个问题：一个方法首先放到它主要利用的信息和参数确定原则对应的区域。第三个问题作为横向标签记录，同一方法可以同时带有多个实现或改进标签。分类不要求所有方法在抽象意义上完全互斥，但要让每个方法有一个清楚的主要位置，跨类别的联系用连接线表达。

## 五条路线的分类框架

v1.1报告用五条路线组织方法地图，各路线以统计对象与参数确定原则区分，方法之间的沿袭、数学联系与组合落实到具体节点和步骤。

| 工作簇 | 一句话原理 | 当前代表范围 |
|---|---|---|
| **似然估计路线** | 固定观测，将各密度因子视为同一组参数的函数，构造联合似然并按最大化确定参数；变体修改似然项或估计方程。 | MLE、WMLE、修正似然、Cohen–Whitten MMLE、K–R MMLE、DMMLE、CMLE及罚似然；数值优化器仍按其实际目标归属。 |
| **分布匹配路线** | 比较理论分布与样本呈现的分布形态、概率图关系或概率间隔，选择二者最一致的参数。 | 概率图、LSE／WLSE、最小距离估计、MPS；概率间距作为该路线的一个分支，不单列一级。 |
| **统计关系反演路线** | 建立样本矩、分位数、次序统计量或其他统计特征与总体参数之间的理论关系，再匹配或反解参数。 | MM、PWM、L矩、TL矩、分位数与次序统计量方法；线性最小方差作为条件性估计量构造分支。 |
| **后验推断路线** | 将样本信息与参数先验结合形成后验分布，再按后验规则给出估计。 | Bayes、后验均值、后验中位数、MAP；与似然共享模型时用关系线连接。 |
| **学习映射路线** | 通过训练样本或模拟数据学习从样本特征到分布参数的估计函数。 | ANN、BPNN及直接学习参数映射；用于搜索既定目标的PSO、SA等不归入此路线。 |

三条经典路线构成地图主体，后验推断和学习映射放在侧面作为扩展估计范式。加权、偏差修正、位置处理、约束、数值优化、交替求解和混合估计不强行另立一级类别，而通过横向标签和关系线表示它们改变了哪个环节。灰色模型、LSPF／LPF及其他跨路线方法先按其实际信息和参数确定原则放置，再保留模型或组合标签。

## 中心思路

前半部分同时开展两条线的梳理：

1. **根据上述三个方面组织方法地图。** 先辨明方法使用的样本信息和参数确定原则，再记录实现与改进发生的环节；当前以五簇工作骨架作为报告入口，具体归属随文献核对调整。
2. **梳理文献之间的沿袭与联系。** 追溯一篇文献承接了哪些已有研究，具体借用了什么、修改了什么，以及不同文献中的方法有哪些构造或数学联系。引用、沿袭与构造联系分别核对，不能仅凭引用或原理相近就认定继承。

分类说明这些方法怎样归拢，文献关系说明它们怎样发展、彼此怎样联系；实现与改进标签补充每条路线具体改变了哪里。三者通过前述讲述骨架、路线图和完整地图共同呈现。报告的实际图示与口述仍在审阅中调整。

## 梳理范式

对每个具体方法及其相关文献回答六个问题：

1. **针对什么困难与场景？** 说明要解决的问题，记录完整／删失等数据条件、参数范围和样本量；分别注明理论成立条件、作者实验范围与使用建议，未交代的留明。
2. **利用什么信息？** 从样本中提取观测密度、概率量、矩、次序统计量、概率图关系或其他可观测特征中的哪些信息。
3. **按什么原则确定参数？** 用什么目标、方程、匹配关系或后验规则把这些信息转成三个参数的估计值，尤其怎样处理未知位置参数。
4. **实现与改进改了哪里？** 明确加权、偏差修正、约束、位置处理、数值求解和组合步骤的作用；区分统计构造的改变与计算过程的改变。
5. **继承了什么？** 承接哪个已有方法的思想、公式或估计步骤，文献或构造依据是什么。
6. **与其他方法是什么关系？** 按具体内容注明关系类型，不由名称相近或分类相同推定沿袭。

关系类型按需要使用：**沿袭／扩展、局部借鉴、组合、共享构造、数学特例／等价／单调对应、计算工具的作用**。数学联系须写成立条件和联系对象，不能将评分对应自动扩大为估计器等价。同名异构、异名同指另作名称辨析，不作为发展箭头。

**论文之间的引用是关系证据的一部分。** 核对正文及参考文献表，记录“哪篇引用哪篇、被引文献编号或作者年份、正文位置及上下文”，说明属于背景介绍、比较评价、问题批评，还是明确采用、扩展或组合。涉及承接时，再定位借用的公式、假设或估计步骤。经综述转述的标明转述来源及原文是否核对；仅在参考文献表发现的，注明正文用途待核。

引用关系与沿袭判断分别记录：既有引用且明确承接的，可据此确认具体来源；仅引用不自动认定继承，未引用也不能据此认定独立。作者明示的关系与本研究通过构造比较得到的联系要标清。引用方向是“后文引用前文”，沿袭方向通常是“前方法发展为后方法”。

每条关系简记**关系类型、证据来源、核对状态**：来源写作者明示、原文构造对照、本研究推导或二手转述；状态写已核实、部分核实或待核，并指出具体缺口。这些是不同维度，不排成统一的证据强弱等级；仅同名或同动机先保留为线索。

边梳理关系，边检验分类：底层信息利用和参数确定原则一致的方法可重新归并，同一名称下构造不同的方法应分清具体分支。关系由引用与构造证据判断，分类由三方面的原理归纳，两者不能互相充当证明。一个方法可有多个来源；跨路线联系发现时即记入同一条关系，扩展到另一条路线时继续补充。分类有实质调整时，在04工作稿简记理由。实现与改进不强行另立一级类别，而在方法卡片和关系图中作为横向标签保留。

## 内容、形式与制作的顺序

先确定方法的信息利用、参数确定原则和关系依据，再按本文件的讲述骨架制作图与口述稿。当前在已存档的v1.1基线上继续审阅，完成与否以相应反馈及存档记录为准。

原理图以结构为骨架，在关键节点嵌入少量曲线或公式，说明“利用了什么信息、依据什么原则确定参数、后续方法具体改了哪里”。五类机制图和完整机理地图均保留draw.io源文件；主要归属、实现标签、历史沿袭和数学联系分别标明。当前图中公式须使用LaTeX或等效标准数学排版，英文、数字和拉丁数学变量使用Times New Roman；具体规则与生成核验见[制图与公式排版规范](机制图-v1.1/制图与公式排版规范.md)。图示检查同时覆盖源文件结构、节点覆盖、连线含义、静态预览和文档链接；HTML 审阅页只展示预览图，draw.io 文件作为可编辑源保存。

本部分希望在现有文献范围内，理清方法的沿袭、改进与组合关系，解释不同名称背后的共同构造及关键差异。具体新增认识须与Yang、Research09已有内容对照后逐项说明；记录方式本身不作为创新结论。后续统一实验比较用于考察性能，不能代替沿袭关系的文献依据。
