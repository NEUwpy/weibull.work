## 梳理范式

对每个具体方法回答五个问题：

1. **针对什么困难与场景？** 说明要解决的问题，记录完整／删失等数据条件、参数范围和样本量；分别注明理论成立条件、作者实验范围与使用建议，未交代的留明。
2. **依据什么估计？** 使用什么样本信息、统计关系或估计准则，怎样确定三个参数，尤其是未知位置参数。
3. **继承了什么？** 承接哪个已有方法的思想、公式或估计步骤，文献或构造依据是什么。
4. **改变了什么？** 明确修改环节、作用及引入的限制；区分统计构造的改变与数值求解的改变。
5. **与其他方法是什么关系？** 按具体内容注明关系类型，不由名称相近或分类相同推定沿袭。

关系类型按需要使用：**沿袭／扩展、局部借鉴、组合、共享构造、数学特例／等价／单调对应、计算工具的作用**。数学联系须写成立条件和联系对象，不能将评分对应自动扩大为估计器等价。同名异构、异名同指另作名称辨析，不作为发展箭头。

**论文之间的引用是关系证据的一部分。** 核对正文及参考文献表，记录“哪篇引用哪篇、被引文献编号或作者年份、正文位置及上下文”，说明属于背景介绍、比较评价、问题批评，还是明确采用、扩展或组合。涉及承接时，再定位借用的公式、假设或估计步骤。经综述转述的标明转述来源及原文是否核对；仅在参考文献表发现的，注明正文用途待核。

引用关系与沿袭判断分别记录：既有引用且明确承接的，可据此确认具体来源；仅引用不自动认定继承，未引用也不能据此认定独立。作者明示的关系与本研究通过构造比较得到的联系要标清。引用方向是“后文引用前文”，沿袭方向通常是“前方法发展为后方法”。

每条关系简记**关系类型、证据来源、核对状态**：来源写作者明示、原文构造对照、本研究推导或二手转述；状态写已核实、部分核实或待核，并指出具体缺口。这些是不同维度，不排成统一的证据强弱等级；仅同名或同动机先保留为线索。

边梳理关系，边检验分类：底层原理一致的方法可重新归并，同一名称下构造不同的方法应分清具体分支。关系由引用与构造证据判断，分类由原理归纳，两者不能互相充当证明。一个方法可有多个来源；跨路线联系发现时即记入同一条关系，扩展到另一条路线时继续补充。分类有实质调整时，在04工作稿简记理由。

## 内容、形式与制作的顺序

先确定方法原理、关系依据与分类；再讨论以什么形式呈现；最后制作图、PPT与口述稿。当前先推进内容。
