## 梳理范式

对每个具体方法回答四个问题：

1. **依据什么估计？** 使用什么样本信息、统计关系或估计准则，怎样确定三个参数，尤其是未知位置参数。
2. **继承了什么？** 承接哪个已有方法的思想、公式或估计步骤，文献或构造依据是什么。
3. **改变了什么，为什么改变？** 明确修改环节、针对的问题、适用条件及引入的限制；区分统计构造的改变与数值求解的改变。
4. **与其他方法是什么关系？** 分别说明直接沿袭与改进、共享底层构造、不同路线的组合。原理相似本身不足以认定历史继承。

边梳理关系，边检验分类：底层原理一致的方法可重新归并，同一名称下构造不同的方法应分清具体分支。分类依据和层级可以随认识调整；组合方法可以跨类说明。类别数量在内容分析中逐步确定。

## 内容、形式与制作的顺序

先确定方法原理、关系依据、分类及比较对象的代表性；再讨论以什么形式呈现；最后制作图、PPT与口述稿。当前先推进内容。

本部分预期形成的贡献，是在已有分类基础上，系统梳理方法的沿袭、改进与组合关系，解释不同名称背后的共同构造及关键差异。后续统一实验比较用于考察性能，不能代替沿袭关系的文献依据。
