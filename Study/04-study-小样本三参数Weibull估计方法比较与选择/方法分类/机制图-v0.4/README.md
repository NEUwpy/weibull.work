# Study04 方法机制图 v0.4

本目录是报告上篇 v0.4 的当前机制图源文件，全部使用 draw.io 格式；`预览/` 保存由源图生成的静态 SVG，供报告和 HTML 审阅页直接阅读。

## 五类机制图

| 文件 | 作用 |
|---|---|
| `01-似然估计路线-机制图.drawio` | 从观测密度、联合似然到修正方程、求解诊断 |
| `02-分布匹配路线-机制图.drawio` | 概率图、分布距离、概率间距和尺度一致性 |
| `03-统计关系反演路线-机制图.drawio` | 矩、PWM/L矩、次序统计量、枢轴和条件线性估计 |
| `04-后验推断路线-机制图.drawio` | 似然、先验、后验规则与后验计算 |
| `05-学习映射路线-机制图.drawio` | 训练样本、特征、损失、训练域和参数映射 |

每张图都按“样本信息 → 参数确定原则 → 参数输出 → 方法分支 → 实现与改进标签 → 解释边界”的结构绘制。横向改进不另立一级分类。

## 分类前后预览

`预览/06-完整机理地图-五簇分类与方法关系.svg` 展示当前五簇分类后的完整地图，五张路线预览图与五个 draw.io 源文件一一对应；旧版七条主干预览仅作为历史对照保留。

## 完整地图

`06-完整机理地图-五簇分类与方法关系.drawio` 将五簇主要归属、代表方法、沿袭／扩展、数学联系、局部借用、组合节点和求解工具放在同一张图中。连线含义必须结合颜色和虚实线阅读，不能把共享构造自动解释为历史继承。

## 源文件与核对

`生成机制图.ps1` 是本目录的生成源。重新生成后应检查：

1. 六个 `.drawio` 文件都能被 XML 解析；
2. 每个节点 ID 唯一，所有连线的 source/target 都存在；
3. 五类机制图各自包含信息、原则、输出、分支、标签和边界；
4. 完整地图包含五个工作簇以及代表方法关系；
5. 当前报告使用 `预览/` 中的静态图；可编辑源仍保留为 `.drawio`，不在 HTML 审阅页中作为下载链接；
6. 关系线的标签说明是沿袭、数学联系、局部借用还是组合。

旧版机制图和 HTML 审阅材料已经移入 `其他/历史版本/reviewbyhtml-方法分类-v0.2/`，不作为 v0.4 的内容来源入口。
