参数估计方法 / MDM

最小差异法 MDM

固定位置γ时，让各观测反算出的伪尺度尽量一致；再按最小差异曲线的梯度与偏移δ确定位置，伪尺度均值给出η。

每个位置 γ 都对应一次形状寻优；位置判据与形状图显示同一个 γ。

 162          def profile_gradient(gamma):
 163              """Finite-difference derivative of the profiled sigma curve."""
 164              gamma = float(gamma)
 165              cache_key = gamma
 166              if cache_key in profile_gradient_cache:
 167                  return profile_gradient_cache[cache_key]
 168              t_min_float = float(t_min)
 169              scale = max(abs(t_min_float), 1.0)
 170              nominal_h = scale * 1e-5
 171              left_room = max(gamma, 0.0)
 172              right_room = max(t_min_float - gamma, 0.0)
 173
 174              if right_room <= 0:
 175                  return float("inf")
 176
 177              if gamma <= 0.0 or left_room <= nominal_h:
 178                  h = min(nominal_h, right_room * 0.25)
 179                  h = max(h, np.finfo(float).eps * scale)
 180                  gradient = (profile_sigma(gamma + h) - profile_sigma(gamma)) / h
 181                  profile_gradient_cache[cache_key] = float(gradient)
 182                  return profile_gradient_cache[cache_key]
 183
 184              if right_room <= nominal_h:
 185                  h = min(nominal_h, left_room * 0.25, right_room * 0.5)
 186                  h = max(h, np.finfo(float).eps * scale)
 187                  gradient = (profile_sigma(gamma) - profile_sigma(gamma - h)) / h
 188                  profile_gradient_cache[cache_key] = float(gradient)
 189                  return profile_gradient_cache[cache_key]
 190
 191              h = min(nominal_h, left_room * 0.25, right_room * 0.25)
 192              h = max(h, np.finfo(float).eps * scale)
 193              gradient = (profile_sigma(gamma + h) - profile_sigma(gamma - h)) / (2.0 * h)
 194              profile_gradient_cache[cache_key] = float(gradient)
 195              return profile_gradient_cache[cache_key]

  79      def _calculate_r2(self, beta, eta, gamma_val):
  80          """Helper to calculate R-squared for any method"""
  81          if gamma_val >= self.data[0]: return 0.0
  82

  88          # y = beta * x - beta * ln(eta)

  96          return 1 - (ss_res / ss_tot)
