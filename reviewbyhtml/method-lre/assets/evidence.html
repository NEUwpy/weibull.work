This implies that the plot of log $\left\{ { \bf \Phi } - \log ( 1 - p ) \right\}$ versus log $x _ { p }$ should be a straight line with slope $\left( \kappa \right)$ and intercept $\left( - \kappa \log \theta \right)$ when the data have the Weibull distribution. It is well known that $\operatorname { C o r } ( a X + b , c Y + d ) = \operatorname { C o r } ( X , Y )$ where a, b, c and d are constants. Thus, the correlation coeficient from the Weibull plot is independent of the parameters, κ and θ. Thus, this correlation is a pivotal quantity. We also note that the Weibull probability paper widely used in engineering reliability fields is based on this idea.

In practice, we need to estimate $p = F ( x _ { p } )$ with real data. Let $x _ { ( 1 ) } , x _ { ( 2 ) } , \ldots , x _ { ( n ) }$ denote the order statistics from the smallest and let $p _ { i } = \hat { F } ( x _ { ( i ) } )$ be the empirical CDF value at $\boldsymbol { x } _ { ( i ) }$ . This empirical CDF value, $p _ { i } .$ , is also called the plotting position which is an increasing step function jumping at $\boldsymbol { x } _ { ( i ) }$ . Several diferent versions of these plotting positions have been suggested in the literature. Due to Blom (1958) and Wilk and Gnanadesikan (1968), the two most popular plotting positions are $p _ { i } = ( i - 3 / 8 ) / ( n + 1 / 4 )$ for $n \leq 1 0$ and $p _ { i } = ( i - 1 / 2 ) / n$ for $n \geq 1 1$ , which are used in this paper.

The straightness of the Weibull plot can be used to assess the goodness of fit of the Weibull distribution (so-called Weibullness test). The sample correlation coeficient of the paired points can be used for a measure of the linear relationship between two variables. For the practical application of the correlation coeficient for this purpose, the reader is referred to Chen et al. (2009). Lipson and Sheth (1973) estimated $\mu$ by visually inspecting the Weibull plot and then comparing the location estimates which correspond to the corresponding correlations in the modified Weibull plot. Along the line of this method, we can estimate $\mu$ more accurately and objectively by maximizing the sample correlation from the Weibull plot. Replacing $x _ { i }$ by $x _ { i } - \mu$ in Equation (1), we can obtain the sample correlation as a function of $\mu$

$$
R (\mu) = \frac {\sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) (v _ {i} - \bar {v})}{\left[ \sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) ^ {2} \cdot \sum_ {i = 1} ^ {n} (v _ {i} - \bar {v}) ^ {2} \right] ^ {1 / 2}},\tag{2}
$$

where $u _ { i } ^ { * } = \log ( x _ { ( i ) } - \mu )$ and $\bar { u ^ { * } } = \sum u _ { i } ^ { * } / n$ . Thus, we have $\hat { \mu } = \arg \operatorname* { m a x } _ { \mu } R ( \mu )$

The function $R ( \mu )$ is continuous on $[ 0 , x _ { ( 1 ) } )$ . Diferentiating (2) with respect to $\mu ,$ we have

$$
\frac {d R (\mu)}{d \mu} = \frac {\sum_ {i = 1} ^ {n} (w _ {i} ^ {*} - \bar {w} ^ {*}) (v _ {i} - \bar {v}) \cdot \sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) ^ {2} - \sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) (v _ {i} - \bar {v}) \cdot \sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) (w _ {i} ^ {*} - \bar {w} ^ {*})}{\left[ \sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) ^ {2} \right] ^ {3 / 2} \cdot \left[ \sum_ {i = 1} ^ {n} (v _ {i} - \bar {v}) ^ {2} \right] ^ {1 / 2}},
$$

where $u _ { i } ^ { * } = \log ( x _ { ( i ) } - \mu )$ and $w _ { i } ^ { * } = ( - 1 ) / ( x _ { ( i ) } - \mu )$ . Thus, solving $d R ( \mu ) / d \mu = 0$ for $\mu$ is equivalent to solving $g ( \mu ) = 0$ for $\mu ,$ where

$$
g (\mu) = \frac {\sum_ {i = 1} ^ {n} (w _ {i} ^ {*} - \bar {w} ^ {*}) (v _ {i} - \bar {v})}{\sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) (v _ {i} - \bar {v})} - \frac {\sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) (w _ {i} ^ {*} - \bar {w} ^ {*})}{\sum_ {i = 1} ^ {n} (u _ {i} ^ {*} - \bar {u} ^ {*}) ^ {2}}.\tag{3}
$$

Thus, we can also estimate the location parameter more accurately by solving Equation (3) using a root search algorithm.
