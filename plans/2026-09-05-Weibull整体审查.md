## 结果、安全与运行问题

**F01：Git 跟踪了非占位 Moonshot 密钥。** [配置文件第 3 行](D:/weibull/src/app/api/chat/config.json:3)存在非空、非占位格式的 API key，`git ls-files --error-unmatch src/app/api/chat/config.json` 确认文件受版本控制。[聊天路由](D:/weibull/src/app/api/chat/route.ts:8)直接读取它并初始化客户端。报告没有复制密钥，也没有对外验证其有效性。若仍有效，仓库及相应构建上下文持有者能够使用该凭证。应轮换该密钥，改为服务端环境变量，并提交无密钥的配置模板；只删除当前值不能代替轮换。修复时验证无密钥环境的受控错误及部署注入，避免聊天模块启动崩溃。

**F02：文件读取接口缺少边界。** [文献接口](D:/weibull/src/app/api/content/route.ts:23)接受任意 `slug/type`，第 30–38 行直接拼接路径并返回文件；[算法接口](D:/weibull/src/app/api/algorithms/route.ts:14)也直接将 slug 拼为 Markdown 文件路径。路径分隔符和父目录段未被限制，规范化后的目标没有做允许目录检查。影响是服务可读范围内的其他 Markdown 可能被返回；固定 `.md` 后缀限制了文件类型，不能表述为任意类型文件均可读。本次没有探测线上或读取敏感目标。建议使用文献/算法索引白名单、type 枚举与规范化目录包含性校验；以合法请求及拒绝越界的本地测试验收。

**F03：结果分析页会在 API 失败后混入另一种估计。** [ResultAnalysisLab](D:/weibull/src/components/methods/ResultAnalysisLab.tsx:372)捕获网络或非成功响应后，用 `trueGamma` 调用前端回归，再于第 421–432 行进入当前方法统计。[方法页](D:/weibull/src/app/methods/[methodId]/page.tsx:736)实际使用该模块，MDM 结果分析已开放。这里的 trueGamma 是本轮模拟生成总体的位置参数，回退估计直接使用它，会人为消除回退行的位置估计误差；页面没有把它标为另一方法。这既是正确性问题，也违反统一后端模拟和指标规则。应委托共享后端模拟入口，保留方法身份、失败数和统计分母，禁止异常时默默换算法。该发现限于网页结果分析路径，不能据此断言正式论文产物受污染。

**F04：批量导出把失败写成零 Bias。** [main.py](D:/weibull/python/main.py:138)中 `_csv_cell` 将缺失估计、缺失误差转换为字符串零；[CSV 表头](D:/weibull/python/main.py:199)又没有收敛状态及失败原因。[批量行](D:/weibull/python/studies/common/simulation.py:129)没有携带 runner 的失败诊断。本地有界复现使用 PWM、n=7、重复 1 次：方法抛出 NotImplementedError，CSV 却正常返回全零估计及全零 Bias。后续取均值会把失败误认为零误差，且无法恢复失败率。应保留空值并增加状态/失败原因，核查旧 CSV 消费者兼容性。`/monte_carlo_simulate` JSON 保留空值及收敛字段；正式 experiment 三件套不经过该格式器，不在本发现的污染范围内。

**F05：样本数量被静默改变。** [WeibullBase](D:/weibull/python/base.py:28)直接过滤非正数；[runner](D:/weibull/python/studies/common/runner.py:70)检查有限性、数量和全等值，却未拒绝混入零/负值的输入。WMLE 本地数值核验中，10 个正数前加入 -2 和 0，仍报告收敛且结果与原 10 个数一致。用户提交 12 个观测，实际只估计 10 个，没有删值提示。应按当前正寿命产品合同明确拒绝非法观测；无需为此扩展负位置研究域。AI MDM selector 已经有正值校验，可作为现有一致性参照。

**F06：旧请求可能写入新样本。** [首页计算](D:/weibull/src/app/page.tsx:475)以 card 快照发请求，第 512 行回写时只比较 card id；[样本变更](D:/weibull/src/app/page.tsx:436)没有使旧请求失效。[样本输入框](D:/weibull/src/components/calculator/AnalysisCard.tsx:617)在计算时仍可编辑。批量路径第 413 行同样按当前下标配旧结果。因此等待期间更换样本/案例组，可能出现新样本配旧参数并标为 fit。置信来自静态异步流程，尚未做浏览器交互复现。建议每卡片记录请求版本及输入身份，变更输入后拒绝旧响应；批量结果按稳定数据源身份合并。可复用 AI MDM 详情页已有请求版本模式，不必引入全局状态库。

**F07：偏移量多选没有完整进入分片组合。** [GenericStudyViewer](D:/weibull/src/components/methods/shared/studies/GenericStudyViewer.tsx:414)取得额外参数所选数组，但第 429–432 行只使用 `vals[0]`。[MDM 方法页](D:/weibull/src/app/methods/[methodId]/page.tsx:758)明确将 offset 配为变量。多个值虽显示已选，只有首项参与数据加载和图表统计。建议让额外参数加入组合展开；至少用两个不同 offset 核对文件集合和呈现分组。增加后的请求量是原多选功能的真实成本，应做合理限制。

**F08：现场模拟占住异步服务线程。** [Monte Carlo handler](D:/weibull/python/main.py:228)为 async 函数，却在第 256 行同步执行重复计算；批量导出也先同步构造完整 CSV。[部署启动](D:/weibull/python/Dockerfile.backend:21)未设置多个 worker，请求的 n/rep 和批量组合缺少上界。50ms 有界 stub 核验中，计算结束后另一个协程才获得执行机会；未做压力测试，也未核验 NAS 外部限流。一项长模拟因而可以让同 worker 的其他计算等待。先设置工作量上限、有界并发并移出事件循环；只有实际负载需要时再引入任务队列。不能简单无限增加线程/进程，科学计算库的内存及线程竞争仍需控制。

**F09：注册能力不等于真实实现。** [registry](D:/weibull/python/methods/registry.py:24)将 PWM、GreyGM11、Bayesian 放进 IMPLEMENTED，但[pwm](D:/weibull/python/methods/pwm.py:5)、[grey_gm11](D:/weibull/python/methods/grey_gm11.py:5)、[bayesian](D:/weibull/python/methods/bayesian.py:5)均直接抛 NotImplementedError。README 后端表对应的勾选也过强。应将其与关联别名正确表达为未实现，解析阶段返回 501，而非计算阶段失败。计算器的独立建设门槛目前只开放 6 个方法，因此不是声称普通用户能从计算器选择全部空实现。
