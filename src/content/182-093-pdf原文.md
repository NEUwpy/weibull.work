# On the existence of the nonlinear weighted least squares estimate for a three-parameter Weibull distribution✩

Dragan Jukic´ ∗, Mirta Bensiˇ c, Rudolf Scitovski ´

Department of Mathematics, University of Osijek, Trg Ljudevita Gaja 6, HR-31 000 Osijek, Croatia

# Abstract

The problem of nonlinear weighted least squares fitting of the three-parameter Weibull distribution to the given data $( w _ { i } , t _ { i } , y _ { i } )$ , $i = 1 , \ldots , n$ , is considered. The part $w _ { i } ~ > ~ 0$ of the data stands for the data weights. It is shown that the best least squares estimate exists provided that the data satisfy just the following two natural conditions: (i) $0 < t _ { 1 } < t _ { 2 } < \cdots < t _ { n }$ and (ii) $0 < y _ { 1 } < y _ { 2 } < \cdot \cdot \cdot < y _ { n } < 1$ . To support this, an illustrative numerical example is given.

# 1. Introduction

In this paper we consider the nonlinear weighted least squares fitting problem for the three-parameter Weibull distribution (model)

$$
F (t; \alpha , \beta , \eta) = \left\{ \begin{array}{l l} 1 - \mathrm {e} ^ {- \left(\frac {t - \alpha}{\eta}\right) ^ {\beta}}, & t > \alpha \\ 0, & t \leq \alpha \end{array} \right. \tag {1}
$$

where $\alpha ~ \geq ~ 0$ is a location parameter, $\eta ~ > ~ 0$ the scale, and $\beta ~ > ~ 0$ the shape parameter (Weibull, 1951). The corresponding density function is given by

$$
f (t; \alpha , \beta , \eta) = \left\{ \begin{array}{l l} \frac {\beta}{\eta} \left(\frac {t - \alpha}{\eta}\right) ^ {\beta - 1} \mathrm {e} ^ {- \left(\frac {t - \alpha}{\eta}\right) ^ {\beta}} & t > \alpha \\ 0, & t \leq \alpha . \end{array} \right. \tag {2}
$$

If $\alpha = 0$ , the resulting distribution is called the two-parameter Weibull distribution. A nonnegative random variable T is said to follow the three-parameter Weibull distribution if its probability density function (PDF) and the cumulative distribution function (CDF) are given by (2) and (1), respectively. We refer the reader to an excellent survey book by Murthy et al. (2004), in which various Weibull models are classified into seven different groups.

Named in honour of its inventor Waloddi Weibull who introduced it for the first time in 1939 in connection with his studies on the strength of materials (see Weibull (1939)), this distribution is widely used as a model in reliability and lifetime studies (see Lawless (1982); Murthy et al. (2004); Nelson (1982)). There are many applications of the Weibull distribution in medicine, biology, agriculture, forestry and engineering sciences. In addition, the Weibull distribution has found applications as a trend curve in much applied research (see Banks (1994); Ross (1990); Seber and Wild (1989)). The reliability function $R ( t )$ and the hazard (instantaneous failure rate) function $h ( t )$ for the Weibull distribution are given by

$$
R (t; \alpha , \beta , \eta) = \mathrm {e} ^ {- (\frac {t - \alpha}{\eta}) ^ {\beta}}, \quad t > \alpha
$$

and

$$
h (t; \alpha , \beta , \eta) = \frac {f (t ; \alpha , \beta , \eta)}{1 - F (t ; \alpha , \beta , \eta)} = \frac {\beta}{\eta} \left(\frac {t - \alpha}{\eta}\right) ^ {\beta - 1}, t > \alpha .
$$

The Weibull distribution hazard function is monotone increasing if $\beta > 1$ , decreasing if $0 < \beta < 1$ , and constant for $\beta = 1$ . When $\beta = 1$ , the Weibull distribution reduces to an exponential distribution.

The most common way of estimating the parameters of the density function from the observed data is the maximum likelihood (ML) method. Assuming $n$ independent observations $t _ { 1 } , \ldots , t _ { n }$ from the density, the likelihood function of this sample is given by $\begin{array} { r } { L ( \pmb \theta ) = \prod _ { i = 1 } ^ { n } p ( t _ { i } ; \pmb \theta ) } \end{array}$ , where $p ( t ; \pmb \theta )$ is the underlying density. The maximum likelihood estimate (MLE) of parameters $\pmb \theta$ is the value $\hat { \pmb { \theta } }$ that maximizes the likelihood function. But MLE does not necessarily exist, and it is not necessarily unique. For the two-parameter Weibull distribution, the results of Pratt (1981) and Burridge (1981) guarantee the existence of a unique MLE. However, our focus of attention here is on the case when $\alpha$ is unknown. In this case many additional difficulties arise. For example, there is no standard MLE for any observation $t _ { 1 } , \ldots , t _ { n }$ from density (2) (see e.g. Lawless (1982)). In order to verify this, we may assume, without loss of generality, that $t _ { 1 } ~ = ~ \operatorname* { m i n } \{ t _ { 1 } , \dots , t _ { n } \}$ . Fix $\beta ~ \in ~ ( 0 , 1 )$ and $\eta ~ \in ~ ( 0 , \infty )$ . Then $f ( t _ { 1 } ; \alpha , \beta , \eta ) = ( \beta / \eta ) ( ( t _ { 1 } - \alpha ) / \eta ) ^ { \beta - 1 } \exp ( - ( ( t _ { 1 } - \alpha ) / \eta ) ^ { \beta } ) \to \infty$ as $\alpha  t _ { 1 }$ from the left, whereas if $t _ { i } > t _ { 1 }$ then f (ti ; α, β, η) = (β $\begin{array} { r } { \prime \eta ) ( ( t _ { i } - \alpha ) / \eta ) ^ { \beta - 1 } \exp ( - ( ( t _ { i } - \alpha ) / \eta ) ^ { \beta } ) \to ( \beta / \eta ) ( ( t _ { i } - t _ { 1 } ) / \eta ) ^ { \beta - 1 } \exp ( - ( ( t _ { i } - t _ { 1 } ) / \eta ) ^ { \beta } ) > 0 , } \end{array}$ and hence MLE does not exist. In the literature, considerable effort has been devoted to such difficulties with the maximum likelihood approach (Cheng and Iles, 1990; Smith and Naylor, 1987). There are several other statistical methods for estimating model parameters such as the method of moments, the method of percentiles and the Bayesian method. Unfortunately, none of these methods (excluding the Bayesian one) is appropriate for small data sets (see Lawless (1982); Murthy et al. (2004); Nelson (1982)).

A very popular method for parameter estimation is the least squares (LS) method. Numerical methods for solving the nonlinear LS problem are described in Dennis and Schnabel (1996); Gill et al. (1981). Before the iterative minimization of the sum of squares it is still necessary to ask whether the least squares estimate (LSE) exists. In the case of nonlinear LS problems it is still extremely difficult to answer this question (see Bates and Watts (1988); Bjorck¨ (1996); Demidenko (2006, 2000); Hadeler et al. (2007); Jukic´ et al. (2004, 1999)).

Surprisingly, in spite of the many papers on Weibull models, we have not managed to find any paper dealing with the existence problem for a solution to a nonlinear LS problem for the three-parametric Weibull distribution.

The structure of the paper is as follows. In Section 2 we present our main result (Theorem 1) which guarantees the existence of the LSE for the three-parametric Weibull distribution. An illustrative numerical example is given in Section 3. To avoid nonnecessary technicalities at an early stage, all proofs are given in Section 4.

# 2. The LS existence theorem

The LS method can be described as follows: Suppose we are given the data $( w _ { i } , t _ { i } , y _ { i } ) , i = 1 , \dots , n , n > 3$ , where

$$
0 <   t _ {1} <   t _ {2} <   \dots <   t _ {n} \tag {3}
$$

denote the values of the independent variable (observations of the nonnegative Weibull random variable $T$ ),

$$
0 <   y _ {1} <   y _ {2} <   \dots <   y _ {n} <   1 \tag {4}
$$

are the respective estimates of the empirical CDF and $w _ { i } ~ > ~ 0$ are the data weights which describe the assumed relative accuracy of the data. The unknown parameters $\alpha$ , $\beta$ and $\eta$ of function (1) have to be estimated by minimizing the functional

$$
\begin{array}{l} S (\alpha , \beta , \eta) = \sum_ {i = 1} ^ {n} w _ {i} [ F (t _ {i}; \alpha , \beta , \eta) - y _ {i} ] ^ {2} \\ = \sum_{\substack{i = 1\\ t_{i} <   \alpha}}^{n}w_{i}y_{i}^{2} + \sum_{\substack{i = 1\\ t_{i}\geq \alpha}}^{n}w_{i}\left[1 - \mathrm{e}^{-\left(\frac{t_{i} - \alpha}{\eta}\right)^{\beta}} - y_{i}\right]^{2} \\ \end{array}
$$

on the set $\mathcal { P } : = \big \{ ( \alpha , \beta , \eta ) \in \mathbb { R } ^ { 3 } : \alpha \ge 0 ; \beta , \eta > 0 \big \}$ . A point $( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) \in \mathcal { P }$ such that

$$
S (\alpha^ {\star}, \beta^ {\star}, \eta^ {\star}) = \inf  _ {(\alpha , \beta , \eta) \in \mathcal {P}} S (\alpha , \beta , \eta)
$$

is called the least squares estimate (LSE), if it exists (see Bjorck ¨ (1996); Gill et al. (1981); Ross (1990); Seber and Wild (1989)).

If the problem of weighted LS estimation for the Weibull distribution is considered, $y _ { i }$ comes from the empirical CDF and conditions (3) and (4) are natural. But, if the analogue LS estimation procedure is considered from the nonlinear regression curve fitting point of view, then there is no reason to expect that the conditions (3) and (4) are naturally fulfilled. The main result of this paper, which follows, can be applied in both cases.

Theorem 1. If the data $( w _ { i } , t _ { i } , y _ { i } )$ $( w _ { i } , t _ { i } , y _ { i } ) , i \ = \ 1 , \ldots , n , n \ > \ 3 ,$ $i = 1 , \ldots , n$ $n > 3$ , satisfy the conditions (3) and (4), then the LSE for the three-parametric Weibull distribution exists.

# 4. Proof of the theorem

Before starting the proof of Theorem 1, we need some preliminary results.

Lemma 2. $$

$$

$$
\Sigma_ {\theta} := \sum_ {t _ {i} <   \theta} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \theta} w _ {i} (y _ {i} - \bar {y} _ {\theta}) ^ {2}.
$$

Then,

(i) if $\mathbf { \nabla } \cdot \theta = t _ { n - 1 }$ , then there exists a point in $\mathcal { P }$ at which functional S attains a value equal to $\begin{array} { r } { \sum _ { t _ { n - 1 } } = \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } } \end{array}$

\bar {y} _ {t _ {k}} <   F (t _ {i}; \alpha (\beta), \beta , \eta (\beta)) <   y _ {i}, \quad \text {i f} \tau_ {l} <   t _ {i} \leq t _ {m}.
$$

Since $k \leq n - 2$ , there are at least two indices $i$ for which $t _ { i } ~ > ~ t _ { k }$ . Furthermore, since the sequence $\{ y _ { i } \} _ { i = 1 } ^ { n }$ is strictly increasing, the equality $y _ { i } = \bar { y } _ { t _ { k } }$ can hold for at most one index i. Hence, for every $\beta \in ( 0 , \beta _ { 0 } )$ , it follows from (11) that

$$
\sum_ {t _ {i} > t _ {k}} w _ {i} \left[ F (t _ {i}; \alpha (\beta), \beta , \eta (\beta)) - y _ {i} \right] ^ {2} <   \sum_ {i = k + 1} ^ {n} w _ {i} \left(y _ {i} - \bar {y} _ {t _ {k}}\right) ^ {2}.
$$

Therefore, for any such $\beta$ we have

$$
S (\alpha (\beta), \beta , \eta (\beta)) = \sum_ {i = 1} ^ {n} w _ {i} [ F (t _ {i}; \alpha (\beta), \beta , \eta (\beta)) - y _ {i} ] ^ {2}
$$

$$
\begin{array}{l} = \sum_ {t _ {i} <   t _ {k}} w _ {i} [ F (t _ {i}; \alpha (\beta), \beta , \eta (\beta)) - y _ {i} ] ^ {2} + \sum_ {t _ {i} > t _ {k}} w _ {i} [ F (t _ {i}; \alpha (\beta), \beta , \eta (\beta)) - y _ {i} ] ^ {2} \\ <   \sum_ {i = 1} ^ {k - 1} w _ {i} y _ {i} ^ {2} + \sum_ {i = k + 1} ^ {n} w _ {i} \left(y _ {i} - \bar {y} _ {l _ {k}}\right) ^ {2}. \tag {12} \\ \end{array}
$$

From (10) and (12) it follows that $S ( \alpha ( \beta ) , \beta , \eta ( \beta ) ) < { \varSigma } _ { \theta } .$ . If $\theta = 0$ , then $\mathcal { \Sigma } _ { 0 } > \mathcal { \Sigma } _ { t _ { 1 } / 2 }$

If $\theta \in ( t _ { n - 2 } , t _ { n - 1 } ) \cup ( t _ { n - 1 } , \infty )$ , then $\begin{array} { r } { \sum _ { \theta } > \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } = \sum _ { t _ { n - 1 } } . } \end{array}$ . As shown in the proof of claim (i), there exists a point in $\mathcal { P }$ at which functional $s$ attains the value $\textstyle \sum _ { t _ { n - 1 } }$ . This completes the proof. 

Proof of Theorem 1. Since functional $s$ is nonnegative, there exists $\begin{array} { r } { S ^ { \star } : = \operatorname* { i n f } _ { ( \alpha , \beta , \eta ) \in { \mathcal { P } } } S ( \alpha , \beta , \eta ) . } \end{array}$ . It should be shown that there exists a point $( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) \in \mathcal { P }$ such that $S ( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) = S ^ { \star }$ .

According to Lemma 2(i), there exists a point $( \alpha _ { 0 } , \beta _ { 0 } , \eta _ { 0 } ) \in \mathcal { P }$ such that $\begin{array} { r } { S ( \alpha _ { 0 } , \beta _ { 0 } , \eta _ { 0 } ) = \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } , } \end{array}$ . Therefore, $\begin{array} { r } { S ^ { \star } \le \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } } \end{array}$ . If $\begin{array} { r } { S ^ { \star } = \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } } \end{array}$ , to complete the proof it is enough to set $( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) = ( \alpha _ { 0 } , \beta _ { 0 } , \eta _ { 0 } )$ . Hence, we can further assume that

$$
S ^ {\star} <   \sum_ {i = 1} ^ {n - 2} w _ {i} y _ {i} ^ {2}. \tag {13}
$$

Let $( \alpha _ { k } , \beta _ { k } , \eta _ { k } )$ be a sequence in $\mathcal { P }$ , such that

$$
\begin{array}{l} S ^ {\star} = \lim  _ {k \rightarrow \infty} S (\alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \rightarrow \infty} \sum_ {i = 1} ^ {n} w _ {i} [ F (t _ {i}; \alpha_ {k}, \beta_ {k}, \eta_ {k}) - y _ {i} ] ^ {2} \\ = \lim  _ {k \rightarrow \infty} \left[ \sum_ {t _ {i} <   \alpha_ {k}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} \geq \alpha_ {k}} w _ {i} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}} - y _ {i}\right) ^ {2} \right]. \tag {14} \\ \end{array}
$$

Without loss of generality, in further consideration we may assume that sequences $( \alpha _ { k } )$ , $( \beta _ { k } )$ and $( \eta _ { k } )$ are monotone. This is possible because the sequence $( \alpha _ { k } , \beta _ { k } , \eta _ { k } )$ has a subsequence $( \alpha _ { l _ { k } } , \beta _ { l _ { k } } , \eta _ { l _ { k } } )$ , such that all its component sequences $( \alpha _ { l _ { k } } )$ , $( \beta _ { l _ { k } } )$ and $( \eta _ { l _ { k } } )$ ) are monotone; and since $\begin{array} { r l } { \mathrm { l i m } _ { k \to \infty } S ( \alpha _ { l _ { k } } , \beta _ { l _ { k } } , \eta _ { l _ { k } } ) } & { = } \end{array}$ $\begin{array} { r } { \operatorname* { l i m } _ { k \to \infty } S ( \alpha _ { k } , \beta _ { k } , \eta _ { k } ) = S ^ { \star } } \end{array}$ .

Since each monotone sequence of real numbers converges in the extended real number system $\bar { \mathbb { R } }$ , define

$$
\alpha^ {\star} := \lim  _ {k \rightarrow \infty} \alpha_ {k}, \quad \beta^ {\star} := \lim  _ {k \rightarrow \infty} \beta_ {k}, \quad \eta^ {\star} := \lim  _ {k \rightarrow \infty} \eta_ {k}.
$$

Note that $0 \leq \alpha ^ { \star }$ , $\beta ^ { \star }$ , $\eta ^ { \star } \leq \infty$ , because $( \alpha _ { k } , \beta _ { k } , \eta _ { k } ) \in \mathcal { P }$ .

To complete the proof it is enough to show that $( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) \in \mathcal { P }$ , i.e. that $0 \leq \alpha ^ { \star } < \infty$ and $\beta ^ { \star } , \eta ^ { \star } \in ( 0 , \infty )$ . The continuity of the functional $s$ will then imply that $\begin{array} { r } { S ^ { \star } = \operatorname* { l i m } _ { k \to \infty } S ( \alpha _ { k } , \beta _ { k } , \eta _ { k } ) = S ( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) } \end{array}$ .

It remains to show that $( \alpha ^ { \star } , \beta ^ { \star } , \eta ^ { \star } ) \in \mathcal { P }$ . The proof will be done in five steps. In step 1 we will show that $\alpha ^ { \star } \leq t _ { n - 2 }$ . In step 2 we will show that $\eta ^ { \star } \neq \infty$ . The proof that $\eta ^ { \star } \neq 0$ will be done in step 3. In step 4 we prove that $\beta ^ { \star } \neq \infty$ . Finally, in step 5 we show that $\beta ^ { \star } \neq 0$ .

Step 1. If $\alpha ^ { \star } > t _ { n - 2 }$ , from (14) it follows that $\begin{array} { r } { S ^ { \star } \geq \sum _ { i = 1 } ^ { n - 2 } w _ { i } y _ { i } ^ { 2 } } \end{array}$ , which contradicts assumption (13). Thus, we have proved that $\alpha ^ { \star } \leq t _ { n - 2 }$ .

By taking an appropriate subsequence of $( \alpha _ { k } , \beta _ { k } , \eta _ { k } )$ , if necessary, we may assume that if $t _ { i } < \alpha ^ { \star }$ , then $t _ { i } < \alpha _ { k }$ for every $k \in \mathbb N$ . Similarly, if $t _ { i } > \alpha ^ { \star }$ , we may assume that $t _ { i } > \alpha _ { k }$ for every $k \in \mathbb N$ . Due to this, now it is easy to show that from (14) it follows that

$$
S ^ {\star} \geq \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \lim  _ {k \rightarrow \infty} \left[ \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}} - y _ {i}\right) ^ {2} \right]. \tag {15}
$$

Step 2. Let us show that $\eta ^ { \star } \neq \infty$ . We prove this by contradiction. Suppose on the contrary that $\eta ^ { \star } = \infty$ . Then only one of the following two cases can occur: (i) $\eta ^ { \star } = \infty$ and $\beta ^ { \star } > 0$ or (ii) $\eta ^ { \star } = \infty$ and $\beta ^ { \star } = 0$ . Now, we are going to show that functional S cannot attain its infimum in either of these two cases, which will prove that $\eta ^ { \star } \neq \infty$ .

Case (i): $\eta ^ { \star } = \infty$ and $\beta ^ { \star } > 0$ . Since $\alpha ^ { \star } \leq t _ { n - 2 } < t _ { n }$ , in this case we would have

$$
\lim  _ {k \rightarrow \infty} F (t _ {i}; \alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \rightarrow \infty} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}}\right) = 0, \quad t _ {i} \geq \alpha^ {\star}
$$

and hence from (14) it would follow that

$$
S ^ {\star} = \lim  _ {k \rightarrow \infty} S (\alpha_ {k}, \beta_ {k}, \eta_ {k}) = \sum_ {i = 1} ^ {n} w _ {i} y _ {i} ^ {2} > \sum_ {i = 1} ^ {n - 2} w _ {i} y _ {i} ^ {2}
$$

which contradicts assumption (13).

Case (ii): $\eta ^ { \star } = \infty$ and $\beta ^ { \star } = 0$ . Since $\eta _ { k } \to \infty$ , for every sufficiently great $k \in \mathbb N$ , $0 < ( 1 / \eta _ { k } ) ^ { \beta _ { k } } < 1 .$ . This means that the sequence $( 1 / \eta _ { k } ) ^ { \beta _ { k } }$ is bounded. We may assume that it is convergent. Let $( 1 / \eta _ { k } ) ^ { \beta _ { k } }  L \in [ 0 , 1 ]$ . Since in this case we have

$$
\lim  _ {k \rightarrow \infty} F (t _ {i}; \alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \rightarrow \infty} \left(1 - \mathrm {e} ^ {- (\frac {1}{\eta_ {k}}) ^ {\beta_ {k}} (t _ {i} - \alpha_ {k}) ^ {\beta_ {k}}}\right) = 1 - \mathrm {e} ^ {- L}, \quad t _ {i} > \alpha^ {\star}
$$

and since the quadratic function $\begin{array} { r } { x \mapsto \sum _ { t _ { i } > \alpha ^ { \star } } w _ { i } ( x - y _ { i } ) ^ { 2 } } \end{array}$ attains its minimum $\begin{array} { r } { \sum _ { t _ { i } > \alpha ^ { \star } } w _ { i } ( \bar { y } _ { \alpha ^ { \star } } - y _ { i } ) ^ { 2 } } \end{array}$ at point $\begin{array} { r } { \bar { y } _ { \alpha ^ { \star } } = \sum _ { t _ { i } > \alpha ^ { \star } } w _ { i } y _ { i } / \sum _ { t _ { i } > \alpha ^ { \star } } w _ { i } } \end{array}$ , by using (15) we obtain

$$
\begin{array}{l} S ^ {\star} \geq \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} \left(1 - e ^ {- L} - y _ {i}\right) ^ {2} \\ \geq \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} (\bar {y} _ {\alpha^ {\star}} - y _ {i}) ^ {2} = \Sigma_ {\alpha^ {\star}}. \\ \end{array}
$$

Due to the fact that $\alpha ^ { \star } \leq t _ { n - 2 } < t _ { n - 1 }$ , according to Lemma 2(ii) there exists a point in $\mathcal { P }$ at which functional $s$ attains a value smaller than $\Sigma _ { \alpha ^ { \star } }$ . This means that in this case functional $s$ cannot attain its infimum.

Step 3. Now, we are going to show that $\eta ^ { \star } \neq 0$ . We prove this by contradiction. Suppose $\eta ^ { \star } = 0$ . Then, without loss of generality, we may assume that $1 / \eta _ { k } > 1$ for all $k \in \mathbb N$ . Since in that case $( 1 / \eta _ { k } ) ^ { \beta _ { k } } \ge 1$ , only one of the following can occur: (i) $\eta ^ { \star } = 0$ and $( 1 / \eta _ { k } ) ^ { \beta _ { k } }  \infty$ or (ii) $\eta ^ { \star } = 0$ and $( 1 / \eta _ { k } ) ^ { \beta _ { k } }  L \in [ 1 , \infty )$ . Let us show that functional $s$ cannot attain its infimum in either of these two cases, which will prove that $\eta ^ { \star } \neq 0$ .

Case (i): $\eta ^ { \star } = 0$ and $( 1 / \eta _ { k } ) ^ { \beta _ { k } }  \infty$ . In this case we have

$$
\lim  _ {k \rightarrow \infty} \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}} = \infty , \quad t _ {i} > \alpha^ {\star}
$$

and therefore

$$
\lim  _ {k \rightarrow \infty} F (t _ {i}; \alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \rightarrow \infty} \left(1 - e ^ {- \left(\frac {t - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}}\right) = 1, \quad t _ {i} > \alpha^ {\star}.
$$

Indeed, if $t _ { i } > \alpha ^ { \star }$ and $\beta ^ { \star } = 0$ , then

$$
\lim  _ {k \rightarrow \infty} \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}} = \lim  _ {k \rightarrow \infty} \left(\frac {1}{\eta_ {k}}\right) ^ {\beta_ {k}} (t _ {i} - \alpha_ {k}) ^ {\beta_ {k}} = \infty \cdot 1 = \infty .
$$

If $t _ { i } > \alpha ^ { \star }$ and $\beta ^ { \star } > 0$ , then obviously

$$
\lim _ {k \to \infty} \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}} = \infty .
$$

Case (ii): $\eta ^ { \star } = 0$ and $( 1 / \eta _ { k } ) ^ { \beta _ { k } }  L \in [ 1 , \infty )$ . In this case, sequence $( \beta _ { k } )$ must converge to 0, because by assumption $\eta _ { k }  0$ . Therefore,

$$
\lim  _ {k \rightarrow \infty} F (t _ {i}; \alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \rightarrow \infty} \left(1 - \mathrm {e} ^ {- (\frac {1}{\eta_ {k}}) ^ {\beta_ {k}} (t _ {i} - \alpha_ {k}) ^ {\beta_ {k}}}\right) = 1 - \mathrm {e} ^ {- L}, \quad t _ {i} > \alpha^ {\star}.
$$

Arguing now similarly to in case (ii) from step 2, in both cases we obtain

$$
S ^ {\star} \geq \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} (\bar {y} _ {\alpha^ {\star}} - y _ {i}) ^ {2} = \Sigma_ {\alpha^ {\star}}.
$$

As we have already shown that there exists a point in $\mathcal { P }$ at which functional $s$ attains a valuer smaller than $\Sigma _ { \alpha ^ { \star } }$ , this means that in this way $( \eta ^ { \star } = 0$ ) functional $s$ cannot attain its infimum.

So far, we have shown that $0 \leq \alpha ^ { \star } \leq t _ { n - 2 }$ and $0 < \eta ^ { \star } < \infty$ . By using this, in the next two steps we will show that $0 < \beta ^ { \star } < \infty$ .

Step 4. Let us show that $\beta ^ { \star } \neq \infty$ . To see this, suppose on the contrary that $\beta ^ { \star } = \infty$ . Then,

$$
\lim  _ {k \to \infty} F (t; \alpha_ {k}, \beta_ {k}, \eta_ {k}) = \lim  _ {k \to \infty} \left(1 - \mathrm {e} ^ {- \left(\frac {t - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}}\right) = \left\{ \begin{array}{l l} 0, & \text {i f} \alpha^ {\star} \leq t <   \alpha^ {\star} + \eta^ {\star} \\ 1, & \text {i f} t > \alpha^ {\star} + \eta^ {\star} \end{array} \right.
$$

so that from (15) it follows that

$$
\begin{array}{l} S ^ {\star} \geq \lim  _ {k \rightarrow \infty} \left[ \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {\alpha^ {\star} <   t _ {i} <   \alpha^ {\star} + \eta^ {\star}} w _ {i} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}} - y _ {i}\right) ^ {2} + \sum_ {t _ {i} > \alpha^ {\star} + \eta^ {\star}} w _ {i} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}} - y _ {i}\right) ^ {2} \right] \\ = \sum_ {t _ {i} <   \alpha^ {\star} + \eta^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star} + \eta^ {\star}} w _ {i} (1 - y _ {i}) ^ {2}. \\ \end{array}
$$

Arguing now like in case (ii) from step 2, it can be shown that

$$
S ^ {\star} \geq \sum_ {t _ {i} <   \alpha^ {\star} + \eta^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star} + \eta^ {\star}} w _ {i} (y _ {i} - \bar {y} _ {\alpha^ {\star} + \eta^ {\star}}) ^ {2} = \Sigma_ {\alpha^ {\star} + \eta^ {\star}},
$$

where $\begin{array} { r } { \bar { y } _ { \alpha ^ { \star } + \eta ^ { \star } } = \sum _ { t _ { i } > \alpha ^ { \star } + \eta ^ { \star } } w _ { i } y _ { i } / \sum _ { t _ { i } > \alpha ^ { \star } + \eta ^ { \star } } w _ { i } . } \end{array}$ . Due to assumption (13), $\alpha ^ { \star } + \eta ^ { \star } \ne t _ { n - 1 }$ . Hence, according to i Lemma 2(ii), there exists a point in $\mathcal { P }$ i at which functional $s$ attains a value smaller than $\Sigma _ { \alpha ^ { \star } + \eta ^ { \star } }$ . In this way $\beta ^ { \star } = \infty$ ) functional S cannot attain its infimum. Thus, we have proved that $\beta ^ { \star } < \infty$ .

Step 5. It remains to be shown that $\beta ^ { \star } \neq 0$ . If $\beta _ { k } \to 0$ , then by using (15) we would obtain

$$
\begin{array}{l} S ^ {\star} \geq \lim  _ {k \rightarrow \infty} \left[ \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} \left(1 - \mathrm {e} ^ {- \left(\frac {t _ {i} - \alpha_ {k}}{\eta_ {k}}\right) ^ {\beta_ {k}}} - y _ {i}\right) ^ {2} \right] \\ = \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} \left(1 - e ^ {- 1} - y _ {i}\right) ^ {2} \\ \geq \sum_ {t _ {i} <   \alpha^ {\star}} w _ {i} y _ {i} ^ {2} + \sum_ {t _ {i} > \alpha^ {\star}} w _ {i} (y _ {i} - \bar {y} _ {\alpha^ {\star}}) ^ {2} = \Sigma_ {\alpha^ {\star}}. \\ \end{array}
$$

According to Lemma 2(ii), in this way functional $s$ cannot attain its infimum. Thus, we have proved that $\beta ^ { \star } > 0$ and completed the proof. 

Remark 3. Given $1 \leq p < \infty$ , let

$$
S _ {p} (\alpha , \beta , \eta) = \sum_ {i = 1} ^ {n} w _ {i} | F (t _ {i}; \alpha , \beta , \eta) - y _ {i} | ^ {p}.
$$

Arguing like in the proofs of Lemma 2 and Theorem 1, it can be easily shown that there exists a point $( \alpha _ { p } ^ { \star } , \beta _ { p } ^ { \star } , \eta _ { p } ^ { \star } ) \in \mathcal { P }$ such that $\begin{array} { r } { S _ { p } ( \alpha _ { p } ^ { \star } , \beta _ { p } ^ { \star } , \eta _ { p } ^ { \star } ) = \operatorname* { i n f } _ { ( \alpha , \beta , \eta ) \in \mathcal { P } } S _ { p } ( \alpha , \beta , \eta ) } \end{array}$ .
