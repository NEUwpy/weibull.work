# 三参数Weibull分布非线性加权最小二乘估计的存在性✩

Dragan Jukić ∗, Mirta Benšić, Rudolf Scitovski

克罗地亚奥西耶克大学数学系,Trg Ljudevita Gaja 6, HR-31 000 Osijek, Croatia

2008年2月20日收到;2008年3月3日收到修订稿;2008年3月4日接受;2008年3月8日在线发布

# 摘要

本文研究了三参数Weibull分布对给定数据$(w_i, t_i, y_i)$,$i = 1, \ldots, n$的非线性加权最小二乘拟合问题。其中$w_i > 0$部分表示数据权重。研究表明,只要数据满足以下两个自然条件,最佳最小二乘估计就存在:(i) $0 < t_1 < t_2 < \cdots < t_n$和(ii) $0 < y_1 < y_2 < \cdots < y_n < 1$。为了支持这一结论,给出了一个说明性的数值算例。

# 1. 引言

本文研究三参数Weibull分布(模型)的非线性加权最小二乘拟合问题

$
F(t; \alpha, \beta, \eta) = \left\{ \begin{array}{ll} 1 - \mathrm{e}^{-\left(\frac{t - \alpha}{\eta}\right)^{\beta}}, & t > \alpha \\ 0, & t \leq \alpha \end{array} \right. \tag{1}
$

其中$\alpha \geq 0$是位置参数,$\eta > 0$是尺度参数,$\beta > 0$是形状参数(Weibull, 1951)。相应的密度函数为

$
f(t; \alpha, \beta, \eta) = \left\{ \begin{array}{ll} \frac{\beta}{\eta} \left(\frac{t - \alpha}{\eta}\right)^{\beta - 1} \mathrm{e}^{-\left(\frac{t - \alpha}{\eta}\right)^{\beta}} & t > \alpha \\ 0, & t \leq \alpha. \end{array} \right. \tag{2}
$

如果$\alpha = 0$,则所得分布称为两参数Weibull分布。一个非负随机变量T如果其概率密度函数(PDF)和累积分布函数(CDF)分别由(2)和(1)给出,则称其服从三参数Weibull分布。我们推荐读者参考Murthy等人(2004)的优秀综述著作,其中将各种Weibull模型分为七个不同的组别。

该分布以其发明者Waloddi Weibull的名字命名,他于1939年首次引入该分布,用于材料强度研究(见Weibull(1939)),在可靠性和寿命研究中被广泛用作模型(见Lawless(1982);Murthy等人(2004);Nelson(1982))。Weibull分布在医学、生物学、农业、林业和工程科学中有许多应用。此外,Weibull分布还在许多应用研究中作为趋势曲线得到应用(见Banks(1994);Ross(1990);Seber和Wild(1989))。Weibull分布的可靠性函数$R(t)$和风险(瞬时失效率)函数$h(t)$分别为

$
R(t; \alpha, \beta, \eta) = \mathrm{e}^{-(\frac{t - \alpha}{\eta})^{\beta}}, \quad t > \alpha
$

和

$
h(t; \alpha, \beta, \eta) = \frac{f(t; \alpha, \beta, \eta)}{1 - F(t; \alpha, \beta, \eta)} = \frac{\beta}{\eta} \left(\frac{t - \alpha}{\eta}\right)^{\beta - 1}, t > \alpha.
$

当$\beta > 1$时,Weibull分布的风险函数单调递增;当$0 < \beta < 1$时单调递减;当$\beta = 1$时为常数。当$\beta = 1$时,Weibull分布退化为指数分布。

从观测数据估计密度函数参数最常用的方法是极大似然(ML)方法。假设有来自密度的$n$个独立观测$t_1, \ldots, t_n$,该样本的似然函数为$L(\pmb\theta) = \prod_{i=1}^{n} p(t_i; \pmb\theta)$,其中$p(t; \pmb\theta)$是基础密度函数。参数$\pmb\theta$的极大似然估计(MLE)是使似然函数最大化的值$\hat{\pmb\theta}$。但MLE不一定存在,也不一定唯一。对于两参数Weibull分布,Pratt(1981)和Burridge(1981)的结果保证了唯一MLE的存在。然而,我们此处的关注点是$\alpha$未知的情况。在这种情况下,会出现许多额外的困难。例如,对于来自密度(2)的任何观测$t_1, \ldots, t_n$,不存在标准的MLE(见Lawless(1982))。为了验证这一点,我们可以不失一般性地假设$t_1 = \min\{t_1, \dots, t_n\}$。固定$\beta \in (0, 1)$和$\eta \in (0, \infty)$。则当$\alpha \to t_1$时(从左侧趋近),$f(t_1; \alpha, \beta, \eta) = (\beta / \eta) ((t_1 - \alpha) / \eta)^{\beta - 1} \exp(-((t_1 - \alpha) / \eta)^{\beta}) \to \infty$,而如果$t_i > t_1$,则$f(t_i; \alpha, \beta, \eta) = (\beta / \eta) ((t_i - \alpha) / \eta)^{\beta - 1} \exp(-((t_i - \alpha) / \eta)^{\beta}) \to (\beta / \eta) ((t_i - t_1) / \eta)^{\beta - 1} \exp(-((t_i - t_1) / \eta)^{\beta}) > 0$,因此MLE不存在。文献中对极大似然方法的这类困难进行了大量研究(Cheng和Iles, 1990; Smith和Naylor, 1987)。还有其他几种估计模型参数的统计方法,如矩法、百分位法和贝叶斯方法。遗憾的是,这些方法(贝叶斯方法除外)都不适用于小数据集(见Lawless(1982);Murthy等人(2004);Nelson(1982))。

一种非常流行的参数估计方法是最小二乘(LS)方法。求解非线性LS问题的数值方法在Dennis和Schnabel(1996);Gill等人(1981)中有描述。在迭代最小化平方和之前,仍然有必要问最小二乘估计(LSE)是否存在。对于非线性LS问题,回答这个问题仍然极其困难(见Bates和Watts(1988);Björck(1996);Demidenko(2006, 2000);Hadeler等人(2007);Jukić等人(2004, 1999))。

令人惊讶的是,尽管关于Weibull模型的论文很多,我们却没有找到任何一篇论文专门讨论三参数Weibull分布非线性LS问题解的存在性问题。

本文结构如下。第2节给出主要结果(定理1),该定理保证了三参数Weibull分布LSE的存在性。第3节给出了一个说明性的数值算例。为了避免早期阶段不必要的复杂性,所有证明放在第4节。

# 2. LS存在性定理

LS方法可描述如下:假设给定数据$(w_i, t_i, y_i)$,$i = 1, \dots, n$,$n > 3$,其中

$
0 < t_1 < t_2 < \dots < t_n \tag{3}
$

表示自变量的值(非负Weibull随机变量T的观测值),

$
0 < y_1 < y_2 < \dots < y_n < 1 \tag{4}
$

是相应的经验CDF估计值,$w_i > 0$是描述数据假定相对精度的数据权重。函数(1)的未知参数$\alpha$、$\beta$和$\eta$需要通过最小化泛函

$
S(\alpha, \beta, \eta) = \sum_{i = 1}^{n} w_i [F(t_i; \alpha, \beta, \eta) - y_i]^{2} = \sum_{\substack{i = 1\\ t_i < \alpha}}^{n}w_i y_i^2 + \sum_{\substack{i = 1\\ t_i \geq \alpha}}^{n}w_i \left[1 - \mathrm{e}^{-\left(\frac{t_i - \alpha}{\eta}\right)^{\beta}} - y_i\right]^{2}
$

在集合$\mathcal{P} := \{(\alpha, \beta, \eta) \in \mathbb{R}^3 : \alpha \ge 0; \beta, \eta > 0\}$上来估计。满足

$
S(\alpha^{\star}, \beta^{\star}, \eta^{\star}) = \inf_{(\alpha, \beta, \eta) \in \mathcal{P}} S(\alpha, \beta, \eta)
$

的点$(\alpha^{\star}, \beta^{\star}, \eta^{\star}) \in \mathcal{P}$称为最小二乘估计(LSE),如果它存在的话(见Björck(1996);Gill等人(1981);Ross(1990);Seber和Wild(1989))。

如果考虑Weibull分布的加权LS估计问题,则$y_i$来自经验CDF,条件(3)和(4)是自然的。但是,如果从非线性回归曲线拟合的角度考虑类似的LS估计过程,则没有理由期望条件(3)和(4)自然满足。本文的主要结果如下,可适用于这两种情况。

**定理1.** 如果数据$(w_i, t_i, y_i)$,$i = 1, \ldots, n$,$n > 3$满足条件(3)和(4),则三参数Weibull分布的LSE存在。

有许多不同的方法可以计算样本数据$t_1, \ldots, t_n$对应的经验分布函数$\hat{F}$。它们都涉及将数据按升序排列,使得$t_{(1)} < t_{(2)} < \cdots < t_{(n)}$,如表2所示。最常用的估计量可以表示为以下形式(见Lawless(1982);Nelson(1982)):

$
\hat{F}\left(t_{(i)}\right) = \frac{i - c}{n + 1 - 2c} =: y_i, \quad 0 \leq c < 1. \tag{5}
$

一些常用的选择如下:

- $y_i = \frac{i}{n + 1}$(平均秩估计量,$c = 0$)
- $y_i = \frac{i - 0.5}{n}$(中位秩估计量,$c = 0.5$)

$
y = \ln\left\{\ln\left[\frac{1}{1 - F(t; \alpha_0, \beta, \eta)}\right]\right\} = \beta \ln(t - \alpha_0) - \beta \ln \eta
$

并使用最小二乘法在$\ln(t - \alpha_0)$上拟合直线$y$来计算$\beta_0$和$\eta_0$。

# 4. 定理的证明

在开始证明定理1之前,我们需要一些预备结果。

**引理2.** 假设给定数据$(w_i, t_i, y_i)$,$i = 1, \ldots, n$,$n > 3$,满足$0 < t_1 < t_2 < \cdots < t_n$,$0 < y_1 < y_2 < \cdots < y_n < 1$和$w_i > 0$,$i = 1, \ldots, n$。给定任意实数$\theta \geq 0$,设

$
\bar{y}_{\theta} := \frac{\sum_{t_i > \theta} w_i y_i}{\sum_{t_i > \theta} w_i}
$

和

$
\Sigma_{\theta} := \sum_{t_i < \theta} w_i y_i^2 + \sum_{t_i > \theta} w_i (y_i - \bar{y}_{\theta})^2.
$

则:

(i) 如果$\theta = t_{n-1}$,则存在$\mathcal{P}$中的一个点,使得泛函S在该点取得等于$\sum_{t_{n-1}} = \sum_{i=1}^{n-2} w_i y_i^2$的值;

(ii) 如果$\theta \neq t_{n-1}$,则存在$\mathcal{P}$中的一个点,使得泛函S在该点取得小于$\Sigma_{\theta}$的值。

求和符号$\sum_{t_i > \theta}$(或$\sum_{t_i < \theta}$)应理解为:对满足$t_i > \theta$(或$t_i < \theta$)的那些指标$i \leq n$求和。如果不存在这样的点$t_i$,则和为空;按照惯例,我们将其定义为零。

**证明.** 首先,假设$0 < \theta \leq t_{n-1}$。设$k \in \{1, \ldots, n\}$使得

$
\theta \in (t_{k-1}, t_k], \tag{6}
$

其中定义$t_0 = 0$。定义

$
\bar{y}_{t_k} := \frac{\sum_{t_i > t_k} w_i y_i}{\sum_{t_i > t_k} w_i} \quad \text{和} \quad l := \min\{i: y_i \geq \bar{y}_{t_k}\}.
$

由于序列$\{y_i\}_{i=1}^n$严格递增且$y_n < 1$,容易证明$y_k < \bar{y}_{t_k} < 1$且$k < l$。现在定义

$
\tau_l := \left\{ \begin{array}{ll} t_l, & \text{如果} y_l = \bar{y}_{t_k} \\ \frac{t_{l-1} + t_l}{2}, & \text{如果} y_l > \bar{y}_{t_k}. \end{array} \right.
$

注意$t_k < \tau_l$,因为$k < l$。

现在,我们将首先构造一类Weibull分布,其图像将包含点$(t_k, y_k)$和$(\tau_l, \bar{y}_{t_k})$,并在所有点$t_1, \ldots, t_{k-1}$处为零。为此,我们首先使用以下公式定义函数$K: (0, \infty) \to (0, \infty)$

$
K(\beta) := \frac{\left(\frac{\ln(1 - y_k)}{\ln(1 - \bar{y}_{t_k})}\right)^{1/\beta}}{1 - \left(\frac{\ln(1 - y_k)}{\ln(1 - \bar{y}_{t_k})}\right)^{1/\beta}}.
$

由于$t_k > 0$且

$
\lim_{\beta \rightarrow 0} K(\beta) = 0, \tag{7}
$

存在足够小的$\beta_0 > 0$使得

$
t_k - K(\beta)(\tau_l - t_k) > t_{k-1} \geq 0, \quad \beta \in (0, \beta_0),
$

因此

$
(\alpha(\beta), \beta, \eta(\beta)) := \left(t_k - K(\beta)(\tau_l - t_k), \beta, \frac{\tau_l - t_k + K(\beta)(\tau_l - t_k)}{\left(\ln\left(\frac{1}{1 - \bar{y}_{t_k}}\right)\right)^{1/\beta}}\right) \in \mathcal{P}
$

对所有$\beta \in (0, \beta_0)$成立。现在,对每个实数$\beta \in (0, \beta_0)$,关联一个Weibull分布

$
F(t; \alpha(\beta), \beta, \eta(\beta)) = \left\{ \begin{array}{ll} 1 - \mathrm{e}^{-\ln\left(\frac{1}{1 - \bar{y}_{t_k}}\right) \left(\frac{t - t_k + K(\beta)(\tau_l - t_k)}{\tau_l - t_k + K(\beta)(\tau_l - t_k)}\right)^{\beta}}, & t > t_k - K(\beta)(\tau_l - t_k) \\ 0, & t \leq t_k - K(\beta)(\tau_l - t_k). \end{array} \right.
$

不难证明

$
F(t_k; \alpha(\beta), \beta, \eta(\beta)) = y_k,
$

$
F(\tau_l; \alpha(\beta), \beta, \eta(\beta)) = \bar{y}_{t_k}, \tag{8}
$

$
F(t_i; \alpha(\beta), \beta, \eta(\beta)) = 0, \quad i = 1, \dots, k - 1
$

和

$
\lim_{\beta \rightarrow 0} F(t; \alpha(\beta), \beta, \eta(\beta)) = \bar{y}_{t_k}, \quad t > t_k. \tag{9}
$

(i) 如果$\theta = t_{n-1}$,则$k = n - 1$,$\bar{y}_{t_k} = y_n$,$l = n$且$\tau_l = t_n$。因此,由(8)可得

$
S(\alpha(\beta), \beta, \eta(\beta)) = \sum_{i=1}^{n} w_i [F(t_i; \alpha(\beta), \beta, \eta(\beta)) - y_i]^2 = \sum_{i=1}^{n-2} w_i y_i^2 = \Sigma_{t_{n-1}}
$

对所有$\beta \in (0, \beta_0)$成立,因此结论(i)得证。

现在证明结论(ii)。如果$\theta \in (0, t_{n-2}]$,由假设(6)有

$
\Sigma_{\theta} = \sum_{t_i < \theta} w_i y_i^2 + \sum_{t_i > \theta} w_i (y_i - \bar{y}_{\theta})^2 \geq \sum_{i=1}^{k-1} w_i y_i^2 + \sum_{i=k+1}^{n} w_i (y_i - \bar{y}_{\theta})^2
$

其中等号仅在$\theta = t_k$时成立。基于此事实以及二次函数$x \mapsto \sum_{i=1}^{p} w_i (x_i - x)^2$在点$\bar{x} = \sum_{i=1}^{p} w_i x_i / \sum_{i=1}^{p} w_i$处取得最小值$\sum_{i=1}^{p} w_i (x_i - \bar{x})^2$,我们得到

$
\Sigma_{\theta} \geq \sum_{i=1}^{k-1} w_i y_i^2 + \sum_{i=k+1}^{n} w_i (y_i - \bar{y}_{t_k})^2. \tag{10}
$

函数$t \mapsto F(t; \alpha(\beta), \beta, \eta(\beta))$,$\beta \in (0, \beta_0)$,在区间$(t_k - K(\beta)(\tau_l - t_k), \infty)$上严格递增。基于此事实、(7)和(9),我们可以假设$\beta_0 > 0$足够小,使得对所有$\beta \in (0, \beta_0)$,

$
y_i < F(t_i; \alpha(\beta), \beta, \eta(\beta)) < \bar{y}_{t_k}, \quad \text{如果} t_k < t_i < \tau_l
$

$
y_i = F(t_i; \alpha(\beta), \beta, \eta(\beta)) = \bar{y}_{t_k}, \quad \text{如果} t_i = \tau_l \tag{11}
$

$
\bar{y}_{t_k} < F(t_i; \alpha(\beta), \beta, \eta(\beta)) < y_i, \quad \text{如果} \tau_l < t_i \leq t_m.
$

由于$k \leq n - 2$,至少有两个指标$i$满足$t_i > t_k$。此外,由于序列$\{y_i\}_{i=1}^n$严格递增,等式$y_i = \bar{y}_{t_k}$最多只能对一个指标$i$成立。因此,对每个$\beta \in (0, \beta_0)$,由(11)可得

$
\sum_{t_i > t_k} w_i [F(t_i; \alpha(\beta), \beta, \eta(\beta)) - y_i]^2 < \sum_{i=k+1}^{n} w_i (y_i - \bar{y}_{t_k})^2.
$

因此,对任何这样的$\beta$,我们有

$
S(\alpha(\beta), \beta, \eta(\beta)) = \sum_{i=1}^{n} w_i [F(t_i; \alpha(\beta), \beta, \eta(\beta)) - y_i]^2
$

$
= \sum_{t_i < t_k} w_i [F(t_i; \alpha(\beta), \beta, \eta(\beta)) - y_i]^2 + \sum_{t_i > t_k} w_i [F(t_i; \alpha(\beta), \beta, \eta(\beta)) - y_i]^2 < \sum_{i=1}^{k-1} w_i y_i^2 + \sum_{i=k+1}^{n} w_i (y_i - \bar{y}_{t_k})^2. \tag{12}
$

由(10)和(12)可得$S(\alpha(\beta), \beta, \eta(\beta)) < \Sigma_{\theta}$。如果$\theta = 0$,则$\Sigma_0 > \Sigma_{t_1/2}$。

如果$\theta \in (t_{n-2}, t_{n-1}) \cup (t_{n-1}, \infty)$,则$\Sigma_{\theta} > \sum_{i=1}^{n-2} w_i y_i^2 = \Sigma_{t_{n-1}}$。如结论(i)的证明所示,存在$\mathcal{P}$中的一个点,使得泛函S在该点取得值$\Sigma_{t_{n-1}}$。证毕。

**定理1的证明.** 由于泛函S非负,存在$S^{\star} := \inf_{(\alpha, \beta, \eta) \in \mathcal{P}} S(\alpha, \beta, \eta)$。需要证明存在点$(\alpha^{\star}, \beta^{\star}, \eta^{\star}) \in \mathcal{P}$使得$S(\alpha^{\star}, \beta^{\star}, \eta^{\star}) = S^{\star}$。

根据引理2(i),存在点$(\alpha_0, \beta_0, \eta_0) \in \mathcal{P}$使得$S(\alpha_0, \beta_0, \eta_0) = \sum_{i=1}^{n-2} w_i y_i^2$。因此,$S^{\star} \le \sum_{i=1}^{n-2} w_i y_i^2$。如果$S^{\star} = \sum_{i=1}^{n-2} w_i y_i^2$,则只需设$(\alpha^{\star}, \beta^{\star}, \eta^{\star}) = (\alpha_0, \beta_0, \eta_0)$即可完成证明。因此,我们可以进一步假设

$
S^{\star} < \sum_{i=1}^{n-2} w_i y_i^2. \tag{13}
$

设$(\alpha_k, \beta_k, \eta_k)$是$\mathcal{P}$中的序列,使得

$
S^{\star} = \lim_{k \rightarrow \infty} S(\alpha_k, \beta_k, \eta_k) = \lim_{k \rightarrow \infty} \sum_{i=1}^{n} w_i [F(t_i; \alpha_k, \beta_k, \eta_k) - y_i]^2 = \lim_{k \rightarrow \infty} \left[ \sum_{t_i < \alpha_k} w_i y_i^2 + \sum_{t_i \geq \alpha_k} w_i \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}} - y_i\right)^2 \right]. \tag{14}
$

不失一般性,在后续讨论中我们可以假设序列$(\alpha_k)$、$(\beta_k)$和$(\eta_k)$是单调的。这是可能的,因为序列$(\alpha_k, \beta_k, \eta_k)$有一个子序列$(\alpha_{l_k}, \beta_{l_k}, \eta_{l_k})$,其所有分量序列$(\alpha_{l_k})$、$(\beta_{l_k})$和$(\eta_{l_k})$都是单调的;且由于$\lim_{k \to \infty} S(\alpha_{l_k}, \beta_{l_k}, \eta_{l_k}) = \lim_{k \to \infty} S(\alpha_k, \beta_k, \eta_k) = S^{\star}$。

由于每个实数单调序列在扩充实数系$\bar{\mathbb{R}}$中收敛,定义

$
\alpha^{\star} := \lim_{k \rightarrow \infty} \alpha_k, \quad \beta^{\star} := \lim_{k \rightarrow \infty} \beta_k, \quad \eta^{\star} := \lim_{k \rightarrow \infty} \eta_k.
$

注意$0 \leq \alpha^{\star}$,$\beta^{\star}$,$\eta^{\star} \leq \infty$,因为$(\alpha_k, \beta_k, \eta_k) \in \mathcal{P}$。

要完成证明,只需证明$(\alpha^{\star}, \beta^{\star}, \eta^{\star}) \in \mathcal{P}$,即$0 \leq \alpha^{\star} < \infty$且$\beta^{\star}, \eta^{\star} \in (0, \infty)$。泛函S的连续性将意味着$S^{\star} = \lim_{k \to \infty} S(\alpha_k, \beta_k, \eta_k) = S(\alpha^{\star}, \beta^{\star}, \eta^{\star})$。

下面证明$(\alpha^{\star}, \beta^{\star}, \eta^{\star}) \in \mathcal{P}$。证明分五步进行。第1步证明$\alpha^{\star} \leq t_{n-2}$。第2步证明$\eta^{\star} \neq \infty$。第3步证明$\eta^{\star} \neq 0$。第4步证明$\beta^{\star} \neq \infty$。最后,第5步证明$\beta^{\star} \neq 0$。

**第1步.** 如果$\alpha^{\star} > t_{n-2}$,由(14)可得$S^{\star} \geq \sum_{i=1}^{n-2} w_i y_i^2$,这与假设(13)矛盾。因此,我们证明了$\alpha^{\star} \leq t_{n-2}$。

通过在必要时取$(\alpha_k, \beta_k, \eta_k)$的适当子序列,我们可以假设如果$t_i < \alpha^{\star}$,则对每个$k \in \mathbb{N}$都有$t_i < \alpha_k$。类似地,如果$t_i > \alpha^{\star}$,我们可以假设对每个$k \in \mathbb{N}$都有$t_i > \alpha_k$。基于此,容易证明由(14)可得

$
S^{\star} \geq \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \lim_{k \rightarrow \infty} \left[ \sum_{t_i > \alpha^{\star}} w_i \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}} - y_i\right)^2 \right]. \tag{15}
$

**第2步.** 现在证明$\eta^{\star} \neq \infty$。用反证法。假设$\eta^{\star} = \infty$。则只可能出现以下两种情况之一:(i) $\eta^{\star} = \infty$且$\beta^{\star} > 0$,或(ii) $\eta^{\star} = \infty$且$\beta^{\star} = 0$。现在我们将证明泛函S在这两种情况下都不能取得其下确界,从而证明$\eta^{\star} \neq \infty$。

**情况(i):** $\eta^{\star} = \infty$且$\beta^{\star} > 0$。由于$\alpha^{\star} \leq t_{n-2} < t_n$,在此情况下我们有

$
\lim_{k \rightarrow \infty} F(t_i; \alpha_k, \beta_k, \eta_k) = \lim_{k \rightarrow \infty} \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}}\right) = 0, \quad t_i \geq \alpha^{\star}
$

因此由(14)可得

$
S^{\star} = \lim_{k \rightarrow \infty} S(\alpha_k, \beta_k, \eta_k) = \sum_{i=1}^{n} w_i y_i^2 > \sum_{i=1}^{n-2} w_i y_i^2
$

这与假设(13)矛盾。

**情况(ii):** $\eta^{\star} = \infty$且$\beta^{\star} = 0$。由于$\eta_k \to \infty$,对每个足够大的$k \in \mathbb{N}$,有$0 < (1 / \eta_k)^{\beta_k} < 1$。这意味着序列$(1 / \eta_k)^{\beta_k}$有界。我们可以假设它是收敛的。设$(1 / \eta_k)^{\beta_k} \to L \in [0, 1]$。由于在此情况下

$
\lim_{k \rightarrow \infty} F(t_i; \alpha_k, \beta_k, \eta_k) = \lim_{k \rightarrow \infty} \left(1 - \mathrm{e}^{-(\frac{1}{\eta_k})^{\beta_k} (t_i - \alpha_k)^{\beta_k}}\right) = 1 - \mathrm{e}^{-L}, \quad t_i > \alpha^{\star}
$

且二次函数$x \mapsto \sum_{t_i > \alpha^{\star}} w_i (x - y_i)^2$在点$\bar{y}_{\alpha^{\star}} = \sum_{t_i > \alpha^{\star}} w_i y_i / \sum_{t_i > \alpha^{\star}} w_i$处取得最小值$\sum_{t_i > \alpha^{\star}} w_i (\bar{y}_{\alpha^{\star}} - y_i)^2$,由(15)可得

$
S^{\star} \geq \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i (1 - e^{-L} - y_i)^2 \geq \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i (\bar{y}_{\alpha^{\star}} - y_i)^2 = \Sigma_{\alpha^{\star}}.
$

由于$\alpha^{\star} \leq t_{n-2} < t_{n-1}$,根据引理2(ii),存在$\mathcal{P}$中的一个点,使得泛函S在该点取得小于$\Sigma_{\alpha^{\star}}$的值。这意味着在此情况下泛函S不能取得其下确界。

**第3步.** 现在证明$\eta^{\star} \neq 0$。用反证法。假设$\eta^{\star} = 0$。则不失一般性,我们可以假设对所有$k \in \mathbb{N}$有$1 / \eta_k > 1$。由于此时$(1 / \eta_k)^{\beta_k} \ge 1$,只可能出现以下情况之一:(i) $\eta^{\star} = 0$且$(1 / \eta_k)^{\beta_k} \to \infty$,或(ii) $\eta^{\star} = 0$且$(1 / \eta_k)^{\beta_k} \to L \in [1, \infty)$。我们证明泛函S在这两种情况下都不能取得其下确界,从而证明$\eta^{\star} \neq 0$。

**情况(i):** $\eta^{\star} = 0$且$(1 / \eta_k)^{\beta_k} \to \infty$。在此情况下

$
\lim_{k \rightarrow \infty} \left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k} = \infty, \quad t_i > \alpha^{\star}
$

因此

$
\lim_{k \rightarrow \infty} F(t_i; \alpha_k, \beta_k, \eta_k) = \lim_{k \rightarrow \infty} \left(1 - e^{-\left(\frac{t - \alpha_k}{\eta_k}\right)^{\beta_k}}\right) = 1, \quad t_i > \alpha^{\star}.
$

实际上,如果$t_i > \alpha^{\star}$且$\beta^{\star} = 0$,则

$
\lim_{k \rightarrow \infty} \left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k} = \lim_{k \rightarrow \infty} \left(\frac{1}{\eta_k}\right)^{\beta_k} (t_i - \alpha_k)^{\beta_k} = \infty \cdot 1 = \infty.
$

如果$t_i > \alpha^{\star}$且$\beta^{\star} > 0$,则显然

$
\lim_{k \to \infty} \left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k} = \infty.
$

**情况(ii):** $\eta^{\star} = 0$且$(1 / \eta_k)^{\beta_k} \to L \in [1, \infty)$。在此情况下,序列$(\beta_k)$必须收敛到0,因为假设$\eta_k \to 0$。因此,

$
\lim_{k \rightarrow \infty} F(t_i; \alpha_k, \beta_k, \eta_k) = \lim_{k \rightarrow \infty} \left(1 - \mathrm{e}^{-(\frac{1}{\eta_k})^{\beta_k} (t_i - \alpha_k)^{\beta_k}}\right) = 1 - \mathrm{e}^{-L}, \quad t_i > \alpha^{\star}.
$

现在类似于第2步情况(ii)的论证,在这两种情况下我们都得到

$
S^{\star} \geq \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i (\bar{y}_{\alpha^{\star}} - y_i)^2 = \Sigma_{\alpha^{\star}}.
$

由于我们已经证明存在$\mathcal{P}$中的一个点,使得泛函S在该点取得小于$\Sigma_{\alpha^{\star}}$的值,这意味着以这种方式($\eta^{\star} = 0$)泛函S不能取得其下确界。

到目前为止,我们已经证明了$0 \leq \alpha^{\star} \leq t_{n-2}$且$0 < \eta^{\star} < \infty$。利用此结果,接下来的两步将证明$0 < \beta^{\star} < \infty$。

**第4步.** 证明$\beta^{\star} \neq \infty$。用反证法。假设$\beta^{\star} = \infty$。则

$
\lim_{k \to \infty} F(t; \alpha_k, \beta_k, \eta_k) = \lim_{k \to \infty} \left(1 - \mathrm{e}^{-\left(\frac{t - \alpha_k}{\eta_k}\right)^{\beta_k}}\right) = \left\{ \begin{array}{ll} 0, & \text{如果} \alpha^{\star} \leq t < \alpha^{\star} + \eta^{\star} \\ 1, & \text{如果} t > \alpha^{\star} + \eta^{\star} \end{array} \right.
$

因此由(15)可得

$
S^{\star} \geq \lim_{k \rightarrow \infty} \left[ \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{\alpha^{\star} < t_i < \alpha^{\star} + \eta^{\star}} w_i \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}} - y_i\right)^2 + \sum_{t_i > \alpha^{\star} + \eta^{\star}} w_i \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}} - y_i\right)^2 \right] = \sum_{t_i < \alpha^{\star} + \eta^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star} + \eta^{\star}} w_i (1 - y_i)^2.
$

现在类似于第2步情况(ii)的论证,可以证明

$
S^{\star} \geq \sum_{t_i < \alpha^{\star} + \eta^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star} + \eta^{\star}} w_i (y_i - \bar{y}_{\alpha^{\star} + \eta^{\star}})^2 = \Sigma_{\alpha^{\star} + \eta^{\star}},
$

其中$\bar{y}_{\alpha^{\star} + \eta^{\star}} = \sum_{t_i > \alpha^{\star} + \eta^{\star}} w_i y_i / \sum_{t_i > \alpha^{\star} + \eta^{\star}} w_i$。由假设(13),$\alpha^{\star} + \eta^{\star} \ne t_{n-1}$。因此,根据引理2(ii),存在$\mathcal{P}$中的一个点,使得泛函S在该点取得小于$\Sigma_{\alpha^{\star} + \eta^{\star}}$的值。以这种方式($\beta^{\star} = \infty$)泛函S不能取得其下确界。因此,我们证明了$\beta^{\star} < \infty$。

**第5步.** 剩下证明$\beta^{\star} \neq 0$。如果$\beta_k \to 0$,则由(15)可得

$
S^{\star} \geq \lim_{k \rightarrow \infty} \left[ \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i \left(1 - \mathrm{e}^{-\left(\frac{t_i - \alpha_k}{\eta_k}\right)^{\beta_k}} - y_i\right)^2 \right] = \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i (1 - e^{-1} - y_i)^2 \geq \sum_{t_i < \alpha^{\star}} w_i y_i^2 + \sum_{t_i > \alpha^{\star}} w_i (y_i - \bar{y}_{\alpha^{\star}})^2 = \Sigma_{\alpha^{\star}}.
$

根据引理2(ii),以这种方式泛函S不能取得其下确界。因此,我们证明了$\beta^{\star} > 0$,证明完成。□

**注3.** 给定$1 \leq p < \infty$,设

$
S_p(\alpha, \beta, \eta) = \sum_{i=1}^{n} w_i |F(t_i; \alpha, \beta, \eta) - y_i|^p.
$

类似于引理2和定理1的证明,容易证明存在点$(\alpha_p^{\star}, \beta_p^{\star}, \eta_p^{\star}) \in \mathcal{P}$使得$S_p(\alpha_p^{\star}, \beta_p^{\star}, \eta_p^{\star}) = \inf_{(\alpha, \beta, \eta) \in \mathcal{P}} S_p(\alpha, \beta, \eta)$。
