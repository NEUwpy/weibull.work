## 摘要

基于记录数据，许多学者使用经典和贝叶斯方法讨论了两参数威布尔分布的估计问题。本文使用极大似然方法，研究基于已观测记录值预测未来记录值的问题。对于受限参数空间，本文还证明了未来记录值的极大似然预测量以及所有未知量的预测极大似然估计量的存在性和唯一性。本文还讨论了获得似然估计量和预测量的替代近似方法，这些方法始终存在且易于确定。本文研究的替代近似程序包括：基于变换的预测似然函数、修正预测似然函数、最大间距积预测。通过蒙特卡洛模拟比较了所提出的方法，并分析了一个实际数据集用于说明目的。

## 1 引言

记录统计量在许多实际领域中自然产生，在气象学、水文学、体育和竞技赛事中有多种情况，其中通常只记录记录值。关于记录值及其应用的详细论述，可参考 Arnold 等[1]、Nevzorov[2]和 Gulati 与 Padgett[3]的著作。在记录框架中，数据按顺序观测，只有连续的最大（最小）值被记录。具体地，设 $\{ X _ { j } , j \ge 1 \}$ 是一列独立同分布（iid）连续随机变量，具有累积分布函数（cdf）$F ( x )$ 和概率密度函数（pdf）$f ( x )$。如果一个观测 $X _ { j }$ 满足对所有 $i < j$ 有 $X _ { j } > X _ { i }$，则称其为上记录值，下记录值可类似定义（不等号反向）。

预测未来记录值在记录数据背景下具有重要意义，因为它在气候、环境和河流洪水水位等应用领域有重要应用。关于记录预测已有大量工作。Ahsanullah[4]从两参数指数分布出发，基于已观测记录值获得了未来记录值的最佳线性无偏预测量和最佳线性不变预测量。Dunsmore[5]给出了指数分布未来记录值的贝叶斯预测分布。Nagaraja[6]讨论了三种极值分布未来记录值的预测量。Kaminsky 和 Rhodin[7]将极大似然方法扩展到联合预测未来随机变量和估计未知参数。得到的预测量称为极大似然预测量（MLP）。Ahmad[8]使用双重删失数据推导了未来广义次序统计量的贝叶斯预测区间。Ahmadi 和 Doostparast[9]研究了某些寿命分布记录值的估计和预测。最近，Barakat 等[10]基于随机样本量的两参数指数分布发展了未来广义次序统计量的预测区间。

基于记录数据的两参数威布尔分布估计问题已有大量研究，特别是贝叶斯和非贝叶斯方法。有关各种发展的详细信息，感兴趣的读者可参考 Soliman 等[11]、Asgharzadeh 和 Abdi[12]、Teimouri 和 Nadarajah[13]，以及 Bdair 和 Raqab[14]。相比之下，三参数威布尔分布的估计-预测问题尚未受到太多关注，因此我们在此关注这个问题。

本文基于三参数威布尔分布的前 m 个观测记录值，讨论同时估计参数和预测同一 iid 随机变量序列中未来未观测记录值的问题。本文其余部分组织如下：第2节详细讨论基于三参数威布尔分布观测记录值的未来记录值的 MLP 和预测极大似然估计量（PMLE）。通常，未来记录值的 MLP 并不总是存在，因此第3节提出了预测似然函数的一些修正方法。第4节通过偏差和均方误差评估所有估计量和预测量的性能。相应的置信区间和预测区间也在第4节讨论，并给出了一个说明性示例。

## 2 未来记录值的 MLP

设 $\{ X _ { i } , i \ge 1 \}$ 是一列独立同分布（iid）随机变量，具有共同的绝对连续 cdf F 和 pdf $f$。按照惯例，$X _ { 1 }$ 被取为记录值。那么，记录时间序列 $\{ U ( n ) , n \geq 1 \}$ 定义为（参见 Arnold 等[1]和 Charalambides[15]）

$$
U (1) = 1 \text{ 且对于 } n \geq 2, U (n) = \min \{j: j > U (n - 1) \}.
$$

随机变量 $X _ { U ( n ) }$，$n \geq 1$，是记录值。

我们在此的主要关注点是基于前 m 个记录值 $\underline { { { X } } } = ( X _ { U ( 1 ) } , \dots , X _ { U ( m ) } )$（其中 $1 < m < n$）预测序列中的第 n 个记录 $X _ { U ( n ) }$。未来第 n 个记录 $X _ { U ( n ) }$ 和 $\boldsymbol { \zeta } = ( \theta , \alpha , \lambda )$ 的预测似然函数（PLF）为

$$
L = L \left(x _ {U (n)}, \xi ; \underline {{x}}\right) = \prod_ {j = 1} ^ {m} h \left(x _ {U (j)}\right) \frac {\left[ H \left(x _ {U (n)}\right) - H \left(x _ {U (m)}\right) \right] ^ {n - m - 1}}{(n - m - 1) !} f \left(x _ {U (n)}\right), \tag {2.1}
$$

其中 $h ( x ) = f ( x ) / ( 1 - F ( x ) )$ 和 $H ( x ) = - \log ( 1 - F ( x ) )$ 分别是 X 的失效率函数和累积失效率函数。现在，假设 $\delta _ { M L } = t ( \underline { { x } } )$ 和 $\zeta _ { M L } = u ( \underline { { x } } )$ 是满足

$$
L (t (\underline {{x}}), u (\underline {{x}}); \underline {{x}}) = \sup _ {(x _ {U (n)}, \underline {{\zeta}})} L (x _ {U (n)}, \underline {{\zeta}}; \underline {{x}}).
$$

的统计量，则称 $\delta _ { M L } = t ( \underline { { x } } )$ 为 $X _ { U ( n ) }$ 的 MLP，$\hat { \boldsymbol { \xi } } = \boldsymbol { u } ( \boldsymbol { \chi } )$ 为 $\zeta$ 的预测极大似然估计量（PMLE）。

我们假设底层 $X _ { i }$ 服从三参数威布尔分布 $W ( \theta , \alpha , \lambda )$，其 pdf 和 cdf 分别为

$$
f (x) = \alpha \lambda (x - \theta) ^ {\alpha - 1} e ^ {- \lambda (x - \theta) ^ {\alpha}}, F (x) = 1 - e ^ {- \lambda (x - \theta) ^ {\alpha}}, x > \theta , \alpha , \lambda > 0, \tag {2.2}
$$

基于观测的记录数据，将（2.1）中的 PLF 视为 $\theta , \alpha , \lambda$ 和要预测的未来第 n 个记录的函数，可表示为

$$
\begin{array}{l} L = \lambda^ {n} \alpha^ {m + 1} \prod_ {j = 1} ^ {m} (x _ {U (j)} - \theta) ^ {\alpha - 1} \frac {[ (x _ {U (n)} - \theta) ^ {\alpha} - (x _ {U (m)} - \theta) ^ {\alpha} ] ^ {n - m - 1}}{(n - m - 1) !} \\ \times \left(x _ {U (n)} - \theta\right) ^ {\alpha - 1} e ^ {- \lambda \left(x _ {U (n)} - \theta\right) ^ {\alpha}}, \theta < x _ {U (1)} < \dots < x _ {U (m)} < x _ {U (n)}. \tag {2.3} \end{array}
$$

我们的目标是关于 $X _ { U ( n ) }$ 以及威布尔模型中涉及的其他参数最大化（2.3）中的 PLF，以确定 $X _ { U ( n ) }$ 的 MLP 和 $\theta , \alpha , \lambda$ 的 PMLE。

### 2.1 两参数模型

设 $X _ { 1 } , X _ { 2 } , . . .$ 是来自威布尔分布（记为 $W ( \alpha , \lambda )$）的随机序列，其 pdf 和 cdf 在（2.2）中定义，位移参数 $\theta := 0$。相应的记录时间记为 $X _ { U ( 1 ) }$，$X _ { U ( 2 ) } , \ldots$。假设我们只观测到 $\underset { } { X } = ( X _ { U ( 1 ) } , X _ { U ( 2 ) } , \dotsc , X _ { U ( m ) } )$，目标是预测未来记录值 $X _ { U ( n ) }$，其中 $1 \leq m < n$。$X _ { U ( n ) }$、α 和 $\lambda$ 的预测似然函数（PLF）正是 $X _ { U ( n ) }$ 和 $\underset { ^ { \sim } } { X }$ 对某个 $n \geq m + 1$ 的联合 pdf，可表示为两个似然函数 $L _ { 1 }$ 和 $L _ { 2 }$ 的乘积，其中 $L _ { 1 }$ 是前 m 个观测记录值的联合 pdf，$L _ { 2 }$ 是给定 $\underset { \sim } { X } = \underset { \sim } { x }$ 时 $X _ { U ( n ) }$ 的条件 pdf。由记录数据的马尔可夫性质（Arnold 等[1]），给定 $\mathop { { \cal X } } _ { \sim } = \chi$ 时 ${ \cal X } _ { U ( n ) }$ 的条件分布，正是给定 $X _ { U ( m ) } = x _ { U ( m ) }$ 时 $X _ { U ( n ) }$ 的条件分布，即从左截断分布中抽取的序列的第 $( n - m )$ 个记录统计量的分布，其 pdf 为 $f ^ { * } ( y ) = f ( y ) / [ 1 - F ( x _ { U ( m ) } ) ]$，$y > x _ { U ( m ) }$。从（2.1）和（2.2），预测似然方程（PLE）给出 $X _ { U ( n ) }$ 的 MLP 和 $\lambda$ 的 PMLE 的闭式表达式。将从这些 PLE 推导出的 $X _ { U ( n ) }$ 的 MLP 以及 $\lambda$ 和 $\alpha$ 的 PMLE 分别记为 $\delta _ { M L }$、$\hat { \lambda } _ { M L }$ 和 $\hat { \alpha } _ { M L }$。$X _ { U ( n ) }$ 的 MLP 和 $\lambda$ 的 PMLE 分别为

$$
\delta_ {M L} = \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) ^ {\frac {1}{\alpha}} X _ {U (m)}, \hat {\lambda} _ {M L} = \frac {n (m \alpha + 1)}{[ (n - 1) \alpha + 1 ] X _ {U (m)} ^ {\alpha}},
$$

$\alpha$ 的 PMLE 是方程 $\varphi _ { 0 } ( \alpha ; \underline { { x } } ) = 0$ 的解，其中

$$
\varphi_ {0} (\alpha ; \chi) = T _ {0} (\chi) \alpha + (m + 1) + \frac {1}{\alpha} \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) = 0, \tag {2.4}
$$

其中 $\begin{array} { r } { T _ { 0 } ( \underline { { x } } ) = \sum _ { i = 1 } ^ { m } \log x _ { U ( i ) } - m \log x _ { U ( m ) } \leq 0 } \end{array}$。（2.4）中的 PLE 需要数值求解。容易证明 $\varphi _ { 0 } ( \alpha ; \pmb { \chi } )$ 是非增函数，且 $\varphi _ { 0 } ( 0 ; \underline { { x } } ) = n$，$\varphi _ { 0 } ( + \infty ; \underline { { x } } ) = - \infty$，这意味着方程（2.4）在 $\alpha$ 的 PMLE 处有唯一解。这一断言可通过注意到

$$
\begin{array}{l} \frac {\partial \varphi_ {0} (\alpha ; \underline {{x}})}{\partial \alpha} = T _ {0} (\underline {{x}}) + \frac {1}{\alpha^ {2}} \left\{\frac {(n - m - 1) \alpha}{(m \alpha + 1) [ (n - 1) \alpha + 1 ]} - \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) \right\} \\ = T _ {0} (\underline {{x}}) + \frac {1}{\alpha^ {2}} \left\{\frac {1}{m \alpha + 1} \left(1 - \frac {m \alpha + 1}{(n - 1) \alpha + 1}\right) - \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) \right\} \\ \leq T _ {0} (\underline {{x}}) + \frac {1}{\alpha^ {2}} \left\{\left(1 - \frac {m \alpha + 1}{(n - 1) \alpha + 1}\right) - \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) \right\} \\ \leq 0. \end{array}
$$

最后一个不等式利用了对于所有 $x > 0$ 有 $1 - 1 / x \leq \log x$ 这一事实。这证明了 $\hat { \alpha } _ { M L }$、$\hat { \lambda } _ { M L }$ 以及 $\delta _ { M L }$ 的存在性和唯一性。

通常，实践者更喜欢将预测集 $C ( \mathcal { X } ) = \big ( L ( \mathcal { X } ) , U ( \mathcal { X } ) \big )$ 设为一个区间，使得 $P \left( X _ { U ( n ) } \in C ( \mathbb { X } ) \right) = 1 - \gamma$，其中 $1 - \gamma$ 是指定的覆盖概率。通过观察到 $X _ { U ( n ) }$ 的 MLP 和 $\lambda$ 的 PMLE 作为 $\alpha$ 的函数计算，这意味着条件 PLF $L _ { 2}$ 可以被视为枢轴量

$$
Q \left(X _ {U (n)}; x\right) = \frac {n (m \alpha + 1)}{[ (n - 1) \alpha + 1 ]} \frac {X _ {U (n)} ^ {\alpha} - X _ {U (m)} ^ {\alpha}}{X _ {U (m)} ^ {\alpha}}.
$$

的单峰函数。由于 $Q ( X _ { U ( n ) } ; \underline { { X } } )$ 是 $X _ { U ( n ) }$ 的单调函数，预测集 $C ( \mathbb { X } )$ 保证是一个预测区间（PI）。为了确定该统计量的临界点，首先设 $E _ { i } ( \alpha )$ 为标准指数分布的第 i 个记录值，$W _ { m } ( \alpha ) = \xi ( \alpha ) \lambda X _ { U ( m ) } ^ { \alpha }$，其中 $\xi ( \alpha ) = [ ( n - 1 ) \alpha + 1 ] / ( m \alpha + 1 )$。因此，利用条件论证，有

$$
\begin{array}{l} P \left(Q \left(X _ {U (n)}; \underline {{X}}\right) \leq q\right) = P \left(\frac {E _ {n} (\alpha) - E _ {m} (\alpha)}{W _ {m} (\alpha)} \leq q\right) \\ = P \left(E _ {n} (\alpha) - E _ {m} (\alpha) \leq q W _ {m} (\alpha)\right) \\ = \int_ {0} ^ {\infty} P \left(E _ {n} (\alpha) - E _ {m} (\alpha) \leq q x \mid W _ {m} (\alpha) = x\right) f _ {W _ {m}} (x) d x, \end{array}
$$

其中 $f _ { W _ { m } } ( x )$ 是 $G ( m , 1 / \xi ( \alpha ) )$ 密度。利用 $E _ { n } ( \alpha ) - E _ { m } ( \alpha ) \sim G ( n - m , 1 )$ 这一事实，有

$$
\begin{array}{l} P \left(Q \left(X _ {U (n)}; \chi\right) \leq q\right) = \int_ {0} ^ {\infty} \left\{1 - \sum_ {j = 0} ^ {n - m - 1} \frac {e ^ {- q x} (q x) ^ {j}}{j !} \right\} \frac {x ^ {m - 1} e ^ {- x / \xi (\alpha)}}{\xi^ {m} (\alpha) (m - 1) !} d x \\ = 1 - \frac {1}{(q \xi (\alpha) + 1) ^ {m}} \sum_ {j = 0} ^ {n - m - 1} {\binom {m + j - 1} {j}} \left(\frac {q \xi (\alpha)}{q \xi (\alpha) + 1}\right) ^ {j}. \end{array}
$$

$Q ( X _ { U ( n ) } ; \underline { { { x } } } )$ 分布的临界点可通过求解以下两个方程计算：

$$
\frac {1}{(q _ {\frac {\gamma}{2}} \xi (\alpha) + 1) ^ {m}} \sum_ {j = 0} ^ {n - m - 1} \binom {m + j - 1} {j} \left(\frac {q _ {\frac {\gamma}{2}} \xi (\alpha)}{q _ {\frac {\gamma}{2}} \xi (\alpha) + 1}\right) ^ {j} = 1 - \frac {\gamma}{2}
$$

和

$$
\frac {1}{(q _ {1 - \frac {\gamma}{2}} \xi (\alpha) + 1) ^ {m}} \sum_ {j = 0} ^ {n - m - 1} \binom {m + j - 1} {j} \left(\frac {q _ {1 - \frac {\gamma}{2}} \xi (\alpha)}{q _ {1 - \frac {\gamma}{2}} \xi (\alpha) + 1}\right) ^ {j} = \frac {\gamma}{2}.
$$

如果 $\alpha$ 未知，则可用其 PMLE $\hat { \alpha } _ { M L }$ 代替，该值通过数值求解（2.4）获得。这意味着 $X _ { U ( n ) }$ 的 $100 ( 1 - \gamma ) \%$ PI 为 $( L _ { 1 } ( \underline { { x } } ) , U _ { 1 } ( \underline { { x } } ) )$，其中

$$
L _ {1} (\underline {{x}}) = \left(1 + q _ {\frac {\gamma}{2}} \xi (\hat {\alpha} _ {M L})\right) X _ {U (m)} ^ {\hat {\alpha} _ {M L}}, U _ {1} (\underline {{x}}) = \left(1 + q _ {1 - \frac {\gamma}{2}} \xi (\hat {\alpha} _ {M L})\right) X _ {U (m)} ^ {\hat {\alpha} _ {M L}}.
$$

我们还可以使用参数 bootstrap 程序来开发未来记录值的 PI。该程序可以在校准所获得的 PI 时容纳估计的影响。这里的主要思想是，可以通过重抽样信息数据来建模参数的估计，然后基于从这些数据获得的分位数进行 PI。考虑从给定 $\underset { \sim } { X } = \underset { \sim } { x }$ 时 $X _ { U ( n ) }$ 的条件 PLF 获得的枢轴量，即

$$
Q (X _ {U (n)}; \underline {{x}}) = \frac {n (m \hat {\alpha} _ {M L} + 1)}{[ (n - 1) \hat {\alpha} _ {M L} + 1 ]} \frac {X _ {U (n)} ^ {\hat {\alpha} _ {M L}} - X _ {U (m)} ^ {\hat {\alpha} _ {M L}}}{X _ {U (m)} ^ {\hat {\alpha} _ {M L}}}.
$$

它表示用 $\hat { \alpha } _ { M L }$ 代替 $\alpha$ 后的 Q 的版本。设 $\hat { \alpha } _ { M L }$ 为基于前 m 个记录 $X _ { U ( 1 ) } , X _ { U ( 2 ) } , \dots , X _ { U ( m ) }$ 的 $\alpha$ 的 PMLE。我们的目标是基于重抽样数据生成 Q 的各种版本 $Q ^ { * }$。总之，参数 bootstrap 算法包括以下步骤：

- 步骤1：基于前 m 个观测记录，求出 $\alpha$ 和 $\lambda$ 的 PMLE $\hat { \alpha } _ { M L }$ 和 $\hat { \lambda } _ { M L }$；
- 步骤2：使用步骤1获得的 $\hat { \alpha } _ { M L }$ 和 $\hat { \lambda } _ { M L }$，在威布尔模型下生成 bootstrap 样本 $X _ { U ( 1 ) } ^ { * } , X _ { U ( 2 ) } ^ { * } , \dotsc , X _ { U ( n ) } ^ { * }$。然后，从 $X _ { U ( 1 ) } ^ { * } , X _ { U ( 2 ) } ^ { * } , \dotsc , X _ { U ( m ) } ^ { * }$ 获得 $\alpha$ 和 $\lambda$ 的相应 PMLE $\hat { \alpha } _ { M L } ^ { * }$ 和 $\hat { \lambda } _ { M L } ^ { * }$ 以及 $X _ { U ( n ) }$ 的 MLP $\hat { X } _ { U ( n ) }$；
- 步骤3：基于 bootstrap 样本，定义估计的 bootstrap 版本

$$
Q ^ {*} = \frac {n (m \hat {\alpha} _ {M L} ^ {*} + 1)}{[ (n - 1) \hat {\alpha} _ {M L} ^ {*} + 1 ]} \frac {X _ {U (n)} ^ {\hat {\alpha} _ {M L} ^ {*}} - X _ {U (m)} ^ {\hat {\alpha} _ {M L} ^ {*}}}{X _ {U (m)} ^ {\hat {\alpha} _ {M L} ^ {*}}}
$$

- 步骤4：生成 $\mathtt { B } = 1000$ 个 bootstrap 样本和 $Q ^ { * }$ 的版本，然后获得第 $100 \gamma ^ { th }$ 和第 $100 ( 1 - \gamma ) ^ { th }$ 样本分位数（记为 $\hat { q } _ { \gamma }$ 和 $\hat { q } _ { 1 - \gamma }$）；
- 步骤5：基于步骤4计算的近似分位数和枢轴量 Q，我们为 $X _ { ( n ) }$ 设定一个近似的 $100 ( 1 - \gamma ) \%$ PI 为 $( L _ { 2 } ( \underline { { x } } ) , U _ { 2 } ( \underline { { x } } ) )$，其中

$$
L _ {2} (\underline {{x}}) = \left(1 + \hat {q} _ {\frac {\gamma}{2}} \xi (\hat {\alpha} _ {M L})\right) X _ {U (m)} ^ {\hat {\alpha} _ {M L}}, U _ {2} (\underline {{x}}) = \left(1 + \hat {q} _ {1 - \frac {\gamma}{2}} \xi (\hat {\alpha} _ {M L})\right) X _ {U (m)} ^ {\hat {\alpha} _ {M L}}.
$$

### 2.2 三参数模型

我们现在考虑 pdf 由（2.2）给出的三参数威布尔分布。基于观测 x 的 $X _ { U ( n ) }$ 的预测似然函数（PLF）的对数可表示为

$$
\begin{array}{l} \log L \propto (m + 1) \log \alpha + n \log \lambda + (\alpha - 1) \sum_ {i = 1} ^ {m} \log \left(x _ {U (i)} - \theta\right) + (n - m - 1) \\ \log \left[ (x _ {U (n)} - \theta) ^ {\alpha} - (x _ {U (m)} - \theta) ^ {\alpha} \right] + (\alpha - 1) \log (x _ {U (n)} - \theta) - \lambda (x _ {U (n)} - \theta) ^ {\alpha}, \tag {2.5} \end{array}
$$

前提是 $x _ { U ( 1 ) } > \theta$，$\alpha , \lambda > 0$。容易验证，对于 $\alpha < 1$ 和 $\lambda > 0$，当 $\theta$ 趋近于 $x _ { U ( 1 ) }$ 时，似然函数趋于 $\infty$。因此，在整个参数空间上，$X _ { U ( n ) }$ 的 MLP 以及 $\theta$、$\alpha$ 和 $\lambda$ 的 PMLE 不存在。因此，我们的目标是双重的。首先，我们在受限参数空间上确定未来记录值 $X _ { U ( n ) }$ 的 MLP 和未知参数 $\theta$、$\alpha$ 和 $\lambda$ 的 PMLE，其中 MLP 和 PMLE 确实存在。其次，我们使用惩罚预测似然函数开发未来记录值的修正 MLP。

三参数威布尔分布关于 PLF 的得分方程为

$$
\left\{ \begin{array}{l} \frac {n}{\lambda} - (x _ {U (n)} - \theta) ^ {\alpha} = 0, \\ \frac {(n - m - 1) \alpha (x _ {U (n)} - \theta) ^ {\alpha}}{(x _ {U (n)} - \theta) ^ {\alpha} - (x _ {U (m)} - \theta) ^ {\alpha}} + (\alpha - 1) - \lambda \alpha (x _ {U (n)} - \theta) ^ {\alpha} = 0, \\ \frac {m + 1}{\alpha} + \sum_ {i = 1} ^ {m} \log \left(x _ {U (i)} - \theta\right) + (n - m - 1) \left[ \frac {\left(x _ {U (n)} - \theta\right) ^ {\alpha} \log \left(x _ {U (n)} - \theta\right) - \left(x _ {U (m)} - \theta\right) ^ {\alpha} \log \left(x _ {U (m)} - \theta\right)}{\left(x _ {U (n)} - \theta\right) ^ {\alpha} - \left(x _ {U (m)} - \theta\right) ^ {\alpha}} \right] \\ + \log \left(x _ {U (n)} - \theta\right) - \lambda \left(x _ {U (n)} - \theta\right) ^ {\alpha} \log \left(x _ {U (n)} - \theta\right) = 0, \\ (\alpha - 1) \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)} - \theta} + (n - m - 1) \alpha \left[ \frac {\left(x _ {U (n)} - \theta\right) ^ {\alpha - 1} - \left(x _ {U (m)} - \theta\right) ^ {\alpha - 1}}{\left(x _ {U (n)} - \theta\right) ^ {\alpha} - \left(x _ {U (m)} - \theta\right) ^ {\alpha}} \right] + \frac {\alpha - 1}{x _ {U (n)} - \theta} \\ - \lambda \alpha \left(x _ {U (n)} - \theta\right) ^ {\alpha - 1} = 0. \end{array} \right. \tag {2.6}
$$

系统（2.6）给出了 $X _ { U ( n ) }$ 的 MLP 和 $\lambda$ 的 PMLE 的闭式表达式

$$
\hat {\lambda} _ {M L} = \frac {n}{(x _ {U (n)} - \theta) ^ {\alpha}} \tag {2.7}
$$

和

$$
\delta_ {M L} = \theta + \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) ^ {1 / \alpha} \left(x _ {U (m)} - \theta\right). \tag {2.8}
$$

另外两个方程简化为：

$$
T _ {1} (\mathbf {x}; \theta) \alpha + (m + 1) + \frac {1}{\alpha} \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) = 0 \tag {2.9}
$$

和

$$
\left(x _ {U (m)} - \theta\right) \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)} - \theta} - \frac {m \alpha + 1}{\alpha - 1} = 0, \tag {2.10}
$$

其中

$$
T _ {1} (\mathbf {x}; \theta) = \sum_ {i = 1} ^ {m} \log \left(\frac {x _ {U (i)} - \theta}{x _ {U (m)} - \theta}\right) = \sum_ {i = 1} ^ {m} \log (x _ {U (i)} - \theta) - \log (x _ {U (m)} - \theta) ^ {m}.
$$

对于 $\alpha > 1$，（2.10）可以直接得到 $\alpha$ 作为 $\theta$ 函数的显式解，即

$$
\hat {\alpha} _ {M L} = \frac {\sum_ {i = 1} ^ {m} \left(\frac {x _ {U (m)} - \theta}{x _ {U (i)} - \theta}\right) + 1}{\sum_ {i = 1} ^ {m} \left(\frac {x _ {U (m)} - x _ {U (i)}}{x _ {U (i)} - \theta}\right)}. \tag {2.11}
$$

如果（2.6）中的方程组存在有效解，则可以通过将（2.11）代入（2.9）然后对 $\theta$ 数值求解以下方程，获得 $X _ { U ( n ) }$ 的 MLP 和三个参数的 PMLE：

$$
T _ {1} (\mathbf {x}; \theta) = \psi (\hat {\alpha} _ {M L}), \tag {2.12}
$$

其中

$$
\psi (a) = \frac {- \frac {1}{a} \log \left(\frac {(n - 1) a + 1}{m a + 1}\right) - (m + 1)}{a},
$$

然后分别使用（2.11）、（2.7）和（2.8）计算 $\alpha$、λ 的 PMLE 和 $X _ { U ( n ) }$ 的 MLP。现在，将（2.9）的左边（LHS）记为 $\varphi _ { 1 } ( \alpha , \theta ; \mathbf { x } )$。容易验证，对于任意给定的 $\theta$，当 $\alpha \to 0$ 时 $\varphi _ { 1 } ( \alpha , \theta ; \mathbf { x } )$ 趋于 n，当 $\alpha \to + \infty$ 时达到 $- \infty$。进一步，其关于 $\alpha$ 的梯度为

$$
\frac {\partial \varphi_ {1} (\alpha , \theta ; \underline {{x}})}{\partial \alpha} = T _ {1} (\underline {{x}}, \theta) + \frac {n - m - 1}{\alpha [ (n - 1) \alpha + 1 ] [ m \alpha + 1 ]} - \frac {1}{\alpha^ {2}} \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right).
$$

利用不等式

$$
\frac {(n - m - 1) \alpha}{[ (n - 1) \alpha + 1 ]} = 1 - \frac {m \alpha + 1}{(n - 1) \alpha + 1} < \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right).
$$

我们可以容易地证明 $\partial \varphi _ { 1 } ( \alpha , \theta ; { \mathbf x } ) / \partial \alpha < 0$。这是由于 $1 - 1 / x < \log x$，等号成立当且仅当 $x = 1$。这意味着 $\varphi _ { 1 } ( \alpha , \theta ; \mathbf { x } )$ 是 $\alpha$ 的非增函数，从 0 处的 n 开始，当 $\alpha \to \infty$ 时达到 $- \infty$，因此 $\varphi _ { 1 } ( \alpha , \theta ; \mathbf { x } )$ 在 $\alpha$ 的 PMLE 处恰好与 0 相交一次。

现在，我们将（2.10）另写为

$$
\left(x _ {U (m)} - \theta\right) \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)} - \theta} = \frac {m \alpha + 1}{\alpha - 1}. \tag {2.13}
$$

在约束 $\theta < x _ { U ( 1 ) }$ 下，我们将（2.13）的左边记为 $\eta _ { 1 } ( \theta ; \mathbf { x } )$。现在我们证明对于给定样本 x，$\eta _ { 1 } ( \theta ; \mathbf { x } )$ 是 $\theta$ 的单调非减函数。为此，有

$$
\begin{array}{l} \frac {\partial \eta_ {1} (\theta ; \mathbf {x})}{\partial \theta} = (x _ {U (m)} - \theta) \sum_ {i = 1} ^ {m} \frac {1}{(x _ {U (i)} - \theta) ^ {2}} - \sum_ {i = 1} ^ {m} \frac {1}{(x _ {U (i)} - \theta)} \\ \geq \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)} - \theta} - \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)} - \theta} \geq 0. \end{array}
$$

这表明 $\eta _ { 1 } ( \theta ; \mathbf { x } )$ 是 $\theta$ 的单调非减函数。此外，它在 0 和 $x _ { U ( 1 ) }$ 处分别取得最小值和最大值，下限和上限为

$$
m \leq \eta_ {1} (0; \mathbf {x}) = x _ {U (m)} \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)}} \leq \sum_ {i = 1} ^ {m} \frac {x _ {U (m)} - x _ {U (1)}}{x _ {U (i)} - x _ {U (1)}}. \tag {2.14}
$$

为确保（2.10）有唯一解，我们需要使通过（2.9）获得的 $\alpha = \hat { \alpha } _ { M L }$ 时（2.13）右边（RHS）在（2.14）给出的下限和上限内。显然，对于任意满足约束 $\theta < x _ { U ( 1 ) }$ 的 $\theta$，方程（2.9）总有实数解。如果我们对 $\theta$ 的搜索从 $x _ { U ( 1 ) }$ 移开，且获得的 $\alpha$ 解满足不等式

$$
m \leq x _ {U (m)} \sum_ {i = 1} ^ {m} \frac {1}{x _ {U (i)}} < \frac {m \alpha + 1}{\alpha - 1} < \sum_ {i = 1} ^ {m} \frac {x _ {U (m)} - x _ {U (1)}}{x _ {U (i)} - x _ {U (1)}}, \tag {2.15}
$$

则可以保证 $\theta$ 的 PMLE。这意味着（2.6）中的方程组可以数值求解，因此 $X _ { U ( n ) }$ 的 MLP 存在且唯一。另一方面，如果 $\alpha \leq 1$，则（2.13）无法实现，此时 $\theta$ 的 PMLE 不存在。$\theta$ 的 PMLE 可以在（2.15）的条件下找到。总之，方程（2.13）是我们试图找到未知参数的 PMLE 以及未来记录值的 MLP 的主要关注点。如果（2.15）中的不等式成立，则可以数值获得 $\theta$ 和 $\alpha$ 的 PMLE。这些估计量记为 $\hat { \theta } _ { M L }$ 和 $\hat { \alpha } _ { M L }$。

值得指出的是，虽然似然方法是统计学中估计未知参数最重要的技术之一，但它并不总是能提供似然方程的解，即使存在解也可能不可行（参见 Ng 等[16]）。如前所述，有些情况下 PMLE 和 MLP 无法获得。因此，有必要通过修改 PLF 来克服这个问题，然后开发未来记录值的替代 MLP 作为易于确定的预测量。为此，对 $\theta$ 的相应 PLE 进行修改将非常有用。

## 3 未来记录值的修正 MLP

本节考虑修改（2.1）中的 PLF，以允许基于观测记录 $\mathbf { X } = ( X _ { U ( 1 ) } , X _ { U ( 2 ) } , \ldots , X _ { U ( m ) } )$（$n \geq m + 1$）联合预测未来随机变量（如 $X _ { U ( n ) }$）和估计未知参数的问题。

### 3.1 基于变换的 PLF

首先，我们采用 Smith [17] 的方法，用其相合估计量 $\tilde { \theta } = X _ { U ( 1 ) }$ 估计未知位置参数 $\theta$。然后，可以基于跳过第一个记录统计量来修改 PLF。该方法基于 $X - \theta$ 服从 $W ( \alpha , \lambda )$ 以及 $X _ { U ( 1 ) }$ 是 $\theta$ 的相合估计这一事实。通过跳过初始记录，我们可以考虑以下变量：

$$
Y _ {2} = X _ {U (2)} - X _ {U (1)}, \quad Y _ {3} = X _ {U (3)} - X _ {U (1)}, \dots , Y _ {m} = X _ {U (m)} - X _ {U (1)},
$$

以及 $Y _ { n } = X _ { U ( n ) } - X _ { U ( 1 ) }$。

PLF 随后修改为

$$
L _ {T} = \prod_ {i = 2} ^ {m} h (y _ {i}) \frac {[ H (y _ {n}) - H (y _ {m}) ] ^ {n - m - 1}}{(n - m - 1) !} f (y _ {n}).
$$

基于观测记录间隔 $Y _ { i }$（$i = 2 , \ldots , m$）的第 n 个记录间隔 $Y _ { n }$ 的修正对数 PLF 形式为

$$
\begin{array}{l} \log L = m \log \alpha + (n - 1) \log \lambda + (\alpha - 1) \sum_ {i = 2} ^ {m} \log y _ {i} + (n - m - 1) \log \left(y _ {n} ^ {\alpha} - y _ {m} ^ {\alpha}\right) \\ + (\alpha - 1) \log y _ {n} - \lambda y _ {n} ^ {\alpha}. \tag {3.1} \end{array}
$$

方程（3.1）直接给出 $\lambda$ 的 PMLE 和 $Y _ { n }$ 的 MLP 的闭式表达式：

$$
\hat {Y} _ {n} = \left(\frac {(n - 2) \alpha + 1}{(m - 1) \alpha + 1}\right) ^ {1 / \alpha} Y _ {m}, \hat {\lambda} _ {T} = \frac {n - 1}{\hat {Y} _ {n} ^ {\alpha}},
$$

以及 $\alpha$ 的简化预测似然方程（PLE）：

$$
T _ {2} (\mathbf {y}) \alpha + m + \frac {1}{\alpha} \log \left(\frac {(n - 2) \alpha + 1}{(m - 1) \alpha + 1}\right) = 0, \tag {3.2}
$$

其中

$$
T _ {2} (\mathbf {y}) = \sum_ {i = 2} ^ {m} \log \left(\frac {y _ {U (i)}}{y _ {U (m)}}\right).
$$

与第2节类似的论证表明，（3.2）的左边是 $\alpha$ 的非增函数，从 0 处的 $n - 1$ 开始，当 $\alpha \to \infty$ 时趋于 $- \infty$。这确保了 $\alpha$ 的 PMLE（记为 $\hat { \alpha } _ { T }$）存在且唯一，然后 $\lambda$ 的 PMLE 和 $Y _ { n }$ 的 MLP 随之可得。现在，通过以下步骤描述该方法：

- 步骤1：形成观测记录值的 $( m - 1 )$ 个间隔

$$
Y _ {2} = X _ {U (2)} - X _ {U (1)}, Y _ {3} = X _ {U (3)} - X _ {U (1)}, \dots , Y _ {m} = X _ {U (m)} - X _ {U (1)};
$$

以及第 n 个记录间隔 $Y _ { n } = X _ { U ( n ) } - X _ { U ( 1 ) }$。

- 步骤2：基于 $Y _ { 2 } , Y _ { 3 } , \dots , Y _ { m }$ 获得 $\alpha$ 的 PMLE（记为 $\hat { \alpha } _ { T }$）。$\alpha$ 的 PMLE 是（3.2）的数值解；
- 步骤3：由步骤2，我们直接得到 $Y _ { n }$ 的 MLP 为

$$
\widehat {Y} _ {n} = \left(\frac {(n - 2) \hat {\alpha} _ {T} + 1}{(m - 1) \hat {\alpha} _ {T} + 1}\right) ^ {1 / \hat {\alpha} _ {T}} Y _ {m},
$$

然后使用变换程序得到 $X _ { U ( n ) }$ 的 MLP 为

$$
\delta_ {T} = X _ {U (1)} + \left(\frac {(n - 2) \hat {\alpha} _ {T} + 1}{(m - 1) \hat {\alpha} _ {T} + 1}\right) ^ {1 / \hat {\alpha} _ {T}} \left(X _ {U (m)} - X _ {U (1)}\right);
$$

- 步骤4：基于步骤2和3，用此方法得到的 $\lambda$ 的 PMLE（记为 $\widehat { \lambda } _ { T }$）为

$$
\hat {\lambda} _ {T} = \frac {n - 1}{\left(\frac {(n - 2) \hat {\alpha} _ {T} + 1}{(m - 1) \hat {\alpha} _ {T} + 1}\right) \left(X _ {U (m)} - X _ {U (1)}\right) ^ {\hat {\alpha} _ {T}}}.
$$

由于

$$
E X _ {U (1)} = \theta + \frac {\Gamma (1 + \frac {1}{\alpha})}{\lambda^ {\frac {1}{\alpha}}},
$$

$\theta$ 的偏差修正估计为

$$
\tilde {\theta} _ {T} = X _ {U (1)} - \frac {\Gamma \left(1 + \frac {1}{\hat {\alpha} _ {T}}\right)}{(\hat {\lambda} _ {T}) ^ {1 / \hat {\alpha} _ {T}}}.
$$

### 3.2 修正 PLF

Cheng 和 Iles [18] 提出的思想是考虑来自连续分布的失效率增量可以取为以下形式

$$
H \left(x _ {U (i)} + \Delta\right) - H \left(x _ {U (i)}\right) = \int_ {x _ {U (i)}} ^ {x _ {U (i)} + \Delta} h (x) d x.
$$

假设 $\varDelta$ 很小。PLF 取以下形式

$$
L _ {C} = \left[ H \left(x _ {U (2)}\right) - H \left(x _ {U (1)}\right) \right] \prod_ {i = 2} ^ {m} h \left(x _ {U (i)}\right) \frac {\left[ H \left(x _ {U (n)}\right) - H \left(x _ {U (m)}\right) \right] ^ {n - m - 1}}{(n - m - 1) !} f \left(x _ {U (n)}\right).
$$

然后在约束 $\theta < x _ { U ( 1 ) }$ 下，关于 $\theta , \alpha , \lambda$ 和 $x _ { U ( n ) }$ 最大化 $L _ { C }$，可以获得 $\theta$、$\alpha$、$\lambda$ 的 PMLE 和 $X _ { U ( n ) }$ 的 MLP。修正对数 PLF 变为

$$
\begin{array}{l} \log L _ {C} = m \log \alpha + n \log \lambda + \log \left[ (x _ {U (2)} - \theta) ^ {\alpha} - (x _ {U (1)} - \theta) ^ {\alpha} \right] \\ + (\alpha - 1) \sum_ {i = 2} ^ {m} \log \left(x _ {U (i)} - \theta\right) + (n - m - 1) \log \left[ \left(x _ {U (n)} - \theta\right) ^ {\alpha} - \left(x _ {U (m)} - \theta\right) ^ {\alpha} \right] \\ + (\alpha - 1) \log \left(x _ {U (n)} - \theta\right) - \lambda \left(x _ {U (n)} - \theta\right) ^ {\alpha}. \tag {3.3} \end{array}
$$

$\lambda$ 和 $X _ { U ( n ) }$ 的 PLE 给出 $\lambda$ 的修正 PMLE $\widehat { \lambda } _ { C }$ 和 $X _ { U ( n ) }$ 的 MLP $\delta _ { C }$ 的闭式表达式：

$$
\widehat {\lambda} _ {C} = \frac {n}{(x _ {U (n)} - \theta) ^ {\alpha}}
$$

和

$$
\delta_ {C} = \theta + \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) ^ {1 / \alpha} (x _ {U (m)} - \theta),
$$

这与精确的 $\lambda$ 的 PMLE 和 $X _ { U ( n ) }$ 的 MLP 的表达式相同。$\alpha$ 和 $\theta$ 的 PLE 分别为

$$
T _ {3} (\mathbf {x}, \theta) \alpha + m + \frac {1}{\alpha} \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) = 0 \tag {3.4}
$$

和

$$
\begin{array}{l} \left(x _ {U (m)} - \theta\right) \left\{(\alpha - 1) \sum_ {i = 2} ^ {m} \frac {1}{x _ {U (i)} - \theta} + \alpha \left[ \frac {\left(x _ {U (2)} - \theta\right) ^ {\alpha - 1} - \left(x _ {U (1)} - \theta\right) ^ {\alpha - 1}}{\left(x _ {U (2)} - \theta\right) ^ {\alpha} - \left(x _ {U (1)} - \theta\right) ^ {\alpha}} \right] \right\} \\ - (m \alpha + 1) = 0, \tag {3.5} \end{array}
$$

其中

$$
\begin{array}{l} T _ {3} (\mathbf {x}, \theta) = \frac {(x _ {U (2)} - \theta) ^ {\alpha} \log (x _ {U (2)} - \theta) - (x _ {U (1)} - \theta) ^ {\alpha} \log (x _ {U (1)} - \theta)}{(x _ {U (2)} - \theta) ^ {\alpha} - (x _ {U (1)} - \theta) ^ {\alpha}} \\ + \sum_ {i = 2} ^ {m} \log \left(x _ {U (i)} - \theta\right) - m \log \left(x _ {U (m)} - \theta\right). \tag {3.6} \end{array}
$$

这样获得的 $\alpha$ 和 $\theta$ 的修正 PMLE 分别记为 $\widehat { \alpha } _ { C }$ 和 ${ \widehat { \theta } } _ { C }$。

### 3.3 最大间距积预测

Cheng 和 Amin [19] 以及 Ranneby [20] 指出，最大间距积（MPS）估计是获得相合估计的良好替代方法，特别是当底层分布呈 J 形时，这种情况下 MLE 必然失效。类似的论证可以应用于记录数据，考虑一阶近似，其中最大化 $\log h \big ( x _ { U ( i ) } \big )$ 本质上与 $\log [ H ( x _ { U ( i ) } ) - H ( x _ { U ( i - 1 ) } ) ]$ 相同。因此，要最大化的间距积为

$$
L _ {P} = \prod_ {i = 1} ^ {m} [ H (x _ {U (i)}) - H (x _ {U (i - 1)}) ] \frac {[ H (x _ {U (n)}) - H (x _ {U (m)}) ] ^ {n - m - 1}}{(n - m - 1) !} f (x _ {U (n)}),
$$

其中对于 $i = 1$ 有 $H ( x _ { U ( i - 1 ) } ) = 0$。相应的对数似然为

$$
\begin{array}{l} \log L _ {p} \propto \log \alpha + n \log \lambda + \sum_ {i = 1} ^ {m} \log \left[ (x _ {U (i)} - \theta) ^ {\alpha} - (x _ {U (i - 1)} - \theta) ^ {\alpha} \right] \\ + (n - m - 1) \log \left[ \left(x _ {U (n)} - \theta\right) ^ {\alpha} - \left(x _ {U (m)} - \theta\right) ^ {\alpha} \right] + (\alpha - 1) \log \left(x _ {U (n)} - \theta\right) \\ - \lambda (x _ {U (n)} - \theta) ^ {\alpha}. \end{array}
$$

$\lambda$ 的修正 PMLE 和 $X _ { U ( n ) }$ 的 MLP 与 PMLE 和 MLP 相同。$\alpha$ 和 $\theta$ 的修正 PLE 为

$$
T _ {4} (\mathbf {x}, \theta) \alpha + 1 + \frac {1}{\alpha} \log \left(\frac {(n - 1) \alpha + 1}{m \alpha + 1}\right) = 0 \tag {3.7}
$$

和

$$
\alpha \left(X _ {U (m)} - \theta\right) \sum_ {i = 1} ^ {m} \frac {\left(x _ {U (i)} - \theta\right) ^ {\alpha - 1} - \left(x _ {U (i - 1)} - \theta\right) ^ {\alpha - 1}}{\left(x _ {U (i)} - \theta\right) ^ {\alpha} - \left(x _ {U (i - 1)} - \theta\right) ^ {\alpha}} - (m \alpha + 1) = 0, \tag {3.8}
$$

其中

$$
\begin{array}{l} T _ {4} (\mathbf {x}, \theta) = \sum_ {i = 1} ^ {m} \frac {\left(x _ {U (i)} - \theta\right) ^ {\alpha} \log \left(x _ {U (i)} - \theta\right) - \left(x _ {U (i - 1)} - \theta\right) ^ {\alpha} \log \left(x _ {U (i - 1)} - \theta\right)}{\left(x _ {U (i)} - \theta\right) ^ {\alpha} - \left(x _ {U (i - 1)} - \theta\right) ^ {\alpha}} \\ - m \log \left(x _ {U (m)} - \theta\right). \end{array}
$$

### 4.2 模拟研究

这里，我们比较基于观测前 m 个记录值估计模型参数 $( \theta , \alpha , \lambda )$ 和预测第 n 个未来记录的不同方法的性能。具体地，我们比较参数的 PMLE 在偏差和 MSE 方面的性能，以及 MLP 在偏差和 MSPE 方面的性能。

为此，从三参数 ${ \mathsf W } ( \theta , \alpha , \lambda )$ 分布生成记录数据，其中 $\theta = 5$，$\lambda = 3$，$\alpha = 2, 1, 0.5$，观测记录数据的大小分别为 $m = 6, 7, 8$，要预测的记录有不同选择（$m + 1 \leq n \leq m + 3$）。使用得到的记录数据，我们计算了第2节和第3节讨论的所有方法（即 MLP、MLP-T、MLP-C 和 MLP-M）每次模拟的估计量和预测量。对于预测问题，我们从威布尔分布随机生成上记录数据 $X _ { U ( 1 ) } , X _ { U ( 2 ) } , \dots , X _ { U ( m ) }$，对于给定的 $n ( n > m )$，我们计算点预测值以及相应的 PI。（2.5）中的非线性方程随后被数值求解，以获得参数的 PMLE 和 $X _ { U ( n ) }$ 的 MLP。类似地，第3节中的其他非线性方程被数值求解以获得 MLP-T、MLP-C 和 MLP-M。具体地，对于 MLP-T，需要求解（3.2）以获得 $\hat { \alpha }$，然后使用其显式形式获得 $\hat { \lambda }$ 和 $\hat { X } _ { U ( n ) }$。对于 MLP-C 和 MLP-M，分别基于（3.4）-（3.5）和（3.7）-（3.8）计算 $\hat { \alpha }$ 和 $\hat { \theta }$，然后从其函数形式获得 $\hat { \lambda }$ 和 $\hat { X } _ { U ( n ) }$。

每种方法在1000次重复中计算了参数估计的偏差和 MSE 以及预测量的偏差和 MSPE，这些结果列于表2-4。表5-7展示了基于 bootstrap-t 方法的 $\theta$、$\lambda$、$\alpha$ 的 $95\%$ CI 和未来第 n 个记录的 $95\%$ PI 的平均长度（AL）和覆盖概率（CP）。如第2节所述，对于 $\alpha < 1$，由于无法满足（2.9），估计未知参数、PMLE 和预测未来记录的精确方法不适用。

尽管大的形状参数不会改变三参数威布尔模型分布的形状，但少量极端抽样估计可能掩盖所获得估计量的真实性能表现。因此，很难评估它们的准确性（参见 Ng 等[16]）。为克服这个问题，我们舍弃了形状参数 $\alpha$ 的估计值比其初始值大 $\epsilon _ { 0 } = 5$ 以上的样本。然后我们为每种方法获得了1000组有效估计（即计算优化算法收敛且 $\alpha$ 的估计值被接受的情况）。

从表2-4可以清楚地看到，对于考虑的所有 $\alpha$ 值，使用 MLP-T 的参数估计的偏差和 MSE 小于其他方法。未来记录的预测也有相同的观察结果。对于 $\alpha = 2$ 和 1 的情况，MLP 方法在估计和预测方面都是第二好的方法。正如预期的那样，当观测记录数 m 增加时，点估计量和预测量的性能会改善。此外，当 n 远离 m 时，正如预期的那样，$X _ { U ( n ) }$ 的变化趋于变大，因此这种情况下 PI 变得更宽。

从表5-7可以观察到，对于考虑的所有 $\alpha$ 值，基于 MLP-T 获得的 CI 和 PI 是最窄的。对于 $\alpha = 2$ 和 1，与 MLP-C 和 MLP-M 相比，MLP 方法表现良好。有明确的证据表明，所有方法在 CP 方面都是有效的程序，因为它们确实提供了接近名义水平0.95的模拟 CP。从表7还可以注意到，对于 n 的各种值，基于 MLP-T 方法的 PI 是与其他 PI 相比最窄的 PI，而 MLP-C 导致最宽的 PI。

表5-8（略）：详细数值结果

最后，为了检查我们模拟研究中可靠样本的百分比，我们计算了 $m = 7, 9$ 和 $\alpha = 2, 0.5$ 时形状参数的估计值有效的可靠样本占所有考虑样本的百分比。模拟百分比列于表8。可以容易地观察到，MLP-T 方法具有最高的可靠样本百分比，而与 MLP-T 和 MLP 方法相比，MLP-M 和 MLP-C 给出最低的百分比。

与其他方法不同，MLP-T 在计算上是容易的，因为与变换方法相关的非线性方程比其他方法中涉及的非线性方程更容易求解。因此，基于这项研究，我们推荐 MLP-T 是基于我们考虑的所有最优性准则估计模型参数以及预测未来记录的首选方法。

## 5 结论

本文基于记录数据考虑了三参数威布尔分布的估计和预测问题。使用极大似然方法进行未来记录的联合预测以及模型中所有参数的估计。详细讨论了未来记录的 MLP 以及所有未知量的 PMLE 的存在性和唯一性。研究表明，MLP 和 PMLE 并不总是存在，或者即使存在也可能不可行。为此，通过修改 PLF 开发了其他近似方法，然后获得了修正的 MLP 和 PMLE。这些替代方法是基于变换、修正和最大间距积方法开发的。此外，通过数值模拟在不同大小的观测记录 m 和各种要预测的记录选择 n 下，以偏差和 MSE 为准则比较了 MLP、PMLE 及其近似。观察到，总体而言，以偏差、MSE、AL 和 CP 为最优性准则，MLP-T 是与其他方法相比最好的方法。
