# 基于最小二乘支持向量机的小样本威布尔可靠性分析

张新锋1 赵 彦2

长安大学汽车运输安全保障技术交通行业重点实验室,西安,西安电子科技大学,西安,

摘要:在图估法的基础上,提出了基于最小二乘支持向量机的威布尔可靠性分析方法,在平台上绘制了威布尔概率纸,通过程序化的方式分析估计威布尔概率参数;进行了可靠性寿命分析,并对比分析了基于最小二乘支持向量机、支持向量机和最小二乘法威布尔可靠性分析的效果。实例分析结果显示,在威布尔可靠性分析中,最小二乘支持向量机的拟合精度不仅优于传统的最小二乘法的拟合精度,而且优于支持向量机的拟合精度,表明该方法可以提高可靠性分析效率和精度,可作为威布尔可靠性分析的一种新方法,特别适用于小样本的情况。

## 0 引言

威布尔分布对试验数据有较强的拟合能力在可靠性工程中得到了广泛的应用。关于威布尔分布三参数的估计 以及以此为基础进行的寿命特征估计 一直以来是工程研究中的一个重要问题 常用的估计方法主要有最大似然法和图估计法 最大似然法相对精度高 但是计算复杂 且要求正则条件,往往导致多解和无解发生[1],为此一些改进的最大似然法<sup>[</sup>2<sup>]</sup>被提出 但依然过于繁琐不便在工程中应用。而图估计法相对简便,但是精度不高,也出现了一些改进的图估计法[3飊4],丰富了解决这一问题的理论。

在威布尔可靠性分析中 在数据点的拟合方面,过去一直采用最小二乘法,而近年来发展起来的一种专门研究小样本情况下的机器学习规律理论———支持向量机理论,被认为是针对小样本统计和预测学习的最佳理论<sup>[</sup>5<sup>]</sup> 可以用于解决数据拟合的问题 支持向量机 <sup>[</sup>6<sup>]</sup>建立在维理论基础上,采用结构风险最小化原则,不仅结构简单 且有效解决了模型选择与欠学习 过学习 小样本 非线性 局部最优和维数灾难等问题[7],泛化能力大大提高,成为学术研究的热点。在模式识别 函数估计 时间序列预测 医学上的病况检测等领域得到了广泛的应用<sup>[</sup>8飊9<sup>]</sup>

本文试图采用支持向量机理论 在平台上通过编程绘制威布尔概率纸 在图估计法的基础上 提出了改进的威布尔可靠性分析

方法。

## 威布尔可靠性分析

威布尔分布的分布函数为

$$
F (t) = 1 - \exp \left[ - \frac {(t - a) ^ {m}}{t _ {0}} \right]\tag{1}
$$

其中,随机变量t不小于位置参数 $a$ ,即 $t \geqslant a$ ,形状参数 $m > 0$ ,尺度参数 $t _ { 0 } > 0$

当 $a = 0$ 时,式()可以表示为

$$
F (t) = 1 - \exp (- \frac {t ^ {m}}{t _ {0}})\tag{2}
$$

对式()进行恒等变换,整理得

$$
\ln (\ln \frac {1}{1 - F (t)}) = m \ln t - \ln t _ {0}\tag{3}
$$

设

$$
\left. \begin{array}{l} x = \ln t \\ y = \ln (\ln \frac {1}{1 - F (t)}) \\ B = \ln t _ {0} \end{array} \right\}\tag{4}
$$

把式(4)代入式(3),可得

$$
y = m x - B\tag{5}
$$

根据式 和式 可在 $x - y$ 和 $t - F ( t )$ )两个坐标系上建立一张特殊的坐标纸,即威布尔概率纸。

把数据 $( t _ { i } , F ( t _ { i } ) )$ 描在威布尔概率纸上 如果产品的寿命服从威布尔分布 且 $a = 0$ 根据式(),则这些数据点会形成一条回归直线,据此可以估计出威布尔分布的参数 分析产品寿命特征 当然 对于 $a \ne 0$ 的情况 这种方法也是同样适用的 不过需要进行一些变换处理

## 2.1 最小二乘支持向量机

在进行威布尔概率可靠性分析时 对于数据点的回归直线分析通常用最小二乘法 这里我们试图采用最小二乘支持向量机 进行回归分析。

设训练样本有 l 个,样本集记为 $T = \{ \boldsymbol { \mathbf { \mathit { x } } } _ { i }$ $y _ { i } ) \}$ 其中 $, x _ { i } \in \mathbf { R } ^ { n } , y _ { i } \in \mathbf { R } , i = 1 , 2 , \cdots , l ,$ 对于支持向量机回归分析 有两个最基本的问题在 $\mathbf { R } ^ { n }$ 中寻找一个实值逼近函数 $f ( x )$ ),使得定义在 毰 不敏感损失函数下函数估计的结构风险最小,以便用 $_ { y } = f ( \boldsymbol { x } )$ 推断对任一输入 $_ { \mathcal { X } }$ 所对应的 $y$ 值 尽可能保证函数 $f ( x )$ )平坦。

根据结构风险最小化原则[10],函数逼近的最小二乘支持向量机采用等式约束,把原始问题变成了求解凸二次规划问题，

$$
\left. \begin{array}{l} \min \frac {1}{2} \| \boldsymbol {w} \| ^ {2} + \frac {\gamma}{2} \sum_ {i = 1} ^ {l} \boldsymbol {\eta} _ {i} ^ {2} \\ \text {s.t.} y _ {i} - (\langle \boldsymbol {w} \cdot \varphi (x _ {i}) \rangle + b) = \boldsymbol {\eta} _ {i} \quad i = 1, 2, \dots , l \end{array} \right\}\tag{6}
$$

其中, $w$ 为权向量, $\gamma$ 为正则化参数, $\pmb { \eta } _ { i }$ 为误差向量, $\varphi ( \boldsymbol { \mathscr { x } } _ { i } )$ )为 $\boldsymbol { \mathscr { x } } _ { i }$ 的变换,b 为偏置量。

采用拉格朗日乘子法求解,可得如下求解矩阵:

$$
\begin{array}{r l} & {\left[ \begin{array}{c c} 0 & \mathbf {1} ^ {\mathrm{T}} \\ \mathbf {1} & \mathbf {K} + \frac {\mathbf {I}}{\gamma} \end{array} \right] \left[ \begin{array}{l} b \\ \boldsymbol {\alpha} \end{array} \right] = \left[ \begin{array}{l} 0 \\ \mathbf {y} \end{array} \right]} \\ & {\quad \mathbf {y} = \left[ \begin{array}{l l l l} y _ {1} & y _ {2} & \dots & y _ {l} \end{array} \right] ^ {\mathrm{T}}} \\ & {\quad \mathbf {1} = \left[ \begin{array}{l l l l} 1 & 1 & \dots & 1 \end{array} \right] ^ {\mathrm{T}}} \\ & {\quad \boldsymbol {\alpha} = \left[ \begin{array}{l l l l} \alpha_ {1} & \alpha_ {2} & \dots & \alpha_ {l} \end{array} \right] ^ {\mathrm{T}}} \\ & {\mathbf {K} = \mathbf {K} (x _ {i}, x _ {j}), i, j = 1, 2, \dots , l} \end{array}\tag{7}
$$

式中 K为满足 条件的核函数

通过求解式(),可解得 毩 和b,即

$$
\left. \begin{array}{c} \boldsymbol {\alpha} = \boldsymbol {A} ^ {- 1} (\boldsymbol {y} - b \boldsymbol {1}) \\ b = \frac {\boldsymbol {1} ^ {\mathrm{T}} \boldsymbol {A} ^ {- 1} \boldsymbol {y}}{\boldsymbol {1} ^ {\mathrm{T}} \boldsymbol {A} ^ {- 1} \boldsymbol {1}} \\ \boldsymbol {A} = \boldsymbol {K} + \boldsymbol {I} / \gamma \end{array} \right\}\tag{8}
$$

把式()代入 $w = \sum _ { i = 1 } ^ { l } \alpha _ { i } x _ { i }$ (该式是在求解式()过程中得到的),进一步可得到回归方程:

$$
f (x) = \sum_ {i = 1} ^ {l} \alpha_ {i} \mathbf {K} \left(x _ {i}, x\right) + b\tag{9}
$$

## 2.2.2 LSSVM 回归直线拟合

对寿命数据进行直线拟合时,通常首先要对数据进行预处理和后处理 选择合适的核函数对参数进行优化选择 才能获得较好的预测效果。

数据的预处理和后处理 为了加快训练收敛性,首先对数据进行归一化预处理。归一化的方法通常有线性函数转换、对数函数转换和反余切函数转换 对于数据拟合 通常可以采用线性函数转换的方法,即

$y = \left[ x _ { i } - \operatorname* { m i n } ( x _ { i } ) \right] / \left[ \operatorname* { m a x } ( x _ { i } ) - \operatorname* { m i n } ( x _ { i } ) \right]$ ( )其中, $, x _ { i } \setminus y$ 分别表示预处理前后的数值。

值得注意的是 经过最小二乘支持向量机拟合后的寿命数据 必须再进行反归一化处理 即后处理 后才能得到真正的拟合值

核函数的选择 常用的核函数主要有线性核函数 多项式核函数 径向基核函数核函数、非齐次多项式多项式核函数[11]。这里选用最常用的径向基核函数作为训练核函数:

$$
\mathbf {K} (x, x _ {i}) = \exp (- \| x - x _ {i} \| ^ {2} / \sigma^ {2})\tag{12}
$$

式中 $, \sigma$ 为核宽度。

参数选择 选择不同的参数对预测结果的准确性影响很大,如果参数选择不当,可能直接导致拟合结果的失效 这里 对支持向量机和最小二乘支持向量机拟合参数分别采用交叉验证和网格搜索法,通过程序优化选择最佳参数,以保证结果的有效性

## .. 回归直线拟合误差分析

为了验证 的逼近性能 必须对数据拟合效果进行误差分析。可以使用如下指标进行比较。

()R 的平方 $( R - \mathrm { S q u a r e } )$ ,即拟合优度为

$$
R ^ {2} = 1 - \sum_ {i = 1} ^ {n} (y _ {i} - \hat {y} _ {i}) / \sum_ {i = 1} ^ {n} (y _ {i} - \hat {y})\tag{13}
$$

$R ^ { 2 }$ 即响应数据与预测响应数据之间相关系数的平方，该值越接近1，表明拟合效果越好。

()均方根误差(RMSE)为

$$
R M S E = \sqrt {\sum_ {i = 1} ^ {n} (y _ {i} - \overline {{{{y}}}} _ {i}) ^ {2} / n}\tag{14}
$$

均方误差越接近 ,表明拟合效果越好。

## 4 结束语

本文对比分析了最小二乘支持向量机 支持向量机和最小二乘法在小样本威布尔可靠性分析中的效果 并采用 对威布尔概率纸编程,分析过程采用程序化方式实现,提高了威布尔分布参数估计和可靠性分析的效率和精度。由于支持向量机在小样本统计和预测方面的出色性能 通过实验仿真分析发现 在小样本情况下 最小二乘支持向量机拟合精度最高 参数估计最为准确 而且其计算过程较为简便 可以作为威布尔可靠性分析中的一种新方法。
