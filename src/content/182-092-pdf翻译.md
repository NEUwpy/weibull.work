# 非线性回归中最小二乘全局最小值准则

Eugene Demidenko

Section of Biostatistics and Epidemiology, Dartmouth Medical School, Lebanon, NH 03756, USA

Received 27 February 2006; received in revised form 12 June 2006; accepted 18 June 2006

Available online 28 August 2006

# 摘要

Demidenko [2000. Is this the least squares estimate? Biometrika 87, 437–452] 建立了非线性回归曲率与残差平方和局部凸性之间的关系：当残差平方和小于全曲率的最小平方半径时，Hessian矩阵是正定的。在本文中，我们继续发展非线性回归中残差平方和全局最小值的准则。特别地，引入了局部单峰性的概念；如果一个函数在水平集的每个分量中都有唯一的局部最小值，则称该函数在该水平集上是局部单峰的。我们证明了残差平方和的局部单峰性水平等于非线性回归函数固有曲率的最小平方半径。引入了一类新的单向非线性回归模型，并用微分几何进行了解释。通过几个常用的非线性回归模型对这些准则进行了说明。

# 1. 引言

统计中的曲率概念，特别是在非线性回归中，已经发展得相当成熟。Beal (1960) 是第一个将曲率概念应用于改进非线性回归中近似置信区间的人。他的思想在Bates and Watts (1980, 1981, 1988)、Wei (1994)、Kang and Rawlings (1998)以及Haines et al. (2004)的工作中得到了进一步发展。Guay (1995)将曲率方法推广到多响应非线性回归。Hougaard (1982)和Kass (1984)强调了重新参数化以减小曲率并改进非线性回归置信区间的重要性。Hougaard (1985)利用回归曲率推导了最小二乘估计量的近似分布。多位作者利用曲率为非线性回归寻找最优设计（Hamilton and Watts, 1985）。曲率的一般统计方面在Amari (1985)和Kass and Vos (1997)的著作中有讨论。

本文的主题是构建非线性回归中残差平方和（SS）最小化的全局准则。众所周知，常用的最小化算法如Gauss-Newton和Levenberg-Marquardt只能找到局部最小值（Bard, 1973）。SS最小化的最终迭代是否得到最小二乘估计？这是一个容易提出却难以回答的问题。事实上，正如Demidenko (2000)所指出的，在温和的假设下，对于任何非线性回归，SS至少有两个局部最小值的概率都不为零。

在早期工作中，Demidenko (1989)和Chavent (1991a,b,c)用几何术语表述了全局准则：如果收敛时的SS很小，那么找到的最小值就是全局的。多小才算足够小，阈值是多少？在我们之前的论文（Demidenko, 2000）中，引入了局部凸性的概念，即SS的Hessian矩阵是正定的。在本文中，我们发展了更精确的准则来验证局部最小值是否为全局最小值。特别地，建立了与回归曲率的联系：基本上，阈值等于最大曲率平方的倒数。

现在我们引入符号和基本概念。设$y _ { i }$为第i个观测值，$f \left( \mathbf { x } _ { i } ; \pmb { \alpha } \right)$为相应的回归函数，其中$\mathbf { x } _ { i }$是固定向量，$\pmb { \alpha } = ( \alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { m } ) \in \pmb { \Theta } \subset \ l _ { R } m$是未知向量参数（我们用粗体表示向量和矩阵）。我们假设$f$是两次连续可微函数，且$\mathbf { \Theta } _ { \mathbf { \Theta } } \Theta$是一个开放的m维凸子集。由于$\left\{ \mathbf { x } _ { i } \right\}$是非随机向量，我们可以通过设$f _ { i } \left( { \pmb { \alpha } } \right) = f \left( \mathbf { x } _ { i } ; \pmb { \alpha } \right)$来简化符号。那么非线性回归模型的形式为

$$
y _ {i} = f _ {i} (\boldsymbol {\alpha}) + \varepsilon_ {i}, \quad i = 1, \dots , n, \tag {1}
$$

其中假设$E \left( \varepsilon _ { i } \right) = 0$；$\varepsilon _ { 1 } , \ldots , \varepsilon _ { n }$独立同分布，具有正密度函数$( n \geqslant m )$。$R ^ { n }$中的点集{f1(), . . . , $f _ { n } ( { \pmb { \alpha } } ) : { \pmb { \alpha } } \in { \pmb { \Theta } } \}$称为期望（或回归）曲面（Bates and Watts, 1988; Seber and Wild, 1989）。我们要研究的对象是SS

$$
S (\boldsymbol {\alpha}) = \sum_ {i = 1} ^ {n} \left(y _ {i} - f _ {i} (\boldsymbol {\alpha})\right) ^ {2}, \quad \boldsymbol {\alpha} \in \boldsymbol {\Theta}. \tag {2}
$$

我们想在$\Theta \subset R ^ { m }$上找到$S ( { \pmb \alpha } )$的全局最小值。使S最小化的$\pmb { x } = \widehat { \pmb { \alpha } }$值称为最小二乘估计。在优化文献中，$\mathbf { \Theta } _ { \Theta }$被称为最小化域，$\widehat { \pmb { \alpha } }$被称为最小化点（minimizer）（Chong and Zak, 1996）。假设非线性回归是正则的（Gallant, 1987; Pazman, 1993）。即，导数矩阵满秩：对所有${ \pmb { \mathscr { x } } } \in \Theta$，rank $\mathbf { G } ( { \pmb { \alpha } } ) = m$，其中$\mathbf { G } ( \pmb { \alpha } )$是一阶导数的$n \times m$矩阵，$\left\{ \phantom { } \hat { \mathrm { o f } } / \phantom { } \hat { \mathrm { o } } \alpha _ { 1 } , \dots , \hat { \mathrm { o f } } / \phantom { } \hat { \mathrm { o } } \alpha _ { m } \right\}$。此外，假设非线性回归是可识别的：即$f \left( \pmb { \alpha } _ { 1 } \right) = f \left( \pmb { \alpha } _ { 2 } \right)$意味着${ \pmb x } _ { 1 } = { \pmb x } _ { 2 }$。

全局准则用水平集来表述，定义为$L \left( S _ { * } \right) = \left\{ \pmb { \alpha } \in \pmb { \Theta } : S ( \pmb { \alpha } ) < S _ { * } \right\}$。图1显示了一个典型的多峰SS。全局最小值是$B$，$C$是局部最小值；$A$是稳定/驻点，梯度为零的地方。在Demidenko (2000)中，我们将局部凸性水平集定义为$S ( { \pmb \alpha } )$局部凸的水平集。即，Hessian矩阵正定的地方。在本文中，我们引入局部单峰性的概念，并将其与固有曲率半径联系起来。这个概念成为我们全局准则的基石。

论文结构如下。在下一节中，引入局部单峰性的概念并陈述主要结果：SS的局部单峰性水平等于固有曲率的最小平方半径。在第3节中，我们给出几何解释。第4节引入两类新的非线性回归。第5节通过几个例子说明局部单峰性和凸性的计算。

# 2. SS的局部单峰性

在本节中，我们给出局部单峰性的定义，并表述SS (2)的全局准则。

从任意二次可微函数$F ( \mathbf { u } )$，$\mathbf { u } \in R ^ { m }$（下有界）开始讨论是有益的。设$F _ { * }$为任意数。显然，水平集$L \left( F _ { * } \right) = \left\{ { \mathbf { u } } \in R ^ { m } : F ( { \mathbf { u } } ) < F _ { * } \right\}$可能不是凸的，甚至不是连通的。然而，根据一般拓扑学，$L (F_*)$可以表示为其不相交开分量的并集（Kelley, 1975）。水平集的每个分量可以看作是一个最大连通子集。如果一个集合只包含一个分量，则它是连通的（Ortega and Rheinboldt, 1970）。下一个结果将多个局部最小值的存在与水平集的分离联系起来。

**命题1**（Ortega and Rheinboldt, 1970）。设$F ( \mathbf { u } )$是连通集$Q \subset R ^ { m }$上的连续函数。如果该函数至少有两个局部最小值，则存在$F _ { * }$使得相应的水平集不连通。反之，如果存在$F _ { * }$使得水平集有界且不连通，则$F ( \mathbf { u } )$在$Q$上至少有两个局部最小值。

现在我们可以引入局部单峰性的概念——读者可参考图2的几何说明，其中$F$是SS $( m = 1 )$。

![](/182-092-图片/images/316cf569a0f02ededfcc550cf2cc22ed0f345103593d107323abe824c9ab3c5c.jpg)
图1. 残差平方和的四个水平集。如果存在一个参数值使其残差平方和小于存在水平$\overline { { S } } _ { \mathrm { E } }$，则存在水平集是有界的。局部单峰性水平集由两个分量组成，对应于两个局部最小值。然而，每个分量中只有一个局部最小值。残差平方和的Hessian矩阵在局部凸性水平集上是正定的。最后，全局最小值水平集是凸的。如果$\alpha _ { * }$是一个局部最小化点，其残差平方和小于全局最小值水平，则$\alpha _ { * }$是最小二乘估计。

**定义1**。我们称$F ( \mathbf { u } )$在水平集$L (F_*)$上是局部单峰的，如果每个分量包含不超过一个局部最小值。值$F _ { * }$称为局部单峰性水平。

注意，可能存在一个连续的局部单峰性水平；它们的上确界称为上局部单峰性水平。下面将建立局部单峰性与回归曲面固有曲率平方半径之间的关系（见定义3和定理2）。

显然，如果$F ( \mathbf { u } )$在$L ( F _ { * } )$上是严格局部凸函数，则$F ( \mathbf { u } )$是局部单峰的。在表述局部单峰性的一般准则之前，我们将存在水平（existence level）的概念（Nakamura, 1984; Demidenko, 1989）推广到最小化域不一定与整个空间$R ^ { n }$重合的情况。

**定义2**。设$F ( \mathbf { u } )$，$\mathbf { u } \in { \cal { Q } }$是凸集$Q \subset { \cal R } ^ { m }$上的连续函数。设$\widehat { \mathrm { d } } Q$表示$Q$的边界。$F$在$Q$上的存在水平定义为

$$
\bar {F} _ {\mathrm {E}} = \inf  _ {\mathbf {u} _ {*} \in \partial Q} \lim  _ {\mathbf {u} _ {k} \rightarrow \mathbf {u} _ {*}} F (\mathbf {u} _ {k}). \tag {3}
$$

![](/182-092-图片/images/10022d22d1c7b3c59043ca43108fa27bbaba18676c99a9a0171bcf1baf2d5c81.jpg)
图2. 局部单峰性的几何说明：对于局部单峰回归（左图），点$B$和$C$是局部最小值点，A是最大值点。水平集$\left\{ \alpha \in R ^ { 1 } : \| \mathbf { y } - f ( \alpha ) \| ^ { 2 } < r ^ { 2 } \right\}$由两个区间（粗弧）组成。每个区间上有一个最小值。因此，$r ^ { 2 }$是一个局部单峰性水平。右边的回归不是局部单峰的，因为有两个最小值的残差平方和都小于$r ^ { 2 }$。

换句话说，存在水平是所有以$Q$的边界点为极限点的序列的$F$值的最小极限。特别地，如果$Q = R ^ { m }$，我们有

$$
\overline {{F}} _ {\mathrm {E}} = \lim  _ {r \to \infty} \inf  _ {\| \mathbf {u} \| \geqslant r} F (\mathbf {u}).
$$

Demidenko (2000)中给出了SS的存在水平$\overline { { S } } _ { \mathrm { E } }$的类似定义。存在准则很容易使用：如果${ \mathbf { u } } _ { 0 } \in { \cal Q }$使得$F \left( \mathbf { u } _ { 0 } \right) < { \overline { { F } } } _ { \mathrm { E } }$，则$F$在$Q$上的全局最小值可以达到。一些常用非线性回归的最小二乘估计存在准则可以在Demidenko (1996)、Jukic and Scitovski (2003)、Jukic (2004)、Jukic et al. (2004)中找到。

现在我们可以表述以下基本结果，这是我们研究的核心。

**定理1**（Demidenko, 1989）。设$F ( { \mathbf { u } } )$是凸集$Q$上的二次可微函数，且存在一点${ \mathbf { u } } _ { 0 } \in { \mathfrak { Q } }$使得$F _ { 0 } = F \left( \mathbf { u } _ { 0 } \right) < \overline { { F } } _ { \mathrm { E } }$。那么，全局最小化点存在。此外，如果$\mathbf { u } _ { * } \in L = \{ \mathbf { u } \in Q : F ( \mathbf { u } ) < F _ { 0 } \}$且$\widehat { \mathrm { O } } F \left( \mathbf { u } _ { * } \right) / \widehat { \mathrm { O } } \mathbf { u } { = } 0$，这意味着$\widehat { 0 } ^ { 2 } F \left( \mathbf { u } _ { * } \right) / \widehat { 0 } \mathbf { u } ^ { 2 }$是正定矩阵，则$L$的每个分量上只存在一个局部最小化点。即，$F ( \mathbf { u } )$在$L$上是局部单峰的。特别地，如果$L$是连通的，则$F$在$L$上只有一个局部最小值，也就是全局最小值。

Mäkeläinen et al. (1981)对特殊情况$\overline { { F } } _ { \mathrm { E } } = \infty$得到了类似结果，另见Demidenko (2000)中的引理A.1。Gasanov and Rikun (1985)也得到了另一个类似结果。条件$F _ { 0 } < \overline { { F } } _ { \mathrm { E } }$保证了最小值的存在。

值得注意的是，在标准多元微积分中，要确认一个函数是单峰的，需要证明Hessian矩阵在所有点都是正定的。根据定理1，只需检验驻点处Hessian的正定性就足够了。

现在我们将定理1应用于SS。在代数上，为了找到局部单峰性水平，我们需要在限制条件$\partial S / \partial { \pmb { \alpha } } = \mathbf { 0 }$下找到一个使Hessian正定的SS值。以下结果是经典Cauchy不等式的推广。

**命题2**（线性限制下的Cauchy不等式）。设$\mathbf{e}$和$\mathbf{h}$为$n \times 1$非零向量，$\mathbf{G}$为满秩的$n \times m$矩阵$( m \leqslant n )$。则在限制条件$\mathbf { G ^ { \prime } e } = \mathbf { 0 }$下，以下不等式成立：

$$
\mathbf {e} ^ {\prime} \mathbf {h} \leqslant \| \mathbf {e} \| \left[ \mathbf {h} ^ {\prime} \left\{\mathbf {I} - \mathbf {G} \left(\mathbf {G} ^ {\prime} \mathbf {G}\right) ^ {- 1} \mathbf {G} ^ {\prime} \right\} \mathbf {h} \right] ^ {1 / 2} \tag {4}
$$

当$\mathbf{h}$可以表示为矩阵$\mathbf{G}$的列向量的线性组合时，不等式变为等式。

**证明**。设$\mathbf{t}$为任意$n \times 1$向量。那么，根据经典Cauchy不等式

$$
\mathbf {e} ^ {\prime} \mathbf {h} = \mathbf {e} ^ {\prime} \mathbf {h} - \mathbf {e} ^ {\prime} \mathbf {G t} = \mathbf {e} ^ {\prime} (\mathbf {h} - \mathbf {G t}) \leqslant \| \mathbf {e} \| \| \mathbf {h} - \mathbf {G t} \|.
$$

显然，如果$\mathbf { h } = \mathbf { G } \mathbf { t }$，不等式变为等式。由于最后一个不等式对任意$\mathbf{t}$成立，我们可以取$\mathbf { t } = \mathbf { t } _ { * }$使得

$$
\| \mathbf {h} - \mathbf {G t} _ {*} \| = \min  _ {t} \| \mathbf {h} - \mathbf {G t} \| = \left[ \mathbf {h} ^ {\prime} \left\{\mathbf {I} - \mathbf {G} \left(\mathbf {G} ^ {\prime} \mathbf {G}\right) ^ {- 1} \mathbf {G} ^ {\prime} \right\} \mathbf {h} \right] ^ {1 / 2},
$$

这就得到了(4)。□

在将推广的Cauchy不等式(4)应用于SS (2)之前，我们注意到半梯度和半Hessian矩阵分别为

$$
\frac {1}{2} \frac {\partial S (\boldsymbol {\alpha})}{\partial \boldsymbol {\alpha}} = - \mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \mathbf {e} (\boldsymbol {\alpha}), \tag {5}
$$

$$
\frac {1}{2} \frac {\partial^ {2} S (\boldsymbol {\alpha})}{\partial \boldsymbol {\alpha} ^ {2}} = \mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \mathbf {G} (\boldsymbol {\alpha}) - \sum_ {i = 1} ^ {n} e _ {i} (\boldsymbol {\alpha}) \mathbf {H} _ {i} (\boldsymbol {\alpha}), \tag {6}
$$

其中$\mathbf { e } ( \pmb { \alpha } ) = ( e _ { 1 } ( \pmb { \alpha } ) , \dots , e _ { n } ( \pmb { \alpha } ) ) ^ { \prime }$是$n \times 1$残差向量，第i个分量为$e _ { i } ( { \pmb { \alpha } } ) = y _ { i } - f _ { i } ( { \pmb { \alpha } } )$，$\mathbf G ( \pmb { \alpha } )$是一阶导数的$n \times m$矩阵，$\mathbf { H } _ { i } ( \pmb { \alpha } ) = \hat { \sigma } ^ { 2 } f _ { i } / \hat { \sigma } \pmb { \alpha } ^ { 2 }$是二阶导数的$m \times m$矩阵。

**定义3**。期望曲面在方向向量$\mathbf { p } \in R ^ { m }$上，点${ \pmb { \alpha } } \in { \bf { \Theta } } \Theta$处的固有曲率半径定义为（Bates and Watts, 1988）

$$
R _ {\mathrm {I}} (\alpha , p) = \frac {\mathbf {p} ^ {\prime} \mathbf {G} ^ {\prime} (\alpha) \mathbf {G} (\alpha) \mathbf {p}}{\sqrt {\mathbf {h} ^ {\prime} (\mathbf {p} , \alpha) \mathbf {P} (\alpha) \mathbf {h} (\mathbf {p} , \alpha)}}, \tag {7}
$$

其中

$$
\mathbf {P} (\boldsymbol {\alpha}) = \mathbf {I} - \mathbf {G} (\boldsymbol {\alpha}) \left(\mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \mathbf {G} (\boldsymbol {\alpha})\right) ^ {- 1} \mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \tag {8}
$$

是$n \times n$矩阵，$\mathbf { h } ( \mathbf { p } , \pmb { \alpha } )$是$n \times 1$向量，第i个元素为$\mathbf { p } ^ { \prime } \mathbf { H } _ { i } ( \pmb { \alpha } ) \mathbf { p }$。如果(7)的分母为零，我们设$R _ { \mathrm { I } }$为无穷大。非线性回归模型SS的上局部单峰性水平定义为

$$
\bar {S} _ {\mathrm {L U}} = \min  _ {\boldsymbol {\alpha} \in \Theta} \min  _ {\mathbf {p}} R _ {\mathrm {I}} ^ {2} (\boldsymbol {\alpha}, \mathbf {p}), \tag {9}
$$

局部单峰性水平$S _ { \mathrm { L U } }$是任何小于或等于$\overline { { S } } _ { \mathrm { L U } }$的数。

注释：(1) 在微分几何教材中，使用外曲率（extrinsic curvature）一词代替固有曲率（intrinsic curvature）（Weisstein, 2003）。我们倾向于使用原来的术语，因为它在统计学界更为人熟知。(2) 在符号方面，我们用上划线表示上水平；在实践中，我们可能无法得到它，因为它需要最小化，但较低的近似也可以工作（详见下文）。

可以证明，固有曲率是期望曲面$\mathbf f ( \pmb { \alpha } )$上测地线的曲率，Bates and Watts (1988)和Pazman (1993)。回顾一下，测地线是曲线$\pmb { \eta } ( \lambda ) = \mathbf { f } ( \pmb { \psi } ( \lambda ) )$，其中$\psi ( \lambda )$是$R ^ { m }$中的曲线，其加速度与切平面正交，或用符号表示，$\mathbf { \ddot { \pmb { \eta } } } \perp \mathbf { G }$。更多讨论见第4节。

众所周知，方向$\mathbf{p}$上的全曲率半径由下式给出

$$
R _ {\mathrm {F}} (\boldsymbol {\alpha}, \mathbf {p}) = \frac {\mathbf {p} ^ {\prime} \mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \mathbf {G} (\boldsymbol {\alpha}) \mathbf {p}}{\left[ \sum_ {i} \left\{\mathbf {p} ^ {\prime} \mathbf {H} _ {i} (\boldsymbol {\alpha}) \mathbf {p} \right\} ^ {2} \right] ^ {1 / 2}}, \tag {10}
$$

它随重新参数化而变化，但固有曲率半径$R _ { \mathrm { I } }$不变，正如Bates and Watts (1981)所证明的。因此，(10)的倒数有时被称为参数效应曲率（Ratkowsky, 1983）。在自然参数化下，当加速度向量与切平面正交（向量$\mathbf { h } ( \mathbf { p } , \pmb { \alpha } )$与$\mathbf{G}$正交）时，我们有$R _ { \mathrm { F } } = R _ { \mathrm { I } }$。

上局部凸性水平定义为

$$
\bar {S} _ {\mathrm {L C}} = \min  _ {\boldsymbol {\alpha}, \mathbf {p}} R _ {\mathrm {F}} ^ {2} (\boldsymbol {\alpha}, \mathbf {p}). \tag {11}
$$

Demidenko (2000)证明，如果$S ( \pmb { \alpha } ) < \overline { { S } } _ { \mathrm { L C } }$，则Hessian在$\pmb { \alpha }$处正定。由于$R _ { \mathrm { F } } ( \pmb { \alpha } , \mathbf { p } ) \leqslant R _ { \mathrm { I } } ( \pmb { \alpha } , \mathbf { p } )$，对于任何回归我们得到

$$
\bar {S} _ {\mathrm {L C}} \leqslant \bar {S} _ {\mathrm {L U}}. \tag {12}
$$

换句话说，局部凸性是比局部单峰性更严格的函数性质。

以下结果建立了SS的固有曲率与局部单峰性之间的关系。

**定理2**（局部和全局单峰性准则）。在水平集$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$的每个分量中，最多只有一个局部最小值。此外，如果$\pmb { \alpha } _ { \ast }$是一个局部最小化点，使得$S \left( \alpha _ { * } \right) < \overline { { S } } _ { \mathrm { L U } } < \overline { { S } } _ { \mathrm { E } }$且水平集$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$是连通的，则$\pmb { \alpha } _ { \ast }$是全局最小化点。

**证明**。设$\mathbf{p}$为任意$m \times 1$向量。用$\mathbf { p } ^ { \prime }$左乘(6)中定义的半Hessian，用$\mathbf{p}$右乘，我们得到

$$
\mathbf {p} ^ {\prime} \mathbf {G} ^ {\prime} (\boldsymbol {\alpha}) \mathbf {G} (\boldsymbol {\alpha}) \mathbf {p} - \sum_ {i = 1} ^ {n} e _ {i} (\boldsymbol {\alpha}) \mathbf {p} ^ {\prime} \mathbf {H} _ {i} (\boldsymbol {\alpha}) \mathbf {p}. \tag {13}
$$

我们希望这个量在梯度为零的地方$\mathbf { G } ^ { \prime } ( \pmb { \alpha } ) \mathbf { e } ( \pmb { \alpha } ) = \mathbf { 0 }$为正。在此限制下，将Cauchy不等式(4)应用于(13)的第二项，我们得到

$$
\mathbf {p} ^ {\prime} \mathbf {G} ^ {\prime} (\alpha) \mathbf {G} (\alpha) \mathbf {p} - S ^ {1 / 2} (\alpha) \sqrt {\mathbf {h} ^ {\prime} (\mathbf {p} , \alpha) \mathbf {P} (\mathbf {p} , \alpha) \mathbf {h} (\mathbf {p} , \alpha)} \tag {14}
$$

对任意非零$\mathbf{p}$为正。注意，如果$\mathbf{h}$是矩阵$\mathbf { G }$列向量的线性组合，则(14)为零，但此时$R _ { \mathrm { I } } = \infty$。根据定理1，在水平集$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$的每个分量中，最多有一个局部最小值。此外，不等式$\overline { { S } } _ { \mathrm { L U } } < \overline { { S } } _ { \mathrm { E } }$意味着$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$的每个（非空）分量上至少有一个局部最小值。由于$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$是连通的，只有一个分量$L \left( \overline { { S } } _ { \mathrm { L U } } \right)$，且$\pmb { \alpha } _ { \ast }$是唯一的局部最小值。然而，如果$\pmb { \alpha } \notin L \left( \overline { { S } } _ { \mathrm { L U } } \right)$，则$S \left( \pmb { \alpha } _ { \ast } \right) < \overline { { S } } _ { \mathrm { L U } } \leqslant S ( \pmb { \alpha } )$。因此，$\pmb { \alpha } _ { \ast }$是全局最小值。□

换句话说，上局部单峰性水平等于固有曲率的最小平方半径，或与(11)类似，我们有

$$
\bar {S} _ {\mathrm {L U}} = \min  _ {\boldsymbol {\alpha}, \mathbf {p}} R _ {\mathrm {I}} ^ {2} (\boldsymbol {\alpha}, \mathbf {p}). \tag {15}
$$

"上"这个词意味着，如果SS $S$大于(15)的右边，则存在观测值$y _ { 1 } , \ldots , y _ { n }$和${ \pmb { \alpha } } _ { 0 }$使得梯度为零但Hessian在${ \pmb { \alpha } } _ { 0 }$处不是非负定的。

在实践中，不需要计算局部单峰性的精确值——较低的近似可能就足够了（见示例部分）。用没有上划线的符号表示小于或等于其最大值的水平，$S _ { \mathrm { L U } } { \leqslant } \overline { { S } } _ { \mathrm { L U } }$。对于固有线性回归，$\overline { { S } } _ { \mathrm { L U } } = \infty$（Pazman, 1993）。

Demidenko (2000)之前已经证明了使用(11)中定义的$S _ { \mathrm { L C } }$的类似准则。定理2中表述的准则更强，如不等式(12)所示。如上所述，SS的凸性受重新参数化的影响，但局部单峰性不受影响。此外，在理想的参数化下，局部凸性和单峰性是一致的。

现在我们考虑当$\pmb { \alpha }$固定时，如何计算由(7)定义的$\min_\mathbf{p} R _ { \mathrm { I } } ^ { 2 } ( { \pmb \alpha } , { \pmb \ p } )$。为此，我们将(7)分母的平方写成矩阵形式，记$\mathbf { H } = [ \mathbf { H } _ { 1 } , \dots , \mathbf { H } _ { n } ] ^ { \prime }$，这是一个由二阶导数组成的$nm \times m$矩阵。可以直接验证$\mathbf { h } = \left( \mathbf { I } _ { n } \otimes \mathbf { p } ^ { \prime } \right) \mathbf { H } _ { \mathbf { F } }$，所以分母的平方等于$\mathbf { p } ^ { \prime } \mathbf { H } ^ { \prime } \left( \mathbf { P } \otimes \mathbf { p p } ^ { \prime } \right) \mathbf { H p }$，其中$\otimes$表示Kronecker矩阵乘积。因此，我们得到以下最小化问题：

$$
\varphi = \frac {\left(\mathbf {p} ^ {\prime} \mathbf {G} ^ {\prime} \mathbf {G p}\right) ^ {2}}{\mathbf {p} ^ {\prime} \mathbf {H} ^ {\prime} \left(\mathbf {P} \otimes \mathbf {p p } ^ {\prime}\right) \mathbf {H p}}, \tag {16}
$$

这可以通过对重复特征值问题的轻微修改来解决（Demidenko, 2000）。事实上，应用Cholesky分解，我们得到$\mathbf { G } ^ { \prime } \mathbf { G } = \mathbf { T } ^ { \prime } \mathbf { T }$，其中$\mathbf { T }$是非奇异矩阵。那么(16)等价于最大化问题

$$
\varphi_ {\max } = \max  _ {\mathbf {q} ^ {\prime} \mathbf {q} = 1} \mathbf {q} ^ {\prime} \mathbf {Q} ^ {\prime} \left(\mathbf {P} \otimes \mathbf {T} ^ {- 1} \mathbf {q q} ^ {\prime} \mathbf {T} ^ {\prime - 1}\right) \mathbf {Q} \mathbf {q}, \tag {17}
$$

其中${ \bf Q } { = } { \bf H } { \bf T } ^ { - 1 }$。为了计算这个最大值，我们按以下步骤进行：给定${ \bf q } _ { 0 }$，计算矩阵$\mathbf { Q } ^ { \prime } \left( \mathbf { P } \otimes \mathbf { T } ^ { - 1 } \mathbf { q } _ { 0 } \mathbf { q } _ { 0 } ^ { \prime } \mathbf { T } ^ { \prime - 1 } \right) \mathbf { Q } = \mathbf { K }$并找到其最大特征向量${ \bf q } _ { 1 }$。然后重新计算矩阵$\mathbf{K}$并重复此过程直到收敛。重复Demidenko (2004)中的论证，可以证明特征值序列是递增的。${ \bf q } _ { 0 }$的一个好的初始值是矩阵$\mathbf { G } ^ { \prime } \mathbf { G }$的最小特征向量。早期作者使用基于Lagrange乘数准则的约束优化方法（Bates and Watts, 1980; Goldberg et al., 1983; Seber and Wild, 1989, Section 4.2.7）。因此，我们将最大曲率的计算归结为一个可在统计软件包中容易求解的特征值问题。

# 3. 几何解释

单参数非线性回归$\mathbf f ( \boldsymbol { \alpha } )$的局部单峰性概念如图2所示。在左图中，水平集$L = \left\{ { \bar { \alpha } } \in R ^ { 1 } : \| \mathbf { y } - \mathbf { f } ( \alpha ) \| ^ { 2 } < { \bar { r } } ^ { 2 } \right\}$的每个分量（弧）都有唯一的局部最小值。因此，SS在$L$上是单峰的。相反，在右图中，$L$上$B$和$C$处有两个局部最小值，因此SS不是局部单峰的。

对于多参数回归，方向$\mathbf{p}$上的固有曲率等于速度向量与$\mathbf{p}$共线、加速度向量与由一阶导数的$n \times m$矩阵$\mathbf{G}$定义的切平面正交的曲线的固有曲率。这条曲线称为测地线（Spivak, 1979）。因此，用几何术语来说，局部单峰性水平是期望曲面上测地线的固有曲率的最小平方半径。

固有曲率与局部单峰性之间的关系可以用代数术语来理解。事实上，局部单峰性和局部凸性都保证Hessian的正定性。区别在于后者使用经典（无约束）Cauchy不等式，前者在约束$\mathbf { G } ^ { \prime } ( \mathbf { y } - \mathbf { f } ) = \mathbf { 0 }$下使用不等式(4)。用几何术语来说，这个约束意味着曲线的加速度向量与由矩阵$\mathbf{G}$的列向量定义的切平面正交（Seber and Wild, 1989）。

如上所述，$\overline { { S } } _ { \mathrm { L U } } \geqslant \overline { { S } } _ { \mathrm { L C } }$。这由$R _ { \mathrm { I } } \geqslant R _ { \mathrm { F } }$这一事实得出，分别由(10)和(7)定义。对于单参数回归，将一阶和二阶导数向量定义为$\dot{\mathbf{f}}$和$\ddot{\mathbf{f}}$，我们得到

$$
R _ {\mathrm {F}} ^ {2} = \frac {\| \dot {\mathbf {f}} \| ^ {4}}{\| \ddot {\mathbf {f}} \| ^ {2}} = \frac {\| \dot {\mathbf {f}} \| ^ {2} \| \ddot {\mathbf {f}} \| ^ {2} - (\dot {\mathbf {f}} ^ {\prime} \ddot {\mathbf {f}}) ^ {2}}{\| \dot {\mathbf {f}} \| ^ {6}} R _ {\mathrm {I}} ^ {2} = \left(1 - \cos^ {2} (\ddot {\mathbf {f}}, \dot {\mathbf {f}})\right) R _ {\mathrm {I}} ^ {2},
$$

其中$\cos (\ddot{\mathbf{f}}, \dot{\mathbf{f}})$表示向量$\ddot{\mathbf{f}}$和$\dot{\mathbf{f}}$之间夹角的余弦。这个关系可以重写为

$$
R _ {\mathrm {F}} ^ {2} = \sin^ {2} (\ddot {\mathbf {f}}, \dot {\mathbf {f}}) R _ {\mathrm {I}} ^ {2}. \tag {18}
$$

特别地，这个公式意味着如果曲线$\mathbf{f}$是自然参数化的，则$\overline { { S } } _ { \mathrm { L U } } = \overline { { S } } _ { \mathrm { L C } }$，因为$\mathbf { \ddot { f } ^ { \prime } \dot { f } } = 0$。

现在我们利用关系式(18)推广到多参数情况。事实上，设$\mathbf{p}$为方向向量，则

$$
R _ {\mathrm {F}} ^ {2} = \sin^ {2} (\mathbf {h}, \mathbf {G}) R _ {\mathrm {I}} ^ {2}, \tag {19}
$$

其中$\sin ( \mathbf { h } , \mathbf { G } )$表示向量$\mathbf{h}$与矩阵$\mathbf{G}$张成的平面之间夹角的正弦。公式(19)可以用来通过$S _ { \mathrm { L C } }$从下方近似局部单峰性。事实上，如果对所有$\pmb { \alpha }$和$\mathbf { p }$都有$\sin ^ { 2 } ( \mathbf { h } , \mathbf { G } ) \geqslant \delta$，我们可以设$S _ { \mathrm { L U } } = S _ { \mathrm { L C } } / \delta$。

# 4. 直线回归和单向回归

在本节中，我们引入两类新的非线性回归。

我们考虑回归曲面$\{ \mathbf { f } ( \pmb { \alpha } ) , \pmb { \alpha } \in \pmb { \Theta } \}$上的曲线。$\mathbf{f}$上的曲线可以表示为$\mathbf{f}(\psi(\lambda))$，其中$\psi(\lambda)$是$R ^ { m }$中的曲线，$\lambda \in R ^ { 1 }$。$R ^ { m }$中最简单的曲线是通过$\pmb { \alpha }$沿方向$\mathbf { p } \in R ^ { m }$的直线。那么定义为$\pmb { \eta } ( \lambda ) = \mathbf { f } ( \pmb { \alpha } + \lambda \mathbf { p } )$的$\mathbf{f}$上的曲线称为直线定向的，如果其导数构成正角。一般来说，我们得到以下定义。

**定义4**。如果非线性回归(1)满足

$$
\left(\boldsymbol {\alpha} _ {2} - \boldsymbol {\alpha} _ {1}\right) ^ {\prime} \mathbf {G} ^ {\prime} \left(\boldsymbol {\alpha} _ {1}\right) \mathbf {G} \left(\boldsymbol {\alpha} _ {2}\right) \left(\boldsymbol {\alpha} _ {2} - \boldsymbol {\alpha} _ {1}\right) \geqslant 0 \tag {20}
$$

对所有$\pmb{\alpha}_1, \pmb{\alpha}_2 \in \pmb{\Theta}$成立，则称其为直线定向的。

为了说明这个定义，我们取${ \pmb { \mathscr { a } } } _ { 1 } \in { \pmb { \Theta } }$和$\mathbf { p } \in R ^ { m }$，这样$\mathbf{f}$上的曲线定义为$\pmb { \eta } ( \lambda ) = \mathbf { f } \left( \pmb { \alpha } _ { 1 } + \lambda \mathbf { p } \right)$。由于$\dot { \pmb { \eta } } _ { 1 } = \mathbf { G } \left( \pmb { \alpha } _ { 1 } \right) \mathbf { p }$且$\dot { \pmb { \eta } } _ { 2 } = \mathbf { G } \left( \pmb { \alpha } _ { 2 } \right) \mathbf { p }$，其中${ \pmb { \alpha } } _ { 2 } = { \pmb { \alpha } } _ { 1 } + \lambda _ { * } { \bf p }$，如果$\pmb { \dot { \eta } } _ { 1 } ^ { \prime } \pmb { \dot { \eta } } _ { 2 } = \mathbf { p } ^ { \prime } \mathbf { G } ^ { \prime } \left( \pmb { \alpha } _ { 1 } \right) \mathbf { G } \left( \pmb { \alpha } _ { 2 } \right) \mathbf { p } \geqslant 0$，则曲线是直线定向的。但${ \bf p } = \left( { \pmb { \alpha } } _ { 2 } - { \pmb { \alpha } } _ { 1 } \right) / { \lambda _ { * } }$，所以$\mathbf{f}$上的曲线是直线定向的当且仅当(20)成立。直线定向回归的一个充分条件是矩阵${ \bf G } ^ { \prime } \left( { \pmb { \alpha } } _ { 1 } \right) { \bf G } \left( { \pmb { \alpha } } _ { 2 } \right)$是非负定的。

单参数非线性回归是直线定向的，如果任意两点处导数之间的夹角是直角或锐角，即$\dot { \mathbf { f } } ^ { \prime } ( \alpha _ { 1 } ) \dot { \mathbf { f } } \left( \alpha _ { 2 } \right) \geqslant 0$。

显然，线性回归$\mathbf { f } ( { \pmb { \alpha } } ) = \mathbf { X } { \pmb { \alpha } }$是直线定向的，因为矩阵$\mathbf { G } ^ { \prime } \left( \pmb { \alpha } _ { 1 } \right) \mathbf { G } \left( \pmb { \alpha } _ { 2 } \right) = \mathbf { X } ^ { \prime } \mathbf { X }$是非负定的。

我们证明，由$\mathbf { f } ( { \pmb { \alpha } } ) = \psi ( \mathbf { X } { \pmb { \alpha } } )$定义的拟线性回归（其中$\psi$是$R ^ { 1 }$上的单调函数，$\mathbf { X }$是满秩的$n \times m$设计矩阵）是直线定向的。事实上，对于这个回归，$\mathbf { G } ( \pmb { \alpha } ) = \mathbf { L } ( \pmb { \alpha } ) \mathbf { X }$，其中$\mathbf { L } ( \pmb { \alpha } ) = \mathrm{diag} \left( \dot { \psi } ( \mathbf { X } \pmb { \alpha } ) \right)$是对角元素全非负（或全非正）的$n \times n$对角矩阵。那么，

$$
\mathbf {G} ^ {\prime} \left(\alpha_ {1}\right) \mathbf {G} \left(\alpha_ {2}\right) = \mathbf {X} ^ {\prime} \mathbf {D} \mathbf {X}, \tag {21}
$$

其中$\mathbf { D } = \mathbf { L } \left( \pmb { \alpha } _ { 1 } \right) \mathbf { L } \left( \pmb { \alpha } _ { 2 } \right)$是对角线上元素非负的对角矩阵。显然，矩阵(21)对所有${ \pmb { \alpha } } _ { 1 }$和$\pmb { \alpha } _ { 2 }$都是非负定的。拟线性回归的重要特例是$\psi ( s ) = \exp ( s )$、$\psi ( s ) = s ^ { p }$和$\psi ( s ) = 1 / s$——分别是指数回归、幂回归和双曲回归（Demidenko, 1996, 2000）。定义为$f _ { i } \left( \alpha _ { 1 } , \alpha _ { 2 } \right) = \left( \alpha _ { 1 } x _ { i } \right) / \left( \alpha _ { 2 } + x _ { i } \right)$且$\alpha _ { 1 } > 0$、$\alpha _ { 2 } > 0$的Michaelis-Menten函数（Bates and Watts, 1988），在重新参数化$z _ { 1 } = 1 / x _ { i }$、$\beta _ { 1 } = \alpha _ { 2 } / \alpha _ { 1 }$、$\beta _ { 2 } = 1 / \alpha _ { 1 }$后变为单向回归$\left( \beta _ { 1 } + \beta _ { 2 } z _ { i } \right) ^ { - 1 }$。另一方面，定义为$\mathbf{f}(\alpha_1, \alpha_2, \alpha_3) = \alpha_1 + \alpha_2 \mathbf{x} + \alpha_2^2 \mathbf{z}$且$\alpha_2 \geqslant 0$（$\mathbf{x} \neq \mathbf{0}$且$\mathbf{z} \neq \mathbf{0}$）的二次回归，如果$\mathbf { x } ^ { \prime } \mathbf { z } < \mathbf { 0 }$则不是单向的。

两个拟线性回归之和是单向的。事实上，如果$f _ { i } ( \pmb { \alpha } ) = \psi \left( \pmb { \alpha } ^ { \prime } \mathbf { x } _ { i } \right) + \varphi \left( \pmb { \alpha } ^ { \prime } \mathbf { x } _ { i } \right)$且${ \dot { \psi } } { \dot { \varphi } } > 0$，则$\mathbf { G } = \left[ \mathrm{diag} \left( \dot { \psi } ( \mathbf { X } \pmb { \alpha } ) \right) + \mathrm{diag} \left( \dot { \varphi } ( \mathbf { X } \pmb { \alpha } ) \right) \right] \mathbf { X }$，矩阵${ \bf G } ^ { \prime } \left( { \pmb { \alpha } } _ { 1 } \right) { \bf G } \left( { \pmb { \alpha } } _ { 2 } \right)$是非负定矩阵。

除了$R ^ { m }$中的直线，还可以选择测地线来刻画回归曲面的"平直"程度。如果$\mathbf{f}$上的曲线定义为$\pmb { \eta } ( \lambda ) = \mathbf { f } ( \pmb { \psi } ( \lambda ) )$，则二阶导数（加速度向量）可以表示为向量形式$\ddot { \pmb { \eta } } = ( \mathbf { I } _ { n } \otimes \pmb { \psi } ) \mathbf { H } \pmb { \psi } + \mathbf { G } \dot { \pmb { \psi } }$，其中$\psi$和$\ddot{\psi}$是曲线$\psi ( \lambda )$的一阶和二阶导数的$m \times 1$向量。由于测地线的加速度向量与切平面正交，我们得到测地线的二阶向量非线性微分方程，

$$
\ddot{\boldsymbol {\psi}} = - \left(\mathbf {G} ^ {\prime} \mathbf {G}\right) ^ {- 1} \mathbf {G} ^ {\prime} \left(\mathbf {I} _ {n} \otimes \boldsymbol {\psi}\right) \mathbf {H} \boldsymbol {\psi}, \tag {22}
$$

其中$\mathbf{G}$和$nm \times m$二阶导数矩阵$\mathbf{H}$在$\mathbf { f } ( \psi ( \lambda ) )$处求值。根据微分方程理论，存在一条以最小曲率连接回归曲面上两点的测地线。对于线性回归，$\mathbf H = \mathbf 0$，测地线变为直线。如果非线性回归在测地线上导数之间的夹角是直角或锐角，我们称其为单向的。在代数上，我们用以下形式表达。

**定义5**。如果非线性回归(1)满足

$$
\left(\psi_ {2} - \psi_ {1}\right) ^ {\prime} \mathbf {G} _ {1} ^ {\prime} \mathbf {G} _ {2} \left(\psi_ {2} - \psi_ {1}\right) \geqslant 0,
$$

其中$\pmb { \psi } _ { k } = \pmb { \psi } _ { k } \left( \lambda _ { k } \right)$，$\mathbf { G } _ { k } = \mathbf { G } \left( \psi _ { k } \left( \lambda _ { k } \right) \right)$对所有$\lambda _ { 1 }$、$\lambda _ { 2 }$（$k = 1 , 2$）成立，$\psi$是(22)的解，则称其为单向的。

虽然我们无法证明这一点，但我们假设对于直线定向和单向回归，局部单峰性准则转化为全局准则。

**猜想**。对于直线定向或单向回归，局部单峰性水平集是连通的。对于直线定向回归，局部凸性水平集是凸的。因此，如果对于直线定向或单向回归，$S _ { \mathrm { L U } }$是局部单峰性水平，$\pmb { \alpha } _ { \ast }$是SS满足$S \left( \pmb { \alpha } _ { \ast } \right) < S _ { \mathrm { L U } } < S _ { \mathrm { E } }$的局部最小化点，则$\pmb { \alpha } _ { \ast }$是全局最小化点。即，$\pmb { \alpha } _ { \ast }$是真正的最小二乘估计。

换句话说，如果对于直线定向或单向回归，SS的局部最小值小于固有曲率的最小平方半径，则找到的最小值是全局的。

# 5. 局部单峰性计算示例

我们用以下三个例子来说明局部单峰性的计算：多线性回归、log-Gompertz（指数）回归和拟线性指数模型。在第一个例子中，我们直接计算局部单峰性水平。在第二个例子中，我们通过求解多项式方程并评估存在多个局部最小值的频率来找到SS的全局最小值。在最后一个例子中，我们通过计算局部凸性水平来推导SS的全局准则。

## 5.1. 多线性回归

这类非线性回归在Demidenko (2000)中引入，

$$
\mathbf {f} (\boldsymbol {\beta}, \rho) = \mathbf {X} \boldsymbol {\beta} + \rho \mathbf {u} - \rho \mathbf {Z} \boldsymbol {\beta}, \quad \boldsymbol {\beta} \in R ^ {m}, \rho \in R ^ {1}, \tag {23}
$$

其中$\mathbf { X }$和$\mathbf { Z }$是固定的满秩$n \times m$设计矩阵，$\mathbf{u}$是$n \times 1$向量。此外，假设矩阵$\mathbf { X } - \rho \mathbf { Z }$对所有$\rho$都满秩。多线性回归的局部凸性水平已在Demidenko (2000)中找到；这里我们的目标是找到局部单峰性水平。将使用以下结果。

**命题3**。设$\mathbf{G}$和$\mathbf { F }$分别是满秩的$n \times m$和$n \times k$矩阵$( k \leqslant m \leqslant n )$，使得矩阵$\mathbf{F}$的列是矩阵$\mathbf{G}$的列的线性组合。那么对任意$n \times 1$向量$\mathbf{t}$，有$\mathbf{t}^{\prime} \left\{ \mathbf { I } - \mathbf { G } \big ( \mathbf { G } ^ { \prime } \mathbf { G } \big ) ^ { - 1 } \mathbf { G } ^ { \prime } \right\} \mathbf { t } \leqslant \mathbf { t } ^ { \prime } \left\{ \mathbf { I } - \mathbf { F } \big ( \mathbf { F } ^ { \prime } \mathbf { F } \big ) ^ { - 1 } \mathbf { F } ^ { \prime } \right\} \mathbf { t }$。

这个不等式有清晰的几何解释：点到线性空间的距离比到其任何子空间的距离更短。

对于回归(23)，我们有$\mathbf { G } = [ \mathbf { X } - \rho \mathbf { Z } ; \mathbf { u } - \mathbf { Z } \pmb { \beta } ]$，这是$n \times ( m + 1 )$矩阵，且

$$
\mathbf {H} _ {i} = \left[ \begin{array}{l l} 0 & \mathbf {z} _ {i} \\ \mathbf {z} _ {i} ^ {\prime} & \mathbf {0} \end{array} \right] \tag {24}
$$

是$( m + 1 ) \times ( m + 1 )$矩阵，其中$\mathbf { z } _ { i }$是矩阵$\mathbf{Z}$的第$i$行。根据命题3，如果$\mathbf { G } = [ \mathbf { X } - \rho \mathbf { Z } ; \mathbf { u } - \mathbf { Z } \beta ]$被矩阵$\mathbf { X } - \rho \mathbf { Z }$替换，则(7)的分母增大。因此，省略参数$\pmb{\alpha}$，我们有$\mathbf { h } ^ { \prime } \left\{ \mathbf { I } - \mathbf { G } \big ( \mathbf { G } ^ { \prime } \mathbf { G } \big ) ^ { - 1 } \mathbf { G } ^ { \prime } \right\} \mathbf { h } \geqslant \mathbf { h } ^ { \prime } \mathbf { P } \mathbf { h }$，其中${ \bf P } ( \rho ) = { \bf I } - ( { \bf X } - \rho { \bf Z } ) \big \{ ( { \bf X } - \rho { \bf Z } ) ^ { \prime } ( { \bf X } - \rho { \bf Z } ) \big \} ^ { - 1 } ( { \bf X } - \rho { \bf Z } ) ^ { \prime }$。进一步，按照Demidenko (2000)的方法，我们得到

$$
\bar {S} _ {\mathrm {L U}} \geqslant S _ {\mathrm {L U}} = \min  _ {\mathbf {p}} \frac {\left[ \mathbf {p} ^ {\prime} \mathbf {W} ^ {\prime} \left\{\mathbf {I} - \mathbf {Z} \left(\mathbf {Z} ^ {\prime} \mathbf {Z}\right) ^ {- 1} \mathbf {Z} ^ {\prime} \right\} \mathbf {W p} \right] ^ {2}}{\max  _ {\rho} \mathbf {h} ^ {\prime} \mathbf {P} (\rho) \mathbf {h}}, \tag {25}
$$

其中${ \mathbf W } = [ { \mathbf X } ; { \mathbf u } ]$是扩展矩阵。为了找到给定$\rho$的$S _ { \mathrm { L U } }$，我们使用重复特征值问题(16)在$\mathbf{p}$上求(25)的最小值。附录中描述了计算(25)右边以及特别地当$\mathbf { p }$固定时分母作为$\rho$函数的最大值的算法。

## 5.2. Log-Gompertz曲线

Gompertz曲线由德国科学家Gompertz于1825年引入，用于建模生命表中的风险（Seber and Wild, 1989）。后来，它在生物学和医学中非常流行，用于建模肿瘤生长（Bajzer and Vuk-Pavlovic, 1997）。特别地，该曲线描述了肿瘤生长的三个阶段：发展期、快速生长期和停滞期。假设乘性误差，Gompertz模型的估计归结为非线性回归

$$
y _ {t} = \alpha_ {1} + \alpha_ {2} \mathrm {e} ^ {\alpha_ {3} x _ {t}} + \varepsilon_ {t}, \tag {26}
$$

其中$y _ { t }$是对数观测值，$x _ { t }$是观测时间点，$\alpha _ { 1 }$、$\alpha_2$和$\alpha _ { 3 }$是参数（$t = 1 , \ldots , n$）。不失一般性，我们可以假设$\{ x _ { t } \}$是递增序列。此外，我们假设$\{ x _ { t } \}$至少取三个不同的值。参数$\alpha _ { 2 }$和$\alpha _ { 3 }$可以假设为负或非负。如果$\alpha _ { 2 }$和$\alpha _ { 3 }$为负，则增长模型是时间的增函数。参数$\alpha _ { 3 }$（速率）是固有非线性的——它指示肿瘤接近其渐近线$\alpha _ { 1 }$的速度。对数尺度上的模型(26)在参数估计方面比原始Gompertz曲线更简单。它也反映了生长测量（通常是肿瘤体积）的误差与其值成正比这一事实；这个模型称为log-Gompertz模型（Demidenko, 2004）。最小二乘估计的存在性已在Demidenko (1996)和Jukic et al. (2004)中研究。在本文中，我们集中讨论唯一性。

通常，时间点是等距的，所以我们假设$x _ { t } = t$来研究(26)。在这种情况下，SS最小化可以归结为多项式方程。这有助于通过模拟评估SS有多个局部最小值的概率。计算用球体肿瘤生长模型数据说明。

我们按以下方式将SS最小化归结为多项式方程。容易证明，在消去线性参数$\alpha _ { 1 }$和$\alpha _ { 2 }$后，SS的最小化等价于在$\alpha _ { 3 }$上的单变量最大化，

$$
r (\alpha_ {3}) = \frac {\left[ \sum_ {t = 1} ^ {n} y _ {t} e _ {t} - \overline {{y}} \sum_ {t = 1} ^ {n} e _ {t} \right] ^ {2}}{\sum_ {t = 1} ^ {n} e _ {t} ^ {2} - n ^ {- 1} \left(\sum_ {t = 1} ^ {n} e _ {t}\right) ^ {2}},
$$

其中$e _ { t } = e _ { t } \left( \alpha _ { 3 } \right) = \exp \left( \alpha _ { 3 } x _ { t } \right)$。用统计学术语，$\alpha _ { 3 }$的LS估计最大化$\{ y _ { t } \}$和$\left\{ \mathrm { e } ^ { \alpha _ { 3 } x _ { t } } \right\}$之间的相关性。令$z = \exp \left( \alpha _ { 3 } \right)$，$r (\alpha_3)$的驻点是$( 3 n - 1 )$次多项式方程$P _ { 3 n - 1 } ( z ) = 0$的解，其中

$$
\begin{array}{l} P _ {3 n - 1} (z) = \left[ \sum_ {t = 1} ^ {n} z ^ {2 t} - n ^ {- 1} \left(\sum_ {t = 1} ^ {n} z ^ {t}\right) ^ {2} \right] \left[ \sum_ {t = 1} ^ {n} t y _ {t} z ^ {t} - \bar {y} \sum_ {t = 1} ^ {n} t z ^ {t} \right] \\ - \left[ \sum_ {t = 1} ^ {n} y _ {t} z ^ {t} - \bar {y} \sum_ {t = 1} ^ {n} z ^ {t} \right] \left[ \sum_ {t = 1} ^ {n} t z ^ {2 t} - n ^ {- 1} \left(\sum_ {t = 1} ^ {n} z ^ {t}\right) \left(\sum_ {t = 1} ^ {n} t z ^ {t}\right) \right]. \tag {27} \end{array}
$$

注意，项$z ^ { 3 n }$在(27)中消失，所以多项式的次数是$3 n - 1$。多项式方程的所有$3 n - 1$个根可以使用标准软件高精度地找到（我们使用S-Plus中的polyroot函数），但只有少数是实根。因此，我们可以通过模拟评估SS有多频繁地具有多个局部最小值。在图3中，我们展示了$\alpha _ { 1 } = 6$、$\alpha _ { 2 } = - 5$、$\alpha _ { 3 } = - 0 . 1$时$n = 5 5$和$30$的模拟结果。这些参数值接近真实数据例子的估计值，见下文。对每个$\sigma$，我们根据(26)模拟$\{ y _ { i } , i = 1 , \ldots , n \}$，其中$\varepsilon _ { i } \sim \mathcal { N } \left( 0 , \sigma ^ { 2 } \right)$且$x _ { i } = i$；实验次数为1000。然后我们求解代数方程

## 5.3. 指数回归

指数回归是$\psi = \exp$的拟线性回归。如第2节的讨论所示，重新参数化$\pmb { \alpha } _ { \ast } = \mathbf { T } \pmb { \alpha }$和${ \bf X } _ { * } = { \bf X } { \bf T } ^ { - 1 }$（其中$\mathbf { T }$是Cholesky三角矩阵，满足$\mathbf { T } ^ { \prime } \mathbf { T } = \mathbf { X } ^ { \prime } \mathbf { X }$）显著改进最小化并"圆化"置信区域，因为这种参数化降低了回归曲率。特别地，在这种参数化下，局部凸性和单峰性很接近。为了找到局部凸性水平，我们需要找到值$\textstyle S = \sum e _ { i } ^ { 2 }$（其中$e _ { i } = y _ { i } - \mathrm { e } ^ { \alpha ^ { \prime } \mathbf { x } _ { i } }$），使得对所有$\pmb { \alpha } : S ( \pmb { \alpha } ) < S$，SS的Hessian矩阵正定。首先，我们考虑标量情况，然后展示如何修改推导以适用于多元指数回归。

SS等于$S$的二阶导数的最小化归结为Lagrange函数：

$$
\mathscr {L} \left(e _ {1}, \dots , e _ {n}; \lambda\right) = \sum_ {i = 1} ^ {n} \left(y _ {i} ^ {2} - e _ {i} y _ {i} - 2 e _ {i} \left(y _ {i} - e _ {i}\right)\right) x _ {i} ^ {2} - 2 \lambda \left(\sum_ {i = 1} ^ {n} e _ {i} ^ {2} - S\right).
$$

一阶条件给出解

$$
e _ {i} = \frac {3}{4} \frac {y _ {i} x _ {i} ^ {2}}{x _ {i} ^ {2} - \lambda}, \quad \lambda < \min x _ {i} ^ {2}. \tag {28}
$$

Lagrange乘数$\lambda$和$S$通过一对一关系相关联：

$$
S = \frac {9}{1 6} \sum_ {i = 1} ^ {n} y _ {i} ^ {2} x _ {i} ^ {4} / \left(x _ {i} ^ {2} - \lambda\right) ^ {2}.
$$

我们注意到右边是$\lambda$在区间$\left( - \infty , \min x _ { i } ^ { 2 } \right)$上的增函数且取正值。由于我们关心二阶导数的正性，我们需要找到$\lambda$方程的最小根，

$$
\sum \left(y _ {i} ^ {2} - e _ {i} y _ {i} - 2 e _ {i} \left(y _ {i} - e _ {i}\right)\right) x _ {i} ^ {2} = 0, \tag {29}
$$

其中$e _ { i }$由(28)定义。将(28)代入(29)，经过一些代数运算，我们得到以下关于$\lambda$的方程：

$$
\sum_ {i = 1} ^ {n} \left[ \frac {8}{9} y _ {i} ^ {2} x _ {i} ^ {2} - \frac {x _ {i} ^ {2} - 2 \lambda}{\left(x _ {i} ^ {2} - \lambda\right) ^ {2}} y _ {i} ^ {2} x _ {i} ^ {4} \right] = 0. \tag {30}
$$

容易验证左边在$( - \infty , 0 )$上是增函数；在零点导数为零且在该点达到最大值$\sum y _ { i } ^ { 2 } x _ { i } ^ { 2 } > { \frac { 8 } { 9 } } \sum y _ { i } ^ { 2 } x _ { i } ^ { 2 }$；在$\left( 0 , \min x _ { i } ^ { 2 } \right)$上是减函数。由于我们在寻找最小的$\lambda$，(30)的解应该在区间$( - \infty , 0 )$中寻找。由于$\lambda$和$S$通过一对一关系相关联，我们可以将(30)视为$S$的隐函数。设此函数为$W ( s )$，其中$s = \sqrt { S } \geqslant 0$。那么我们有

$$
\begin{array}{l} W (0) = \frac {8}{9} \sum y _ {i} ^ {2} x _ {i} ^ {2}, \quad W (\infty) = \infty , \\ W \left(\frac {3}{4} \sqrt {\sum_ {i = 1} ^ {n} y _ {i} ^ {2} x _ {i} ^ {2}}\right) = - \frac {1}{9} \sum y _ {i} ^ {2} x _ {i} ^ {2}. \end{array}
$$

第一个等式来自$S = 0$对应$\lambda = - \infty$这一事实，第二个等式来自$S = \infty$对应$\lambda = \min x _ { i } ^ { 2 }$此时$x _ { i } ^ { 2 } - 2 \lambda < 0$这一事实，第三个等式来自$S = \frac { 9 } { 1 6 } \sum _ { i = 1 } ^ { n } y _ { i } ^ { 2 } x _ { i } ^ { 2 }$对应$\lambda { = } 0$这一事实。在区间$( 0 , s _ { * } )$上对$W ( S )$公式求导，其中$W ( s _ { * } ) = 0$，导致不等式$W / \mathrm { d } s = \frac { 8 } { 3 } \lambda s < 0$且$\mathrm { d } ^ { 2 } W / \mathrm { d } s ^ { 2 } > 0$。但$W ( S ) > W ( 0 ) + s W ^ { \prime } ( 0 )$，

$$
W ^ {\prime} (0) = \left. \frac {\mathrm {d} W}{\mathrm {d} s} \right| _ {s = 0} = \frac {8}{3} \lim _ {\lambda \rightarrow - \infty} \lambda \sqrt {\sum_ {i = 1} ^ {n} \frac {y _ {i} ^ {2} x _ {i} ^ {4}}{\left(x _ {i} ^ {2} - \lambda\right) ^ {2}}} = \frac {8}{3} \sqrt {\sum_ {i = 1} ^ {n} y _ {i} ^ {2} x _ {i} ^ {4}}.
$$

因此，我们得到对于所有满足$S < S _ { \mathrm { { L C } } }$的SS，其中

$$
S _ {\mathrm {L C}} = \frac {1}{9} \frac {\left(\sum y _ {i} ^ {2} x _ {i} ^ {2}\right) ^ {2}}{\sum y _ {i} ^ {2} x _ {i} ^ {4}},
$$

指数回归的SS的Hessian是正的（SS是局部凸的）。

为了获得多元指数回归的局部凸性/单峰性水平，我们计算

$$
S _ {\mathrm {L C}} = \min  _ {\mathbf {p} ^ {\prime} \mathbf {p} = \mathbf {1}} \frac {1}{9} \frac {\left(\sum y _ {i} ^ {2} \left(\mathbf {x} _ {i} ^ {\prime} \mathbf {p}\right) ^ {2}\right) ^ {2}}{\sum y _ {i} ^ {2} \left(\mathbf {x} _ {i} ^ {\prime} \mathbf {p}\right) ^ {4}}
$$

使用第2节描述的迭代特征值算法。设$\mathbf{T}$为矩阵$\mathbf { A } = \sum y _ { i } ^ { 2 } \mathbf { x } _ { i } \mathbf { x } _ { i } ^ { \prime }$的Cholesky分解，$\mathbf { B } ( \mathbf { p } _ { 0 } ) = \sum y _ { i } ^ { 2 } \left( \mathbf { x } _ { i } ^ { \prime } \mathbf { p } _ { 0 } \right) ^ { 2 } \mathbf { x } _ { i } \mathbf { x } _ { i } ^ { \prime }$。具体地，计算$S _ { \mathrm { L C } }$的算法如下：(1) 计算矩阵$\mathbf{A}$的最大特征向量。(2) 计算矩阵$\mathbf { T } ^ { - 1 } \mathbf { B } \left( \mathbf { p } _ { 0 } \right) \left( \mathbf { T } ^ { \prime } \right) ^ { - 1 }$的最大向量$\mathbf{p}$。(3) 设$\mathbf { p } _ { 0 } = \mathbf { p }$。(4) 返回步骤(2)并迭代直到收敛。

由于指数回归是单向的，应用第4节的猜想，我们断言值小于$S _ { \mathrm { L C } }$的局部最小值是SS的全局最小值。为了测试这个准则的有效性，我们进行了$m = 2$、$n = 1 0$、$\alpha _ { 1 } = \alpha _ { 2 } = 0 . 1$且$\mathbf { x } _ { i } = ( 1 , i ) ^ { \prime }$的模拟研究。观测值$y _ { i } = \exp \left( \alpha _ { 1 } + \alpha _ { 2 } i \right) + \varepsilon _ { i }$，其中$\varepsilon _ { i } \sim \mathcal { N } \left( 0 , \sigma ^ { 2 } \right)$，针对$\sigma$在0.1到0.5区间的值生成。由于SS的全局最小值$S$可以用第5.2节的多项式方法精确找到，我们计算存在唯一局部最小值且$S < S _ { \mathrm { { L C } } }$的情况数。当残差不太大，$\sigma < 0 . 4$时，我们的准则$100\%$有效。对于$\sigma { = } 0 . 4$，$S < S _ { \mathrm { { L C } } }$的模拟比例是$98\%$，对于$\sigma = 0 . 5$是$90\%$，而SS只有单一局部最小值。这意味着全局准则对良好到中等拟合有效。然而，当模型不能充分拟合数据时，$S > S _ { \mathrm { { L C } } }$并不一定意味着找到的最小值是错误的。

# 6. 讨论

全局最小化是计算数学中最困难的问题之一（Horst and Pardalos, 1995; Horst and Tuy, 1996; Floudas, 2000）。它对统计问题有深远的影响，因为没有满意的全局最小准则，最小二乘最小化算法以及一般地，最大似然估计程序是不完整的。此外，对于几乎任何非线性参数估计，获得错误估计的概率都是正的。没有局部单峰性准则，置信区间可能是不相交的且容易被忽略。对估计准则（如SS或似然函数）数值性质的全面研究可能改进小样本中的统计显著性检验——Gallant (1975, 1987)的工作是这方面的一个好例子。到目前为止，回归中曲率的计算以及一般统计学中的曲率，纯粹作为回归非线性特征的理论兴趣。我们建立了全曲率和固有曲率与非线性回归中SS数值性质之间的联系。在本文中，我们只提出了全局最小的部分准则——还需要做很多工作来改进我们的结果并将其推广到更一般的最大似然估计问题。

# 附录A. (25)式的计算

我们从分母开始。分母的最大化等价于函数的最小化

$$
D (\rho) = \mathbf {h} ^ {\prime} (\mathbf {X} - \rho \mathbf {Z}) \mathbf {M} ^ {- 1} (\rho) (\mathbf {X} - \rho \mathbf {Z}) ^ {\prime} \mathbf {h}, \tag {31}
$$

其中${ \bf { M } } ( \rho ) = ( { \bf { X } } - \rho { \bf { Z } } ) ^ { \prime } ( { \bf { X } } - \rho { \bf { Z } } )$是$m \times m$非奇异矩阵。我们将证明(31)的最小值在实数轴上可达，并归结为求解三次方程。

事实上，函数$D ( \rho )$有渐近线，因为

$$
\lim _ {\rho \to \pm \infty} D (\rho) = \lim _ {\delta \to 0} \mathbf {h} ^ {\prime} (\delta \mathbf {X} - \mathbf {Z}) \big [ (\delta \mathbf {X} - \mathbf {Z}) ^ {\prime} (\delta \mathbf {X} - \mathbf {Z}) \big ] ^ {- 1} (\delta \mathbf {X} - \mathbf {Z}) ^ {\prime} \mathbf {h} = \mathbf {h} ^ {\prime} \mathbf {Z} \big (\mathbf {Z} ^ {\prime} \mathbf {Z} \big) ^ {- 1} \mathbf {Z} ^ {\prime} \mathbf {h}.
$$

此外，$D$关于$\rho$的导数是

$$
- \rho^ {- 1} \mathbf {h} ^ {\prime} \left[ 2 \mathbf {Z} \mathbf {M} ^ {- 1} (\rho) \left(\rho \mathbf {X} - \rho^ {2} \mathbf {Z}\right) ^ {\prime} + (\mathbf {X} - \rho \mathbf {Z}) \mathbf {M} ^ {- 1} (\rho) \left\{\rho \left(\mathbf {X} ^ {\prime} \mathbf {Z} + \mathbf {Z} ^ {\prime} \mathbf {X}\right) + 2 \rho^ {2} \mathbf {Z} ^ {\prime} \mathbf {Z} \right\} \mathbf {M} ^ {- 1} (\rho) (\mathbf {X} - \rho \mathbf {Z}) ^ {\prime} \right] \mathbf {h}.
$$

对于$\rho$绝对值较大的情况，我们有

$$
\frac {\mathrm {d} D}{\mathrm {d} \rho} = \mathrm {O} \left(- \frac {4}{\rho} \mathbf {h} ^ {\prime} \mathbf {Z} \left(\mathbf {Z} ^ {\prime} \mathbf {Z}\right) ^ {- 1} \mathbf {h}\right) < 0,
$$

这意味着$D ( \rho )$从下方趋近其渐近线。这暗示(31)的最小值在$( - \infty , \infty )$内达到。

为了找到(25)的最小值，我们按以下步骤进行。设$\rho _ { 0 }$为初始值，比如$\rho _ { 0 } = 0$。我们计算矩阵

$$
\mathbf {M} _ {0} = \left(\mathbf {X} - \rho_ {0} \mathbf {Z}\right) ^ {\prime} \left(\mathbf {X} - \rho_ {0} \mathbf {Z}\right), \quad \mathbf {P} _ {0} = \mathbf {M} _ {0} ^ {- 1} \left(\mathbf {X} ^ {\prime} \mathbf {Z} + \mathbf {Z} ^ {\prime} \mathbf {X}\right) \mathbf {M} _ {0} ^ {- 1}, \quad \mathbf {R} _ {0} = \mathbf {M} _ {0} ^ {- 1} \mathbf {Z} ^ {\prime} \mathbf {Z} \mathbf {M} _ {0} ^ {- 1},
$$

并求解以下三次方程作为非线性方程$\mathrm { d } D / \mathrm { d } \rho = 0$的近似：

$$
2 \mathbf {h} ^ {\prime} \mathbf {Z} \mathbf {M} _ {0} ^ {- 1} (\rho \mathbf {Z} - \mathbf {X}) ^ {\prime} \mathbf {h} + \mathbf {h} ^ {\prime} (\rho \mathbf {Z} - \mathbf {X}) \mathbf {P} _ {0} (\rho \mathbf {Z} - \mathbf {X}) ^ {\prime} \mathbf {h} + 2 \rho \mathbf {h} ^ {\prime} (\rho \mathbf {Z} - \mathbf {X}) \mathbf {R} _ {0} (\rho \mathbf {Z} - \mathbf {X}) ^ {\prime} \mathbf {h}.
$$

这个方程至少有一个实根。如果有三个实根，我们取使$D$最小的那个。设$\rho _ { 1 }$为该根，我们重新计算矩阵$\mathbf { M } _ { 0 }$、$\mathbf { P } _ { 0 }$和$\mathbf { R } _ { 0 }$，求解下一个三次方程，迭代直到收敛。序列$\{ \rho _ { s } , s = 0 , 1 , 2 , \ldots \}$至少有一个极限点，因为$D ( \rho )$的导数在$\rho$很大时为负，且在无穷远处不为零。此外，如果$\rho _ { * }$是$\rho _ { s }$当$s \to \infty$时的极限点，我们有$D ^ { \prime } \left( \rho _ { * } \right) = 0$，即$\rho _ { * }$给出$D$的最小值。
