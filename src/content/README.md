# 电子图书馆内容规范 (Library Content Guide)

本文件夹 (`src/content/`) 存储了“电子图书馆”的所有文献内容。
系统会自动扫描本目录下的所有 `.md` 文件，并将其展示在图书馆首页。

## 如何添加新文献？

1.  **文件命名**：请遵循 `ID-pdf翻译.md` 或 `ID-pdf原文.md` 的命名格式。
    *   例如：`181-004-pdf翻译.md`
2.  **填写表头 (Frontmatter)**：文件顶部必须包含 YAML 格式的元数据（详见下方模板）。
3.  **编写正文**：支持标准 Markdown 语法。
4.  **规范参考文献**：在文件末尾添加 `## 参考文献` 标题，并按行列出参考文献。

## 文件格式模板 (Template)

```markdown

title_en: "English Title (可选)"
author: "作者姓名"

short_publication: "出版简称 (推荐)"
```

## 核心格式要求 (Crucial Rules)

### 1. 参考文献规范 (References)
为确保系统能自动将参考文献解析为“结构化列表”并支持“文中角标跳转”，请务必遵守：
- **标题必须准确**：参考文献部分**必须**以 `## 参考文献` 或 `## References` 标题开始（注意 `##` 后面的空格）。
- **格式必须统一**：每一条参考文献**必须**以 `[数字]` 开头（如 `[1]`, `[20]`）。
- **换行要求**：虽然系统会尝试自动修复，但**强烈建议**每一条参考文献占一行。

### 2. 数学公式 (LaTeX)
- **块级公式**：使用 `$$ ... $$`。建议前后各留一个空行。
- **行内公式**：使用 `$ ... $`。

### 3. 图片资源
- 请将图片文件夹（如 `181-004-图片`）复制到项目根目录的 `public/` 文件夹中。
- 在 Markdown 中引用：`![图1](/181-004-图片/image01.png)`

## 字段定义

| 字段 | 说明 | 备注 |
| :--- | :--- | :--- |
| `title` | 文献标题 | 必填 |
| `short_publication` | **出版简称** | **推荐**。用于列表卡片展示，如 "9th ISSSR"。 |
| `type` | 文章类型 | 可选值：`期刊`、`书籍`、`会议`，其他值归为"其它" |
| `year` | 年份 | |
| `related_method_id` | **关联算法ID** | 如果填写（如 `mle`），文章顶部会显示跳转到计算器的按钮。 |
