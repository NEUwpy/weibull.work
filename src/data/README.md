# 威布尔案例库数据规范 (Case Database Schema)

本文件夹 (`src/data/`) 存储了“威布尔案例数据库”的核心数据源。
核心文件为：`cases.json`。

如果您希望手动向系统中添加新的案例数据，请遵循以下 JSON 格式规范。编辑完成后，**无需重启服务器**，Next.js 会自动热更新（或者重新 `npm run build` 以应用到生产环境）。

## JSON 字段说明 (Schema)

每个案例是一个 JSON 对象，必须包含以下字段：

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | String | **是** | 唯一标识符，建议使用 c+数字 或 uuid | `"c101"` |
| `name` | String | **是** | 案例显示的标题名称 | `"航空发动机叶片失效数据"` |
| `industry` | String | **是** | 所属行业，用于筛选 | `"航空航天"`, `"机械制造"`, `"电子元器件"` |
| `type` | String | **是** | 数据类型，用于筛选 | `"完全样本"`, `"右截尾"`, `"区间截尾"` |
| `size` | String | **是** | 样本量级 | `"小样本"`, `"中样本"`, `"大样本"` |
| `description`| String | 否 | 简短描述，显示在列表中 | `"某型号发动机在 2000 小时试车..."` |
| `dataRaw` | String | **是** | **原始数据文本**。格式为每行一个数字，支持 `F`(失效) 或 `S`(删失) 标记。请使用 `\n` 换行。 | `"100\n120 F\n150 S"` |
| `tags` | Array | 否 | 标签数组 | `["疲劳", "高温"]` |
| `related_paper_slug` | String | 否 | 关联的电子图书馆文件名 (不含 .md)。如果填写，界面会出现“查看文献”按钮。 | `"isssr-2023-review"` |
| `created_at` | String | 否 | 创建日期 | `"2024-01-20"` |

## 示例 (Example)

```json
[
  {
    "id": "demo_01",
    "name": "新建测试案例",
    "industry": "其他",
    "type": "完全样本",
    "size": "小样本",
    "description": "这是一个手动添加的测试案例。",
    "dataRaw": "10.5\n12.1\n15.6 F",
    "tags": ["测试", "手动"],
    "related_paper_slug": ""
  }
]
```

## 注意事项
1. **JSON 语法严格**：所有的键名必须用双引号 `""` 包裹。
2. **换行符**：在 `dataRaw` 中，请务必使用 `\n` 来表示换行，不要直接回车。
3. **文件编码**：请确保保存为 **UTF-8** 编码，否则中文可能乱码。
